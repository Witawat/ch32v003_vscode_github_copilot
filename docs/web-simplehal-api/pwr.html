SimplePWR — จัดการพลังงาน

ระดับสูง
ไลบรารี: SimpleHAL.h — ใช้ ไม่ต้อง include ไฟล์ย่อยเอง ทุกฟังก์ชัน PWR รวมอยู่ใน SimpleHAL.h แล้ว

ภาพรวม

SimplePWR จัดการโหมดพลังงานต่ำของ CH32V003 — ลดการใช้ไฟลงจาก ~3-5mA (active) เหลือระดับ µA เมื่อไม่ต้องทำงานต่อเนื่อง

โหมดการทำงานกระแสไฟRAMWakeup
Sleep CPU หยุด, peripherals ทำงานต่อ ~1-2 mA คงอยู่ Interrupt / Event ใด ๆ
Standby ทั้งหมดหยุด — 1.8V domain ปิด ~2-5 µA สูญหาย AWU, EXTI, Wakeup Pin
Standby พัง RAM: ข้อมูลใน RAM สูญหายทั้งหมด — main() จะเริ่มใหม่ตั้งแต่ต้นหลังจาก wakeup เหมือนเพิ่งเปิดไฟ

AWU — Auto Wake-Up

AWU (Auto Wake-Up) ใช้ LSI 128kHz จับเวลาในโหมด Standby — ปลุก MCU อัตโนมัติหลังจากหมดเวลา

ตารางอ้างอิงฟังก์ชัน

ฟังก์ชันพารามิเตอร์คืนค่าคำอธิบายใช้ร่วมกับ
PWR_Sleep() — void เข้า sleep — wake เมื่อมี interrupt ใด ๆ ต้องตั้ง interrupt ไว้ก่อน (เช่น attachInterrupt()) ไม่งั้นไม่มีอะไรมาปลุก — ทางลัดของ PWR_EnterSleepMode(WFI)
PWR_Standby(timeout_ms) timeout_ms: uint32_t void เข้า standby + AWU auto wake — RAM lost, main() restarts ตั้งค่า AWU ให้อัตโนมัติภายในจาก timeout_ms — ไม่ต้องเรียก PWR_ConfigureAWU() เอง (ทางลัดครบวงจร); หลัง wakeup ให้เรียก PWR_WasStandbyWakeup() ที่ต้น main() เพื่อรู้ว่าตื่นจาก standby
PWR_StandbyUntilInterrupt() — void เข้า standby — รอจนกว่า EXTI จะปลุก ใช้แทน PWR_Standby(timeout_ms) เมื่อต้องการปลุกด้วยขา EXTI แทนเวลา — ไม่ต้องตั้ง AWU เลย
PWR_EnterSleepMode(entry) entry: WFI/WFE void เข้า sleep mode ด้วย WFI หรือ WFE เวอร์ชันกำหนด entry เองของ PWR_Sleep() — ใช้แทนกัน ไม่ใช้คู่กัน
PWR_EnterStandbyMode(entry) entry: WFI/WFE void เข้า standby mode ด้วย WFI หรือ WFE ต่างจาก PWR_Standby() ตรงที่ไม่ตั้งค่า AWU ให้เอง — ต้องเรียก PWR_ConfigureAWU() เองก่อนถ้าต้องการปลุกด้วยเวลา (ใช้เมื่อต้องคุม prescaler/window เอง)
PWR_ConfigureAWU(prescaler, window) prescaler: AWU_PRESCALER_*
window: uint8_t (0-0x3F)		 void ตั้งค่า AWU timer ไม่จำเป็นถ้าใช้ PWR_Standby(timeout_ms) (ตั้งให้อัตโนมัติแล้ว) — เรียกเองเฉพาะเมื่อใช้คู่กับ PWR_EnterStandbyMode() ที่ต้องการคุม prescaler ละเอียดกว่า
PWR_EnablePVD(level) level: PVD_LEVEL_* void เปิด PVD + ตั้ง threshold ต้องเรียกก่อน PWR_GetPVDStatus() มิฉะนั้นค่าที่อ่านได้ไม่มีความหมาย (PVD ยังไม่เปิด)
PWR_DisablePVD() — void ปิด PVD เรียก PWR_EnablePVD() ใหม่เพื่อกลับมาใช้งานอีกครั้ง
PWR_GetPVDStatus(level) level: PVD_LEVEL_* uint8_t (1/0) ตรวจสอบ VDD ต่ำกว่า level หรือไม่ ต้องเรียกหลัง PWR_EnablePVD() เท่านั้น — เรียกวนใน main loop เพื่อ poll สถานะแรงดัน
PWR_WasStandbyWakeup() — uint8_t (1/0) รอบนี้ wakeup จาก standby หรือไม่? เรียกที่ต้น main() ก่อนโค้ดอื่น (เพราะ standby ทำให้ RAM/main() เริ่มใหม่) — ถ้า true ให้ตามด้วย PWR_ClearStandbyFlag() ทันที
PWR_ClearStandbyFlag() — void เคลียร์ standby wakeup flag ต้องเรียกหลัง PWR_WasStandbyWakeup() คืน true — ถ้าไม่เคลียร์ flag จะค้างเป็น true ไปเรื่อยๆ ในรอบถัดไป (แม้ไม่ได้มาจาก standby จริง)
PWR_EnableWakeupPin() — void เปิด PA0 เป็น wakeup pin — ⚠️ PA0 ไม่มีในทุกแพ็กเกจ! ดูคำเตือนด้านล่าง — ใช้งานไม่ได้จริงบน CH32V003 ทุกแพ็กเกจ ใช้ EXTI ธรรมดา (attachInterrupt) คู่กับ PWR_StandbyUntilInterrupt() แทน
PWR_DisableWakeupPin() — void ปิด PA0 wakeup คู่กับ PWR_EnableWakeupPin() — มีข้อจำกัดเดียวกัน
PWR_EstimateStandbyCurrent(pvd, awu) pvd: PVD on? (1/0)
awu: AWU on? (1/0)		 uint32_t (µA) ประมาณกระแส standby ใช้ผลลัพธ์เป็น input ให้ PWR_CalculateBatteryLife() (พารามิเตอร์ uA) เพื่อประเมินอายุแบตต่อ
PWR_CalculateBatteryLife(mah, active%, mA, uA) mah: ความจุแบต (mAh)
active%: % เวลาทำงาน
mA: กระแสตอน active
uA: กระแสตอน sleep		 uint32_t (hours) คำนวณอายุแบตเตอรี่เป็นชั่วโมง เป็น calculator ล้วนๆ ไม่ผูกกับฮาร์ดแวร์จริง — ใช้ตอนออกแบบระบบก่อนเลือกโหมดพลังงาน; uA ควรมาจาก PWR_EstimateStandbyCurrent()
⚠️ PA0: PA0 ไม่ bonded ในแพ็กเกจ CH32V003 ใด ๆ — PWR_EnableWakeupPin() ใช้ไม่ได้จริง

Standby ทำให้ main() เริ่มใหม่เสมอ: เพราะ RAM หายหมด โค้ดหลัง PWR_Standby()/PWR_EnterStandbyMode() จะไม่ถูกรันต่อ — ต้องเช็ค PWR_WasStandbyWakeup() ที่ ต้น main() เพื่อแยกว่ารอบนี้เป็นการเปิดเครื่องใหม่หรือตื่นจาก standby

ตารางอ้างอิงการใช้พลังงาน

โหมดกระแสเงื่อนไข
Active (HCLK=48MHz)~3-5 mAทุก peripheral เปิด
Sleep~1-2 mACPU หยุด peripherals ทำงาน
Standby (AWU on)~3-5 µALSI 128kHz ทำงาน
Standby (AWU off)~2 µAรอ EXTI เท่านั้น

ตัวอย่างโค้ด

Sleep + Interrupt Wake

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include <SimpleHAL.h>

volatile uint8_t wakeup_flag = 0;

void OnWakeup() {
    wakeup_flag = 1;
}

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();

    pinMode(PC0, PIN_MODE_OUTPUT);
    pinMode(PC1, PIN_MODE_INPUT_PULLUP);
    attachInterrupt(PC1, OnWakeup, FALLING);

    while (1) {
        digitalWrite(PC0, HIGH);
        Delay_Ms(100);
        digitalWrite(PC0, LOW);

        PWR_Sleep();  // CPU หยุด — PC0 คง LOW, peripherals ทำงานต่อ

        if (wakeup_flag) {
            wakeup_flag = 0;
            // ถูกปลุกจากปุ่ม PC1
        }
    }
}

Standby + AWU 5 วินาที

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include <SimpleHAL.h>

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();

    pinMode(PC0, PIN_MODE_OUTPUT);

    if (PWR_WasStandbyWakeup()) {
        PWR_ClearStandbyFlag();
        // กลับมาจาก standby — กระพริบ LED ยืนยัน
        for (int i = 0; i < 3; i++) {
            digitalWrite(PC0, HIGH);
            Delay_Ms(100);
            digitalWrite(PC0, LOW);
            Delay_Ms(100);
        }
    }

    // ทำงาน...
    digitalWrite(PC0, HIGH);
    Delay_Ms(500);
    digitalWrite(PC0, LOW);

    PWR_Standby(5000);  // standby 5 วินาที → wake → main() เริ่มใหม่
}

PVD — ตรวจจับแบตเตอรี่ต่ำ

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include <SimpleHAL.h>

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();

    pinMode(PC0, PIN_MODE_OUTPUT);

    PWR_EnablePVD(PVD_LEVEL_0);  // threshold 2.9V

    while (1) {
        if (PWR_GetPVDStatus(PVD_LEVEL_0)) {
            // แรงดันต่ำกว่า 2.9V → กระพริบ LED เตือน
            digitalToggle(PC0);
            Delay_Ms(200);
        } else {
            digitalWrite(PC0, LOW);
            Delay_Ms(1000);
        }
    }
}

คำนวณอายุแบตเตอรี่

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include <SimpleHAL.h>

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();

    // แบต 200mAh, active 5% ของเวลา, ใช้ 3mA ตอน active, 3µA ตอน standby
    uint32_t hours = PWR_CalculateBatteryLife(200, 5, 3, 3);
    // hours ≈ 555 ชั่วโมง (~23 วัน)

    while (1) {
        // active — ทำงาน
        Delay_Ms(500);

        // standby — ประหยัดไฟ 95% ของเวลา
        PWR_Standby(9500);  // standby ~9.5s
    }
}
