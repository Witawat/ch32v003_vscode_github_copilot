SimpleFlash — เก็บข้อมูลถาวร สูง

ภาพรวม

SimpleFlash ใช้ 2 หน้าสุดท้ายของ Flash (page 254 และ 255) รวม 128 bytes สำหรับเก็บข้อมูลถาวร (non-volatile) โดยใช้ hardware Flash controller ของ CH32V003 รองรับการอ่าน/เขียน byte/half-word/word, เขียน string และ struct, บันทึก config พร้อม CRC16 ป้องกันข้อมูลเสีย และ auto-erase ในตัว

คุณสมบัติรายละเอียด
พื้นที่2 หน้า (page 254 + 255) = 128 bytes
Page size64 bytes ต่อหน้า
Address0x0803F80 — 0x0803FFF
IntegrityCRC16 checksum
Write endurance~10,000 — 80,000 รอบ
Header#include "SimpleFlash.h"
สำคัญ: Flash write endurance จำกัดที่ ~10k-80k cycles ต่อหน้า — เขียนบ่อยเกินไปจะทำให้ flash เสื่อมสภาพ หลีกเลี่ยงการเขียนใน loop และใช้ Flash_SaveConfig เฉพาะเมื่อค่าเปลี่ยนแปลงจริง

Address Layout

พื้นที่เก็บข้อมูลอยู่ใน 2 หน้าสุดท้ายของ Flash — รวม 128 bytes:

PageAddress RangeSizeแนะนำให้ใช้สำหรับ
254 (config)0x0803F80 — 0x0803FBF64 bytesConfig struct + CRC16
255 (data)0x0803FC0 — 0x0803FFF64 bytesข้อมูลทั่วไป (string, counter, etc.)
ข้อควรระวัง: ห้ามใช้พื้นที่เกิน 128 bytes เด็ดขาด — จะไปทับพื้นที่โปรแกรม อาจทำให้ MCU ทำงานผิดพลาด Linker script ต้องกันพื้นที่นี้ไว้ด้วย

ฟังก์ชันคืนค่าคำอธิบายใช้ร่วมกับ
Flash_Init()FlashStatusเริ่มระบบ Flash — ต้องเรียกก่อนใช้งานต้องเรียกก่อนฟังก์ชัน Flash_* อื่นทุกตัว

Flash_ReadHalfWord(addr)uint16_tอ่าน 1 half-word (2 bytes — address ต้อง align 2)เช่นเดียวกับ ReadByte — address ต้องมาจาก Flash_WriteHalfWord()/WithErase() ก่อนหน้าเพื่อให้ได้ค่าที่มีความหมาย
Flash_ReadWord(addr)uint32_tอ่าน 1 word (4 bytes — address ต้อง align 4)เช่นเดียวกับด้านบน — คู่กับ Flash_WriteWord()/WithErase()
Flash_WriteByte(addr, data)FlashStatusเขียน 1 byte — ต้อง erase ก่อนต้องเรียก Flash_ErasePage() ก่อนเสมอ — ใช้ Flash_WriteByteWithErase() แทนถ้าไม่อยาก erase เอง
Flash_WriteHalfWord(addr, data)FlashStatusเขียน 1 half-word — ต้อง erase ก่อนเช่นเดียวกับ WriteByte — ใช้ Flash_WriteHalfWordWithErase() เป็นทางลัด
Flash_WriteWord(addr, data)FlashStatusเขียน 1 word — ต้อง erase ก่อนเช่นเดียวกับ WriteByte — ใช้ Flash_WriteWordWithErase() เป็นทางลัด
Flash_WriteByteWithErase(addr, data)FlashStatusเขียน 1 byte พร้อม auto-erase (ช้า ใช้ 64B RAM)ใช้แทน Flash_ErasePage()+Flash_WriteByte() สองขั้นตอนรวมเป็นครั้งเดียว — ไม่ต้องเรียก ErasePage เองอีก
Flash_WriteHalfWordWithErase(addr, data)FlashStatusเขียน half-word พร้อม auto-eraseเช่นเดียวกับด้านบน สำหรับ half-word
Flash_WriteWordWithErase(addr, data)FlashStatusเขียน word พร้อม auto-eraseเช่นเดียวกับด้านบน สำหรับ word
Flash_ReadString(addr, buf, max)uint16_tอ่าน string — คืนจำนวน byte ที่อ่านได้คู่กับ Flash_WriteString() ที่เขียนไว้ก่อนหน้า — buf ต้องจองขนาดอย่างน้อย max ก่อนเรียก

Flash_ReadStruct(addr, ptr, size)FlashStatusอ่าน struct จาก Flash เข้า RAMคู่กับ Flash_WriteStruct() — ใช้เมื่อไม่ต้องการ CRC (ถ้าต้องการ CRC ใช้ Flash_SaveConfig/LoadConfig แทน)
Flash_WriteStruct(addr, ptr, size)FlashStatusเขียน struct — auto-eraseauto-erase ในตัว — ต่างจาก Flash_SaveConfig() ตรงที่ไม่คำนวณ/ตรวจ CRC ให้
Flash_SaveConfig(ptr, size)FlashStatusบันทึก config struct ลง page 254 + CRC16struct ที่ส่งเข้าต้องมี field uint16_t crc เป็นตัวสุดท้ายเสมอ (ดู Config Struct Pattern) — เรียก Flash_CalculateCRC16() ให้เองภายใน ไม่ต้องเรียกเอง

Flash_IsAddressValid(addr)boolตรวจสอบว่า address อยู่ในช่วงที่อนุญาตควรเรียกก่อน Read/Write ใดๆ ที่ใช้ address จากตัวแปร/คำนวณเอง (ไม่ใช่ constant ที่รู้อยู่แล้วว่าอยู่ในช่วง) เพื่อกัน FLASH_ERROR_RANGE

Simplified Macros

มาโครช่วยลดความยุ่งยาก — ไม่ต้องระบุ address และ type ด้วยตัวเอง:

Macroคำอธิบายตัวอย่าง
FLASH_SAVE_CONFIG(type)บันทึก config struct — คำนวณ CRC อัตโนมัติFLASH_SAVE_CONFIG(my_config);
FLASH_LOAD_CONFIG(type)โหลด config struct — ตรวจ CRCif (FLASH_LOAD_CONFIG(my_config)) { ... }
FLASH_WRITE_AUTO(addr, value)เขียน data type ใด ๆ — auto-erase + type inferenceFLASH_WRITE_AUTO(addr, 0x5A);
FLASH_READ(addr, type)อ่าน data type ใด ๆ ตามที่ระบุuint32_t v = FLASH_READ(addr, uint32_t);
จุดสำคัญ: FLASH_WRITE_AUTO ใช้ auto-erase ภายใน — ใช้ RAM buffer 64 bytes ทำให้ช้ากว่าการ erase + write แยก แต่สะดวกกว่าสำหรับเขียนค่าเดี่ยว

Config Struct Pattern

struct ที่ใช้กับ Flash_SaveConfig / Flash_LoadConfig ต้องมี uint16_t crc เป็น field สุดท้ายเสมอ — ไลบรารีจะคำนวณ CRC ของทุก field ยกเว้น field crc เอง:

typedef struct {
    uint32_t magic;        // ตรวจสอบว่า config เคยถูกเขียนไหม
    uint8_t  version;      // กัน struct version mismatch
    uint8_t  brightness;   // ข้อมูล config
    uint16_t threshold;
    uint32_t counter;
    uint16_t crc;          // ต้องเป็น field สุดท้ายเสมอ
} MyConfig;
ห้ามลืม: field uint16_t crc ต้องเป็น field สุดท้ายของ struct — ถ้าไม่อยู่สุดท้าย CRC จะคำนวณผิดและโหลดไม่สำเร็จ

CRC16 Workflow

บันทึก (Save)

Flash_SaveConfig() → คำนวณ CRC16 ของ struct (ยกเว้น crc field เอง) → เขียน CRC ลงใน field สุดท้าย → erase หน้า 254 → write struct ทั้งอันลง Flash

โหลด (Load)

Flash_LoadConfig() → อ่าน struct จาก Flash → คำนวณ CRC16 ใหม่จากข้อมูลที่อ่าน → เปรียบเทียบกับค่า crc ใน Flash → ถ้าตรงกัน = OK → ถ้าไม่ตรง = CRC fail (ข้อมูลเสียหาย)

ข้อดีของ CRC: ป้องกันการอ่านข้อมูลเสียหายที่เกิดจาก Flash wear, power loss ระหว่างเขียน, หรือการใช้งานครั้งแรก (Flash ใหม่ = 0xFF = CRC ไม่ตรง = ใช้ default แทน)
Auto-Erase ใช้ 64B RAM: Flash_Write*WithErase และ Flash_WriteStruct ต้องใช้ buffer 64 bytes ใน RAM สำหรับพักข้อมูลระหว่างการเขียน — ระวัง RAM ไม่พอในโปรเจกต์ที่ใช้ RAM มาก

ข้อผิดพลาดที่พบบ่อย

เขียนโดยไม่ erase — Flash hardware ต้อง erase ทั้งหน้า (64B) ก่อนเขียน

ใช้ Flash_ErasePage() ก่อน หรือใช้ฟังก์ชัน ...WithErase() ซึ่งจัดการให้อัตโนมัติ

ลืม uint16_t crc ใน struct — Flash_SaveConfig/Flash_LoadConfig ต้องการ crc field เสมอ

ถ้าไม่มี crc field โค้ดจะคอมไพล์ผ่านแต่ CRC จะคำนวณผิด — ทำให้ Flash_LoadConfig คืน false ทุกครั้ง

เขียนบ่อยเกินไป — Flash write endurance จำกัด

อย่าเรียก Flash_SaveConfig ใน main loop โดยตรง — ใช้วิธีตรวจสอบก่อนว่า data เปลี่ยนจริงหรือไม่ แล้วค่อยเขียน

ใช้พื้นที่เกิน 128 bytes — ไปทับ code space

โครงสร้างข้อมูลทั้งหมดที่เก็บใน Flash ต้องห้ามเกิน 128 bytes (2 หน้า) รวม CRC — ถ้าเกินจะไปทับพื้นที่โปรแกรม ทำให้ MCU ทำงานผิดพลาดหรือ brick

Linker script ทับพื้นที่ — ต้องกันพื้นที่ 0x0803F80 — 0x0803FFF ไว้ใน linker script

ถ้า linker script ไม่กันพื้นที่ไว้ คอมไพเลอร์อาจวางโค้ดโปรแกรมทับพื้นที่ Flash storage — ทำให้ข้อมูลหายหรือโปรแกรมพัง

ตัวอย่างโค้ด

Save & Load Config

#include "SimpleHAL.h"

typedef struct {
    uint32_t magic;
    uint8_t  version;
    uint8_t  brightness;
    uint16_t threshold;
    uint16_t crc;          // ต้องเป็น field สุดท้าย
} MyConfig;

MyConfig config;

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    Flash_Init();

    // ลองโหลด config
    if (!Flash_LoadConfig(&config, sizeof(config))) {
        // ไม่มี config — ใช้ค่า default
        config.magic = 0xDEADBEEF;
        config.version = 1;
        config.brightness = 80;
        config.threshold = 500;
        Flash_SaveConfig(&config, sizeof(config));
    }

    while (1) {
        // ใช้ config...
        if (user_changed_setting()) {
            config.brightness = new_value;
            Flash_SaveConfig(&config, sizeof(config));
        }
    }
}

Write String to Flash

#include "SimpleHAL.h"

#define STR_ADDR  0x0803FC0  // page 255 start

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    Flash_Init();

    Flash_WriteString(STR_ADDR, "CH32V003 Flash OK!");

    char buf[32];
    uint16_t len = Flash_ReadString(STR_ADDR, buf, sizeof(buf));
    USART_Print("Read: "); USART_Print(buf); USART_Print("\r\n");
    // Output: "Read: CH32V003 Flash OK!"

    while (1) { }
}

Auto-Erase Word — เขียนค่าเดี่ยว

#include "SimpleHAL.h"

#define DATA_ADDR  0x0803FC4

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    Flash_Init();

    // เขียนครั้งแรก
    Flash_WriteWordWithErase(DATA_ADDR, 100);

    // อัปเดตค่า — auto-erase จัดการให้
    Flash_WriteWordWithErase(DATA_ADDR, 200);

    uint32_t val = Flash_ReadWord(DATA_ADDR);
    // val == 200

    while (1) { }
}

Factory Reset — ลบ Config

#include "SimpleHAL.h"

void factory_reset(void) {
    Flash_EraseAll();
    // ทั้ง config (page 254) และ data (page 255) = 0xFF ทั้งหมด
    // Flash_LoadConfig จะคืน false ในครั้งถัดไป — ใช้ default ได้
}

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    Flash_Init();

    if (button_held_for_10sec()) {
        factory_reset();
        USART_Print("Factory reset complete\r\n");
    }

    while (1) { }
}
