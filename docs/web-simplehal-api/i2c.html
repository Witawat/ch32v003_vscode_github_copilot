ตารางฟังก์ชัน — Hardware I2C

ฟังก์ชันคืนค่าคำอธิบายใช้ร่วมกับ
I2C_SimpleInit(speed, pin_config)voidเริ่ม I2Cต้องเรียกก่อนฟังก์ชัน I2C_* อื่นทุกตัว — ต้องต่อ pull-up 4.7kΩ ที่ SDA/SCL ไว้ก่อนแล้วด้วย (ไม่งั้นแม้ init สำเร็จก็สื่อสารไม่ได้)
I2C_Write(addr, data, len)I2C_Statusเขียนข้อมูลใช้เมื่ออุปกรณ์ไม่มีแนวคิด "register" (ต่างจาก I2C_WriteReg) — เรียกหลัง I2C_SimpleInit()
I2C_Read(addr, data, len)I2C_Statusอ่านข้อมูลมักเรียกคู่กับ I2C_Write() ก่อนหน้า (ส่ง command แล้วอ่านผล เช่นตัวอย่าง BH1750 ด้านล่าง)
I2C_WriteReg(addr, reg, data)I2C_Statusเขียน registerใช้กับอุปกรณ์แบบ register-based (เซนเซอร์ส่วนใหญ่) — คู่กับ I2C_TryReadReg() เพื่ออ่านค่ากลับมาตรวจสอบ
I2C_ReadReg(addr, reg)uint8_tอ่าน register — 0xFF ambiguous!⚠️ ใช้ I2C_TryReadReg() แทนเสมอ — ดูคำอธิบาย CRITICAL ด้านล่าง
I2C_TryReadReg(addr, reg, &data)I2C_Statusอ่าน register แยก error ได้ — แนะนำเรียกหลัง I2C_SimpleInit() — เช็ค return เป็น I2C_OK ก่อนใช้ค่าใน data เสมอ
I2C_WriteRegMulti(addr, reg, data, len)I2C_Statusเขียนหลาย byte ไป registerสำหรับ EEPROM มักต้อง Delay_Ms() รอ write cycle เสร็จก่อนเรียก I2C_ReadRegMulti() ต่อ (ดูตัวอย่าง EEPROM ด้านล่าง)
I2C_ReadRegMulti(addr, reg, data, len)I2C_Statusอ่านหลาย byte จาก registerคู่กับ I2C_WriteRegMulti() — เช็ค return I2C_OK ก่อนใช้ data
I2C_Scan(devices, max)uint8_tสแกน bus — คืนจำนวน device ที่พบเรียกหลัง I2C_SimpleInit() ก่อนใช้ Write/Read ใดๆ — ใช้ผลลัพธ์ (จำนวน+array addr) ยืนยันว่าอุปกรณ์ต่อถูกต้องก่อนเขียนโค้ดต่อ
I2C_IsDeviceReady(addr)uint8_tตรวจสอบ device — 1=พร้อมใช้แทน I2C_Scan() เมื่อรู้ address อยู่แล้วและต้องการเช็คเร็วๆ ก่อนเรียก Write/Read

CRITICAL: I2C_ReadReg

I2C_ReadReg คืนค่า uint8_t — หากเกิด error จะคืนค่า 0xFF เหมือนกับอ่านได้ 0xFF จริง คุณจึงไม่สามารถแยกแยะระหว่าง error กับข้อมูลที่ถูกต้องได้

ใช้ I2C_TryReadReg แทน:

// แบบเก่า — ตรวจ error ไม่ได้
uint8_t val = I2C_ReadReg(0x50, 0x00);
if (val == 0xFF) {
    // เป็น error หรือข้อมูลจริง? ไม่รู้!
}

// แบบใหม่ — แยก error ได้ชัดเจน
uint8_t val;
if (I2C_TryReadReg(0x50, 0x00, &val) == I2C_OK) {
    USART_Print("Read OK: ");
    USART_PrintHex(val, 1);
} else {
    USART_Print("Read failed!\r\n");
}

SimpleI2C_Soft — Software I2C (Bit-Bang)

คุณสมบัติ

คุณสมบัติรายละเอียด
หลักการBit-bang — ควบคุม GPIO ด้วย software timing
ขาเลือก GPIO ใดก็ได้ (ไม่ผูกกับ hardware pin)
ความเร็ว100kHz, 400kHz
Pull-upต้องต่อ external 4.7kΩ
Header#include "SimpleI2C_Soft.h"

ตารางฟังก์ชัน — Software I2C

ฟังก์ชันคืนค่าคำอธิบายใช้ร่วมกับ
I2C_Soft_Init(scl, sda, speed)voidเริ่ม Soft I2C — กำหนดขา SCL, SDA, ความเร็วต้องเรียกก่อนฟังก์ชัน I2C_Soft_* อื่นทุกตัว (ทั้งระดับสูงและ low-level) — ต้องต่อ pull-up 4.7kΩ ก่อนเช่นเดียวกับ hardware I2C
I2C_Soft_Write(addr, data, len, ignore_ack)I2C_Soft_Statusเขียนข้อมูล — ignore_ack=1 สำหรับ logic analyzerใช้แทนการเรียก Start/WriteByte/Stop เองทีละขั้น — ทางลัดที่ครอบ low-level API ไว้ให้แล้ว
I2C_Soft_Read(addr, data, len)I2C_Soft_Statusอ่านข้อมูลทางลัดเช่นเดียวกัน ครอบ Start/ReadByte/Stop ไว้ให้แล้ว
Low-Level (สำหรับ advanced use) — ใช้ประกอบ transaction เองแทน Write/Read ข้างบน
I2C_Soft_Start()voidส่ง start conditionต้องเรียกเป็นอันดับแรกของทุก transaction — ตามด้วย I2C_Soft_WriteByte() ส่ง address+R/W bit ก่อนเสมอ
I2C_Soft_Stop()voidส่ง stop conditionต้องเรียกปิดท้ายทุก transaction ที่เปิดด้วย I2C_Soft_Start() — ลืมเรียกจะทำให้ bus ค้าง (device คิดว่า transaction ยังไม่จบ)
I2C_Soft_WriteByte(byte)uint8_tส่ง 1 byte — คืน ACK bitเรียกได้หลาย byte ติดกันระหว่าง Start() กับ Stop() — ไบต์แรกหลัง Start() ต้องเป็น (address<<1 | R/W bit) เสมอ; เช็ค return value เป็น ACK ก่อนส่งไบต์ถัดไป
I2C_Soft_ReadByte(ack)uint8_tอ่าน 1 byte — ack=0 ส่ง NACK (stop อ่าน)เรียกวนหลายครั้งเพื่ออ่านหลายไบต์ — ส่ง ack=1 ทุกไบต์ยกเว้นไบต์สุดท้ายที่ต้อง ack=0 เพื่อบอกอุปกรณ์ให้หยุดส่ง ก่อนเรียก I2C_Soft_Stop()

ignore_ack ใน I2C_Soft_Write — เมื่อตั้งเป็น 1 ฟังก์ชันจะไม่รอ ACK จากอุปกรณ์ ใช้ประโยชน์กับ logic analyzer หรืออุปกรณ์ที่ไม่ตอบ ACK ตามปกติ

เมื่อไรใช้ low-level เอง: ใช้ I2C_Soft_Write()/I2C_Soft_Read() พอสำหรับงานทั่วไป — สลับมาใช้ Start/WriteByte/ReadByte/Stop เองเมื่อต้องทำ repeated-start (Start ซ้ำโดยไม่ Stop ก่อน) หรือ protocol พิเศษที่ไม่ตรงกับรูปแบบ write-then-read ปกติ

Use Case: SOP-8

CH32V003 แพ็กเกจ SOP-8 ไม่มีขา PC1/PC2 (I2C hardware pins ไม่ถูก bond ออกมา) จึงใช้ hardware I2C ไม่ได้ — ต้องใช้ SimpleI2C_Soft เลือกขา GPIO ที่มีอยู่แทน (เช่น PD3, PD4)

#include "SimpleHAL.h"
#include "SimpleI2C_Soft.h"

int main(void) {
    SystemCoreClockUpdate();
    Delay_Init();

    // SOP-8: ใช้ PD3=SDA, PD4=SCL
    I2C_Soft_Init(PD4, PD3, I2C_SPEED_100K);

    // สแกนหา device
    uint8_t addrs[16];
    uint8_t count = I2C_Scan_Soft(addrs, 16);
    // ... ใช้งานต่อไป ...
}

Hardware Requirement

ต้องต่อ pull-up resistor 4.7kΩ ที่ SDA และ SCL — CH32V003 ไม่มี internal pull-up บน I2C pins หากไม่ต่อ bus จะทำงานไม่ได้

ข้อผิดพลาดที่พบบ่อย

ลืมต่อ pull-up resistor — SDA/SCL จะลอย (floating) ไม่สามารถสื่อสารได้

ต่อ 4.7kΩ จาก SDA → VDD และ SCL → VDD

REMAP บน SOP8 — PD0/PD1 ไม่ถูก bond ออกมาบนแพ็กเกจ SOP8 → #error ตอนคอมไพล์

ใช้ SimpleI2C_Soft แทน

I2C_ReadReg ambiguity — ค่า 0xFF เป็นได้ทั้ง error และข้อมูลจริง

ใช้ I2C_TryReadReg แทน

SOP-8 I2C pins ไม่ถูก bond — PC1, PC2 ไม่มีอยู่จริงบน SOP-8

ต้องใช้ SimpleI2C_Soft เท่านั้น

EEPROM Write/Read (AT24C02)

#include "SimpleHAL.h"
#include "SimpleI2C.h"

#define EEPROM_ADDR 0xA0

int main(void) {
    SystemCoreClockUpdate();
    Delay_Init();
    I2C_SimpleInit(I2C_SPEED_100K, I2C_PIN_DEFAULT);

    // เขียน 3 byte ไป address 0x00
    uint8_t wdata[] = {0x42, 0x43, 0x44};
    I2C_WriteRegMulti(EEPROM_ADDR, 0x00, wdata, 3);

    Delay_Ms(10);  // รอ EEPROM write cycle

    // อ่าน 3 byte จาก address 0x00
    uint8_t rdata[3];
    if (I2C_ReadRegMulti(EEPROM_ADDR, 0x00, rdata, 3) == I2C_OK) {
        USART_Print("EEPROM: ");
        for (int i = 0; i < 3; i++) {
            USART_PrintHex(rdata[i], 1);
            USART_WriteByte(' ');
        }
    }
    while (1);
}

I2C Scanner

#include "SimpleHAL.h"
#include "SimpleI2C.h"

int main(void) {
    SystemCoreClockUpdate();
    USART_SimpleInit(USART_BAUD_115200, USART_PIN_DEFAULT);
    I2C_SimpleInit(I2C_SPEED_100K, I2C_PIN_DEFAULT);

    USART_Print("I2C Scanner\r\n");

    uint8_t devices[16];
    uint8_t count = I2C_Scan(devices, 16);

    USART_Print("Found: ");
    USART_PrintNum(count);
    USART_Print(" device(s)\r\n");

    for (uint8_t i = 0; i < count; i++) {
        USART_Print("  0x");
        USART_PrintHex(devices[i], 1);
        USART_Print("\r\n");
    }

    while (1);
}

BH1750 Read (Light Sensor)

#include "SimpleHAL.h"
#include "SimpleI2C.h"

#define BH1750_ADDR 0x46

void bh1750_read(uint16_t *lux) {
    // สั่งวัดแบบต่อเนื่อง high-res
    uint8_t cmd = 0x10;
    I2C_Write(BH1750_ADDR, &cmd, 1);
    Delay_Ms(180);

    uint8_t buf[2];
    if (I2C_Read(BH1750_ADDR, buf, 2) == I2C_OK) {
        *lux = ((uint16_t)buf[0] << 8) | buf[1];
        *lux = *lux / 1.2;  // แปลงเป็น lux
    } else {
        *lux = 0xFFFF;
    }
}

int main(void) {
    SystemCoreClockUpdate();
    USART_SimpleInit(USART_BAUD_115200, USART_PIN_DEFAULT);
    I2C_SimpleInit(I2C_SPEED_100K, I2C_PIN_DEFAULT);

    while (1) {
        uint16_t lux;
        bh1750_read(&lux);
        USART_Print("Light: ");
        USART_PrintNum(lux);
        USART_Print(" lux\r\n");
        Delay_Ms(1000);
    }
}

Soft I2C บน SOP-8 (SSD1306 OLED)

#include "SimpleHAL.h"
#include "SimpleI2C_Soft.h"

#define OLED_ADDR 0x78

int main(void) {
    SystemCoreClockUpdate();
    Delay_Init();
    USART_SimpleInit(USART_BAUD_115200, USART_PIN_DEFAULT);

    // SOP-8: ใช้ PD3=SDA, PD4=SCL
    I2C_Soft_Init(PD4, PD3, I2C_SPEED_400K);

    // init OLED...
    uint8_t init_cmds[] = {0x00, 0xAE, 0xD5, 0x80, 0xA8, 0x1F, 0xAF};
    I2C_Soft_Write(OLED_ADDR, init_cmds, sizeof(init_cmds), 0);

    USART_Print("OLED ready (Soft I2C)\r\n");

    while (1);
}
