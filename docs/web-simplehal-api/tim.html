โมดูล 9: SimpleTIM + SimpleTIM_Ext — Timer, Stopwatch, Countdown

ระดับกลาง

Part A: SimpleTIM

ภาพรวม

SimpleTIM ใช้ TIM1 และ TIM2 เป็น hardware timer ตั้งเวลา — คำนวณ prescaler และ period อัตโนมัติตามความถี่ที่ต้องการ รองรับ interrupt callback สำหรับงาน periodic

  • คำนวณ prescaler + period อัตโนมัติจากความถี่ที่ต้องการ
  • รองรับ interrupt callback — เหมาะสำหรับงานที่ต้องทำเป็นจังหวะ
  • Timer Ownership Guard ป้องกันการแย่ง timer กับ SimplePWM
  • ฟังก์ชันอ่าน/เขียน counter และ period โดยตรง

Timer Ownership Guard

SimpleTIM ใช้ระบบเดียวกับ SimplePWM เพื่อป้องกันการแย่ง TIM1/TIM2

Owner Stateความหมาย
TIM_OWNER_NONEยังไม่ถูกใช้ — ใครก็ได้ใช้ก่อน
TIM_OWNER_PWMถูกใช้โดย SimplePWM
TIM_OWNER_TIMERถูกใช้โดย SimpleTIM
TIM_OWNER_TIMEXTถูกใช้โดย SimpleTIM_Ext
สำคัญ: ถ้า timer ถูกครอบครองแล้ว — ฟังก์ชันจะ return ทันทีโดยไม่ทำงาน Guard ป้องกันการเขียน register ทับกัน

Timer Resource Map

Timerใช้โดยข้อจำกัด
TIM1PWM หรือ SimpleTIMใช้กับ PWM หรือ TIM — เลือกอย่างใดอย่างหนึ่ง
TIM2PWM หรือ SimpleTIM หรือ SimpleTIM_Extใช้กับ PWM หรือ TIM หรือ TIM_Ext — เลือกอย่างใดอย่างหนึ่ง
TIM2 ขัดแย้งกับ PWM2 และ TIM_Ext: ถ้าใช้ TIM2 เป็น SimpleTIM — จะใช้ PWM2_CH1~CH4 หรือ Stopwatch/Countdown ร่วมกันไม่ได้

ตารางฟังก์ชัน

ฟังก์ชันคืนค่าคำอธิบายใช้ร่วมกับ
TIM_SimpleInit(timer, freq_hz)voidเริ่ม timer ที่ความถี่ที่กำหนด — ต้องเรียก TIM_Start() ต่อต้องเรียกก่อนฟังก์ชัน TIM_* อื่นทุกตัวของ timer นั้น (เช่น TIM1 หรือ TIM2 แยกกัน) — ตั้ง owner guard ให้ timer นี้ทันที
TIM_Start(timer)voidเริ่มนับเรียกหลัง TIM_SimpleInit()/TIM_AdvancedInit() — ถ้าจะใช้ interrupt ให้เรียก TIM_AttachInterrupt() ก่อน TIM_Start() เพื่อไม่พลาด tick แรก
TIM_Stop(timer)voidหยุดนับเรียก TIM_Start() ซ้ำเพื่อนับต่อ — counter ค้างที่ค่าเดิม (ใช้ Simple_TIM_SetCounter() รีเซ็ตถ้าต้องการ)
TIM_SetFrequency(timer, freq_hz)voidเปลี่ยนความถี่ (คำนวณ prescaler + period ใหม่)เรียกได้ทั้งก่อน/หลัง TIM_Start() — ถ้า timer นี้แชร์กับ PWM (ดู Ownership Guard) การเปลี่ยนความถี่จะกระทบ PWM channel อื่นบน timer เดียวกันด้วย
Simple_TIM_GetCounter(timer)uint16_tอ่านค่า counter ปัจจุบันใช้คู่กับ TIM_GetPeriod() เพื่อคำนวณเปอร์เซ็นต์ที่นับไปแล้ว
Simple_TIM_SetCounter(timer, value)voidตั้งค่า counterเรียกหลัง TIM_SimpleInit() — ใช้รีเซ็ต/sync จุดเริ่มนับ ไม่กระทบ period ที่ตั้งไว้
TIM_GetPeriod(timer)uint16_tอ่านค่า periodค่าที่ได้มาจาก TIM_SimpleInit()/TIM_SetFrequency() คำนวณไว้ — ใช้ debug ความถี่จริง
TIM_AttachInterrupt(timer, callback)voidติด interrupt callback — callback ห้ามใช้ delayควรเรียกก่อน TIM_Start() — ต้องเรียกหลัง TIM_SimpleInit()/TIM_AdvancedInit() เสมอ (timer ต้องถูก init ก่อนถึงจะติด callback ได้)
TIM_DetachInterrupt(timer)voidยกเลิก interruptเรียกได้ทุกเมื่อหลัง AttachInterrupt — timer ยังนับต่อได้ปกติ เพียงไม่เรียก callback อีก
TIM_AdvancedInit(timer, psc, period, mode)voidตั้งค่า timer เองทั้งหมด (ผู้เชี่ยวชาญ)ใช้แทน TIM_SimpleInit() ไม่ใช่ใช้ร่วมกัน — เลือกทางใดทางหนึ่ง ตามด้วย TIM_Start() เหมือนกัน
TIM_SetPrescaler(timer, psc)voidตั้งค่า prescaler เองใช้หลัง TIM_AdvancedInit() เท่านั้น — เปลี่ยนแล้วควรเรียก TIM_GenerateUpdate() เพื่อให้ค่ามีผลทันที
TIM_GetPrescaler(timer)uint16_tอ่านค่า prescalerใช้ debug คู่กับ TIM_GetPeriod() เพื่อคำนวณความถี่จริง
TIM_SetMode(timer, mode)voidตั้งค่า timer modeใช้หลัง TIM_AdvancedInit() — เปลี่ยนโหมดนับ (up/down/center-aligned)
TIM_GenerateUpdate(timer)voidสร้าง update event (บังคับ reload ค่า)เรียกหลัง TIM_SetPrescaler()/TIM_SetMode() เพื่อให้ค่าใหม่มีผลทันทีแทนที่จะรอรอบถัดไป

ลำดับการเรียกใช้ฟังก์ชัน (Call Sequence)

flowchart LR
    A["TIM_SimpleInit(timer, freq_hz)
หรือ TIM_AdvancedInit()"] --> B["TIM_AttachInterrupt(timer, cb)
★ ทำก่อน Start เพื่อไม่พลาด tick แรก"]
    B --> C["TIM_Start(timer)"]
    C --> D["ทำงานใน main loop
callback ทำงานเองใน ISR"]
เลือกเส้นทางเดียว: TIM_SimpleInit() กับ TIM_AdvancedInit() ตั้งค่า timer ตัวเดียวกัน — เรียกอย่างใดอย่างหนึ่งเท่านั้น ห้ามเรียกทั้งคู่กับ timer เดียวกัน

ตัวอย่างโค้ด — งาน Periodic

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"

void onTimerTick(void)
{
    // callback — ห้ามใช้ Delay ภายในนี้
    digitalToggle(PC0);  // LED toggle ทุก 1ms
}

int main(void)
{
    SystemCoreClockUpdate();
    Timer_Init();

    pinMode(PC0, PIN_MODE_OUTPUT);

    TIM_SimpleInit(TIM1, 1000);           // 1kHz = 1ms
    TIM_AttachInterrupt(TIM1, onTimerTick);
    TIM_Start(TIM1);

    while(1)
    {
        // main loop อิสระ — ไม่ถูกบล็อก
    }
}
Callback ห้ามใช้ Delay: ภายใน interrupt callback — ห้ามเรียก Delay_Ms(), Delay_Us(), printf() — จะทำให้โปรแกรมค้าง

Part B: SimpleTIM_Ext — Stopwatch + Countdown

ภาพรวม

SimpleTIM_Ext ใช้ TIM2 ที่ 1kHz เป็นฐานนับเวลา — รองรับทั้ง Stopwatch (นับขึ้น) และ Countdown (นับถอยหลัง) พร้อม format เวลาแบบ HH:MM:SS

  • ใช้ TIM2 ที่ 1kHz — ขัดแย้งกับ PWM2 และ PWM2_CH1~CH4
  • รองรับเวลา format HHMMSS, MMSS, SS
  • โหมดแสดงผล: NORMALIZED (60 วิ = 1 นาที) และ RAW (ค่าตรง)
  • Countdown มี alarm callback เมื่อหมดเวลา
TIM2 ขัดแย้ง: SimpleTIM_Ext ใช้ TIM2 — ไม่สามารถใช้ร่วมกับ PWM2 (PWM2_CH1~CH4) หรือ MOTIM2 ได้

รูปแบบเวลาและโหมดแสดงผล

ตารางฟังก์ชัน Stopwatch

ฟังก์ชันคืนค่าคำอธิบายใช้ร่วมกับ
Stopwatch_Init()voidเริ่มต้น stopwatchต้องเรียกก่อน Stopwatch_Start() และฟังก์ชัน Stopwatch_* อื่นทุกตัว — ใช้ TIM2 ภายใน (ดูคำเตือน TIM2 ขัดแย้งด้านบน)
Stopwatch_Start()voidเริ่มนับเรียกหลัง Stopwatch_Init() เท่านั้น
Stopwatch_Stop()voidหยุดนับเรียก Stopwatch_Start() ซ้ำเพื่อนับต่อจากค่าเดิม หรือ Stopwatch_Reset() ก่อนเพื่อเริ่มใหม่
Stopwatch_Reset()voidรีเซ็ตเวลาเป็น 0เรียกได้ทั้งตอนนับอยู่หรือหยุดแล้ว — ไม่กระทบสถานะ running/stopped
Stopwatch_GetTime(Time_t*)voidอ่านเวลาใส่ structผล Time_t ที่ได้ส่งต่อให้ Time_ToString()/Time_ToSeconds() แปลงรูปแบบต่อได้
Stopwatch_GetTimeString(buf, format, mode)voidอ่านเวลาเป็น stringbuf ต้องจองขนาดตาม format ที่เลือก (ดูตาราง "ขนาด Buffer" ด้านบน) ก่อนเรียก
Stopwatch_GetTotalSeconds()uint32_tอ่านจำนวนวินาทีทั้งหมดทางลัดแทน Stopwatch_GetTime()+Time_ToSeconds() เมื่อต้องการแค่ตัวเลขวินาที
Stopwatch_GetMilliseconds()uint32_tอ่านจำนวนมิลลิวินาทีทั้งหมดใช้เมื่อต้องการความละเอียดกว่า GetTotalSeconds()
Stopwatch_IsRunning()uint8_t1 = กำลังนับ, 0 = หยุดเช็คก่อนเรียก Stopwatch_Start()/Stop() ซ้ำเพื่อเลี่ยงเรียกโดยไม่จำเป็น

ตารางฟังก์ชัน Countdown

ฟังก์ชันคืนค่าคำอธิบายใช้ร่วมกับ
Countdown_Init(h, m, s)voidตั้งเวลานับถอยหลัง (ชั่วโมง, นาที, วินาที)ต้องเรียกก่อน Countdown_Start() — ใช้แทน Countdown_InitFromSeconds() เลือกอย่างใดอย่างหนึ่ง
Countdown_InitFromSeconds(s)voidตั้งเวลาจากจำนวนวินาทีทางเลือกแทน Countdown_Init(h,m,s) เมื่อสะดวกคิดเป็นวินาทีมากกว่า
Countdown_Start()voidเริ่มนับถอยหลังถ้าจะใช้ alarm ต้องเรียก Countdown_SetAlarmCallback() ก่อน เรียกฟังก์ชันนี้ มิฉะนั้นอาจพลาด callback ตอนหมดเวลาพอดี
Countdown_Stop()voidหยุดนับเรียก Countdown_Start() ซ้ำเพื่อนับต่อจากเวลาที่เหลือ
Countdown_Reset()voidรีเซ็ตกลับเป็นเวลาเริ่มต้นกลับไปที่ค่าจาก Countdown_Init()/InitFromSeconds() ล่าสุด ไม่ใช่ 0
Countdown_GetTime(Time_t*)voidอ่านเวลาที่เหลือใส่ structผลส่งต่อให้ Time_ToString()/Time_ToSeconds() ได้เหมือน Stopwatch
Countdown_GetTimeString(buf, format, mode)voidอ่านเวลาที่เหลือเป็น stringbuf ต้องจองขนาดตาม format ที่เลือกเช่นเดียวกับ Stopwatch
Countdown_IsFinished()uint8_t1 = หมดเวลาแล้วใช้เช็คใน main loop เป็นทางเลือกแทนการรอ Countdown_SetAlarmCallback()
Countdown_SetAlarmCallback(callback)voidตั้ง callback เมื่อหมดเวลาต้องเรียกก่อน Countdown_Start() — callback ทำงานใน ISR ห้ามใช้ Delay เหมือน TIM_AttachInterrupt()
Countdown_GetRemainingSeconds()uint32_tอ่านวินาทีที่เหลือทางลัดแทน Countdown_GetTime()+Time_ToSeconds()
Countdown_IsRunning()uint8_t1 = กำลังนับถอยหลังเช็คก่อนเรียก Start()/Stop() ซ้ำ
ลำดับที่พลาดบ่อย: Countdown_Init/InitFromSeconds() → Countdown_SetAlarmCallback() (ถ้าต้องการ) → Countdown_Start() — สลับให้ SetAlarmCallback อยู่หลัง Start() อาจทำให้พลาด callback รอบแรกถ้าตั้งเวลาไว้สั้นมาก

ตัวอย่างโค้ด

Stopwatch

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"

int main(void)
{
    SystemCoreClockUpdate();
    Timer_Init();

    USART_Printf_Init(USART1, BAUD_115200);

    Stopwatch_Init();
    Stopwatch_Start();

    Delay_Ms(5000);  // หน่วง 5 วิ

    uint32_t elapsed = Stopwatch_GetTotalSeconds();
    printf("Elapsed: %lu seconds\r\n", elapsed);

    char buf[16];
    Stopwatch_GetTimeString(buf, MMSS, DISPLAY_NORMALIZED);
    printf("Time: %s\r\n", buf);

    while(1);
}

Countdown with Alarm

void onAlarm(void)
{
    // callback — ห้ามใช้ delay
    printf("Time's up!\r\n");
}

int main(void)
{
    SystemCoreClockUpdate();
    Timer_Init();

    USART_Printf_Init(USART1, BAUD_115200);

    Countdown_Init(0, 0, 10);  // 10 วินาที
    Countdown_SetAlarmCallback(onAlarm);
    Countdown_Start();

    while(!Countdown_IsFinished())
    {
        char buf[12];
        Countdown_GetTimeString(buf, SS, DISPLAY_NORMALIZED);
        printf("Remaining: %s\r\n", buf);
        Delay_Ms(1000);
    }

    printf("Done!\r\n");
    while(1);
}

Stopwatch_Init();

// NORMALIZED: "02:05"

Stopwatch_GetTimeString(buf, MMSS, DISPLAY_NORMALIZED);
printf("Normalized: %s\r\n", buf);

Stopwatch_GetTimeString(buf, MMSS, DISPLAY_RAW);
printf("Raw: %s\r\n", buf);
