  • เริ่มต้น
  • 0เริ่มต้น เริ่มต้นใช้งาน SimpleHAL — 3 ขั้นตอนบังคับ, แพ็กเกจ, Timer Resource Map, ตัวอย่างขั้นต่ำ
  • 1เริ่มต้น GPIO — pinMode, digitalWrite, digitalRead, Interrupt, PulseIn
  • 2เริ่มต้น Delay & Timer — Delay_Ms, Delay_Us, Get_CurrentMs, Non-Blocking Timer
  • 3เริ่มต้น Arduino API — millis, delay, random, yield, Serial Compatibility
  • กลาง
  • 4กลาง USART — USART_SimpleInit, USART_WriteByte, USART_Read, Remap
  • 5กลาง I2C + I2C_Soft — I2C_Init, I2C_Write, I2C_Read, Bus Scan, Remap, Software I2C (bit-bang)
  • 6กลาง SPI — SPI_Init, SPI_Transfer, SPI_WriteByte, SPI_ReadByte, Remap
  • 7กลาง ADC — ADC_Init, ADC_Read, Multi-Channel, VrefInt, Battery Monitor
  • 8กลาง PWM — PWM_Init, PWM_SetDuty, PWM_SetFrequency, Servo, Auto-Start
  • 9กลาง TIM + TIM_Ext — Timer_Init, TIM_ClearITPendingBit, Timer Interrupt, Stopwatch, Countdown
  • สูง
  • 10สูง DMA — DMA_Init, DMA_Start, DMA_Callback, ADC+DMA, USART+DMA
  • 11สูง Flash — Flash_ErasePage, Flash_WriteWord, Flash_ReadData, CRC Config
  • 12สูง IWDG — IWDG_Init, IWDG_ReloadCounter, Independent Watchdog
  • 13สูง WWDG — WWDG_Init, WWDG_SetCounter, WWDG_IRQHandler, Window Watchdog
  • 14สูง Power — PWR_EnterSleepMode, PWR_EnterStandbyMode, AWU, PVD

  • 15ผู้เชี่ยวชาญ OPAMP — OPAMP_Init, Follower, Non-Inverting, Inverting, Comparator
  • 16ผู้เชี่ยวชาญ 1-Wire — OneWire_Init, OneWire_Reset, OneWire_ReadByte, DS18B20
