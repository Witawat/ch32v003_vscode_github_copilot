Simple1Wire — 1-Wire Protocol

ระดับผู้เชี่ยวชาญ
ไลบรารี: SimpleHAL.h — ใช้ ไม่ต้อง include ไฟล์ย่อยเอง ทุกฟังก์ชัน 1-Wire รวมอยู่ใน SimpleHAL.h แล้ว

ภาพรวม

1-Wire เป็นโปรโตคอลสื่อสารของ Dallas/Maxim — ใช้สายสัญญาณเส้นเดียว (1 data + GND) สื่อสารกับอุปกรณ์หลายตัวบนบัสเดียวกัน เช่น DS18B20, DS2431 EEPROM, iButton

  • สายเดียว — 1 data line + GND
  • Multi-device — ต่อได้หลายตัวบนบัสเดียวกัน
  • ROM Search — ค้นหา device address ทั้งหมดบนบัส
  • CRC8 — ตรวจสอบความถูกต้องของข้อมูล
Hardware: ต้องต่อ ตัวต้านทาน pull-up 4.7kΩ ภายนอกระหว่าง data line กับ VCC (3.3V) — ใช้ GPIO pin ใดก็ได้

ROM Commands

CommandCodeคำอธิบาย
SKIP_ROM0xCCคุยกับทุกอุปกรณ์บนบัส (ใช้ได้กรณีมีตัวเดียว)
READ_ROM0x33อ่าน ROM — ใช้ได้เมื่อมีอุปกรณ์ตัวเดียวเท่านั้น
MATCH_ROM0x55เลือกอุปกรณ์ตาม ROM address
SEARCH_ROM0xF0ค้นหาอุปกรณ์ทั้งหมด — Maxim AN187 algorithm
ALARM_SEARCH0xECค้นหาเฉพาะอุปกรณ์ที่ alarm active

ROM Address Format

    [ Family Code 1B ] [ Serial Number 6B ] [ CRC8 1B ]
   เช่น DS18B20 → 28 xx xx xx xx xx xx CR

8 byte = Family (1B) + Serial (6B) + CRC8 (1B) — CRC ครอบคลุมทั้ง 8 byte

ตารางอ้างอิงฟังก์ชัน

bit: 0/1		 void เขียน 1 bit — low-level ใช้เฉพาะเมื่อเขียน custom protocol เอง ปกติใช้ WriteByte/WriteBytes แทน

OneWire_ReadByte(bus) bus: OneWire_Bus* uint8_t อ่าน 1 byte ต้องเรียกหลัง Reset() + ROM command + WriteByte() (ส่ง read command ก่อน เช่น 0xBE)
OneWire_WriteBytes(bus, data, len) bus: OneWire_Bus*
data: uint8_t*
len: uint16_t		 void เขียนหลาย byte ลำดับเดียวกับ WriteByte() แต่ส่งทีเดียวหลายไบต์
OneWire_ReadBytes(bus, data, len) bus: OneWire_Bus*
data: uint8_t*
len: uint16_t		 void อ่านหลาย byte ผล data ที่ได้ควรส่งต่อให้ OneWire_VerifyCRC(data, len) ตรวจก่อนใช้งานเสมอ
OneWire_SkipROM(bus) bus: OneWire_Bus* void ข้าม ROM — ใช้ได้กรณีอุปกรณ์ตัวเดียวบนบัส ต้องเรียกหลัง Reset() ทันที — ตามด้วย WriteByte() ส่ง function command; ห้ามใช้ถ้ามีหลายอุปกรณ์บนบัส (ใช้ MatchROM แทน)
OneWire_ReadROM(bus, rom) bus: OneWire_Bus*
rom: uint8_t[8]		 bool อ่าน ROM — ใช้ได้เมื่อมีอุปกรณ์ตัวเดียวเท่านั้น ต้องเรียกหลัง Reset() ทันที (แทนที่ SkipROM/MatchROM) — ต่างจาก GetAddress() ตรงที่นี่คืออ่านจากฮาร์ดแวร์จริง ไม่ใช่คัดลอกจาก search state
OneWire_MatchROM(bus, rom) bus: OneWire_Bus*
rom: uint8_t[8]		 void เลือกอุปกรณ์ตาม ROM address ต้องเรียกหลัง Reset() ทันที — rom ควรมาจาก OneWire_Search()+GetAddress() ก่อนหน้า; ตามด้วย WriteByte()
OneWire_Select(bus, rom) bus: OneWire_Bus*
rom: uint8_t[8]		 bool Reset + MatchROM — เลือกอุปกรณ์ในขั้นตอนเดียว ทางลัดของ OneWire_Reset(bus) + OneWire_MatchROM(bus, rom) รวมกัน — ใช้แทน 2 บรรทัดนั้นได้เลยเมื่อรู้ ROM แล้ว
OneWire_ResetSearch(bus) bus: OneWire_Bus* void รีเซ็ตสถานะ search — เริ่มค้นหาใหม่ ต้องเรียกก่อนเริ่ม loop OneWire_Search() ทุกครั้ง (ครั้งแรกหรือค้นหาใหม่) มิฉะนั้นจะข้าม/พลาดอุปกรณ์
OneWire_Search(bus) bus: OneWire_Bus* bool ค้นหา ROM ถัดไป — ใช้ Maxim AN187 algorithm เรียกวนใน loop หลัง ResetSearch() — true = เจอ 1 ตัว (ให้เรียก GetAddress() ต่อ), false = ค้นครบแล้ว หยุด loop
OneWire_AlarmSearch(bus) bus: OneWire_Bus* bool ค้นหาเฉพาะอุปกรณ์ที่มี alarm active ใช้แทน OneWire_Search() ใน loop เดียวกัน — ยังต้อง ResetSearch() ก่อนเช่นกัน
OneWire_GetAddress(bus, rom) bus: OneWire_Bus*
rom: uint8_t[8]		 void คัดลอก ROM address จาก bus state ต้องเรียกทันทีหลัง OneWire_Search() คืน true — คัดลอกจาก search state ที่เพิ่งเจอ (ไม่ใช่อ่านฮาร์ดแวร์ใหม่แบบ ReadROM) ผล rom นำไปใช้กับ MatchROM/Select ภายหลังได้
OneWire_CRC8(data, len) data: uint8_t*
len: uint8_t		 uint8_t คำนวณ Dallas CRC8 (x^8 + x^5 + x^4 + 1) ใช้เมื่อต้องการค่า CRC ดิบเอง — ถ้าแค่ต้องการเช็คถูก/ผิดให้ใช้ OneWire_VerifyCRC() แทน (เรียกง่ายกว่า)
OneWire_VerifyCRC(data, len) data: uint8_t*
len: uint8_t		 bool ตรวจสอบ CRC — true = ถูกต้อง เรียกทันทีหลัง OneWire_ReadBytes() ก่อนนำข้อมูลไปใช้ — ภายในเรียก OneWire_CRC8() ให้อัตโนมัติแล้ว
OneWire_Depower(bus) bus: OneWire_Bus* void หยุด parasite power ใช้เฉพาะโหมด parasite power — เรียกหลังจบ operation ที่ดึงกระแสจากบัส (เช่น หลัง Convert T)

ลำดับการเรียกใช้ฟังก์ชัน (Call Sequence)

1-Wire เป็นโปรโตคอลที่ ลำดับการเรียกสำคัญที่สุด — ผิดลำดับแล้ว device จะไม่ตอบหรือได้ข้อมูลผิด กฎหลัก 2 ข้อที่ต้องจำ:

flowchart LR
    A["OneWire_Init(pin)
ครั้งเดียวตอนเริ่ม"] --> B["OneWire_Reset(bus)
ก่อน ROM command ทุกครั้ง"]
    B --> C{"กี่อุปกรณ์บนบัส?"}
    C -->|"ตัวเดียว"| D["SkipROM(bus)"]
    C -->|"หลายตัว รู้ ROM แล้ว"| E["MatchROM(bus, rom)
= Select(bus, rom)"]
    D --> F["WriteByte/ReadBytes
ส่ง command + รับข้อมูล"]
    E --> F
    F --> G["VerifyCRC(data, len)
ก่อนใช้ข้อมูล"]
    
flowchart LR
    H["ResetSearch(bus)
ครั้งเดียวก่อน loop"] --> I["Search(bus)"]
    I -->|"true: เจอ 1 ตัว"| J["GetAddress(bus, rom)"]
    J --> I
    I -->|"false: ครบแล้ว"| K["จบ loop"]
กฎที่พลาดบ่อย: (1) OneWire_Reset() ต้องเรียกก่อน ROM command ทุกครั้ง ไม่ใช่แค่ครั้งแรก — แต่ละ transaction (เช่น Convert T แล้วค่อย Read Scratchpad) ต้อง Reset ใหม่เสมอ ดูตัวอย่างโค้ดด้านล่างที่ Reset ซ้ำ 2 รอบ (2) ResetSearch() เรียกแค่ครั้งเดียวก่อนเริ่ม loop ไม่ใช่ทุกรอบของ Search()

Search Algorithm — Maxim AN187

ROM Search ใช้ binary tree traversal — ค้นหา ROM address ทีละ 1 bit (LSB first) โดยอ่านพร้อมกันจากทุกอุปกรณ์:

  1. Read 2 bits: bit จริง + complement — ถ้าทุกตัวตอบ 0 → bit = 0
  2. Conflict detection: ถ้า complement ต่างจาก bit → มีอุปกรณ์หลายตัว → เลือก branch
  3. Write direction: เขียน 0 หรือ 1 เพื่อเลือก branch — อุปกรณ์ที่ ROM ไม่ตรงจะหยุดตอบ
  4. ทำซ้ำ 64 รอบ จนได้ ROM address ครบ 64 bit
Interrupt-safe: Search algorithm ต้องการ timing ที่แม่นยำ — library จะ ปิด IRQ ชั่วคราว ในช่วง critical section

ตัวอย่างโค้ด

อ่านอุณหภูมิจาก DS18B20 ตัวเดียว

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include <SimpleHAL.h>

#define ONE_WIRE_PIN PC0

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();

    OneWire_Bus* bus = OneWire_Init(ONE_WIRE_PIN);
    if (!bus) while(1);  // bus เต็ม (ไม่ควรเกิด)

    while (1) {
        uint8_t data[9];

        // DS18B20 — เริ่มแปลงอุณหภูมิ
        OneWire_Reset(bus);
        OneWire_SkipROM(bus);
        OneWire_WriteByte(bus, 0x44);  // Convert T

        Delay_Ms(750);  // รอแปลงเสร็จ (max 750ms)

        // อ่านผล
        OneWire_Reset(bus);
        OneWire_SkipROM(bus);
        OneWire_WriteByte(bus, 0xBE);  // Read Scratchpad
        OneWire_ReadBytes(bus, data, 9);

        // ตรวจ CRC
        if (!OneWire_VerifyCRC(data, 9)) continue;

        // แปลงอุณหภูมิ — int16 ใน data[0:1]
        int16_t temp_raw = (data[1] << 8) | data[0];
        float temp_c = temp_raw / 16.0f;

        (void)temp_c;
        Delay_Ms(1000);
    }
}

ค้นหาอุปกรณ์ทั้งหมดบนบัส

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include <SimpleHAL.h>

#define ONE_WIRE_PIN PC0
uint8_t roms[10][8];  // เก็บ ROM ได้สูงสุด 10 ตัว
uint8_t device_count = 0;

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();

    OneWire_Bus* bus = OneWire_Init(ONE_WIRE_PIN);

    OneWire_ResetSearch(bus);
    while (OneWire_Search(bus) && device_count < 10) {
        OneWire_GetAddress(bus, roms[device_count]);
        device_count++;
    }

    // device_count = จำนวนอุปกรณ์ที่พบบนบัส
    while (1) {
        Delay_Ms(1000);
    }
}

ตรวจสอบ CRC

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include <SimpleHAL.h>

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();

    uint8_t data[] = {0x28, 0xAA, 0xBB, 0xCC, 0xDD, 0xEE, 0xFF, 0x00};

    uint8_t crc = OneWire_CRC8(data, 8);

    bool valid = OneWire_VerifyCRC(data, 8);

    (void)crc;
    (void)valid;

    while (1) { Delay_Ms(1000); }
}
