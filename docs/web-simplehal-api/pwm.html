โมดูล 8: SimplePWM — ควบคุมความสว่าง/ความเร็ว

ระดับกลาง

ภาพรวม

SimplePWM ควบคุมความสว่าง LED และความเร็วมอเตอร์ผ่าน 8 ช่องสัญญาณ PWM โดยใช้ TIM1 (4 ช่อง) และ TIM2 (4 ช่อง) พร้อมระบบ Timer Ownership Guard ป้องกันการใช้งานทับซ้อนกับ SimpleTIM

  • เริ่มต้นอัตโนมัติที่ 1kHz เมื่อใช้ PWM_Write() หรือ analogWrite()
  • ตั้ง Duty Cycle ได้ทั้งแบบเปอร์เซ็นต์ (0-100%) และแบบ raw (0-period)
  • เปลี่ยนความถี่ได้ตั้งแต่ Hz ต่ำ ๆ (servo 50Hz) จนถึงหลาย kHz
  • ปรับ Remap ขาเอาต์พุตได้สำหรับแพ็กเกจที่มีข้อจำกัดเรื่องขา

Timer Ownership Guard

CH32V003 มี TIM1 และ TIM2 เพียง 2 ตัว — Timer Owner Guard ป้องกันไม่ให้สองโมดูลแย่ง timer ตัวเดียวกัน

Owner Stateความหมาย
TIM_OWNER_NONEยังไม่ถูกใช้
TIM_OWNER_PWMถูกใช้โดย SimplePWM
TIM_OWNER_TIMERถูกใช้โดย SimpleTIM
TIM_OWNER_TIMEXTถูกใช้โดย SimpleTIM_Ext
สำคัญ: ถ้า TIM1 หรือ TIM2 ถูกใช้โดย SimpleTIM หรือ PWM อื่นอยู่แล้ว — Guard จะป้องกันไม่ให้เขียนทับ ฟังก์ชันจะ return ทันทีโดยไม่เปลี่ยนค่า register ใด ๆ

ข้อจำกัด SOP-8

แพ็กเกจ SOP-8 มีเพียง 6 ขาที่ใช้งานได้ — ใช้มาโคร IS_PWM_VALID_PACKAGE(channel) ตรวจสอบว่าช่อง PWM นั้นใช้ได้กับแพ็กเกจปัจจุบันหรือไม่

PWM ช่องขาสถานะ SOP-8
PWM1_CH2PA1✅ ใช้ได้
PWM1_CH4PC4✅ ใช้ได้
อื่น ๆ-❌ ไม่มีใน SOP-8
SOP-8: ใช้ได้แค่ PWM1_CH2 (PA1) และ PWM1_CH4 (PC4) — ช่องอื่นจะถูก IS_PWM_VALID_PACKAGE ปฏิเสธ

Remap

Remapคำอธิบาย
PWM_REMAP_NONEค่าเริ่มต้น — ใช้ขาตามตาราง PWM ด้านบน
PWM_REMAP_PARTIAL1ย้ายบางช่อง — ตรวจสอบ datasheet ก่อนใช้
PWM_REMAP_PARTIAL2ย้ายบางช่อง — ตรวจสอบ datasheet ก่อนใช้
ทดลอง: PWM_REMAP_PARTIAL1 และ PWM_REMAP_PARTIAL2 เป็นการ remap แบบทดลอง — ตรวจสอบ datasheet ก่อนใช้งาน

ถูกลบ: PWM_REMAP_FULL ถูกลบออกแล้ว — ใช้ PWM_InitRemap() หรือ PWM_SetRemap() แทน

ตารางฟังก์ชัน

ฟังก์ชันคืนค่าคำอธิบายใช้ร่วมกับ
PWM_Init(channel, freq_hz)voidเริ่ม PWM ที่ความถี่ที่กำหนด — duty=0%เรียก PWM_Start() ให้อัตโนมัติภายในอยู่แล้ว (auto-start) — ไม่จำเป็นต้องเรียก PWM_Start() เองซ้ำ (เรียกซ้ำได้แต่ไม่มีผลเพิ่มเติม); ตามด้วย PWM_SetDutyCycle() เพื่อให้มีสัญญาณออกจริง (duty เริ่มที่ 0%)
PWM_InitRemap(channel, freq_hz, remap)voidเริ่ม PWM พร้อมกำหนด remapใช้แทน PWM_Init() เมื่อต้องเลือก remap เอง — auto-start เช่นเดียวกับ PWM_Init(); ควรเรียก PWM_SetRemap()/ตั้ง remap ก่อนถ้าจะใช้ผ่าน PWM_Write()/analogWrite() แทน
PWM_Start(channel)voidเริ่มเอาต์พุต PWMปกติไม่ต้องเรียกเอง เพราะ PWM_Init()/InitRemap() เรียกให้แล้ว — ใช้เรียกอีกครั้งเฉพาะหลัง PWM_Stop() เพื่อเปิดเอาต์พุตกลับมา
PWM_Stop(channel)voidหยุดเอาต์พุต — ขาเป็น LOWเรียก PWM_Start() เพื่อเปิดกลับมา — ค่า duty/frequency ที่ตั้งไว้ยังคงอยู่ ไม่ต้องตั้งใหม่
PWM_SetDutyCycle(channel, percent)voidตั้ง Duty Cycle 0-100%ต้องเรียกหลัง PWM_Init()/InitRemap() — เรียกซ้ำได้ตลอดเวลาที่ทำงานอยู่ (ไม่ต้อง Stop/Start ใหม่)
PWM_SetDutyCycleRaw(channel, raw)voidตั้ง Duty Cycle แบบ raw (0 ถึง period)ใช้แทน PWM_SetDutyCycle() เมื่อต้องการความละเอียดกว่า % — ค่า raw สูงสุดต้องไม่เกิน PWM_GetPeriod()
PWM_SetFrequency(channel, freq_hz)voidเปลี่ยนความถี่ — รีเซ็ต duty=0, เปลี่ยนทุกช่องบน timer เดียวกันต้องเรียก PWM_SetDutyCycle() ใหม่หลังจากนี้เสมอ เพราะ duty ถูกรีเซ็ตเป็น 0 — กระทบทุกช่องที่แชร์ timer เดียวกัน ไม่ใช่แค่ channel ที่ระบุ
PWM_Write(channel, value)voidArduino-style 0-255 — auto-init 1kHz ถ้ายังไม่ initทางลัดรวม PWM_Init()+PWM_SetDutyCycle() — auto-init และ auto-start ให้ในครั้งแรกที่เรียก ไม่ต้องเรียก PWM_Init()/PWM_Start() เอง; analogWrite() เป็น alias เดียวกัน
PWM_SetRemap(channel, remap)voidตั้ง remap ล่วงหน้าก่อนเริ่ม PWMต้องเรียกก่อน PWM_Write()/analogWrite() ครั้งแรก ถ้าต้องการ remap ผ่านเส้นทาง auto-init (ฟังก์ชันนี้แค่ "จำ" remap ไว้ใช้ตอน auto-init เท่านั้น ไม่ได้ตั้งค่าฮาร์ดแวร์ทันที)
PWM_GetPeriod(channel)uint16_tอ่านค่า period ปัจจุบันใช้เป็นค่าอ้างอิงสูงสุดให้ PWM_SetDutyCycleRaw()/PWM_RAW_TO_PERCENT()
PWM_GetDutyCycle(channel)uint8_tอ่าน Duty Cycle เป็น %อ่านค่าที่ตั้งจาก PWM_SetDutyCycle()/SetDutyCycleRaw() ล่าสุด — ใช้ debug
PWM_GetDutyCycleRaw(channel)uint16_tอ่าน Duty Cycle แบบ rawเช่นเดียวกับด้านบนแต่คืนหน่วย raw — คู่กับ PWM_GetPeriod() เพื่อคำนวณ % เอง
PWM_AdvancedInit(ch, prescaler, period, duty)voidตั้งค่า PWM เองทั้งหมด (ผู้เชี่ยวชาญ)ใช้แทน PWM_Init() ไม่ใช่ใช้ร่วมกัน — ตรวจสอบว่า auto-start เหมือนกันหรือไม่จากพฤติกรรมจริงก่อนตัด PWM_Start() ทิ้ง
PWM_SetPolarity(channel, inverted)voidกลับขั้ว — 1 = inverted, 0 = ปกติเรียกได้หลัง PWM_Init() เมื่อใดก็ได้ — ไม่กระทบ duty/frequency ที่ตั้งไว้
PWM_PERCENT_TO_RAW(percent, period)uint16_tมาโคร — แปลง % เป็น rawใช้ period จาก PWM_GetPeriod() — ผลลัพธ์ส่งเข้า PWM_SetDutyCycleRaw() ได้ตรง
PWM_RAW_TO_PERCENT(raw, period)uint8_tมาโคร — แปลง raw เป็น %ทิศทางกลับของด้านบน — raw มาจาก PWM_GetDutyCycleRaw()
PWM_Init/InitRemap เริ่มเอาต์พุตให้อัตโนมัติ: ไม่เหมือน TIM_SimpleInit()/WWDG_Init() ที่ต้องเรียก Start เอง — PWM_Init() เรียก PWM_Start() ให้ภายในเสร็จแล้ว โค้ดตัวอย่างที่เรียก PWM_Start() ซ้ำหลัง PWM_Init() จึงไม่ผิด เพียงแค่ไม่จำเป็น

analogWrite() — เริ่มต้นอัตโนมัติ

PWM_Write() และ analogWrite() ทำงานเหมือน Arduino — ถ้าช่อง PWM ยังไม่ได้ init จะ init อัตโนมัติที่ 1kHz

// ไม่ต้องเรียก PWM_Init — auto-init 1kHz
analogWrite(PWM1_CH1, 128);   // duty ~50%
analogWrite(PWM1_CH2, 64);    // duty ~25%
การ auto-init: ตรวจสอบ Timer Ownership Guard ก่อน — ถ้า timer ถูกใช้โดย SimpleTIM แล้วจะ return ทันที

การเปลี่ยนความถี่

PWM_SetFrequency() เปลี่ยนความถี่ของ timer ทั้งตัว — ทุกช่องบน timer เดียวกันจะเปลี่ยนความถี่พร้อมกัน และ duty cycle จะถูกรีเซ็ตเป็น 0

PWM_Init(PWM1_CH1, 1000);  // 1kHz
PWM_SetDutyCycle(PWM1_CH1, 50);
PWM_SetDutyCycle(PWM1_CH2, 25);

// เปลี่ยนความถี่ — PWM1_CH1 และ PWM1_CH2 เปลี่ยนเป็น 50Hz ทั้งคู่
// duty ทั้งสองช่องถูกรีเซ็ตเป็น 0
PWM_SetFrequency(PWM1_CH1, 50);

ข้อผิดพลาดที่พบบ่อย

อาการสาเหตุวิธีแก้
PWM ไม่มีเอาต์พุตPWM_Init() auto-start ให้แล้ว แต่ duty ยังเป็น 0% หรือถูก PWM_Stop() ไปก่อนหน้าเรียก PWM_SetDutyCycle(channel, ...) ให้มากกว่า 0 หรือเรียก PWM_Start(channel) ถ้าเคย Stop ไปแล้ว
PWM_Init ไม่ทำงานTIM1/TIM2 ถูกใช้แล้วTimer Ownership Guard return ทันที — ตรวจสอบว่า timer ถูกใช้ที่อื่นหรือไม่
บางช่องใช้ไม่ได้ใน SOP-8ขาไม่มีใน SOP-8ใช้เฉพาะ PWM1_CH2 (PA1) และ PWM1_CH4 (PC4)
เปลี่ยนความถี่แล้ว duty หายความถี่รีเซ็ต duty เป็น 0เรียก PWM_SetDutyCycle() ใหม่หลังเปลี่ยนความถี่
PWM_REMAP_FULL ไม่มีถูกลบแล้วใช้ PWM_InitRemap() หรือ PWM_SetRemap()

ตัวอย่างโค้ด

LED Fade

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"

int main(void)
{
    SystemCoreClockUpdate();
    Timer_Init();

    PWM_Init(PWM1_CH1, 1000);
    PWM_Start(PWM1_CH1);

    int duty = 0;
    int dir = 1;

    while(1)
    {
        PWM_SetDutyCycle(PWM1_CH1, duty);

        duty += dir;
        if (duty >= 100 || duty <= 0) dir = -dir;

        Delay_Ms(10);
    }
}

Servo Control (50Hz)

PWM_Init(PWM1_CH2, 50);   // 50Hz สำหรับ servo
PWM_Start(PWM1_CH2);

// SG90: 500-2400us pulse = 2.5-12% ที่ 50Hz
PWM_SetDutyCycle(PWM1_CH2, 7.5);  // center
Delay_Ms(1000);
PWM_SetDutyCycle(PWM1_CH2, 2.5);  // 0°
Delay_Ms(1000);
PWM_SetDutyCycle(PWM1_CH2, 12.5); // 180°

เปลี่ยนความถี่ขณะทำงาน

PWM_Init(PWM1_CH1, 1000);
PWM_SetDutyCycle(PWM1_CH1, 50);
PWM_Start(PWM1_CH1);

Delay_Ms(2000);

// เปลี่ยนเป็น 100Hz — duty รีเซ็ต
PWM_SetFrequency(PWM1_CH1, 100);
PWM_SetDutyCycle(PWM1_CH1, 30);

analogWrite Style

// Arduino-style — auto-init 1kHz
analogWrite(PWM1_CH1, 255);  // 100%
analogWrite(PWM1_CH1, 128);  // ~50%
analogWrite(PWM1_CH1, 0);    // 0%
