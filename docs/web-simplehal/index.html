CH32V003 คืออะไร?

CH32V003 เป็นไมโครคอนโทรลเลอร์ตระกูล RISC-V 32-bit จากบริษัท WCH ประเทศจีน จุดเด่นคือราคาถูกมาก (ประมาณ 15 บาท) แต่สเปกเหลือเฟือสำหรับงานทั่วไป — ซีพียู 48MHz, หน่วยความจำ Flash 16KB, RAM 2KB, และ GPIO 18 ขา

ด้วยจุดเด่นด้านราคาและความสามารถ CH32V003 จึงเหมาะกับทั้งผู้เริ่มต้นเรียนรู้ MCU และผู้เชี่ยวชาญที่ต้องการลดต้นทุนการผลิต

คุณสมบัติรายละเอียด
สถาปัตยกรรมRISC-V 32-bit (RV32EC)
ความเร็วซีพียูสูงสุด 48MHz (HSI)
หน่วยความจำ Flash16KB
หน่วยความจำ RAM2KB
GPIOสูงสุด 18 ขา (ขึ้นกับแพ็กเกจ)
ราคาโดยประมาณ~15-35 บาท (ขึ้นกับแพ็กเกจ)

SimpleHAL คืออะไร?

SimpleHAL เป็นไลบรารีที่ห่อหุ้มฮาร์ดแวร์ระดับล่างของ CH32V003 ให้ใช้งานง่ายแบบ Arduino — เขียนโค้ดเพียงไม่กี่บรรทัดก็ควบคุมอุปกรณ์ต่อพ่วงได้ โดยไม่ต้องอ่านรีจิสเตอร์หลายร้อยหน้า

โมดูลที่มีใน SimpleHAL:

  • GPIO — Digital Input/Output, Interrupt, ปุ่มกด, LED, PulseIn
  • ADC — อ่านค่า Analog, แรงดัน, แบตเตอรี่
  • PWM — LED Fade, Servo, มอเตอร์, Frequency Control
  • USART — Serial Communication, Debug Print, Command Line
  • I2C — คุยกับ Sensor, EEPROM, OLED, Bus Scanner
  • SPI — สื่อสารความเร็วสูง, Flash, MAX7219, Display
  • DMA — Direct Memory Access, ADC+DMA, USART+DMA
  • Flash — ข้อมูลถาวร, Config, CRC
  • Watchdog — IWDG, WWDG, ป้องกันระบบค้าง
  • 1-Wire — DS18B20, อ่านอุณหภูมิ, Multi-device
  • Power Management — Sleep, Standby, แบตเตอรี่
  • OPAMP — Operational Amplifier ในตัวชิป

วิธีอ่าน

เริ่มที่ ch00 → ch01 → ch02 ตามลำดับ สำหรับผู้ที่เพิ่งเริ่มต้น

หากมีพื้นฐานแล้ว สามารถกระโดดไปยังโมดูลที่ต้องการได้เลย — แต่ละบทเรียนเป็นอิสระต่อกัน (ยกเว้นบท 0-1 ที่แนะนำให้อ่านก่อน)

สารบัญ

  • บทที่ 0เริ่มต้น ติดตั้งครั้งแรก — Toolchain, IDE, ต่อวงจร, Build & Flash
  • บทที่ 1เริ่มต้น ก้าวแรก — 3 สิ่งที่ต้องทำทุกโปรเจกต์: SystemCoreClockUpdate, Timer_Init, CH32V003_PACKAGE
  • บทที่ 2เริ่มต้น GPIO — Digital Input/Output, Interrupt, ปุ่มกด, LED, PulseIn
  • บทที่ 3เริ่มต้น Delay & Timer — หน่วงเวลา, Non-blocking, millis/micros, Stopwatch
  • บทที่ 4เริ่มต้น USART — Serial Communication, Debug Print, Command Line
  • บทที่ 5กลาง I2C — คุยกับ Sensor, EEPROM, OLED, Bus Scanner
  • บทที่ 6กลาง Software I2C — ใช้ขาไหนก็ได้, ดีบัก, I2C bus ที่ 2
  • บทที่ 7กลาง SPI — สื่อสารความเร็วสูง, Flash, MAX7219, Display
  • บทที่ 8กลาง ADC — อ่านค่า Analog, แรงดัน, แบตเตอรี่
  • บทที่ 9กลาง PWM — LED Fade, Servo, มอเตอร์, Frequency Control
  • บทที่ 10สูง OPAMP — Operational Amplifier ในตัวชิป
  • บทที่ 11สูง Hardware Timer — Periodic Interrupt, Scheduler, Input Capture
  • บทที่ 12สูง Stopwatch & Countdown — จับเวลา, นับถอยหลัง, Lap Timer
  • บทที่ 13สูง DMA — Direct Memory Access, ADC+DMA, USART+DMA
  • บทที่ 14สูง Flash Storage — ข้อมูลถาวร, Config, CRC
  • บทที่ 15สูง IWDG — Independent Watchdog, ป้องกันระบบค้าง
  • บทที่ 16สูง WWDG — Window Watchdog, ตรวจจับ Timing Error
  • บทที่ 17สูง 1-Wire — DS18B20, อ่านอุณหภูมิ, Multi-device
  • บทที่ 18สูง Power Management — Sleep, Standby, แบตเตอรี่
  • บทที่ 19สูง Arduino API — millis/delay/random/dtostrf
