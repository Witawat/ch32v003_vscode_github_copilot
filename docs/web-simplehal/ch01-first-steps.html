3 สิ่งที่ต้องทำทุกโปรเจกต์

① SystemCoreClockUpdate() — บอก MCU ว่า clock เท่าไหร่

CH32V003 รันที่ HSI 48MHz เป็นค่าเริ่มต้น ฟังก์ชันนี้จะอัปเดตตัวแปร SystemCoreClock ให้มีค่า 48000000 ซึ่งสำคัญมากสำหรับการคำนวณ delay, baud rate, และ PWM frequency หากลืมเรียก — ทุกอย่างที่เกี่ยวกับเวลาจะผิดเพี้ยน

② Timer_Init() — เปิด SysTick สำหรับหน่วงเวลา

SysTick เป็นตัวจับเวลาพื้นฐานที่สร้าง interrupt ทุก 1ms ใช้เป็นฐานให้กับฟังก์ชัน Delay_Ms(), Delay_Us(), และ Get_CurrentMs() หากลืมเรียก — Delay จะค้าง infinity loop

③ #define CH32V003_PACKAGE — เลือกแพ็กเกจของชิป

CH32V003 มี 4 แพ็กเกจ (SOP-8, SOP-16, TSSOP-20, QFN-20) แต่ละแพ็กเกจมีจำนวนขาไม่เท่ากัน — ต้องกำหนดก่อน #include "SimpleHAL.h" เพื่อให้คอมไพเลอร์รู้ว่าขาไหนมี ขาไหนไม่มี และแจ้ง error หากใช้ขาที่ไม่มีในแพ็กเกจนั้น

CH32V003_PACKAGE คืออะไร

CH32V003 มี 4 แพ็กเกจให้เลือก ขึ้นกับรุ่นชิปที่คุณซื้อมา:

#define CH32V003_PACKAGE  PACKAGE_SOP8      // SOP-8  (J4M6)  — 6 GPIO
#define CH32V003_PACKAGE  PACKAGE_SOP16     // SOP-16 (A4M6)  — 14 GPIO
#define CH32V003_PACKAGE  PACKAGE_TSSOP20   // TSSOP-20 (F4P6) — 18 GPIO
#define CH32V003_PACKAGE  PACKAGE_QFN20     // QFN-20 (F4U6)  — 18 GPIO
แพ็กเกจรุ่นชิปจำนวนขาGPIOขาที่ใช้ได้
SOP-8CH32V003J4M686PA1, PA2, PC1, PC2, PC4, PD6
SOP-16CH32V003A4M61614PA1, PA2, PC0, PC1, PC2, PC3, PC4, PD0, PD1, PD2, PD3, PD4, PD5, PD6
TSSOP-20CH32V003F4P62018PA1, PA2, PC0-PC4, PC7, PD0-PD7 (ครบทุกขา)
QFN-20CH32V003F4U62018เหมือน TSSOP-20
💡 แนะนำ: หากไม่แน่ใจว่าชิปของคุณรุ่นอะไร — ดูตัวอักษรบนตัวชิป: J4M6 = SOP-8, A4M6 = SOP-16, F4P6 = TSSOP-20, F4U6 = QFN-20

3 วิธี Include SimpleHAL

วิธีที่ 1: All-in-one (แนะนำ)

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"

รวมทุกโมดูลไว้ในไฟล์เดียว — สะดวก ไม่ต้อง include แยก แต่ใช้ Flash มากกว่าเล็กน้อย (เนื่องจากรวมฟังก์ชันที่ไม่ได้ใช้)

วิธีที่ 2: Specific Modules

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL/SimpleGPIO.h"
#include "SimpleHAL/SimpleADC.h"

Include เฉพาะโมดูลที่ใช้ — ประหยัด Flash และ compile เร็ว เหมาะสำหรับโปรเจกต์ที่มีข้อจำกัดด้านหน่วยความจำ

วิธีที่ 3: All Together

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL/SimpleHAL.h"

เหมือนวิธีที่ 1 แต่ใช้ path แบบมีโฟลเดอร์ — ใช้เมื่อ Library อยู่ใน User/SimpleHAL/

โครงสร้าง main() ที่ถูกต้อง

#define CH32V003_PACKAGE  PACKAGE_TSSOP20
#include "SimpleHAL.h"

int main(void)
{
    SystemCoreClockUpdate();  // ① ต้องเป็นบรรทัดแรก
    Timer_Init();             // ② ต้องเป็นบรรทัดที่สอง

    // ③ ตั้งค่า peripherals ที่นี่
    pinMode(PC0, PIN_MODE_OUTPUT);

    while (1) {
        // loop หลัก
        digitalWrite(PC0, HIGH);
        Delay_Ms(500);
        digitalWrite(PC0, LOW);
        Delay_Ms(500);
    }
}
⚠️ ลำดับสำคัญ: ① SystemCoreClockUpdate() ต้องมาก่อน ② Timer_Init() เสมอ — เพราะ Timer_Init ต้องใช้ค่า SystemCoreClock ที่อัปเดตแล้ว

Hello World ครบวงจร

ตัวอย่างโค้ดที่สมบูรณ์ — LED กระพริบที่ PC0 พร้อมส่งข้อความผ่าน Serial:

#define CH32V003_PACKAGE  PACKAGE_TSSOP20
#include "SimpleHAL.h"

int main(void)
{
    // ① อัปเดตความถี่ระบบ — ต้องมาก่อนเสมอ
    SystemCoreClockUpdate();

    // ② เริ่มต้น Systick — จำเป็นสำหรับ Delay และ Get_CurrentMs
    Timer_Init();

    // ③ ตั้งค่า peripherals
    pinMode(PC0, PIN_MODE_OUTPUT);              // LED output
    USART_SimpleInit(USART_BAUD_115200);        // Serial 115200 bps

    uint32_t counter = 0;                       // ตัวนับรอบ

    while (1)
    {
        digitalWrite(PC0, HIGH);                // ติด LED
        Delay_Ms(500);                          // รอ 500ms
        digitalWrite(PC0, LOW);                 // ดับ LED
        Delay_Ms(500);                          // รอ 500ms

        counter++;                              // เพิ่มตัวนับ
        USART_Print("Counter: %lu\r\n", counter); // ส่งค่าผ่าน Serial
    }
}

💡 อธิบายทีละบรรทัด:
  • #define CH32V003_PACKAGE — เลือกแพ็กเกจ TSSOP-20 (F4P6)
  • pinMode(PC0, PIN_MODE_OUTPUT) — ตั้ง PC0 เป็น output push-pull
  • USART_SimpleInit() — เปิด Serial ที่ baud rate 115200
  • digitalWrite() — เขียน HIGH (3.3V) หรือ LOW (0V) ไปยังขา
  • Delay_Ms(500) — หยุดรอ 500 มิลลิวินาที (ครึ่งวินาที)
  • USART_Print() — ส่งข้อความพร้อมตัวแปรผ่าน Serial

Debug Print คืออะไร

Debug Print คือการส่งข้อความจาก MCU มาที่คอมพิวเตอร์ผ่าน Serial (USART) เพื่อดูว่าโปรแกรมทำงานอย่างไร — เป็นเครื่องมือดีบักที่สำคัญที่สุดสำหรับ embedded

วิธีใช้:

  1. เปิด Serial ด้วย USART_SimpleInit(USART_BAUD_115200)
  2. ส่งข้อความด้วย USART_Print("รูปแบบ %d\r\n", ตัวแปร)
  3. ดูผลใน Serial Monitor (Baud rate ต้องตรงกับที่ตั้งไว้)

ลองทำดู

  1. เปลี่ยน LED ไปใช้ pin อื่น — ลองเปลี่ยนจาก PC0 เป็น PA1 → ต่อวงจรใหม่ → Build → Flash → สังเกตผล
  2. เปลี่ยนความถี่กระพริบ — ลองเปลี่ยน Delay_Ms(500) เป็น Delay_Ms(100) และ Delay_Ms(1000) → สังเกตความเร็วที่เปลี่ยน
  3. เพิ่มปุ่มกดเปลี่ยนทิศทาง LED — ต่อปุ่มที่ PC1 → ใช้ digitalRead() อ่านค่าปุ่ม → เมื่อกดให้ LED กระพริบกลับด้าน (LOW→HIGH แทน HIGH→LOW)
