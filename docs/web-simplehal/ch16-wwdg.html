บทที่ 16: WWDG — Window Watchdog ตรวจจับ Timing Error

ระดับสูง

สิ่งที่ต้องรู้ก่อน

  • บทที่ 15: IWDG — เข้าใจแนวคิด watchdog ก่อน

อุปกรณ์ที่ต้องใช้

  • CH32V003 Dev Board (ไม่ต้องใช้อุปกรณ์เสริมภายนอก)

ทำไมต้องใช้?

ตรวจจับว่าฟังก์ชันทำงานเร็วหรือช้าเกินไป — real-time system, motor control, safety-critical — ผิดปกติแค่ไหนก็รู้

Flowchart การทำงาน

flowchart TD
    A["Counter=0x7F"] --> B["นับถอยหลังทุก PCLK tick"]
    B --> C{"Counter อยู่ใน Window?"}
    C -->|"ใช่ (0x40)"| D["WWDG_Refresh() → OK"]
    C -->|"ไม่ (เร็วเกิน) = ก่อน window"| E["RESET!"]
    C -->|"ไม่ (ช้าเกิน) = <0x40"| F["Early Warning Interrupt"]
    F --> G{"Refresh ทัน?"}
    G -->|"ทัน"| D
    G -->|"ไม่ทัน"| H["RESET! @0x3F"]

หลักการทำงาน

  • Counter: 0x7F → 0x3F (นับถอยหลังทุก PCLK1 tick)
  • Window constraint: ต้อง refresh หลังจาก counter น้อยกว่าค่า window และก่อนถึง 0x40
  • PCLK1: 24MHz (ใช้ร่วมกับ peripherals)
  • Prescaler: /1, /2, /4, /8
PrescalerMax Timeout
/1~10.9ms
/2~21.8ms
/4~43.7ms
/8~87.4ms
สูตรคำนวณ: T(ms) = (counter - 0x3F) × prescaler × 4096 / 24,000,000 × 1000

API Reference

ฟังก์ชันคำอธิบาย
WWDG_SimpleInit(counter, window)เริ่มต้น WWDG แบบง่าย
WWDG_Refresh()ต่ออายุ watchdog (reload counter)
WWDG_CalcTimeout(counter, prescaler)คำนวณ timeout เป็น ms
WWDG_GetInterruptFlag()อ่าน flag Early Warning interrupt
WWDG_ClearInterruptFlag()ล้าง flag Early Warning interrupt
WWDG_Disable()ปิด WWDG (ใช้ได้ก่อน WDGA=1 เท่านั้น)
WWDG_InitWithInterrupt(counter, window)เริ่มต้น WWDG พร้อม Early Warning interrupt
WWDG_SetCallback(fn)ตั้ง callback สำหรับ Early Warning interrupt
WWDG_Init(counter, window, prescaler)เริ่มต้น WWDG แบบกำหนดค่าครบ

คำเตือนสำคัญ

  1. เมื่อ WDGA bit = 1 → หยุดด้วยซอฟต์แวร์ไม่ได้ (hardware limitation)
  2. window > counter → auto-clamped v2.1 (เวอร์ชันเก่าจะเกิด infinite reset loop)
  3. ต้องเรียก WWDG_SetCallback ก่อน WWDG_InitWithInterrupt

ขั้นตอนการใช้งาน (Step by Step)

1. คำนวณ Timeout

เลือก counter (0x7F-0x40) และ window (0x7F-0x40) ให้เหมาะสมกับรอบการทำงาน

2. เริ่มต้น WWDG

WWDG_SimpleInit(0x7F, 0x5F) — counter=0x7F, window=0x5F

3. Refresh ในช่วงเวลาที่ถูกต้อง

WWDG_Refresh() — ต้องเรียกเมื่อ counter อยู่ในช่วง (0x40, window)

4. ระวัง Refresh เร็วเกิน!

ถ้า refresh ก่อนที่ counter จะลดถึงค่า window → RESET ทันที

ระดับขั้นต้น: Basic WWDG — Refresh ทุก 20ms

#include "SimpleHAL.h"

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(USART_115200);

    // counter=0x7F, window=0x5F (ต้อง refresh ระหว่าง 0x5F-0x40)
    WWDG_SimpleInit(0x7F, 0x5F);

    printf("WWDG started\r\n");

    while (1) {
        Delay_Ms(20); // รอให้ counter อยู่ในช่วง window
        WWDG_Refresh();
        printf("Refresh ok\r\n");
    }
}

ระดับขั้นกลาง: WWDG พร้อม Early Warning Interrupt

แนวคิด: ใช้ Early Warning interrupt (counter ≤ 0x40) — แจ้งเตือนก่อน reset จริง — บันทึกสถานะหรือ debug 
#include "SimpleHAL.h"

void wwdg_warning_callback(void) {
    printf("WARNING: WWDG near reset!\r\n");
    // บันทึก debug info, เตรียม shutdown ฯลฯ
}

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(USART_115200);

    // ต้องตั้ง callback ก่อน InitWithInterrupt
    WWDG_SetCallback(wwdg_warning_callback);
    WWDG_InitWithInterrupt(0x7F, 0x5F);

    printf("WWDG with Early Warning started\r\n");

    while (1) {
        Delay_Ms(15);
        WWDG_Refresh();
        printf("Running...\r\n");
    }
}

ระดับขั้นสูง: Timing Violation Detection

แนวคิด: งาน real-time ต้องเสร็จภายใน 10-40ms window — ถ้าเร็วเกินหรือช้าเกิน → WWDG reset → แจ้ง error 
#include "SimpleHAL.h"

volatile uint8_t task_done = 0;

void realtime_task(void) {
    // งานสำคัญ: อ่าน sensor, คำนวณ PID, ส่ง motor command
    // ห้ามช้ากว่า 40ms หรือเร็วเกิน 10ms
    printf("Realtime task running...\r\n");
    Delay_Ms(25);
    task_done = 1;
}

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(USART_115200);

    // counter=0x7F, window=0x5F (refresh window: ~10-40ms)
    WWDG_SimpleInit(0x7F, 0x5F);

    printf("Timing violation detector started\r\n");

    while (1) {
        task_done = 0;
        realtime_task();

        if (task_done) {
            WWDG_Refresh(); // OK — เสร็จในเวลาที่กำหนด
        }
        // ถ้าไม่ refresh → WWDG reset → timing violation!
    }
}

ข้อผิดพลาดที่พบบ่อย

อาการสาเหตุวิธีแก้
Reset ทันทีที่เริ่มRefresh ก่อนที่ counter จะถึง windowdelay พอก่อน refresh ครั้งแรก
Timeout สั้นเกินไปPrescaler น้อยไปใช้ prescaler ใหญ่ขึ้น หรือลดรอบ
เข้าใจผิดว่าเหมือน IWDGWWDG ต้อง refresh ในช่วงเวลาเท่านั้นคิด window ก่อน-หลัง ไม่ใช่แค่ก่อนหมด
ใช้กับ sleep ไม่ได้PCLK หยุดระหว่าง sleepใช้ IWDG แทนถ้าต้องการ sleep

คำถามที่พบบ่อย (FAQ)

ทำไมต้องมี Window?

Window ป้องกันทั้งเร็วเกินและช้าเกิน — เหมาะกับ safety-critical — ดูรายละเอียดที่ บทที่ 15

Disable WWDG ได้ไหม?

ไม่ได้! — Hardware ตั้งใจให้เป็นแบบนี้เพื่อความปลอดภัย — WDGA bit = 1 แล้วปิดไม่ได้

ลองทำดู (แบบฝึกหัด)

  1. ตั้งค่า WWDG พื้นฐาน counter=0x7F, window=0x5F
  2. เปิด Early Warning interrupt — ติด LED แจ้งเตือนก่อน reset
  3. ทดสอบ refresh เร็วเกินไป (ก่อน window) → สังเกต reset
