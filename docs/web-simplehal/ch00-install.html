ขั้นที่ 1: ติดตั้ง MounRiver Studio

MounRiver Studio 2 (MRS2) เป็น IDE ฟรีสำหรับ RISC-V MCU จาก WCH — เราใช้ MRS2 เพื่อ toolchain และไดรเวอร์ OpenOCD สำหรับแฟลชโปรแกรม

  1. ไปที่ http://www.mounriver.com/ → ดาวน์โหลด MounRiver Studio 2
  2. ติดตั้งที่ C:\MounRiver\MounRiver_Studio2\ (path default — แนะนำให้ใช้ path นี้)
  3. หลังติดตั้งเสร็จ ยังไม่ต้องเปิด MRS2 — เราใช้แค่ toolchain ที่มาพร้อมมัน
⚠️ สำคัญ: ต้องติดตั้งที่ C:\MounRiver\ — build script อ้างอิง path นี้ หากติดตั้งที่อื่นต้องแก้ scripts\build.bat

ขั้นที่ 2: ติดตั้ง WCH-Link Driver

WCH-LinkE ต้องการไดรเวอร์ WinUSB บน Windows — โดยปกติ Windows จะติดตั้งให้เองเมื่อเสียบครั้งแรก

หากไม่ติด ให้ลงไดรเวอร์จาก:

C:\MounRiver\MounRiver_Studio2\resources\app\resources\win32\components\WCH\Drivers\

วิธีตรวจสอบ: เปิด Device Manager (กด Win + X → Device Manager) → มองหา "WCH-Link" หรือ "WCH-LinkE" ในหมวด Universal Serial Bus devices

💡 หมายเหตุ: บางครั้ง Windows อาจแสดงเป็น "Unknown device" — ให้คลิกขวา → Update driver → Browse → เลือกโฟลเดอร์ Drivers ด้านบน

ขั้นที่ 3: ต่อวงจร

การเชื่อมต่อระหว่าง WCH-LinkE และ CH32V003 ใช้เพียง 3 เส้น:

    WCH-LinkE                   CH32V003
    ┌───────────┐              ┌──────────┐
    │  3.3V  ├────────────────┤ VDD (5)  │
    │   GND   ├────────────────┤ GND (4)  │
    │  SWDIO  ├────────────────┤ PD1 (7)  │
    └───────────┘              └──────────┘

    ไฟเลี้ยง: WCH-LinkE จ่าย 3.3V ให้ CH32V003 ได้โดยตรง
WCH-LinkE→CH32V003ขาหมายเหตุ
3.3V→VDDPin 5WCH-Link จ่ายไฟให้ MCU
GND→GNDPin 4GND ร่วม
SWDIO↔PD1Pin 7สายข้อมูลแฟลช (SWD)
⚠️ คำเตือน:
  • CH32V003 ใช้ไฟ 3.3V — ห้าม ต่อ 5V เข้า VDD โดยตรง
  • ต่อ GND ให้แน่น — วงจรไม่ครบ = ไม่ทำงาน

ขั้นที่ 4: สร้างโปรเจกต์แรก

ใน MounRiver Studio:

  1. File → New → MounRiver Project
  2. เลือก CH32V003F4P6 จากรายการชิป
  3. ตั้งชื่อโปรเจกต์ (เช่น my_first_project)
  4. คลิก Finish

ไฟล์ที่ถูกสร้าง:

  • User/main.c — ไฟล์หลักที่เราเขียนโค้ด
  • Peripheral/ — Standard Peripheral Library จาก WCH
  • Core/ — RISC-V Core (startup, vector table)
  • Ld/ — Linker script
💡 SimpleHAL: ให้คัดลอกโฟลเดอร์ User/SimpleHAL/ จากโปรเจกต์ SimpleHAL มาไว้ใน User/ ของโปรเจกต์นี้

ขั้นที่ 5: Build

คัดลอกโค้ดต่อไปนี้ลงใน main.c:

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"

int main(void)
{
    SystemCoreClockUpdate();
    Timer_Init();
    pinMode(PC0, PIN_MODE_OUTPUT);

    while (1)
    {
        digitalWrite(PC0, HIGH);
        Delay_Ms(500);
        digitalWrite(PC0, LOW);
        Delay_Ms(500);
    }
}

คลิกปุ่ม Build (รูปค้อน) — ต้องผ่านด้วย 0 errors

หาก Build ผ่าน จะเห็นข้อความ:

Build Successful — Flash: ~3500 / 16384 bytes (21%)

ขั้นที่ 6: Flash

  1. ต่อ WCH-LinkE เข้ากับ CH32V003 ตามวงจรในขั้นที่ 3
  2. เสียบ WCH-LinkE เข้า USB คอมพิวเตอร์
  3. คลิกปุ่ม Download (รูปลูกศรลง) ใน MounRiver Studio
  4. รอข้อความ "Download OK" → MCU จะรีเซ็ตอัตโนมัติ

LED ที่ PC0 กระพริบ = สำเร็จ!

ข้อผิดพลาดที่พบบ่อย

ปัญหาสาเหตุวิธีแก้
WCH-Link ไม่เจอไดรเวอร์ไม่ได้ติดตั้งเช็คไดรเวอร์ใน Device Manager ติดตั้งจากโฟลเดอร์ Drivers ของ MRS2
Flash ไม่ผ่านสาย SWDIO/SWCLK ต่อผิดเช็คสาย — SWDIO ต้องต่อกับ PD1 (Pin 7), GND ต้องต่อร่วม
LED ไม่ติดขั้ว LED กลับด้าน หรือลืม Rเช็คขั้ว LED: ขายาว (Anode) → R → PC0, ขาสั้น (Cathode) → GND
Compiler not foundMounRiver Studio ไม่ได้ติดตั้งติดตั้ง MRS2 ที่ path default หรือแก้ TOOLCHAIN_BASE ใน build script
MCU ร้อนผิดปกติต่อไฟ 5V เข้า VDDถอดไฟทันที — CH32V003 ใช้ 3.3V เท่านั้น
