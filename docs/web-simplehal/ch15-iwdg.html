บทที่ 15: IWDG — Independent Watchdog ป้องกันระบบค้าง

ระดับสูง

สิ่งที่ต้องรู้ก่อน

  • บทที่ 1: ขั้นตอนแรก (basic setup)

อุปกรณ์ที่ต้องใช้

  • CH32V003 Dev Board (ไม่ต้องใช้อุปกรณ์เสริมภายนอก)

ทำไมต้องใช้?

ถ้าโปรแกรมค้าง (deadlock, infinite loop) — IWDG จะรีเซ็ต MCU ให้เองอัตโนมัติ = อุปกรณ์ไม่ค้างตลอดไป

Flowchart การทำงาน

flowchart TD
    A["IWDG_SimpleInit(timeout)"] --> B["while(1)"]
    B --> C["ทำงานปกติ..."]
    C --> D["IWDG_Feed() ← ต่ออายุ"]
    D --> B
    B -->|"ถ้าโปรแกรมค้าง!"| E["ไม่ Feed"]
    E --> F["⏰ หมดเวลา → RESET!"]
    F --> A

คุณสมบัติสำคัญ

  • Clock source: LSI ~40kHz — เป็นอิสระจาก CPU clock (ทำงานแม้ CPU ค้าง)
  • ความแม่นยำ: ±25% (LSI oscillator)
  • Timeout: 1ms – 32.7 วินาที
  • เริ่มแล้วหยุดไม่ได้ — เมื่อเปิด IWDG จะหยุดด้วยซอฟต์แวร์ไม่ได้ (hardware safety)
สำคัญ: เมื่อเริ่ม IWDG จะหยุดไม่ได้อีกเลยจนกว่า MCU จะถูกรีเซ็ต — ทดสอบโค้ดให้ดีก่อน enable

API Reference

ฟังก์ชันคำอธิบาย
IWDG_SimpleInit(timeout_ms)เริ่มต้น IWDG แบบง่าย ระบุ timeout เป็น ms
IWDG_Feed()ต่ออายุ watchdog (reset counter)
IWDG_IsBusy()ตรวจสอบว่า IWDG กำลังเริ่มต้นอยู่หรือไม่
IWDG_Init(prescaler, reload)เริ่มต้น IWDG แบบกำหนดค่าเอง
IWDG_GetTimeout()อ่านค่า timeout ปัจจุบัน (ms)
IWDG_WasResetCause()ตรวจสอบว่ารีเซ็ตล่าสุดเกิดจาก IWDG หรือไม่
IWDG_ClearResetFlag()ล้าง flag รีเซ็ตจาก IWDG

Helper Macros

Macroคำอธิบาย

ขั้นตอนการใช้งาน (Step by Step)

1. เลือก Timeout

คำนวณเวลาที่เหมาะสม — ควรนานกว่า loop หลัก 2-3 เท่า

2. เริ่มต้น IWDG

IWDG_SimpleInit(2000) — timeout 2 วินาที

3. Feed ใน Main Loop

IWDG_Feed() — เรียกเป็นระยะใน while(1) ก่อนหมด timeout

4. ห้าม Feed ใน ISR

ถึงโปรแกรมจะค้าง ISR ก็ยังทำงานได้ — ควร feed ใน main loop เท่านั้น

ระดับขั้นต้น: Basic Watchdog — 2 วินาที

#include "SimpleHAL.h"

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);

    IWDG_SimpleInit(2000); // timeout 2 วินาที

    USART_Print("Watchdog started\r\n");
    uint32_t last_feed = Get_CurrentMs();

    while (1) {
        // ทำงานปกติทุก 1 วินาที
        if (Get_CurrentMs() - last_feed >= 1000) {
            last_feed = Get_CurrentMs();
            IWDG_Feed();
            USART_Print("Feed ok\r\n");
        }
    }
}

ระดับขั้นกลาง: Watchdog กับ Task ที่อาจค้าง

แนวคิด: ใช้ receive_data_timeout pattern — ถ้ารับข้อมูลนานเกิน watchdog จะรีเซ็ตให้เอง 
#include "SimpleHAL.h"

void risky_receive_task(void) {
    // งานที่อาจค้าง เช่น รอข้อมูลจาก sensor
    uint32_t start = Get_CurrentMs();
    while (1) {
        if (USART_Available() > 0) {
            uint8_t ch = USART_ReadChar();
            USART_Print("Received: ");
            USART_WriteByte(ch);
            USART_Print("\r\n");
            return; // สำเร็จ
        }
        if (Get_CurrentMs() - start > 5000) {
            USART_Print("Timeout!\r\n");
            return; // ออกเองก่อน watchdog reset
        }
    }
}

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);
    IWDG_SimpleInit(3000);

    while (1) {
        IWDG_Feed();
        risky_receive_task();
        Delay_Ms(100);
    }
}

ระดับขั้นสูง: ตรวจจับสาเหตุ Reset

แนวคิด: หลังรีเซ็ต — ตรวจสอบว่าเกิดจาก IWDG, PIN reset, POR, หรือ Software reset — บันทึก log ก่อนเริ่มระบบใหม่ 
#include "SimpleHAL.h"

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);

    USART_Print("--- Boot ---\r\n");

    if (IWDG_WasResetCause()) {
        USART_Print("Reset cause: IWDG (Watchdog timeout!)\r\n");
        USART_Print("ระบบอาจค้างก่อนหน้านี้ กรุณาตรวจสอบ\r\n");
        IWDG_ClearResetFlag();
    }

    // เริ่ม IWDG ใหม่
    IWDG_SimpleInit(2000);

    while (1) {
        IWDG_Feed();
        Delay_Ms(1000);
        USART_Print("Running...\r\n");
    }
}

คำถามที่พบบ่อย (FAQ)

IWDG vs WWDG ใช้อะไรดี?

IWDG ป้องกัน hang (โปรแกรมค้าง) — WWDG ป้องกัน timing error (ทำงานเร็วหรือช้าเกินไป) — ดูเพิ่มที่ บทที่ 16

ทำไมไม่ใช้ delay แทน?

delay ไม่ช่วยถ้าโปรแกรมค้างใน infinite loop — watchdog เป็นอิสระจาก CPU ทำงานเองได้

Arduino มี IWDG ไหม?

Arduino UNO (ATmega328P) มี built-in watchdog — แต่ต้องเปิดใช้งานเอง ไม่มีให้โดย default

ลองทำดู (แบบฝึกหัด)

  1. เปิด IWDG timeout 5 วินาที — feed ทุก 2 วินาที
  2. จงใจสร้าง infinite loop ในโค้ด → สังเกต MCU reset เองอัตโนมัติ
  3. ตรวจจับสาเหตุ reset ด้วย IWDG_WasResetCause() — แสดงข้อความก่อนเริ่มระบบใหม่
