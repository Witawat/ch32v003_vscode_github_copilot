MISC — NVIC Interrupt Priority Configuration

ระดับกลาง
ไลบรารี: #include "ch32v00x_misc.h" — นี่คือ Standard Peripheral Library (SPL) ระดับล่างที่ตั้งค่า NVIC (Nested Vectored Interrupt Controller) ของแกน RISC-V โดยตรง ไม่ใช่ SimpleHAL
MISC ไม่มี wrapper ใน SimpleHAL โดยตรง — ฟังก์ชัน attachInterrupt() ของ SimpleHAL เรียกใช้ NVIC_Init() "ภายใน" ให้อัตโนมัติด้วยค่า priority ที่ตั้งไว้ล่วงหน้า ผู้ใช้ SimpleHAL ทั่วไปจึงไม่จำเป็นต้องเรียก NVIC เอง — หน้านี้เหมาะกับผู้ที่ต้องการควบคุมลำดับความสำคัญของ interrupt แบบละเอียด (เช่น ให้ UART ขัดจังหวะ timer ได้) หรือเขียนโค้ดแบบ bare-metal

แนวคิดสำคัญ: Priority Group ต้องตั้งครั้งเดียวก่อน NVIC_Init ทั้งหมด

กฎเหล็กของ NVIC บน CH32V003: CH32V003 ใช้แกน RISC-V (QingKe V2A) ซึ่งมี priority เพียง 2 บิต (ไม่เหมือน ARM Cortex-M ที่มีถึง 4-8 บิต) การซ้อนทับของ interrupt (nesting) ถูกกำหนดจากค่า CSR 0x804 บิต 1 ในไฟล์ startup (.S) — ถ้าเปิด nesting (INTSYSCR_INEST_EN) priority จะแบ่งเป็น 1 บิต preemption + 1 บิต sub; ถ้าปิด nesting priority จะเป็น 0 บิต preemption + 2 บิต sub เท่านั้น ต้องเรียก NVIC_PriorityGroupConfig() เพียงครั้งเดียว ก่อนเรียก NVIC_Init() ตัวแรก — ถ้าเปลี่ยนกลุ่มภายหลัง priority ที่ IRQ อื่นตั้งไว้ก่อนหน้าจะตีความผิดทันที

Enum / Struct / ค่าคงที่ที่ใช้บ่อย

1. NVIC_InitTypeDef (โครงสร้างตั้งค่าแต่ละ IRQ)

ฟิลด์ชนิดความหมาย
NVIC_IRQChanneluint8_tหมายเลข IRQ เช่น TIM2_IRQn, USART1_IRQn, EXTI7_0_IRQn (นิยามอยู่ใน ch32v00x.h)
NVIC_IRQChannelPreemptionPriorityuint8_tลำดับความสำคัญก่อน — ถ้าเปิด nesting: 0–1, ถ้าปิด nesting: ต้องเป็น 0 เสมอ
NVIC_IRQChannelSubPriorityuint8_tลำดับความสำคัญรอง — ถ้าเปิด nesting: 0–1, ถ้าปิด nesting: 0–3
NVIC_IRQChannelCmdFunctionalStateENABLE = เปิดใช้งาน IRQ นี้, DISABLE = ปิด

2. Interrupt Nesting Config (ตั้งใน startup file ไม่ใช่ใน C runtime)

ค่าคงที่ความหมาย
INTSYSCR_INEST_NoENปิดการซ้อนทับ interrupt (CSR 0x804 bit1 = 0) — priority มีแค่ sub priority 2 บิต (0-3), ไม่มี preemption
INTSYSCR_INEST_ENเปิดการซ้อนทับ interrupt (CSR 0x804 bit1 = 1) — priority แบ่งเป็น preemption 1 บิต + sub 1 บิต — ค่า default ของไลบรารีนี้

3. Priority Group

ค่าคงที่เมื่อไรมีให้ใช้ความหมาย
NVIC_PriorityGroup_0เมื่อ INTSYSCR_INEST == INTSYSCR_INEST_NoEN (ปิด nesting)0 บิต preemption / 2 บิต sub priority
NVIC_PriorityGroup_1เมื่อ INTSYSCR_INEST != INTSYSCR_INEST_NoEN (เปิด nesting, ค่า default)1 บิต preemption / 1 บิต sub priority
NVIC_PriorityGroup_0 และ NVIC_PriorityGroup_1 ถูก #if/#else เลือกไว้ตั้งแต่ตอนคอมไพล์ตามค่า INTSYSCR_INEST — มีให้ใช้แค่ตัวเดียวในโปรแกรมเดียวกัน ไม่ใช่เลือกได้ทั้งสองแบบตอนรัน

ตารางอ้างอิงฟังก์ชัน

ฟังก์ชันพารามิเตอร์คืนค่าคำอธิบายหมายเหตุ
NVIC_PriorityGroupConfig(NVIC_PriorityGroup) NVIC_PriorityGroup: NVIC_PriorityGroup_0 หรือ NVIC_PriorityGroup_1 (แล้วแต่ค่า INTSYSCR_INEST) void กำหนดว่า priority ของ IRQ แบ่งเป็นกี่บิต preemption และกี่บิต sub priority เรียกเพียงครั้งเดียวตอนต้นโปรแกรม ก่อนเรียก NVIC_Init() ตัวใดๆ ทั้งหมด
NVIC_Init(NVIC_InitStruct) NVIC_InitStruct: NVIC_InitTypeDef* void ตั้งค่า priority และเปิด/ปิด IRQ channel ที่ระบุตามโครงสร้างที่ส่งมา ต้องเรียก NVIC_PriorityGroupConfig() ก่อนหน้าแล้ว และต้องกำหนดค่าในโครงสร้างให้อยู่ในช่วงที่ priority group นั้นรองรับ ไม่งั้นค่าจะถูกละเว้นเงียบๆ (ฟังก์ชันภายในเช็ค group ตรงหรือไม่ก่อนเรียก NVIC_SetPriority)

ตัวอย่างโค้ด

1. ตั้งค่าพื้นฐาน: เปิด priority group แล้วเปิดใช้งาน 1 IRQ

#include "ch32v00x_misc.h"
#include "ch32v00x_tim.h"

int main(void)
{
    // เรียกครั้งเดียวตอนต้นโปรแกรม ก่อน NVIC_Init ทั้งหมด
    NVIC_PriorityGroupConfig(NVIC_PriorityGroup_1);

    NVIC_InitTypeDef NVIC_InitStructure = {0};
    NVIC_InitStructure.NVIC_IRQChannel = TIM2_IRQn;
    NVIC_InitStructure.NVIC_IRQChannelPreemptionPriority = 1;
    NVIC_InitStructure.NVIC_IRQChannelSubPriority = 0;
    NVIC_InitStructure.NVIC_IRQChannelCmd = ENABLE;
    NVIC_Init(&NVIC_InitStructure);

    while (1) { }
}

2. ตั้งค่าหลาย IRQ ให้ priority ต่างกัน (ให้ตัวหนึ่งขัดจังหวะอีกตัวได้)

#include "ch32v00x_misc.h"

void SetupInterrupts(void)
{
    NVIC_PriorityGroupConfig(NVIC_PriorityGroup_1);  // 1 บิต preempt / 1 บิต sub

    NVIC_InitTypeDef NVIC_InitStructure = {0};

    // USART1: preemption priority สูงกว่า (1) — ขัดจังหวะ TIM2 ได้ระหว่างทำงาน
    NVIC_InitStructure.NVIC_IRQChannel = USART1_IRQn;
    NVIC_InitStructure.NVIC_IRQChannelPreemptionPriority = 1;
    NVIC_InitStructure.NVIC_IRQChannelSubPriority = 0;
    NVIC_InitStructure.NVIC_IRQChannelCmd = ENABLE;
    NVIC_Init(&NVIC_InitStructure);

    // TIM2: preemption priority ต่ำกว่า (0) — ถูก USART1 แทรกได้
    NVIC_InitStructure.NVIC_IRQChannel = TIM2_IRQn;
    NVIC_InitStructure.NVIC_IRQChannelPreemptionPriority = 0;
    NVIC_InitStructure.NVIC_IRQChannelSubPriority = 0;
    NVIC_InitStructure.NVIC_IRQChannelCmd = ENABLE;
    NVIC_Init(&NVIC_InitStructure);
}

3. ปิดใช้งาน IRQ ชั่วคราว (critical section)

#include "ch32v00x_misc.h"

void DisableTimerIRQ(void)
{
    NVIC_InitTypeDef NVIC_InitStructure = {0};
    NVIC_InitStructure.NVIC_IRQChannel = TIM2_IRQn;
    NVIC_InitStructure.NVIC_IRQChannelCmd = DISABLE;  // ปิด IRQ นี้เท่านั้น
    NVIC_Init(&NVIC_InitStructure);

    // ทำงานที่ต้องการให้ TIM2 IRQ ไม่มาแทรก ...

    NVIC_InitStructure.NVIC_IRQChannelCmd = ENABLE;   // เปิดกลับ
    NVIC_Init(&NVIC_InitStructure);
}

4. โหมด No-Nesting: ใช้แค่ Sub Priority 2 บิต (0-3)

// ในไฟล์ startup (.S) ตั้ง CSR 0x804 bit1 = 0 และ define ก่อน include:
// #define INTSYSCR_INEST INTSYSCR_INEST_NoEN
#include "ch32v00x_misc.h"

void SetupNoNesting(void)
{
    NVIC_PriorityGroupConfig(NVIC_PriorityGroup_0);  // 0 บิต preempt / 2 บิต sub

    NVIC_InitTypeDef NVIC_InitStructure = {0};
    NVIC_InitStructure.NVIC_IRQChannel = EXTI7_0_IRQn;
    NVIC_InitStructure.NVIC_IRQChannelPreemptionPriority = 0;  // ต้องเป็น 0 เสมอในโหมดนี้
    NVIC_InitStructure.NVIC_IRQChannelSubPriority = 2;          // 0-3 ได้
    NVIC_InitStructure.NVIC_IRQChannelCmd = ENABLE;
    NVIC_Init(&NVIC_InitStructure);
}

ปัญหาที่พบบ่อย

ปัญหาสาเหตุวิธีแก้
IRQ ไม่ทำงานเลย แม้ตั้ง NVIC_IRQChannelCmd = ENABLE แล้ว ไม่ได้เรียก NVIC_PriorityGroupConfig() ก่อน — ตัวแปร NVIC_Priority_Group ภายในยังเป็น 0 ซึ่งอาจไม่ตรงกับ group ที่ต้องใช้ ทำให้ NVIC_Init() ข้ามการตั้ง priority (แต่ยังเปิด IRQ อยู่ — พฤติกรรม priority จะไม่แน่นอน) เรียก NVIC_PriorityGroupConfig(NVIC_PriorityGroup_1) (หรือ _0 ตามโหมด nesting) ก่อน NVIC_Init() ตัวแรกเสมอ
ลำดับความสำคัญของ IRQ ที่ตั้งไว้ก่อนหน้าเพี้ยนไปหลังเรียก NVIC_Init() ตัวใหม่ เรียก NVIC_PriorityGroupConfig() ซ้ำหลายครั้งกลางโปรแกรม เปลี่ยน group ไปมา — ค่า preemption/sub ของ IRQ ที่ตั้งไว้ก่อนหน้าถูกตีความใหม่ตาม group ปัจจุบันทันที ไม่ได้ถูกคำนวณใหม่ให้อัตโนมัติ เรียก NVIC_PriorityGroupConfig() เพียงครั้งเดียวตอนต้นโปรแกรม อย่าเปลี่ยนกลางทาง
ตั้ง NVIC_IRQChannelPreemptionPriority = 1 แล้วไม่มีผล / คอมไพล์ผ่านแต่พฤติกรรมแปลก ใช้ค่านอกช่วงที่ priority group รองรับ เช่น preemption = 1 ขณะที่ compile ด้วย INTSYSCR_INEST_NoEN (ซึ่งอนุญาตแค่ preemption = 0 เท่านั้น เพราะ NVIC_Init เช็คเฉพาะกรณี group ตรงกับโหมด nesting) ตรวจสอบว่า INTSYSCR_INEST ในไฟล์ startup ตรงกับ priority group ที่ใช้ และค่า preemption/sub priority อยู่ในช่วงที่ตารางกำหนด (ดูตาราง NVIC_InitTypeDef ด้านบน)
เรียก NVIC_Init() ด้วย struct ที่ไม่ได้ initialize ทุกฟิลด์ แล้วพฤติกรรม IRQ เพี้ยน ฟิลด์ที่ไม่ได้ตั้งค่า (เช่นลืม NVIC_IRQChannelSubPriority) มีขยะจาก stack เดิม เพราะ struct local ไม่ได้ zero-initialize ประกาศด้วย NVIC_InitTypeDef NVIC_InitStructure = {0}; เสมอ แล้วค่อยตั้งเฉพาะฟิลด์ที่ต้องใช้
Interrupt ซ้อน (nested) ไม่เกิดขึ้นทั้งที่ตั้ง priority ต่างกันแล้ว ไฟล์ startup (.S) ตั้ง CSR 0x804 bit1 = 0 (ปิด nesting) อยู่ ทำให้ไม่ว่าตั้ง preemption priority เท่าไรก็ไม่มีการซ้อนทับเกิดขึ้นจริงในฮาร์ดแวร์ ตรวจสอบการตั้งค่า CSR 0x804 ในไฟล์ startup ให้ตรงกับที่ต้องการ และ define INTSYSCR_INEST ให้สอดคล้องกันก่อน include ch32v00x_misc.h
