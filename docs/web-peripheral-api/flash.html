FLASH — การเขียน/ลบ/อ่านหน่วยความจำแฟลช

ระดับสูง
ไลบรารี: #include <ch32v00x_flash.h> — นี่คือ Standard Peripheral Library (SPL) ระดับล่างที่เข้าถึง FPEC (Flash Program/Erase Controller) โดยตรง ต้องเข้าใจโครงสร้าง register และลำดับการเรียกให้ถูกต้องเอง ไม่มีการตรวจสอบ error ให้อัตโนมัติเหมือน wrapper
ถ้าต้องการใช้งานง่ายกว่านี้ (บันทึก config พร้อม CRC16, auto-erase, ไม่ต้องยุ่งกับ register) ดู SimpleFlash ซึ่งเป็น wrapper ที่สร้างขึ้นบน SPL นี้อีกที
คำเตือน: การเขียน/ลบ Flash เป็นการทำลายข้อมูลเดิมและจำกัดจำนวนรอบ (wear-limited ~10,000-100,000 รอบต่อหน้า) ทุกฟังก์ชันที่แก้ไข Flash (ยกเว้นฟังก์ชันอ่าน) ต้องเรียก FLASH_Unlock() ก่อนเสมอ และต้อง FLASH_Lock() กลับหลังใช้งานเสร็จ — address ที่ใช้ต้องตรงalignmentตามที่แต่ละฟังก์ชันกำหนด (2 หรือ 4 ไบต์) มิฉะนั้นข้อมูลจะเสียหายหรือ hard fault

ผังการทำงานพื้นฐาน (Erase → Program → Lock)

FLASH_Status — ค่าสถานะที่ฟังก์ชันส่วนใหญ่คืนกลับ

ค่าความหมาย
FLASH_BUSYFPEC กำลังทำงานอยู่ (ค่า 1)
FLASH_ERROR_PGข้อผิดพลาดระหว่างการโปรแกรม (program)
FLASH_ERROR_WRPถูก write-protect กันไว้ — เขียน/ลบไม่ได้
FLASH_COMPLETEทำงานสำเร็จ — ค่าที่ต้องเช็คว่าเท่ากับนี้ก่อนทำขั้นถัดไป
FLASH_TIMEOUTรอเกินเวลาที่กำหนด (timeout) — FPEC ไม่ตอบสนอง
FLASH_OP_RANGE_ERROR (0xFD)ช่วงการทำงาน (StartAddr+Length) เกินพื้นที่ที่อนุญาต — เฉพาะ FLASH_ROM_ERASE/FLASH_ROM_WRITE
FLASH_ALIGN_ERROR (0xFE)Address หรือ Length ไม่ align กับขนาด 64 ไบต์ — เฉพาะ FLASH_ROM_ERASE/FLASH_ROM_WRITE
FLASH_ADR_RANGE_ERROR (0xFF)Address เริ่มต้นอยู่นอกช่วง Flash ที่โปรแกรมได้ — เฉพาะ FLASH_ROM_ERASE/FLASH_ROM_WRITE

ค่าคงที่หลัก (#define)

FLASH_Latency — จำนวนรอบสัญญาณนาฬิกาหน่วงของ Flash

ค่าคงที่ความหมาย
FLASH_Latency_0ไม่หน่วง (ใช้กับความถี่ต่ำ)
FLASH_Latency_1หน่วง 1 รอบ
FLASH_Latency_2หน่วง 2 รอบ (ใช้เมื่อ system clock สูง)

FLASH_WRProt_Pages* — เลือกกลุ่มหน้าที่จะ write-protect (1 หน้า = 64 ไบต์)

ค่าคงที่ความหมาย
FLASH_WRProt_Pages0to15 … FLASH_WRProt_Pages240to255บิตละ 16 หน้า รวม 16 บิต ครอบคลุมหน้า 0-255 — ใช้ OR รวมกันได้หลายกลุ่ม
FLASH_WRProt_AllPagesเลือกป้องกันทุกหน้า (0x0000FFFF)

Option Bytes — ตัวเลือกที่เก็บถาวรใน Flash แยกจากพื้นที่โปรแกรม

กลุ่มค่าคงที่ความหมาย
Independent WatchdogOB_IWDG_SWควบคุม IWDG ด้วยซอฟต์แวร์ (เปิด/ปิดเองในโค้ด)
OB_IWDG_HWIWDG เปิดทำงานอัตโนมัติโดยฮาร์ดแวร์ตั้งแต่ startup
STOP mode resetOB_STOP_NoRSTไม่รีเซ็ตเมื่อเข้าโหมด STOP
OB_STOP_RSTรีเซ็ตเมื่อเข้าโหมด STOP
STANDBY resetOB_STDBY_NoRSTไม่รีเซ็ตเมื่อเข้าโหมด STANDBY
OB_STDBY_RSTรีเซ็ตเมื่อเข้าโหมด STANDBY
ขา RESET (PD7)OB_RST_NoENปิดใช้งานขา RESET — PD7 ใช้เป็น GPIO ปกติได้
OB_RST_EN_DT12msเปิดขา RESET หน่วงเวลา 12ms
OB_RST_EN_DT1msเปิดขา RESET หน่วงเวลา 1ms
OB_RST_EN_DT128usเปิดขา RESET หน่วงเวลา 128µs
โหมดเริ่มต้นหลังจ่ายไฟOB_PowerON_Start_Mode_BOOTเริ่มจาก Bootloader หลัง power-on
OB_PowerON_Start_Mode_USERเริ่มจากโปรแกรมผู้ใช้หลัง power-on

Flags / Interrupts / Start Mode

ค่าคงที่ความหมาย
FLASH_IT_ERRORเปิด/ปิด interrupt เมื่อเกิดข้อผิดพลาด FPEC
FLASH_IT_EOPเปิด/ปิด interrupt เมื่อการทำงานเสร็จสิ้น (End Of Operation)
FLASH_FLAG_BSYFlag แสดงว่า FPEC กำลังทำงาน (busy)
FLASH_FLAG_EOPFlag แสดงว่าการทำงานเสร็จสิ้นแล้ว
FLASH_FLAG_WRPRTERRFlag แสดงว่าเขียน/ลบพื้นที่ที่ถูก write-protect
FLASH_FLAG_OPTERRFlag แสดง option byte error
Start_Mode_USER / Start_Mode_BOOTใช้กับ SystemReset_StartMode() เลือกโหมดเริ่มทำงานหลัง reset ครั้งถัดไป

ตารางอ้างอิงฟังก์ชัน

1. Unlock / Lock

ฟังก์ชันพารามิเตอร์คืนค่าคำอธิบาย
FLASH_Unlock(void)—voidปลดล็อก FPEC มาตรฐาน (เขียน key sequence ลง FLASH->KEYR) ต้องเรียกก่อน erase/program ทุกครั้ง
FLASH_Lock(void)—voidล็อก FPEC กลับ — ตั้งบิต LOCK ใน FLASH->CTLR
FLASH_Unlock_Fast(void)—voidปลดล็อกทั้ง FPEC มาตรฐานและโหมด Fast Program/Erase (เขียน key ลง KEYR และ MODEKEYR)
FLASH_Lock_Fast(void)—voidล็อกเฉพาะโหมด Fast Program/Erase (ตั้งบิต FLOCK)

2. Erase (มาตรฐาน)

ฟังก์ชันพารามิเตอร์คืนค่าคำอธิบาย
FLASH_ErasePage(Page_Address)Page_Address: address เริ่มต้นของหน้า (1 หน้า = 1KB)FLASH_Statusลบ 1 หน้า (1KB) ให้เป็น 0xFF ทั้งหมด
FLASH_EraseAllPages(void)—FLASH_Statusลบทั้งชิป (mass erase) — ลบโค้ดโปรแกรมทั้งหมดด้วย
FLASH_EraseOptionBytes(void)—FLASH_Statusลบ option bytes ทั้งหมด (คืนค่า default) — ใช้ OBKEYR ปลดล็อกแยกต่างหาก

3. Program (มาตรฐาน)

ฟังก์ชันพารามิเตอร์คืนค่าคำอธิบาย
FLASH_ProgramWord(Address, Data)Address: address ปลายทาง (align 4 ไบต์)
Data: ค่า 32-bit		FLASH_Statusเขียน 1 word (4 ไบต์) โดยเขียนเป็น 2 half-word ภายใน — พื้นที่ต้องถูก erase (=0xFF) มาก่อน
FLASH_ProgramHalfWord(Address, Data)Address: address ปลายทาง (align 2 ไบต์)
Data: ค่า 16-bit		FLASH_Statusเขียน 1 half-word (2 ไบต์) — ฟังก์ชันโปรแกรมพื้นฐานที่สุด

4. Option Bytes

ฟังก์ชันพารามิเตอร์คืนค่าคำอธิบาย
FLASH_ProgramOptionByteData(Address, Data)Address: address ของ option byte
Data: ค่า 8-bit		FLASH_Statusเขียนค่าลง option byte data ตำแหน่งที่ระบุ
FLASH_UserOptionByteConfig(OB_IWDG, OB_STDBY, OB_RST, OB_PowerON_Start_Mode)ค่าคงที่ OB_* ทั้ง 4 กลุ่มด้านบนFLASH_Statusตั้งค่า user option byte ทั้งหมดในครั้งเดียว
FLASH_GetUserOptionByte(void)—uint32_tอ่านค่า user option byte ปัจจุบัน (IWDG_SW=bit0, RST_STOP=bit1, RST_STDBY=bit2)

5. Write Protection / Readout Protection

ฟังก์ชันพารามิเตอร์คืนค่าคำอธิบาย
FLASH_EnableWriteProtection(FLASH_Pages)FLASH_Pages: OR ของ FLASH_WRProt_Pages*FLASH_Statusตั้งค่า write-protect ให้กลุ่มหน้าที่ระบุ — ต้อง power-cycle เพื่อให้มีผล
FLASH_ReadOutProtection(NewState)NewState: ENABLE/DISABLEFLASH_Statusเปิด/ปิดการป้องกันอ่านทั้งชิป (readout protection) — เปิดแล้วจะลบทั้งชิปตอนปิดกลับ
FLASH_GetWriteProtectionOptionByte(void)—uint32_tอ่านค่า write-protection option byte register ปัจจุบัน
FLASH_GetReadOutProtectionStatus(void)—FlagStatusตรวจสอบว่าเปิด readout protection อยู่หรือไม่

6. Interrupt / Flag / Status

ฟังก์ชันพารามิเตอร์คืนค่าคำอธิบาย
FLASH_ITConfig(FLASH_IT, NewState)FLASH_IT: FLASH_IT_ERROR/FLASH_IT_EOP
NewState: ENABLE/DISABLE		voidเปิด/ปิด interrupt ของ FPEC
FLASH_GetFlagStatus(FLASH_FLAG)FLASH_FLAG: ค่า FLASH_FLAG_*FlagStatusตรวจสอบ flag ที่ระบุว่า SET หรือ RESET
FLASH_ClearFlag(FLASH_FLAG)FLASH_FLAG: ค่า FLASH_FLAG_*voidเคลียร์ flag ที่ค้างอยู่ (เขียน 1 เพื่อล้าง)
FLASH_GetStatus(void)—FLASH_Statusอ่านสถานะ FPEC ปัจจุบัน (BUSY/ERROR_WRP/COMPLETE) จากการอ่าน register โดยตรง ไม่รอ
FLASH_WaitForLastOperation(Timeout)Timeout: จำนวนรอบสูงสุดที่จะรอFLASH_Statusวนรออ่านสถานะจนกว่าจะไม่ busy หรือครบ timeout — ฟังก์ชัน erase/program ภายในเรียกใช้ตัวนี้ก่อนเริ่มงานเสมอ

7. Latency (Clock)

ฟังก์ชันพารามิเตอร์คืนค่าคำอธิบาย
FLASH_SetLatency(FLASH_Latency)FLASH_Latency: FLASH_Latency_0/1/2voidตั้งค่ารอบหน่วงของการอ่าน Flash ให้เหมาะกับความถี่ system clock ที่ใช้งาน

8. Fast Program/Erase (เฉพาะตระกูล CH32V003)

กลุ่มฟังก์ชัน Fast Program/Erase (ลงท้าย _Fast) เป็นชุดคำสั่งเฉพาะของ CH32V00x ที่เข้าถึง buffer ภายใน FPEC โดยตรง เพื่อเขียนทีละหน้า (64 ไบต์) เร็วกว่าการเขียนทีละ word — ไม่คืนค่า FLASH_Status ตรวจสอบ error ต้องเรียกตามลำดับที่กำหนดอย่างเคร่งครัด
ฟังก์ชันพารามิเตอร์คืนค่าคำอธิบาย
FLASH_BufReset(void)—voidล้างบัฟเฟอร์ page-program ภายใน FPEC ก่อนโหลดข้อมูลชุดใหม่
FLASH_BufLoad(Address, Data0)Address: address ปลายทาง (ต้องอยู่ในช่วง flash ที่ถูกต้อง)
Data0: ค่า 32-bit		voidโหลดข้อมูล 4 ไบต์เข้าบัฟเฟอร์ภายใน — เรียกซ้ำสะสมทีละ word จนครบ 1 หน้า (16 ครั้ง = 64 ไบต์) ก่อนเรียก FLASH_ProgramPage_Fast
FLASH_ErasePage_Fast(Page_Address)Page_Address: address เริ่มหน้า (1 หน้า = 64 ไบต์)voidลบ 1 หน้าแบบเร็ว (64 ไบต์/หน้า ต่างจาก FLASH_ErasePage ที่ลบทีละ 1KB)
FLASH_ProgramPage_Fast(Page_Address)Page_Address: address เริ่มหน้าที่จะเขียนจริงvoidเขียนข้อมูลที่โหลดไว้ด้วย FLASH_BufLoad ลงหน้า Flash จริงในครั้งเดียว

9. ROM Erase/Write & System Reset

ฟังก์ชันพารามิเตอร์คืนค่าคำอธิบาย
FLASH_ROM_ERASE(StartAddr, Length)StartAddr: address เริ่มต้น (ต้องหาร 64 ลงตัว)
Length: ความยาวไบต์ (ต้องหาร 64 ลงตัว)		FLASH_Statusลบช่วง Flash ตามความยาวที่ระบุ โดยเลือกใช้ erase แบบ 1KB หรือ 64B อัตโนมัติให้เหมาะกับ alignment — unlock/lock (รวม Fast lock) ให้ภายในฟังก์ชันแล้ว
FLASH_ROM_WRITE(StartAddr, pbuf, Length)StartAddr: address เริ่มต้น (หาร 64 ลงตัว)
pbuf: pointer ข้อมูล 32-bit
Length: ความยาวไบต์ (หาร 64 ลงตัว)		FLASH_Statusเขียนข้อมูลทีละหน้า (64 ไบต์) โดยใช้ buffer-load ภายใน — พื้นที่ต้องถูก erase มาก่อน (ฟังก์ชันนี้ไม่ erase ให้)
SystemReset_StartMode(Mode)Mode: Start_Mode_USER/Start_Mode_BOOTvoidตั้งค่าโหมดเริ่มทำงานสำหรับการ reset ครั้งถัดไป (unlock → set → lock ให้ภายในฟังก์ชันแล้ว)

กลุ่มฟังก์ชันที่ใช้ร่วมกัน

1. Unlock → ErasePage → ProgramWord → Lock (มาตรฐาน)

#include <ch32v00x.h>

#define TARGET_PAGE   0x08003C00   // หน้าสุดท้ายก่อน option bytes (ตัวอย่าง)

FLASH_Status status;

FLASH_Unlock();

status = FLASH_ErasePage(TARGET_PAGE);
if (status != FLASH_COMPLETE) {
    // จัดการ error: BUSY / ERROR_WRP / TIMEOUT
    FLASH_Lock();
    return;
}

status = FLASH_ProgramWord(TARGET_PAGE, 0x12345678);
if (status != FLASH_COMPLETE) {
    FLASH_Lock();
    return;
}

FLASH_Lock();   // ล็อกกลับทุกครั้งหลังใช้งานเสร็จ

ลำดับมาตรฐาน: Unlock → เช็ค busy/erase/program ทีละขั้น → Lock เสมอ ไม่ว่าจะสำเร็จหรือ error

2. เขียนหลาย word ต่อเนื่องในหน้าเดียวกัน

FLASH_Unlock();
FLASH_ErasePage(TARGET_PAGE);

for (uint32_t i = 0; i < 16; i++) {
    FLASH_Status s = FLASH_ProgramWord(TARGET_PAGE + i * 4, data_array[i]);
    if (s != FLASH_COMPLETE) break;   // หยุดทันทีถ้าเขียนล้มเหลว
}

FLASH_Lock();

เขียนทีละ word ต่อเนื่อง 16 ตัว (รวม 64 ไบต์ = 1 หน้า) — ต้อง erase หน้าเดียวครั้งเดียวก่อนเริ่ม ไม่ใช่ erase ซ้ำระหว่าง loop

3. Fast Program/Erase — เขียนทีละหน้าแบบเร็ว

FLASH_Unlock_Fast();

FLASH_ErasePage_Fast(TARGET_PAGE);

FLASH_BufReset();
for (uint32_t i = 0; i < 16; i++) {
    FLASH_BufLoad(TARGET_PAGE + i * 4, data_array[i]);
}
FLASH_ProgramPage_Fast(TARGET_PAGE);

FLASH_Lock_Fast();
FLASH_Lock();

โหมด Fast ต้องปลดล็อก 2 ชั้น (Unlock_Fast ปลดทั้ง KEYR และ MODEKEYR) และล็อกกลับทั้ง Lock_Fast และ Lock มาตรฐาน

4. ตรวจสอบ write-protection ก่อนเขียนจริง

FLASH_Unlock();

if (FLASH_GetFlagStatus(FLASH_FLAG_WRPRTERR) == SET) {
    FLASH_ClearFlag(FLASH_FLAG_WRPRTERR);
}

FLASH_Status status = FLASH_WaitForLastOperation(0x00002000);
if (status == FLASH_COMPLETE) {
    FLASH_ProgramHalfWord(TARGET_PAGE, 0xABCD);
}

FLASH_Lock();

เคลียร์ flag ค้างก่อน แล้วรอด้วย FLASH_WaitForLastOperation เพื่อให้แน่ใจว่า FPEC ว่างก่อนเขียนจริง

ปัญหาที่พบบ่อย

ปัญหาสาเหตุวิธีแก้
เขียนค่าแล้วอ่านกลับมาไม่ตรง (bit ไม่เปลี่ยนจาก 0 เป็น 1) Flash เขียนได้ทิศทางเดียว: 1→0 เท่านั้น การลบ (erase) คือการตั้งทุกบิตกลับเป็น 1 — จะ program 0→1 โดยไม่ erase ก่อนไม่ได้ เรียก FLASH_ErasePage() ให้พื้นที่กลับเป็น 0xFF ทั้งหมดก่อน แล้วค่อย FLASH_ProgramWord()/ProgramHalfWord()
เขียน/ลบไม่สำเร็จ หรือได้ผลลัพธ์ไม่แน่นอน (undefined) เรียก erase/program ซ้อนกันขณะที่ FPEC ยัง busy จากคำสั่งก่อนหน้า — ฟังก์ชัน erase/program ภายในมีการรอ (FLASH_WaitForLastOperation) อยู่แล้ว แต่ถ้าไปเขียน register ตรงๆ หรือ interrupt แทรกกลางคัน อาจข้ามการเช็คนี้ได้ เช็ค FLASH_GetBank1Status()/FLASH_GetStatus() ว่าไม่ใช่ FLASH_BUSY ก่อนเรียกคำสั่งถัดไปเสมอ และห้าม disable การรอ timeout
โปรแกรมอื่นเขียนทับ Flash โดยไม่ตั้งใจหลัง flash ทำงานเสร็จ ลืมเรียก FLASH_Lock() หลังใช้งานเสร็จ — FPEC จะค้างอยู่ในสถานะปลดล็อก ทำให้โค้ดส่วนอื่น (หรือบั๊ก pointer) เขียนทับ Flash โดยไม่ได้ตั้งใจ เรียก FLASH_Lock() ทุกครั้งหลัง erase/program เสร็จ ไม่ว่าผลลัพธ์จะสำเร็จหรือ error ก็ตาม (ใส่ใน path error ด้วย)
เขียนข้อมูลผิดตำแหน่งหรือ hard fault Address ไม่ตรง alignment ที่ฟังก์ชันต้องการ — FLASH_ProgramWord ต้อง align 4 ไบต์, FLASH_ProgramHalfWord ต้อง align 2 ไบต์, ส่วน FLASH_ROM_ERASE/FLASH_ROM_WRITE ต้องหาร 64 ลงตัวทั้ง address และ length ตรวจสอบ address % 4 == 0 (word) หรือ % 2 == 0 (half-word) ก่อนเรียกเสมอ — ฟังก์ชัน ROM_* จะคืน FLASH_ALIGN_ERROR ให้เองถ้าไม่ตรง
เผลอเรียก FLASH_EraseAllPages() แล้วโปรแกรมหาย ฟังก์ชันนี้ mass-erase ทั้งชิปรวมถึง sector ที่เก็บโค้ดโปรแกรมด้วย ไม่ใช่แค่ข้อมูล ใช้ FLASH_ErasePage() เฉพาะหน้าที่ต้องการแทน สงวน EraseAllPages ไว้สำหรับ factory-reset/bootloader เท่านั้น และกันพื้นที่โปรแกรมด้วย linker script
