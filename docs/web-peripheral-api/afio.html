AFIO — Alternate Function I/O

ระดับ Peripheral (SPL ดิบ)
ไฟล์: #include "ch32v00x_gpio.h" — AFIO ไม่มีไฟล์ header แยก ฟังก์ชัน AFIO อยู่ใน ch32v00x_gpio.h ร่วมกับ GPIO AFIO ควบคุม 2 เรื่องหลัก: Pin Remap (เปลี่ยนขาของ peripheral) และ EXTI Line Config (เลือกว่า EXTI line ผูกกับพอร์ตไหน)
ถ้าต้องการ API ที่ใช้ง่ายกว่านี้ ดูที่ SimpleGPIO (SimpleHAL wrapper)

AFIO_TypeDef — โครงสร้าง register

สมาชิกชนิดคำอธิบาย
PCFR1uint32_tPin Configuration Register 1 — ควบคุม pin remap ของ SPI1, I2C1, USART1, TIM1, TIM2 และ JTAG/SWD config
EXTICRuint32_tExternal Interrupt Configuration Register — เลือกว่า EXTI Line 0-7 ผูกกับพอร์ต PA, PC หรือ PD

GPIO_Remap_define — ตาราง Pin Remap สำหรับ GPIO_PinRemapConfig()

ค่าคงที่เหล่านี้ใช้เป็นพารามิเตอร์ GPIO_Remap ในฟังก์ชัน GPIO_PinRemapConfig() — แต่ละค่าเป็น bitmask 32 บิต ที่ encode ข้อมูล: bit ที่จะแก้ไขใน AFIO->PCFR1, จำนวนบิต, และตำแหน่ง

SDI (Serial Debug Interface)

Macroค่าคำอธิบาย
GPIO_Remap_SDI_Disable0x00300400ปิด SDI — ขา SDI (PD1) ใช้เป็น GPIO ได้ (⚠️ ปิด serial debug)
หมายเหตุ Bit Structure: ค่า GPIO_Remap เป็น bitmask 32 บิต ที่ encode:
• bit [15:0]: bitmask ของบิตที่จะแก้ไขใน AFIO->PCFR1
• bit [20:16]: ตำแหน่งบิต (shift amount)
• bit [21]: flag สำหรับ 2-bit remap (บาง peripheral)
• bit [27]: flag สำหรับ SDI disable
• bit [31]: flag สำหรับ USART1 partial remap
ไม่จำเป็นต้องเข้าใจ bit structure นี้เพื่อใช้งาน — แค่ใช้ macro ที่กำหนดให้

ตารางอ้างอิงฟังก์ชัน

ฟังก์ชันพารามิเตอร์คืนค่าคำอธิบายหมายเหตุ
void GPIO_PinRemapConfig(uint32_t GPIO_Remap, FunctionalState NewState) GPIO_Remap: bitmask ของ remap ที่ต้องการ (เช่น AFIO_PCFR1_SPI1_REMAP)
NewState: ENABLE เปิด remap / DISABLE ปิด remap		 void เปิดหรือปิด pin remap ของ peripheral ตาม bitmask — ใช้ OR รวมหลาย remap ได้ ต้องเปิด clock AFIO ก่อน (RCC_APB2Periph_AFIO)
void GPIO_EXTILineConfig(uint8_t GPIO_PortSource, uint8_t GPIO_PinSource) GPIO_PortSource: พอร์ต GPIO (GPIO_PortSourceGPIOA/C/D)
GPIO_PinSource: เลขขา (GPIO_PinSource0 .. GPIO_PinSource7)		 void เลือกว่า EXTI Line ตาม PinSource จะผูกกับขาของพอร์ตไหน ต้องเรียกก่อน EXTI_Init() เสมอ — เขียนลง AFIO->EXTICR

ตัวอย่างการใช้งาน

1. Remap SPI1 ไปใช้ขา PC

#include "ch32v00x_gpio.h"

// เปิด clock AFIO และ GPIOC
RCC_APB2PeriphClockCmd(RCC_APB2Periph_AFIO | RCC_APB2Periph_GPIOC, ENABLE);

// Remap SPI1 ไปใช้ขา PC0/PC5/PC6/PC7
GPIO_PinRemapConfig(GPIO_Remap_SPI1, ENABLE);

2. ปิด JTAG 保留 SWD (释放 PA15, PB4 เป็น GPIO)

#include "ch32v00x_gpio.h"

RCC_APB2PeriphClockCmd(RCC_APB2Periph_AFIO, ENABLE);

// ปิด JTAG 保留 SWD — ขา PA13/PA14 ยังใช้ debug ได้
// 释放 PA15, PB3, PB4 ใช้เป็น GPIO
GPIO_PinRemapConfig(AFIO_PCFR1_SWJ_CFG_JTAGDISABLE, ENABLE);

3. ผูก EXTI Line2 กับขา PD2

#include "ch32v00x_gpio.h"
#include "ch32v00x_exti.h"

RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOD | RCC_APB2Periph_AFIO, ENABLE);

// ตั้งขา PD2 เป็น input
GPIO_InitTypeDef GPIO_InitStructure = {0};
GPIO_InitStructure.GPIO_Pin = GPIO_Pin_2;
GPIO_InitStructure.GPIO_Mode = GPIO_Mode_IPU;
GPIO_Init(GPIOD, &GPIO_InitStructure);

// ผูก EXTI Line2 กับ PD2
GPIO_EXTILineConfig(GPIO_PortSourceGPIOD, GPIO_PinSource2);

4. ใช้ TIM1 Partial Remap

#include "ch32v00x_gpio.h"

RCC_APB2PeriphClockCmd(RCC_APB2Periph_AFIO | RCC_APB2Periph_GPIOA, ENABLE);

// TIM1 Partial Remap 1 — BKIN ย้ายไป PA6
GPIO_PinRemapConfig(GPIO_PartialRemap1_TIM1, ENABLE);

ปัญหาที่พบบ่อย

ปัญหาสาเหตุวิธีแก้
เรียก GPIO_PinRemapConfig() แล้วไม่ผล ลืมเปิด clock AFIO (RCC_APB2Periph_AFIO) — register PCFR1 จะไม่รับค่าเขียน เพิ่ม RCC_APB2PeriphClockCmd(RCC_APB2Periph_AFIO, ENABLE) ก่อนเรียก remap
ตั้ง EXTI แล้ว interrupt ไม่เข้า ทั้งที่ขายังมีสัญญาณ ลืมเรียก GPIO_EXTILineConfig() — EXTI line ยังผูกกับพอร์ต default (GPIOA) ไม่ใช่พอร์ตที่ใช้จริง เรียก GPIO_EXTILineConfig() ก่อน EXTI_Init() เสมอ
ปิด JTAG แล้ว debug ไม่ได้ ใช้ AFIO_PCFR1_SWJ_CFG_DISABLE ปิดทั้ง JTAG และ SWD ใช้ AFIO_PCFR1_SWJ_CFG_JTAGDISABLE แทน — ปิดเฉพาะ JTAG 保留 SWD
