RCC — Reset and Clock Control

ระดับกลาง
ไลบรารี: #include "ch32v00x_rcc.h" — นี่คือ Standard Peripheral Library (SPL) ระดับล่างที่เข้าถึงเรจิสเตอร์ฮาร์ดแวร์โดยตรง ไม่ใช่ SimpleHAL
RCC ไม่มี wrapper ใน SimpleHAL โดยตรง — SystemCoreClockUpdate() และการตั้งค่านาฬิกาเริ่มต้นใน SimpleHAL เรียกใช้ฟังก์ชัน RCC เหล่านี้ "ภายใน" อยู่แล้ว ผู้ใช้ทั่วไปที่ใช้ SimpleHAL จึงไม่จำเป็นต้องเรียก RCC เองเลย — หน้านี้เหมาะกับผู้ที่ต้องการปรับความถี่นาฬิกาเอง, เปิด/ปิด peripheral clock แบบละเอียด, หรือเขียนโค้ดแบบ bare-metal

ผังการทำงาน RCC

flowchart LR
    HSI["HSI 24MHz (ภายใน)"] --> SW["RCC_SYSCLKConfig()"]
    HSE["HSE (ภายนอก, ต้อง RCC_HSEConfig ON)"] --> SW
    PLL["PLL (RCC_PLLConfig + RCC_PLLCmd)"] --> SW
    SW --> SYSCLK["SYSCLK"]
    SYSCLK --> HCLK["RCC_HCLKConfig() → HCLK (AHB)"]
    HCLK --> PCLK["PCLK1/PCLK2 (APB)"]
    PCLK --> PERIPH["RCC_APB1/APB2/AHBPeriphClockCmd() เปิด clock ให้ peripheral"]
    PERIPH --> USE["ใช้งาน GPIO/TIM/USART/ฯลฯ ได้"]

แนวคิดสำคัญ: ต้องเปิด Peripheral Clock ก่อนใช้งานเสมอ

กฎเหล็กของ CH32V003: ทุก peripheral (GPIO, TIM, USART, SPI, I2C, ADC, ...) มี "clock gate" ที่ปิดอยู่โดย default หลัง reset — ถ้าไม่เรียก RCC_APB2PeriphClockCmd() / RCC_APB1PeriphClockCmd() / RCC_AHBPeriphClockCmd() เปิด clock ก่อน การเขียนอ่านเรจิสเตอร์ของ peripheral นั้นจะไม่มีผลใดๆ (อ่านได้ 0 เสมอ หรือค้าง) เพราะวงจรไม่มีสัญญาณนาฬิกาขับ

ค่าคงที่ / Enum ที่ใช้บ่อย

1. แหล่งนาฬิการะบบ (System Clock Source)

ค่าคงที่คำอธิบาย
RCC_SYSCLKSource_HSIใช้ HSI (ออสซิลเลเตอร์ภายใน 24MHz) เป็นนาฬิการะบบ — ค่า default หลัง reset
RCC_SYSCLKSource_HSEใช้ HSE (คริสตัลภายนอก) เป็นนาฬิการะบบ
RCC_SYSCLKSource_PLLCLKใช้ผลลัพธ์จาก PLL เป็นนาฬิการะบบ

2. แหล่งนาฬิกาเข้า PLL

ค่าคงที่คำอธิบาย
RCC_PLLSource_HSI_MUL2PLL รับสัญญาณจาก HSI คูณ 2 (24MHz → 48MHz)
RCC_PLLSource_HSE_MUL2PLL รับสัญญาณจาก HSE คูณ 2

3. HSE Mode

ค่าคงที่คำอธิบาย
RCC_HSE_OFFปิด HSE
RCC_HSE_ONเปิด HSE (ใช้คริสตัล/เรโซเนเตอร์)
RCC_HSE_Bypassข้าม oscillator ใช้สัญญาณนาฬิกาจากภายนอกโดยตรง (เช่นจากชิปอื่น)

4. ตัวหารนาฬิกา AHB (RCC_HCLKConfig)

ค่าคงที่ตัวหาร
RCC_SYSCLK_Div1÷1 (HCLK = SYSCLK)
RCC_SYSCLK_Div2 ... RCC_SYSCLK_Div8÷2 ถึง ÷8
RCC_SYSCLK_Div16 ... RCC_SYSCLK_Div256÷16, ÷32, ÷64, ÷128, ÷256

5. ตัวหารนาฬิกา ADC (RCC_ADCCLKConfig, หารจาก PCLK2)

ค่าคงที่ตัวหาร
RCC_PCLK2_Div2 / Div4 / Div6 / Div8÷2, ÷4, ÷6, ÷8
RCC_PCLK2_Div12 / Div16 / Div24 / Div32÷12, ÷16, ÷24, ÷32
RCC_PCLK2_Div48 / Div64 / Div96 / Div128÷48, ÷64, ÷96, ÷128

7. RCC_ClocksTypeDef (โครงสร้างผลลัพธ์ RCC_GetClocksFreq)

ฟิลด์ความหมาย
SYSCLK_Frequencyความถี่นาฬิการะบบ (Hz)
HCLK_Frequencyความถี่ AHB (Hz)
PCLK1_Frequencyความถี่ APB1 (Hz) — บนชิปนี้เท่ากับ HCLK เสมอ (ไม่มีตัวหารแยก)
PCLK2_Frequencyความถี่ APB2 (Hz) — เท่ากับ HCLK เสมอเช่นกัน
ADCCLK_Frequencyความถี่นาฬิกา ADC (Hz)

ตารางอ้างอิงฟังก์ชัน

ฟังก์ชันพารามิเตอร์คืนค่าคำอธิบายหมายเหตุ
RCC_DeInit(void) ไม่มี void รีเซ็ตการตั้งค่านาฬิกาทั้งหมดกลับสู่ค่า default (HSI, ไม่มี PLL, ไม่มี prescaler) ใช้ตอนเริ่มโปรแกรมใหม่หรือ debug ปัญหานาฬิกา
RCC_HSEConfig(RCC_HSE) RCC_HSE: RCC_HSE_OFF / _ON / _Bypass void เปิด/ปิด/bypass ออสซิลเลเตอร์ภายนอก HSE ห้ามปิด HSE ขณะกำลังใช้เป็นนาฬิการะบบ (ตรงหรือผ่าน PLL)
RCC_WaitForHSEStartUp(void) ไม่มี ErrorStatus (READY/NoREADY) รอ HSE จนเสถียร หรือจน timeout (HSE_STARTUP_TIMEOUT) เรียกหลัง RCC_HSEConfig(RCC_HSE_ON) ก่อนใช้ HSE จริง
RCC_AdjustHSICalibrationValue(HSICalibrationValue) HSICalibrationValue: 0–0x1F void ปรับค่า trim ของ HSI ภายใน ไม่จำเป็นสำหรับผู้ใช้ทั่วไป — ใช้เมื่อต้องการความแม่นยำนาฬิกาสูงเป็นพิเศษ
RCC_HSICmd(NewState) NewState: ENABLE/DISABLE void เปิด/ปิด HSI ห้ามปิด HSI ถ้ากำลังใช้เป็นนาฬิการะบบ/PLL source อยู่ ไม่งั้น MCU ค้าง
RCC_PLLConfig(RCC_PLLSource) RCC_PLLSource: RCC_PLLSource_HSI_MUL2 / _HSE_MUL2 void ตั้งค่าแหล่งสัญญาณเข้า PLL ต้องตั้งก่อนเปิด PLL ด้วย RCC_PLLCmd
RCC_PLLCmd(NewState) NewState: ENABLE/DISABLE void เปิด/ปิด PLL ห้ามปิด PLL ถ้ากำลังใช้เป็นนาฬิการะบบอยู่
RCC_SYSCLKConfig(RCC_SYSCLKSource) RCC_SYSCLKSource: _HSI/_HSE/_PLLCLK void สลับแหล่งนาฬิการะบบ (SYSCLK) ต้องเปิดและรอแหล่งสัญญาณนั้นเสถียรก่อนสลับมาใช้ ไม่งั้น MCU ค้าง
RCC_GetSYSCLKSource(void) ไม่มี uint8_t (0x00=HSI, 0x04=HSE, 0x08=PLL) อ่านแหล่งนาฬิการะบบปัจจุบัน ใช้ตรวจสอบว่าการสลับนาฬิกาสำเร็จจริงหรือไม่
RCC_HCLKConfig(RCC_SYSCLK) RCC_SYSCLK: RCC_SYSCLK_Div1...Div256 void ตั้งตัวหารนาฬิกา AHB (HCLK) จาก SYSCLK HCLK ขับ core, memory, DMA และเป็นฐานของ APB1/APB2
RCC_ITConfig(RCC_IT, NewState) RCC_IT: RCC_IT_LSIRDY/_HSIRDY/_HSERDY/_PLLRDY
NewState: ENABLE/DISABLE		 void เปิด/ปิด interrupt เมื่อ clock source พร้อมใช้งาน ใช้ร่วมกับ RCC IRQ handler ถ้าต้องการ async clock switching
RCC_ADCCLKConfig(RCC_PCLK2) RCC_PCLK2: RCC_PCLK2_Div2...Div128 void ตั้งตัวหารนาฬิกา ADC จาก PCLK2 ADC ต้องการนาฬิกาไม่เกิน 14MHz โดยประมาณ — เลือกตัวหารให้เหมาะกับ SYSCLK ที่ใช้
RCC_LSICmd(NewState) NewState: ENABLE/DISABLE void เปิด/ปิดออสซิลเลเตอร์ความเร็วต่ำภายใน LSI ห้ามปิด LSI ถ้า IWDG (Independent Watchdog) กำลังทำงานอยู่
RCC_GetClocksFreq(RCC_Clocks) RCC_Clocks: RCC_ClocksTypeDef* void คำนวณและเขียนความถี่นาฬิกาปัจจุบันทุกจุด (SYSCLK/HCLK/PCLK1/PCLK2/ADCCLK) ลงในโครงสร้างที่ส่งมา ผลลัพธ์อาจไม่แม่นยำถ้า HSE เป็นค่าที่ไม่ใช่จำนวนเต็ม MHz
RCC_AHBPeriphClockCmd(RCC_AHBPeriph, NewState) RCC_AHBPeriph: bitmask RCC_AHBPeriph_*
NewState: ENABLE/DISABLE		 void เปิด/ปิด clock ให้ peripheral บนบัส AHB (DMA1, SRAM) ต้องเปิดก่อนใช้ DMA1 เสมอ
RCC_APB2PeriphClockCmd(RCC_APB2Periph, NewState) RCC_APB2Periph: bitmask RCC_APB2Periph_*
NewState: ENABLE/DISABLE		 void เปิด/ปิด clock ให้ peripheral บนบัส APB2 (GPIO, AFIO, ADC1, TIM1, SPI1, USART1) ฟังก์ชันที่ถูกเรียกบ่อยที่สุดใน RCC — ต้องเรียกก่อนตั้งค่า GPIO ทุกครั้ง
RCC_APB1PeriphClockCmd(RCC_APB1Periph, NewState) RCC_APB1Periph: bitmask RCC_APB1Periph_*
NewState: ENABLE/DISABLE		 void เปิด/ปิด clock ให้ peripheral บนบัส APB1 (TIM2, WWDG, I2C1, PWR) ต้องเรียกก่อนใช้ TIM2/I2C1 เสมอ
RCC_APB2PeriphResetCmd(RCC_APB2Periph, NewState) เหมือนด้านบน (APB2) void บังคับหรือปล่อย reset ของ peripheral บน APB2 (คนละอย่างกับเปิด/ปิด clock) ใช้ reset peripheral ให้กลับสู่ค่า default โดยไม่ต้อง reset ทั้งชิป — ต้องเรียก ENABLE แล้วค่อย DISABLE เพื่อ "สะบัด" reset
RCC_APB1PeriphResetCmd(RCC_APB1Periph, NewState) เหมือนด้านบน (APB1) void บังคับหรือปล่อย reset ของ peripheral บน APB1 เหมือนกับ APB2 แต่สำหรับ TIM2/WWDG/I2C1/PWR
RCC_ClockSecuritySystemCmd(NewState) NewState: ENABLE/DISABLE void เปิด/ปิดระบบตรวจจับ HSE ล้มเหลว (Clock Security System) — ถ้า HSE ดับกะทันหันจะสลับไป HSI อัตโนมัติและเกิด NMI ใช้ในงานที่ต้องการความน่าเชื่อถือสูง เมื่อใช้ HSE เป็นนาฬิการะบบ
RCC_MCOConfig(RCC_MCO) RCC_MCO: RCC_MCO_NoClock/_SYSCLK/_HSI/_HSE/_PLLCLK void ส่งสัญญาณนาฬิกาที่เลือกออกทางขา MCO เพื่อตรวจวัดด้วยออสซิลโลสโคป มีประโยชน์มากสำหรับ debug ว่านาฬิกาจริงตรงกับที่ตั้งค่าไว้หรือไม่
RCC_GetFlagStatus(RCC_FLAG) RCC_FLAG: RCC_FLAG_* FlagStatus (SET/RESET) ตรวจสอบสถานะแฟล็ก RCC เช่น oscillator ready หรือสาเหตุการรีเซ็ตล่าสุด ใช้ตรวจว่า MCU รีเซ็ตมาจากอะไร (power-on, watchdog, pin, ...)
RCC_ClearFlag(void) ไม่มี void ล้างแฟล็กสาเหตุการรีเซ็ตทั้งหมด (PINRST, PORRST, SFTRST, IWDGRST, WWDGRST, LPWRRST) เรียกหลังอ่านสาเหตุ reset แล้ว เพื่อให้รอบถัดไปตรวจสอบใหม่ได้ถูกต้อง
RCC_GetITStatus(RCC_IT) RCC_IT: RCC_IT_* (รวม RCC_IT_CSS) ITStatus (SET/RESET) ตรวจสอบว่า interrupt ของ RCC เกิดขึ้นหรือยัง ใช้ใน RCC IRQ handler
RCC_ClearITPendingBit(RCC_IT) RCC_IT: RCC_IT_* void ล้างบิต interrupt ที่ค้างอยู่ของ RCC ต้องเรียกใน ISR ไม่งั้น interrupt จะเข้าซ้ำไม่จบ

ตัวอย่างโค้ด

1. เปิด Clock ให้ GPIOC ก่อนใช้งาน (พื้นฐานที่สุด)

#include "ch32v00x_rcc.h"
#include "ch32v00x_gpio.h"

int main(void)
{
    // ต้องเปิด clock ให้ GPIOC ก่อน ไม่งั้นเขียนเรจิสเตอร์ GPIO ไม่มีผล
    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOC, ENABLE);

    GPIO_InitTypeDef GPIO_InitStructure = {0};
    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_0;
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_Out_PP;
    GPIO_InitStructure.GPIO_Speed = GPIO_Speed_10MHz;
    GPIO_Init(GPIOC, &GPIO_InitStructure);

    while (1) { }
}

2. เปิดหลาย Peripheral พร้อมกันด้วย bitwise OR

// เปิด GPIOC, GPIOD และ AFIO (จำเป็นสำหรับ EXTI/remap) พร้อมกันในครั้งเดียว
RCC_APB2PeriphClockCmd(
    RCC_APB2Periph_GPIOC | RCC_APB2Periph_GPIOD | RCC_APB2Periph_AFIO,
    ENABLE
);

// เปิด TIM2 บนบัส APB1 แยกต่างหาก
RCC_APB1PeriphClockCmd(RCC_APB1Periph_TIM2, ENABLE);

3. สลับไปใช้ PLL เป็นนาฬิการะบบ (เพิ่มความเร็ว)

#include "ch32v00x_rcc.h"

void SetupPLL_48MHz(void)
{
    RCC_DeInit();                                  // เริ่มจากค่า default
    RCC_PLLConfig(RCC_PLLSource_HSI_MUL2);          // PLL = HSI(24MHz) x2 = 48MHz
    RCC_PLLCmd(ENABLE);                             // เปิด PLL

    // รอ PLL ล็อกก่อนสลับไปใช้งานจริง
    while (RCC_GetFlagStatus(RCC_FLAG_PLLRDY) == RESET) { }

    RCC_HCLKConfig(RCC_SYSCLK_Div1);                // HCLK = SYSCLK (ไม่หาร)
    RCC_SYSCLKConfig(RCC_SYSCLKSource_PLLCLK);      // สลับ SYSCLK ไปใช้ PLL

    // ตรวจสอบผลว่าสลับสำเร็จจริง
    while (RCC_GetSYSCLKSource() != 0x08) { }
}

4. อ่านความถี่นาฬิกาปัจจุบัน และตรวจสอบสาเหตุการรีเซ็ต

#include "ch32v00x_rcc.h"

RCC_ClocksTypeDef clocks;
RCC_GetClocksFreq(&clocks);
// clocks.SYSCLK_Frequency, clocks.HCLK_Frequency, ... เป็นหน่วย Hz

if (RCC_GetFlagStatus(RCC_FLAG_IWDGRST) != RESET) {
    // รีบูตล่าสุดเกิดจาก watchdog timeout — โปรแกรมค้างมาก่อน
}
RCC_ClearFlag();  // ล้างแฟล็กเพื่อตรวจรอบถัดไปให้ถูกต้อง

ปัญหาที่พบบ่อย

ปัญหาสาเหตุวิธีแก้
ตั้งค่า GPIO/TIM/USART แล้วไม่มีผล เหมือน peripheral ไม่ทำงานเลย ลืมเปิด peripheral clock ก่อน — เรจิสเตอร์ของ peripheral ที่ไม่มีนาฬิกาขับจะเขียนไม่ติด อ่านค่าคงที่หรือ 0 เสมอ เรียก RCC_APB2PeriphClockCmd() หรือ RCC_APB1PeriphClockCmd() ให้ตรงกับ peripheral นั้น ก่อน _Init() ของ peripheral เสมอ
MCU ค้าง/แฮงค์ หลังเรียก RCC_SYSCLKConfig(RCC_SYSCLKSource_PLLCLK) สลับไปใช้ PLL/HSE ก่อนที่แหล่งสัญญาณนั้นจะพร้อม (ยังไม่ล็อก/ยังไม่เสถียร) ต้อง poll RCC_GetFlagStatus(RCC_FLAG_PLLRDY) หรือ RCC_WaitForHSEStartUp() จนพร้อมก่อน แล้วค่อยเรียก RCC_SYSCLKConfig()
ปิด HSE/HSI/PLL แล้ว MCU ค้างทันที ปิดแหล่งนาฬิกาที่กำลังเป็นนาฬิการะบบอยู่ (โดยตรงหรือผ่าน PLL) — MCU ไม่มีสัญญาณนาฬิกาขับ core เลย สลับ RCC_SYSCLKConfig() ไปใช้แหล่งอื่นก่อน แล้วค่อยปิดแหล่งเดิมที่ไม่ใช้แล้ว
ADC อ่านค่าผิดเพี้ยน/ไม่นิ่ง นาฬิกา ADC (ADCCLK) เร็วเกินสเปกที่ ADC รองรับ เพราะไม่ได้ตั้ง RCC_ADCCLKConfig() ให้เหมาะกับ SYSCLK ที่ใช้จริง เลือกตัวหาร RCC_PCLK2_Div* ให้ ADCCLK อยู่ในช่วงที่ datasheet กำหนด (โดยทั่วไปไม่เกินสิบกว่า MHz)
เรียก RCC_APB1PeriphResetCmd(..., ENABLE) แล้ว peripheral ไม่ทำงานอีกเลย ฟังก์ชัน ResetCmd ต่างจาก ClockCmd — ENABLE คือ "บังคับ hold reset ค้างไว้" ไม่ใช่ "เปิดใช้งาน" ถ้าไม่เรียก DISABLE ต่อ peripheral จะติด reset ตลอดไป ใช้ ENABLE แล้วตามด้วย DISABLE ทันที (สะบัด reset ครั้งเดียว) ไม่ใช่ปล่อย ENABLE ค้างไว้
RCC_GetFlagStatus(RCC_FLAG_IWDGRST) แสดงค่า SET ตลอดแม้รีเซ็ตด้วยสาเหตุอื่นแล้ว ไม่ได้เรียก RCC_ClearFlag() หลังตรวจสอบ — แฟล็กค้างจากรอบก่อนหน้า เรียก RCC_ClearFlag() ทุกครั้งหลังอ่านสาเหตุ reset เสร็จ
