ความแตกต่างจาก SimpleHAL: เอกสารชุดนี้อธิบาย Standard Peripheral Library (SPL) ซึ่งเป็นไลบรารีระดับล่าง เข้าถึง register/struct ของ MCU โดยตรง (เช่น GPIO_Init(), ADC_Init()) — ยืดหยุ่นและควบคุมได้ละเอียดกว่า แต่ใช้ยากกว่า ถ้าต้องการ API ที่ใช้ง่ายกว่า ดู SimpleHAL API Reference ซึ่งห่อ (wrap) SPL นี้ไว้อีกชั้น

สารบัญโมดูล

  • Core / System
  • 1 — RCCพื้นฐาน Reset and Clock Control — HSE/HSI/PLL, peripheral clock enable, RCC_GetClocksFreq
  • 2 — GPIOพื้นฐาน GPIO + AFIO remap — GPIO_Init, GPIO_ReadInputDataBit, GPIO_SetBits/ResetBits, Pin Remap
  • 3 — EXTIพื้นฐาน External Interrupt Lines — EXTI_Init, Trigger Rising/Falling, ใช้คู่กับ GPIO Interrupt
  • 4 — MISC (NVIC)พื้นฐาน NVIC — NVIC_PriorityGroupConfig, NVIC_Init, ตั้งลำดับความสำคัญ interrupt
  • 5 — DBGMCUพื้นฐาน Debug MCU — DBGMCU_GetCHIPID/DEVID/REVID, debug behavior ใน low-power mode
  • Communication
  • 6 — USARTกลาง USART_Init, USART_SendData/ReceiveData, IrDA, Smart Card, Half-Duplex
  • 7 — I2Cกลาง I2C_Init, GenerateSTART/STOP, Send7bitAddress, CheckEvent, PEC
  • 8 — SPIกลาง SPI_Init, SPI_I2S_SendData/ReceiveData, NSS Software, CRC
  • Analog / Timer
  • 9 — ADCสูง ADC_Init, Calibration, Regular/Injected Channel, Analog Watchdog, DMA
  • 10 — OPAสูง Op-Amp/Comparator — OPA_Init, PSEL/NSEL channel select, OPA_Cmd
  • 11 — TIMสูง TIM1 (advanced) / TIM2 — Time Base, PWM/Output Compare, Input Capture, Encoder, Dead-Time
  • 12 — DMAสูง DMA_Init, Memory-to-Memory, Circular Mode, ผูก channel ตายตัวกับ peripheral
  • Power / Safety
  • 13 — FLASHผู้เชี่ยวชาญ Flash Erase/Program, Option Bytes, Fast Program (CH32V003 extension)
  • 14 — PWRผู้เชี่ยวชาญ PWR_EnterSTANDBYMode, PVD, Auto Wake-Up (AWU), WFI/WFE Sleep
  • 15 — IWDGผู้เชี่ยวชาญ Independent Watchdog — IWDG_SetReload, IWDG_ReloadCounter, IWDG_Enable
  • 16 — WWDGผู้เชี่ยวชาญ Window Watchdog — WWDG_SetWindowValue, WWDG_SetCounter, WWDG_EnableIT
วิธีอ่าน: เริ่มจาก RCC และ GPIO ก่อน เพราะทุกโมดูลต้องเปิด peripheral clock ผ่าน RCC ก่อนใช้งาน จากนั้นเลือกโมดูลตามลำดับหมวดหมู่ที่ต้องการใช้งาน
ข้อควรระวัง: ก่อนเรียกฟังก์ชันของ peripheral ใดๆ ต้องเปิด clock ให้ peripheral นั้นก่อนเสมอ ผ่าน RCC_APB2PeriphClockCmd() / RCC_APB1PeriphClockCmd() / RCC_AHBPeriphClockCmd() ตามบัสที่ peripheral นั้นสังกัด — ไม่เช่นนั้น register จะไม่ตอบสนอง (อ่านค่าเป็น 0 หรือค้าง) ดูรายละเอียดที่หน้า RCC
