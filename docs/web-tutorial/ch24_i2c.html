ex01_I2C_Scan_Bus — สแกนหา I2C devices บัส

📖 แนวคิด

สแกนหาอุปกรณ์ I2C ทั้งหมดบนบัสด้วย I2C_SimpleInit + I2C_IsDeviceReady — ส่ง address 7-bit (0x01-0x7F) แล้วดูว่ามี device ไหนตอบกลับ — พื้นฐานก่อนใช้งาน I2C จริง

🔌 วงจร

    CH32V003        3.3V          I2C Device
    --------         |            ----------
    PC2 --[SCL]--/\/\/\---+-- SCL
                 4.7kΩ    |
    PC1 --[SDA]--/\/\/\---+-- SDA
                 4.7kΩ    |
    GND                   +-- GND

    ใช้ I2C_PINS_PARTIAL_REMAP → PD2=SCL, PD1=SDA (TSSOP-20/SOP-16/QFN-20 — ไม่รองรับ SOP-8)
MCU Pin→อุปกรณ์ขาหมายเหตุ
PC2 (SCL)→R 4.7kΩ → 3.3V—Pull-up บนสาย SCL
PC2 (SCL)→I2C Device (SCL)SCLI2C clock
PC1 (SDA)↔R 4.7kΩ → 3.3V—Pull-up บนสาย SDA
PC1 (SDA)↔I2C Device (SDA)SDAI2C data (two-way)
GND↔I2C Device (GND)GNDCommon ground

รู้จักขา

  • PC2 (SCL): ขาสัญญาณนาฬิกา I2C — ต้องมี R 4.7kΩ พull-up ไป 3.3V
  • PC1 (SDA): ขาสัญญาณข้อมูล I2C (สองทิศทาง) — ต้องมี R 4.7kΩ พull-up
  • R 4.7kΩ (×2): ตัวต้านทาน pull-up — I2C ใช้ open-drain ต้องมี pull-up เสมอ
  • I2C Device: อุปกรณ์ปลายทางเช่น EEPROM, sensor — ใช้ GND ร่วมกับ MCU

วิธีต่อทีละขั้น

  1. ต่อ PC2 (SCL) ไป R 4.7kΩ → 3.3V — pull-up สาย SCL
  2. ต่อ PC2 (SCL) ไป I2C Device (SCL) — สัญญาณนาฬิกา
  3. ต่อ PC1 (SDA) ไป R 4.7kΩ → 3.3V — pull-up สาย SDA
  4. ต่อ PC1 (SDA) ไป I2C Device (SDA) — สัญญาณข้อมูล
  5. ต่อ GND MCU ไป GND I2C Device

💻 โค้ด + อธิบายทีละบรรทัด

#define CH32V003_PACKAGE  PACKAGE_TSSOP20
#include <SimpleHAL.h>

int main(void)
{
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);
    I2C_SimpleInit(I2C_100KHZ, I2C_PINS_PARTIAL_REMAP);

    while(1)
    {
        uint8_t count = 0;
        USART_Print("Scanning I2C bus...\r\n");

        for (uint8_t addr = 1; addr < 128; addr++)
        {
            if (I2C_IsDeviceReady(addr))
            {
                USART_Print("Found: 0x");
                USART_PrintHex(addr, 1);
                USART_Print("\r\n");
                count++;
            }
        }

        USART_PrintNum(count);
        USART_Print(" device(s) found\r\n");
        Delay_Ms(2000);
    }
    return 0;
}
  • I2C_SimpleInit(speed, pinConfig): ตั้งค่า I2C hardware — 100kHz/400kHz — กำหนด pin mapping ตามแพ็กเกจ
  • I2C_IsDeviceReady(addr): ส่ง START + address bit 7-bit + รอ ACK — คืน 1 ถ้ามี device อยู่
  • I2C_PINS_PARTIAL_REMAP: SCL=PD2, SDA=PD1 — ใช้ได้เฉพาะ TSSOP-20/SOP-16/QFN-20 (SOP-8 ไม่รองรับเพราะไม่มี PD2 — I2C_SimpleInit() จะ no-op)

⚠️ จุดควรระวัง

  • ต้องมี pull-up 4.7kΩ ทั้ง SCL และ SDA — I2CK ไม่ทำงานถ้าไม่มี
  • Address 7-bit (0x03-0x77 ปกติ) — 0x00 = General Call, 0x78-0x7F reserved
  • Device address อยาก BU ขึ้นกับ logic level — ถ้า device เป็น 5V ต้อง level shifter!

✅ ตรวจสอบก่อนรัน

  • Pull-up 4.7kΩ ต่อครบทั้ง SCL และ SDA?
  • GND ของ device ต่อร่วมกับ GND MCU?
  • VCC device ตรงกับ logic level (3.3V / 5V)?

ex02_I2C_EEPROM — อ่าน/เขียน EEPROM AT24Cxx

📖 แนวคิด

ใช้ I2C_WriteRegMulti + I2C_ReadRegMulti อ่าน/เขียนข้อมูลแบบ register-based กับ AT24Cxx EEPROM — เขียน "Hello" ที่ address 0x00 แล้วอ่านกลับ — ทดสอบการสื่อสารแบบ multi-byte

🔌 วงจร

    CH32V003        3.3V          AT24Cxx EEPROM
    --------         |            --------------
    PC2 --[SCL]--/\/\/\---+-- SCL
                 4.7kΩ    |
    PC1 --[SDA]--/\/\/\---+-- SDA
                 4.7kΩ    |
                          +-- WP=GND
                           +-- A0/A1/A2=GND
                           +-- VCC=3.3V
    GND                   +-- GND
MCU Pin→อุปกรณ์ขาหมายเหตุ
PC2 (SCL)→R 4.7kΩ → 3.3V—Pull-up
PC2 (SCL)→AT24Cxx (SCL)SCLI2C clock
PC1 (SDA)↔R 4.7kΩ → 3.3V—Pull-up
PC1 (SDA)↔AT24Cxx (SDA)SDAI2C data
AT24Cxx (WP)→GND—Write protect = disable
AT24Cxx (A0/A1/A2)→GND—Address 0x50
AT24Cxx (VCC)←3.3V——
GND↔AT24Cxx (GND)GNDCommon ground

รู้จักขา

  • PC2 (SCL): ขานาฬิกา I2C ต่อกับ AT24Cxx (SCL)
  • PC1 (SDA): ขาข้อมูล I2C ต่อกับ AT24Cxx (SDA)
  • R 4.7kΩ (×2): pull-up SCL/SDA
  • AT24Cxx (WP): ขา Write Protect — ต่อ GND เพื่อให้เขียนได้
  • AT24Cxx (A0/A1/A2): ขากำหนด address — ต่อ GND ทั้งหมด = address 0x50
  • AT24Cxx (VCC): ต่อ 3.3V

วิธีต่อทีละขั้น

  1. ต่อ PC2 (SCL) → R 4.7kΩ → 3.3V และ → AT24Cxx (SCL)
  2. ต่อ PC1 (SDA) → R 4.7kΩ → 3.3V และ → AT24Cxx (SDA)
  3. ต่อ AT24Cxx (WP) ไป GND — เปิดให้เขียน EEPROM
  4. ต่อ AT24Cxx (A0/A1/A2) ไป GND — address 0x50
  5. ต่อ AT24Cxx (VCC) ไป 3.3V, (GND) ไป GND

💻 โค้ด + อธิบายทีละบรรทัด

#define CH32V003_PACKAGE  PACKAGE_TSSOP20
#include <SimpleHAL.h>

#define EEPROM_ADDR 0x50
#define REG_START   0x00

int main(void)
{
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);
    I2C_SimpleInit(I2C_100KHZ, I2C_PINS_PARTIAL_REMAP);

    while(1)
    {
        uint8_t writeData[] = "Hello";
        uint8_t readBuf[16] = {0};

        I2C_WriteRegMulti(EEPROM_ADDR, REG_START, writeData, sizeof(writeData) - 1);
        Delay_Ms(10);

        USART_Print("Written \"Hello\" to EEPROM\r\n");

        I2C_ReadRegMulti(EEPROM_ADDR, REG_START, readBuf, sizeof(writeData) - 1);
        USART_Print("Read back: ");
        USART_Print((char*)readBuf);
        USART_Print("\r\n");

        Delay_Ms(3000);
    }
    return 0;
}
  • I2C_WriteRegMulti(addr, reg, data, len): เขียนหลาย byte ไปยัง register ที่กำหนด — I2C protocol: START+addr+reg+data+STOP
  • I2C_ReadRegMulti(addr, reg, buf, len): อ่านหลาย byte — ส่ง register address ก่อนแล้ว restart → อ่าน data
  • AT24Cxx มี write cycle time ~5ms — ต้อง Delay_Ms หลัง write เสมอ

⚠️ จุดควรระวัง

  • EEPROM ใช้เวลาประมวลผล ~5ms ต่อ write (แม้จะได้ ACK ทันที) — ต้องรอ 5ms ก่อนค่อยทำอะไรต่อ
  • AT24C32/64 ใช้ address 2-byte — I2C_WriteRegMulti ใช้ address 1-byte ไม่ได้
  • ถ้า WP (Write Protect) ต่อ HIGH — เขียนไม่ได้!

✅ ตรวจสอบก่อนรัน

  • WP (pin 7) ต่อ GND? (HIGH = write protect)
  • A0/A1/A2 จับคู่กับ address 0x50-0x57 หรือยัง?
  • Delay_Ms(10) ให้เวลาเพียงพอ? (EEPROM ต้องการ ~5ms)

ex03_I2C_MultiByte_Transfer — BH1750 Light Sensor

📖 แนวคิด

ใช้ I2C_Write + I2C_Read อ่านค่าความสว่างจาก BH1750 digital light sensor — ส่ง command เปิดเครื่อง → เลือกโหมด High Resolution → อ่านค่า 2 byte raw → แปลงเป็น lux

🔌 วงจร

    CH32V003        3.3V          BH1750 Sensor
    --------         |            -------------
    PC2 --[SCL]--/\/\/\---+-- SCL
                 4.7kΩ    |
    PC1 --[SDA]--/\/\/\---+-- SDA
                 4.7kΩ    |
                           +-- ADDR=GND → 0x23
                           +-- VCC=3.3V
    GND                   +-- GND
MCU Pin→อุปกรณ์ขาหมายเหตุ
PC2 (SCL)→R 4.7kΩ → 3.3V—Pull-up
PC2 (SCL)→BH1750 (SCL)SCLI2C clock
PC1 (SDA)↔R 4.7kΩ → 3.3V—Pull-up
PC1 (SDA)↔BH1750 (SDA)SDAI2C data
BH1750 (ADDR)→GND—Address 0x23
BH1750 (VCC)←3.3V——
GND↔BH1750 (GND)GNDCommon ground

รู้จักขา

  • PC2 (SCL): ขานาฬิกา I2C ต่อ BH1750 (SCL)
  • PC1 (SDA): ขาข้อมูล I2C ต่อ BH1750 (SDA)
  • R 4.7kΩ (×2): pull-up SCL/SDA
  • BH1750 (ADDR): ขากำหนด address — ต่อ GND = 0x23, ต่อ VCC = 0x5C
  • BH1750 (VCC): ต่อ 3.3V

วิธีต่อทีละขั้น

  1. ต่อ PC2 (SCL) → R 4.7kΩ → 3.3V และ → BH1750 (SCL)
  2. ต่อ PC1 (SDA) → R 4.7kΩ → 3.3V และ → BH1750 (SDA)
  3. ต่อ BH1750 (ADDR) ไป GND — ใช้ address 0x23
  4. ต่อ BH1750 (VCC) ไป 3.3V, (GND) ไป GND

🧭 ผังการทำงาน

flowchart TD
    A["I2C_SimpleInit(100kHz)"] --> B["I2C_Write(CMD_PWR_ON)"]
    B --> C["Delay 10ms"]
    C --> D["I2C_Write(CMD_HRES)"]
    D --> E["Delay 180ms"]
    E --> F["while(1)"]
    F --> G["I2C_Read(raw, 2)"]
    G --> H["lux = (raw[0]<<8|raw[1])/1.2"]
    H --> I["Print lux"]
    I --> J["Delay 500ms"]

💻 โค้ด + อธิบายทีละบรรทัด

#define CH32V003_PACKAGE  PACKAGE_TSSOP20
#include <SimpleHAL.h>

#define BH1750_ADDR  0x23
#define CMD_PWR_ON   0x01
#define CMD_HRES     0x10

int main(void)
{
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);
    I2C_SimpleInit(I2C_100KHZ, I2C_PINS_PARTIAL_REMAP);

    uint8_t cmd = CMD_PWR_ON;
    I2C_Write(BH1750_ADDR, &cmd, 1);
    Delay_Ms(10);
    cmd = CMD_HRES;
    I2C_Write(BH1750_ADDR, &cmd, 1);
    Delay_Ms(180);

    while(1)
    {
        uint8_t raw[2] = {0, 0};
        uint16_t lux = 0;

        I2C_Read(BH1750_ADDR, raw, 2);
        lux = ((uint16_t)raw[0] << 8) | raw[1];
        lux = lux / 1.2;

        USART_Print("Light: ");
        USART_PrintNum(lux);
        USART_Print(" lux\r\n");
        Delay_Ms(500);
    }
    return 0;
}
  • I2C_Write(addr, data, len): ส่งข้อมูล raw ไปยัง device — ไม่มี internal register — ใช้กับ sensor ที่ใช้ command-based protocol
  • I2C_Read(addr, buf, len): อ่านข้อมูล raw จาก device — ไม่มี register address ก่อนหน้า
  • BH1750 conversion: raw / 1.2 = lux (ในโหมด H-Resolution Mode)
  • CMD_PWR_ON → Delay 10ms → CMD_HRES → Delay 180ms: ต้องรอให้ sensor พร้อมก่อนอ่านค่าแรก

⚠️ จุดควรระวัง

  • BH1750 ต้องการ ~180ms สำหรับการวัดครั้งแรกใน H-Resolution Mode — ถ้าอ่านเร็วไปได้ค่า 0
  • ADDR pin = HIGH → address 0x5C, ADDR = LOW → address 0x23 — ต้องตรงกัน
  • การหาร raw / 1.2 ทำใน integer — ใช้ float เพื่อความแม่นยำ หรือขยับเป็น (raw * 5) / 6

ex04_Software_I2C — I2C โดยไม่ใช้ Hardware

📖 แนวคิด

ใช้ I2C_Soft_Init + I2C_Soft_Write เพื่อจำลอง I2C protocol ด้วย software bit-bang — เลือก pin GPIO ไหนก็ได้ (แม้แต่ SOP-8) — ความเร็ว ~100kHz เหมาะกับ SOP-8 ที่ไม่มี I2C hardware pins

🔌 วงจร

    CH32V003        3.3V          I2C Device
    --------         |            ----------
    PD2 --[SCL]--/\/\/\---+-- SCL
                 4.7kΩ    |
    PD3 --[SDA]--/\/\/\---+-- SDA
                 4.7kΩ    |
    GND                   +-- GND

    ใช้ PD2, PD3 — แต่เลือก pin GPIO ไหนก็ได้!

รู้จักขา

  • PD2 (Soft SCL): ขาสัญญาณนาฬิกา I2C แบบ software bit-bang — เลือก GPIO ไหนก็ได้
  • PD3 (Soft SDA): ขาสัญญาณข้อมูล I2C แบบ software — สองทิศทาง
  • R 4.7kΩ (×2): pull-up SCL/SDA เหมือน I2C ทั่วไป

วิธีต่อทีละขั้น

  1. ต่อ PD2 (Soft SCL) → R 4.7kΩ → 3.3V และ → I2C Device (SCL)
  2. ต่อ PD3 (Soft SDA) → R 4.7kΩ → 3.3V และ → I2C Device (SDA)
  3. ต่อ GND MCU ไป GND I2C Device

#define CH32V003_PACKAGE  PACKAGE_TSSOP20
#include "SimpleI2C_Soft.h"

#define SOFT_SCL_PIN PD2
#define SOFT_SDA_PIN PD3

int main(void)
{
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);

    I2C_Soft_Init(SOFT_SCL_PIN, SOFT_SDA_PIN, I2C_SOFT_100KHZ);

    while (1)
    {
        uint8_t count = 0;
        USART_Print("Soft I2C scanning...\r\n");

        for (uint8_t addr = 1; addr < 128; addr++)
        {
            if (I2C_Soft_Write(addr, NULL, 0, 1) == I2C_SOFT_OK)
            {
                USART_Print("Found: 0x");
                USART_PrintHex(addr, 1);
                USART_Print("\r\n");
                count++;
            }
        }

        USART_PrintNum(count);
        USART_Print(" device(s) found\r\n");
        Delay_Ms(3000);
    }
}
  • I2C_Soft_Init(scl, sda, speed): เริ่มต้น software I2C — ใช้ pin GPIO อะไรก็ได้ — ต้องรวม #include "SimpleI2C_Soft.h"
  • I2C_Soft_Write(addr, buf, len, start_stop): ส่งข้อมูล — ส่ง NULL, 0, 1 = แค่ส่ง address ดูก่อน (เหมือน IsDeviceReady)
  • ข้อดี: ใช้ pin ไหนก็ได้ — ต่อวงจรยืดหยุ่น — ข้อเสีย: ช้ากว่า, ใช้ CPU มากกว่า hardware I2C

⚠️ จุดควรระวัง

  • Software I2C ช้ากว่า Hardware I2C และใช้ CPU มากกว่า — ไม่เหมาะกับความเร็วสูง
  • ต้องมี Pull-up resistor (4.7kΩ) เหมือน I2C ทั่วไป
  • SimpleI2C_Soft.h เป็น header แยก — ต้อง include แยกจาก SimpleHAL.h
  • ความเร็วสูงสุด ~100kHz — ขึ้นอยู่กับ SystemCoreClock

📖 แนวคิด

ใช้ I2C_SimpleInit + I2C_Scan ร่วมกับ I2C_PINConfig 3 แบบ: DEFAULT (PC2/PC1), PARTIAL_REMAP (PD2/PD1), REMAP (PD0/PD1) — ทดสอบสแกนบัสในแต่ละ config — ใช้ I2C_Scan แบบ batch (คืน array)

#define CH32V003_PACKAGE  PACKAGE_TSSOP20
#include "SimpleHAL.h"

static void scan_bus(I2C_PinConfig config, const char* name) {
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);
    I2C_SimpleInit(I2C_100KHZ, config);

    USART_Print("\r\n=== Scan I2C [");
    USART_Print(name);
    USART_Print("] ===\r\n");

    uint8_t devices[16];
    uint8_t count = I2C_Scan(devices, 16);

    if (count == 0) {
        USART_Print("  No devices found (check pull-up resistors)\r\n");
    } else {
        for (uint8_t i = 0; i < count; i++) {
            USART_Print("  Found: 0x");
            USART_PrintHex(devices[i], 1);
            USART_Print("\r\n");
        }
    }
}

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    pinMode(PC0, PIN_MODE_OUTPUT);

    scan_bus(I2C_PINS_DEFAULT, "DEFAULT PC2/PC1");
    Delay_Ms(500);

    scan_bus(I2C_PINS_PARTIAL_REMAP, "PARTIAL PD2/PD1");
    Delay_Ms(500);

#if CH32V003_HAS_PD0
    scan_bus(I2C_PINS_REMAP, "FULL   PD0/PD1");
    Delay_Ms(500);
#endif

    USART_Print("\r\nI2C remap test complete!\r\n");

    while (1) {
        digitalToggle(PC0);
        Delay_Ms(1000);
    }
}
  • I2C_PinConfig: I2C_PINS_DEFAULT (PC2/PC1), I2C_PINS_PARTIAL_REMAP (PD2/PD1), I2C_PINS_REMAP (PD0/PD1)
  • I2C_Scan(devices, max): สแกนแบบ batch — ส่ง array ไปรับ device address ที่เจอ — ได้จำนวน device คืน
  • CH32V003_HAS_PD0: compile-time macro — PD0 มีเฉพาะ TSSOP-20/QFN-20 — ถ้าใช้ SOP-8/SOP-16 จะ #error

⚠️ จุดควรระวัง

  • I2C_PINS_REMAP ต้องใช้ PD0 — SOP-8/SOP-16 ไม่มี → compile error
  • การเปลี่ยน pin config ต้องเรียก I2C_SimpleInit ใหม่ทุกครั้ง — ไม่ใช่แค่เปลี่ยน IO
  • Pull-up resistor 4.7kΩ จำเป็นทุก config — ไม่ว่าพินจะอยู่ตำแหน่งไหน

✅ ตรวจสอบก่อนรัน

  • เลือก PACKAGE ให้ตรงกับชิปจริง — PACKAGE_TSSOP20 / PACKAGE_QFN20 / PACKAGE_SOP16
  • ต่อ device I2C ไว้บนบัสที่สแกน — อย่างน้อย 1 ตัว
  • Check CH32V003_HAS_PD0 — ใช้ได้เฉพาะ TSSOP-20/QFN-20
