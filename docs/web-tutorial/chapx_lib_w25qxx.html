W25Qxx เป็น SPI NOR Flash — ความจุสูงกว่า EEPROM มาก (4-128MB), แต่อายุสั้นกว่า (100K vs 1M write cycles) และต้อง Erase ก่อนเขียนเสมอ, HOLD# และ WP# ต้อง pull-up ถ้าไม่ใช้

📚 หลักการทำงาน

W25Qxx เป็น SPI NOR Flash — อ่านเขียนแบบ SPI ที่ความเร็วสูง (สูงสุด 80MHz แต่ CH32V003 limit ที่ ~24MHz), แบ่งเป็น sectors (4KB), blocks (32KB/64KB), และ chip

กฎสำคัญของ Flash: Flash เปลี่ยนบิตจาก 1→0 ได้ แต่เปลี่ยน 0→1 ต้อง Erase ทั้ง Sector — การ Erase ใช้เวลานาน (~45ms/sector, ~10-80s/chip), เขียนได้ทีละ 1-256 bytes ต่อ page (Page Program)

JEDEC ID: ทุก W25Qxx มี JEDEC ID 3-byte ไม่ซ้ำกัน — Manufacturer ID + Memory Type + Capacity — ใช้อ่านเพื่อ verify ว่าชิปที่ต่อถูกต้องและ SPI สื่อสารได้ดี

Write Protect: Status Register มี BP bits (Block Protect) — ใช้ป้องกัน sector ไม่ให้ถูกเขียนทับ — สำคัญมากสำหรับ bootloader หรือ calibration data

💻 เขียน Code ทีละขั้น

ขั้นที่ 1: Init + Verify JEDEC ID

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "W25Qxx.h"

int main(void) {
    SystemCoreClockUpdate();
    SPI_Init(SPI1, SPI_BAUD_4MHZ, SPI_MODE0);
    W25Q_Init(SPI1, PC3);  // CS=PC3
    USART_Init(USART1, BAUD_115200);

    uint32_t jedec = W25Q_ReadJEDEC();
    USART_Print("JEDEC ID: 0x");
    USART_PrintHex24(jedec);
    USART_Println("");
    // W25Q32: 0xEF4016, W25Q64: 0xEF4017
    if((jedec & 0xFFFF) != 0x4016) {
        USART_Println("Wrong chip!"); while(1);
    }

🔍 W25Q_ReadJEDEC() — อ่าน ID 3-byte ใช้ verify, Manufacturer ID W25Q=0xEF, Memory Type=0x40, Capacity=0x16 (32MBit)/0x17 (64MBit)

ขั้นที่ 2: Erase Sector → เขียนข้อมูล

    // === Erase Sector 0 (4KB) ===
    W25Q_EraseSector(0x000000);  // erase sector 0
    Delay_Ms(50);                // wait erase complete
    // หรือ poll W25Q_IsBusy()

    // === Write Page (max 256 bytes/page) ===
    uint8_t data[32];
    for(int i=0; i<32; i++) data[i] = i;
    W25Q_WritePage(0x000000, data, 32);  // write page 0
    Delay_Ms(5);

🔍 เขียน Flash ต้อง Erase Sector ก่อนเสมอ — 1 sector = 4KB, ถ้าข้อมูลเดิมไม่สำคัญก็ Erase ได้เลย, W25Q_WritePage(addr, buf, len) — 1 page = 256 bytes, ห้ามเขียนข้าม page boundary

ขั้นที่ 3: อ่านข้อมูล + Write Protect

    // === Read back ===
    uint8_t rbuf[32];
    W25Q_Read(0x000000, rbuf, 32);  // read 32 bytes
    for(int i=0; i<32; i++) {
        USART_PrintInt(rbuf[i]); USART_Print(" ");
    }
    USART_Println("");

    // === Write Protect Sector 0-3 (16KB) ===
    W25Q_WriteProtect(0, 3);  // protect sectors 0-3
    // ถ้าพยายามเขียน sector 0 → จะเงียบ (ไม่เขียน)
    W25Q_WritePage(0x000000, data, 32);  // silently fails!
    // ต้อง Unprotect ก่อนถึงเขียนได้
    W25Q_WriteUnprotect(0, 3);

🔍 W25Q_Read(addr, buf, len) — อ่านได้ไม่มี page boundary limit, W25Q_WriteProtect(s,e) — ป้องกัน sector ไม่ให้ถูกเขียนทับ (สำคัญสำหรับ critical data)

⚠️ ข้อผิดพลาดที่พบบ่อย

ปัญหาสาเหตุวิธีแก้
JEDEC ID = 0xFFFFFFSPI ไม่ได้ต่อ หรือ CS ผิด pinเช็คสาย MOSI/MISO/CLK/CS, ใช้ SPI Mode 0
อ่านข้อมูลแล้วได้ 0xFF ทั้งหมดSector ถูกลบ (ปกติหลัง erase) หรือยังไม่เคยเขียนErase → ค่าทั้งหมดเป็น 0xFF — ต้องเขียนทับก่อนอ่าน
เขียนแล้วค่าไม่เปลี่ยนลืม Erase sector ก่อนเขียนFlash ต้อง Erase ก่อนเขียนทุกครั้ง — 0→1 ต้อง Erase
Erase Chip แล้วค้างนานChip Erase ใช้เวลา 10-80 วินาทีใช้ W25Q_IsBusy() poll แทน fixed delay
ข้อมูลต้น sector หายเขียนข้ามหน้า (page boundary)แต่ละ page 256 bytes — อย่าเขียนเกินขอบ

🛠️ สร้าง Product: Data Logger with SPI Flash

บันทึกค่าอุณหภูมิทุก 10 วินาทีลง W25Q32 (4096 sectors, 4MB) — วนเขียน sector ใหม่

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "W25Qxx.h"

#define SECTOR_SIZE 4096
#define TOTAL_SECTORS 1024  // W25Q32 = 1024 sectors

int main(void)
{
    SystemCoreClockUpdate();
    SPI_Init(SPI1, SPI_BAUD_4MHZ, SPI_MODE0);
    W25Q_Init(SPI1, PC3);
    USART_Init(USART1, BAUD_115200);

    uint32_t current_sector = 0;
    uint16_t offset = 0;
    uint8_t buffer[256];

    USART_Println("SPI Flash Logger Ready");

    while(1)
    {
        // Prepare data
        uint8_t hour = 12, min = 30, sec = 0;
        uint16_t value = ADC_Read(ADC1, ADC_CH0);
        uint8_t len = sprintf((char*)buffer,
            "%02d:%02d:%02d,ADC=%d\n", hour, min, sec, value);

        // Erase new sector when needed
        if(offset == 0) {
            W25Q_EraseSector(current_sector * SECTOR_SIZE);
            while(W25Q_IsBusy());  // wait erase done
        }

        // Write
        W25Q_WritePage(current_sector*SECTOR_SIZE + offset,
                       buffer, len);
        while(W25Q_IsBusy());

        offset += len;
        if(offset + 256 > SECTOR_SIZE) {
            USART_Print("Sector "); USART_PrintInt(current_sector);
            USART_Println(" full, moving to next");
            current_sector = (current_sector + 1) % TOTAL_SECTORS;
            offset = 0;
        }
        Delay_Ms(10000);
    }
}

✏️ ลองทำดู

  1. ทำ SPI Flash dump tool — อ่านทั้งชิปผ่าน USART → แสดง hex dump ทีละ 16 ไบต์
  2. ทำ firmware storage — เก็บเฟิร์มแวร์เวอร์ชันใหม่ใน SPI Flash → bootloader อ่านไป flash ผ่าน IAP
  3. ทำ file system อย่างง่าย — จอง sector 0 เป็น FAT (ตารางว่า sector ไหนใช้/ว่าง) → เขียน/อ่าน/ลบไฟล์
