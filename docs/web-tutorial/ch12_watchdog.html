สำคัญ: IWDG เมื่อเปิดแล้ว ปิดไม่ได้ จนกว่าจะ reset — ส่วน WWDG_Disable() ก็ ไม่ใช่ disable จริง (ดูคำเตือนใน ex05) การออกแบบนี้ป้องกัน bug ที่อาจปิด watchdog โดยไม่ตั้งใจ

📚 หลักการทำงาน

Watchdog — ตัวจับเวลาถอยหลัง — ถ้าไม่ "feed" (รีเซ็ต counter) ภายในเวลาที่กำหนด → MCU จะถูกรีเซ็ต — ป้องกันระบบค้างจาก bug

IWDG (Independent Watchdog — LSI 40kHz)

  • ใช้ LSI (40kHz) เป็น clock — อิสระจาก system clock — ทำงานแม้ HSI หยุด
  • Timebase: IWDG_TIMEOUT_MS(prescaler, reload) = (prescaler × reload × 1000) / 40000 — เลือกได้ 0.1ms ถึง 32.7 วินาที
  • IWDG_SimpleInit(timeout_ms) จะ auto-pick prescaler ที่พอดีกับ timeout ที่ขอ (1-32768ms)
  • เมื่อเปิดแล้ว ปิดไม่ได้ — hardware fuse — ออกแบบมาเพื่อความปลอดภัยสูงสุด
  • ตรวจ reset source ด้วย IWDG_WasResetCause() (คืน 1 = reset ล่าสุดเกิดจาก IWDG)
  • ถ้า main loop ค้าง → ไม่มีการ feed → IWDG timeout → reset → ระบบกลับมาทำงานใหม่

WWDG (Window Watchdog — PCLK1)

  • ใช้ PCLK1 (= SystemCoreClock, APB1 prescaler = 1 โดย default) เป็น clock — แม่นยำกว่า IWDG
  • Counter เป็น raw register value 0x40-0x7F (6 บิต usable) — นับถอยจากค่าที่ตั้ง
  • Timeout: WWDG_TIMEOUT_US(prescaler, counter) = (4096 × prescaler × (counter - 0x3F) × 1000000) / SystemCoreClock — ที่ PCLK1=24MHz prescaler 8 ได้ ~1.37ms ถึง ~87.4ms
  • Window concept: ต้อง feed เมื่อ window < counter < 0x40 — feed ตอน counter > window (เร็วเกิน) → reset — ปล่อยจนถึง 0x3F (ช้าเกิน) → reset
  • มี EWI (Early Wakeup Interrupt) — ตอน counter = 0x40 — ให้โอกาสบันทึกข้อมูลสำคัญก่อน reset
  • WWDG_Refresh(counter) ต้องส่ง counter ทุกครั้ง (ไม่ใช่ no-arg)
  • ⚠️ Window-clamp (silent): ถ้า window > counter จะถูก clamp ลงเท่ากับ counter โดยไม่แจ้งเตือน — ไม่งั้นจะไม่มีทาง feed ผ่านได้และ WWDG จะ reset ไม่รู้จบ (อธิบายใน ex03)

Watchdog Strategy: วาง feed จุดเดียวใน main loop — ห้าม feed ใน ISR — ถ้า loop ทำงานถูกต้อง จะ feed ทันเวลา — ถ้าค้าง = reset

💻 เขียน Code ทีละขั้น

ex01 — IWDG พื้นฐาน: SimpleInit + Feed + reset detection

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"

int main(void) {
    SystemCoreClockUpdate();

    // เช็คว่าตื่นจาก IWDG reset หรือไม่ (ต้องเช็คก่อน init อะไร)
    if (IWDG_WasResetCause()) {
        // ตื่นเพราะ Watchdog timeout!
        Timer_Init();
        USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);
        pinMode(PC0, PIN_MODE_OUTPUT);
        USART_Print("WARNING: Woke from IWDG reset!\r\n");
        // กระพริบ LED เร็ว 3 ครั้ง แสดงว่าเกิด reset
        for (int i = 0; i < 3; i++) {
            digitalWrite(PC0, HIGH); Delay_Ms(100);
            digitalWrite(PC0, LOW);  Delay_Ms(100);
        }
        // เคลียร์ flag หลังใช้งานเสร็จ (ดูคำเตือนใน ex02)
        IWDG_ClearResetFlag();
    }

    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);

    // เริ่ม IWDG — timeout 2 วินาที (auto-pick prescaler)
    IWDG_SimpleInit(2000);

    USART_Print("System running with IWDG (2s timeout)\r\n");
    pinMode(PC0, PIN_MODE_OUTPUT);

    uint32_t counter = 0;
    while (1) {
        digitalWrite(PC0, !digitalRead(PC0));  // Toggle LED
        Delay_Ms(500);
        counter++;
        USART_Print("Loop #");
        USART_PrintNum((int32_t)counter);
        USART_Print(" — feeding watchdog\r\n");

        // Feed watchdog — รีเซ็ต counter กลับไป 2s (no-arg)
        IWDG_Feed();
        // ถ้า loop ใช้เวลาน้อยกว่า 2s — OK
        // ถ้ามี bug ทำให้ loop ค้าง → ไม่ feed → 2s → reset
    }
}

🔍 IWDG_WasResetCause() คืน 1 ถ้า reset ล่าสุดเกิดจาก IWDG — เช็คตั้งแต่ต้น main() ก่อนเริ่ม IWDG ใหม่ — IWDG_SimpleInit(2000) auto-pick prescaler ที่พอดี 2000ms — IWDG_Feed() เป็น no-arg รีเซ็ต counter — กฎเหล็ก: feed ใน main loop เท่านั้น ห้าม feed ใน ISR (เพราะ ISR อาจยังทำงานแม้ main loop ค้าง)

ex02 — IWDG ขั้นสูง: manual prescaler + busy + gettimeout + clearflag

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);
    pinMode(PC0, PIN_MODE_OUTPUT);

    // ——— อ่าน reset cause ทุกตัว "ก่อน" เคลียร์ ———
    if (IWDG_WasResetCause()) {
        USART_Print("Last reset: IWDG (main loop ค้างมาก่อน)\r\n");
    }
    // ⚠ IWDG_ClearResetFlag() เคลียร์ flag "ทุกตัวพร้อมกัน"
    //   (POR, PIN, Software, IWDG, WWDG, LowPower) ตาม CH32V003 hardware
    //   ถ้าจะอ่าน flag อื่นด้วย (เช่น RCC_GetFlagStatus) ต้องอ่าน "ก่อน" เรียกฟังก์ชันนี้
    IWDG_ClearResetFlag();

    // ———.manual init: ต้องการ 500ms timeout พอดีๆ ด้วย prescaler 32 ———
    uint16_t reload = IWDG_CALC_RELOAD(32, 500);      // = (500*40000)/(32*1000) = 625
    IWDG_Init(IWDG_PRESCALER_32, reload);              // manual prescaler + reload

    // รอจน register sync เสร็จ (IWDG always-on clock ต้องรอ 5 LSI cycles)
    while (IWDG_IsBusy()) { }

    // ตรวจ timeout จริงที่จะได้ (อาจต่างจากที่กำหนดเล็กน้อย)
    uint32_t actual_ms = IWDG_GetTimeout(32, reload);  // = (32*625*1000)/40000 = 500
    USART_Print("IWDG actual timeout = ");
    USART_PrintNum((int32_t)actual_ms);
    USART_Print(" ms\r\n");

    while (1) {
        digitalWrite(PC0, !digitalRead(PC0));
        Delay_Ms(400);
        IWDG_Feed();  // ก่อน timeout 500ms
    }
}

🔍 IWDG_CALC_RELOAD(prescaler, timeout_ms) คำนวณ reload จาก timeout ที่ต้องการ — IWDG_Init(IWDG_PRESCALER_32, reload) ตั้ง manual — IWDG_IsBusy() ใช้รอ register sync (5 LSI cycles) — IWDG_GetTimeout(prescaler, reload) คืน timeout จริงเป็น ms — ⚠ IWDG_ClearResetFlag(): ฮาร์ดแวร์ CH32V003 ไม่รองรับการเคลียร์ flag เฉพาะตัว — RCC_ClearFlag() เคลียร์ reset flag ทุกตัวพร้อมกัน (POR, PIN, Software, IWDG, WWDG, LowPower) — ถ้าต้องการอ่านสาเหตุ reset อื่นด้วย ให้เรียก RCC_GetFlagStatus() ของ flag อื่น ก่อน เรียกฟังก์ชันนี้

ex03 — WWDG พื้นฐาน: counter + window + refresh(counter) + window-clamp

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);
    pinMode(PC0, PIN_MODE_OUTPUT);
    pinMode(PC1, PIN_MODE_OUTPUT);

    // ——— คำนวณ timing ก่อน (PCLK1 = 24MHz, prescaler 8) ———
    // Max timeout: counter = 0x7F (127)  → (4096*8*(127-63)) / 24M ≈ 87.4 ms
    // Window boundary: counter = 0x50 (80) → (4096*8*( 80-63)) / 24M ≈ 23.2 ms
    // ดังนั้น "refresh ได้ตอน counter อยู่ระหว่าง 0x50 - 0x40" ≈ ช่วงเวลา 23.2..87.4 ms
    uint32_t us_max = WWDG_TIMEOUT_US(8, 0x7F);  // ≈ 87381 µs
    uint32_t us_win = WWDG_TIMEOUT_US(8, 0x50);  // ≈ 23211 µs
    USART_Print("WWDG timeout: ~");
    USART_PrintNum((int32_t)(us_max / 1000));
    USART_Print(" ms, window opens at ~");
    USART_PrintNum((int32_t)(us_win / 1000));
    USART_Print(" ms\r\n");

    // ——— init: counter=127, window=80 (raw register values 0x40-0x7F) ———
    // WWDG_SimpleInit รับ raw counter และ window — ไม่ใช่ (timeout_constant, percentage)
    WWDG_SimpleInit(0x7F, 0x50);  // default prescaler 8

    // ⚠ window-clamp แบบ silent (commit 5293ae3):
    //   ถ้าส่ง window > counter เช่น WWDG_SimpleInit(0x60, 0x70)
    //   → window จะถูก clamp ลงเท่ากับ counter (0x60) โดยไม่แจ้งเตือน
    //   เหตุผล: ถ้า window > counter จะไม่มีช่วงที่ "window < counter" เลย
    //   → feed ผ่านไม่ได้ → WWDG reset ไม่รู้จบ
    //   ป้องกันโดยการ clamp ให้มีอย่างน้อย 1 tick ที่ feed ได้

    uint32_t counter = 0;
    while (1) {
        counter++;
        digitalWrite(PC0, !digitalRead(PC0));

        // หน่วงให้เลย window (เวลาต้อง > ~23ms)
        Delay_Ms(30);   // อยู่ใน window แล้ว (23-30ms), ก่อน timeout 87ms

        // ——— refresh ต้องส่ง counter เสมอ ———
        digitalWrite(PC1, HIGH);
        WWDG_Refresh(0x7F);   // คืน counter กลับไป 127
        digitalWrite(PC1, LOW);

        if (counter % 20 == 0) {
            USART_Print("WWDG feed #");
            USART_PrintNum((int32_t)counter);
            USART_Print(" OK (30ms in window)\r\n");
        }
    }
}

🔍 WWDG_SimpleInit(0x7F, 0x50) รับ raw register values (counter=127, window=80) — ไม่ใช่ (timeout constant, percentage) — WWDG_Refresh(0x7F) ต้องส่ง counter ทุกครั้ง (ไม่ใช่ no-arg) — refresh ได้เมื่อ window < counter < 0x40 นับจากตอน init/refresh ครั้งก่อน — ⚠ window-clamp silent: ถ้า window > counter จะถูกลดลงเท่า counter โดยไม่แจ้ง — ทำให้มีอย่างน้อย 1 tick ที่ feed ผ่านได้ ป้องกัน reset loop ไม่รู้จบ — ก่อนใช้งานจริงให้คำนวณ timing ด้วย WWDG_TIMEOUT_US(prescaler, counter)

ex04 — WWDG + Early Wakeup Interrupt (EWI)

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"

// ——— callback สำหรับ EWI: ตอน counter = 0x40 (ก่อน reset 1 tick) ———
void EarlyWarning(void) {
    // โอกาสสุดท้ายก่อน reset — บันทึก debug info, ปิด output, เป็นต้น
    USART_Print(">>> WWDG EWI: about to reset in 1 tick — save state!\r\n");
}

int main(void) {
    SystemCoreClockUpdate();

    // เช็ค reset cause ก่อน (เปลี่ยนจากชื่อเดิม)
    if (IWDG_WasResetCause()) {
        // (อาจเกิดจาก WWDG ครั้งก่อน — ดู ex05 สำหรับการแยก IWDG/WWDG ละเอียดกว่านี้)
        USART_Print("Reset by watchdog (IWDG/WWDG)\r\n");
    }

    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);
    pinMode(PC0, PIN_MODE_OUTPUT);

    // ตั้ง callback EWI ก่อนเปิด interrupt
    WWDG_SetCallback(EarlyWarning);

    // เปิด WWDG พร้อม EWI: counter=127, window=80, prescaler 8
    WWDG_InitWithInterrupt(0x7F, 0x50, WWDG_PRESCALER_8);

    USART_Print("WWDG + EWI active (87ms timeout)\r\n");

    uint32_t tick = 0;
    while (1) {
        digitalWrite(PC0, !digitalRead(PC0));
        Delay_Ms(30);          // อยู่ใน window
        WWDG_Refresh(0x7F);   // ต้องส่ง counter
        if (++tick % 50 == 0) {
            USART_Print("WWDG tick OK\r\n");
        }
    }
}

🔍 WWDG_SetCallback(cb) ตั้ง callback สำหรับ EWI — WWDG_InitWithInterrupt(counter, window, prescaler) เปิด WWDG พร้อม Early Wakeup Interrupt — interrupt จะ firing ตอน counter = 0x40 (ก่อน reset 1 tick) — เป็นโอกาสสุดท้ายในการ log/state-save — ในเฉลยนี้ใช้ IWDG_WasResetCause() ตาม API จริงของ SimpleHAL — คำเตือน: ต้องเพิ่ม WWDG_IRQHandler ใน ch32v00x_it.c ตามตัวอย่างใน header (จะเรียก WWDG_IRQHandler_Callback() ให้อัตโนมัติ)

ex05 — WWDG ขั้นสูง: manual init + flag + WWDG_Disable limitation

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"

void OnEarlyWarning(void) {
    // ตรวจ/clear flag ภายใน callback ก็ได้ — หรือทำใน main loop
    if (WWDG_GetInterruptFlag()) {
        USART_Print("EWI flag set — preparing reset\r\n");
        WWDG_ClearInterruptFlag();  // เคลียร์ EWI flag
    }
}

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);
    pinMode(PC0, PIN_MODE_OUTPUT);

    WWDG_SetCallback(OnEarlyWarning);

    // ——— manual init พร้อมเลือก prescaler เอง ———
    // WWDG_Init(counter, window, prescaler) — ไม่มี preset timeout constant
    // ตัวอย่าง: prescaler 4, counter 0x7F, window 0x50
    //   timeout  = WWDG_TIMEOUT_MS(4, 0x7F) ≈ 43.7 ms (PCLK1=24MHz)
    //   window   = ~11.6 ms (counter=0x50)
    uint32_t timeout_ms = WWDG_CalcTimeout(4, 0x7F);  // คืน ms ≈ 43
    USART_Print("WWDG timeout (prc=4, c=0x7F) = ");
    USART_PrintNum((int32_t)timeout_ms);
    USART_Print(" ms\r\n");

    WWDG_Init(0x7F, 0x50, WWDG_PRESCALER_4);

    uint32_t tick = 0;
    while (1) {
        // ตรวจ EWI ใน main loop ก็ได้ ไม่จำเป็นต้องอยู่ใน callback เท่านั้น
        if (WWDG_GetInterruptFlag()) {
            USART_Print("EWI detected in main loop\r\n");
            WWDG_ClearInterruptFlag();
        }

        digitalWrite(PC0, !digitalRead(PC0));
        Delay_Ms(15);          // อยู่ใน window (counter 0x50-0x40)
        WWDG_Refresh(0x7F);

        if (++tick == 100) {
            // ⚠ ทดลองเรียก WWDG_Disable() — "ไม่ใช่ disable จริง"
            //   (Header บรรทัด 173-184) — เมื่อ WDGA set แล้ว WWDG
            //   จะนับถอยต่อไปและยัง reset ได้ถ้าไม่ refresh
            //   ฟังก์ชันนี้แค่รีเซ็ต config registers
            WWDG_Disable();
            USART_Print("WWDG_Disable() called — but countdown still active!\r\n");
            USART_Print("Must keep calling WWDG_Refresh(counter) or MCU will reset.\r\n");
        }

        if (tick == 120) {
            // ถ้าหยุด refresh จริงๆ → MCU reset ในอีก ~43ms
            USART_Print("Stopping refresh intentionally → RESET\r\n");
            while (1) { }
        }
    }
}

🔍 WWDG_Init(counter, window, prescaler) เปิด manual — WWDG_CalcTimeout(prescaler, counter) คืน timeout เป็น ms — WWDG_GetInterruptFlag() / WWDG_ClearInterruptFlag() จัดการ EWI flag — ⚠ WWDG_Disable() ไม่ใช่ disable จริง (header บรรทัด 173-184) — "once WDGA is set, WWDG cannot be disabled by software" — มันยังคง countdown อยู่ และจะ reset ถ้าไม่ refresh — ฟังก์ชันนี้แค่รีเซ็ต config registers — ฉะนั้น ห้าม คาดหวังว่าเรียกแล้วจะหยุด watchdog ได้ — ถ้าจะหยุดจริงต้องปล่อย MCU reset เท่านั้น

⚠️ ข้อผิดพลาดที่พบบ่อย

ปัญหาสาเหตุวิธีแก้
MCU รีเซ็ตตลอดเวลาIWDG timeout สั้นเกินไป — main loop ใช้เวลาเกิน timeoutเพิ่ม timeout หรือลดงานใน loop — เช็คสาเหตุที่ต้น main() ด้วย if(IWDG_WasResetCause()) {...} แล้ว log ดูจำนวนครั้ง
IWDG ไม่ทำงานตอน debugDebugger หยุด IWDG อัตโนมัติใน debug modeทดสอบโดยไม่ใช้ debugger — IWDG ทำงานเฉพาะรันจริง
Feed แล้วก็ยัง resetลืม feed หลังจาก Delay_Ms() ยาวเกิน timeoutถ้า delay นานกว่า timeout — ต้อง feed ก่อน delay หรือแยก delay เป็นช่วงสั้นๆ
WWDG reset ไม่รู้จบหลังตั้ง window > counterwindow-clamp ใหม่ (commit 5293ae3) ลด window ลงเท่า counter แบบ silent — ทำให้ feed ได้แค่ช่วงแคบมากอย่าตั้ง window > counter — ถ้าเกิดแล้วให้ refresh ตั้งแต่ต้น (หลัง init เลย) และใช้ prescaler สั้นจนกว่าจะแก้ code — คำนวณ timing ก่อนด้วย WWDG_TIMEOUT_US(prescaler, counter)
IWDG_WasResetCause() เป็นจริงตลอดทุกครั้ง bootลืมเคลียร์ flag — ครั้งถัดไปยังเจอ flag ค้างอยู่เรียก IWDG_ClearResetFlag() หลังจากใช้งานเสร็จ — ⚠ แต่ ฟังก์ชันนี้เคลียร์ reset flag ทุกตัวพร้อมกัน (POR/PIN/IWDG/WWDG/SW/LP) — ถ้าจะอ่านสาเหตุ reset อื่น ให้อ่านด้วย RCC_GetFlagStatus() ก่อนเรียกฟังก์ชันนี้
WWDG_Refresh แบบไม่ส่ง counter ไม่ทำงานAPI จริงต้องส่ง counter (ไม่ใช่ no-arg)ใช้ WWDG_Refresh(0x7F) — ส่งค่า counter ที่ตั้งไว้ใน init
ไม่มี timeout constant แบบเสร็จสรรค์ใน headerSimpleWWDG ไม่มี macro timeout สำเร็จ ต้องคำนวณเองคำนวณจาก WWDG_TIMEOUT_MS(prescaler, counter) เอง — เช่น WWDG_TIMEOUT_MS(8, 0x7F) ≈ 87ms
โค้ดเรียก WWDG_Disable() แล้ว watchdog ยัง resetฟังก์ชันนี้ ไม่ใช่ disable จริง (header 173-184) — WWDG ยัง countdown อยู่หลัง WDGA setต้องเรียก WWDG_Refresh(counter) ต่อไปจนกว่าจะ reset MCU เอง — หยุด watchdog จริงไม่ได้ by design

🛠️ สร้าง Product: ระบบที่ไม่เคยค้าง

ระบบ production-grade — IWDG 4s timeout + ตรวจจับ reset + log การค้าง

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"

volatile uint32_t g_wdg_reset_count = 0;

int main(void)
{
    SystemCoreClockUpdate();

    // เช็คสาเหตุ reset — ใช้ API จริง IWDG_WasResetCause()
    if (IWDG_WasResetCause())
    {
        // ตื่นจาก Watchdog — เกิดการค้าง!
        // หน่วงเวลาเล็กน้อยก่อน init — ป้องกัน infinite reset loop
        for (volatile uint32_t i = 0; i < 100000; i++);

        g_wdg_reset_count++;

        // อ่าน flag อื่นที่ต้องการ "ก่อน" เคลียร์ เพราะ IWDG_ClearResetFlag()
        // เคลียร์ reset flag ทุกตัวพร้อมกัน (POR/PIN/IWDG/WWDG/SW/LP)
    }

    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);
    pinMode(PC0, PIN_MODE_OUTPUT);

    if (g_wdg_reset_count > 0)
    {
        USART_Print("!!! WATCHDOG RESET #");
        USART_PrintNum((int32_t)g_wdg_reset_count);
        USART_Print(" !!!\r\n");

        // ถ้ารีเซ็ตติดกันเกิน 5 ครั้ง — safe mode
        if (g_wdg_reset_count >= 5)
        {
            USART_Print("Entering SAFE MODE\r\n");
            IWDG_ClearResetFlag();  // เคลียร์หลังใช้งาน reset cause ครบแล้ว
            while (1)
            {
                digitalWrite(PC0, HIGH);
                Delay_Ms(200);
                digitalWrite(PC0, LOW);
                Delay_Ms(800);
                // Safe mode: ไม่ทำอะไรเสี่ยง — แค่กระพริบ LED
                IWDG_Feed();
            }
        }
    }

    IWDG_ClearResetFlag();  // เคลียร์ flag ให้ครั้งถัดไปอ่านได้สะอาด

    // เริ่ม IWDG — 4 วินาที
    IWDG_SimpleInit(4000);
    USART_Print("System running (IWDG 4s)\r\n");

    uint32_t tick = 0;
    while (1)
    {
        // งานที่อาจค้าง... (ตัวอย่าง: เช็ค I2C device)
        digitalWrite(PC0, !digitalRead(PC0));

        USART_Print("Tick: ");
        USART_PrintNum((int32_t)++tick);
        USART_Print(" OK\r\n");

        Delay_Ms(1000);  // < 4s — ปลอดภัย

        IWDG_Feed();  // Feed ทุกรอบ loop
    }
}

✏️ ลองทำดู

  1. ลด IWDG timeout เป็น 500ms (ด้วย IWDG_SimpleInit(500) หรือ IWDG_Init(IWDG_PRESCALER_64, IWDG_CALC_RELOAD(64, 500))) — เพิ่ม Delay_Ms(2000) ใน loop — สังเกตการ reset แล้ว log ที่ IWDG_WasResetCause() ที่ต้น main()
  2. ใช้ WWDG แทน IWDG — WWDG_SimpleInit(0x7F, 0x50) prescaler default 8 — ทดสอบ feed เร็วเกิน (WWDG_Refresh(0x7F) ทันทีหลัง init) และ feed ช้าเกิน (Delay_Ms(100)) — ดูผลต่าง — คำนวณ window จริงด้วย WWDG_TIMEOUT_US(8, 0x50)
  3. สร้างระบบที่ใช้ทั้ง IWDG + WWDG พร้อมกัน — IWDG เป็น safety net (4s) — WWDG ตรวจจับ loop anomaly (prescaler 8, counter 0x7F ≈ 87ms window) — เพิ่ม EWI callback ด้วย WWDG_SetCallback() + WWDG_InitWithInterrupt()
  4. ทดลองเรียก WWDG_Disable() แล้วหยุด refresh — สังเกตว่า MCU ยัง reset อยู่ (พิสูจน์ว่าไม่ใช่ disable จริง) — จดบันทึกหากใช้ตอน production
  5. ตั้ง WWDG_SimpleInit(0x60, 0x70) (window > counter) — สังเกต window-clamp silent ที่ลด window ลงเท่า counter — ใช้ WWDG_Refresh(0x60) ตั้งแต่ต้นเพื่อรอดจาก reset loop
