⚠️ VMOT 8.2–45V — ต่อ capacitor 100μF ขนาน VMOT-GND ใกล้ driver — ปรับ Current Limit ด้วย potentiometer บนบอร์ด — DRV8825 ร้อนเร็วที่กระแสสูง ควรติด heatsink

รู้จักขา

  • STEP: ขารับพัลส์ — 1 พัลส์ = 1 microstep
  • DIR: กำหนดทิศทางหมุน — HIGH หรือ LOW
  • EN: เปิด/ปิด driver — LOW = เปิดใช้งาน
  • M0/M1/M2: เลือกโหมด microstep (1/1 ถึง 1/32)
  • VMOT: จ่ายไฟให้มอเตอร์ 8.2–45V
  • GND: Ground ร่วมกับ MCU

วิธีต่อทีละขั้น

  1. ต่อ STEP/DIR/EN ของ DRV8825 ไป GPIO (PC0–PC2) — สั่งพัลส์และควบคุมทิศทาง
  2. ต่อ M0/M1/M2 ไป GPIO (PC3–PC5) — เลือก microstep ratio
  3. ต่อ VMOT กับ แหล่งจ่าย 8.2–45V และ GND ต่อ GND — จ่ายไฟให้มอเตอร์
  4. ต่อ NEMA17 เข้ากับ ขา A1/A2/B1/B2 — ขดลวดมอเตอร์
  5. ต่อ 100µF capacitor ขนาน VMOT-GND — กรองสัญญาณรบกวน

📚 หลักการทำงาน

DRV8825 เป็น stepper motor driver ที่ใช้ STEP/DIR interface — ต่างจาก ULN2003 ตรงที่ไม่ต้องเขียน step sequence เอง — ส่ง pulse ที่ STEP pin 1 ครั้ง = 1 microstep — ความถี่ของ pulse กำหนดความเร็ว

Microstepping 1/1 ถึง 1/32 — ตั้งค่าด้วย M0,M1,M2 3 pins — NEMA17 ทั่วไป 1.8°/step (200 steps/rev ใน full-step) — 1/32 microstepping = 6400 pulses/rev — การเคลื่อนที่ละเอียดและเงียบขึ้นมาก

Current Limit: ตั้งกระแสสูงสุดด้วยตัวต้านทานปรับค่า (pot) บนบอร์ด — สูตร: I_max = Vref × 2 — วัด Vref ที่ test point — NEMA17 ทั่วไป 1-2A/phase ตั้ง Vref = 0.5-1.0V

Enable (EN): LOW = เปิดใช้งาน, HIGH = ปิด (ปล่อย motor) — ใช้ LOW ตลอดเวลาเพื่อให้มอเตอร์ hold ตำแหน่ง

💻 เขียน Code ทีละขั้น

ขั้นที่ 1: Init + Setup

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "DRV8825.h"

int main(void) {
    SystemCoreClockUpdate();
    DRV8825_Instance drv;
    DRV8825_Init(&drv, PC1, PC0, PC2, 200);  // STEP=PC1, DIR=PC0, EN=PC2, 200 steps/rev
    DRV8825_Enable(&drv);
    DRV8825_SetSpeed(&drv, 60);  // 60 RPM

🔍 DRV8825_Init(&drv, STEP, DIR, EN, steps_per_rev) — ตั้งค่า GPIO อัตโนมัติ — DRV8825_Enable(&drv) เปิด driver — DRV8825_SetSpeed(&drv, rpm) ตั้งความเร็ว

ขั้นที่ 2: Move Steps + Degrees

    while(1) {

⚠️ ข้อผิดพลาดที่พบบ่อย

ปัญหาสาเหตุวิธีแก้
Motor ไม่หมุน — DRV8825 ร้อนจัดต่อ VMOT กลับขั้ว หรือ Current Limit สูงเกินตรวจสอบขั้ว VMOT — ปรับ pot ทวนเข็มเพื่อลด Vref — วัด Vref ≤ 1V
Motor สั่นแต่ไม่หมุนpulse frequency สูงเกิน หรือ microstep mode ไม่ตรงเริ่มจากความเร็วต่ำ (delay 1000μs) — ตรวจสอบ M0-M2 logic กับตาราง datasheet
Motor skip steps ที่ความเร็วสูงไม่มี acceleration — หรือ current limit ต่ำไปใช้ ramp-up profile — เพิ่ม Vref (ระวังความร้อน) — ลด microstep level
STEP pin ไม่สร้าง pulseลืมเรียก DRV8825_Enable หรือ Init ไม่ถูกต้องตรวจสอบ DRV8825_Init(&drv, PC1, PC0, PC2, 200) — ใช้ oscilloscope วัด
นับรอบผิด — จำนวน pulses ไม่ตรงลืมเปลี่ยน steps/rev ตาม microstep modeFull=200, 1/16=3200, 1/32=6400 — คำนวณสูตร: 200 × microstep_level

🛠️ สร้าง Product: Precision Linear Slide

NEMA17 + DRV8825 + Lead Screw GT2 — เคลื่อนที่ตำแหน่ง mm ที่แม่นยำ — ใช้ Endstop + Home sequence

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "DRV8825.h"

#define LIMIT PC6  // Endstop (NC, LOW=triggered)

DRV8825_Instance drv;
int32_t position_mm = 0;

void move_to_mm(int32_t target_mm) {
    int32_t delta = target_mm - position_mm;
    uint32_t steps = (delta > 0) ? delta * 200 : (-delta) * 200;  // 200 steps/mm
    if(delta != 0) {
        DRV8825_Move(&drv, steps);
    }
    position_mm = target_mm;
}

void home_sequence() {
    while(digitalRead(LIMIT)) {
        DRV8825_Move(&drv, 1);  // move 1 step toward limit
    }
    position_mm = 0;
}

int main(void) {
    SystemCoreClockUpdate();
    pinMode(LIMIT, PIN_MODE_INPUT_PULLUP);
    DRV8825_Init(&drv, PC1, PC0, PC2, 200);
    DRV8825_Enable(&drv);
    DRV8825_SetSpeed(&drv, 60);

    home_sequence();
    while(1) {
        move_to_mm(100); Delay_Ms(1000);
        move_to_mm(0);   Delay_Ms(1000);
    }
}

  2. เพิ่ม Stall Detection — ใช้ back-EMF sensing หรือ encoder feedback ตรวจจับเมื่อมอเตอร์ stall
  3. ทำ Multi-Axis CNC Controller — ใช้ DRV8825 3 ตัว (X,Y,Z) + PWM Spindle — ส่ง G-Code ผ่าน USART
