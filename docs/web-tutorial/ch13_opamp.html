🔌 การต่อวงจร

    OPAMP ภายใน CH32V003 — ไม่ต้องใช้ IC OPAMP ภายนอก
    (CH32V003 มี OPAMP 1 ตัว — เช็ค datasheet ว่ารุ่นที่ใช้มี OPAMP หรือไม่)

    OPAMP มี input channels แบ่งเป็นฝั่งบวก (Positive) และฝั่งลบ (Negative)
    ┌────────────────────────────────────────────────┐
    │  CH32V003 (OPAMP เดียว)                         │
    │                                                │
    │   สัญญาณเข้า ─→  CHP0/CHP1 (+) ──┐             │
    │                                  │             │
    │                           ┌──────▼──────┐      │
    │                           │   OPAMP     │      │
    │                           │  (1 ตัว)     │      │
    │                           └──────┬──────┘      │
    │                                  │             │
    │   CHN0/CHN1 (−) ─── feedback ────┘             │
    │                                  │             │
    │                                  └──→ ADC ch7  │
    │                                       (ภายใน)  │
    │                                                │
    │  โหมดการใช้งาน 4 แบบ (เลือกผ่าน mode enum):      │
    │  ├─ Voltage Follower (Gain = 1) : CHP0 → OUT   │
    │  ├─ Non-Inverting (Gain = 1+R2/R1) : + R ภายนอก│
    │  ├─ Inverting (Gain = -R2/R1) : + R ภายนอก      │
    │  └─ Comparator : output HIGH เมื่อ V+ > V−      │
    └────────────────────────────────────────────────┘
OPAMP Channel→อุปกรณ์หมายเหตุ
OPAMP_CHP0 (Positive 0)←สัญญาณเข้าฝั่งบวกเช่น sensor high-Z, Vin (Non-Inverting)
OPAMP_CHP1 (Positive 1)←สัญญาณเข้าฝั่งบวก (สำรอง)เลือก input อีกช่องได้
OPAMP_CHN0 (Negative 0)—ขาลบ / feedbackใช้กับ Non-Inverting / Inverting / Comparator
OPAMP_CHN1 (Negative 1)—ขาลบ (สำรอง)เช่น reference ในโหมด Comparator
OPAMP Output → ADC ch7→ADC ภายในต่อภายในอัตโนมัติ — ไม่ต้องต่อสาย — อ่านด้วย ADC_Read(ADC_CH_7)

รู้จักขา / Channel

  • OPAMP_CHP0 / OPAMP_CHP1 (Positive): ขาเข้าฝั่งบวกของ OPAMP — รับสัญญาณหลัก (เช่นเซ็นเซอร์)
  • OPAMP_CHN0 / OPAMP_CHN1 (Negative): ขาเข้าฝั่งลบ — ใช้เป็น feedback ในโหมดขยาย หรือเป็น reference ในโหมด Comparator
  • OPAMP Output: ขาออกของ OPAMP — ต่อภายในกับ ADC ch7 อยู่แล้ว — ไม่ต้องต่อสายเพิ่ม

หมายเหตุ: mapping ของแต่ละ channel ไปยังขา GPIO จริงขึ้นกับรุ่น/package ของชิป — ให้เช็ค CH32V003 datasheet ของรุ่นที่ใช้ก่อนต่อวงจรจริง

วิธีต่อทีละขั้น

  1. ต่อ สัญญาณเซ็นเซอร์ เข้าขาที่แมปกับ OPAMP_CHP0 — สัญญาณเข้าฝั่งบวก
  2. OPAMP Output ต่อกับ ADC ch7 ภายใน อยู่แล้ว — ไม่ต้องต่อสายเพิ่ม
  3. (ถ้าใช้ Non-Inverting/Inverting) ต่อ R ภายนอก R1/R2 ที่ขา CHN0 เพื่อกำหนด gain — Voltage Follower ไม่ต้องใช้ R ภายนอก
  4. เรียก OPAMP_Enable() ในโค้ดหลัง init เสมอ ก่อนอ่าน ADC

📚 หลักการทำงาน

OPAMP (Operational Amplifier) — วงจรขยายสัญญาณอนาล็อก — CH32V003 มี OPAMP ในตัว 1 ตัว — ไม่ต้องต่อ IC ภายนอก

Mode การทำงาน (4 แบบ)

  • Voltage Follower (Buffer): Gain = 1 — อินพุต impedance สูงมาก — เอาต์พุต impedance ต่ำ — ใช้กับเซ็นเซอร์ที่มี output impedance สูง (pH probe, piezo) เพื่อ buffer สัญญาณก่อนเข้า ADC
  • Non-Inverting Amplifier: ใช้ R ภายนอก R1, R2 ตั้ง gain — Gain = 1 + (R2/R1) — เฟสออกตรงกับเข้า — ใช้ขยายสัญญาณเล็กให้ ADC อ่านได้แม่น
  • Inverting Amplifier: ใช้ R ภายนอก R1, R2 — Gain = -(R2/R1) — กลับเฟสสัญญาณ และขยาย
  • Comparator: ทำงานแบบ open-loop — output เป็น HIGH เมื่อ V+ > V− และ LOW เมื่อ V+ < V− — ใช้ตรวจจับ threshold

Gain preset helper: OPAMP_GAIN_1X/2X/4X/8X/16X เป็น enum helper สำหรับคำนวณ/เลือกค่า R — ไม่ใช่ register setting — gain จริงขึ้นกับค่า R ภายนอกที่ต่อจริง

ข้อควรระวัง: OPAMP ภายใน CH32V003 มี input common-mode range 0–VDD, output range ~0.1V ถึง VDD−0.1V (ไม่ใช่ rail-to-rail) — ถ้า gain สูงเกิน จะเกิด clipping ที่ output

Power: OPAMP กินกระแส ~200µA เมื่อเปิด — ถ้าไม่ใช้ควรปิดด้วย OPAMP_Disable() เพื่อประหยัดไฟ

💻 เขียน Code ทีละขั้น

ขั้นที่ 1: Voltage Follower + อ่าน ADC

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);
    ADC_SimpleInit();  // เปิด ADC ก่อนอ่าน OPAMP output

    // Voltage Follower: CHP0 เข้า → output → ADC ch7
    OPAMP_SimpleInit(OPAMP_MODE_VOLTAGE_FOLLOWER);

    // เปิดใช้งาน OPAMP (no-arg)
    OPAMP_Enable();

    while(1) {
        // อ่าน OPAMP output ผ่าน ADC ch7 (ต่อภายในอยู่แล้ว)
        uint16_t raw = ADC_Read(ADC_CH_7);
        float voltage = ADC_ToVoltage(raw, 3.3f);

        USART_Print("Vout=");
        USART_PrintNum((int32_t)(voltage * 1000));
        USART_Print(" mV\r\n");

        Delay_Ms(500);
    }
}

🔍 OPAMP_SimpleInit(OPAMP_MODE_VOLTAGE_FOLLOWER) รับ mode เดียว — ตั้งวงจรเป็น buffer — OPAMP_Enable() เป็น no-arg จ่ายไฟให้ OPAMP — output ต่อกับ ADC ch7 ภายใน จึงอ่านด้วย ADC_Read(ADC_CH_7) ได้เลย

ขั้นที่ 2: Non-Inverting Amplifier + คำนวณ gain

// วงจร: Input → CHP0(+),  CHN0(−) ← R2 ← Output, CHN0 ← R1 ← GND
//       Gain = 1 + (R2/R1)

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);
    ADC_SimpleInit();

    // ตั้งค่า Non-Inverting ระบุ channel เอง
    OPAMP_ConfigNonInverting(OPAMP_CHP0, OPAMP_CHN0);
    OPAMP_Enable();

    // ค่า R ภายนอกที่ต่อจริง
    uint32_t r1 = 10000;  // 10 kΩ (to GND)
    uint32_t r2 = 10000;  // 10 kΩ (feedback)
    float gain = OPAMP_CalculateGainNonInv(r1, r2);  // คืน 1 + R2/R1 = 2.0

    USART_Print("Non-Inverting gain = ");
    USART_PrintNum((int32_t)(gain * 10));
    USART_Print("\r\n");

    while(1) {
        float v_out = ADC_ReadVoltage(ADC_CH_7, 3.3f);
        float v_in  = v_out / gain;  // คืนกลับเป็น voltage เข้าจริง

        USART_Print("Vout=");
        USART_PrintNum((int32_t)(v_out * 1000));
        USART_Print(" mV  Vin~");
        USART_PrintNum((int32_t)(v_in * 1000));
        USART_Print(" mV\r\n");

        Delay_Ms(500);
    }
}

🔍 OPAMP_ConfigNonInverting(pos, neg) ระบุ channel เอง — gain ตั้งด้วย R ภายนอก (ไม่ใช่ register) — OPAMP_CalculateGainNonInv(r1, r2) คืนค่า 1 + R2/R1 ใช้ในโค้ดเพื่อคิด voltage เข้าจริงจาก output

ขั้นที่ 3: Inverting Amplifier

// วงจร: Output → R2 → CHN0(−),  Input → R1 → CHN0(−),  CHP0(+) → reference
//       Gain = -(R2/R1)

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);
    ADC_SimpleInit();

    OPAMP_ConfigInverting(OPAMP_CHP0, OPAMP_CHN0);
    OPAMP_Enable();

    uint32_t r1 = 10000;  // 10 kΩ (input)
    uint32_t r2 = 20000;  // 20 kΩ (feedback)
    float gain = OPAMP_CalculateGainInv(r1, r2);  // คืน -(R2/R1) = -2.0

    while(1) {
        float v_out = ADC_ReadVoltage(ADC_CH_7, 3.3f);
        // Inverting: v_out = -gain_mag * v_in  → ต้อง bias ที่ reference ก่อน
        USART_Print("Vout=");
        USART_PrintNum((int32_t)(v_out * 1000));
        USART_Print(" mV (gain ");
        USART_PrintNum((int32_t)(gain * 10));
        USART_Print(")\r\n");

        Delay_Ms(500);
    }
}

🔍 OPAMP_ConfigInverting(pos, neg) กลับเฟสสัญญาณ — OPAMP_CalculateGainInv(r1, r2) คืนค่าติดลบ -(R2/R1) — ในทางปฏิบัติต้อง bias ที่ขา CHP0 ให้อยู่กลาง range (เช่น VDD/2) เพื่อให้ output ไม่ติดลบ rail

ขั้นที่ 4: Comparator

// วงจร: สัญญาณ → CHP0(+),  threshold → CHN0(−)
//       output = HIGH เมื่อ V+ > V−,  LOW เมื่อ V+ < V−

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);
    pinMode(PC0, PIN_MODE_OUTPUT);  // LED status

    OPAMP_ConfigComparator(OPAMP_CHP0, OPAMP_CHN0);
    OPAMP_Enable();

    while(1) {
        // Comparator output อ่านผ่าน ADC ch7: ~0V = LOW, ~VDD = HIGH
        uint16_t raw = ADC_Read(ADC_CH_7);
        uint8_t  high = (raw > 512);

        digitalWrite(PC0, high ? HIGH : LOW);

        USART_Print(high ? "V+ > V-  (HIGH)\r\n" : "V+ < V-  (LOW)\r\n");
        Delay_Ms(100);
    }
}

🔍 OPAMP_ConfigComparator(pos, neg) ทำงานแบบ open-loop — output swing เกือบเต็ม rail ทำให้สามารถอ่านผ่าน ADC ได้แบบ digital (ค่าใกล้ 0 หรือใกล้ 1023)

ขั้นที่ 5: OPAMP + SimpleADC (อ่าน output)

// รวม OPAMP กับ SimpleADC เป็น signal chain เดียว

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);
    ADC_SimpleInit();          // เปิด ADC (no-arg)

    OPAMP_SimpleInit(OPAMP_MODE_VOLTAGE_FOLLOWER);
    OPAMP_Enable();

    while(1) {
        // วิธีที่ 1: อ่าน raw แล้วแปลงเอง
        uint16_t raw = ADC_Read(ADC_CH_7);
        float v1 = ADC_ToVoltage(raw, 3.3f);

        // วิธีที่ 2: อ่านและแปลงเป็น voltage ทีเดียว
        float v2 = ADC_ReadVoltage(ADC_CH_7, 3.3f);

        // วิธีที่ 3: อ่านแบบเฉลี่ยเพื่อลด noise
        uint16_t avg = ADC_ReadAverage(ADC_CH_7, 8);

        USART_Print("raw=");
        USART_PrintNum(raw);
        USART_Print(" avg=");
        USART_PrintNum(avg);
        USART_Print(" V=");
        USART_PrintNum((int32_t)(v2 * 1000));
        USART_Print(" mV\r\n");

        Delay_Ms(500);
    }
}

🔍 OPAMP output ต่อภายในกับ ADC ch7 — ใช้ SimpleADC API ทั้ง ADC_SimpleInit(), ADC_Read(), ADC_ReadVoltage() และ ADC_ReadAverage() ได้เลย โดยไม่ต้องตั้งค่า pin เพิ่ม

ขั้นที่ 6: สลับโหมด + ประหยัดไฟ + ตรวจสถานะ

// Advanced Control: เปลี่ยน mode ขณะทำงาน + ปิดเพื่อประหยัดไฟ

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);
    ADC_SimpleInit();

    // เริ่มต้นด้วย Voltage Follower
    OPAMP_SimpleInit(OPAMP_MODE_VOLTAGE_FOLLOWER);
    OPAMP_Enable();

    uint8_t stage = 0;

    while(1) {
        if (OPAMP_IsEnabled()) {
            float v = ADC_ReadVoltage(ADC_CH_7, 3.3f);
            USART_Print("stage ");
            USART_PrintNum(stage);
            USART_Print("  V=");
            USART_PrintNum((int32_t)(v * 1000));
            USART_Print(" mV\r\n");
        }

        Delay_Ms(2000);
        stage++;

        // สลับโหมดระหว่างทำงาน (OPAMP จะถูก disable ชั่วคราวระหว่างเปลี่ยน)
        if (stage == 1) {
            OPAMP_SetMode(OPAMP_MODE_NON_INVERTING);
        } else if (stage == 2) {
            OPAMP_SetMode(OPAMP_MODE_COMPARATOR);
        } else {
            // เสร็จงาน → ปิดประหยัดไฟ
            OPAMP_Disable();
            USART_Print("OPAMP disabled (sleep)\r\n");
            while(1) { Delay_Ms(1000); }
        }
    }
}

🔍 OPAMP_SetMode(mode) เปลี่ยน mode ขณะทำงาน — OPAMP_IsEnabled() คืน 1/0 ใช้ตรวจสถานะก่อนอ่าน ADC — OPAMP_Disable() (no-arg) ปิด OPAMP เพื่อประหยัดไฟในระบบ battery-powered

⚠️ ข้อผิดพลาดที่พบบ่อย

ปัญหาสาเหตุวิธีแก้
OPAMP output เป็น 0V ตลอดลืมเรียก OPAMP_Enable() หลัง initต้องเรียก OPAMP_Enable() (no-arg) เสมอหลัง OPAMP_SimpleInit() หรือ OPAMP_ConfigXXX()
Output ติดเพดาน (clipping ที่ VDD หรือ 0V)gain สูงเกิน ทำให้ output เกิน swing rangeลด gain R2/R1 ให้ Vin × gain ไม่เกิน VDD−0.1V — ใช้ OPAMP_CalculateGainNonInv() ช่วยคำนวณก่อน
Compile error: undeclared identifier (ชื่อ channel/mode ปลอม เช่น CH1, MODE_FOLLOWER, MODE_PGA)ใช้ชื่อ enum ปลอมที่ไม่มีใน header จริงเปลี่ยนเป็นชื่อจริง: OPAMP_MODE_VOLTAGE_FOLLOWER + channel OPAMP_CHP0/CHN0
Compile error: too many arguments to OPAMP_Enable()เรียก OPAMP_Enable(ch) ทั้งที่จริงเป็น no-argเรียก OPAMP_Enable() ไม่ต้องส่ง channel (OPAMP มีตัวเดียว)
Compile error: OPAMP_SimpleInit รับ 2 argsเรียก OPAMP_SimpleInit(ch, mode) ทั้งที่จริงรับ mode เดียวเรียก OPAMP_SimpleInit(mode) — ถ้าต้องการเลือก channel ใช้ OPAMP_Init(pos, neg) แทน
สัญญาณ noise มากไม่ได้ต่อ decoupling cap หรือ PCB layout ไม่ดีต่อ 100nF cap ใกล้ VDD pin — แยก analog ground — ใช้ ADC_ReadAverage() เฉลี่ยค่าหลายครั้ง
Non-Inverting output ไม่ตรง gainโหลด R ภายนอกไม่ตรงค่า / หรือ offset voltage (~5mV typ)ใช้ OPAMP_CalculateGainNonInv(r1, r2) ตรวจค่า R — calibrate offset ใน software โดยวัด output เมื่อ input = 0V

✏️ ลองทำดู

  1. Buffer เซ็นเซอร์ + อ่าน ADC: ใช้ OPAMP เป็น Voltage Follower ให้เซ็นเซอร์ที่มี output impedance สูง (เช่น piezo, pH probe) แล้วอ่านค่าด้วย ADC_ReadVoltage(ADC_CH_7, 3.3f) แสดงเป็น mV ผ่าน USART
  2. Comparator สั่ง LED: ใช้ OPAMP_ConfigComparator(OPAMP_CHP0, OPAMP_CHN0) เปรียบเทียบสัญญาณกับ threshold — อ่าน output ที่ ADC ch7 — ถ้าค่าเกินกึ่งกลางให้ติด LED ที่ PC0 ดับถ้าต่ำกว่า
  3. ขยายสัญญาณเสียง/noise เล็ก: ใช้ OPAMP_ConfigNonInverting(OPAMP_CHP0, OPAMP_CHN0) ขยายสัญญาณจาก mic หรือ noise ที่ประมาณไว้ — คำนวณ R1/R2 ด้วย OPAMP_CalculateR2NonInv(r1, desired_gain) ให้ได้ gain ที่เหมาะสม แล้วอ่านค่า ADC แสดงผล
