ULN2003 เป็น Darlington array ขับกระแสสูง — ต่อ MCU 4 GPIO เข้ากับ IN1–IN4 — ใช้ไฟ 5V เลี้ยงมอเตอร์ (ห้ามใช้ 3.3V) — 28BYJ-48 มี gear ratio 1:64, stride angle 5.625°, 2048 steps/rev (full-step)

รู้จักขา

  • IN1–IN4: ขาควบคุม线圈 4 เฟสของ ULN2003
  • VCC (ULN2003): จ่ายไฟ 5V ให้ driver และมอเตอร์
  • GND: Ground ร่วม
  • OUT1–OUT4: ขาต่อขดลวดของ 28BYJ-48

วิธีต่อทีละขั้น

  1. ต่อ IN1–IN4 ของ ULN2003 ไป GPIO (PC0–PC3) — ส่ง step sequence
  2. ต่อ VCC ของ ULN2003 ไป 5V และ GND ไป GND — จ่ายไฟ
  3. เสียบ 28BYJ-48 เข้ากับ ขา OUT1–OUT4 — ต่อตรงขั้วต่อ 5-pin

📚 หลักการทำงาน

28BYJ-48 เป็น unipolar stepper motor ราคาถูก — ใช้ไฟ 5V, กินกระแส ~240mA ต่อเฟส, gearbox 1:64 — ในโหมด Full-Step (4 steps/cycle) หมุน 1 รอบ = 2048 steps, Half-Step (8 steps/cycle) = 4096 steps/rev — ความละเอียดสูงกว่า 2 เท่าแต่แรงบิดลด

Step Sequence: Full-step ใช้ coil activation pattern 4 state: A→AB→B→BC→C→CD→D→DA — สลับขั้ว coil เพื่อดึง rotor หมุนทีละ step — Half-Step เพิ่ม state กลางอีก 4 state รวมเป็น 8

Speed Control: StepperMotor_SetSpeed(&st, rpm) ตั้งความเร็วรอบ — ไลบรารีจัดการ delay ระหว่างขั้นตอนอัตโนมัติ — ความเร็วสูงสุด ~10 RPM ที่ 5V — เกินกว่านี้มอเตอร์จะ missed step

Acceleration: เริ่มจาก speed ต่ำ (หมุนช้า) แล้วค่อยเพิ่ม — ป้องกัน missed step และมอเตอร์กระตุก

💻 เขียน Code ทีละขั้น

ขั้นที่ 1: สร้าง Instance + Init

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "StepperMotor.h"

StepperMotor_Instance st;

int main(void) {
    SystemCoreClockUpdate();

    // Init ULN2003: IN1=PC0, IN2=PC1, IN3=PC2, IN4=PC3, 2048 steps/rev
    StepperMotor_InitULN2003(&st, PC0, PC1, PC2, PC3, 2048);

🔍 StepperMotor_InitULN2003(&st, in1, in2, in3, in4, stepsPerRev) — ใช้ instance-based — 2048 steps/rev สำหรับ 28BYJ-48 full-step — ไลบรารีจัดการ GPIO sequence อัตโนมัติ

ขั้นที่ 2: ตั้งความเร็ว + เคลื่อนที่

    // ตั้งความเร็ว
    StepperMotor_SetSpeed(&st, 5);  // 5 RPM

    // เคลื่อนที่ 2048 steps (1 รอบ full-step)
    StepperMotor_Move(&st, 2048);
    Delay_Ms(1000);

    // หมุนกลับ
    StepperMotor_Move(&st, -2048);

    // เคลื่อนที่เป็นองศา
    StepperMotor_MoveDegrees(&st, 90);   // หมุน 90 องศา
    Delay_Ms(500);
    StepperMotor_MoveDegrees(&st, -90);  // หมุนกลับ

🔍 StepperMotor_SetSpeed(&st, rpm) ตั้งความเร็ว — StepperMotor_Move(&st, steps) เคลื่อนที่ n steps (blocking) — StepperMotor_MoveDegrees(&st, deg) เคลื่อนที่เป็นองศา — ค่าติดลบ = กลับทิศ

ขั้นที่ 3: Loop วนไปกลับ

    while(1) {
        // หมุน 1 รอบ
        StepperMotor_Move(&st, 2048);
        Delay_Ms(1000);

        // หมุนกลับ 1 รอบ
        StepperMotor_Move(&st, -2048);
        Delay_Ms(1000);
    }
}

🔍 วนไปกลับ 1 รอบ — Delay_Ms ระหว่างรอบเพื่อให้ motor หยุด — StepperMotor_Move เป็น blocking — 1 รอบ = 2048 steps (full-step), ~4096 steps (half-step)

⚠️ ข้อผิดพลาดที่พบบ่อย

ปัญหาสาเหตุวิธีแก้
มอเตอร์สั่นแต่ไม่หมุนลำดับ pin ผิดตรวจสอบลำดับ pin: IN1,IN2,IN3,IN4 — ต้องตรงกับ ULN2003
มอเตอร์หมุนช้ามากตั้ง speed ต่ำเกินใช้ SetSpeed 5-10 RPM — 28BYJ-48 max ~10 RPM ที่ 5V
Missed steps — เสียงดังติ๊กSpeed สูงเกินไป (เร็วไป)ลด speed ลง — เริ่มที่ 5 RPM — เพิ่มทีละ 1
แรงบิดไม่พอ — ไม่สามารถหมุนโหลดใช้ 3.3V เลี้ยงมอเตอร์28BYJ-48 ต้องใช้ 5V — ตรวจสอบ ULN2003 VCC ต่อเข้ากับ 5V
ร้อนมากเมื่อหยุดนิ่งStop() ปล่อย coil — แต่ถ้าต้องการ hold torqueใช้ Stop() เพื่อปล่อย coil — หรือใช้ฟังก์ชัน hold ในไลบรารี

🛠️ สร้าง Product: Programmable Stepper Positioner

หมุน stepper ไปตำแหน่งองศาที่ต้องการ — ใช้ Potentiometer ตั้งองศา + ปุ่มกด start

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "StepperMotor.h"

StepperMotor_Instance st;
int32_t current_pos = 0;  // in steps

int main(void) {
    SystemCoreClockUpdate();
    ADC_Init_Single(PA1);
    pinMode(PC4, PIN_MODE_INPUT_PULLUP);  // Start button

    StepperMotor_InitULN2003(&st, PC0, PC1, PC2, PC3, 2048);
    StepperMotor_SetSpeed(&st, 5);

    while(1) {
        if(!digitalRead(PC4)) {  // กดปุ่ม
            uint16_t adc = ADC_Read(PA1);
            int32_t target_deg = (int32_t)(adc * 360 / 4095);
            int32_t target_steps = (int32_t)(target_deg * 2048 / 360);
            int32_t delta = target_steps - current_pos;
            StepperMotor_Move(&st, delta);
            current_pos = target_steps;
            Delay_Ms(200); // debounce
        }
    }
}

✏️ ลองทำดู

  1. ทำ Microstepping ด้วย Software — สร้าง PWM บน coil เพื่อให้หมุนละเอียดกว่า half-step
  2. เพิ่ม Endstop Switch — ใช้ limit switch + home sequence ให้ stepper กลับตำแหน่ง 0 ทุกครั้งที่เปิดเครื่อง
  3. ทำ 3-Axis CNC Plotter ขนาดเล็ก — ใช้ stepper 3 ตัว + servo ยกปากกา — วาดรูปจาก G-code ง่าย ๆ
