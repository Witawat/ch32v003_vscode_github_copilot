DS3231 มี TCXO (Temperature Compensated Crystal Oscillator) ในตัว — แม่น ±2ppm (ผิดไม่เกิน 1 นาทีต่อปี), ต่อ battery backup CR2032 เพื่อให้เวลาเดินต่อแม้ไฟหลักดับ, I2C address 0x68 (fixed)

📚 หลักการทำงาน

DS3231 เป็น RTC (Real-Time Clock) แบบ I2C — แม่นยำสูงเพราะมี TCXO ในตัวชดเชยอุณหภูมิ, เก็บวินาที-นาที-ชั่วโมง-วัน-เดือน-ปี (BCD format), จัดการ leap year อัตโนมัติถึงปี 2100

2 Alarms: Alarm 1 ตั้งได้ละเอียดถึงวินาที, Alarm 2 ตั้งได้ถึงนาที — เมื่อ alarm ตรงจะ set flag และสามารถขับ SQW pin เป็น LOW เพื่อ wake up MCU

Temperature Sensor: DS3231 มี temperature sensor ในตัว (±3°C) — อ่านได้ผ่าน register 0x11-0x12 — ใช้ตรวจสอบอุณหภูมิแวดล้อมและ TCXO compensation

SQW Output: สร้าง square wave ความถี่ 1Hz, 1.024kHz, 4.096kHz, 8.192kHz — ใช้เป็น interrupt ให้ MCU อ่านเวลาทุก 1 วินาทีได้

💻 เขียน Code ทีละขั้น

ขั้นที่ 1: Init + ตั้งเวลาเริ่มต้น

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "DS3231.h"

int main(void) {
    SystemCoreClockUpdate();
    I2C_Init(I2C1, I2C_SPEED_STANDARD);
    DS3231_Init(I2C1);  // addr 0x68 fixed
    USART_Init(USART1, BAUD_115200);

    // ตั้งเวลา (ทำครั้งเดียว หรือเมื่อเปลี่ยน battery)
    // DS3231_SetTime(14, 30, 0);  // 14:30:00
    // DS3231_SetDate(15, 6, 2025); // 15 Jun 2025
    USART_Println("DS3231 RTC Ready!");

🔍 DS3231_Init(I2C1) — I2C address 0x68 fixed, DS3231_SetTime() และ DS3231_SetDate() — ตั้งค่าเริ่มต้น หลังจากนั้นแบตเตอรี่จะรักษาเวลาไว้

ขั้นที่ 2: อ่านเวลา + ตั้ง Alarm

    RTC_Time tm;
    DS3231_GetTime(&tm);  // อ่านเวลาปัจจุบัน
    USART_Print("Time: ");
    USART_PrintInt(tm.hour); USART_Print(":");
    USART_PrintInt(tm.min);  USART_Print(":");
    USART_PrintInt(tm.sec);  USART_Println("");

    // ตั้ง Alarm 1: ทุกวัน 08:00:00
    DS3231_SetAlarm1(DS3231_ALARM1_EVERYDAY, 8, 0, 0);
    // ตั้ง Alarm 2: ทุกนาทีที่ 30
    DS3231_SetAlarm2(DS3231_ALARM2_PERMINUTE, 0, 30);

🔍 DS3231_GetTime(&tm) — อ่านเวลาเป็น struct, DS3231_SetAlarm1(mode, hr, min, sec) — mode: EVERYDAY, DATE, PER SECOND/MINUTE/HOUR

ขั้นที่ 3: Loop — แสดงผล + ตรวจสอบ Alarm

    while(1) {
        DS3231_GetTime(&tm);
        USART_PrintInt(tm.hour); USART_Print(":");
        USART_PrintInt(tm.min);  USART_Print(":");
        USART_PrintInt(tm.sec);
        USART_Print(" | ");
        USART_PrintInt(tm.day); USART_Print("/");
        USART_PrintInt(tm.month); USART_Print("/");
        USART_PrintInt(tm.year); USART_Println("");

        // เช็ค Alarm
        if(DS3231_AlarmFired(1)) {
            USART_Println("ALARM 1 FIRED!");
            digitalToggle(PC0);  // blink LED
            DS3231_ClearAlarm(1);
        }

        // อ่านอุณหภูมิจาก DS3231
        float temp = DS3231_ReadTemp();
        USART_Print("Temp: "); USART_PrintFloat(temp, 1);
        USART_Println(" C");

        Delay_Ms(1000);
    }
}

🔍 DS3231_AlarmFired(n) — เช็ค flag alarm 1 หรือ 2, DS3231_ClearAlarm(n) — ล้าง flag หลัง alarm fired (ไม่งั้นจะ fired ตลอด), DS3231_ReadTemp() — อ่านอุณหภูมิภายในชิป (±3°C)

⚠️ ข้อผิดพลาดที่พบบ่อย

ปัญหาสาเหตุวิธีแก้
เวลารีเซ็ตทุกครั้งที่เปิดไฟไม่มี battery backup หรือ battery หมดต่อ CR2032 ที่ขา BAT — ไม่งั้นเวลาเริ่ม 00:00:00 ทุกครั้ง
อ่านเวลาได้ 0x00 หรือ 0xFFOscillator หยุด (OSF bit set)เช็ค DS3231_IsOscillatorStopped(), ตั้งเวลาใหม่เพื่อ clear OSF
เวลาเพี้ยนเร็ว/ช้าAging crystal หรืออุณหภูมิสุดขั้วDS3231 TCXO ชดเชยอัตโนมัติ — ถ้ายังเพี้ยน >2ppm → ชิปเสีย
Alarm ไม่เคยดังAlarm flag ไม่ได้เคลียร์ หรือ SQW pin ไม่ได้ตั้งต้อง DS3231_ClearAlarm() หลัง alarm fired, เช็ค INTCN bit
I2C address ไม่เจอDS3231 address 0x68 fixed — ต่อผิดใช้ I2C scanner (I2C_Scan()) ยืนยัน address, เช็ค pull-up 4.7k

🛠️ สร้าง Product: Digital Alarm Clock

DS3231 RTC + USART display — แสดงเวลา อุณหภูมิ และตั้งปลุกได้

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "DS3231.h"

int main(void)
{
    SystemCoreClockUpdate();
    I2C_Init(I2C1, I2C_SPEED_STANDARD);
    DS3231_Init(I2C1);
    USART_Init(USART1, BAUD_115200);
    pinMode(PC0, PIN_MODE_OUTPUT);  // alarm LED

    DS3231_SetTime(12, 0, 0);      // 12:00:00
    DS3231_SetDate(1, 1, 2025);    // 1 Jan 2025
    DS3231_SetAlarm1(DS3231_ALARM1_EVERYDAY, 8, 0, 0);

    RTC_Time tm;
    Timer_t tmr_display;
    Start_Timer(&tmr_display, 1000, 1);

    while(1)
    {
        if(Is_Timer_Expired(&tmr_display)) {
            DS3231_GetTime(&tm);
            USART_PrintInt(tm.hour); USART_Print(":");
            USART_PrintInt(tm.min);  USART_Print(":");
            USART_PrintInt(tm.sec);  USART_Print(" | ");
            USART_PrintInt(tm.day);  USART_Print("/");
            USART_PrintInt(tm.month); USART_Print("/");
            USART_PrintInt(tm.year); USART_Print(" | ");
            float temp = DS3231_ReadTemp();
            USART_PrintFloat(temp, 1); USART_Println(" C");
        }

        if(DS3231_AlarmFired(1)) {
            digitalWrite(PC0, HIGH);    // LED ON
            USART_Println("*** ALARM ***");
            Delay_Ms(10000);             // ring 10s
            digitalWrite(PC0, LOW);     // LED OFF
            DS3231_ClearAlarm(1);
        }
    }
}

✏️ ลองทำดู

  1. ทำนาฬิกาจับเวลาถอยหลัง (countdown timer) — ตั้งเวลาเป้าหมาย → DS3231 อ่านเวลาปัจจุบัน → คำนวณเวลาคงเหลือ
  2. ทำ data logger พร้อม timestamp — บันทึกค่าเซนเซอร์ + เวลาจาก DS3231 ลง EEPROM หรือ SPI Flash
  3. ใช้ SQW 1Hz interrupt — ตั้ง SQW output → ต่อกับ EXTI pin → interrupt ทุก 1 วินาที → อ่านเวลา
