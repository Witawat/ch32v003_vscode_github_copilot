Active Buzzer: ต่อ GPIO ขาไหนก็ได้ — Passive Buzzer: ต้องต่อกับขา PWM (PC4=TIM1_CH4 หรือ PC3=TIM1_CH3)

📚 หลักการทำงาน

Active Buzzer: มี oscillator ในตัว — ต่อไฟ DC ก็ดังที่ความถี่คงที่ (ปกติ ~2.3kHz) — ใช้ Buzzer_Beep() กำหนดระยะเวลาดัง

Passive Buzzer: เหมือนลำโพงเล็กๆ — ต้องสร้างสัญญาณ PWM/square wave — เลือกความถี่ได้ตั้งแต่ 20Hz-20kHz — ใช้ Buzzer_Tone() เล่นโน้ตและทำนอง

วิธีแยก Active vs Passive: ต่อไฟ DC — Active ดัง, Passive เงียบ (ได้ยินแค่ click ตอนต่อไฟ) — หรือวัดความต้านทาน: Active ~16-32Ω, Passive ~8Ω

CH32V003 Pin Current Limit: GPIO จ่ายได้ ~8mA/pin — Buzzer กิน ~30mA → ต้องใช้ทรานซิสเตอร์ (NPN: BC547/2N2222) หรือ MOSFET

Piezo vs Magnetic: Piezo buzzer ใช้ voltage drive (อิมพีแดนซ์สูง), Magnetic buzzer ใช้ current drive (อิมพีแดนซ์ต่ำ) — เลือก transistor ให้เหมาะ

💻 เขียน Code ทีละขั้น

ขั้นที่ 1: Init + Setup

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "Buzzer.h"

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();

    // Active Buzzer — ต่อ PC0
    Buzzer_Init(PC0, BUZZER_ACTIVE);

    // Passive Buzzer — ต่อ PC4 (ต้องเป็น PWM pin!)
    Buzzer_Init(PC4, BUZZER_PASSIVE);

    USART_Println("Buzzer Ready!");

🔍 Buzzer_Init(pin, type) — type เป็น BUZZER_ACTIVE (GPIO) หรือ BUZZER_PASSIVE (PWM — ต้องต่อขา PWM), Passive ใช้ TIM1_CH4 (PC4) หรือ TIM1_CH3 (PC3)

ขั้นที่ 2: Active Beep + Passive Tone

    // Active Buzzer — ดัง 200ms, เงียบ 500ms (SOS pattern)
    Buzzer_Beep(PC0, 200);    // ดัง 200ms
    Delay_Ms(200);
    Buzzer_Beep(PC0, 200);    // ดัง 200ms
    Delay_Ms(200);
    Buzzer_Beep(PC0, 200);    // ดัง 200ms
    Delay_Ms(500);

    // Passive Buzzer — เล่น tone 1kHz 500ms
    Buzzer_Tone(PC4, 1000, 500);   // 1kHz, 500ms
    Delay_Ms(200);
    Buzzer_Tone(PC4, 2000, 300);   // 2kHz, 300ms
    Delay_Ms(200);

    // หยุดเสียง
    Buzzer_NoTone(PC4);

🔍 Buzzer_Beep(pin, ms) ใช้กับ Active — ดังตามเวลาที่กำหนดแล้วเงียบเอง, Buzzer_Tone(pin, freq, ms) ใช้กับ Passive — เลือกความถี่ได้ (Hz), Buzzer_NoTone(pin) หยุดเสียงทันที

ขั้นที่ 3: Melody + Non-Blocking Loop

    // Melody — เล่น C Major Scale (C4-C5)
    uint16_t notes[] = {262,294,330,349,392,440,494,523};
    uint16_t durations[] = {200,200,200,200,300,300,300,400};
    Buzzer_Melody(PC4, notes, durations, 8);

    Timer_t tmr;
    Start_Timer(&tmr, 3000, 1);

    while(1) {
        if(Is_Timer_Expired(&tmr)) {
            // เล่น melody ซ้ำทุก 3 วิ
            Buzzer_Melody(PC4, notes, durations, 8);
        }
        IWDG_Feed();
    }
}

🔍 Buzzer_Melody(pin, notes, dur, len) เล่นอาเรย์ของโน้ต — แต่ละโน้ตใช้ความถี่ Hz, durations ใช้ ms, len คือจำนวนโน้ต — melody เล่นแบบ blocking

⚠️ ข้อผิดพลาดที่พบบ่อย

ปัญหาสาเหตุวิธีแก้
Active buzzer เสียงเบาหรือไม่ดังเลยGPIO จ่ายกระแสไม่พอ — CH32V003 max 8mA แต่ buzzer กิน ~30mAใช้ NPN transistor (BC547/2N2222) — GPIO → base (ผ่าน R 1kΩ), collector → buzzer, emitter → GND
Passive buzzer ไม่ดัง — ได้ยินแต่ clickต่อผิดขา — Passive ต้องต่อกับ PWM pin (PC4/PC3)ต่อ PC4 (TIM1_CH4) หรือ PC3 (TIM1_CH3) — ถ้าต่อขาอื่น PWM ไม่ทำงาน
ใช้ BUZZER_ACTIVE กับ Passive buzzer → ดังเสียงเดียวสลับ type ตอน Init — Passive ไม่มี oscillator ในตัวเปลี่ยน Buzzer_Init(pin, BUZZER_PASSIVE) — แล้วใช้ Buzzer_Tone() แทน Buzzer_Beep()
Melody เล่นแล้ว loop ค้างBuzzer_Melody() เป็น blocking — ใช้ Delay_Ms() ระหว่างโน้ตใช้ Task scheduler หรือ state machine ถ้าต้องการ non-blocking melody — แยกโน้ตทีละตัวด้วย Timer_t
Volume ไม่เปลี่ยนเมื่อเรียก SetVolumeSetVolume() เปลี่ยนแค่ PWM duty — ไม่มีผลกับ Active buzzerActive buzzer ไม่สามารถปรับ volume ได้ด้วย PWM — ต้องใช้ digital pot หรือ voltage divider

🛠️ สร้าง Product: กริ่งประตู + เล่นทำนอง

Passive buzzer + ปุ่มกด — กดปุ่มแล้วเล่นทำนอง Happy Birthday

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "Buzzer.h"

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();

    Buzzer_Init(PC4, BUZZER_PASSIVE);
    pinMode(PC0, PIN_MODE_INPUT_PULLUP);  // ปุ่มกด

    uint16_t melody[] = {
        262,262,294,262,349,330,
        262,262,294,262,392,349,
        262,262,523,440,349,330,294,
        466,466,440,349,392,349
    };
    uint16_t dur[] = {
        300,150,400,400,400,800,
        300,150,400,400,400,800,
        300,150,400,400,400,400,400,
        300,150,400,400,400,800
    };

    while(1) {
        if(digitalRead(PC0) == LOW) {      // กดปุ่ม (Active Low)
            Buzzer_Melody(PC4, melody, dur, 25);
            Delay_Ms(500);                  // debounce
        }
        IWDG_Feed();
    }
}

✏️ ลองทำดู

  1. ทำไฟเลี้ยวรถ — LED กระพริบ + Buzzer ดังพร้อมกัน (Non-Blocking ทั้งคู่ — LED toggle ทุก 500ms, Buzzer beep ทุก 1s)
  2. สร้าง Piano 4 ปุ่ม — 4 ปุ่ม → 4 โน้ต (C D E F) — กดปุ่ มแล้ว Passive buzzer เล่นโน้ตนั้นด้วย Buzzer_Tone()
  3. ทำ Alarm 3 ระดับ — เขียว: active beep สั้น 100ms, เหลือง: active beep ยาว 500ms, แดง: passive tone 2kHz ต่อเนื่อง
  4. เปรียบเทียบ Active vs Passive — ต่อทั้ง 2 ตัว (PC0=Active, PC4=Passive) แล้วทดสอบ API ต่างกัน
