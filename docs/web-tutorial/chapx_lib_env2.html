BH1750 — เซนเซอร์วัดแสงโดยรอบ (I2C)

3.3V─VCC  GND─GND  PC1─SDA  PC2─SCL  (ADDR─GND = 0x23, ADDR─VCC = 0x5C)
MCU Pin→อุปกรณ์ขาหมายเหตุ
PC1↔BH1750SDAI2C data
PC2→BH1750SCLI2C clock
3.3V→BH1750VCCจ่ายไฟ 3.3V
GND↔BH1750GNDกราวด์ร่วม
ADDR→BH1750ADDRต่อ GND = 0x23, VCC = 0x5C
 
#include "BH1750.h"
BH1750_Init(0x23, BH1750_CONT_HIRES);  // 1lx resolution
uint16_t lux = BH1750_ReadLux();
USART_Print("Light: "); USART_PrintNum(lux); USART_Print(" lx");

// โหมดอื่น:
// BH1750_CONT_HIRES2  — 0.5lx (ละเอียดขึ้น, วัดนานขึ้น)
// BH1750_ONETIME_HIRES — วัดครั้งเดียวแล้ว sleep (ประหยัดไฟ)

⚠️ 2 address: ADDR=GND → 0x23, ADDR=VCC → 0x5C — ต่อ 2 ตัวบน I2C เดียวได้, mode หลัก: CONT_HIRES (ต่อเนื่อง 1lx), HIRES2 (0.5lx), range 1-65535lx (กลางแจ้ง ~10,000-25,000lx), ไม่ต้อง calibrate — ค่า factory-calibrated, I2C speed สูงสุด 400kHz

API หลัก

BH1750_Init(addr, mode)Init + เลือกโหมดBH1750_ReadLux()อ่านค่าแสง (lux)
BH1750_SetMode(mode)เปลี่ยนโหมดระหว่างทำงานBH1750_PowerDown()Sleep (ประหยัดไฟ)

TCS34725 — RGB Color Sensor (I2C)

3.3V─VCC  GND─GND  PC1─SDA  PC2─SCL  (LED pin — optional, built-in white LED)
MCU Pin→อุปกรณ์ขาหมายเหตุ
PC1↔TCS34725SDAI2C data
PC2→TCS34725SCLI2C clock
3.3V→TCS34725VCCจ่ายไฟ 3.3V
GND↔TCS34725GNDกราวด์ร่วม
LED→TCS34725LEDควบคุม built-in white LED
 
#include "TCS34725.h"
TCS34725_Init(0x29, TCS34725_GAIN_1X, TCS34725_INTEG_24MS);
uint16_t r, g, b, c;
TCS34725_GetRawData(&r, &g, &b, &c);
float lux = TCS34725_CalcLux(r, g, b);          // แสงโดยรอบ
uint16_t ct = TCS34725_CalcColorTemp(r, g, b);  // อุณหภูมิสี (K)

// เปิด LED built-in (ตาไม่กระพริบ):
TCS34725_SetLED(1);  // 1=ON, 0=OFF
// ปรับ gain: TCS34725_GAIN_1X / 4X / 16X / 60X
// ปรับ integration: TCS34725_INTEG_24MS / 50MS / 101MS / 154MS / 700MS

⚠️ I2C addr 0x29 (fix), gain 1x/4x/16x/60x — gain สูง = ไวแสงขึ้นแต่ noise เพิ่ม, integration time 2.4ms-700ms — นานขึ้น = ความแม่นยำสูงขึ้นแต่ช้าลง, dark reading → ลบค่า baseline หากอ่านในที่มืด, ค่า c = clear channel (ไม่มี IR filter), การ classify สี → ใช้ HSV จาก RGB หรือ threshold แต่ละ channel

API หลัก

TCS34725_Init(addr, gain, integ)Init + set gain & integrationTCS34725_GetRawData(&r,&g,&b,&c)อ่าน raw 4 channel
TCS34725_CalcLux(r,g,b)คำนวณแสงโดยรอบTCS34725_CalcColorTemp(r,g,b)คำนวณอุณหภูมิสี (K)
TCS34725_SetLED(state)เปิด/ปิด LED ในตัวTCS34725_SetGain(g)เปลี่ยน gain

MQGas — MQ-2/3/5/7/135 Gas Sensor (ADC)

5V─VCC  GND─GND  PC4(AIN2)─AO  (R 10kΩ load — บนโมดูลมีแล้ว)
MCU Pin→อุปกรณ์ขาหมายเหตุ
PC4←MQ Gas SensorAOAnalog output (ADC)
5V→MQ Gas SensorVCCจ่ายไฟ 5V (heater ~800mW)
GND↔MQ Gas SensorGNDกราวด์ร่วม
 
#include "MQGas.h"
MQGas_Init(ADC_CH_PC4, MQ2);   // MQ2/MQ3/MQ5/MQ7/MQ135
MQGas_Calibrate();              // ★ ในอากาศสะอาด — หาค่า Ro
Delay_Ms(100);
float ppm = MQGas_ReadPPM();    // อ่านค่า gas concentration

// Raw ADC: uint16_t raw = MQGas_ReadRaw();
// PPM = a * (Rs/Ro)^b — curve parameter ฝังตาม gas type

// เปลี่ยน gas type:
MQGas_SetType(MQ135);  // เปลี่ยนระหว่าง MQ2→MQ135 (re-calibrate ด้วย)

⚠️ ต้อง preheat 24-48 ชั่วโมงครั้งแรก! — สร้าง stable oxide layer บน sensing element, calibration ในอากาศสะอาด (Rs/Ro ≈ 1 → PPM ≈ 0), Rs/Ro ratio → PPM ใช้ curve ที่ฝังใน Lib, sensitivity curve แตกต่างตาม gas type (MQ-2: LPG+smoke, MQ-3: alcohol, MQ-5: LPG+CH4, MQ-7: CO, MQ-135: NH3+benzene), อายุการใช้งาน ~5 ปี — sensitivity ลดลงเรื่อยๆ, ใช้ไฟ 5V — heater กิน ~800mW

API หลัก

MQGas_Init(ch, type)Init ADC + gas typeMQGas_Calibrate() calibrate Ro ในอากาศสะอาด
MQGas_ReadPPM()อ่าน gas concentrationMQGas_ReadRaw()อ่าน ADC raw
MQGas_SetType(type)เปลี่ยน gas typeMQGas_GetRo()อ่านค่า Ro ที่ calibrate ไว้

PMS5003 — PM2.5/PM10 Particle Sensor (USART)

5V─VCC  GND─GND  PD5(TX)─RX(PMS)  PD6(RX)─TX(PMS)
MCU Pin→อุปกรณ์ขาหมายเหตุ
PD5→PMS5003RXUSART TX → device RX
PD6←PMS5003TXUSART RX ← device TX
5V→PMS5003VCCจ่ายไฟ 5V
GND↔PMS5003GNDกราวด์ร่วม
 
#include "PMS5003.h"
PMS5003_Init(USART1);             // ใช้ USART1, baud 9600
PMS5003_SetMode(PMS5003_MODE_ACTIVE);  // Auto-send ทุก ~1s

PMS5003_Data_t data;
if(PMS5003_Read(&data)) {         // ★ checksum ผ่าน
    USART_Print("PM1.0:"); USART_PrintNum(data.pm1_0);
    USART_Print(" PM2.5:"); USART_PrintNum(data.pm2_5);
    USART_Print(" PM10:");  USART_PrintNum(data.pm10);
    // data.pm1_0_env, data.pm2_5_env — atmospheric (ไม่ใช่標準)
}

// Passive mode — request-read (ประหยัดไฟ):
PMS5003_SetMode(PMS5003_MODE_PASSIVE);
PMS5003_RequestRead();
Delay_Ms(1000);
PMS5003_Read(&data);

⚠️ 32-byte frame — checksum validation ป้องกันข้อมูลเสีย, active mode = auto send ทุก ~1s (ค่าต่อเนื่อง), passive mode = request-read (manual control), ต้องตั้ง USART baud 9600, fan life ~8,000 ชั่วโมง — ต้อง clean ทุก 3-6 เดือน (ฝุ่นสะสมในเลเซอร์), PM1.0/PM2.5/PM10 — 3 ค่าในเฟรมเดียว, USART เดียวของ CH32V003 — แชร์กับ debug print ไม่ได้

API หลัก

PMS5003_Init(uart)Init USART 9600PMS5003_SetMode(mode)ACTIVE/PASSIVE/SLEEP
PMS5003_Read(&data)อ่าน frame (คืน 1=OK)PMS5003_RequestRead()Request ใน passive mode
PMS5003_Sleep()Sleep (หยุดพัดลม)PMS5003_Wakeup()Wake up (30s stable)

NTC10K — Thermistor วัดอุณหภูมิ (ADC)

3.3V─NTC─PC4(AIN2)─R10kΩ─GND  (voltage divider — วัดแรงดันคร่อม R_fixed)
MCU Pin→อุปกรณ์ขาหมายเหตุ
PC4←NTC 10kΩ + R 10kΩVoltage divider midpointADC แรงดันคร่อม R_fixed
3.3V→NTC 10kΩVCC (ผ่าน NTC)จ่ายไฟ voltage divider
GND↔R 10kΩGNDกราวด์ร่วม
 
#include "NTC10K.h"
NTC10K_Init(ADC_CH_PC4, 10000.0f);  // R_fixed = 10kΩ
float temp = NTC10K_ReadCelsius();

// Steinhart-Hart equation (ฝังใน Lib):
// 1/T = A + B*ln(R) + C*(ln(R))^3
// A, B, C — coefficients for Beta 3950 NTC

// Averaging noise (10 samples):
float temps[10]; float sum = 0;
for(int i=0;i<10;i++) { temps[i]=NTC10K_ReadCelsius(); sum+=temps[i]; }
float avg = sum / 10.0f;

⚠️ A/B/C coefficients ฝังใน Lib → Beta 3950, accuracy ±0.5°C (หลัง calibrate 1 จุด), self-heating → ใช้ R_fixed สูง (100kΩ) ลดกระแส, voltage divider: Vout = VCC * R_fixed/(R_ntc+R_fixed) — ADC อ่านด้าน R_fixed, noise → averaging 10-20 samples, NTC ตอบสนองช้ากว่า DS18B20 (~1-2s)

API หลัก

NTC10K_Init(ch, r_fixed)Init ADC + ค่า R fixedNTC10K_ReadCelsius()อ่าน temp (°C)
NTC10K_ReadResistance()อ่าน R_ntc (Ω)NTC10K_SetBeta(beta)เปลี่ยนค่า Beta

Buzzer — Active + Passive (GPIO/PWM)

PC0─Buzzer(+)  GND─Buzzer(-)  (Active: transistor optional ถ้า curr > 20mA)
MCU Pin→อุปกรณ์ขาหมายเหตุ
PC0 / PC4→Buzzer+ (Signal)Active: GPIO, Passive: PWM
GND↔Buzzer−กราวด์ร่วม
 
#include "Buzzer.h"

// === Active Buzzer (มี oscillator ในตัว — ต่อไฟก็ดัง) ===
Buzzer_Init(PC0, BUZZER_ACTIVE);
Buzzer_Beep(PC0, 200);     // ดัง 200ms
Delay_Ms(500);
Buzzer_Beep(PC0, 500);     // ดัง 500ms (pattern: SOS)

// === Passive Buzzer (ต้อง PWM — เลือกความถี่ได้) ===
Buzzer_Init(PC4, BUZZER_PASSIVE);
Buzzer_Tone(PC4, 1000, 500);  // 1kHz, 500ms
Delay_Ms(200);
Buzzer_Tone(PC4, 2000, 300);  // 2kHz, 300ms

// Melody — เล่นเพลงง่ายๆ
uint16_t notes[] = {262,294,330,349,392,440,494,523};  // C4-C5
uint16_t dur[]   = {200,200,200,200,300,300,300,400};
for(int i = 0; i < 8; i++) {
    Buzzer_Tone(PC4, notes[i], dur[i]);
    Delay_Ms(50);
}

⚠️ Active buzzer = มี oscillator ในตัว (ต่อไฟ DC ก็ดังที่ความถี่คงที่), Passive buzzer = ต้องสร้าง PWM/tone (เลือกความถี่ได้ — เล่นทำนอง), กระแส ~30mA → ใช้ transistor ถ้า pin MCU จ่ายไม่พอ (CH32V003 max 8mA/pin), piezo vs magnetic — impedance ต่างกัน (piezo ใช้ voltage drive, magnetic ใช้ current drive), passive ต้องต่อกับ PWM pin (PC4=TIM1_CH4, PC3=TIM1_CH3)

API หลัก

Buzzer_Init(pin, type)Init active/passiveBuzzer_Beep(pin, ms)Active: ดัง ms มิลลิวินาที
Buzzer_Tone(pin, freq, ms)Passive: เล่นความถี่ (Hz)Buzzer_Stop(pin)หยุดเสียง
Buzzer_Melody(pin, notes, dur, len)เล่น melody arrayBuzzer_SetVolume(level)ปรับ volume (PWM duty)

✏️ ลองทำดู

  1. BH1750 + LED — ทำไฟกลางคืนอัตโนมัติ: เมื่อ lux < 50 → เปิด LED, lux > 100 → ปิด LED (hysteresis)
  2. TCS34725 แยกสี M&Ms — อ่าน RGB → classify เป็น "แดง" / "เขียว" / "น้ำเงิน" / "เหลือง" → นับจำนวน
  3. MQ-2 smoke alarm — เมื่อ PPM > threshold → LED กระพริบ + Buzzer ดัง (ทดสอบด้วยควันจากหัวแร้ง/ไฟแช็ก)
  4. PMS5003 + OLED — real-time air quality dashboard แสดง PM1.0/PM2.5/PM10 + AQI index
  5. NTC10K + DS18B20 — เปรียบเทียบ accuracy ระหว่าง thermistor (analog) vs digital sensor — วัดของเหลวอุณหภูมิเดียวกัน
  6. รวม 3 module: BH1750 + MQ-2 + Buzzer — ระบบเตือนภัยห้องครัว (dark + gas → alarm)
