ESP01 (ESP8266) — WiFi (USART)

PD5(TX)─RX(ESP01)  PD6(RX)─TX(ESP01)  3.3V─VCC+CH_PD  GND─GND+GPIO0
⚠️ ESP01 กินไฟ 300mA peak → ใช้ external 3.3V regulator (AMS1117-3.3, 500mA+)

รู้จักขา

  • TX (PD5): ส่งข้อมูล USART ไป RX ของ ESP01
  • RX (PD6): รับข้อมูล USART จาก TX ของ ESP01
  • VCC + CH_PD (3.3V): จ่ายไฟ 3.3V ผ่าน regulator แยก 500mA+
  • GND + GPIO0: กราวด์ร่วม (GPIO0 LOW = flash mode)

วิธีต่อทีละขั้น

  1. ต่อ PD5 ไป RX ของ ESP01 — ส่งคำสั่ง AT
  2. ต่อ PD6 ไป TX ของ ESP01 — รับ response
  3. ต่อ 3.3V จาก regulator ไป VCC + CH_PD
  4. ต่อ GND ร่วม
MCU Pin→อุปกรณ์ขาหมายเหตุ
PD5→ESP01RXUSART TX → device RX
PD6←ESP01TXUSART RX ← device TX
3.3V→ESP01VCC + CH_PDExternal 3.3V regulator 500mA+
GND↔ESP01GND + GPIO0กราวด์ร่วม
 
#include "ESP01.h"
ESP01_Handle wifi;
ESP01_Init(&wifi, USART1, BAUD_115200);
ESP01_Reset(&wifi); Delay_Ms(2000);
ESP01_JoinAP(&wifi, "SSID", "PASSWORD");
// HTTP GET:
ESP01_TCPConnect( "api.thingspeak.com", "/update?api_key=XXX&field1=25", 80);
// TCP:
ESP01_ConnectTCP(&wifi, "192.168.1.100", 8080);
ESP01_Send(&wifi, "hello");
// Check connection:
if(ESP01_IsConnected(&wifi)) ESP01_GetIP(&wifi);

⚠️ ESP01 กินไฟ 300mA peak → ต้องมี 3.3V regulator แยก (AMS1117-3.3, 500mA+), CH_PD ต้อง HIGH, GPIO0 LOW = flash mode / GPIO2 HIGH = normal, firmware AT v1.7+, ใช้ CPU ประมวลผล AT responses (~100ms), heap 36KB บน ESP, 3.3V เท่านั้น ห้ามต่อ 5V — ESP01 ไม่ทน 5V, voltage divider 5V→3.3V บน RX ของ ESP01 (ถ้า CH32V003 เป็น 5V)

API หลัก

ESP01_Init(&h, usart, baud)Init USART + test ATESP01_Reset(&h)Hardware reset
ESP01_JoinAP(&h, ssid, pass)เชื่อม WiFiESP01_TCPConnect(&h, host, port)TCP เชื่อมต่อ
ESP01_ConnectTCP(&h, ip, port)เปิด TCP connectionESP01_Send(&h, data)ส่งข้อมูลผ่าน TCP
ESP01_IsConnected(&h)เช็ค WiFi connectionESP01_GetIP(&h)อ่าน IP address

HC05 — Bluetooth (USART)

PD5(TX)─RX(HC05)  PD6(RX)─TX(HC05)  5V─VCC  GND─GND  EN─PC3 (HIGH=AT mode)
HC05 TX 3.3V OK → CH32V003 RX, CH32V003 TX 3.3V → HC05 RX OK

รู้จักขา

  • TX (PD5): ส่งข้อมูล USART ไป RX ของ HC05
  • RX (PD6): รับข้อมูล USART จาก TX ของ HC05
  • VCC (5V): จ่ายไฟ 5V
  • GND: กราวด์ร่วม
  • EN (PC3): HIGH = AT mode, LOW = data mode

วิธีต่อทีละขั้น

  1. ต่อ PD5 ไป RX ของ HC05 — ส่งข้อมูล
  2. ต่อ PD6 ไป TX ของ HC05 — รับข้อมูล
  3. ต่อ 5V ไป VCC และ GND ไป GND
  4. ต่อ PC3 ไป EN — ควบคุม AT mode
MCU Pin→อุปกรณ์ขาหมายเหตุ
PD5→HC05RXUSART TX → device RX
PD6←HC05TXUSART RX ← device TX
5V→HC05VCCจ่ายไฟ 5V
GND↔HC05GNDกราวด์ร่วม
PC3→HC05ENHIGH = AT mode, LOW = data mode
 
#include "HC05.h"
HC05_Handle bt;
HC05_Init(&bt, USART1, BAUD_38400);
// AT Mode (EN=HIGH):
HC05_ATMode(&bt, 1);
HC05_SendAT(&bt, "AT+NAME=MyCH32V003\r\n");
HC05_SendAT(&bt, "AT+PSWD=1234\r\n");
HC05_SendAT(&bt, "AT+ROLE=0\r\n"); // 0=slave
HC05_ATMode(&bt, 0); // back to data mode
// Data Mode (EN=LOW or floating):
while(1) {
    if(HC05_Available(&bt)) { char c = HC05_Read(&bt); USART_WriteByte(c); }
    if(USART_Available()) { char c = USART_Read(); HC05_Write(&bt, c); }
}

⚠️ default baud 38400 (HC05), AT mode: EN pin HIGH ก่อน power-on, baud=38400 8N1, pairing: ค้นหาจากมือถือ → ใส่รหัส 1234, HC05 TX 3.3V OK → CH32V003 RX รับได้, CH32V003 TX 3.3V → HC05 RX รับได้ (HC05 RX ทน 3.3V), โหมด master/slave เลือกด้วย AT+ROLE, range ~10m (class 2)

API หลัก

HC05_Init(&h, usart, baud)Init USARTHC05_ATMode(&h, en)สลับ AT/Data mode
HC05_SendAT(&h, cmd)ส่งคำสั่ง ATHC05_Available(&h)เช็คข้อมูลรอรับ
HC05_Read(&h)อ่าน 1 byteHC05_Write(&h, c)เขียน 1 byte
HC05_SetName(&h, name)ตั้งชื่อ BluetoothHC05_SetPin(&h, pin)ตั้งรหัส PIN

nRF24L01 — 2.4GHz Radio (SPI)

PC4─CSN  PC5─SCK  PC6─MOSI  PC7─MISO  PC3─CE  3.3V─VCC (ห้าม 5V!)
Decoupling 100nF ceramic ใกล้ขา VCC

รู้จักขา

  • CSN (PC4): เลือกชิป SPI
  • SCK (PC5): สัญญาณนาฬิกา SPI
  • MOSI (PC6): ส่งข้อมูลไป nRF24L01
  • MISO (PC7): รับข้อมูลจาก nRF24L01
  • CE (PC3): ควบคุมรับ/ส่ง
  • VCC (3.3V ONLY): จ่ายไฟ 3.3V เท่านั้น!
  • GND: กราวด์ร่วม

วิธีต่อทีละขั้น

  1. ต่อ PC4–PC7 ไป CSN, SCK, MOSI, MISO — SPI
  2. ต่อ PC3 ไป CE
  3. ต่อ 3.3V ONLY ไป VCC พร้อม capacitor 100nF
  4. ต่อ GND ร่วม
MCU Pin→อุปกรณ์ขาหมายเหตุ
PC4→nRF24L01CSNSPI chip select
PC5→nRF24L01SCKSPI clock
PC6→nRF24L01MOSISPI data in
PC7←nRF24L01MISOSPI data out
PC3→nRF24L01CEChip enable (RX/TX control)
3.3V→nRF24L01VCC3.3V ONLY — 100nF decoupling
GND↔nRF24L01GNDกราวด์ร่วม
 
#include "nRF24L01.h"
uint8_t tx_addr[] = {0xE7,0xE7,0xE7,0xE7,0xE7};
uint8_t rx_addr[] = {0xC2,0xC2,0xC2,0xC2,0xC2};
// === SENDER ===
nRF24_Init(PC4, PC3); // CSN, CE
nRF24_SetTxAddrtx_addr, 0x60); // RF channel 0x60
char msg[] = "Hello CH32V003";
nRF24_Transmit((uint8_t*)msg, sizeof(msg));
// === RECEIVER ===
nRF24_Init(PC4, PC3);
nRF24_SetRxAddrrx_addr, 0x60);
while(1) {
    if(nRF24_StartListening)) {
        char buf[32];
        nRF24_StartListening(uint8_t*)buf, 32);
        USART_Print("RX: "); USART_Println(buf);
    }
}

⚠️ 3.3V ONLY — 5V kills chip ทันที, 6 pipes (0-5) สำหรับ multi-node network, auto-ACK + auto-retransmit ใน TX mode, range ~50-100m (module +PA+LNA แบบมี antenna), address 5 bytes, RF channel 0-125 (2.4GHz + channel MHz), max payload 32 bytes, SPI max 10MHz, ต้องใช้ capacitor 100nF ใกล้ขา VCC ป้องกัน noise

API หลัก

nRF24_Init(csn, ce)Init SPI + confignRF24_SetTxAddraddr, ch)เข้าโหมดส่ง
nRF24_SetRxAddraddr, ch)เข้าโหมดรับnRF24_Transmit(buf, len)ส่ง packet
nRF24_StartListening)เช็คข้อมูลรอรับnRF24_StartListeningbuf, len)อ่าน packet
nRF24_SetChannel(ch)เปลี่ยน RF channelnRF24_SetPower(db)ตั้งกำลังส่ง (0/-6/-12/-18dBm)

GPS NEO6M — GPS Module (USART)

PD5(RX)─TX(GPS)  PD6(TX)─RX(GPS) optional  3.3-5V─VCC  GND─GND
ต้องมี active antenna — indoor = no signal

รู้จักขา

  • RX (PD5): รับข้อมูล USART จาก TX ของ GPS (NMEA)
  • TX (PD6): ส่งข้อมูลไป GPS (optional)
  • VCC (3.3–5V): จ่ายไฟ
  • GND: กราวด์ร่วม

วิธีต่อทีละขั้น

  1. ต่อ PD5 ไป TX ของ GPS — รับพิกัด
  2. ต่อ VCC กับไฟ 3.3V หรือ 5V
  3. ต่อ GND ร่วม
  4. ต่อ active antenna เข้า GPS module
MCU Pin→อุปกรณ์ขาหมายเหตุ
PD5←GPS NEO6MTXUSART RX ← device TX
PD6 (optional)→GPS NEO6MRXUSART TX → device RX (optional)
3.3–5V→GPS NEO6MVCCจ่ายไฟ 3.3–5V
GND↔GPS NEO6MGNDกราวด์ร่วม
 
#include "GPS.h"
GPS_Handle gps;
GPS_Init(&gps, USART1, BAUD_9600);
while(1) {
    GPS_Update(&gps); // process NMEA sentences
    if(GPS_HasFix(&gps)) {
        USART_Print("Lat:");  USART_PrintFloat(GPS_GetLatitude(&gps), 6);
        USART_Print(" Lon:"); USART_PrintFloat(GPS_GetLongitude(&gps), 6);
        USART_Print(" Alt:"); USART_PrintFloat(GPS_GetAltitude(&gps), 1);
        USART_Print(" Spd:"); USART_PrintFloat(GPS_GetSpeed(&gps), 1);
        USART_Println(" km/h");
        // Time: GPS_GetHour(&gps) / GetMin / GetSec
        // Date: GPS_GetDay(&gps) / GetMonth / GetYear
    }
}

⚠️ ต้องมี antenna (active or passive), cold start ~30s / hot start ~1s, NMEA sentences: GGA=fix data / RMC=min recommended, UBX protocol for advanced features (not supported), baud 9600 default, update rate 1Hz default, indoor = no signal (ต้อง outdoor เท่านั้น), GPS_Update() ต้องเรียกทุกรอบเพื่อ parse NMEA, GPS_HasFix() = satellite lock ≥3 ดวง

API หลัก

GPS_Init(&h, usart, baud)Init USART 9600GPS_Update(&h)Parse NMEA (ต้องเรียกบ่อย)
GPS_HasFix(&h)เช็คว่ามีสัญญาณหรือไม่GPS_GetLatitude(&h)ละติจูด (decimal degrees)
GPS_GetLongitude(&h)ลองจิจูดGPS_GetAltitude(&h)ความสูง (m)
GPS_GetSpeed(&h)ความเร็ว (km/h)GPS_GetSatellites(&h)จำนวนดาวเทียมที่เชื่อม

IR — Infrared Remote (GPIO)

PC0─OUT(IR receiver)  3.3V─VCC  GND─GND
ใช้ VS1838B หรือ TSOP38238 (38kHz carrier)

รู้จักขา

  • OUT (PC0): ขา output สัญญาณ IR ที่ demodulated แล้ว
  • VCC (3.3V): จ่ายไฟ 3.3V
  • GND: กราวด์ร่วม

วิธีต่อทีละขั้น

  1. ต่อ PC0 ไป OUT ของ IR receiver
  2. ต่อ 3.3V ไป VCC และ GND ไป GND
  3. ใช้ interrupt จับ timing ในโค้ด
MCU Pin→อุปกรณ์ขาหมายเหตุ
PC0←IR Receiver VS1838BOUTDemodulated IR signal
3.3V→IR Receiver VS1838BVCCจ่ายไฟ 3.3V
GND↔IR Receiver VS1838BGNDกราวด์ร่วม
 
#include "IR.h"
IR_Handle ir;
IR_Init(&ir, PC0);
while(1) {
    if(IR_Available(&ir)) {
        uint32_t code = IR_Read(&ir);
        USART_Print("IR code: 0x");
        USART_PrintHex(code, 8);
        USART_Println("");
        // NEC format: address(8bit) + ~address(8bit) + command(8bit) + ~command(8bit)
        uint8_t cmd = (code >> 8) & 0xFF;
        USART_Print("Command: "); USART_PrintNum(cmd); USART_Println("");
    }
}

⚠️ NEC protocol (ใช้มากที่สุด — รีโมท TV/Audio/DVD), VS1838B receiver (38kHz carrier), 9ms leading pulse + 4.5ms space, address+command+inverted bytes (32-bit total), timing: logic 0 = 562µs pulse + 562µs space / logic 1 = 562µs + 1687µs, repeat code = 9ms + 2.25ms (ไม่มี data), ใช้ GPIO interrupt จับ timing — แม่นกว่า polling

API หลัก

IR_Init(&h, pin)Init GPIO + interruptIR_Available(&h)เช็คมี code รอ
IR_Read(&h)อ่าน IR code (32-bit)IR_GetData()อ่าน decoded data struct
IR_Send(proto, addr, cmd)ส่ง IR codeIR_SendRepeat()ส่ง repeat code

SoftUART — Software Serial (GPIO)

PC0─TX(soft)  PC1─RX(soft)  (pin ไหนก็ได้ — software bit-bang)
ใช้เมื่อ USART1 ถูกใช้แล้ว → 1 USART HW + 1 SoftUART = 2 UART ports

รู้จักขา

  • TX (PC0): ขาส่งข้อมูล SoftUART (pin อะไรก็ได้)
  • RX (PC1): ขารับข้อมูล SoftUART (pin อะไรก็ได้)

วิธีต่อทีละขั้น

  1. เลือก PC0 เป็น TX ต่อกับ RX ของอุปกรณ์
  2. เลือก PC1 เป็น RX ต่อกับ TX ของอุปกรณ์
  3. ตั้ง baud rate ให้ตรงกันในโค้ด
MCU Pin→อุปกรณ์ขาหมายเหตุ
PC0 (pin ใดก็ได้)→SoftUARTTXSoftware bit-bang TX
PC1 (pin ใดก็ได้)←SoftUARTRXSoftware bit-bang RX
 
#include "SoftUART.h"
SoftUART_Handle suart;
SoftUART_Init(&suart, PC0, PC1, BAUD_9600); // TX, RX, baud
SoftUART_WriteString(&suart, "Hello from soft UART!\r\n");
SoftUART_Printf(&suart, "%d\r\n", 42);
// Receive (blocking with timeout — RX buffer เป็น known limitation):
uint8_t c;
while(1) {
    if(SoftUART_ReadByte(&suart, &c, 1000) == SOFTUART_OK) {  // timeout 1s
        SoftUART_WriteByte(&suart, c); // echo
    }
}

⚠️ software bit-bang → CPU intensive (ใช้ CPU 100% ขณะ send/receive), baud limit ~19200, ห้ามมี interrupt ขัดจังหวะตอน send/receive (เช่น TIM interrupt), ใช้เมื่อ USART1 ถูกใช้แล้ว, timing depends on SystemCoreClock accuracy, TX pin idle = LOW → HIGH, 1 USART HW + 1 SoftUART = 2 UART ports บน CH32V003, เหมาะกับ debug print ระหว่างที่ USART1 คุยกับ ESP01/HC05

API หลัก

SoftUART_Init(&h, tx, rx, baud)Init GPIO + timerSoftUART_WriteString(&h, str)ส่ง string
SoftUART_Printf(&h, fmt, ...)ส่ง formatted (เลข ฯลฯ)SoftUART_WriteByte(&h, c)ส่ง 1 byte
SoftUART_ReadByte(&h, &data, timeout_ms)อ่าน 1 byte (blocking+timeout)SoftUART_Available(&h)เช็คข้อมูลรอรับ (⚠️ known limit)
SoftUART_Flush(&h)ล้าง buffer

✏️ ลองทำดู

  1. ESP01 IoT weather station — อ่าน BMP280 ทุก 30s → ส่งอุณหภูมิ+ความชื้นไป ThingSpeak (HTTP GET), แสดงค่าล่าสุดบน OLED
  2. nRF24L01 remote control — 2 บอร์ด CH32V003: transmitter ต่อ 4 ปุ่ม → receiver ขับ LED 4 ดวง, เช็ค lost connection (heartbeat ทุก 1s)
  3. GPS tracker — อ่าน GPS ทุก 10s → log lat/lon ลง W25Qxx Flash, กดปุ่ม → ดึงข้อมูลทั้งหมดออกทาง USART เป็น CSV
  4. IR universal remote — learn mode: กดรีโมท → เก็บ IR code ใน EEPROM, play mode: กดปุ่ม → replay IR code, รองรับ 10 ปุ่ม
  5. ESP01 + SoftUART combo — ESP01 บน SoftUART (PC0,PC1) สื่อสาร WiFi → USART1 ใช้เป็น debug console (Serial Monitor), bridge ข้อมูลระหว่าง ESP01 ↔ USART1
