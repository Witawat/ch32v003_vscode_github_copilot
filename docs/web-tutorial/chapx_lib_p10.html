P10 — LED Panel 32×16 GPIO

ระดับสูง

🧭 แผนภาพการทำงาน

flowchart TD
    A["P10_Init(6 pins)"] --> B["P10_Clear()"]
    B --> C["P10_SetCursor + P10_Print"]
    C --> D["TIM2 ISR (auto scan)"]
    D --> E["Row A/B select → Shift CLK → OE"]
    E --> D
    C --> F["while(1): อัปเดต buffer"]
    F --> C

🔌 การต่อวงจร

          P10 LED Panel 32x16 (1/4 scan)
    ┌────────────────────────────────┐
    │ MCU                   P10      │
    │ 5V (External 2A+) ─── VCC      │
    │ GND ──────────────── GND       │
    │ PC0 ──────────────── A (row)   │
    │ PC1 ──────────────── B (row)   │
    │ PC2 ──────────────── CLK       │
    │ PC3 ──────────────── SCLK (latch)
    │ PC4 ──────────────── R1 (data) │
    │ PC5 ──────────────── OE        │
    │ (CH32V003 3.3V logic → 5V P10)│
    └────────────────────────────────┘

P10 ต้องใช้ external 5V 2A+ จ่ายไฟ — CH32V003 ใช้ 3.3V logic ซึ่ง marginal แต่ใช้งานได้กับ P10 ส่วนใหญ่ — 6 GPIO ขาควบคุม

📚 หลักการทำงาน

Multiplexed LED Panel: P10 32×16 ใช้การสแกน 1/4 scan — แบ่งจอเป็น 4 แถว (A,B เลือก 00,01,10,11) — แต่ละแถวมี 32×4 LEDs — CPU ต้องส่งข้อมูล 32 คอลัมน์ต่อ 1 แถว แล้วเลื่อนไปแถวถัดไป — ทำซ้ำเร็วพอให้ตาเห็นเป็นภาพนิ่ง

TIM2 Auto Scan: P10_Init() ตั้ง TIM2 interrupt ให้ทำงานอัตโนมัติที่ ~2kHz — ISR ของ TIM2 จะวนสแกน 4 แถว — CLK shift ข้อมูลเข้า shift register — SCLK latch — OE เปิด LED ช่วงสั้นๆ

64-Byte Buffer: buffer ขนาด 32×16 = 64 ไบต์ — 1 ไบต์ = 8 pixels ในแนวตั้ง — การเปลี่ยนแปลงข้อมูลใน main loop จะถูกแสดงผลโดยอัตโนมัติผ่าน ISR — ไม่มี flicker เพราะ ISR ทำงานสม่ำเสมอ

5V Logic Challenge: CH32V003 output 3.3V — P10 รับ 5V logic — แรงดัน 3.3V มักพอให้ P10 ตีความเป็น HIGH — ถ้าไม่เวิร์กให้ใช้ level shifter 74HCT245

💻 เขียน Code ทีละขั้น

ขั้นที่ 1: Init + Setup

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "P10.h"

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();

    // P10_Init(CLK, R1, A, B, SCLK, OE)
    P10_Init(PC2, PC4, PC0, PC1, PC3, PC5);
    P10_Clear();

🔍 P10_Init() รับ 6 พารามิเตอร์ตามลำดับ — ฟังก์ชันตั้งค่า GPIO และ TIM2 interrupt โดยอัตโนมัติ — เมื่อ Init แล้ว P10 จะเริ่มสแกนอัตโนมัติใน background

ขั้นที่ 2: แสดงข้อความ

    P10_SetCursor(0, 0);
    P10_Print("Hello");
    P10_SetCursor(0, 8);
    P10_Print("P10");

    // วาดเส้นและรูปทรง
    P10_DrawLine(0, 15, 31, 0, 1);
    P10_DrawRect(2, 2, 28, 12, 1);

🔍 P10_SetCursor(row, col) — row 0-15, col 0-31 — Print() เขียนข้อความบน buffer — DrawLine, DrawRect วาดบน buffer — ข้อมูลจะแสดงบนจอทันทีผ่าน ISR

ขั้นที่ 3: Loop อัปเดตข้อความ

    Timer_t tmr;
    Start_Timer(&tmr, 1000, 1);
    uint8_t sec = 0;

    while(1) {
        if(Is_Timer_Expired(&tmr)) {
            P10_Clear();
            P10_SetCursor(0, 0);
            P10_PrintNum(sec);
            sec++;
        }
        // ไม่ต้องเรียก update — TIM2 ISR จัดการให้
    }
}

🔍 P10 auto-updates ผ่าน TIM2 ISR — main loop แค่เปลี่ยน buffer ก็พอ — Clear() ก่อนเขียนใหม่ — ไม่ต้องเรียก Display()

⚠️ ข้อผิดพลาดที่พบบ่อย

ปัญหาสาเหตุวิธีแก้
จอไม่มีไฟเลยP10 ต้องใช้ external 5V 2A+ — CH32V003 จ่ายเองไม่พอใช้ adapter 5V 2A ขึ้นไป — อย่าพึ่งไฟจาก MCU หรือ USB
ครึ่งจอดับ / บางแถวไม่ติดA/B pin ผิด — เลือกแถวไม่ถูกต้องตรวจสอบการต่อ A (PC0) และ B (PC1) — อาจสลับกัน
จอ flicker / กระพริบScan rate ต่ำ — TIM2 interrupt ไม่ทำงานตรวจสอบว่า SystemCoreClockUpdate() ถูกเรียกก่อน P10_Init()
CH32V003 3.3V logic กับ P10 5V3.3V อาจไม่พอให้ P10 ตีความเป็น HIGHMarginal แต่ใช้ได้กับ P10 ส่วนใหญ่ — ถ้าไม่เวิร์กใช้ 74HCT245 level shifter
ข้อความแสดงไม่ครบBuffer size 32×16 — ข้อความเกินจอจัดการ wrapping เอง หรือใช้ scrolling algorithm

🛠️ สร้าง Product: ป้ายแสดงเวลา+วันที่

P10 + DS3231 RTC — แสดงเวลาสลับกับวันที่ทุก 5 วินาที

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "P10.h"

RTC_DS3231_t rtc;

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    I2C_SimpleInit(I2C_SPEED_100K, I2C_PINS_DEFAULT);
    DS3231_Init(&rtc);

    P10_Init(PC2, PC4, PC0, PC1, PC3, PC5);
    P10_Clear();

    RTC_DateTime_t dt;
    Timer_t tmr;
    Start_Timer(&tmr, 1000, 1);

    while(1) {
        if(Is_Timer_Expired(&tmr)) {
            DS3231_GetDateTime(&rtc, &dt);
            P10_Clear();
            P10_SetCursor(0, 2);
            P10_PrintNumZero(&dt.hour, 2);
            P10_Print(":");
            P10_PrintNumZero(&dt.minute, 2);
            P10_Print(":");
            P10_PrintNumZero(&dt.second, 2);
        }
    }
}
