TJC HMI สื่อสารผ่าน USART 9600 baud — CH32V003 ใช้ PD5(TX)/PD6(RX) — ออกแบบ UI ด้วย TJC Editor บน PC แล้วโหลดลง SD card

📚 หลักการทำงาน

USART 9600 Baud Protocol: TJC ใช้ USART ที่ 9600 bps — โปรโตคอลเป็น text-based — ส่ง command ห่อด้วย 0xFF 3 ไบต์หน้า-หลัง — เช่น "page 0" เปลี่ยนหน้า, "t0.txt=\"Hello\"" เขียนข้อความ

Callback-Driven Architecture: TJC รับ event จากจอผ่าน USART RX — Library parse event แล้วเรียก callback ที่ลงทะเบียนไว้ — มี callback สำหรับ Touch, Numeric Input, Page Change, Command Result — ProcessResponse() ต้องถูกเรียกใน loop ตลอด

UI Design in TJC Editor: หน้าจอทั้งหมดออกแบบใน TJC Editor (PC software) — วางปุ่ม, ข้อความ, ตัวเลข, กราฟ — ตั้งชื่อ object (เช่น t0, b1, n0, p0) — Export เป็นไฟล์ .tft → โหลดลง SD card ใส่จอ — MCU ไมได้ render UI

MCU Role: MCU ส่ง command ควบคุมจอ (เปลี่ยนหน้า, เขียนข้อความ, อ่านค่า) — รับ event จากจอ (กดปุ่ม, เปลี่ยนค่า) — จอ render UI เองทั้งหมด — MCU แค่ประมวลผล logic และตอบสนอง event

💻 เขียน Code ทีละขั้น

ขั้นที่ 1: Init + Setup

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"

TJC_Handle_t hmi;
void OnTouch(uint8_t page, uint8_t id, uint8_t event) {
    if(page == 0 && id == 1) TJC_SendCommand(&hmi, "page 1");
}

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    USART_Init(USART1, BAUD_9600);
    TJC_Init(&hmi, USART1, BAUD_9600);
    TJC_RegisterTouchCallback(&hmi, OnTouch);
    TJC_SendCommand(&hmi, "page 0");

🔍 เริ่ม USART — TJC_Init(handle, usart, baud) — RegisterTouchCallback ลงทะเบียน callback — SendCommand ส่งคำสั่งเปลี่ยนหน้า

ขั้นที่ 2: ส่งข้อมูล + อ่านค่า

    TJC_SetText(&hmi, "t0", "Hello");
    TJC_SetValue(&hmi, "n0", 123);
    int32_t val = TJC_GetValue(&hmi, "n0");
    TJC_SendCommand(&hmi, "page 1");

🔍 SetText(obj, txt) เขียนข้อความ — SetValue(obj, n) ตั้งค่าตัวเลข — GetValue(obj) อ่านค่าจาก widget — SendCommand สำหรับคำสั่งที่ไม่มีฟังก์ชันสำเร็จ

ขั้นที่ 3: Loop + ProcessResponse

    while(1) {
        TJC_ProcessResponse(&hmi);
        // ทุกอย่างทำงานผ่าน callback
        // main loop ต้องวนเร็วพอ ≥ 100Hz
        Delay_Ms(5);
    }
}

🔍 ProcessResponse() ต้องถูกเรียกใน loop — มันอ่าน USART RX buffer — parse event — เรียก callback ที่เกี่ยวข้อง — delay น้อยๆ เพื่อให้ตอบสนองไว

⚠️ ข้อผิดพลาดที่พบบ่อย

ปัญหาสาเหตุวิธีแก้
จอไม่ตอบสนองเลยBaud rate ไม่ตรง — TJC default 9600ตรวจสอบ baud rate เป็น 9600 ทั้ง MCU และ TJC — เช็คใน TJC Editor
USART_Print ใช้ไม่ได้USART1 ถูก TJC แชร์ — ใช้ร่วมกันไม่ได้ใช้ USART2 (PD7/PD8) สำหรับ debug print — อย่าใช้ USART1 ซ้อน
ตัวหนังสือไทยไม่แสดงTJC ต้องใช้ font ที่มี glyph ไทยใน TJC Editor: เลือก font ที่รองรับไทย — ตั้ง encoding เป็น UTF-8
Touch callback ไม่ถูกเรียกไม่ได้เรียก ProcessResponse() หรือเรียกช้าเกินต้องเรียก ProcessResponse() ใน main loop ตลอด — แนะนำทุก 5-10ms
จอรับคำสั่งแต่ไม่เปลี่ยนชื่อ object ไม่ตรงกับใน TJC Editorตรวจสอบชื่อ object (t0, b1, n0) ตรงกับที่ตั้งใน TJC Editor

🛠️ สร้าง Product: Smart Home Dashboard

TJC HMI 2 หน้า — หน้า 1: แสดงอุณหภูมิ+ความชื้นจาก DHT11, หน้า 2: ตั้งค่า Threshold — ใช้ callback เปลี่ยนหน้าและปรับค่า

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"

TJC_Handle_t hmi;
DHT11_Data_t dht;
uint8_t temp_threshold = 30;

void OnTouch(uint8_t page, uint8_t id, uint8_t event) {
    if(event == 1) { // Press
        if(page == 0 && id == 1) TJC_SendCommand(&hmi, "page 1");
        if(page == 1 && id == 0) TJC_SendCommand(&hmi, "page 0");
    }
}
void OnNumeric(uint8_t id, int32_t val) {
    if(id == 0) temp_threshold = val;
}

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    DHT11_Init(PC3);
    USART_Init(USART1, BAUD_9600);
    TJC_Init(&hmi, USART1, BAUD_9600);
    TJC_RegisterTouchCallback(&hmi, OnTouch);
    TJC_RegisterNumericCallback(&hmi, OnNumeric);
    TJC_SendCommand(&hmi, "page 0");

    Timer_t tmr;
    Start_Timer(&tmr, 2000, 1);

    while(1) {
        TJC_ProcessResponse(&hmi);
        if(Is_Timer_Expired(&tmr)) {
            if(DHT11_Read(&dht) == DHT11_OK) {
                TJC_SetValue(&hmi, "n0", dht.temp);
                TJC_SetValue(&hmi, "n1", dht.hum);
            }
        }
        Delay_Ms(5);
    }
}
