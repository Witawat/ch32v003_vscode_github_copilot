🔌 การต่อวงจร

          TJC HMI Touch Display (USART)
    ┌────────────────────────────────┐
    │ MCU                      TJC   │
    │ 5V  ─────────────── VCC        │
    │ GND ─────────────── GND        │
    │ PD5 (TX) ───────── RX          │
    │ PD6 (RX) ───────── TX          │
    └────────────────────────────────┘
MCU Pin→อุปกรณ์ขาหมายเหตุ
5V↔TJC HMIVCCจ่ายไฟ 5V
GND↔TJC HMIGNDกราวด์ร่วม
PD5 (TX)→TJC HMIRXMCU→จอ
PD6 (RX)←TJC HMITXจอ→MCU

รู้จักขา

  • VCC: ไฟเลี้ยง 5V
  • GND: กราวด์
  • RX: รับข้อมูลจาก MCU — ต่อขา PD5 (TX) ของ MCU
  • TX: ส่งข้อมูลไป MCU — ต่อขา PD6 (RX) ของ MCU

วิธีต่อทีละขั้น

  1. ต่อ VCC TJC ไป 5V ของ MCU
  2. ต่อ GND TJC ไป GND ของ MCU
  3. ต่อ RX TJC ไปขา PD5 (TX) ของ MCU
  4. ต่อ TX TJC ไปขา PD6 (RX) ของ MCU

📚 หลักการทำงาน

TJC HMI สื่อสารผ่าน USART 9600 baud — TJC_Init() เริ่มต้น — TJC_SendCommand() ส่งคำสั่ง — TJC_ProcessResponse() ประมวลผล response — ไม่มี instance (global functions)

💻 เขียน Code ทีละขั้น

ขั้นที่ 1: Init + Setup

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "TJC.h"

void OnTouch(TJC_TouchEvent_t *event) {
    if(event->page_id == 0 && event->component_id == 1) TJC_SendCommand("page 1");
}

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    USART_Init(USART1, BAUD_9600);

    TJC_Init(BAUD_9600, USART_PINS_DEFAULT);
    TJC_RegisterTouchEventCallback(OnTouch);
    TJC_SendCommand("page 0");

🔍 TJC_Init(baud, pins) — ไม่มี instance, ใช้ global functions — USART_PINS_DEFAULT

ขั้นที่ 2: ส่งข้อมูล + อ่านค่า

    TJC_SendCommand("t0.txt=\"Hello\"");
    TJC_SendCommand("n0.val=123");
    TJC_RegisterNumericCallback(on_numeric);
    TJC_SendCommand("page 1");

🔍 TJC_SendCommand(cmd) — ส่ง raw command เช่น t0.txt="Hi" หรือ n0.val=123 — อ่านค่าจาก HMI ใช้ callback-based (RegisterNumericCallback) ไม่มี sync getValue — ต้อง register callback แล้วรอ event

ขั้นที่ 3: Loop + ProcessResponse

    while(1) {
        TJC_ProcessResponse();
        Delay_Ms(5);
    }
}

🔍 TJC_ProcessResponse() — ต้องเรียกใน loop — parse RX buffer — เรียก callback ที่เกี่ยวข้อง

⚠️ ข้อผิดพลาดที่พบบ่อย

🛠️ สร้าง Product: Smart Home Dashboard

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "TJC.h"

void OnTouch(TJC_TouchEvent_t *event) {
    if(event->event_type == 1) {
        if(event->page_id == 0 && event->component_id == 1) TJC_SendCommand("page 1");
        if(event->page_id == 1 && event->component_id == 0) TJC_SendCommand("page 0");
    }
}

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    USART_Init(USART1, BAUD_9600);

    TJC_Init(BAUD_9600, USART_PINS_DEFAULT);
    TJC_RegisterTouchEventCallback(OnTouch);
    TJC_SendCommand("page 0");

    while(1) {
        TJC_ProcessResponse();
        Delay_Ms(5);
    }
}
