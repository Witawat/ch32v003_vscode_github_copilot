ต่อ LED + R 220Ω แบบ Active-HIGH (HIGH = ติด, LOW = ดับ)
ต่อปุ่มกด + R 10kΩ Pull-up ภายนอก หรือใช้ PIN_MODE_INPUT_PULLUP

CH32V003 Pins: GPIOA (PA1-PA2), GPIOC (PC0-PC7), GPIOD (PD2-PD7) — PD0/PD1 มีเฉพาะ TSSOP-20/QFN-20

📚 หลักการทำงาน

CH32V003 มี 18 I/O pins (TSSOP-20), แบ่งเป็น 3 พอร์ท:

  • GPIOA — PA1, PA2 (PA1 รองรับ PWM)
  • GPIOC — PC0-PC7 (PC0, PC3-4 รองรับ PWM)
  • GPIOD — PD2-PD7 (ทุก pin รองรับ ADC, PD2-4,PD7 รองรับ PWM; PD0/PD1 = debug pins)

Pin แต่ละ pin มี output drive สูงสุด 8mA, รวมทั้ง MCU ไม่เกิน 120mA
โหมดที่ใช้บ่อย: PIN_MODE_OUTPUT (push-pull), PIN_MODE_INPUT_PULLUP (input + internal pull-up)

ขั้นที่ 2: ตั้งค่า Pin LED + Button

    pinMode(PC0, PIN_MODE_OUTPUT);       // LED
    pinMode(PC1, PIN_MODE_INPUT_PULLUP);  // Button (pull-up ภายใน)

🔍 PIN_MODE_INPUT_PULLUP ใช้ pull-up ภายใน (~40kΩ) ไม่ต้องต่อ R ภายนอก — ปุ่มกดต่อลง GND, ปกติอ่าน HIGH, กดแล้วอ่าน LOW (Active LOW)

ขั้นที่ 3: อ่านค่า + ควบคุม LED

    while(1) {
        uint8_t btn = digitalRead(PC1);
        digitalWrite(PC0, !btn);  // กด=LOW → LED=HIGH
        Delay_Ms(50);
    }
}

🔍 digitalRead() คืนค่า HIGH (1) หรือ LOW (0) — ใช้ ! เพื่อกลับค่า Active LOW

ขั้นที่ 4: Interrupt (ทางเลือก)

volatile uint32_t count = 0;
void btn_isr(void) { count++; }

    attachInterrupt(PC1, btn_isr, FALLING);
    while(1) {
        if(count) { digitalToggle(PC0); count = 0; }
    }

🔍 attachInterrupt(pin, callback, mode) — เรียก callback ทันทีเมื่อมีสัญญาณ (RISING/FALLING/CHANGE) ห้ามใช้ Delay ใน ISR!

⚠️ ข้อผิดพลาดที่พบบ่อย

ปัญหาสาเหตุวิธีแก้
ปุ่มกดอ่านค่าผิดตลอดไม่ได้ใช้ Pull-up (pin ลอย)ใช้ PIN_MODE_INPUT_PULLUP หรือต่อ R 10kΩ ภายนอกไป 3.3V
LED ไม่ติดเลยต่อ LED กลับขั้ว หรือไม่มี R จำกัดกระแสตรวจสอบขั้ว (แอโนด→R→MCU, แคโทด→GND) และใช้ R 220Ω
MCU รีเซ็ตตอนเปิด LEDดึงกระแสเกิน 8mA/pinเพิ่มค่าตัวต้านทาน ลด brightness หรือใช้ทรานซิสเตอร์ขับ
Interrupt ไม่ทำงานลืมตั้ง pinMode INPUT ก่อนต้อง pinMode(pin, PIN_MODE_INPUT_PULLUP) ก่อน attachInterrupt()
Pin not valid compile errorSOP-8 ไม่มี pin นั้นตรวจสอบ IS_VALID_PIN() macro สำหรับแพ็กเกจที่ใช้

🛠️ สร้าง Product: ไฟกระพริบ + ปุ่มกดเปลี่ยนโหมด

LED กระพริบ 3 โหมด: เร็ว / ปานกลาง / ช้า — เปลี่ยนด้วยปุ่มกด (Interrupt)

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"

volatile uint8_t mode = 0;
void btn_isr(void) {
    mode = (mode + 1) % 3;
}

int main(void)
{
    SystemCoreClockUpdate();
    Timer_Init();

    pinMode(PC0, PIN_MODE_OUTPUT);       // LED
    pinMode(PC1, PIN_MODE_INPUT_PULLUP); // Button
    attachInterrupt(PC1, btn_isr, FALLING);

    const uint16_t speeds[] = {100, 250, 500};

    while(1)
    {
        digitalToggle(PC0);
        Delay_Ms(speeds[mode]);
    }
}

✏️ ลองทำดู

  1. เพิ่ม LED ตัวที่ 2 ที่ PA1 — ติดเฉพาะเมื่อกดปุ่มค้าง (ไม่ใช่ toggle)
  2. ใช้ pulseIn() วัดระยะห่างของปุ่มกด 2 ครั้ง (double-click detector)
  3. ใช้ pinModeMultiple() ตั้ง LED 3 ดวง (PC0,PC1,PC2) เป็น output พร้อมกัน
