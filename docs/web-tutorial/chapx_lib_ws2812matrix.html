🔌 การต่อวงจร

          WS2812B 8x8 RGB Matrix
    ┌────────────────────────────────┐
    │ MCU                    Matrix  │
    │ 5V (External 2A+) ───── VCC    │
    │ GND ──────────────── GND      │
    │ PC0 ──[LEVEL SHIFT]── DIN     │
    │                                │
    │ ⚠️ Level Shifter Required!     │
    │ 64 LEDs × 60mA = ~3.8A max    │
    │ ต่อ 5V แยก — อย่าพึ่ง MCU!     │
    └────────────────────────────────┘

WS2812B 8×8 Matrix มี LED 64 ดวงเรียงแบบ Serpentine (S-curve) — ใช้ protocol เดียวกับ NeoPixel — ต้องต่อ 5V แยก ≥ 2A — Level Shifter จำเป็น

📚 หลักการทำงาน

Built-in Font Engine: WS2812Matrix มีระบบฟอนต์ 5×7 ในตัว — รองรับอักษร A-Z, 0-9 และสัญลักษณ์ — WS2812Matrix_Print() คล้าย OLED — มี SetCursor, Print, PrintChar — ฟอนต์ไทยผ่าน custom bitmap

Serpentine Mapping: 8×8 Matrix เรียง LED แบบซิกแซก (แถว 0 ซ้าย→ขวา, แถว 1 ขวา→ซ้าย, ...) — Library จัดการ mapping ภายใน — ระบุตำแหน่งด้วย (x, y) แบบ Cartesian ปกติ

Effects Engine: มี effect ในตัว — ScrollText (เลื่อนข้อความ), Sparkle (ระยิบระยับ), Rainbow (รุ้งวน), ColorWipe (กวาดสี) — ใช้ Non-Blocking state machine ในแต่ละ effect

Color Support: 24-bit RGB ต่อ LED — RGB(), HSV(), SetPixel(x, y, color) — 16.7 ล้านสี — แต่ละ LED กินกระแสสูงสุด 60mA (RGB full white)

💻 เขียน Code ทีละขั้น

ขั้นที่ 1: Init + Setup

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "WS2812Matrix.h"

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();

    WS2812Matrix_Init(PC0, 8, 8);   // DIN, width, height
    WS2812Matrix_SetBrightness(100);
    WS2812Matrix_Clear();
    WS2812Matrix_Show();

🔍 WS2812Matrix_Init(pin, w, h) — รองรับ matrix ขนาดต่างๆ — SetBrightness ปรับความสว่าง — Clear+Show ล้างหน้าจอ

ขั้นที่ 2: แสดงข้อความ + Effect

    // แสดงข้อความ
    WS2812Matrix_SetCursor(0, 0);
    WS2812Matrix_SetTextColor(RGB(255, 0, 0));  // Red
    WS2812Matrix_Print("HI");
    WS2812Matrix_Show();

    // Effect: Scroll Text
    WS2812Matrix_ScrollText("CH32V003", 150, RGB(0, 255, 0));

    // Effect: Rainbow
    WS2812Matrix_Rainbow(50);

    // Custom Bitmap
    WS2812Matrix_DrawBitmap(my_bitmap, 8, 8, RGB(255, 255, 0));

🔍 SetTextColor กำหนดสีข้อความ — ScrollText เลื่อนข้อความสีเขียว — Rainbow วิ่งรุ้ง — DrawBitmap รับ array 2D + สี

ขั้นที่ 3: Loop สลับ Effect

    Timer_t tmr;
    Start_Timer(&tmr, 5000, 1);
    uint8_t fx = 0;

    while(1) {
        if(Is_Timer_Expired(&tmr)) {
            WS2812Matrix_Clear();
            if(fx == 0) {
                WS2812Matrix_SetCursor(0, 0);
                WS2812Matrix_Print("1");
            } else if(fx == 1) {
                WS2812Matrix_ScrollText("HELLO", 100, RGB(0,255,0));
            } else {
                WS2812Matrix_Rainbow(30);
            }
            fx = (fx + 1) % 3;
        }
    }
}

🔍 สลับ 3 effect ทุก 5 วินาที — ScrollText ทำงานแบบ blocking ในตัวอย่าง (มี Non-Blocking variant ด้วย) — Rainbow ทำงานต่อเนื่อง

⚠️ ข้อผิดพลาดที่พบบ่อย

ปัญหาสาเหตุวิธีแก้
Matrix ไม่ติดเลยขาด Level Shifter — 3.3V logic ไม่พอใช้ 74HCT125 — หรือใช้โมดูลที่มี level shifter ในตัว
Matrix ติดบางส่วน สีผิดเพี้ยนไฟเลี้ยงไม่พอ — ต้องการ 5V ≥ 2Aใช้ external PSU 5V 2A+ — ต่อไฟเข้าขั้ว Matrix โดยตรง
ข้อความแสดงตำแหน่งผิดSerpentine mapping ไม่ตรงกับโมดูลตรวจสอบว่า library mapping ตรงกับโมดูล — บางตัวเริ่มมุมต่างกัน
สีจางเมื่อเปิดหลาย LEDVoltage drop — สายไฟเล็กเกินใช้สาย AWG 20-22 — ต่อ 5V + GND ทั้งด้านเข้าและออก
Effect กระตุกShow() ใช้เวลานานสำหรับ 64 LEDs64 LEDs = ~1.9ms — ใช้ Non-Blocking effect variant ที่มี state machine

🛠️ สร้าง Product: ป้ายไฟ RGB 3 Effect สลับ

8×8 Matrix แสดง 3 โหมด — Scroll Text → Rainbow → Sparkle — กดปุ่มเปลี่ยนโหมด

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "WS2812Matrix.h"

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    WS2812Matrix_Init(PC0, 8, 8);
    WS2812Matrix_SetBrightness(100);

    pinMode(PC3, PIN_MODE_INPUT_PULLUP);
    uint8_t mode = 0;
    Timer_t tmr;
    Start_Timer(&tmr, 1, 1);

    while(1) {
        if(digitalRead(PC3) == 0) {
            Delay_Ms(50);
            if(digitalRead(PC3) == 0) {
                mode = (mode + 1) % 3;
                while(digitalRead(PC3) == 0);
            }
        }

        switch(mode) {
            case 0: WS2812Matrix_ScrollText("HELLO", 150, RGB(0, 255, 0)); break;
            case 1: WS2812Matrix_Rainbow(30); break;
            case 2: WS2812Matrix_Sparkle(RGB(255, 255, 0), 10); break;
        }
    }
}
