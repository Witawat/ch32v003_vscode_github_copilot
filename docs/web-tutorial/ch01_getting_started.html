บทที่ 1: เริ่มต้นอย่างถูกต้อง — ระบบขั้นต่ำที่ใช้ได้

ระดับเริ่มต้น

🧭 แผนภาพการทำงาน

flowchart TD
    A["#define CH32V003_PACKAGE"] --> B["SystemCoreClockUpdate()"]
    B --> C["Timer_Init()"]
    C --> D["pinMode()"]
    D --> E["Loop วนไป"]
    E --> F["digitalWrite() + Delay_Ms()"]
    F --> E

🔌 การต่อวงจร

    CH32V003 (TSSOP-20)
    ┌─────┐
    │     │ PC0 ──┬──/\/\/\──┬──|LED|── GND
    │ MCU │         220Ω
    │     │
    │     │ VDD ──── 3.3V
    │     │ GND ──── GND
    └─────┘

บอร์ด CH32V003 ขั้นต่ำต้องการไฟ 3.3V, GND, และ LED ต่อผ่าน R 220Ω ที่ PC0

หมายเหตุ SOP-8: หากใช้ SOP-8 (CH32V003J4M6) ให้ใช้ PACKAGE_SOP8 และใช้ PC1 หรือ PA1 แทน PC0 (PC0 ไม่มีบน SOP-8)

📚 หลักการทำงาน

ทุกโปรแกรม CH32V003 ต้องเริ่มด้วย 3 ขั้นตอนพื้นฐาน:

  1. SystemCoreClockUpdate() — อัปเดตตัวแปรความถี่ระบบให้ถูกต้อง (ค่า default: HSI 48MHz) ต้องเรียกก่อนใช้ Delay หรือ USART
  2. Timer_Init() — ตั้งค่า SysTick ให้ทำงานที่ 1ms resolution (จำเป็นสำหรับ Delay_Ms(), Get_CurrentMs())
  3. pinMode() — ตั้งค่า pin เป็น Input/Output ก่อนใช้งานเสมอ

CH32V003_PACKAGE ต้องกำหนดก่อน #include "SimpleHAL.h" มิฉะนั้นจะ default เป็น TSSOP20 (มีคำเตือน)

💻 เขียน Code ทีละขั้น

ขั้นที่ 1: Include + เลือก Package

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"

🔍 CH32V003_PACKAGE บอกคอมไพเลอร์ว่าบอร์ดใช้แพ็กเกจไหน (SOP8, SOP16, TSSOP20, QFN20) ส่งผลต่อว่า pin ไหนใช้ได้บ้าง

ขั้นที่ 2: เริ่มต้นระบบ

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();

🔍 SystemCoreClockUpdate() อัปเดต SystemCoreClock จาก HSI 48MHz default Timer_Init() เปิด SysTick ที่ 1ms — ใช้โดยฟังก์ชัน Delay ทั้งหมด

ขั้นที่ 3: ตั้งค่า Pin + LED Blink

    pinMode(PC0, PIN_MODE_OUTPUT);
    while(1) {
        digitalWrite(PC0, HIGH);
        Delay_Ms(500);
        digitalWrite(PC0, LOW);
        Delay_Ms(500);
    }
}

🔍 pinMode(PC0, PIN_MODE_OUTPUT) ตั้ง PC0 เป็น output push-pull digitalWrite() เขียน HIGH/LOW ไปยัง pin Delay_Ms() หน่วงเวลาแบบ blocking (โปรแกรมหยุดรอตรงนั้นเลย)

📋 API Reference

ฟังก์ชันคำอธิบายตัวอย่าง
SystemCoreClockUpdate()อัปเดตตัวแปร SystemCoreClockเรียกก่อนใช้ Delay/USART
Timer_Init()เริ่มต้น SysTick 1msจำเป็นสำหรับ Delay_Ms()
pinMode(pin, mode)ตั้งโหมด pinpinMode(PC0, PIN_MODE_OUTPUT)
digitalWrite(pin, val)เขียน HIGH/LOW ไปยัง pindigitalWrite(PC0, HIGH)
Delay_Ms(ms)หน่วงเวลาแบบ blocking (ms)Delay_Ms(500)
Delay_Us(us)หน่วงเวลาแบบ blocking (μs)Delay_Us(100)

⚠️ ข้อผิดพลาดที่พบบ่อย

ปัญหาสาเหตุวิธีแก้
LED ไม่กระพริบ ไฟติดค้างลืมเรียก SystemCoreClockUpdate()เพิ่ม SystemCoreClockUpdate() บรรทัดแรกใน main()
Compile error: pin not validใช้ pin ที่ไม่มีใน SOP-8 แต่เลือก PACKAGE_TSSOP20ตรวจสอบว่า pin มีในแพ็กเกจที่เลือกหรือไม่
LED ติดแต่ไม่ดับลืมเขียน LOW หรือ Delay น้อยเกินตรวจสอบ digitalWrite(PC0, LOW) และ Delay_Ms()
warning CH32V003_PACKAGEไม่ได้กำหนด CH32V003_PACKAGEเพิ่ม #define CH32V003_PACKAGE PACKAGE_xxx ก่อน include

🛠️ สร้าง Product: LED กระพริบบนบอร์ดเปล่า

โปรเจกต์แรกสุด — ทำให้ LED กระพริบด้วย CH32V003 ขั้นต่ำ (MCU + LED + R 220Ω)

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"

int main(void)
{
    SystemCoreClockUpdate();
    Timer_Init();
    pinMode(PC0, PIN_MODE_OUTPUT);

    while(1)
    {
        digitalWrite(PC0, HIGH);
        Delay_Ms(250);
        digitalWrite(PC0, LOW);
        Delay_Ms(250);
    }
}

✏️ ลองทำดู

  1. เปลี่ยนความถี่กระพริบ LED จาก 250ms เป็น 100ms (2 รอบ/sec)
  2. เปลี่ยน pin LED จาก PC0 ไปเป็น PA1 แล้วทดสอบใหม่
  3. ถ้าคุณใช้ SOP-8 — แก้ #define CH32V003_PACKAGE เป็น PACKAGE_SOP8 แล้วเลือก pin ที่ใช้ได้ (PA1, PC1, PC2, PC4, PD6)
