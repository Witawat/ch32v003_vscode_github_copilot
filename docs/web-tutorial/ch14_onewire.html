รู้จักขา

  • PC0 (DQ): ขาข้อมูล 1-Wire — ต่อกับ DQ ของ DS18B20
  • R 4.7kΩ: ตัวต้านทาน Pull-up — ต่อจาก DQ ไป 3.3V (จำเป็น!)
  • VDD (DS18B20): ขาไฟเลี้ยง — ต่อ 3.3V

วิธีต่อทีละขั้น

  1. ต่อ R 4.7kΩ จาก PC0 ไป 3.3V — pull-up สำหรับ 1-Wire
  2. ต่อ PC0 ไป DQ (ขา 2) ของ DS18B20 — สายข้อมูล
  3. ต่อ 3.3V ไป VDD (ขา 3) ของ DS18B20 — จ่ายไฟ
  4. ต่อ GND ไป GND (ขา 1) ของ DS18B20 — กราวด์

Pull-up 4.7kΩ สำคัญมาก! — 1-Wire เป็น open-drain — ต้องมี pull-up เพื่อให้บัสกลับเป็น HIGH — ถ้าไม่มี pull-up บัสจะเป็น LOW ตลอด

📚 หลักการทำงาน

1-Wire — โปรโตคอลสื่อสารผ่าน 1 สาย data (+GND) — คิดค้นโดย Dallas Semiconductor (ปัจจุบันเป็นของ Maxim/Analog Devices)

SimpleHAL API รูปแบบ Bus Handle (ไม่ใช่ global)

ทุกฟังก์ชันใน Simple1Wire.h รับ OneWire_Bus* bus เป็นอาร์กิวเมนต์แรก — ไม่มี global state — ทำให้รองรับได้สูงสุด ONEWIRE_MAX_BUSES = 4 บัสพร้อมกัน ผู้ใช้ต้องเก็บ handle ที่ได้จาก OneWire_Init(pin) แล้วส่งต่อไปยังทุกฟังก์ชัน

Timing สำคัญ

  • Reset Pulse: Master ลาก LOW 480µs → ปล่อย → รอ 15-60µs → Slave ลาก LOW 60-240µs (Presence Pulse)
  • Write 1: Master ลาก LOW 1-15µs → ปล่อย
  • Write 0: Master ลาก LOW 60µs → ปล่อย
  • Read: Master ลาก LOW 1-15µs → ปล่อย → อ่านภายใน 15µs
  • Convert T: DS18B20 ใช้เวลา 750ms (12-bit) — ต้องรอให้เสร็จ!

DS18B20 Command Flow

  1. Reset → Presence
  2. ROM Command: Skip ROM (0xCC) — ถ้ามีตัวเดียว — หรือ Match ROM (0x55) — เลือกตัวใดตัวหนึ่ง
  3. Function Command: Convert T (0x44) — เริ่มวัด — หรือ Read Scratchpad (0xBE) — อ่านผล
  4. Data: อ่าน 9 bytes scratchpad — byte 0-1 = temperature, byte 8 = CRC8

CH32V003 ต้องใช้ Software Bit-Banging — ไม่มี hardware 1-Wire — ใช้ Delay_Us() ให้ตรง timing — SimpleHAL จัดการให้ภายในตัวฟังก์ชัน — และปิด interrupt ใน critical section เพื่อให้ timing ตรง

💻 เขียน Code ทีละขั้น

ขั้นที่ 1: Init OneWire — รับ Bus Handle

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"

#define OW_PIN PC0

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);

    // เริ่มต้น OneWire — รับ handle กลับมา (factory pattern)
    OneWire_Bus* bus = OneWire_Init(OW_PIN);
    if (bus == NULL) {
        USART_Print("ERROR: bus เต็ม (max 4) หรือ pin ผิด\r\n");
        while (1);
    }

🔍 OneWire_Init(pin) — คืน OneWire_Bus* (handle ของ bus instance) หรือ NULL ถ้า slot เต็ม (สูงสุด ONEWIRE_MAX_BUSES = 4) — ต้องเก็บ pointer นี้ไว้ แล้วส่งให้ทุกฟังก์ชัน OneWire_* ถัดไป — ภายในตั้ง pin เป็น open-drain พร้อม internal pull-up — แต่แนะนำให้ต่อ external 4.7kΩ pull-up ด้วยเพื่อความน่าเชื่อถือ

ขั้นที่ 2: ตรวจจับ DS18B20

    // ตรวจจับอุปกรณ์บนบัส — ต้องส่ง bus arg
    bool presence = OneWire_Reset(bus);

    if (presence) {
        USART_Print("DS18B20 detected!\r\n");
    } else {
        USART_Print("No device found on 1-Wire bus\r\n");
        USART_Print("Check wiring & pull-up resistor\r\n");
        while (1);  // หยุด — ไม่มีอะไรให้อ่าน
    }

🔍 OneWire_Reset(bus) — ส่ง reset pulse — คืน true ถ้ามีอุปกรณ์ตอบ presence pulse — คืน false ถ้าบัสว่างเปล่าหรือ short — ควรเรียกก่อนทุก transaction (ก่อนส่ง ROM command ทุกครั้ง)

ขั้นที่ 3: อ่านอุณหภูมิ (Single Device — ใช้ SkipROM)

    while (1) {
        // ——— Step 1: Start Conversion ———
        OneWire_Reset(bus);
        OneWire_SkipROM(bus);              // 0xCC — ข้าม ROM (มีตัวเดียว)
        OneWire_WriteByte(bus, 0x44);      // Convert T command

        // รอ conversion (~750ms for 12-bit)
        Delay_Ms(750);

        // ——— Step 2: Read Scratchpad ———
        OneWire_Reset(bus);
        OneWire_SkipROM(bus);
        OneWire_WriteByte(bus, 0xBE);      // Read Scratchpad

        // อ่าน 9 bytes scratchpad ทีเดียว
        uint8_t sp[9];
        OneWire_ReadBytes(bus, sp, 9);

        // ——— Step 3: ตรวจ CRC ก่อนใช้ ———
        if (!OneWire_VerifyCRC(sp, 9)) {
            USART_Print("CRC ERROR — data corrupt\r\n");
            continue;
        }

        // Temperature = byte0 | (byte1 << 8) — signed 16-bit, LSB = 1/16 C
        int16_t temp_raw = (int16_t)(sp[0] | (sp[1] << 8));
        float temp_c = temp_raw / 16.0f;

        USART_Print("Temperature: ");
        USART_PrintNum((int32_t)temp_c);
        USART_Print(".");
        int16_t dec = (int16_t)((temp_c - (int32_t)temp_c) * 10);
        if (dec < 0) dec = -dec;
        USART_PrintNum(dec);
        USART_Print(" C\r\n");

        Delay_Ms(1000);
    }

🔍 ทุกฟังก์ชันต้องส่ง bus เป็น arg แรก — OneWire_SkipROM(bus) ข้ามการระบุ ROM ID — ใช้เมื่อมีอุปกรณ์ตัวเดียวบนบัส — ถ้ามีหลายตัว — ห้ามใช้ SkipROM ตอนอ่าน! — OneWire_WriteByte(bus, data) ส่ง 1 byte — OneWire_ReadBytes(bus, buf, 9) อ่าน 9 bytes scratchpad ทีเดียว — OneWire_VerifyCRC(sp, 9) ตรวจ CRC ทั้ง 9 bytes (รวม CRC byte ท้ายสุด) — คืน true = CRC ถูก

ขั้นที่ 4: CRC สองทาง — VerifyCRC หรือ CRC8

    // ทางที่ 1: VerifyCRC — สะดวกสุด — len รวม CRC byte ท้ายสุด
    if (OneWire_VerifyCRC(sp, 9)) {
        // CRC ถูกต้อง
    }

    // ทางที่ 2: CRC8 — คำนวณ CRC ของ 8 bytes แรก แล้วเทียบกับ byte ที่ 9 (sp[8])
    uint8_t crc = OneWire_CRC8(sp, 8);  // ไม่ต้องส่ง bus (pure function)
    if (crc == sp[8]) {
        // CRC ถูกต้อง
    }

    // ตรวจ ROM ID ที่ได้จาก ReadROM ก็ได้เหมือนกัน — ROM มี 8 bytes (7 data + 1 CRC)
    uint8_t rom[8];
    if (OneWire_ReadROM(bus, rom) && OneWire_VerifyCRC(rom, 8)) {
        USART_Print("Family: 0x%02X\r\n", rom[0]);
    }

🔍 OneWire_CRC8(data, len) และ OneWire_VerifyCRC(data, len) เป็น pure function — ไม่รับ bus arg — polynomial Dallas/Maxim 0x8C — VerifyCRC คำนวณ CRC ของ len-1 bytes แรกแล้วเทียบกับ byte สุดท้าย — ใช้งานง่ายกว่า — CRC8 เหมาะตอนต้องการค่า CRC ดิบไปใช้ต่อ

ขั้นที่ 5: ROM Search Triad — หลายอุปกรณ์

Simple1Wire.h ไม่มี ฟังก์ชัน search ROM สำเร็จรูปที่คืน array ทีเดียว — ให้ใช้ triad ของสามฟังก์ชันแทน:

    // เก็บ ROM IDs แต่ละตัวเป็น uint8_t[8] — ไม่ใช่ uint64_t
    uint8_t roms[8][8];
    uint8_t count = 0;

    OneWire_ResetSearch(bus);                    // (1) เริ่ม search ใหม่
    while (OneWire_Search(bus) && count < 8) {    // (2) วนหาจนครบ
        OneWire_GetAddress(bus, roms[count]);     // (3) ดึง ROM 8 bytes ออกมา
        count++;
    }

    USART_Print("Found ");
    USART_PrintNum(count);
    USART_Print(" device(s)\r\n");

    for (uint8_t d = 0; d < count; d++) {
        USART_Print("Device ");
        USART_PrintNum(d);
        USART_Print(" ROM: ");
        for (int i = 0; i < 8; i++) {
            USART_PrintHex(roms[d][i], 1);
        }
        USART_Print("\r\n");
    }

🔍 triad ทำงานคู่กัน — OneWire_ResetSearch(bus) รีเซ็ต state การค้น — OneWire_Search(bus) ค้น device ถัดไป (คืน true = พบ, false = ครบ) และเก็บ ROM ไว้ใน bus->rom ภายใน — OneWire_GetAddress(bus, rom) ดึง ROM 8 bytes ออกมาเก็บใน buffer ของเรา — อย่าใช้ uint64_t เพราะ API จัดเก็บ ROM เป็น uint8_t[8] และส่งผ่านเป็น pointer เสมอ

🛠️ สร้าง Product: เทอร์โมมิเตอร์หลายจุด

อ่านอุณหภูมิจาก DS18B20 3 ตัวบนบัสเดียวกัน — แสดง ROM ID + อุณหภูมิ — ใช้เทคนิค Jump Temp: สั่ง Convert T ทุกตัวพร้อมกันด้วย SkipROM → รอ 750ms ครั้งเดียว → MatchROM + Read Scratchpad ทีละตัว

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"

#define OW_PIN      PC0
#define MAX_DEVICES 8

// ROM IDs เก็บเป็น uint8_t[8] — ตาม API จริง
uint8_t g_roms[MAX_DEVICES][8];
uint8_t g_count = 0;

// อ่าน scratchpad ของ device เฉพาะ (รอ Convert มาก่อนแล้ว)
// คืน true สำเร็จ, false = CRC error หรือไม่มี device
bool read_scratchpad(OneWire_Bus* bus, const uint8_t* rom, uint8_t* sp)
{
    if (!OneWire_Reset(bus)) return false;
    OneWire_MatchROM(bus, rom);    // 0x55 + 8 bytes ROM
    OneWire_WriteByte(bus, 0xBE);  // Read Scratchpad

    OneWire_ReadBytes(bus, sp, 9);
    return OneWire_VerifyCRC(sp, 9);
}

void print_rom(const uint8_t* rom)
{
    for (int i = 0; i < 8; i++) {
        USART_PrintHex(rom[i], 1);
    }
}

int main(void)
{
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);

    OneWire_Bus* bus = OneWire_Init(OW_PIN);
    if (bus == NULL) {
        USART_Print("Bus init failed\r\n");
        while (1);
    }

    // ค้นหาอุปกรณ์ด้วย triad
    OneWire_ResetSearch(bus);
    while (OneWire_Search(bus) && g_count < MAX_DEVICES) {
        OneWire_GetAddress(bus, g_roms[g_count]);
        g_count++;
    }

    USART_Print("Found ");
    USART_PrintNum(g_count);
    USART_Print(" DS18B20(s)\r\n");

    if (g_count == 0) {
        USART_Print("No sensors — check wiring & pull-up\r\n");
        while (1);
    }

    while (1)
    {
        // === Jump Temp: สั่ง Convert T ทุกตัวพร้อมกัน ===
        OneWire_Reset(bus);
        OneWire_SkipROM(bus);           // สั่งทุกตัวในครั้งเดียว
        OneWire_WriteByte(bus, 0x44);   // Convert T (all devices)

        Delay_Ms(750);                  // รอครั้งเดียว (ไม่ใช่ N × 750)

        // === อ่านทีละตัวด้วย MatchROM ===
        for (uint8_t i = 0; i < g_count; i++)
        {
            USART_Print("[");
            USART_PrintNum(i);
            USART_Print("] ROM: ");
            print_rom(g_roms[i]);
            USART_Print("  Temp: ");

            uint8_t sp[9];
            if (!read_scratchpad(bus, g_roms[i], sp)) {
                USART_Print("ERROR (CRC / no device)\r\n");
                continue;
            }

            // 85°C = power-on default — skip (0x0550)
            int16_t raw = (int16_t)(sp[0] | (sp[1] << 8));
            if (raw == 0x0550) {
                USART_Print("(still powering up)\r\n");
                continue;
            }

            float temp = raw / 16.0f;
            USART_PrintNum((int32_t)temp);
            USART_Print(".");
            int16_t dec = (int16_t)((temp - (int32_t)temp) * 10);
            if (dec < 0) dec = -dec;
            USART_PrintNum(dec);
            USART_Print(" C\r\n");
        }
        USART_Print("---\r\n");
        Delay_Ms(2000);
    }
}

เทคนิค Jump Temp (เร่งความเร็ว): สั่ง Convert T (0x44) แบบ SkipROM → เริ่มวัดทุกตัวพร้อมกัน → รอ 750ms ครั้งเดียว → อ่านทีละตัวด้วย MatchROM → ลดเวลารวมจาก N × 750ms เหลือ 750ms + N × เวลาอ่าน scratchpad (ราว 5ms ต่อตัว)

🔍 OneWire_MatchROM(bus, rom) รับ const uint8_t* rom (pointer ไปยัง 8 bytes) — ส่ง 0x55 ตามด้วย ROM 8 bytes — เฉพาะ device ที่ ROM ตรงเท่านั้นที่ตอบ — ทำให้แยกอุปกรณ์บนบัสเดียวกันได้ — read_scratchad() ห่อ Reset+MatchROM+0xBE+Read9Bytes+CRC เป็น helper ลดความซ้ำซาน

⚠️ ข้อผิดพลาดที่พบบ่อย

ปัญหาสาเหตุวิธีแก้
OneWire_Reset(bus) คืน false ตลอดไม่มี pull-up resistor, สายยาวเกิน, หรือ pin ผิดต่อ 4.7kΩ ระหว่าง DQ กับ 3.3V — ใช้สายสั้น < 2m — ตรวจ OneWire_Init ไม่คืน NULL
OneWire_Init คืน NULLbus slot เต็ม (สูงสุด 4) หรือ pin เป็น pin ที่ไม่รองรับลดจำนวน bus — ใช้ OneWire_GetBusByPin(pin) เรียกซ้ำ หรือตรวจ ONEWIRE_MAX_BUSES
อุณหภูมิอ่านได้ 85°C ตลอดDS18B20 ยัง convert ไม่เสร็จ (default power-on = 85°C = 0x0550)รออย่างน้อย 750ms หลัง Convert T (0x44) — ตรวจค่า raw == 0x0550 เพื่อ skip
CRC Error บ่อย OneWire_VerifyCRC(sp, 9) คืน falseTiming ไม่ตรง — interrupt รบกวน — สายยาวSimpleHAL ปิด interrupt ใน critical section แล้ว — ลองสายสั้นขึ้น — ตรวจ pull-up
หลายตัว — อ่านค่าผิดหมด / ค่าเดียวกันซ้ำใช้ OneWire_SkipROM(bus) ตอนอ่าน scratchpad ทั้งที่มีหลายอุปกรณ์ — ทุกตัวตอบพร้อมกันทำให้ข้อมูลชนกันใช้ triad ResetSearch/Search/GetAddress หา ROM IDs — แล้วใช้ OneWire_MatchROM(bus, roms[i]) อ่านทีละตัว
คอมไพล์ผ่านแต่ link error — undefined reference ฟังก์ชัน search ROM แบบ arrayใช้ API ปลอมจากเอกสารเก่าเปลี่ยนเป็น triad: ResetSearch → Search → GetAddress — ดู Simple1Wire.h
DS18B20 ร้อนมากต่อ VDD กลับขั้ว หรือ parasitic power ไม่พอเช็คขา 1=GND, 2=DQ, 3=VDD — ใช้ external power ถ้าเป็นไปได้

✏️ ลองทำดู

  1. ใช้ triad ResetSearch/Search/GetAddress หา DS18B20 หลายตัว — เก็บ ROM ใน uint8_t roms[N][8] — แล้วใช้ OneWire_MatchROM(bus, roms[i]) + 0x44 อ่านทีละตัว — วัดเวลารวมเทียบกับแบบ SkipROM broadcast + อ่านทีละตัว (Jump Temp)
  2. เปลี่ยน DS18B20 resolution จาก 12-bit เป็น 9-bit (เขียน scratchpad ด้วย 0x4E + 3 bytes ของ config) — สังเกตความเร็ว (93ms vs 750ms)
  3. ใช้ OneWire_AlarmSearch(bus) แทน OneWire_Search(bus) — วนหาเฉพาะ device ที่ตั้ง alarm flag (เช่น temp เกินขีด) โดยไม่ต้องอ่านทุกตัว
  4. เปรียบเทียบ OneWire_Select(bus, rom) (Reset+MatchROM รวม) กับการเรียก OneWire_Reset(bus) + OneWire_MatchROM(bus, rom) แยก — อะไรสั้นกว่า?
