รู้จักขา

  • PC0 (DQ): ขาข้อมูล 1-Wire — ต่อกับ DQ ของ DS18B20
  • R 4.7kΩ: ตัวต้านทาน Pull-up — ต่อจาก DQ ไป 3.3V (จำเป็น!)
  • VDD (DS18B20): ขาไฟเลี้ยง — ต่อ 3.3V

วิธีต่อทีละขั้น

  1. ต่อ R 4.7kΩ จาก PC0 ไป 3.3V — pull-up สำหรับ 1-Wire
  2. ต่อ PC0 ไป DQ (ขา 2) ของ DS18B20 — สายข้อมูล
  3. ต่อ 3.3V ไป VDD (ขา 3) ของ DS18B20 — จ่ายไฟ
  4. ต่อ GND ไป GND (ขา 1) ของ DS18B20 — กราวด์

Pull-up 4.7kΩ สำคัญมาก! — 1-Wire เป็น open-drain — ต้องมี pull-up เพื่อให้บัสกลับเป็น HIGH — ถ้าไม่มี pull-up บัสจะเป็น LOW ตลอด

📚 หลักการทำงาน

1-Wire — โปรโตคอลสื่อสารผ่าน 1 สาย data (+GND) — คิดค้นโดย Dallas Semiconductor (ปัจจุบันเป็นของ Maxim/Analog Devices)

Timing สำคัญ

  • Reset Pulse: Master ลาก LOW 480µs → ปล่อย → รอ 15-60µs → Slave ลาก LOW 60-240µs (Presence Pulse)
  • Write 1: Master ลาก LOW 1-15µs → ปล่อย
  • Write 0: Master ลาก LOW 60µs → ปล่อย
  • Read: Master ลาก LOW 1-15µs → ปล่อย → อ่านภายใน 15µs
  • Convert T: DS18B20 ใช้เวลา 750ms (12-bit) — ต้องรอให้เสร็จ!

DS18B20 Command Flow

  1. Reset → Presence
  2. ROM Command: Skip ROM (0xCC) — ถ้ามีตัวเดียว — หรือ Match ROM (0x55) — เลือกตัวใดตัวหนึ่ง
  3. Function Command: Convert T (0x44) — เริ่มวัด — หรือ Read Scratchpad (0xBE) — อ่านผล
  4. Data: อ่าน 9 bytes scratchpad — byte 0-1 = temperature

CH32V003 ต้องใช้ Software Bit-Banging — ไม่มี hardware 1-Wire — ใช้ Delay_Us() ให้ตรง timing — SimpleHAL จัดการให้

ขั้นที่ 3: อ่านอุณหภูมิ (Single Device)

    while(1) {
        // ——— Step 1: Start Conversion ———
        OneWire_Reset();
        OneWire_SkipROM();              // ข้าม ROM — มีตัวเดียว
        OneWire_WriteByte(0x44);        // Convert T command

        // รอ conversion (~750ms for 12-bit)
        Delay_Ms(750);

        // ——— Step 2: Read Scratchpad ———
        OneWire_Reset();
        OneWire_SkipROM();
        OneWire_WriteByte(0xBE);        // Read Scratchpad

        // อ่าน 9 bytes scratchpad
        uint8_t sp[9];
        for(int i=0; i<9; i++) {
            sp[i] = OneWire_ReadByte();
        }

        // Temperature = byte0 | (byte1 << 8) — signed 16-bit
        int16_t temp_raw = sp[0] | (sp[1] << 8);
        float temp_c = temp_raw / 16.0f;

        USART_Print("Temperature: ");
        USART_PrintNum((int32_t)temp_c);
        USART_Print(".");
        // แสดงทศนิยม 1 ตำแหน่ง
        int16_t dec = (int16_t)((temp_c - (int32_t)temp_c) * 10);
        if(dec < 0) dec = -dec;
        USART_PrintNum(dec);
        USART_Print(" °C\r\n");

        Delay_Ms(1000);
    }

🔍 OneWire_SkipROM() — ข้ามการระบุ ROM ID — ใช้เมื่อมีอุปกรณ์ตัวเดียวบนบัส — ถ้ามีหลายตัว — ห้ามใช้ SkipROM! — OneWire_WriteByte() — ส่ง 1 byte — OneWire_ReadByte() — อ่าน 1 byte — ต้องอ่าน 9 bytes (scratchpad)

⚠️ ข้อผิดพลาดที่พบบ่อย

ปัญหาสาเหตุวิธีแก้
OneWire_Reset() ได้ 0 ตลอดไม่มี pull-up resistor หรือสายยาวเกินต่อ 4.7kΩ ระหว่าง DQ กับ 3.3V — ใช้สายสั้น < 2m
อุณหภูมิอ่านได้ 85°C ตลอดDS18B20 ยัง convert ไม่เสร็จ (default power-on = 85°C)รออย่างน้อย 750ms หลังจาก Convert T (0x44) — เช็ค busy flag
CRC Error บ่อยTiming ไม่ตรง — interrupt รบกวนDisable interrupt ชั่วคราวระหว่าง 1-Wire transaction
หลายตัว — อ่านค่าผิดหมดใช้ SkipROM กับหลายอุปกรณ์ใช้ OneWire_SearchROM() หา ROM IDs — แล้วใช้ OneWire_MatchROM() ทีละตัว
DS18B20 ร้อนมากต่อ VDD กลับขั้ว หรือ parasitic power ไม่พอเช็คขา 1=GND, 2=DQ, 3=VDD — ใช้ external power ถ้าเป็นไปได้

อ่านอุณหภูมิจาก DS18B20 3 ตัวบนบัสเดียวกัน — แสดง ROM ID + อุณหภูมิ

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"

#define OW_PIN      PC0
#define MAX_DEVICES 8

uint64_t g_roms[MAX_DEVICES];
uint8_t  g_count = 0;

float read_ds18b20(uint64_t rom)
{
    OneWire_Reset();
    OneWire_MatchROM(rom);
    OneWire_WriteByte(0x44);  // Convert T

    // รอ conversion (poll busy)
    Delay_Ms(750);

    OneWire_Reset();
    OneWire_MatchROM(rom);
    OneWire_WriteByte(0xBE);  // Read Scratchpad

    uint8_t sp[9];
    for(int i=0; i<9; i++) sp[i] = OneWire_ReadByte();

    // CRC check
    if(OneWire_CRC8(sp, 8) != sp[8]) {
        return -999.0f;  // Error
    }

    int16_t raw = sp[0] | (sp[1] << 8);
    if(raw == 0x0550) return -999.0f;  // 85°C = power-on default

    return raw / 16.0f;
}

void print_rom(uint64_t rom)
{
    for(int i=0; i<8; i++) {
        USART_PrintHex((rom >> (i*8)) & 0xFF, 1);
    }
}

int main(void)
{
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);
    OneWire_Init(OW_PIN);

    // ค้นหาอุปกรณ์
    g_count = OneWire_SearchROM(g_roms, MAX_DEVICES);
    USART_Print("Found ");
    USART_PrintNum(g_count);
    USART_Print(" DS18B20(s)\r\n");

        USART_Print("No sensors — check wiring\r\n");
        while(1);

เทคนิคเร่งความเร็ว: ส่ง Convert T (0x44) แบบ SkipROM เพื่อเริ่มวัดทุกตัวพร้อมกัน → รอ 750ms → อ่านทีละตัวด้วย MatchROM → ลดเวลารอรวม

✏️ ลองทำดู

  1. ใช้ OneWire_SkipROM() + Convert T (0x44) เพื่อเริ่มวัดทุกตัวพร้อมกัน — แล้วอ่านทีละตัว — วัดเวลารวมเทียบกับแบบอ่านทีละตัว
  2. เปลี่ยน DS18B20 resolution จาก 12-bit เป็น 9-bit (เขียน config register — byte 4 ของ scratchpad) — สังเกตความเร็ว (93ms vs 750ms)
  3. เพิ่ม DS18B20 ตัวที่ 2 — ใช้ OneWire_SearchROM() — เปรียบเทียบอุณหภูมิระหว่าง 2 ตัว
