💻 ติดตั้งซอฟต์แวร์

1. ติดตั้ง MounRiver Studio 2

MounRiver Studio 2 (MRS2) เป็น IDE ฟรีสำหรับ RISC-V MCU จาก WCH — เราใช้ MRS2 เพื่องาน 2 อย่าง:

  1. Toolchain (GCC12): คอมไพเลอร์ RISC-V สำหรับ CH32V003
  2. OpenOCD + Driver: ใช้แฟลชโปรแกรมผ่าน WCH-Link

วิธีติดตั้ง:

  1. ไปที่ http://www.mounriver.com/ → ดาวน์โหลด MounRiver Studio 2
  2. ติดตั้งที่ C:\MounRiver\MounRiver_Studio2\ (path default — แนะนำให้ใช้ path นี้)
  3. ติดตั้งเสร็จแล้ว ไม่ต้องเปิด MRS2 — เราใช้แค่ toolchain ที่มาพร้อมมัน
⚠️ สำคัญ: ต้องติดตั้งที่ C:\MounRiver\ — เพราะ build script ของเราอ้างอิง path นี้ หากติดตั้งที่อื่น ต้องแก้ scripts\build.bat และ scripts\upload.bat

2. ติดตั้ง VS Code

  1. ดาวน์โหลดจาก https://code.visualstudio.com/
  2. ติดตั้งแบบปกติ (next → next → finish)

3. ตรวจสอบ Toolchain

เปิด Command Prompt หรือ PowerShell แล้วพิมพ์:

dir "C:\MounRiver\MounRiver_Studio2\resources\app\resources\win32\components\WCH\Toolchain\RISC-V Embedded GCC12\bin\riscv-wch-elf-gcc.exe"

ถ้าเจอไฟล์ — toolchain พร้อมใช้

ถ้าไม่เจอ — ตรวจสอบว่า:

  • ติดตั้ง MounRiver Studio 2 แล้วหรือยัง
  • ติดตั้งที่ path ถูกต้องหรือไม่
  • ลองค้นหา riscv-wch-elf-gcc.exe ในเครื่อง แล้วแก้ไข path ใน scripts\build.bat

4. ติดตั้ง Driver WCH-Link

เสียบ WCH-Link เข้า USB — Windows ควรติดตั้ง driver ให้เอง

หากไม่ติด ให้ลง driver จาก:

C:\MounRiver\MounRiver_Studio2\resources\app\resources\win32\components\WCH\Drivers\

5. ดาวน์โหลดโปรเจกต์

แบบที่ 1 — Git Clone (แนะนำ):

git clone https://github.com/Witawat/ch32v003_vscode_github_copilot.git
cd ch32v003_vscode_github_copilot
code .

แบบที่ 2 — ดาวน์โหลด ZIP:

  1. ไปที่ GitHub repository → Code → Download ZIP
  2. แตกไฟล์ไว้ที่โฟลเดอร์ที่ต้องการ
  3. เปิด VS Code → File → Open Folder → เลือกโฟลเดอร์ที่แตกไว้
💡 เนื้อหาในโปรเจกต์: ทุกอย่างพร้อมใช้ — SimpleHAL library, build scripts, examples, และ tutorial นี้ก็อยู่ใน docs/web-tutorial/

MCU Pin→อุปกรณ์ขาหมายเหตุ
PC0→R 220Ω → LEDAnode(+)LED ขาสั้น (Cathode) → GND
VDD (Pin 5)→ไฟเลี้ยง 3.3VVCCจาก LDO หรือ WCH-Link
GND (Pin 4)→GNDGNDต่อร่วมแหล่งจ่ายทั้งหมด

รู้จักขา

  • PC0 (Pin 12): ขาสัญญาณออก — ควบคุม LED (HIGH = ติด, LOW = ดับ)
  • VDD (Pin 5): ขาไฟเลี้ยง 3.3V — ต่อกับแหล่งจ่ายไฟ
  • GND (Pin 4): ขากราวด์ — ต่อร่วมกับ GND ของแหล่งจ่าย

วิธีต่อทีละขั้น

  1. ต่อ R 220Ω ระหว่าง PC0 (Pin 12) กับ LED ขาบวก (Anode) — จำกัดกระแสไม่ให้ LED ไหม้
  2. ต่อ LED ขาลบ (Cathode) ไป GND — ครบวงจรให้ LED ทำงาน
  3. ต่อ VDD (Pin 5) ไป 3.3V — จ่ายไฟให้ MCU
  4. ต่อ GND (Pin 4) ไป GND — กราวด์ร่วม

การต่อ WCH-Link สำหรับแฟลช

    WCH-Link                    CH32V003
    ┌──────┐                   ┌──────┐
    │ 3.3V ├───────────────────┤ VDD  │  Pin 5
    │ GND  ├───────────────────┤ GND  │  Pin 4
    │ SWIO ├───────────────────┤ PD1  │  Pin 7  (SWD data)
    │      │                   └──────┘
    └──────┘

    ⚠️ ต่อ 3 เส้นนี้ก่อนแฟลชทุกครั้ง
       WCH-Link จ่ายไฟ 3.3V ให้ CH32V003 ได้เลย (กระแสเพียงพอ)
WCH-Link→MCU Pinขาหมายเหตุ
3.3V→VDDPin 5WCH-Link จ่ายไฟให้ MCU
GND→GNDPin 4GND ร่วม
SWIO↔PD1Pin 7SWD data สำหรับแฟลช

รู้จักขา

  • 3.3V (WCH-Link): จ่ายไฟ 3.3V ให้ MCU — ไม่ต้องใช้ไฟเลี้ยงแยก
  • GND (WCH-Link): กราวด์ร่วมระหว่าง WCH-Link กับ MCU
  • SWIO (WCH-Link): สายข้อมูลสำหรับแฟลชโปรแกรม — ต่อกับ PD1 (Pin 7)

วิธีต่อทีละขั้น

  1. ต่อ 3.3V (WCH-Link) ไป VDD (Pin 5) — WCH-Link จ่ายไฟให้ MCU
  2. ต่อ GND (WCH-Link) ไป GND (Pin 4) — กราวด์ร่วมกัน
  3. ต่อ SWIO (WCH-Link) ไป PD1 (Pin 7) — สายข้อมูลสำหรับอัปโหลด
⚠️ คำเตือน:
  • CH32V003 ใช้ไฟ 3.3V — ห้าม ต่อ 5V เข้า VDD โดยตรง
  • LED ต้องมี R 220Ω เสมอ — ต่อตรงจะดึงกระแสเกิน pin พังได้
  • ตรวจสอบสาย GND ให้ดี — วงจรไม่ครบ = ไม่ทำงาน

⚡ แฟลชโปรแกรมลง MCU

📚 พื้นฐานภาษา C — สำหรับคนไม่เคยเขียนโค้ด

เนื้อหาในบทเรียนใช้ภาษา C — ถ้าไม่เคยเขียน C มาก่อน นี่คือสิ่งจำเป็นที่ต้องรู้:

1. โครงสร้างโปรแกรม C พื้นฐาน

// คำสั่งที่ขึ้นต้นด้วย # คือ Preprocessor — รันก่อนคอมไพล์
#define CH32V003_PACKAGE PACKAGE_TSSOP20   // กำหนดค่าคงที่
#include "SimpleHAL.h"                     // ดึงโค้ดจากไฟล์อื่นเข้ามา

// ฟังก์ชัน main() — จุดเริ่มต้นของทุกโปรแกรม
int main(void) {
    // โค้ดที่นี่รันครั้งเดียวตอนเริ่มต้น (setup)

    while (1) {
        // โค้ดที่นี่รันวนไปเรื่อย ๆ ไม่หยุด (loop)
    }
}

2. ตัวแปร (Variables)

uint8_t  led_state = 0;      // เลข 0-255 (8-bit)
uint16_t adc_value = 512;    // เลข 0-65535 (16-bit)
uint32_t time_ms   = 1000;   // เลข 0-4,294,967,295 (32-bit)
float    voltage   = 3.3f;   // เลขทศนิยม

const uint16_t MAX = 100;    // const = ห้ามเปลี่ยนค่า

🔍 uint8_t ย่อมาจาก unsigned integer 8-bit — ใช้แทน int เพื่อประหยัด RAM บน MCU

3. การตัดสินใจ (if/else)

if (digitalRead(PC1) == LOW) {   // ถ้ากดปุ่ม (Active LOW)
    digitalWrite(PC0, HIGH);      // ติด LED
} else {                          // ถ้าไม่กด
    digitalWrite(PC0, LOW);       // ดับ LED
}

4. การวนซ้ำ (while/for)

// วนตลอดไป
while (1) {
    // ทำซ้ำ
}

// วนตามจำนวนครั้ง
for (int i = 0; i < 10; i++) {
    digitalToggle(PC0);
    Delay_Ms(200);
}
💡 ไม่ต้องกลัว: โค้ดในบทเรียนเขียนให้เข้าใจง่ายที่สุด — คัดลอกไปใช้ได้เลย ไม่ต้องดัดแปลงมาก แต่ถ้าอยากเข้าใจลึกซึ้ง แนะนำให้หัดเขียน C พื้นฐานไปด้วย

Upload — "Error: open failed"WCH-Link ไม่ได้ต่อ หรือ driver ไม่ติดตั้งตรวจสอบ USB, ลองเสียบพอร์ทอื่น, ติดตั้ง driver
MCU ร้อนผิดปกติต่อไฟ 5V เข้า VDD โดยตรงถอดไฟทันที — CH32V003 ใช้ 3.3V เท่านั้น
Breadboard ต่อแล้วไฟเข้าแต่ MCU ไม่ทำงานสายไฟไม่แน่น, GND ไม่ครบวงจรใช้มัลติมิเตอร์วัดความต่อเนื่องของสาย
เปิด VS Code แล้วไม่มี IntelliSenseC/C++ extension ไม่ได้ติดตั้งติดตั้ง extension "C/C++" (Microsoft) ใน VS Code

VS Code Tasks ไม่ขึ้นไม่ได้เปิด workspace ถูกต้องต้องเปิดโฟลเดอร์ CH32V003/ ใน VS Code (ไม่ใช่โฟลเดอร์ docs/)
