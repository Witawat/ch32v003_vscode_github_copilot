AS5600 — Magnetic Encoder 12-bit I2C

ระดับกลาง

🧭 แผนภาพการทำงาน

flowchart TD
    A["AS5600_Init(addr)"] --> B["AS5600_ReadAngle()"]
    B --> C["Raw 0-4095 (12-bit)"]
    C --> D["Degrees = raw × 360 / 4096"]
    D --> E["Display / Motor Control"]
    E --> B

              AS5600 — Magnetic Rotary Encoder

    │ MCU                          AS5600│
    │ PC1─────────SDA         ┌─────────┤
    │ PC2─────────SCL         │ Hall    │

PC1─SDA, PC2─SCL — ต้องใช้แม่เหล็ก diametric (ขั้ว N-S ตามเส้นผ่านศูนย์กลาง) วางห่างจากชิป 0.5–2 มม., DIR pin กลับทิศการนับ

📚 หลักการทำงาน

AS5600 ใช้ Hall sensor array ตรวจจับสนามแม่เหล็กจากแม่เหล็กที่หมุนอยู่เหนือชิป — ให้ค่ามุม 12-bit (0–4095 steps) — ไม่มี contact → ไม่สึกหรอ → อายุการใช้งานยาวนานกว่า potentiometer หลายเท่า

ข้อควรรู้:

  • Magnet: ต้องเป็น diametric magnet (ขั้ว N-S แบ่งครึ่ง) ทรงกระบอก ∅6 มม. — ถ้าใช้แม่เหล็ก axial (ขั้วที่หน้า) จะวัดไม่ได้!
  • ระยะห่าง: 0.5–2.0 มม. จากผิว AS5600 — ใกล้เกิน = saturation, ไกลเกิน = weak field
  • Output: 12-bit angle (0–4095) + analog/PWM output (optional)
  • Zero programming: สามารถตั้งตำแหน่ง 0° ได้ผ่าน I2C หรือใช้โปรแกรม zero (ดึงขา PGO HIGH)

💻 เขียน Code ทีละขั้น

ขั้นที่ 1: Init + Setup

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "AS5600.h"

int main(void) {
    SystemCoreClockUpdate();
    USART_Init(USART1, BAUD_115200);
    I2C_Init(I2C1, I2C_SPEED_STANDARD);

    AS5600_Init(0x36);  // default I2C address

    // เช็คว่ามีแม่เหล็กหรือไม่
    if(AS5600_IsMagnetDetected()) {
        USART_Println("Magnet: OK");
    } else {
        USART_Println("Magnet: NOT FOUND!");
    }

🔍 AS5600_Init(addr) — default address 0x36 — AS5600_IsMagnetDetected() เช็คสถานะบิต MD (Magnet Detected) — ถ้า FALSE: แม่เหล็กอ่อนไป, ไกลเกิน, หรือใช้แม่เหล็กผิดชนิด

ขั้นที่ 2: อ่าน/เขียนค่า

    uint16_t raw = AS5600_ReadRawAngle();
    float deg = AS5600_ReadAngle();       // 0.0 – 360.0°
    float rad = AS5600_ReadAngleRad();    // 0.0 – 2π

    USART_Print("Raw: "); USART_PrintInt(raw);
    USART_Print(" | Angle: "); USART_PrintFloat(deg, 1);
    USART_Print("° | RPM: ");

    // คำนวณ RPM (ต้องเก็บเวลา)
    float rpm = AS5600_GetRPM();  // ต้องเรียก ReadAngle ต่อเนื่อง
    USART_PrintFloat(rpm, 0);
    USART_Println("");

🔍 AS5600_ReadRawAngle() — 0–4095 (12-bit) — AS5600_ReadAngle() แปลงเป็น 0–360° — AS5600_GetRPM() คำนวณรอบต่อนาทีจากประวัติการอ่าน

ขั้นที่ 3: Loop + แสดงผล

    OLED_t oled;
    OLED_Init(&oled, 0x3C, OLED_128x64);

    while(1) {
        float angle = AS5600_ReadAngle();
        uint16_t raw = AS5600_ReadRawAngle();

        OLED_Clear(&oled);
        OLED_SetCursor(&oled, 0, 0);
        OLED_PrintFloat(&oled, "Angle:", angle, 1);
        OLED_Print(&oled, " deg");

        // Draw angle bar (0-127 px = 0-360°)
        int barW = (int)(raw * 127 / 4096);
        OLED_DrawRect(&oled, 0, 24, barW, 10, 1);

        // Draw a simple dial indicator
        int cx = 64, cy = 48, r = 12;
        float radVal = angle * M_PI / 180.0f;
        int tx = cx + (int)(r * sin(radVal));
        int ty = cy - (int)(r * cos(radVal));
        OLED_DrawCircle(&oled, cx, cy, r, 0);  // circle outline
        OLED_DrawLine(&oled, cx, cy, tx, ty);   // needle

        OLED_Display(&oled);
        Delay_Ms(50);
    }
}

🔍 อ่านมุมทุก 50ms (20Hz) — แสดงทั้งตัวเลขและกราฟิกเข็ม — OLED_DrawLine วาดเข็มจากมุมที่อ่านได้ — ใช้ raw angle สำหรับ bar graph 12-bit → แม่นถึง 0.088°

🛠️ สร้าง Product: Digital Knob — ปุ่มหมอนับรอบ

AS5600 อ่านมุม → ตรวจจับการหมุน → นับรอบ + ทิศทาง

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "AS5600.h"
#include "OLED.h"

int main(void)
{
    SystemCoreClockUpdate();
    I2C_Init(I2C1, I2C_SPEED_STANDARD);
    USART_Init(USART1, BAUD_115200);

    OLED_t oled;
    OLED_Init(&oled, 0x3C, OLED_128x64);

    AS5600_Init(0x36);

    float prevAngle = AS5600_ReadAngle();
    int32_t totalDegrees = 0;
    float rpm = 0;

    uint32_t lastTime = Get_CurrentMs();

    while(1)
    {
        float angle = AS5600_ReadAngle();

        // Detect wrap-around and count turns
        float diff = angle - prevAngle;
        if(diff > 180) diff -= 360;       // wraparound 0→360
        else if(diff < -180) diff += 360; // wraparound 360→0

        totalDegrees += (int32_t)diff;
        int turns = totalDegrees / 360;

        prevAngle = angle;

        OLED_Clear(&oled);
        OLED_SetCursor(&oled, 0, 0);
        OLED_PrintFloat(&oled, "Angle:", angle, 1);
        OLED_Print(&oled, " deg");

        OLED_SetCursor(&oled, 0, 2);
        OLED_Print(&oled, "Turns: ");
        OLED_PrintInt(&oled, turns);

        OLED_Display(&oled);
        Delay_Ms(10);
    }
}

✏️ ลองทำดู

  1. ทำ RPM meter — ใช้ Timer interrupt อ่าน angle ที่ 100Hz → คำนวณ RPM แสดงบน OLED
  2. ทำ servo position feedback — ติด AS5600 ที่แกน servo → อ่านตำแหน่งจริง → PID แก้ให้ตรงกับ setpoint
  3. ทำ magnetic rotary switch — แบ่ง 360° เป็น 8 โซน (45° ต่อโซน) → เลือกโหมดโดยหมุนแม่เหล็ก
