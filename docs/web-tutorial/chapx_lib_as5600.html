🔌 การต่อวงจร

              AS5600 — Magnetic Rotary Encoder
    ┌────────────────────────────────────┐
    │ MCU                          AS5600│
    │ PC1─────────SDA         ┌─────────┤
    │ PC2─────────SCL         │ Hall    │
    │ 3.3V────────VCC         │ Sensor  │
    │ GND─────────GND         │ Array   │
    │ PC0─────────DIR(opt)    └─────────┤
    │                                    │
    │ Magnet: diametric, 6mm dia.        │
    │ Distance: 0.5-2mm from chip        │
    │ addr=0x36 (default)                │
    └────────────────────────────────────┘

PC1─SDA, PC2─SCL — ต้องใช้แม่เหล็ก diametric (ขั้ว N-S ตามเส้นผ่านศูนย์กลาง) วางห่างจากชิป 0.5–2 มม., DIR pin กลับทิศการนับ

📚 หลักการทำงาน

AS5600 ใช้ Hall sensor array ตรวจจับสนามแม่เหล็กจากแม่เหล็กที่หมุนอยู่เหนือชิป — ให้ค่ามุม 12-bit (0–4095 steps) — ไม่มี contact → ไม่สึกหรอ

ข้อควรรู้:

  • Magnet: ต้องเป็น diametric magnet (ขั้ว N-S แบ่งครึ่ง) ทรงกระบอก ∅6 มม.
  • ระยะห่าง: 0.5–2.0 มม. จากผิว AS5600 — ใกล้เกิน = saturation, ไกลเกิน = weak field
  • Output: 12-bit angle (0–4095)

💻 เขียน Code ทีละขั้น

ขั้นที่ 1: Init + Setup

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "AS5600.h"

AS5600_Instance enc;

int main(void) {
    SystemCoreClockUpdate();
    USART_Init(115200);

    AS5600_Init(&enc);  // default address 0x36

    USART_Println("AS5600 Ready!");

🔍 AS5600_Init(&enc) — ใช้ address default 0x36 — library จัดการ I2C ให้

ขั้นที่ 2: อ่านมุม

    float deg = AS5600_ReadAngleDegrees(&enc);  // 0.0 – 360.0°

    USART_Print("Angle: ");
    USART_PrintFloat(deg, 1);
    USART_Println("°");

🔍 AS5600_ReadAngleDegrees(&enc) — คืนค่ามุม 0.0–360.0° โดยตรง

ขั้นที่ 3: Loop + แสดงผล

    OLED_Handle oled;
    OLED_Init(&oled, OLED_128x64, 0x3C);

    while(1) {
        float angle = AS5600_ReadAngleDegrees(&enc);

        OLED_Clear(&oled);
        OLED_SetCursor(&oled, 0, 0);
        OLED_PrintFloat(&oled, "Angle:", angle, 1);
        OLED_Print(&oled, " deg");

        OLED_Update(&oled);
        Delay_Ms(50);
    }
}

🔍 อ่านมุมทุก 50ms (20Hz) — แสดงตัวเลขบน OLED — ใช้ instance-based API

🛠️ สร้าง Product: Digital Knob — ปุ่มหมอนับรอบ

AS5600 อ่านมุม → ตรวจจับการหมุน → นับรอบ + ทิศทาง

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "AS5600.h"
#include "oled_i2c.h"

int main(void)
{
    SystemCoreClockUpdate();
    USART_Init(115200);

    AS5600_Instance enc;
    AS5600_Init(&enc);

    OLED_Handle oled;
    OLED_Init(&oled, OLED_128x64, 0x3C);

    float prevAngle = AS5600_ReadAngleDegrees(&enc);
    int32_t totalDegrees = 0;

    while(1)
    {
        float angle = AS5600_ReadAngleDegrees(&enc);

        float diff = angle - prevAngle;
        if(diff > 180) diff -= 360;
        else if(diff < -180) diff += 360;

        totalDegrees += (int32_t)diff;
        int turns = totalDegrees / 360;
        prevAngle = angle;

        OLED_Clear(&oled);
        OLED_SetCursor(&oled, 0, 0);
        OLED_PrintFloat(&oled, "Angle:", angle, 1);
        OLED_Print(&oled, " deg");

        OLED_SetCursor(&oled, 0, 2);
        OLED_Print(&oled, "Turns: ");
        OLED_PrintInt(&oled, turns);

        OLED_Update(&oled);
        Delay_Ms(10);
    }
}

✏️ ลองทำดู

  1. ทำ RPM meter — ใช้ Timer interrupt อ่าน angle ที่ 100Hz → คำนวณ RPM
  2. ทำ servo position feedback — ติด AS5600 ที่แกน servo → PID แก้ตำแหน่ง
  3. ทำ magnetic rotary switch — แบ่ง 360° เป็น 8 โซน → เลือกโหมดโดยหมุนแม่เหล็ก
