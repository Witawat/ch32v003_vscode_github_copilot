AHT10/AHT20 — Temp+Hum I2C

ระดับกลาง

🧭 แผนภาพการทำงาน

flowchart TD
    A["AHT10_Init(0x38)"] --> B["TriggerMeasurement"]
    B --> C["Delay 80ms"]
    C --> D["ReadTemperature+ReadHumidity"]
    D --> B

🔌 การต่อวงจร

        AHT10 / AHT20 (I2C)
┌────────────────────────────────────┐
│ PC1 ──── SDA                       │
│ PC2 ──── SCL                       │
│ 3.3V ─── VCC                       │
│ GND  ─── GND                       │
│                                    │
│ I2C addr = 0x38 (fixed — เปลี่ยนไม่ได้)│
│ AHT20 = drop-in replacement        │
│ (pin+code เหมือน AHT10, accuracy ดีกว่า)│
└────────────────────────────────────┘

I2C address คงที่ 0x38 — AHT20 ใช้แทน AHT10 ได้ทันที ไม่ต้องเปลี่ยนวงจรหรือโค้ด

📚 หลักการทำงาน

I2C Address Fixed 0x38: ไม่มีขาให้เลือก address — ต่อได้ตัวเดียวต่อบัส

Calibration Command: ตอน Init ต้องส่งคำสั่ง calibration — Library ทำ auto

Trigger → Wait 80ms → Read: ต้องเรียก TriggerMeasurement() ก่อนอ่านทุกครั้ง — รอ 80ms ให้วัดเสร็จ — แตกต่างจาก DHT ที่อ่านทีเดียวเสร็จ

AHT10 vs AHT20: AHT20 เป็นรุ่นใหม่ — drop-in replacement, accuracy ±0.3°C (vs AHT10 ±0.5°C), pin และ code เหมือนกันทุกประการ

CRC Check: มี CRC ในตัว — ข้อมูลได้รับความเสียหายจะถูกตรวจจับได้

Accuracy: ±0.3°C / ±2%RH — ดีกว่า DHT22 ในด้านอุณหภูมิ

💻 เขียน Code ทีละขั้น

ขั้นที่ 1: Init I2C + AHT10

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "AHT10.h"

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    I2C_SimpleInit(I2C_SPEED_100K, I2C_PINS_DEFAULT);

    if(AHT10_Init(0x38) != AHT10_OK) {
        USART_Println("AHT10 Init Failed!");
        while(1);
    }
    USART_Println("AHT10 Ready!");

🔍 AHT10_Init(0x38) ส่ง calibration command + ตรวจสอบ ACK — ถ้า init fail มักเกิดจากปัญหา I2C (สายสลับ / ไม่ดึง pull-up / chip เสีย)

ขั้นที่ 2: Trigger + อ่านค่า

    AHT10_TriggerMeasurement();       // สั่งวัด
    Delay_Ms(80);                     // รอ measurement เสร็จ
    float t = AHT10_ReadTemperature();
    float h = AHT10_ReadHumidity();

    USART_Print("T: "); USART_PrintFloat(t, 1);
    USART_Print("C  H: "); USART_PrintFloat(h, 1);
    USART_Println("%");

🔍 TriggerMeasurement() ต้องเรียกทุกครั้งก่อนอ่าน — Delay_Ms(80) เป็นเวลาที่ต้องรอ, ReadTemperature() และ ReadHumidity() คืนค่าจาก measurement ล่าสุด

ขั้นที่ 3: Loop + OLED Display

    OLED_Handle oled;
    OLED_Init(&oled, OLED_128x64, 0x3C);
    OLED_SetFont(&oled, FONT_8x16);

    Timer_t tmr;
    Start_Timer(&tmr, 2000, 1);

    while(1) {
        if(Is_Timer_Expired(&tmr)) {
            AHT10_TriggerMeasurement();
            Delay_Ms(80);
            float t = AHT10_ReadTemperature();
            float h = AHT10_ReadHumidity();
            OLED_Clear(&oled);
            OLED_SetCursor(&oled, 0, 0);
            OLED_PrintFloat(&oled, "Temp:", t, 1); OLED_Print(&oled, " C");
            OLED_SetCursor(&oled, 0, 2);
            OLED_PrintFloat(&oled, "Hum :", h, 1); OLED_Print(&oled, " %");
            OLED_Update(&oled);
        }
        IWDG_Feed();
    }
}

🔍 ระบบทั้งหมดเป็น Non-Blocking — main loop ว่างทำงานอื่นได้, IWDG_Feed() ป้องกัน watchdog reset

⚠️ ข้อผิดพลาดที่พบบ่อย

ปัญหาสาเหตุวิธีแก้
Init fail — AHT10 ไม่ตอบ ACKCalibration command ไม่ได้รับตอบ — สาย I2C หลวม หรือ addr ผิดเช็คสาย SDA/SCL — I2C Scan หา address, เช็ค pull-up 4.7kΩ บน I2C
อ่านได้ค่า 0 ทั้ง temp และ humลืมเรียก TriggerMeasurement() ก่อนอ่านต้องเรียก TriggerMeasurement() → Delay_Ms(80) → ReadTemperature() ทุกครั้ง
อ่านค่าได้ช้า — ต้องรอ 80ms ทุกครั้งAHT10 ต้องใช้เวลา 80ms ต่อการวัด 1 ครั้ง (เป็นข้อจำกัดของชิป)ใช้ Timer Non-Blocking: trigger → flag → loop อ่านเมื่อครบ 80ms (แทน Delay_Ms blocking)
ค่าแกว่ง ±2°C ระหว่างอ่านต่อเนื่องSelf-heating — sensor element ร้อนจากการวัดต่อเนื่องลด sampling rate เหลือทุก 2-5 วินาที — ใช้ FORCED mode (หยุดระหว่างวัด)
ใช้อ่านในตู้บ่มเพาะ (Incubator) — ค่าเพี้ยนที่ความชื้นสูง > 90%Condensation บน sensor elementใช้ SHT3x ที่มี heater ไล่ condensation — AHT10 ไม่เหมาะกับ humidity > 90% ต่อเนื่อง

🛠️ สร้าง Product: Incubator Monitor

AHT10 + Relay + OLED — ควบคุมอุณหภูมิในตู้ฟักไข่

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "AHT10.h"
#include "oled_i2c.h"

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    I2C_SimpleInit(I2C_SPEED_100K, I2C_PINS_DEFAULT);

    AHT10_Init(0x38);
    pinMode(PC0, PIN_MODE_OUTPUT);  // Relay = Heater
    digitalWrite(PC0, LOW);

    OLED_Handle oled;
    OLED_Init(&oled, OLED_128x64, 0x3C);
    OLED_SetFont(&oled, FONT_8x16);

    Timer_t tmr;
    Start_Timer(&tmr, 2000, 1);

    while(1) {
        if(Is_Timer_Expired(&tmr)) {
            AHT10_TriggerMeasurement();
            Delay_Ms(80);
            float t = AHT10_ReadTemperature();
            float h = AHT10_ReadHumidity();

            if(t < 37.0f) digitalWrite(PC0, HIGH);  // Heater ON
            if(t > 37.8f) digitalWrite(PC0, LOW);   // Heater OFF

            OLED_Clear(&oled);
            OLED_SetCursor(&oled, 0, 0);
            OLED_PrintFloat(&oled, "T:", t, 1); OLED_Print(&oled, "C");
            OLED_SetCursor(&oled, 0, 2);
            OLED_PrintFloat(&oled, "H:", h, 1); OLED_Print(&oled, "%");
            OLED_SetCursor(&oled, 0, 4);
            OLED_Print(&oled, digitalRead(PC0) ? "HEATER ON " : "HEATER OFF");
            OLED_Update(&oled);
        }
        IWDG_Feed();
    }
}

✏️ ลองทำดู

  1. เทียบ AHT10 vs DHT22 — ต่อทั้ง 2 ตัว (AHT10=I2C, DHT22=GPIO) วัดอุณหภูมิ+ความชื้นพร้อมกัน แสดงผลบน OLED ดู accuracy ต่างกัน
  2. ทำ Humidity Alarm — เมื่อความชื้น > 80% → Buzzer ดัง + LED กระพริบ — ใช้ Buzzer_Beep()
  3. ทดลอง AHT10_SoftReset() — กดปุ่มเพื่อรีเซ็ต sensor โดยไม่ต้องตัดไฟ — เช็คว่าค่าที่อ่านได้หลัง reset ถูกต้อง
