LCD1602 I2C — จอตัวอักษร 16×2

ระดับเริ่มต้น

🧭 แผนภาพการทำงาน

flowchart TD
    A["LCD1602_I2C_Init(0x27)"] --> B["LCD1602_I2C_Clear()"]
    B --> C["LCD1602_I2C_SetCursor(row, col)"]
    C --> D["LCD1602_I2C_Print(str)"]
    D --> E["loop: อ่าน sensor → Print → Delay"]
    E --> C

🔌 การต่อวงจร

          LCD1602 I2C (HD44780 + PCF8574)
    ┌────────────────────────────────┐
    │ MCU                      LCD   │
    │ 5V  ─────────────── VCC        │
    │ GND ─────────────── GND        │
    │ PC1 ─────────────── SDA        │
    │ PC2 ─────────────── SCL        │
    │                 (backpack มี   │
    │                  pull-up ในตัว) │
    └────────────────────────────────┘

LCD1602 ใช้ PCF8574 I2C backpack — address 0x27 หรือ 0x3F ขึ้นอยู่กับรุ่น — ใช้ 5V จ่ายไฟ (backpack มี regulator ในตัว)

📚 หลักการทำงาน

Hitachi HD44780 Controller: เป็นจอตัวอักษร 16 คอลัมน์ × 2 แถว — ภายในใช้ controller HD44780 ที่มี RAM สำหรับตัวอักษร (DDRAM) 80 ตำแหน่ง และ CGRAM สำหรับตัวอักษรที่กำหนดเอง 8 ตัว (5×8 pixel ต่อตัว)

PCF8574 I2C Backpack: แปลงสัญญาณ I2C 2 เส้น → parallel 8-bit สำหรับ HD44780 — ทำให้ใช้สายแค่ 4 เส้น (VCC, GND, SDA, SCL) แทน 8-16 เส้น — address 0x27 (A0-A2 = GND) หรือ 0x3F

Custom Characters: CGRAM รองรับตัวอักษรกำหนดเอง 8 ตัว — แต่ละตัวใช้ 8 ไบต์ (5-bit ต่อแถว × 8 แถว) — ใช้ LCD1602_I2C_CreateChar() กำหนดรูปแบบ — แล้ว WriteChar() แสดง

Backlight Control: PCF8574 ขา P3 ควบคุม backlight — LCD1602_I2C_Backlight(on/off) เปิดปิดไฟหลังจอ — ประหยัดไฟเมื่อไม่ต้องแสดงผล

💻 เขียน Code ทีละขั้น

ขั้นที่ 1: Init + Setup

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    I2C_SimpleInit(I2C_SPEED_100K, I2C_PINS_DEFAULT);

    LCD1602_I2C_Init(0x27);
    LCD1602_I2C_Clear();
    LCD1602_I2C_Backlight(1);

🔍 เริ่มต้นด้วย I2C 100kHz (LCD รองรับสูงสุด 100kHz) — Init(0x27) ระบุ address ของ backpack — Clear() ล้างหน้าจอและตั้ง cursor ไปที่ (0,0)

ขั้นที่ 2: พิมพ์ข้อความ + Custom Char

    // Custom character: heart
    uint8_t heart[8] = {0x00,0x0A,0x1F,0x1F,0x0E,0x04,0x00,0x00};
    LCD1602_I2C_CreateChar(0, heart);

    LCD1602_I2C_SetCursor(0, 0);
    LCD1602_I2C_Print("Hello");
    LCD1602_I2C_WriteChar(0);  // heart symbol

    LCD1602_I2C_SetCursor(1, 0);
    LCD1602_I2C_Print("Temp: ");
    LCD1602_I2C_PrintNum(25);
    LCD1602_I2C_Print("C");

🔍 CreateChar(slot, pattern) — เก็บใน CGRAM slot 0-7 — WriteChar(slot) แสดง custom char — SetCursor(row, col) กำหนดตำแหน่ง — PrintNum() แสดงตัวเลข

ขั้นที่ 3: Loop แสดงค่า Sensor

    uint32_t temp = 0;

    while(1) {
        temp = ADC_Read(ADC_CH0);  // อ่าน sensor
        temp = (temp * 3300 / 4096) / 10;  // แปลงเป็น °C (สมมติ LM35)

        LCD1602_I2C_SetCursor(1, 6);
        LCD1602_I2C_PrintNum(temp);
        LCD1602_I2C_Print("C   ");

        Delay_Ms(1000);
    }
}

🔍 ไม่ต้อง Clear() ก็ได้ — แค่เขียนทับที่เดิม — ต่อท้ายด้วยช่องว่างเพื่อลบตัวเลขเก่า — หน่วง 1 วิ ก่อนอัปเดตใหม่

⚠️ ข้อผิดพลาดที่พบบ่อย

ปัญหาสาเหตุวิธีแก้
จอดำหมด ไม่มีไฟ backlightJumper backlight หลุด หรือไม่ได้ต่อ 5Vตรวจสอบ jumper บน backpack — ต้องมี 5V จ่ายให้ LED backlight
ตัวหนังสือประหลาด / สี่เหลี่ยมดำContrast ไม่เหมาะสม — V0 potentiometerหมุน potentiometer สีน้ำเงินบน backpack จนเห็นตัวอักษรชัด
I2C ไม่ตอบ — จอดำ+backlight ติดใช้ address ผิด (0x27 vs 0x3F)ใช้ I2C_Scan() หา address — ลองทั้ง 0x27 และ 0x3F
แสดงผลแค่ 8 ตัวอักษรต่อแถวไม่ได้ init เป็น 16×2 mode — stuck ใน 8×2LCD1602_I2C_Init() ต้องตั้งค่าเป็น 2-line mode — ตรวจสอบว่าเรียก Init ก่อนใช้งาน
ตัวอักษรกระพริบหรือหายสาย I2C ยาวเกินหรือ pull-up อ่อนเพิ่ม pull-up 4.7kΩ ที่ SDA/SCL หรือลดความเร็ว I2C

🛠️ สร้าง Product: เครื่องวัดอุณหภูมิ LCD

DHT11 อ่านอุณหภูมิ+ความชื้น แสดงผลบน LCD1602 I2C — ใช้ Non-Blocking Timer อัปเดตทุก 2 วินาที

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    I2C_SimpleInit(I2C_SPEED_100K, I2C_PINS_DEFAULT);

    LCD1602_I2C_Init(0x27);
    LCD1602_I2C_Clear();
    LCD1602_I2C_Backlight(1);

    DHT11_Init(PC3);
    DHT11_Data_t dht;
    Timer_t tmr;
    Start_Timer(&tmr, 2000, 1);

    while(1) {
        if(Is_Timer_Expired(&tmr)) {
            if(DHT11_Read(&dht) == DHT11_OK) {
                LCD1602_I2C_SetCursor(0, 0);
                LCD1602_I2C_Print("Temp: ");
                LCD1602_I2C_PrintNum(dht.temp);
                LCD1602_I2C_Print("C  ");

                LCD1602_I2C_SetCursor(1, 0);
                LCD1602_I2C_Print("Hum : ");
                LCD1602_I2C_PrintNum(dht.hum);
                LCD1602_I2C_Print("%  ");
            } else {
                LCD1602_I2C_SetCursor(0, 0);
                LCD1602_I2C_Print("Sensor Error!  ");
            }
        }
    }
}

✏️ ลองทำดู

  1. ทำ Scrolling Text — ข้อความยาวกว่า 16 ตัวอักษรเลื่อนซ้ายอัตโนมัติ — ใช้ ScrollLeft() ทุก 500ms
  2. สร้าง Custom Characters ตัวเลข 0-9 แบบดิจิทัล 8 ตัว — ใช้ CGRAM ทั้ง 8 slots
  3. ทำปุ่ม Toggle สลับภาษาไทย/อังกฤษ — ใช้ custom char แสดงภาษาไทย 2-3 ตัว (ใช้หลาย char ต่อกัน)
