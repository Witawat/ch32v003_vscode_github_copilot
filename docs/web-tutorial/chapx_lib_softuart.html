Software UART — Bit-Bang บน GPIO, สร้าง UART Port เพิ่ม

Software UART ใช้ GPIO 2 ขา + bit-bang timing — จำกัดที่บอดเรตต่ำ (≤19200) เพราะ CH32V003 48MHz CPU ไม่เร็วพอสำหรับบอดสูง, ใช้ตอนต้องการ UART port เพิ่มเมื่อ HW UART 2 ช่องถูกใช้หมดแล้ว

📚 หลักการทำงาน

Bit-Bang UART จำลองการส่ง-รับข้อมูลแบบ asynchronous serial โดยใช้ GPIO + delay แม่นยำ — TX: สร้าง start bit (LOW) → 8 data bits → stop bit (HIGH) ด้วย timing control, RX: รอ falling edge (start bit) → sample ที่กลางบิต → อ่าน 8 bits → เช็ค stop bit

Timing สำคัญมาก: ที่ 9600 baud 1 bit = ~104.17µs — ต้องใช้ Delay_Us() หรือ hardware timer เพื่อให้ timing แม่นยำ ห้ามใช้ SysTick 1ms เพราะหยาบเกินไป

ข้อจำกัด:

  • บอดเรตสูงสุดประมาณ 19200 bps — สูงกว่านี้ timing ไม่แม่นพอ
  • RX ต้องรอรับ — ขณะรอ RX CPU ทำงานอื่นไม่ได้ (blocking) — ใช้ interrupt ภายนอกช่วยได้
  • ไม่มี hardware buffer — ต้องอ่านให้ทันก่อนบิตต่อไปมา

💻 เขียน Code ทีละขั้น

ขั้นที่ 1: Init + Setup

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "SoftUART.h"

int main(void) {
    SystemCoreClockUpdate();
    USART_Init(USART1, BAUD_115200);  // debug
    SoftUART_Init(PC0, PC1, BAUD_9600);  // TX=PC0, RX=PC1
    USART_Println("SoftUART Ready @ 9600bps");

🔍 SoftUART_Init(tx_pin, rx_pin, baud) — ใช้ GPIO 2 ขา ธรรมดา ไม่ต้องเป็นขา USART, บอด ≤ 19200, TX ตั้งเป็น output push-pull, RX ตั้งเป็น input pull-up

ขั้นที่ 2: ส่งข้อมูล (TX)

    SoftUART_Write("Hello from SoftUART!\r\n");
    SoftUART_WriteChar('A');  // ส่งตัวอักษรเดียว
    SoftUART_WriteInt(12345); // ส่งตัวเลข
    SoftUART_WriteHex(0xAB);  // ส่ง hex 0xAB

    // ส่ง buffer
    uint8_t buf[] = {0x01, 0x02, 0x03, 0x04};
    SoftUART_WriteBuf(buf, 4);

🔍 SoftUART_Write(str) — ส่ง string แบบ blocking (รอจนส่งหมด), แต่ละ byte ใช้เวลาประมาณ 1ms ที่ 9600 baud — ถ้าส่งยาวมากจะบล็อก CPU นาน

ขั้นที่ 3: รับข้อมูล (RX) + Loop

    char rx_buf[32]; uint8_t idx = 0;
    while(1) {
        if(SoftUART_Available()) {       // non-blocking check
            char c = SoftUART_Read();    // read 1 byte
            USART_Write(USART1, c);      // echo to debug
            rx_buf[idx++] = c;
            if(c == '\n' || idx >= 31) {
                rx_buf[idx] = '\0';
                USART_Print("SoftRX: ");
                USART_Println(rx_buf);
                idx = 0;
            }
        }
        // ทำงานอื่นได้ที่นี่ (แต่ระวัง — ถ้า RX มีข้อมูลมา
        // ขณะทำงานอื่นอาจทำข้อมูลสูญหาย)
    }
}

🔍 SoftUART_Available() — เช็ค RX buffer แบบ non-blocking, ⚠️ ข้อควรระวัง: ขณะ CPU ทำงานอื่นอยู่ ถ้ามีข้อมูลเข้ามาทาง SoftUART จะสูญหาย — ควร poll ถี่ๆ หรือใช้ hardware interrupt

⚠️ ข้อผิดพลาดที่พบบ่อย

ปัญหาสาเหตุวิธีแก้
ส่งข้อมูลไม่ได้เลยTX pin ไม่ได้ตั้งเป็น outputเช็ค SoftUART_Init() — ต้องกำหนด TX, RX ให้ถูกต้อง
ข้อมูลออกมาขยะบอดเรตไม่ตรงกันทั้งสองฝั่งใช้ค่ามาตรฐาน: 1200, 2400, 4800, 9600, 19200
ข้อมูลเพี้ยนบางไบต์CPU ถูก interrupt ขัดจังหวะระหว่าง sampleปิด interrupt ช่วง RX critical, หรือลดบอดเรตลง
RX ไม่เคยได้รับข้อมูลลืม poll SoftUART_Available()ต้องเรียกเช็คบ่อยๆ ใน main loop — อย่ามี delay นาน
ส่งเร็วแล้วพังบอด >19200 — timing ไม่แม่นพอใช้ HW UART แทน หรือลดเหลือ 9600

🛠️ สร้าง Product: 3-Port Serial Hub

CH32V003 รับข้อมูลจาก 2 อุปกรณ์พร้อมกัน — HW USART1=debug, HW USART2=GPS, SoftUART=Bluetooth

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "SoftUART.h"

int main(void)
{
    SystemCoreClockUpdate();
    USART_Init(USART1, BAUD_115200);   // Port 0: Debug PC
    USART_Init(USART2, BAUD_9600);     // Port 1: GPS NEO-6M
    SoftUART_Init(PC0, PC1, BAUD_9600);// Port 2: HC-05 BT

    USART_Println("3-Port Serial Hub Ready");

    while(1)
    {
        // Forward USART2 (GPS) → USART1 (PC)
        if(USART_Available(USART2)) {
            USART_Write(USART1, USART_Read(USART2));
        }

        // Forward SoftUART (BT) → USART1 (PC)
        if(SoftUART_Available()) {
            USART_Write(USART1, SoftUART_Read());
        }

        // Forward USART1 (PC) → SoftUART (BT)
        if(USART_Available(USART1)) {
            char c = USART_Read(USART1);
            SoftUART_WriteChar(c);
        }
    }
}

✏️ ลองทำดู

  1. ทำ dual GPS tracker — HW UART1=GPS1, SoftUART=GPS2, ส่งทั้งสองขึ้น USART2 debug ทุก 5 วินาที
  2. ทำ ESP8266 + GPS บน CH32V003 พร้อมกัน — ใช้ HW UART1=debug, HW UART2=ESP8266, SoftUART=GPS
  3. วัด error rate ของ SoftUART ที่บอดต่างๆ — ส่ง pattern 0x00-0xFF loop 1000 รอบ ตรวจสอบความถูกต้อง
