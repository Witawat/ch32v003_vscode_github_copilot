📚 3. Layout — วางอุปกรณ์ + ลากเส้น

กฎเหล็ก 10 ข้อ

  1. Decoupling cap ใกล้ VDD: 100nF ต้องอยู่ห่างจาก VDD pin < 5mm
  2. Ground Plane: Layer ล่างควรเป็น GND ทั้งแผ่น — ลด noise, ลด EMI
  3. Track Width: Signal = 0.25-0.3mm (10-12mil), Power = 0.5-0.8mm (20-30mil)
  4. Via Size: 0.6mm hole / 1.0mm pad (24/40mil) — มาตรฐาน JLCPCB
  5. Keep-out โซน RF: ถ้ามี nRF24L01 / WiFi — antenna ต้องลอย ไม่มี copper ใต้
  6. แยก Analog/Digital: AGND ต้องแยกจาก DGND → เชื่อมจุดเดียว (star ground)
  7. Crystal (ถ้าใช้): วางใกล้ MCU, track สมมาตร, ห้ามมีสัญญาณอื่นไขว้
  8. USB Diff Pair: D+/D- — track คู่ขนาน, ความยาวเท่ากัน, impedance ~90Ω
  9. Silkscreen: ใส่ชื่อ pin, ขั้ว LED, ขั้ว capacitor — ช่วยตอนประกอบ
  10. Board Edge: Keep-out ≥ 0.5mm จากขอบบอร์ด

ขนาดบอร์ดแนะนำ

    ขนาดเล็กสุด (2-layer, 1.6mm):
    ├─ 20x20mm  → ~$2 (5 ชิ้น) JLCPCB
    ├─ 30x40mm  → ~$2 (5 ชิ้น) พอสำหรับ CH32V003 + LDO + header
    └─ 50x50mm  → ~$5 (5 ชิ้น) มีพื้นที่เหลือ

    ✅ ใช้ 2-layer ก็พอสำหรับ CH32V003
    ✅ 4-layer ไม่จำเป็น (แพงขึ้น 3-5 เท่า)

📚 4-5. Gerber Export + สั่งผลิต

วิธี Export จาก EasyEDA

  1. Open PCB → File → Export → Gerber
  2. เช็ค layers: GTL (top copper), GBL (bottom copper), GTS (top soldermask), GBS, GTO (top silkscreen), GBO, GKO (outline), TXT (drill)
  3. บีบอัดเป็น .zip
  4. อัปโหลดไป jlcpcb.com → Gerber Viewer ออนไลน์จะแสดงตัวอย่าง

✅ Checklist ก่อนสั่ง:
  • เปิด Gerber Viewer ดูทุก layer — ถูกต้องไหม
  • ขนาดบอร์ดตรงกับที่คิดไหม
  • รู drill ครบ — mounting hole, via, component pad
  • ไม่มี track สั้น (DRC check ผ่าน)
  • Silkscreen ไม่ทับ pad

📚 6. ประกอบ + ทดสอบ

การบัดกรี TSSOP-20 ด้วยมือ (Drag Soldering)

  1. ทา flux บาง ๆ ที่ pad
  2. วาง IC ตรงตำแหน่ง — บัดกรี 1 ขาตรงมุมก่อน (ยึด IC)
  3. ตรวจสอบว่าขาตรง pad ทุกขา — ถ้าไม่ตรง → ละลายขามุมแล้วเลื่อน
  4. หยด solder ที่ปลายหัวแร้ง → ลากจากขา 1 → 20 ช้า ๆ
  5. ถ้ามี solder bridge → ใช้ solder wick ซับออก
  6. ล้าง flux ด้วย IPA (isopropyl alcohol)
  7. ตรวจสอบด้วยแว่นขยาย — ทุกขาดูดี

การทดสอบ PCB ใหม่

  1. Visual: ตรวจด้วยตา — มี solder bridge? ขาไหนไม่ติด?
  2. Short Circuit: มัลติมิเตอร์โหมด Continuity — จิ้ม VDD กับ GND → ต้องไม่มีเสียง (ถ้ามี = short!)
  3. Power-on: จ่ายไฟ — วัด VDD = 3.3V — เอานิ้วจับ MCU → ไม่ควรร้อน
  4. Flash Test: ต่อ WCH-Link → Upload → LED กระพริบไหม?
  5. Peripheral Test: ทดสอบ USART, I2C, SPI ทีละตัว
  6. Burn-in: ปล่อยรัน 24 ชม. — ไม่ควรมี reset หรือ hang

⚠️ ข้อผิดพลาดที่พบบ่อย
