PC1─SDA, PC2─SCL (ขา I2C ของ CH32V003), ADDR ต่อ GND = address 0x23

📚 หลักการทำงาน

BH1750 เป็นเซนเซอร์วัดความสว่างแบบ I2C ambient light sensor ย่านวัด 1–65535 lux — การตอบสนองสเปกตรัมใกล้เคียงกับตามนุษย์มาก (human eye spectral response) จึงวัดแสงที่ตามองเห็นได้แม่น ไม่ต้อง calibrate เอง

โหมดการวัด:

  • BH1750_CONT_HIRES — Continuous High Resolution (1 lux/step), วัดต่อเนื่อง ~120ms ต่อครั้ง
  • BH1750_CONT_HIRES2 — Continuous High Resolution Mode 2 (0.5 lux/step), ละเอียดกว่าแต่ช้ากว่า ~120ms
  • BH1750_ONCE_HIRES — Single measurement แล้วเข้า power-down อัตโนมัติ

I2C Address: ADDR pin → LOW = 0x23, HIGH = 0x5C — เลือกได้ 2 address → ใช้ BH1750 พร้อมกัน 2 ตัวบนบัสเดียวได้

💻 เขียน Code ทีละขั้น

ขั้นที่ 1: Init + Setup

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "BH1750.h"

int main(void) {
    SystemCoreClockUpdate();
    USART_Init(USART1, BAUD_115200);
    I2C_Init(I2C1, I2C_SPEED_STANDARD);  // 100kHz
    BH1750_Init(0x23, BH1750_CONT_HIRES); // addr=0x23, continuous mode

🔍 BH1750_Init(addr, mode) — กำหนด address (0x23 หรือ 0x5C) และโหมดการวัด แนะนำ CONT_HIRES สำหรับงานส่วนใหญ่

ขั้นที่ 2: อ่าน/เขียนค่า

    uint16_t lux = BH1750_ReadLux();     // อ่านค่า lux (uint16)
    if(lux == 0xFFFF) {                  // error check
        USART_Println("Sensor error!");
        Delay_Ms(500);
    } else {
        USART_Print("Light: ");
        USART_PrintInt(lux);
        USART_Println(" lux");
    }

🔍 BH1750_ReadLux() คืนค่า 1–65535 lux — ถ้าได้ 0xFFFF แปลว่า I2C error (สายหลุด/address ผิด) เช็ค 0 lux อาจเกิดจากอยู่ใน single mode แล้วไม่ได้เริ่มวัดใหม่

ขั้นที่ 3: Loop + แสดงผล

    while(1) {
        uint16_t lux = BH1750_ReadLux();
        if(lux != 0xFFFF) {
            // ปรับ LED brightness อัตโนมัติตามแสง
            uint8_t duty = (uint8_t)((uint32_t)lux * 255 / 1000);
            if(duty > 255) duty = 255;
            PWM_SetDuty(TIM2_CH1, duty);  // สว่างในที่มืด หรี่ในที่สว่าง
        }
        Delay_Ms(200);  // ~5 readings/sec
    }
}

🔍 ใช้ map(lux, 0, 1000, 0, 255) แบบ manual — lux * 255 / 1000 — ปรับความสว่าง LED ผกผันกับแสงแวดล้อม: มืด→LED สว่าง, สว่าง→LED หรี่

📋 API Reference

ฟังก์ชันคำอธิบายตัวอย่าง
BH1750_Init(addr, mode)เริ่มต้นเซนเซอร์, ตั้งโหมดBH1750_Init(0x23, BH1750_CONT_HIRES)
BH1750_ReadLux()อ่านค่า lux ปัจจุบันuint16_t lux = BH1750_ReadLux()
BH1750_SetMode(mode)เปลี่ยนโหมดระหว่างรันBH1750_SetMode(BH1750_CONT_HIRES2)
BH1750_PowerDown()เข้า sleep โหมดประหยัดไฟBH1750_PowerDown()
BH1750_PowerOn()ปลุกจาก sleepBH1750_PowerOn()
BH1750_Reset()รีเซ็ต registerBH1750_Reset()

⚠️ ข้อผิดพลาดที่พบบ่อย

ปัญหาสาเหตุวิธีแก้
อ่านได้ 0 lux ตลอดAddress ผิด (0x23 vs 0x5C)เช็ค ADDR pin — ต่อ GND ได้ 0x23, ต่อ VCC ได้ 0x5C
ค่าไม่เปลี่ยน (ค้าง)ยังอยู่ใน single modeใช้ BH1750_CONT_HIRES แทน BH1750_ONCE_HIRES
ค่า overflow (65535)แสงแดดจัด >65535 luxเพิ่มตัวกรองแสง (ND filter) หรือเปลี่ยนโหมด low-gain
อ่านค่าได้แต่เพี้ยนMTreg ไม่ได้ตั้ง หรือ I2C noiseใช้ BH1750_SetMTreg(69) ค่า default, เพิ่ม pull-up 4.7kΩ
I2C scan ไม่เจอ deviceสาย SDA/SCL สลับ หรือลืม VCCเช็คการต่อสาย, วัดไฟ 3.3V ที่ sensor, ลอง I2C_Scan()

🛠️ สร้าง Product: ไฟอัตโนมัติ

BH1750 วัดแสง + LED PWM — เมื่อมืด LED สว่างอัตโนมัติ, เมื่อสว่าง LED หรี่ลง

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "BH1750.h"

int main(void)
{
    SystemCoreClockUpdate();
    USART_Init(USART1, BAUD_115200);
    I2C_Init(I2C1, I2C_SPEED_STANDARD);
    PWM_Init(TIM2, TIM2_CH1, PC4, 1000);  // PWM 1kHz ที่ PC4

    BH1750_Init(0x23, BH1750_CONT_HIRES);
    USART_Println("Auto Light System Ready");

    while(1)
    {
        uint16_t lux = BH1750_ReadLux();
        if(lux == 0xFFFF) { USART_Println("Err"); Delay_Ms(1000); continue; }

        uint8_t duty;
        if(lux <= 50)      duty = 255;      // มืดมาก → LED 100%
        else if(lux < 500) duty = (uint8_t)((500 - lux) * 255 / 450);  // fade
        else               duty = 0;        // สว่าง → LED off

        PWM_SetDuty(TIM2_CH1, duty);

        USART_Print("Lux: "); USART_PrintInt(lux);
        USART_Print(" | PWM: "); USART_PrintInt(duty); USART_Println("");

        Delay_Ms(200);
    }
}

✏️ ลองทำดู

  1. ทำ lux logger — บันทึกค่า lux ทุก 1 วินาที ผ่าน USART ดูกราฟแสงใน 24 ชม.
  2. ทำไฟกลางคืนอัตโนมัติ — lux < 30 → LED ติด, lux > 50 → LED ดับ (เพิ่ม hysteresis)
  3. ต่อ OLED แสดงค่า lux + กราฟแท่ง — ใช้ OLED_PrintFloat(&oled, "Lux:", lux, 0)
