บทที่ 3: Delay & Timer — จับเวลา Blocking และ Non-Blocking

ระดับเริ่มต้น

🧭 แผนภาพการทำงาน

flowchart TD

    B -->|"Blocking"| C["Delay_Ms() / Delay_Us()"]

วงจรเดียวกับบทก่อน — LED 2 ดวงแสดงความแตกต่างระหว่าง Blocking vs Non-Blocking

📚 หลักการทำงาน

Blocking Delay (Delay_Ms()): โปรแกรมหยุดรอตรงนั้นเลย — CPU ว่างเปล่าในช่วงรอ

Non-Blocking Timer (Timer_t + Is_Timer_Expired()): โปรแกรมตรวจสอบว่าเวลาครบหรือยัง ถ้ายังก็ไปทำงานอื่นต่อ — CPU ไม่เสียเปล่า

Timer_t struct เก็บ start_time, duration, active flag, และ repeat flag — นับด้วย SysTick 1ms

เมื่อไรควรใช้ Non-Blocking:

  • ต้องการทำหลายอย่างพร้อมกัน (LED กระพริบ + อ่านปุ่ม + ส่ง Serial)
  • ไม่อยากให้โปรแกรม "ค้าง" รอ
  • ทำ State Machine

💻 เขียน Code ทีละขั้น

ขั้นที่ 1: Setup + LED 2 ดวง

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    pinMode(PC0, PIN_MODE_OUTPUT);  // LED1 = Non-Blocking
    pinMode(PC1, PIN_MODE_OUTPUT);  // LED2 = Blocking

🔍 ตั้งค่า pin ทั้ง 2 ดวง — PC0 จะใช้ Non-Blocking ส่วน PC1 ใช้ Blocking เทียบกัน

ขั้นที่ 2: Non-Blocking Timer (PC0)

    Timer_t tmr_led1;
    Start_Timer(&tmr_led1, 500, 1);  // repeat ทุก 500ms

🔍 Start_Timer(timer, ms, repeat) — repeat=1 หมายถึง reset อัตโนมัติหลังหมดเวลา repeat=0 ต้องเรียก Start ใหม่เอง

ขั้นที่ 3: เปรียบเทียบใน Loop

    while(1) {
        // Non-Blocking: LED1 toggle ทุก 500ms
        if(Is_Timer_Expired(&tmr_led1)) {
            digitalToggle(PC0);
        }

        // Blocking: LED2 toggle ทุก 500ms
        digitalToggle(PC1);
        Delay_Ms(500);
    }
}

🔍 Is_Timer_Expired() ตรวจสอบโดยไม่หยุดรอ — LED1 กระพริบได้แม้ LED2 กำลังติด ด้วยวิธีนี้ LED1 toggle ได้อิสระจาก Delay_Ms ของ LED2

📋 API Reference

ฟังก์ชันคำอธิบายตัวอย่าง
Timer_Init()เริ่มต้น SysTick 1msเรียกก่อนใช้ฟังก์ชันเวลาทั้งหมด
Delay_Ms(n)หน่วงเวลา blocking (ms)Delay_Ms(500)
Delay_Us(n)หน่วงเวลา blocking (μs)Delay_Us(150)
Start_Timer(tmr, ms, repeat)เริ่ม Non-Blocking TimerStart_Timer(&tmr, 1000, 1)
Is_Timer_Expired(tmr)ตรวจสอบว่าครบเวลาหรือยังif(Is_Timer_Expired(&tmr)){...}
Stop_Timer(tmr)หยุด TimerStop_Timer(&tmr)
Reset_Timer(tmr, repeat)รีเซ็ตเริ่มนับใหม่Reset_Timer(&tmr, 1)
Get_CurrentMs()อ่าน milliseconds นับตั้งแต่เริ่มuint32_t now = Get_CurrentMs()
Get_CurrentUs()อ่าน microseconds นับตั้งแต่เริ่มuint32_t now = Get_CurrentUs()
ELAPSED_TIME(start, now)คำนวณเวลาที่ผ่านไป (overflow-safe)if(ELAPSED_TIME(t,Get_CurrentMs()) >= 100)

⚠️ ข้อผิดพลาดที่พบบ่อย

ปัญหาสาเหตุวิธีแก้
Timer ไม่ทำงานเลยลืม Start_Timer()ต้องเรียก Start ก่อนเช็ค Is_Timer_Expired()
Timer หมดครั้งเดียวแล้วหยุดใช้ repeat=0ใช้ repeat=1 ถ้าต้องการ loop, หรือเรียก Start ใหม่
LED 2 ดวงกระพริบ sync กันใช้ Delay แบบ blocking 2 ที่ใช้ Non-Blocking Timer แยกกัน 2 ตัว
ไม่ควรใช้ timer ค่า 0msTimer 0ms ทำงานไม่ถูกต้องใช้ค่าอย่างน้อย 1ms
เวลาคลาดเคลื่อนSysTick 1ms resolutionความละเอียดสูงสุด 1ms — ใช้ Delay_Us() สำหรับละเอียดกว่า

🛠️ สร้าง Product: นาฬิกาจับเวลาแบบไม่บล็อก + Stopwatch

LED 2 ดวงกระพริบอิสระที่ความถี่ต่างกัน โดย main loop ไม่เคยหยุดรอ

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"

int main(void)
{
    SystemCoreClockUpdate();
    Timer_Init();

    pinMode(PC0, PIN_MODE_OUTPUT);
    pinMode(PC1, PIN_MODE_OUTPUT);

    Timer_t tmr_fast, tmr_slow;
    Start_Timer(&tmr_fast, 200, 1);   // PC0: 200ms (5Hz)
    Start_Timer(&tmr_slow, 700, 1);   // PC1: 700ms (~1.4Hz)

    while(1)
    {
        if(Is_Timer_Expired(&tmr_fast)) {
            digitalToggle(PC0);
        }
        if(Is_Timer_Expired(&tmr_slow)) {
            digitalToggle(PC1);
        }
        // Main loop วนอิสระ ไม่เคยหยุด!
    }
}

✏️ ลองทำดู

  1. เพิ่มปุ่มกด — หยุด/เริ่ม LED1 โดยใช้ Stop_Timer()/Start_Timer() แบบ Non-Blocking
  2. ทำ LED 3 ดวง กระพริบอิสระ 3 ความถี่ (100ms, 300ms, 700ms) ใช้ Non-Blocking ทั้งหมด
  3. ใช้ ELAPSED_TIME() macro สร้าง counter ที่เพิ่มค่าเองทุก 1 วิ พิมพ์ผ่าน USART
