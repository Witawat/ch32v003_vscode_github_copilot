ADDR pin เลือก address — 0x44 (GND) หรือ 0x45 (VCC) — ALERT pin แจ้งเตือน threshold (optional)

📚 หลักการทำงาน

I2C Interface: Address 0x44 หรือ 0x45 — เลือกด้วยขา ADDR, สื่อสารเร็วสูงสุด 1MHz

Single-Shot Mode: วัด 1 ครั้งเมื่อสั่ง — เสร็จใน ~15ms (เร็วกว่า DHT22 ที่ 25ms และ AHT10 ที่ 80ms มาก)

Periodic Mode: ตั้งความถี่ (0.5/1/2/4/10 MPS) — ชิปวัดอัตโนมัติตามจังหวะ, อ่านค่าได้ทันทีไม่ต้องรอ — เหมาะกับ logging ต่อเนื่อง

Heater: ไล่ condensation / de-icing — ใช้ในสภาพแวดล้อมความชื้นสูง หรือหลังจากเกิดน้ำแข็งเกาะ

Alert Pin: ตั้ง threshold อุณหภูมิ/ความชื้น — MCU อ่านจาก interrupt pin แทนการ polling

Accuracy: ±0.3°C / ±2%RH — repeatability สูงมาก, response time ~8s (tau 63%)

Range: -40°C ถึง +125°C, 0-100%RH — กว้างกว่า AHT10 มาก

💻 เขียน Code ทีละขั้น

ขั้นที่ 1: Init I2C + SHT3x

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "SHT3x.h"

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    I2C_SimpleInit(I2C_SPEED_100K, I2C_PINS_DEFAULT);

    SHT3x_Init(0x44);    // ADDR=GND → 0x44
    USART_Println("SHT3x Ready!");

🔍 SHT3x_Init(addr) ตรวจสอบ sensor status — ถ้า ADDR pin ต่อ GND ใช้ 0x44, ต่อ VCC ใช้ 0x45, ต่อ 2 ตัวบน I2C เดียวกันได้

ขั้นที่ 2: Single-Shot Mode — วัดเมื่อต้องการ

    SHT3x_ReadSingle();               // วัด 1 ครั้ง (~15ms)
    float t = SHT3x_GetTemperature();  // °C
    float h = SHT3x_GetHumidity();     // %

    USART_Print("T: "); USART_PrintFloat(t, 2);
    USART_Print("C  H: "); USART_PrintFloat(h, 2);
    USART_Println("%");

    // เปิด Heater ไล่ condensation (1 ครั้ง)
    SHT3x_Heater(1);
    Delay_Ms(1000);
    SHT3x_Heater(0);

🔍 ReadSingle() วัดครั้งเดียว บล็อก ~15ms — เร็วกว่า DHT22 และ AHT10 มาก, Heater(1) เปิด heater ชั่วคราว — ใช้ไล่ความชื้นหลังเจอ condensation

ขั้นที่ 3: Periodic Mode — อ่านต่อเนื่องไม่ต้อง Trigger

    SHT3x_StartPeriodic(SHT3x_1MPS);  // 1 measurement/sec
    Timer_t tmr;
    Start_Timer(&tmr, 1000, 1);

    while(1) {
        if(Is_Timer_Expired(&tmr)) {
            SHT3x_ReadPeriodic();          // อ่านค่าล่าสุด (ไม่ต้องรอ)
            float t = SHT3x_GetTemperature();
            float h = SHT3x_GetHumidity();
            USART_Print("T:"); USART_PrintFloat(t, 2);
            USART_Print(" H:"); USART_PrintFloat(h, 2);
            USART_Println("%");
        }
        // Alert pin (PC3) — interrupt-driven
        if(digitalRead(PC3) == LOW) {
            USART_Println("⚠️ ALERT: Threshold exceeded!");
        }
        IWDG_Feed();
    }
}

🔍 Periodic mode = ชิปวัดเองตลอด — ReadPeriodic() ไม ่ต้องรอ, digitalRead(PC3) เช็ค alert pin แบบ polling — หรือใช้ interrupt edge detection

⚠️ ข้อผิดพลาดที่พบบ่อย

ปัญหาสาเหตุวิธีแก้
Init fail — SHT3x ไม่ตอบADDR เลือกผิด — ใช้ 0x44 แต่ต่อ ADDR ที่ VCCเช็คขา ADDR — GND=0x44, VCC=0x45 — หรือใช้ I2C Scan
Periodic mode ไม่อ่านค่าใหม่ลืมเรียก ReadPeriodic() — หรือความถี่ MPS ต่ำเกินต้องเรียก ReadPeriodic() ก่อน GetTemperature() ทุกครั้งที่ต้องการค่าล่าสุด
Alert pin ไม่ toggleยังไม่ได้ตั้ง threshold ด้วย SetAlertTH()เรียก SetAlertTH(t_hi, t_lo, h_hi, h_lo) ก่อน — ตัวเลขอยู่ใน raw units (ไม่ใช่ °C/%)
Heater ทำให้ค่าพุ่ง 5-10°CSelf-heating — heater อุ่น sensor element โดยตรงใช้ heater แค่ 100-500ms ต่อครั้ง — ห้ามเปิด heater แล้วอ่านค่าทันที
Single-shot mode ใช้แล้ว I2C hangClock stretching ระหว่าง measurementเพิ่ม I2C timeout handling — ใช้ SHT3x_SoftReset() ถ้า timeout

🛠️ สร้าง Product: Weather Station ความแม่นยำสูง

SHT3x + BMP280 + OLED — แสดง Temp, Hum, Pressure, Altitude บนจอเดียว

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "SHT3x.h"
#include "BMP280.h"
#include "oled_i2c.h"

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    I2C_SimpleInit(I2C_SPEED_100K, I2C_PINS_DEFAULT);

    SHT3x_Init(0x44);
    SHT3x_StartPeriodic(SHT3x_1MPS);
    BMP280_Init(0x76);
    BMP280_SetMode(BMP280_MODE_NORMAL);
    Delay_Ms(100);

    OLED_Handle oled;
    OLED_Init(&oled, OLED_128x64, 0x3C);
    OLED_SetFont(&oled, FONT_8x16);

    Timer_t tmr;
    Start_Timer(&tmr, 1000, 1);

    while(1) {
        if(Is_Timer_Expired(&tmr)) {
            SHT3x_ReadPeriodic();
            float st = SHT3x_GetTemperature();
            float sh = SHT3x_GetHumidity();
            float bp = BMP280_ReadPressure() / 100.0f;

            OLED_Clear(&oled);
            OLED_SetCursor(&oled, 0, 0);
            OLED_PrintFloat(&oled, "T:", st, 1); OLED_Print(&oled, "C");
            OLED_SetCursor(&oled, 0, 1);
            OLED_PrintFloat(&oled, "H:", sh, 1); OLED_Print(&oled, "%");
            OLED_SetCursor(&oled, 0, 2);
            OLED_PrintFloat(&oled, "P:", bp, 1); OLED_Print(&oled, "hPa");
            OLED_Update(&oled);
        }
        IWDG_Feed();
    }
}

✏️ ลองทำดู

  1. เทียบ Single-shot vs Periodic mode — วัด sampling rate ต่างกัน ดู response time และ power consumption
  2. ใช้ Alert pin แบบ interrupt — ต่อ PC3 เข้า EXTI — เมื่อ temp > 40°C → LED แดง + Buzzer ดัง
  3. Heater test — ใส่ SHT3x ในตู้เย็น → อ่านค่า → เปิด heater 1 วิ → อ่านอีกที — ดู self-heating effect
