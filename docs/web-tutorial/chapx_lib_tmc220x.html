MCU Pin→อุปกรณ์ขาหมายเหตุ
PC0→TMC2209STEPPulse input
PC1→TMC2209DIRทิศทางหมุน
PC2→TMC2209ENLOW = เปิดใช้งาน
PD5↔TMC2209TX1-Wire UART (1kΩ→PD5, 1kΩ→GND)
3.3V→TMC2209VIOLogic voltage 3.3V
GND→TMC2209GNDGround ร่วม
VMOT (12V)→TMC2209VMOTMotor supply 4.75–29V

⚠️ TMC2209 ใช้ 1-Wire UART — ต้องมี resistor 1kΩ ต่อระหว่าง TX pin กับ PD5, และ 1kΩ ต่อ PD5 ลง GND — VIO ต่อ 3.3V (logic level) — VMOT 4.75-29V — address 0–3 ตั้งด้วย MS1/MS2 pins

รู้จักขา

  • STEP: ขารับพัลส์ — 1 พัลส์ = 1 microstep
  • DIR: กำหนดทิศทางหมุน
  • EN: เปิด/ปิด driver — LOW = เปิด
  • TX: 1-Wire UART — สื่อสารกับ MCU ผ่าน resistor 1kΩ
  • VIO: จ่ายไฟ logic 3.3V
  • VMOT: จ่ายไฟมอเตอร์ 4.75–29V
  • GND: Ground ร่วม
  • A1/A2/B1/B2: ขาต่อ NEMA17

วิธีต่อทีละขั้น

  1. ต่อ STEP/DIR/EN ไป GPIO (PC0–PC2) — ควบคุมพัลส์และทิศทาง
  2. ต่อ TX (1-Wire UART) ผ่าน 1kΩ ไป PD5 และอีก 1kΩ ลง GND — สื่อสารกับ driver
  3. ต่อ VIO ไป 3.3V — จ่ายไฟ logic
  4. ต่อ VMOT กับ แหล่งจ่าย 4.75–29V และ GND ไป GND — จ่ายไฟมอเตอร์
  5. ต่อ NEMA17 เข้ากับ A1/A2/B1/B2 — ขดลวดมอเตอร์

📚 หลักการทำงาน

TMC2208/2209 เป็น stepper driver ยุคใหม่จาก Trinamic — เงียบกว่า DRV8825 มากด้วย StealthChop2™ (กระแสรูป sine wave แทน square wave) — SpreadCycle™ สำหรับแรงบิดสูง — เลือกโหมดได้แบบ real-time ผ่าน UART

StallGuard2™ (TMC2209 เท่านั้น): ตรวจจับว่ามอเตอร์ "stall" (ติดขัด) โดยไม่ต้องใช้ endstop switch — วัด back-EMF — ค่า SG_RESULT ต่ำมาก (< threshold) = motor stall — ใช้ทำ sensorless homing ได้

1-Wire UART Protocol: สื่อสารผ่าน TX pin เส้นเดียว (half-duplex) — ใช้ Single Wire UART ที่ 115200 baud — เขียน/อ่าน registers ผ่าน datagrams แบบ CRC-protected — address 0-3 รองรับ 4 drivers บนบัสเดียว

Registers สำคัญ: GCONF (mode), IHOLD_IRUN (current), CHOPCONF (chopper settings), SGTHRS (stall threshold), SG_RESULT (read stall value), TCOOLTHRS (coolStep threshold)

💻 เขียน Code ทีละขั้น

ขั้นที่ 1: สร้าง Instance + Init

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "TMC220x.h"

TMC220x_Instance drv;

int main(void) {
    SystemCoreClockUpdate();

    // Init: model=TMC2209, EN=PC2, DIR=PC1, STEP=PC0, 200 steps/rev
    TMC220x_Init(&drv, TMC220x_MODEL_2209, PC2, PC1, PC0, 200);
    USART_Println("TMC220x Ready!");

🔍 TMC220x_Init(&drv, model, en, dir, step, stepsPerRev) — รองรับ TMC2208 และ TMC2209 — EN=PC2 (LOW=on), DIR=PC1, STEP=PC0 — 200 steps/rev สำหรับ NEMA17 ทั่วไป — ไลบรารีจัดการ 1-Wire UART ให้อัตโนมัติ

ขั้นที่ 2: ตั้งความเร็ว + Enable

    // ตั้งความเร็ว และเปิด driver
    TMC220x_SetSpeed(&drv, 120);   // 120 RPM
    TMC220x_Enable(&drv);

    // StallGuard threshold (TMC2209 only)
    TMC220x_SetStallThreshold(&drv, 100);  // 0-255, lower = more sensitive

🔍 TMC220x_SetSpeed(&drv, rpm) ตั้งความเร็วรอบ — TMC220x_Enable(&drv) เปิด driver และ StealthChop — TMC220x_SetStallThreshold ตั้งค่า stall detection — ค่าต้อง tune ตามมอเตอร์ (เริ่มที่ 50-100)

ขั้นที่ 3: เคลื่อนที่ + Sensorless Homing

    // เคลื่อนที่ 1000 steps (5 รอบ สำหรับ 200 steps/rev)
    TMC220x_Move(&drv, 1000);
    // ไลบรารีใช้ blocking move — ฟังก์ชัน return เมื่อเคลื่อนที่เสร็จ

    Delay_Ms(500);

    // เคลื่อนที่กลับทิศทาง — ใช้ค่าติดลบ
    TMC220x_Move(&drv, -1000);

    // Sensorless Homing
    if(TMC220x_IsStalled(&drv)) {
        USART_Println("Stall detected! At home position.");
        TMC220x_Stop(&drv);
    }

    while(1) {
        // วนไปกลับ
        TMC220x_Move(&drv, 2000);
        Delay_Ms(500);
        TMC220x_Move(&drv, -2000);
        Delay_Ms(500);
    }
}

🔍 TMC220x_Move(&drv, steps) — steps > 0 หมุนตามเข็ม, steps < 0 หมุนทวนเข็ม — ใช้ blocking move — TMC220x_IsStalled(&drv) ตรวจสอบ stallGuard — sensorless homing ทำโดยเคลื่อนที่จน stall แล้วหยุด

⚠️ ข้อผิดพลาดที่พบบ่อย

ปัญหาสาเหตุวิธีแก้
UART ไม่ตอบสนองลืมต่อ resistor 1kΩ 1-Wire interfaceต่อ 1kΩ จาก TX → PD5 และ 1kΩ จาก PD5 → GND — ถ้าไม่มี resistor TMC2209 จะไม่ได้ยิน MCU
Motor เงียบแต่ไม่มีแรงStealthChop ที่ความเร็วสูง → ลดแรงบิดใช้ Hybrid Mode — ตั้ง TPWMTHRS ให้ switch เป็น SpreadCycle ที่ความเร็วหนึ่ง
StallGuard ไม่ detect stallSGTHRS ตั้งสูงเกินไป หรือ motor current ต่ำไปลด SGTHRS ลง (0-50) — เพิ่ม IRUN — motor ต้องเดินช้าพอ (stallGuard ทำงานที่ low speed)
TMC2209 ร้อนเกิน 100°CIRUN สูงเกิน + ไม่มี heatsinkลด IRUN — ใช้ heatsink — เปิด CoolStep™ (TCOOLTHRS) ให้ปรับกระแสอัตโนมัติ
หลาย driver address ชนกันไม่ได้ตั้ง MS1/MS2 pinsตั้ง MS1,MS2 pins (GND=addr0, VIO=addr3) — แต่ละ driver ต้องมี unique address

🛠️ สร้าง Product: Silent 3D Printer Z-Axis Controller

ใช้ TMC2209 + Sensorless Homing — Z-axis เงียบ + ไม่ต้องใช้ endstop switch — รับ G-Code Z commands ผ่าน USART

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "TMC220x.h"

TMC220x_Instance drv;
int32_t z_pos = 0;
#define STEPS_PER_MM 3200  // 1/16 * 200 steps/rev / 1.25mm pitch

void z_home(void) {
    // เคลื่อนที่ช้า ๆ จน stall
    TMC220x_SetStallThreshold(&drv, 30);
    TMC220x_Move(&drv, -50000);  // เคลื่อนที่เข้าหา home
    if(TMC220x_IsStalled(&drv)) {
        z_pos = 0;
        USART_Println("Homed!");
    }
}

void z_move_to(int32_t target_mm) {
    int32_t delta = (target_mm * STEPS_PER_MM) - z_pos;
    TMC220x_Move(&drv, delta);
    z_pos = target_mm * STEPS_PER_MM;
}

int main(void) {
    SystemCoreClockUpdate();
    USART1_Init(115200);
    USART2_Init(115200);

    TMC220x_Init(&drv, TMC220x_MODEL_2209, PC2, PC1, PC0, 200);
    TMC220x_SetSpeed(&drv, 120);
    TMC220x_Enable(&drv);
    z_home();

    while(1) {
        if(USART2_Available()) {
            char cmd[32]; uint8_t i=0;
            while(USART2_Available() && i<31) cmd[i++]=USART2_Read();
            cmd[i]=0;
            if(strstr(cmd,"G1 Z")) {
                float z = atof(strstr(cmd,"Z")+1);
                z_move_to((int32_t)(z*10)); // 0.1mm precision
            }
            if(strstr(cmd,"G28")) z_home();
        }
    }
}

✏️ ลองทำดู

  1. ทำ Auto-Tune StallGuard — โปรแกรมให้มอเตอร์เดินจน stall แล้วอ่านค่า stall — เก็บค่า threshold ที่เหมาะสมลง EEPROM
  2. ควบคุม TMC2209 หลายตัวบน UART bus เดียว (address 0-3) — ทำ 4-axis (X,Y,Z,E) ด้วย CH32V003 ตัวเดียว
  3. ใช้ SpreadCycle สำหรับ Z-hop — switch โหมดระหว่าง StealthChop (เคลื่อนที่ปกติ) กับ SpreadCycle (ตอน Z-hop ที่ต้องการแรงบิดสูง)
