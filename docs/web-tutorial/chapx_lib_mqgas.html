            MQ Gas Sensor — เชื่อมต่อ ADC
    ┌────────────────────────────────────┐
    │ MCU                        MQ-xxx  │

    │                      │ B: H1─5V    │

PA1─AOUT (analog output) ผ่าน voltage divider — MQ-2 (LPG/ควัน), MQ-3 (แอลกอฮอล์), MQ-4 (มีเทน), MQ-7 (CO), MQ-135 (CO2/Air Quality)

📚 หลักการทำงาน

MQ Gas Sensors ใช้หลักการเปลี่ยนความต้านทานของวัสดุ SnO₂ เมื่อสัมผัสแก๊ส — Heater ภายในต้องให้ความร้อนตลอดเวลาเพื่อให้วัสดุไวต่อแก๊ส — ต้อง preheat 24–48 ชม. ก่อน Calibrate

การ Calibrate Ro (ความต้านทานในอากาศสะอาด):

  • เปิด Heater ทิ้งไว้ ≥24 ชม. ในอากาศสะอาด
  • วัดค่า ADC → คำนวณ Rs = RL × (1024 − ADC) / ADC
  • Ro = Rs / Ro_ratio (Ro_ratio จาก datasheet ของแต่ละรุ่น)

PPM Curve: แต่ละแก๊สมี sensitivity curve ต่างกัน — ใช้สมการ log-log: PPM = a × (Rs/Ro)^b — ค่า a, b เป็นค่าคงที่เฉพาะแก๊สและเซนเซอร์แต่ละรุ่น

💻 เขียน Code ทีละขั้น

ขั้นที่ 1: Init + Setup

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "MQGas.h"

int main(void) {
    SystemCoreClockUpdate();
    USART_Init(USART1, BAUD_115200);
    ADC_Init(ADC1);

    // MQ-2: LPG/ควัน, calibrate ในอากาศสะอาด
    // Ro_calibrated ได้จากการ calibrate ล่วงหน้า
    MQGas_Init(MQ2, PA1, 4.7f, 9.83f, -0.43f);
    //              ^type ^pin ^RL(kΩ) a     b (log-log params)

🔍 MQGas_Init(type, adcPin, RL, a, b) — type เลือก MQ2/MQ3/MQ4/MQ7/MQ135, RL=load resistor (kΩ), a,b=duration coefficients จาก datasheet — ต้อง calibrate Ro ด้วยตนเองก่อนใช้งานจริง

ขั้นที่ 2: อ่าน/เขียนค่า

    // อ่านค่า PPM
    float ppm = MQGas_ReadPPM();
    USART_Print("Gas PPM: ");
    USART_PrintFloat(ppm, 2);
    USART_Println("");

    // อ่านค่า Rs/Ro ratio (ค่าดิบ)
    float ratio = MQGas_ReadRatio();
    USART_Print("Rs/Ro: ");
    USART_PrintFloat(ratio, 3);
    USART_Println("");

🔍 MQGas_ReadPPM() คืนค่า PPM — ค่านี้ขึ้นอยู่กับ Ro calibration โดยตรง — ถ้า Ro ไม่แม่น PPM ก็ไม่แม่น — MQGas_ReadRatio() อ่าน Rs/Ro โดยไม่แปลงเป็น PPM

ขั้นที่ 3: Loop + แสดงผล

    // Calibrate Ro อัตโนมัติ (ต้องทำในอากาศสะอาด)
    MQGas_CalibrateRo(50);  // เฉลี่ย 50 samples

    while(1) {
        float ppm = MQGas_ReadPPM();

        USART_Print("PPM: "); USART_PrintFloat(ppm, 2);
        if(ppm > 1000) {
            USART_Println(" ⚠️ DANGER! Gas leak!");
            // เปิดพัดลม / แจ้งเตือน
        } else if(ppm > 200) {
            USART_Println(" ⚡ WARNING! Elevated gas");
        } else {
            USART_Println(" ✓ Normal");
        }

        Delay_Ms(1000);
    }
}

🔍 CalibrateRo ต้องทำ ในอากาศสะอาด — เซนเซอร์ใช้เวลา warm-up อย่างน้อย 30 นาทีก่อนวัด — เก็บค่าเฉลี่ยหลาย sample ลด noise — ตั้ง threshold ตาม datasheet

⚠️ ข้อผิดพลาดที่พบบ่อย

ปัญหาสาเหตุวิธีแก้
ค่า PPM ไม่ตรง/แกว่งยังไม่预热 หรือ Ro ยังไม่ calibratePreheat ≥24 ชม. แล้ว calibrate Ro ในอากาศสะอาด
อ่านค่าต่ำมาก (ใกล้ 0)Heater ยังไม่ถึงอุณหภูมิรอ warm-up 30-60 นาทีหลังจ่ายไฟ
ค่า Rs/Ro ต่ำกว่า 1 ในอากาศสะอาดRL ผิดค่า หรือ Ro calibrate ตอนมีแก๊สเช็ค RL ตาม datasheet, calibrate ในที่อากาศถ่ายเทดี
เซนเซอร์ร้อนเกินใช้ไฟ Heater เกิน specsMQ series ใช้ Heater 5V/150mA — ห้ามต่อ 3.3V ที่ Heater
PPM = 0 ทั้งที่ได้กลิ่นแก๊สMQ sensor ไม่ตอบสนองแก๊สชนิดนั้นเช็ค datasheet ว่าเซนเซอร์ไวต่อแก๊สนั้นหรือไม่ (MQ-2 ไม่ไว CO)

🛠️ สร้าง Product: เครื่องตรวจจับแก๊สรั่ว

MQ-2 ตรวจจับ LPG/ควัน — เมื่อเกิน threshold ให้ Buzzer ดัง + LED กระพริบ

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "MQGas.h"

int main(void)
{
    SystemCoreClockUpdate();
    USART_Init(USART1, BAUD_115200);
    ADC_Init(ADC1);

    pinMode(PC0, PIN_MODE_OUTPUT);  // Buzzer
    pinMode(PC1, PIN_MODE_OUTPUT);  // LED Alarm

    MQGas_Init(MQ2, PA1, 4.7f, 9.83f, -0.43f);
    USART_Println("Calibrating Ro in clean air...");
    MQGas_CalibrateRo(100);
    USART_Println("Ready!");

    Timer_t tmr_buzz;
    Start_Timer(&tmr_buzz, 200, 1);

    while(1)
    {
        float ppm = MQGas_ReadPPM();
        USART_Print("PPM: "); USART_PrintFloat(ppm, 2); USART_Println("");

        if(ppm > 500) {  // อันตราย!
            digitalWrite(PC1, HIGH);
            if(Is_Timer_Expired(&tmr_buzz)) digitalToggle(PC0);
        } else {
            digitalWrite(PC1, LOW);
            digitalWrite(PC0, LOW);
        }

        Delay_Ms(1000);
    }
}

✏️ ลองทำดู

  1. ทดลอง calibrate MQ-2 ในอากาศสะอาด — บันทึกค่า Ro แล้วทดสอบกับควันธูป — สังเกต PPM ที่เปลี่ยน
  2. ทำ gas logger — บันทึก PPM ทุกวินาทีผ่าน USART ลง PC — plot กราฟดูก่อน-หลังจุดไฟแช็ค
  3. ใช้ MQ-135 วัด Air Quality — เทียบกับวันที่ฝนตก vs วันที่ฝุ่น PM2.5 สูง
