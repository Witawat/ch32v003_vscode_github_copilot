   LCD1602 I2C + 4 Push Buttons

│  PC2 ─── SCL                       │
│  5V  ─── VCC                       │
│  GND ─── GND                       │
│                                    │
│ Buttons (Active LOW, pull-up):     │
│  PC3 ─── UP     ─── GND            │
│  PC4 ─── DOWN   ─── GND            │

MCU Pin→อุปกรณ์ขาหมายเหตุ
PC1↔LCD1602 I2CSDAI2C data
PC2→LCD1602 I2CSCLI2C clock
5V→LCD1602 I2CVCCจ่ายไฟ 5V
GND↔LCD1602 I2CGNDกราวด์ร่วม
PC3←Push ButtonUP → GNDActive LOW, internal pull-up
PC4←Push ButtonDOWN → GNDActive LOW, internal pull-up
PC5←Push ButtonENTER → GNDActive LOW, internal pull-up
PC6←Push ButtonBACK → GNDActive LOW, internal pull-up

รู้จักขา

  • SDA (PC1): สายข้อมูล I2C ส่งคำสั่งไปแสดงผลบน LCD
  • SCL (PC2): สัญญาณนาฬิกา I2C ควบคุมจังหวะส่งข้อมูล
  • VCC (5V): จ่ายไฟ 5V ให้ LCD ทำงาน
  • GND: กราวด์ร่วม MCU กับ LCD
  • PC3 (UP): ปุ่มเลื่อนขึ้น กดแล้วต่อ GND
  • PC4 (DOWN): ปุ่มเลื่อนลง
  • PC5 (ENTER): ปุ่มยืนยันเข้าเมนู
  • PC6 (BACK): ปุ่มกลับเมนูก่อนหน้า

วิธีต่อทีละขั้น

  1. ต่อ PC1 ไป SDA ของ LCD — สายข้อมูล I2C
  2. ต่อ PC2 ไป SCL ของ LCD — สายนาฬิกา I2C
  3. ต่อ 5V ไป VCC ของ LCD — จ่ายไฟให้ LCD
  4. ต่อ GND ไป GND ของ LCD — กราวด์ร่วม
  5. ต่อ PC3 ไปขาหนึ่งของปุ่ม UP อีกขาไป GND — กดแล้วกราวด์
  6. ต่อ PC4, PC5, PC6 แบบเดียวกันกับปุ่ม DOWN, ENTER, BACK

LCD 16×2 ตัวอักษรผ่าน I2C (ลด pin usage) — 4 ปุ่มสำหรับนำทางเมนู — ทุกปุ่มใช้ internal pull-up (ACTIVE_LOW) — ต้อง init Button_Instance ก่อน LCDMenu_Init

📚 หลักการทำงาน

LCDMenu: ไลบรารีเมนูแบบลำดับชั้น (hierarchical) สำหรับ LCD1602 16×2 — ใช้ร่วมกับ LCD1602_I2C และ Button — ออกแบบมาสำหรับ MCU หน่วยความจำจำกัดด้วย static memory pool

Menu Tree: สร้างเมนูเป็นลำดับชั้น — เพิ่ม item ด้วย LCDMenu_AddSubMenu/AddCallback/AddToggle/AddValue() — ระบุ parent เพื่อสร้าง hierarchy — เปลี่ยนหน้าโดย UP/DOWN, เข้าด้วย ENTER, กลับด้วย BACK

4 Item Types (LCDMenu_ItemType):

  • LCDMENU_TYPE_SUBMENU — เข้าไปยังเมนูย่อย — เหมือน folder — มี children — ใช้ LCDMenu_AddSubMenu()
  • LCDMENU_TYPE_VALUE — แก้ไขค่าตัวเลข (int32_t) — ENTER เข้า edit mode, UP/DOWN เปลี่ยนค่า, ENTER ยืนยัน, BACK ยกเลิก — ใช้ LCDMenu_AddValue()
  • LCDMENU_TYPE_TOGGLE — เปิด/ปิด (bool) — ENTER สลับสถานะทันที — ใช้ LCDMenu_AddToggle()
  • LCDMENU_TYPE_CALLBACK — เรียก callback ทันทีที่กด ENTER — เหมือนปุ่ม execute — ใช้ LCDMenu_AddCallback()

BACK button — กลับไปเมนูก่อนหน้า (หรือออกจาก edit mode) — จัดการอัตโนมัติโดย library

Static Memory Pool: ทุกอย่างจัดสรรตอน compile — ไม่มี malloc — ปลอดภัยสำหรับ MCU RAM 2KB — กำหนดจำนวน item สูงสุดใน header

💻 เขียน Code ทีละขั้น

ขั้นที่ 1: Init Buttons + LCD + Menu

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "LCDMenu.h"
#include "lcd1602_i2c.h"

LCD1602_Handle lcd;
Button_Instance btn_up, btn_down, btn_enter, btn_back;
LCDMenu_Handle menu;

uint8_t setpoint = 40;

void on_setpoint(void) { USART_Print("Setpoint: "); USART_PrintNum(setpoint); }

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    USART_Init(115200);

    // Init LCD1602 I2C
    LCD_Init(&lcd, 0x27, LCD_16x2);

    // Init 4 buttons
    Button_Init(&btn_up,   PC3, BUTTON_ACTIVE_LOW);
    Button_Init(&btn_down, PC4, BUTTON_ACTIVE_LOW);
    Button_Init(&btn_enter,PC5, BUTTON_ACTIVE_LOW);
    Button_Init(&btn_back, PC6, BUTTON_ACTIVE_LOW);

    // Init menu with LCD + buttons
    LCDMenu_Init(&menu, &lcd, &btn_up, &btn_down, &btn_enter, &btn_back);
    LCDMenu_CreateRoot(&menu, "Main Menu");

🔍 LCDMenu_Init(&menu, &lcd, &btn_up, &btn_down, &btn_enter, &btn_back) — ต้อง Init LCD และ Button_Instance ก่อน — LCDMenu_CreateRoot(&menu, "Main Menu") สร้าง root menu

ขั้นที่ 2: สร้าง Menu Tree + Callbacks

    // ตัวแปรที่ menu items จะใช้ (ต้องเป็น static/global)
    static int32_t set_max = 80, set_min = 10;
    static bool wifi_on = false;
    static int32_t kp = 20, ki = 5;

    // Sub-menu: Temperature (items ลูกอยู่ใต้ temp)
    LCDMenu_Item* temp = LCDMenu_AddSubMenu(&menu, menu.root, "Temperature", NULL);
    LCDMenu_AddValue(&menu, temp, "Set Max", &set_max, -50, 200, 1, on_setpoint);
    LCDMenu_AddValue(&menu, temp, "Set Min", &set_min, -50, 200, 1, NULL);

    // Toggle: WiFi Control (ที่ root)
    LCDMenu_AddToggle(&menu, menu.root, "WiFi Control", &wifi_on, NULL);

    // Sub-menu: PID Tuning
    LCDMenu_Item* pid = LCDMenu_AddSubMenu(&menu, menu.root, "PID Tuning", NULL);
    LCDMenu_AddValue(&menu, pid, "Kp", &kp, 0, 100, 1, NULL);
    LCDMenu_AddValue(&menu, pid, "Ki", &ki, 0, 100, 1, NULL);

    // Callback action: Save & Exit
    LCDMenu_AddCallback(&menu, menu.root, "Save & Exit", NULL);
    USART_Println("Menu Ready!");

🔍 ใช้ LCDMenu_AddSubMenu/AddCallback/AddToggle/AddValue(&menu, parent, name, ...) — ระบุ parent เพื่อสร้าง hierarchy (ไม่ใช้การเว้นวรรคนำหน้า) — BACK จัดการอัตโนมัติโดยปุ่ม BACK

ขั้นที่ 3: Loop — Update Menu

    while(1) {
        LCDMenu_Update(&menu);  // จัดการ input + render อัตโนมัติ
        Delay_Ms(50);
        IWDG_Feed();
    }
}

🔍 LCDMenu_Update(&menu) — อ่านปุ่มทั้งหมด + จัดการ navigation + render LCD — เรียกครั้งเดียว — refresh 50ms พอดีสำหรับการตอบสนองของมนุษย์ — อย่าลืม IWDG_Feed เพื่อกัน MCU รีเซ็ต

⚠️ ข้อผิดพลาดที่พบบ่อย

ปัญหาสาเหตุวิธีแก้
จอไม่แสดงอะไรเลยลืม LCD_Init() ก่อน LCDMenu_Init()ต้อง Init LCD ก่อน — LCD_Init(&lcd, 0x27, 16, 2) แล้วตามด้วย LCDMenu_Init()
กด UP/DOWN แล้วกระโดดหลายช่องRefresh rate เร็วเกินไป + ไม่มี debounceเพิ่ม Delay_Ms เป็น 80-100ms — Button_Instance มี debounce ในตัว
SUBMENU ไม่ยอมเข้าลืม BACK item — หรือลูกศรไม่ตรงกับ ENTERBACK จัดการอัตโนมัติโดยปุ่ม BACK — เช็ค pin mapping ปุ่ม
TOGGLE ค่าไม่เปลี่ยนCallback signature ไม่ตรงCallback ต้องเป็น void cb(void) — อ่านค่าจาก bool* ที่ส่งให้ AddToggle
VALUE item ไม่เซฟค่าไม่ได้ใช้ค่าที่แก้ไขใน callbackใน callback ของ VALUE ให้ดึงค่าจาก int32_t* ที่ส่งให้ AddValue
RAM หมด — menu item หายเกิน MAX_ITEMS ที่ตั้งใน headerเพิ่ม #define LCDMENU_MAX_ITEMS 32 ก่อน include — หรือลดจำนวน item

🛠️ สร้าง Product: Settings Menu

เมนูปรับแต่งระบบ: WiFi SSID, Temperature Setpoint, Fan Toggle — บันทึกค่าลง Flash เมื่อกด Save

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "LCDMenu.h"
#include "lcd1602_i2c.h"

LCD1602_Handle lcd;
Button_Instance btn_up, btn_down, btn_enter, btn_back;
LCDMenu_Handle menu;
int32_t setpoint = 40;
bool fan_on = false;

void on_setpoint(void) { USART_Print("Setpoint: "); USART_PrintNum(setpoint); }
void on_fan(void) {
    pinMode(PC0, PIN_MODE_OUTPUT); digitalWrite(PC0, fan_on);
}
void on_save(void) {
    Flash_Unlock();
    Flash_WriteByte(0x0800FC00, setpoint);
    Flash_WriteByte(0x0800FC01, fan_on);
    Flash_Lock();
    USART_Println("Settings Saved!");
}

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    USART_Init(115200);

    LCD_Init(&lcd, 0x27, LCD_16x2);
    Button_Init(&btn_up,   PC3, BUTTON_ACTIVE_LOW);
    Button_Init(&btn_down, PC4, BUTTON_ACTIVE_LOW);
    Button_Init(&btn_enter,PC5, BUTTON_ACTIVE_LOW);
    Button_Init(&btn_back, PC6, BUTTON_ACTIVE_LOW);

    LCDMenu_Init(&menu, &lcd, &btn_up, &btn_down, &btn_enter, &btn_back);
    LCDMenu_CreateRoot(&menu, "Settings");

    // Sub-menu: Temperature
    LCDMenu_Item* temp = LCDMenu_AddSubMenu(&menu, menu.root, "Temperature", NULL);
    LCDMenu_AddValue(&menu, temp, "Setpoint", &setpoint, 0, 200, 1, on_setpoint);
    // Toggle: Fan Control (ที่ root)
    LCDMenu_AddToggle(&menu, menu.root, "Fan Control", &fan_on, on_fan);
    // Callback action: Save & Exit
    LCDMenu_AddCallback(&menu, menu.root, "Save & Exit", on_save);

    while(1) {
        LCDMenu_Update(&menu);
        Delay_Ms(50);
        IWDG_Feed();
    }
}
