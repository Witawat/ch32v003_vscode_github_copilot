AT24Cxx EEPROM — I2C, Page Boundary, Wear Leveling

ระดับสูง

🧭 แผนภาพการทำงาน

flowchart TD
    A["AT24Cxx_Init(&eeprom, type, addr)"] --> B{"Operation"}
    B -->|"Write"| C["AT24Cxx_WriteByte(&eeprom, addr, val)"]
    B -->|"Read"| D["AT24Cxx_ReadByte(&eeprom, addr)"]
    C --> F["Wait 5ms (write cycle)"]
    F --> G{"Done"}
    D --> G

🔌 การต่อวงจร

               AT24Cxx EEPROM I2C
    ┌──────────────────────────────────────────────┐
    │ CH32V003                        AT24C02/256  │
    │ PC1(SDA)────────SDA    ┌────────────────────┤
    │ PC2(SCL)────────SCL    │                    │
    │ 3.3V───────────VCC    │ Size   Address      │
    │ GND────────────GND    │ AT24C02  256B   0x50│
    │ WP─GND = write enable  │ AT24C32  4KB   0x50│
    │ A0,A1,A2─GND = 0x50   └────────────────────┤
    └──────────────────────────────────────────────┘
MCU Pin→อุปกรณ์ขาหมายเหตุ
PC1↔SDA-สายข้อมูล I2C — ต้องมี R 4.7kΩ pull-up ไป 3.3V
PC2→SCL-สายนาฬิกา I2C — ต้องมี R 4.7kΩ pull-up ไป 3.3V
3.3V→VCC-ไฟเลี้ยง 3.3V
GND→GND-กราวด์ร่วม
GND→WP-ต่อ GND = เปิดใช้งานการเขียน
GND→A0/A1/A2-ต่อ GND = ตั้งค่า I2C address เป็น 0x50

📚 หลักการทำงาน

AT24Cxx เป็น EEPROM แบบ I2C — เก็บข้อมูลได้แม้ไม่มีไฟ, endurance 1,000,000 write cycles, data retention >100 ปี

💻 เขียน Code ทีละขั้น

ขั้นที่ 1: Init + Setup

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "AT24Cxx.h"

AT24Cxx_Instance eeprom;

int main(void) {
    SystemCoreClockUpdate();
    I2C_Init(I2C1, I2C_SPEED_STANDARD);
    USART_Init(USART1, BAUD_115200);

    AT24Cxx_Init(&eeprom, AT24C32, 0x50);
    USART_Println("AT24C32 Ready (4096 bytes)");

🔍 AT24Cxx_Init(&eeprom, type, addr) — instance-based, เลือกเบอร์ชิปและ I2C address

ขั้นที่ 2: เขียน/อ่าน ไบต์

    AT24Cxx_WriteByte(&eeprom, 0, 42);  // เขียน 42 ที่ addr 0
    Delay_Ms(5);

    uint8_t val = AT24Cxx_ReadByte(&eeprom, 0);
    USART_Print("Value at addr 0: ");
    USART_PrintInt(val);
    USART_Println("");  // → 42

🔍 AT24Cxx_WriteByte(&eeprom, addr, val) — เขียน 1 ไบต์, AT24Cxx_ReadByte(&eeprom, addr) — อ่าน 1 ไบต์

ขั้นที่ 3: Sequential Read + Wear Leveling

    // Sequential Read
    uint8_t rbuf[32];
    AT24Cxx_ReadSeq(&eeprom, 0, rbuf, 32);

    // Wear Leveling — เขียนวนไปเรื่อยๆ
    uint16_t write_addr = 0;
    uint16_t eeprom_size = AT24Cxx_GetSize(&eeprom);
    while(1) {
        uint8_t data = (uint8_t)(write_addr & 0xFF);
        AT24Cxx_WriteByte(&eeprom, write_addr, data);
        Delay_Ms(5);

        write_addr = (write_addr + 1) % eeprom_size;
        Delay_Ms(1000);
    }
}

🔍 AT24Cxx_ReadSeq(&eeprom, addr, buf, len) — อ่านต่อเนื่องหลายไบต์, wear leveling: เขียนวนไปเรื่อยๆ ทั่วพื้นที่

⚠️ ข้อผิดพลาดที่พบบ่อย

ปัญหาสาเหตุวิธีแก้
อ่านค่าผิด/0xFF ตลอดลืม delay หลัง writeต้อง Delay_Ms(5) หลังเขียนทุกครั้ง
เขียนแล้วค่าที่ต้น page หายเขียนข้าม page boundaryเช็ค page size ก่อนเขียน
EEPROM พังเร็วเขียนที่ address เดิมซ้ำๆใช้ wear leveling กระจายการเขียน

🛠️ สร้าง Product: Config Store

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "AT24Cxx.h"

int main(void)
{
    SystemCoreClockUpdate();
    I2C_Init(I2C1, I2C_SPEED_STANDARD);
    USART_Init(USART1, BAUD_115200);

    AT24Cxx_Instance eeprom;
    AT24Cxx_Init(&eeprom, AT24C32, 0x50);

    // Load saved config
    uint8_t brightness = AT24Cxx_ReadByte(&eeprom, 0);
    if(brightness == 0xFF) brightness = 128;

    USART_Print("Brightness: ");
    USART_PrintInt(brightness);
    USART_Println("");

    // Save new config
    AT24Cxx_WriteByte(&eeprom, 0, 100);
    Delay_Ms(5);

    while(1);
}

✏️ ลองทำดู

  1. ทำ settings manager — เก็บ config ใน EEPROM → อ่านตอน boot
  2. ทำ event counter — นับจำนวนครั้งที่กดปุ่ม → เก็บใน EEPROM
  3. ต่อ AT24Cxx 2 ตัวบนบัส I2C เดียวกัน — address 0x50 และ 0x51
