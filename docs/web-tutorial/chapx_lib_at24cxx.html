🔌 การต่อวงจร

                AT24Cxx EEPROM I2C
    ┌──────────────────────────────────────────────┐
    │ CH32V003                       AT24C02/256   │
    │ PC1(SDA)────────SDA   ┌────────────────────┤
    │ PC2(SCL)────────SCL   │                    │
    │ 3.3V───────────VCC    │ Size   Address      │
    │ GND────────────GND    │ AT24C02  256B   0x50│
    │ WP─GND = write enable  │ AT24C32  4KB   0x50│
    │ A0,A1,A2─GND = 0x50   └────────────────────┤
    └──────────────────────────────────────────────┘
MCU Pin→อุปกรณ์ขาหมายเหตุ
PC1↔SDA-สายข้อมูล I2C — ต้องมี R 4.7kΩ pull-up ไป 3.3V
PC2→SCL-สายนาฬิกา I2C — ต้องมี R 4.7kΩ pull-up ไป 3.3V
3.3V→VCC-ไฟเลี้ยง 3.3V
GND→GND-กราวด์ร่วม
GND→WP-ต่อ GND = เปิดใช้งานการเขียน
GND→A0/A1/A2-ต่อ GND ทั้งหมด = I2C address 0x50 — สลับค่าเพื่อใช้หลายชิปบนบัสเดียวกัน

รู้จักขา

  • VCC: ไฟเลี้ยง 3.3V
  • GND: กราวด์
  • SDA (PC1): สายข้อมูล I2C
  • SCL (PC2): สายนาฬิกา I2C
  • WP: ต่อ GND = เปิดเขียน (write enable)
  • A0/A1/A2: เลือก I2C address — ต่อ GND ทั้งหมด = 0x50 — สูตร addr = 0x50 | (A2<<2) | (A1<<1) | A0
  • pull-up 4.7kΩ: ต่อระหว่าง SDA→3.3V และ SCL→3.3V (โมดูลส่วนมากมีในตัว)

วิธีต่อทีละขั้น

  1. ต่อ VCC ของ AT24Cxx ไป 3.3V
  2. ต่อ GND ของ AT24Cxx ไป GND
  3. ต่อ SDA ของ AT24Cxx ไป PC1 (ขา 13) ของ CH32V003
  4. ต่อ SCL ของ AT24Cxx ไป PC2 (ขา 14) ของ CH32V003
  5. ต่อ WP ไป GND เพื่อเปิดใช้งานการเขียน
  6. ต่อ A0/A1/A2 ไป GND ทั้งหมด — I2C address = 0x50
  7. ตรวจสอบว่าโมดูลมี R pull-up 4.7kΩ ในตัวหรือไม่ — ถ้าไม่มี ต่อ R เพิ่มจาก SDA→3.3V และ SCL→3.3V

📚 หลักการทำงาน

AT24Cxx เป็น EEPROM แบบ I2C — เก็บข้อมูลได้แม้ไม่มีไฟ, endurance ~1,000,000 write cycles ตาม LIMITATIONS.md, data retention >100 ปี — เหมาะกับการเก็บ config / calibration ที่เขียนนานๆ ครั้ง (ไม่ใช่ log ที่เขียนบ่อย)

รูปแบบ API (สำคัญ — ต่างจากบทเดิม): ทุกฟังก์ชันรับ AT24Cxx_Instance* เป็น arg แรก (instance-based) และทุกฟังก์ชันคืน AT24Cxx_Status (ไม่ใช่ค่าที่อ่านได้ตรงๆ) — ค่าที่อ่านได้ส่งกลับผ่าน out-param ด้วย pointer

รองรับตั้งแต่ AT24C01 (128B) ถึง AT24C512 (64KB) — เลือก type ใน AT24Cxx_Init แล้ว library จะคำนวณ capacity, page_size, addr_bytes ให้เอง

💻 เขียน Code ทีละขั้น

ขั้นที่ 1: Init + Setup

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "AT24Cxx.h"

AT24Cxx_Instance eeprom;

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();                                              // จำเป็น
    I2C_SimpleInit(I2C_100KHZ, I2C_PINS_DEFAULT);             // PC1=SDA, PC2=SCL
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);        // debug

    // type เป็น enum: AT24C01..AT24C512, i2c_addr 7-bit (default 0x50)
    AT24Cxx_Status st = AT24Cxx_Init(&eeprom, AT24C32, 0x50);
    if (st != AT24CXX_OK) {
        USART_Println("AT24Cxx Init FAILED!");
        USART_Println(AT24Cxx_StatusStr(st));
        while (1);
    }
    USART_Printf("AT24C32 ready, capacity=%lu bytes\r\n",
                 AT24Cxx_GetCapacity(&eeprom));

🔍 AT24Cxx_Init(&eeprom, type, i2c_addr) — คืน AT24Cxx_Status (ไม่ใช่ instance pointer) — type เป็น enum AT24C32 ไม่ใช่ int — ต้องเรียก Timer_Init() และ I2C_SimpleInit() ก่อน

ขั้นที่ 2: Write/Read Single Byte — เน้น status + out-param

    // WriteByte คืน status (ไม่ใช่ void) — ต้องเช็ค
    AT24Cxx_Status w = AT24Cxx_WriteByte(&eeprom, 0x00, 0xAB);
    //                                          eeprom  addr  data
    if (w != AT24CXX_OK) {
        USART_Print("Write fail: ");
        USART_Println(AT24Cxx_StatusStr(w));
    }
    // library จัดการ write cycle 5ms ให้ภายในตัว (AT24CXX_WRITE_CYCLE_MS)

    // ReadByte — data กลับมาเป็น OUT-PARAM ผ่าน pointer ไม่ใช่ return value
    uint8_t val = 0;   // เตรียม buffer ก่อน
    AT24Cxx_Status r = AT24Cxx_ReadByte(&eeprom, 0x00, &val);
    //                                          eeprom  addr &out
    if (r == AT24CXX_OK) {
        USART_Printf("Read addr 0x00 = 0x%02X\r\n", val);   // → 0xAB
    } else {
        USART_Println("Read fail");
    }

🔍 รูปแบบใหม่ที่ถูกต้อง: ReadByte คืน AT24Cxx_Status ส่วนค่าที่อ่านได้อยู่ใน out-param &val — ห้ามเขียน uint8_t v = AT24Cxx_ReadByte(&eeprom, 0) แบบเดิม (บทเดิมเขียนผิด — return เป็น status ไม่ใช่ byte) — ต้องเช็ค return ทุกครั้ง ไม่งั้นจะไม่รู้ว่า I2C fail หรือ address out of range

ขั้นที่ 3: Read Capacity + ทดสอบเขียน pattern

    uint32_t cap = AT24Cxx_GetCapacity(&eeprom);   // คืน bytes (ไม่ใช่ size enum)
    USART_Printf("Capacity = %lu bytes\r\n", cap);    // AT24C32 → 4096

    // เขียน test pattern แล้วอ่านกลับด้วย ReadArray (มี out-param)
    uint8_t pat[8] = {0xAA, 0x55, 0x01, 0x02, 0x03, 0x04, 0x05, 0x06};
    AT24Cxx_Status wp = AT24Cxx_WriteArray(&eeprom, 0x10, pat, 8);
    //                                       eeprom  addr  data len
    if (wp == AT24CXX_OK) {
        uint8_t rb[8] = {0};
        AT24Cxx_Status rp = AT24Cxx_ReadArray(&eeprom, 0x10, rb, 8);
        //                                        eeprom  addr &out len
        if (rp == AT24CXX_OK && memcmp(pat, rb, 8) == 0) {
            USART_Println("Pattern round-trip OK");
        }
    }

    while (1);
}

🔍 GetCapacity(&eeprom) คืน uint32_t bytes ไม่ใช่ขนาด enum — WriteArray / ReadArray คืน status เหมือนกัน — ทั้งคู่ข้าม page boundary อัตโนมัติ — buffer รับ (rb) เป็น out-param

🛠️ Product: Save Config Struct พร้อม CRC16

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "AT24Cxx.h"

#define EE_CFG_ADDR   0x0000
#define EE_MAGIC      0xA55A
#define SSID_MAX_LEN  32
#define PASS_MAX_LEN  32

typedef struct {
    uint16_t magic;
    uint16_t crc;
    char     ssid[SSID_MAX_LEN];
    char     pass[PASS_MAX_LEN];
    uint8_t  brightness;
    uint8_t  reserved[15];   // align รวม 96 bytes (เผื่อขยาย)
} ee_config_t;

ee_config_t cfg;
AT24Cxx_Instance eeprom;

uint16_t crc16(const uint8_t *data, uint16_t len) {
    uint16_t crc = 0xFFFF;
    while (len--) {
        crc ^= (uint16_t)(*data++) << 8;
        for (uint8_t i = 0; i < 8; i++)
            crc = (crc & 0x8000) ? (crc << 1) ^ 0x1021 : crc << 1;
    }
    return crc;
}

// บันทึก config → เขียนทั้ง struct ในครั้งเดียว (WriteArray ข้าม page boundary ให้)
AT24Cxx_Status cfg_save(void) {
    cfg.magic = EE_MAGIC;
    cfg.crc   = crc16((uint8_t *)&cfg + 4, sizeof(cfg) - 4);  // CRC ตัด magic+crc ออก

    return AT24Cxx_WriteArray(&eeprom, EE_CFG_ADDR,
                              (uint8_t *)&cfg, sizeof(cfg));
    //                               eeprom  addr   data   len
    // library รอ write cycle 5ms/segment ให้ภายในตัว
}

// โหลด config — คืน 1 = OK, 0 = ไม่ valid (ใช้ default)
uint8_t cfg_load(void) {
    uint8_t ok = 0;
    AT24Cxx_Status r = AT24Cxx_ReadArray(&eeprom, EE_CFG_ADDR,
                                         (uint8_t *)&cfg, sizeof(cfg));
    if (r != AT24CXX_OK) {
        USART_Println(AT24Cxx_StatusStr(r));
        return 0;
    }

    if (cfg.magic == EE_MAGIC) {
        uint16_t calc = crc16((uint8_t *)&cfg + 4, sizeof(cfg) - 4);
        if (calc == cfg.crc) {
            ok = 1;          // config valid
        } else {
            USART_Println("[EEPROM] CRC mismatch — config corrupt");
        }
    }
    if (!ok) {
        memset(&cfg, 0, sizeof(cfg));
        strcpy(cfg.ssid, "DEFAULT_SSID");
        strcpy(cfg.pass, "DEFAULT_PASS");
        cfg.brightness = 128;
    }
    return ok;
}

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    I2C_SimpleInit(I2C_100KHZ, I2C_PINS_DEFAULT);
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);

    if (AT24Cxx_Init(&eeprom, AT24C32, 0x50) != AT24CXX_OK) {
        USART_Println("EEPROM init fail");
        while (1);
    }

    uint8_t loaded = cfg_load();
    USART_Println(loaded ? "Config loaded from EEPROM" : "Default config loaded");
    USART_Print("SSID = "); USART_Println(cfg.ssid);
    USART_Printf("Brightness = %u\r\n", cfg.brightness);

    // สมมติผู้ใช้เปลี่ยนค่าจาก UI → บันทึก
    cfg.brightness = 200;
    strcpy(cfg.ssid, "MyHome");
    AT24Cxx_Status w = cfg_save();
    if (w == AT24CXX_OK) USART_Println("Config saved");
    else                 USART_Println(AT24Cxx_StatusStr(w));

    while (1);
}

🔍 เน้น pattern ที่ถูกต้อง: WriteArray และ ReadArray คืน AT24Cxx_Status — buffer เป็น out-param — magic+CRC16 ตรวจ integrity — WriteArray จัดการ write cycle 5ms/segment ภายในตัวให้ (จาก AT24CXX_WRITE_CYCLE_MS) — ไม่ต้อง Delay_Ms(5) เอง — อย่าเขียน AT24Cxx_Write(&eeprom, ...) แบบบทเดิม (ฟังก์ชันชื่อนั้นไม่มีใน header)

⚠️ ข้อผิดพลาดที่พบบ่อย

ปัญหาสาเหตุวิธีแก้
ReadByte ได้ 0xFF ตลอดลืมเช็ค status หรือชิปว่าง/ผิด addressเช็ค return ทุกครั้ง: if (AT24Cxx_ReadByte(&eeprom, addr, &v) != AT24CXX_OK) — ชิปใหม่อ่านได้ 0xFF เป็นค่า erased ปกติ — ยืนยัน address ตรง (A0/A1/A2 + type)
Write แล้วค่าไม่คงเช็ค AT24CXX_WRITE_CYCLE_MS = 5ms — เขียนซ้อนเร็วเกิน tWRLibrary รอ write cycle ให้ภายในตัวอยู่แล้ว — ถ้าเขียนซ้อนเองหลังเรียก API ต้องเว้นช่วง — หรือเช็ค status = AT24CXX_ERROR_TIMEOUT
ค่าที่อ่านผิดเพี้ยนเขียนผิด type (เช่น AT24C02 จริงแต่ตั้ง AT24C32)เช็ค enum type ให้ตรงรุ่นชิป — type ผิด → capacity/addr_bytes/page_size ผิด → I2C address sequence ผิด → อ่านตำแหน่งผิด
I2C error ตลอด (AT24CXX_ERROR_I2C)pull-up ขาด / SDA-SCL สลับ / WP ต่อ VCCเพิ่ม R 4.7kΩ pull-up — สลับสาย — ต่อ WP ไป GND เพื่อเปิดเขียน
Address out of bounds (AT24CXX_ERROR_ADDR_OOB)เขียนเลข address เกิน capacityใช้ AT24Cxx_GetCapacity(&eeprom) เช็คขนาดก่อนเขียน
EEPROM พังเร็วเขียนที่ address เดิมซ้ำๆ (endurance ~1M cycles)ใช้ wear leveling กระจาบการเขียน — อย่าเขียนใน loop แน่นอน — เขียนเฉพาะตอน config เปลี่ยน
Build fail: AT24Cxx_ReadByte ใช้เป็น return valueเขียนผิด: uint8_t v = AT24Cxx_ReadByte(...)ใช้ out-param: uint8_t v; AT24Cxx_ReadByte(&eeprom, addr, &v) แล้วเช็ค status — function คืน status ไม่ใช่ byte

✏️ ลองทำดู

  1. ทำ settings manager — เก็บ config (brightness, mode, threshold) เป็น struct ลง EEPROM → อ่านตอน boot → ถ้า magic ไม่ตรงใช้ default
  2. ทำ event counter — นับจำนวนครั้งที่กดปุ่มแล้วเก็บ uint32_t ด้วย AT24Cxx_WriteUint32(&eeprom, addr, value) + wear leveling หมุน address แต่ละครั้ง
  3. ต่อ AT24Cxx 2 ตัวบนบัสเดียวกัน — init 2 instance แยกใช้ address 0x50 และ 0x51 (A0 = VCC) — อ่าน capacity ทั้งคู่แล้วเปรียบเทียบ
