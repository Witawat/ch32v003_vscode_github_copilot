DHT11/DHT22 — วัดอุณหภูมิ+ความชื้น (GPIO)

3.3V─VCC  GND─GND  PC0─DATA  (R 4.7kΩ pull-up DATA↔3.3V)
MCU Pin→อุปกรณ์ขาหมายเหตุ
PC0↔DHT11/DHT22DATAGPIO bit-bang, ต้องมี pull-up 4.7kΩ
3.3V→DHT11/DHT22VCCจ่ายไฟ 3.3V
GND↔DHT11/DHT22GNDกราวด์ร่วม
 
#include "DHT.h"
DHT_Init(PC0, DHT11);   // หรือ DHT22
float t, h;
if(DHT_Read(&t, &h) == DHT_OK) {
    USART_Print("T:"); USART_PrintFloat(t, 1);
    USART_Print(" H:"); USART_PrintFloat(h, 1);
}

⚠️ DHT11 อ่านได้ทุก 1 วินาที, DHT22 ทุก 2 วินาที — ถ้าอ่านเร็วเกินจะได้ค่าเดิม, ถ้าคืน -999 = อ่านไม่สำเร็จ (สายหลวม/ไฟตก/pull-up หาย), COM port bit-bang — ห้ามเรียกใน interrupt เพราะต้อง polling รอ ~25ms, CRC 8-bit ใน DHT22 ตรวจสอบความถูกต้องของข้อมูล

API หลัก

DHT_Init(pin, type)กำหนด pin + รุ่น (DHT11/DHT22)DHT_Read(&t, &h)อ่านค่า — คืน DHT_OK/FAIL

DS18B20 — 1-Wire Temperature (GPIO)

3.3V─VCC  GND─GND  PC0─DQ  (R 4.7kΩ pull-up DQ↔3.3V)
MCU Pin→อุปกรณ์ขาหมายเหตุ
PC0 / PD2↔DS18B20DQ1-Wire bus, ต้องมี pull-up 4.7kΩ
3.3V→DS18B20VCCจ่ายไฟ 3.3V (หรือ parasite power)
GND↔DS18B20GNDกราวด์ร่วม
 
#include "DS18B20.h"
DS18B20_Device* s = DS18B20_Init(PD2);
float t = DS18B20_ReadTemperatureBlocking(s);

// Multi-sensor — หลาย DS18B20 บน bus เดียว
DS18B20_Device* sensors[3];
sensors[0] = DS18B20_Init(PD2);
sensors[1] = DS18B20_Init(PC0);
sensors[2] = DS18B20_Init(PC1);
for(uint8_t i = 0; i < 3; i++) {
    float ti = DS18B20_ReadTemperatureBlocking(sensors[i]);
    USART_Print("T"); USART_PrintNum(i);
    USART_Print(" = "); USART_PrintFloat(ti, 2);
}

⚠️ 1-Wire timing critical — ห้ามมี interrupt ตอนอ่าน, conversion time 750ms (12-bit) / 93.75ms (9-bit), parasite power mode ใช้ 2 wires (DQ+GND) — ต้องมี strong pull-up ระหว่าง conversion, แต่ละตัวมี unique 64-bit ROM ID, bus เดียวต่อได้หลายร้อยตัว, range -55°C ~ +125°C, accuracy ±0.5°C

API หลัก

DS18B20_Init(pin)Init sensor (returns DS18B20_Device*)DS18B20_ReadTemperatureBlocking(dev)อ่าน temp (blocking)
DS18B20_ReadTemperature(dev)อ่าน temp (non-blocking)DS18B20_SearchDevices(dev)ค้นหา devices ทั้งหมดบน bus
DS18B20_GetDeviceCount()จำนวน devicesDS18B20_GetROM(i, &rom)อ่าน ROM ID
DS18B20_GetTempC(&rom)อ่านตาม ROMDS18B20_SetResolution(bits)9/10/11/12 bit

BMP280 — วัดความกดอากาศ+อุณหภูมิ (I2C)

3.3V─VCC  GND─GND  PC1─SDA  PC2─SCL  (SDO─GND = 0x76, SDO─VCC = 0x77)
MCU Pin→อุปกรณ์ขาหมายเหตุ
PC1↔BMP280SDAI2C data
PC2→BMP280SCLI2C clock
3.3V→BMP280VCCจ่ายไฟ 3.3V
GND↔BMP280GNDกราวด์ร่วม
SDO→BMP280SDOต่อ GND = 0x76, VCC = 0x77
 
#include "BMP280.h"
BMP280_Init(0x76);                  // หรือ 0x77
BMP280_SetMode(BMP280_MODE_NORMAL); // SLEEP / FORCED / NORMAL
Delay_Ms(100);  // รอ measurement แรก
float t = BMP280_ReadTemperature();         // °C
float p = BMP280_ReadPressure() / 100.0f;   // hPa
float alt = BMP280_ReadAltitude(1013.25f);  // ความสูงจากระดับน้ำทะเล (m)

⚠️ 2 address: 0x76 (SDO=GND) vs 0x77 (SDO=VCC) — ต่อ 2 ตัวบน I2C เดียวได้, mode SLEEP (พัก), FORCED (วัดครั้งเดียวแล้วพัก), NORMAL (วัดต่อเนื่องอัตโนมัติ), calibration data อ่านจาก registers ภายใน — Lib จัดการให้, oversampling: temperature x1/x2/x4/x8/x16, pressure x1~x16, IIR filter: off/2/4/8/16

API หลัก

BMP280_Init(addr)Init + load calibrationBMP280_SetMode(mode)SLEEP/FORCED/NORMAL
BMP280_ReadTemperature()อ่าน temp (°C)BMP280_ReadPressure()อ่าน pressure (Pa)
BMP280_ReadAltitude(sea_hPa)คำนวณ altitude (m)BMP280_SetOversampling(t,p)ตั้ง oversampling

AHT10/AHT20 — วัดอุณหภูมิ+ความชื้น (I2C)

3.3V─VCC  GND─GND  PC1─SDA  PC2─SCL
MCU Pin→อุปกรณ์ขาหมายเหตุ
PC1↔AHT10/AHT20SDAI2C data
PC2→AHT10/AHT20SCLI2C clock
3.3V→AHT10/AHT20VCCจ่ายไฟ 3.3V
GND↔AHT10/AHT20GNDกราวด์ร่วม
 
#include "AHT10.h"
AHT10_Init(0x38);          // I2C addr fixed
AHT10_TriggerMeasurement();
Delay_Ms(80);              // รอวัดเสร็จ
float t = AHT10_ReadTemperature();
float h = AHT10_ReadHumidity();

⚠️ ต้องเรียก TriggerMeasurement() ก่อนอ่านทุกครั้ง — แตกต่างจาก DHT ที่อ่านอัตโนมัติ, I2C addr 0x38 (fix — เปลี่ยนไม่ได้), AHT20 = drop-in replacement (pin+code เหมือนแต่ accuracy ดีกว่า), init ต้องส่ง calibration command (Lib ทำ auto), CRC check ในตัว, accuracy ±0.3°C / ±2%RH

API หลัก

AHT10_Init(addr)Init + send cal cmdAHT10_TriggerMeasurement()สั่งวัด
AHT10_ReadTemperature()อ่าน temp (°C)AHT10_ReadHumidity()อ่าน humidity (%)

SHT3x — วัดอุณหภูมิ+ความชื้นแม่นยำสูง (I2C)

3.3V─VCC  GND─GND  PC1─SDA  PC2─SCL  (ADDR─GND = 0x44, ADDR─VCC = 0x45)
MCU Pin→อุปกรณ์ขาหมายเหตุ
PC1↔SHT3xSDAI2C data
PC2→SHT3xSCLI2C clock
3.3V→SHT3xVCCจ่ายไฟ 3.3V
GND↔SHT3xGNDกราวด์ร่วม
ADDR→SHT3xADDRต่อ GND = 0x44, VCC = 0x45
 
#include "SHT3x.h"
SHT3x_Init(0x44);         // หรือ 0x45
SHT3x_ReadSingle();       // single-shot measurement
float t = SHT3x_GetTemperature();
float h = SHT3x_GetHumidity();

// Periodic mode — อ่านต่อเนื่องไม่ต้อง trigger ทุกครั้ง
SHT3x_StartPeriodic(SHT3x_1MPS);  // 1 measurement/sec
while(1) {
    SHT3x_ReadPeriodic();
    float tp = SHT3x_GetTemperature();
    float hp = SHT3x_GetHumidity();
    Delay_Ms(1000);
}

⚠️ 2 address: ADDR pin GND=0x44, VCC=0x45 — ต่อ 2 ตัวบน I2C เดียวได้, มี heater สำหรับ de-icing (ไล่น้ำแข็ง), accuracy ±0.3°C / ±2%RH, เร็วกว่า DHT22 มาก (วัดเสร็จใน ~15ms), repeatability สูง, alert pin สำหรับแจ้งเตือน threshold

API หลัก

SHT3x_Init(addr)Init sensorSHT3x_ReadSingle()Single-shot measurement
SHT3x_GetTemperature()อ่าน temp หลัง readSHT3x_GetHumidity()อ่าน humidity หลัง read
SHT3x_StartPeriodic(mps)เริ่ม periodic modeSHT3x_ReadPeriodic()อ่านตามจังหวะที่ตั้งไว้
SHT3x_Heater(en)เปิด/ปิด heaterSHT3x_SetMPS(mps)0.5/1/2/4/10 MPS

MAX31855 / MAX6675 — Thermocouple K-Type (SPI)

3.3V─VCC  GND─GND  PC4─CS  PC5─SCK  PC7─MISO  (Thermocouple → K-type)
MCU Pin→อุปกรณ์ขาหมายเหตุ
PC4→MAX31855/MAX6675CSChip select (SPI)
PC5→MAX31855/MAX6675SCKSPI clock
PC7←MAX31855/MAX6675MISOSPI data out (อ่านค่า)
3.3V→MAX31855/MAX6675VCCจ่ายไฟ 3.3V
GND↔MAX31855/MAX6675GNDกราวด์ร่วม
Thermocouple←MAX31855/MAX6675T+/T−K-type thermocouple
 
#include "MAX31855.h"
MAX31855_Init(PC4);               // CS pin
float tc = MAX31855_ReadCelsius();  // thermocouple temp
float cj = MAX31855_ReadInternal(); // cold-junction temp
uint8_t fault = MAX31855_ReadFault(); // 0=OK, bit0=OC, bit1=SCG, bit2=SCV

// MAX6675 variant (16-bit, simpler):

MAX6675_Init(PC4);
float t = MAX6675_ReadCelsius();

⚠️ SPI mode 0, MAX31855 = 32-bit read (14-bit TC + 12-bit CJ + fault bits), MAX6675 = 16-bit read (12-bit TC), ทั้งคู่เป็น K-type, cold-junction compensation ฝังในชิป → ไม่ต้องคำนวณเอง, thermocouple ไม่ต้องใช้ ADC — ชิปอ่าน mV ตรง, MAX31855 range -270°C ~ +1372°C, accuracy ±2°C, SPI pins ใน SOP-8 ไม่มี — ใช้กับ SOP-16/QFN เท่านั้น

API หลัก

MAX31855_Init(cs_pin)Init SPI + CSMAX31855_ReadCelsius()อ่าน temp TC (°C)
MAX31855_ReadInternal()อ่าน CJ tempMAX31855_ReadFault()ตรวจ fault: OC/SCG/SCV
MAX6675_Init(cs_pin)Init MAX6675MAX6675_ReadCelsius()อ่าน temp (°C)

เลือกยังไง? อุณหภูมิทั่วไป → DHT22/AHT10, ต้องการความชื้นด้วย → AHT10/SHT3x, วัดกลางแจ้ง/กันน้ำ → DS18B20, ความกดอากาศ → BMP280, อุณหภูมิสูงมาก (เตาเผา) → MAX31855, โปรเจกต์ละเอียดสูง → SHT3x

✏️ ลองทำดู

  1. เทียบ DHT11 vs AHT10 — ต่อทั้ง 2 ตัว (คนละ interface — GPIO + I2C) วัดพร้อมกัน แสดงผลบน OLED ดู accuracy ต่างกันไหม
  2. DS18B20 3 ตัวบน 1-Wire เดียว — แสดง ROM ID และอุณหภูมิทีละตัว — ใช้ลูปวน DS18B20_GetDeviceCount()
  3. BMP280 แสดง altitude + sea-level pressure — หาความสูงของห้องเทียบกับ Google Maps
  4. MAX31855 อ่านอุณหภูมิทุก 500ms — plot graph ผ่าน USART (ส่งค่าขึ้น Serial Plotter ใน Arduino IDE)
  5. รวม 3 sensor: DS18B20 + AHT10 + BMP280 — ทำ weather station ย่อส่วน แสดง temp, hum, pressure, altitude
