ex01_Sleep_Mode — เข้า Sleep + ปลุกด้วย EXTI

📖 แนวคิด

Sleep mode ปิด CPU clock แต่ SRAM และ peripheral ยังทำงาน — ใช้ PWR_EnterSleepMode เข้า sleep — ปลุกด้วย EXTI interrupt (ปุ่มกด) — กินกระแส ~mA

🔌 วงจร

    CH32V003              LED
    PC0 ----/\/\/\---->|---- GND
           220 Ohm

    PC1 -- Button -- GND     (INPUT_PULLUP, ปลุกด้วย FALLING)
MCU Pin→อุปกรณ์ขาหมายเหตุ
PC0→R 220Ωขา 1จำกัดกระแส LED
R 220Ω→LED (แอโนด)ขายาว (+)—
LED (แคโทด)→GNDขาสั้น (-)—
PC1→Push Buttonขา 1Input pull-up, wake from sleep
Push Button→GNDขา 2FALLING edge triggers wake

รู้จักขา

  • PC0: ขาออก ต่อ LED แสดงสถานะ — ติดเมื่อตื่น, ดับเมื่อหลับ
  • PC1: ขาอินพุต (pull-up) — กดปุ่มเพื่อปลุก MCU จาก Sleep
  • R 220Ω: จำกัดกระแส LED
  • Push Button: ACTIVE_LOW — กด = LOW (FALLING edge ปลุก EXTI)

วิธีต่อทีละขั้น

  1. ต่อ PC0 → R 220Ω → LED แอโนด, LED แคโทด → GND
  2. ต่อ PC1 ไป Push Button ขา 1 — ขาปลุก
  3. ต่อ Push Button ขา 2 ไป GND — กดปุ่ม = FALLING edge

🧭 ผังการทำงาน

flowchart TD
    A["Init + attachInterrupt()"] --> B["while(1)"]
    B --> C["digitalToggle(LED)"]
    C --> D["PWR_EnterSleepMode()"]
    D --> E["⏰ Wake by EXTI"]
    E --> B

💻 โค้ด + อธิบายทีละบรรทัด

#define CH32V003_PACKAGE  PACKAGE_TSSOP20
#include <SimpleHAL.h>

volatile uint8_t wake_flag = 0;

void EXTI_Callback(void) {                           // เรียกเมื่อปุ่มกด (FALLING)
    wake_flag = 1;
}

int main(void)
{
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);
    pinMode(PC0, PIN_MODE_OUTPUT);
    pinMode(PC1, PIN_MODE_INPUT_PULLUP);
    attachInterrupt(PC1, EXTI_Callback, FALLING);    // EXTI ขอบตก

    USART_Print("Entering sleep — press button to wake\r\n");

    while(1)
    {
        wake_flag = 0;
        PWR_EnterSleepMode();                        // ★ หยุด CPU — รอ interrupt
        // กลับมาทำงานต่อหลังจาก EXTI
        digitalToggle(PC0);                          // LED สลับ = ตื่นแล้ว
        USART_Print("Woke up!\r\n");
        Delay_Ms(500);
    }
}
  • PWR_EnterSleepMode(): WFI (Wait For Interrupt) — หยุด CPU จนกว่า interrupt ใด ๆ เกิดขึ้น
  • Sleep = CPU off, peripherals on: USART, Timer, GPIO ยังทำงาน — กระแส ~2-5mA
  • EXTI (FALLING): ปุ่มกด (pull-up) กด = LOW → EXTI trigger → CPU ตื่น

⚠️ จุดควรระวัง

  • หลัง PWR_EnterSleepMode บรรทัดถัดไปทำงานทันที — CPU เริ่มจากตรงนั้น ไม่ใช่从头
  • interrupt ต้อง enable ก่อนเข้า sleep — ถ้าไม่มี interrupt → CPU หลับตลอด
  • Sleep mode ตื่นเร็ว (~µs) แต่กระแสยังสูง — ถ้าต้องการประหยัดกว่านี้ใช้ Standby

✅ ตรวจสอบก่อนรัน

  • ปุ่มกดต่อถูก? PC1-PULLUP → Button → GND (ACTIVE_LOW)
  • EXTI ค้าง? กดปุ่มค้างไว้ตอน sleep → ตื่นทันที

ex02_Standby_AWU — Standby + ปลุกด้วย Auto Wake-up

📖 แนวคิด

Standby mode ปิดเกือบทุกอย่าง — SRAM, register หาย — ใช้ PWR_ConfigureAWU ตั้งเวลาปลุกอัตโนมัติด้วย LSI — ใช้ WasStandbyWakeup เช็คว่าตื่นจาก Standby หรือไม่

🧭 ผังการทำงาน

flowchart TD
    A["PWR_ConfigureAWU(5s)"] --> B{"PWR_WasStandbyWakeup?"}
    B -->|"Yes"| C["Print Woke up"]
    B -->|"No"| D["Print First boot"]
    C --> E["PWR_EnterStandbyMode()"]
    D --> E
    E --> A

💻 โค้ด

#define CH32V003_PACKAGE  PACKAGE_TSSOP20
#include <SimpleHAL.h>

int main(void)
{
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);

    if(WasStandbyWakeup()) {                         // เช็คว่าตื่นจาก Standby?
        USART_Print("Woke from Standby!\r\n");
    } else {
        USART_Print("Cold boot\r\n");
    }

    // ตั้ง AWU ปลุกทุก ~2s (LSI 40kHz / 16 / 5000 ≈ 2s)
    PWR_ConfigureAWU(PWR_AWU_DIVIDER_16, 5000);      // divider=16, counter=5000
    PWR_EnterStandbyMode();                          // ★ เข้า Standby — ทุกอย่างดับ

    // ไม่ถึงตรงนี้ — MCU รีเซ็ตเมื่อตื่น
    while(1) { IWDG_Feed(); }
}
  • PWR_ConfigureAWU(divider, counter): ตั้ง AWU (Auto Wake-up) — ใช้ LSI 40kHz → divider → counter → timeout = counter × divider / LSI
  • PWR_EnterStandbyMode(): ปิด Vcore — SRAM/lost register หาย — เมื่อตื่น = เหมือนรีเซ็ต (startup จาก main ใหม่)
  • WasStandbyWakeup(): อ่าน RCC flag ว่าตื่นจาก Standby หรือ boot จริง — ใช้ตอน initialization

⚠️ จุดควรระวัง

  • Standby = กระแส ~nA — แต่ข้อมูลหายทั้งหมด — ต้อง reconfigure ทุกอย่างหลังตื่น
  • WasStandbyWakeup() คืนค่าได้ครั้งเดียว — ต้อง read แล้ว clear (หรือใช้ครั้งแรกเท่านั้น)
  • AWU ใช้ LSI oscillator — LSI มีความแม่นยำ ±50% — เวลาปลุกอาจคลาดเคลื่อน

✅ ตรวจสอบก่อนรัน

  • หลังจากเข้า Standby แล้ว MCU ควรปลุกทุก ~2s — ดู USART "Woke from Standby!" ซ้ำ ๆ
  • ลองกด reset — ควรเห็น "Cold boot" ครั้งแรก

ex03_Standby_External_Wake — ปลุก Standby ด้วย External Wakeup Pin

📖 แนวคิด

ใช้ PWR_EnableWakeupPin เปิดใช้งานขา wakeup (PA0/PA2/PC1) — MCU อยู่ใน Standby — เมื่อสัญญาณที่ขามา (rising edge) → MCU ตื่น — เหมาะกับ remote sensor ที่กดปุ่มแล้วส่งค่า

🧭 ผังการทำงาน

flowchart TD
    A["PWR_EnableWakeupPin(PA0, RISING)"] --> B["PWR_EnterStandbyMode()"]
    B --> C["⏰ Wake by PA0 rising edge"]
    C --> D{"WasStandbyWakeup?"}
    D -->|"Yes"| E["Print Woke by pin"]
    D -->|"No"| F["Cold boot"]
    E --> A
    F --> A

💻 โค้ด

#define CH32V003_PACKAGE  PACKAGE_TSSOP20
#include <SimpleHAL.h>

int main(void)
{
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);

    if(WasStandbyWakeup()) {
        USART_Print("Woke by external wakeup pin!\r\n");
    }

    PWR_EnableWakeupPin(PWR_WAKEUP_PIN_PA0, RISING); // PA0 ขอบขึ้น = ปลุก
    PWR_EnterStandbyMode();

    while(1) { IWDG_Feed(); }
}
  • PWR_EnableWakeupPin(pin, mode): เปิดใช้งาน wakeup pin — RISING/FALLING — pin ที่เลือกได้: PA0, PA2, PC1
  • External wakeup pin: อุปกรณ์ต่อพ่วง active ต่ำ — พอ active → ส่ง rising edge → MCU ตื่น
  • Standby + external wake: กระแส ~300nA — ตื่นเร็ว ~50µs

⚠️ จุดควรระวัง

  • Wakeup pin บางขาเท่านั้น — PA0, PA2, PC1 ขึ้นกับชิป — เช็ค datasheet
  • Rising/Falling edge ตั้งได้ — แต่อุปกรณ์ต้องให้สัญญาณตรงกับที่ตั้ง
  • ใน Standby I/O เป็น Hi-Z — pull-up/pull-down ก็ปิด — วงจรภายนอกต้องจัดการ电平

ex04_PVD_Monitor — ตรวจสอบแรงดันตกด้วย PVD

📖 แนวคิด

Programmable Voltage Detector (PVD) ตรวจสอบ VDD — ถ้าแรงดันต่ำกว่าเกณฑ์ที่ตั้ง (2.2V-2.9V) → interrupt หรือ flag — ใช้ป้องกันข้อมูลเสียหายเมื่อแบตใกล้หมด

🧭 ผังการทำงาน

flowchart TD
    A["PWR_SetCallback(PVD_Callback)"] --> B["PWR_EnablePVD(2.7V)"]
    B --> C["while(1)"]
    C --> D{"VDD < 2.7V?"}
    D -->|"Yes"| E["PVD interrupt → flag"]
    E --> F["Print Low voltage"]
    D -->|"No"| G["Poll PWR_GetPVDStatus()"]
    F --> C
    G --> C

💻 โค้ด

volatile uint8_t voltage_low = 0;

void PVD_Callback(void) {
    voltage_low = 1;                                 // แรงดันต่ำกว่าเกณฑ์
}

int main(void)
{
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);

    PWR_SetCallback(PVD_Callback);                   // ลงทะเบียน PVD interrupt
    PWR_EnablePVD(PWR_PVD_LEVEL_2V7);                // ตั้ง threshold 2.7V
    // เมื่อ VDD < 2.7V → PVD_Callback ถูกเรียก

    USART_Print("PVD Monitor Ready (threshold=2.7V)\r\n");

    while(1)
    {
        if(voltage_low) {
            USART_Print("⚠ Low voltage detected!\r\n");
            // บันทึกข้อมูลสำคัญลง Flash ก่อน VDD หมด
            voltage_low = 0;
        }

        // เช็ค PVD แบบ polling ด้วย
        if(PWR_GetPVDStatus()) {
            USART_Print("PVD active (polling)\r\n");
        }

        Delay_Ms(500);
        IWDG_Feed();
    }
}
  • PWR_EnablePVD(level): เปิด PVD — ตั้ง threshold 2.2V-2.9V — เมื่อ VDD ต่ำกว่า → PVD flag set + interrupt
  • PWR_GetPVDStatus(): อ่าน PVD flag แบบ polling — คืน 1 ถ้า VDD ต่ำกว่า threshold
  • PVD level options: PWR_PVD_LEVEL_2V2, _2V3, _2V4, _2V5, _2V6, _2V7, _2V8, _2V9

⚠️ จุดควรระวัง

  • PVD เปรียบเทียบ VDD กับ threshold — ไม่ใช่ VREF หรือแบต
  • PVD level ไม่ละเอียดมาก — เลือกค่าที่ใกล้เคียงกับ VDD_min ของวงจร
  • PVD interrupt ใช้ PVD_IRQn — เปิด NVIC ด้วย

ex05_Battery_Life_Estimation — ประมาณอายุแบตเตอรี่

📖 แนวคิด

ใช้ CalculateBatteryLife คำนวณอายุแบตจากความจุแบตและกระแสที่ใช้ — และ EstimateStandbyCurrent ประมาณกระแส standby จาก configuration ปัจจุบัน — ช่วยออกแบบระบบ battery-powered

🧭 ผังการทำงาน

flowchart TD
    A["Define battery params"] --> B["CalculateBatteryLife(220mAh, ...)"]
    B --> C["Print estimated hours/days"]
    C --> D["EstimateStandbyCurrent()"]
    D --> E["Print estimated nA"]
    E --> F["while(1)"]

💻 โค้ด

#define CH32V003_PACKAGE  PACKAGE_TSSOP20
#include <SimpleHAL.h>

int main(void)
{
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);

    // ตัวอย่าง: แบต CR2032 220mAh
    uint32_t active_current_ua = 3200;                // 3.2mA ขณะทำงาน
    uint32_t standby_current_na = 500;                // 500nA ขณะ standby
    uint32_t active_time_ms = 50;                     // ทำงาน 50ms
    uint32_t standby_time_ms = 9950;                  // standby 9950ms (รอบ 10s)

    uint32_t hours = CalculateBatteryLife(
        220,                                          // แบต 220mAh
        active_current_ua, standby_current_na,
        active_time_ms, standby_time_ms
    );

    USART_Print("Estimated battery life: ");
    USART_PrintNum(hours);
    USART_Print(" hours (");
    USART_PrintNum(hours / 24);
    USART_Print(" days)\r\n");

    uint32_t estimated_na = EstimateStandbyCurrent();
    USART_Print("Estimated standby current: ");
    USART_PrintNum(estimated_na);
    USART_Print(" nA\r\n");

    while(1) { IWDG_Feed(); }
}
  • CalculateBatteryLife(mAh, active_ua, standby_na, active_ms, standby_ms): คำนวณอายุแบตเป็นชั่วโมง — ใช้ duty cycle เฉลี่ย
  • EstimateStandbyCurrent(): ประมาณกระแส standby จาก peripheral ที่เปิดอยู่ — AWU, PVD, IWDG แต่ละตัวกินกระแสเพิ่ม ~nA
  • Duty cycle สำคัญ: ยิ่ง active time สั้น + standby นาน = แบตยืนยาว

⚠️ จุดควรระวัง

  • EstimateStandbyCurrent เป็นแค่การประมาณ — ค่าจริงขึ้นกับ voltage, temperature
  • แบต CR2032 จริง ๆ 220mAh ที่ 25°C — ถ้าหนาว = ความจุลดลง
  • คำนวณด้วย active time จริง — รวมเวลาบูต + ADC + ส่งข้อมูล

ex06_Wakeup_Pin — AWU + Wakeup Pin ใช้ร่วมกัน

📖 แนวคิด

รวม AWU (ปลุกเป็นระยะ) กับ Wakeup Pin (ปลุกเมื่อมีเหตุการณ์) — AWU ปลุกทุก 10s เพื่ออ่าน sensor — Wakeup Pin ปลุกเมื่อมี interrupt จากภายนอก — ยืดหยุ่นและประหยัดพลังงานสูงสุด

🧭 ผังการทำงาน

flowchart TD
    A{"WasStandbyWakeup?"} -->|"Yes"| B{"PWR_GetWakeupFlag?"}
    B -->|"1 (AWU)"| C["Print Woke by AWU"]
    B -->|"0 (Pin)"| D["Print Woke by ext pin"]
    C --> E["PWR_ConfigureAWU(10s)"]
    D --> E
    E --> F["PWR_EnableWakeupPin(PA0, RISING)"]
    F --> G["PWR_EnterStandbyMode()"]
    G --> A
    A -->|"No"| E

💻 โค้ด

#define CH32V003_PACKAGE  PACKAGE_TSSOP20
#include <SimpleHAL.h>

int main(void)
{
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);

    if(WasStandbyWakeup()) {
        if(PWR_GetWakeupFlag()) {
            USART_Print("Woke by AWU timer\r\n");
        } else {
            USART_Print("Woke by external wakeup pin\r\n");
        }
    }

    // AWU ปลุกทุก ~10s (LSI 40kHz / 128 / 3125 ≈ 10s)
    PWR_ConfigureAWU(PWR_AWU_DIVIDER_128, 3125);

    // Wakeup pin PA0 — กดปุ่มปลุก
    PWR_EnableWakeupPin(PWR_WAKEUP_PIN_PA0, RISING);

    PWR_EnterStandbyMode();                          // เข้า standby

    while(1) { IWDG_Feed(); }
}
  • PWR_GetWakeupFlag(): อ่าน flag ว่าตื่นเพราะ AWU (1) หรือ external wakeup pin (0)
  • AWU + Wakeup Pin = hybrid: AWU สำหรับ periodic task, wakeup pin สำหรับ event-driven
  • PWR_EnterStandbyMode: เปิดทั้งสองอย่างก่อนเข้า — อะไรเกิดก่อนก็ตื่น

⚠️ จุดควรระวัง

  • PWR_GetWakeupFlag ต้องอ่านหลัง WasStandbyWakeup — flag จะถูกล้างอัตโนมัติ
  • AWU divider/counter = timeout — ถ้าตั้งค่าผิด ปลุกถี่เกินไป = กินแบต
  • ทั้ง AWU และ Wakeup Pin ใช้ LSI — ถ้า LSI ไม่ stable ค่าอาจคลาดเคลื่อน
