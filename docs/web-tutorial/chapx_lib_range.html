HCSR04 — Ultrasonic Distance (GPIO)

PC0─TRIG  PC1─ECHO  5V─VCC  GND─GND
⚠️ ECHO 5V → voltage divider 2.2kΩ+3.3kΩ ลดเหลือ ~3.3V
MCU Pin→อุปกรณ์ขาหมายเหตุ
PC0→HC-SR04TRIGสั่งส่ง ultrasonic 10µs pulse
PC1←HC-SR04ECHOรับ pulse ตามระยะทาง
5V→HC-SR04VCCจ่ายไฟ 5V
GND↔HC-SR04GNDกราวด์ร่วม
 
#include "HCSR04.h"
HCSR04_Init(PC0, PC1);
float dist = HCSR04_MeasureCm();
if(dist > 0) { USART_PrintFloat(dist, 1); USART_Println(" cm"); }
// Average: float avg = HCSR04_ReadAvgCm(5); // 5 samples

⚠️ Range 2-400cm, angle ~15°, ECHO 5V → ต้องใช้ voltage divider (2.2kΩ+3.3kΩ), pulseIn timeout 30ms, ห้ามวัดถี่กว่า 60ms (รอ echo decay), sound speed varies with temp → 0.6% error per 1°C, ถ้าคืน 0 = object อยู่นอกระยะ / timeout

API หลัก

HCSR04_Init(trig, echo)ตั้ง pin TRIG + ECHOHCSR04_MeasureCm()อ่านระยะ cm
HCSR04_ReadAvgCm(n)เฉลี่ย n samplesHCSR04_ReadInch()อ่านระยะนิ้ว

VL53L0X — ToF Laser Distance (I2C)

PC1─SDA  PC2─SCL  3.3V─VCC  GND─GND  XSHUT─3.3V (หรือ GPIO สำหรับ multi-sensor)
MCU Pin→อุปกรณ์ขาหมายเหตุ
PC1↔VL53L0XSDAI2C data
PC2→VL53L0XSCLI2C clock
3.3V→VL53L0XVCCจ่ายไฟ 3.3V
GND↔VL53L0XGNDกราวด์ร่วม
XSHUT→VL53L0XXSHUTต่อ 3.3V หรือ GPIO ควบคุม
 
#include "VL53L0X.h"
VL53L0X_Init(0x29); // I2C addr (เปลี่ยน XSHUT สำหรับ multiple)
uint16_t mm = VL53L0X_ReadRangeMM();
// Continuous mode: VL53L0X_StartContinuous(); VL53L0X_ReadRangeContinuous();

⚠️ Range 3-200cm (indoor, dark surface), accuracy ±3%, แสงแดดจัดอ่านไม่ได้ — ใช้ในที่ร่ม/ในห้อง, I2C addr 0x29 (single), multi-sensor: toggle XSHUT → assign address ใหม่ทีละตัว, เร็วกว่า+แม่นกว่าอัลตราโซนิคสำหรับระยะ <2m, range mode: default/long/high speed เลือกได้

API หลัก

VL53L0X_Init(addr)Init + calibrationVL53L0X_ReadRangeMM()Single-shot (mm)
VL53L0X_StartContinuous()เริ่ม continuousVL53L0X_ReadRangeContinuous()อ่านต่อเนื่อง
VL53L0X_SetRangeMode(mode)Default/Long/HighSpeedVL53L0X_SetTimeout(ms)Timeout

MPU6050 — Gyro+Accel 6-axis (I2C)

PC1─SDA  PC2─SCL  3.3V─VCC  GND─GND  AD0─GND (=0x68, หรือ VCC =0x69)
MCU Pin→อุปกรณ์ขาหมายเหตุ
PC1↔MPU6050SDAI2C data
PC2→MPU6050SCLI2C clock
3.3V→MPU6050VCCจ่ายไฟ 3.3V
GND↔MPU6050GNDกราวด์ร่วม
AD0→MPU6050AD0ต่อ GND = 0x68, VCC = 0x69
 
#include "MPU6050.h"
MPU6050_Data_t data;
MPU6050_Init(0x68);
MPU6050_GetAll(&data);
// Accel (raw → g): float ax = data.ax / 16384.0f;
// Gyro (raw → °/s): float gx = data.gx / 131.0f;
// Complementary filter:
float angle = 0.98f * (angle + gx*dt) + 0.02f * (atan2(ay, az)*57.3f);

⚠️ I2C addr 0x68 (AD0=GND) หรือ 0x69 (AD0=VCC), gyro drift ~0.05°/s → ใช้ complementary filter ชดเชย, accel noise ±0.01g, calibration: อ่าน 100 samples ตอนอยู่กับที่ → หัก bias, DMP (Digital Motion Processor) → CH32V003 RAM 2KB ไม่พอ (ต้องใช้ MCU ที่ RAM ≥16KB), range configurable: accel ±2/4/8/16g, gyro ±250/500/1000/2000°/s

API หลัก

MPU6050_Init(addr)Init + wake upMPU6050_GetAll(&data)อ่าน accel+gyro+temp
MPU6050_ReadAccel(&data)อ่านเฉพาะ accelMPU6050_ReadGyro(&data)อ่านเฉพาะ gyro
MPU6050_Calibrate(n)หัก bias จาก n samplesMPU6050_SetRange(acc, gyr)ตั้ง range

AS5600 — Magnetic Encoder 12-bit (I2C)

PC1─SDA  PC2─SCL  3.3V─VCC  GND─GND  DIR─GND (clockwise, หรือ VCC กลับทิศ)
MCU Pin→อุปกรณ์ขาหมายเหตุ
PC1↔AS5600SDAI2C data
PC2→AS5600SCLI2C clock
3.3V→AS5600VCCจ่ายไฟ 3.3V
GND↔AS5600GNDกราวด์ร่วม
DIR→AS5600DIRต่อ GND = clockwise, VCC = reverse
 
#include "AS5600.h"
AS5600_Init();
uint16_t raw = AS5600_ReadAngle();        // 0-4095
float deg = AS5600_ReadAngleDegrees();    // 0.0-359.9
// Zero position: AS5600_SetZeroPosition(current_angle);
// Detect magnet: if(AS5600_GetStatus() & AS5600_MAGNET_DETECT)

⚠️ ต้องมีแม่เหล็ก diametrically magnetized อยู่เหนือ IC ~1-2mm, 12-bit = 0.088° resolution, I2C addr 0x36 (fix), PWM/analog output modes ใช้แทน I2C ได้ (แต่ CH32V003 อ่าน I2C แม่นกว่า), แม่เหล็กแรงเกิน/อ่อนเกิน → reading error, DIR pin กลับทิศการนับ, no-contact → ทนทานกว่า potentiometer, zero position ตั้งด้วยการเขียน register หรือ ZPOS pin

API หลัก

AS5600_Init()Init + check magnetAS5600_ReadAngle()Raw 0-4095
AS5600_ReadAngleDegrees()0.0-359.9°AS5600_SetZeroPosition(raw)ตั้งตำแหน่งศูนย์
AS5600_GetStatus()Status registerAS5600_GetMagnetStrength()AGAIN + magnitude

PIR — Motion Sensor (GPIO)

PC1─OUT  5V─VCC  GND─GND  (OUT 3.3V compatible — ต่อตรงได้)
MCU Pin→อุปกรณ์ขาหมายเหตุ
PC1←PIR Motion SensorOUTHIGH เมื่อ detect การเคลื่อนไหว
5V→PIR Motion SensorVCCจ่ายไฟ 5V
GND↔PIR Motion SensorGNDกราวด์ร่วม
 
volatile uint8_t motion = 0;
void pir_isr(void) { motion = 1; }
pinMode(PC1, PIN_MODE_INPUT);
attachInterrupt(PC1, pir_isr, RISING);
while(1) {
    if(motion) { motion=0; USART_Println("Motion!"); digitalWrite(PC0,HIGH); Delay_Ms(3000); digitalWrite(PC0,LOW); }
    PWR_Sleep(); // sleep until next motion
}

⚠️ 2 potentiometer บนโมดูล: sensitivity (ปรับระยะ detect) + delay time (HIGH output duration), ใช้ interrupt ดีกว่า polling — ประหยัดพลังงาน, ต้องมี warm-up 30-60s หลังจ่ายไฟ (sensor stabilize), false trigger ในที่มีลม/ความร้อนเปลี่ยนแปลงเร็ว/แสงแดด, detect infrared จากคน/สัตว์เท่านั้น — ไม่ทะลุกำแพง, OUT pulse = HIGH เมื่อ detect → 2-200s (ขึ้นกับ delay pot)

API หลัก

attachInterrupt(pin, isr, edge)ตั้ง interruptpinMode(pin, INPUT)ตั้งขาเป็น input
PWR_Sleep()MCU เข้า sleepdigitalRead(pin)อ่านสถานะ (polling)

RCWL0516 — Microwave Radar (GPIO)

PC1─OUT  3.3-5V─VCC  GND─GND  (OUT 3.3V compatible)
MCU Pin→อุปกรณ์ขาหมายเหตุ
PC1←RCWL0516OUTHIGH เมื่อ detect movement
3.3–5V→RCWL0516VCCจ่ายไฟ 3.3–5V
GND↔RCWL0516GNDกราวด์ร่วม
 
volatile uint8_t radar = 0;
void radar_isr(void) { radar = 1; }
pinMode(PC1, PIN_MODE_INPUT);
attachInterrupt(PC1, radar_isr, RISING);
while(1) {
    if(radar) { radar=0; USART_Println("Movement detected!"); digitalWrite(PC0,HIGH); Delay_Ms(2000); digitalWrite(PC0,LOW); }
    PWR_Sleep();
}

⚠️ ผ่านกำแพงได้ (ต่างจาก PIR) — detect movement หลังผนังบาง/พลาสติก/กระจก, range ~5-7m, Doppler effect → ตรวจจับเฉพาะ movement (ไม่ใช่ presence — คนยืนนิ่งไม่ detect), กินไฟมากกว่า PIR (~3mA vs <0.1mA) — ไม่เหมาะกับ battery, ไม่มี delay adjust → OUT pulse ต่อเนื่องตราบที่ detect movement, 3.3-5V wide range input, CDS pin สำหรับปิดเมื่อมีแสง (ต่อ photoresistor)

API หลัก

attachInterrupt(pin, isr, edge)ตั้ง interruptpinMode(pin, INPUT)ตั้งขาเป็น input
PWR_Sleep()MCU เข้า sleepdigitalRead(pin)อ่านสถานะ (polling)

เลือกยังไง? วัดระยะแม่น → VL53L0X (ในร่ม) / HCSR04 (ทั่วไป), ตรวจจับการเคลื่อนไหวคน → PIR (ประหยัด) / RCWL0516 (ทะลุกำแพง), วัดมุม/การหมุน → AS5600 (no-contact) / MPU6050 (6-axis), สร้าง motion controller → MPU6050

✏️ ลองทำดู

  1. HC-SR04 parking sensor — LED สีเขียว >50cm, เหลือง 20-50cm, แดง <20cm, buzzer ดังถี่ขึ้นเมื่อใกล้ พร้อมแสดงค่าระยะ cm บน OLED
  2. MPU6050 tilt alarm — buzzer เมื่อเอียง > 30° (คำนวณจาก complementary filter), แสดงองศาบน OLED
  3. AS5600 knob controller — อ่านมุม → ส่งค่า serial + ใช้ OLED แสดงมุมแบบกราฟิก (แถบหมุน), ใช้เปิด/ปิด LED ตาม quadrant
  4. PIR + RCWL0516 dual detection — PIR จับคนภายใน (in) / RCWL0516 จับผ่านผนังด้านนอก (out), แยกแสดงผล 2 Channel, LED แยกสี
  5. รวม VL53L0X + MPU6050 — ทำหุ่นยนต์หลบสิ่งกีดขวาง + ตรวจจับการเอียงล้ม แล้วหยุด motor
