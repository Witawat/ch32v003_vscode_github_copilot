I2C Scanner เป็นเครื่องมือพื้นฐานที่สุด — ใช้หา address ของอุปกรณ์ I2C ทุกตัวบนบัส — ฟังก์ชันเดียว: I2CScan_Run()

MCU Pin→อุปกรณ์ขาหมายเหตุ
PC1↔SDA-สายข้อมูล I2C — ต้องมี R 4.7kΩ pull-up ไป 3.3V
PC2→SCL-สายนาฬิกา I2C — ต้องมี R 4.7kΩ pull-up ไป 3.3V
3.3V→SDA-ผ่าน R 4.7kΩ pull-up ไป 3.3V
3.3V→SCL-ผ่าน R 4.7kΩ pull-up ไป 3.3V
GND→GND-กราวด์ร่วม

รู้จักขา

  • VCC: ไฟเลี้ยง 3.3V
  • GND: กราวด์
  • SDA (PC1): สายข้อมูล I2C
  • SCL (PC2): สายนาฬิกา I2C
  • pull-up 4.7kΩ: ต่อระหว่าง SDA→3.3V และ SCL→3.3V (จำเป็นสำหรับ I2C)

วิธีต่อทีละขั้น

  1. ต่อสาย SDA (PC1) และ SCL (PC2) ของ MCU ไปยังอุปกรณ์ I2C ที่ต้องการตรวจสอบ
  2. ต่อ VCC ของอุปกรณ์ I2C ไป 3.3V
  3. ต่อ GND ของอุปกรณ์ I2C ไป GND รวมกับ MCU
  4. ต่อ R pull-up 4.7kΩ จาก SDA→3.3V และ SCL→3.3V — ถ้าอุปกรณ์ไม่มีในตัว
  5. เสียบสาย USB และรันโค้ด — I2C Scanner จะหา address อุปกรณ์ให้อัตโนมัติ

📚 หลักการทำงาน

I2C Scanner ทำงานโดยส่ง I2C Start condition + Address + R/W bit ไปยังทุก address ตั้งแต่ 1 ถึง 127 — ถ้าอุปกรณ์ตอบ ACK แสดงว่ามีอุปกรณ์ที่ address นั้น

ประโยชน์:

  • ตรวจสอบว่าอุปกรณ์ต่อถูกต้อง — ถ้า scan ไม่เจอ แสดงว่าสายหลุดหรือ address ไม่ตรง
  • ตรวจจับ address conflict — ถ้า 2 อุปกรณ์ใช้ address เดียวกัน I2C จะพัง
  • ทดสอบ pull-up resistors — ถ้าไม่มี pull-up, I2C จะไม่ทำงาน

💻 เขียน Code ทีละขั้น

ขั้นที่ 1: Init + Scan

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "I2CScan.h"

int main(void) {
    SystemCoreClockUpdate();

    I2C_SimpleInit(I2C_100KHZ, I2C_PINS_DEFAULT);
    // 100kHz, PC1=SDA, PC2=SCL

    USART_Println("=== I2C Scanner ===");
    I2CScan_Run();  // สแกนและพิมพ์ผลลัพธ์อัตโนมัติ

🔍 I2C_SimpleInit(I2C_100KHZ, I2C_PINS_DEFAULT) — เริ่มต้น I2C ง่ายๆ — I2CScan_Run() สแกนและพิมพ์ผล address 1-127 อัตโนมัติผ่าน USART

ขั้นที่ 2: แสดงสรุป

    USART_Println("Scan complete!");

    while(1) {
        // ทำงานอื่นต่อ...
        Delay_Ms(1000);
    }
}

🔍 I2CScan_Run() จัดการทุกอย่าง — Init → Scan → Print — ทั้งหมดในฟังก์ชันเดียว — เหมาะสำหรับ debug ตอนต่ออุปกรณ์ใหม่

⚠️ ข้อผิดพลาดที่พบบ่อย

ปัญหาสาเหตุวิธีแก้
Scan ไม่เจออุปกรณ์เลยลืมต่อ pull-up resistors (4.7k)ต่อ 4.7kΩ จาก SDA→3.3V และ SCL→3.3V
เจอ address ลึกลับที่ไม่รู้จักNoise หรือสายยาวเกินไปใช้สายสั้น (<20cm), ลด speed, เพิ่ม capacitor 100nF ที่ VCC
เจอแต่บาง address ไม่ครบBus capacitance สูงลด pull-up เหลือ 2.2k หรือ 1k, ลดความเร็ว I2C
Address conflict (2 devices)2 อุปกรณ์ใช้ address เดียวกันเปลี่ยน address ด้วย A0/A1/A2 pins

🛠️ สร้าง Product: I2C Bus Monitor

สแกน I2C ทุก 5 วินาที — แสดงอุปกรณ์ที่ต่ออยู่

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "I2CScan.h"

int main(void)
{
    SystemCoreClockUpdate();
    I2C_SimpleInit(I2C_100KHZ, I2C_PINS_DEFAULT);

    USART_Println("I2C Bus Monitor");

    while(1)
    {
        USART_Println("=== Scanning ===");
        I2CScan_Run();
        Delay_Ms(5000);
    }
}

✏️ ลองทำดู

  1. ทำ I2C device enumerator — ต่ออุปกรณ์หลายตัว → scan → แสดงชื่ออุปกรณ์จาก lookup table
  2. ทำ I2C conflict detector — เช็คว่ามี address ซ้ำกันไหม → แจ้งเตือนถ้า conflict
  3. ทำ I2C bus diagnostic — ตรวจจับ stuck bus, แนะนำ pull-up value ที่เหมาะสม
