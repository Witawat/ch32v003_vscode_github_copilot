บทที่ 7: I2C — คุยกับเซ็นเซอร์และ EEPROM

ระดับกลาง

🧭 แผนภาพการทำงาน

flowchart TD
    A["I2C_SimpleInit()"] --> B{"สแกนบัส"}
    B --> C["I2C_IsDeviceReady(addr)"]
    C --> D["เจอ Device"]
    D --> E{"เขียน/อ่าน"}
    E -->|"Register Write"| F["I2C_WriteReg(addr,reg,data)"]

🔌 การต่อวงจร

    I2C Bus (SDA + SCL + Pull-up 4.7kΩ)
    ┌─────────────────────────────────────┐
    │                  3.3V               │
    │                   │                 │
    │               ┌───┴────┐            │
    │               │        │            │
    │             4.7kΩ   4.7kΩ           │
    │               │        │            │
    │  MCU           │        │           │
    │  PC1(SDA)──────┴────────┼── SDA ────┤──► BH1750 (0x23)
    │  PC2(SCL)───────────────┘── SCL ────┤──► MPU6050 (0x68)
    │                                     │──► AT24Cxx (0x50)
    │  GND ──── GND ร่วมกันทุกตัว          │
    └─────────────────────────────────────┘

    Pin Configurations:
    DEFAULT        : SCL=PC2, SDA=PC1  (ทุกแพ็กเกจ)
    PARTIAL_REMAP  : SCL=PD2, SDA=PD1  (SOP-8 compatible)
    FULL_REMAP     : SCL=PD0, SDA=PD1  (เฉพาะ TSSOP-20/QFN-20)

Pull-up 4.7kΩ จำเป็น! — I2C เป็น open-drain ต้องมี pull-up ถึงจะทำงาน — SOP-8 ใช้ PC1/PC2 หรือ PARTIAL_REMAP (PD1/PD2)
สามารถต่อหลายอุปกรณ์บนบัสเดียวกันได้ (แต่ละตัวมี address ไม่ซ้ำกัน)

📚 หลักการทำงาน

I2C (Inter-Integrated Circuit) — การสื่อสาร 2 สาย (SDA=Data, SCL=Clock) ระหว่าง Master (MCU) และ Slave (เซ็นเซอร์)

7-bit Address: แต่ละอุปกรณ์มี address เฉพาะ (เช่น BH1750=0x23, MPU6050=0x68, AT24Cxx=0x50) — อยู่ในช่วง 0x03-0x77

การทำงาน: Master ส่ง Start → Address+R/W → Slave ตอบ ACK → ส่ง/รับข้อมูล → Master ส่ง Stop

Register Access: เซ็นเซอร์ส่วนใหญ่ใช้โมเดล register — เขียน register address ก่อน แล้วอ่าน/เขียนข้อมูล

ความเร็ว: Standard (100kHz) และ Fast (400kHz) — CH32V003 รองรับทั้งสอง

I2C_Soft (Software I2C): ถ้าต้องการใช้ pin อื่นที่ไม่ใช่ hardware I2C (PC1/PC2) — ใช้ SimpleI2C_Soft.h

💻 เขียน Code ทีละขั้น

ขั้นที่ 1: Init + Scan Bus

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);
    I2C_SimpleInit(I2C_100KHZ, I2C_PINS_DEFAULT);

🔍 I2C_SimpleInit(speed, pins) — ตั้งค่า hardware I2C — 100kHz ใช้ได้กับอุปกรณ์ส่วนใหญ่ — default pins PC1(SDA)/PC2(SCL)

ขั้นที่ 2: สแกนหา Devices

    USART_Print("Scanning I2C...\r\n");
    for(uint8_t addr = 1; addr < 128; addr++) {
        if(I2C_IsDeviceReady(addr)) {
            USART_Print("Found: 0x");
            USART_PrintHex(addr, 1);
            USART_Print("\r\n");
        }
    }

🔍 I2C_IsDeviceReady(addr) — ส่ง address แล้วเช็คว่ามี ACK กลับมาหรือไม่ — วิธีที่เร็วสุดในการเช็คว่าอุปกรณ์ต่ออยู่หรือไม่

ขั้นที่ 3: เขียน/อ่าน Register (BH1750)

    // BH1750: One-time High-Res Mode
    I2C_WriteReg(0x23, 0x10, 0x00);  // สั่งวัดแสง 1 ครั้ง
    Delay_Ms(180);  // รอ measurement time

    uint8_t buf[2];
    I2C_ReadRegMulti(0x23, 0x00, buf, 2);  // อ่าน 2 bytes
    uint16_t lux = ((uint16_t)buf[0] << 8) | buf[1];
    lux = lux / 1.2;  // convert to lux

🔍 I2C_WriteReg(addr, reg, data) — เขียน 1 byte ไปยัง register — I2C_ReadRegMulti() — อ่านหลาย bytes จาก register — BH1750 ต้องรอ measurement time 180ms

ขั้นที่ 4: ตรวจสอบ Error

    I2C_Status status = I2C_WriteReg(0x50, 0x00, 0x55);
    if(status != I2C_OK) {
        USART_Print("Write failed!\r\n");
    }
}

🔍 ฟังก์ชัน I2C คืนค่า I2C_Status — เช็ค I2C_OK ก่อนใช้ข้อมูล — I2C_ERROR_TIMEOUT, I2C_ERROR_NACK, I2C_ERROR_BUS_BUSY

⚠️ ข้อผิดพลาดที่พบบ่อย

ปัญหาสาเหตุวิธีแก้
I2C ไม่ทำงานเลยลืมต่อ Pull-up resistor 4.7kΩต่อ R 4.7kΩ จาก SDA/SCL ไป 3.3V — จำเป็น!
Scan ไม่เจอ device ใดๆสายสลับ SDA/SCL, หรือ address ผิดตรวจสอบ pin SDA=PC1, SCL=PC2 — ลอง I2C_Scan()
เขียน/อ่าน Error ตลอดความเร็วไม่ตรง หรือสายยาวเกินใช้ 100kHz, สาย < 20cm, pull-up ไม่เกิน 10kΩ
อ่านค่าได้ 0xFF ตลอดI2C_ReadReg() คืน 0xFF เมื่อ errorตรวจสอบว่าอุปกรณ์ต่ออยู่ ใช้ I2C_IsDeviceReady()
SOP-8: I2C ใช้ pin อื่นได้ไหมHardware I2C fixed ที่ PC1/PC2 (หรือ PD1/PD2 remap)SOP-8 ใช้ PARTIAL_REMAP (SCL=PD2,SDA=PD1) หรือใช้ Software I2C

🛠️ สร้าง Product: เครื่องวัดแสง + วัดความเร่ง

สแกน I2C bus → อ่าน BH1750 (แสง lux) และ MPU6050 (ความเร่งแกน Z) → แสดงผล Serial

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"

int main(void)
{
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);
    I2C_SimpleInit(I2C_100KHZ, I2C_PINS_DEFAULT);

    // สแกนหา sensor
    USART_Print("Scanning bus...\r\n");
    for(uint8_t a=1; a<128; a++)
        if(I2C_IsDeviceReady(a)) {
            USART_Print("Found: 0x"); USART_PrintHex(a,1); USART_Print("\r\n");
        }

    while(1)
    {
        // BH1750: Continuous High-Res Mode (0x10)
        I2C_WriteReg(0x23, 0x10, 0x00);
        Delay_Ms(180);
        uint8_t buf[2];
        I2C_ReadRegMulti(0x23, 0x00, buf, 2);
        uint16_t lux = ((uint16_t)buf[0]<<8 | buf[1]) * 10 / 12;

        // MPU6050: อ่าน Z-axis acceleration
        uint8_t zh = I2C_ReadReg(0x68, 0x3F);  // ACCEL_ZOUT_H
        uint8_t zl = I2C_ReadReg(0x68, 0x40);  // ACCEL_ZOUT_L
        int16_t az = (int16_t)((zh<<8) | zl);

        USART_Print("Lux: "); USART_PrintNum(lux);
        USART_Print(", AccelZ: "); USART_PrintNum(az);
        USART_Print("\r\n");
        Delay_Ms(500);
    }
}

✏️ ลองทำดู

  1. เปลี่ยนไปใช้ I2C_PINS_PARTIAL_REMAP (SCL=PD2,SDA=PD1) — ทดสอบกับ SOP-8
  2. ใช้ I2C_Scan() ฟังก์ชันแทนการวน loop เอง
  3. เพิ่ม AHT10 sensor (0x38) — อ่านอุณหภูมิและความชื้น
