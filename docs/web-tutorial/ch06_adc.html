บทที่ 6: ADC — อ่านค่า Analog จากเซ็นเซอร์

ระดับกลาง

🧭 แผนภาพการทำงาน

flowchart TD
    A["ADC_SimpleInit()"] --> B["ADC_Read(channel)"]
    B --> C["ADC_ToVoltage(value, vref)"]
    C --> D["แปลงเป็นหน่วยจริง (°C, %, V)"]

Voltage Divider แบตเตอรี่: R บน 10k + R ล่าง 10k = ratio 2:1 — 4.2V input → 2.1V ที่ ADC pin (ปลอดภัยสำหรับ 3.3V MCU)

📚 หลักการทำงาน

ADC (Analog-to-Digital Converter) — แปลงแรงดัน analog (0-3.3V) เป็นค่า digital 0-1023 (10-bit resolution)

Step Size: 3.3V ÷ 1024 = ~3.22mV ต่อ 1 LSB

Internal Vref (ADC_CH_VREFINT): CH32V003 มี internal 1.2V reference — ใช้คำนวณ VDD จริง (มีประโยชน์สำหรับ Battery Monitor)

Arduino-style: analogRead(pin) — ใช้ชื่อ pin (PD2) แทนเลข channel — มี compile-time validation

CH32V003 ไม่มี FPU — การใช้ float ใช้ software emulation (~800 cycles) — พยายามใช้ integer arithmetic ถ้าต้องการความเร็ว

💻 เขียน Code ทีละขั้น

ขั้นที่ 1: Init + Setup

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);
    ADC_SimpleInit();  // เปิดทุก ADC channels

🔍 ADC_SimpleInit() — เปิดทุก 8 channels พร้อมกัน (หรือใช้ ADC_SimpleInitChannels() เลือกเฉพาะที่ต้องการเพื่อประหยัด)

ขั้นที่ 2: อ่าน Potentiometer

    while(1) {
        uint16_t val = ADC_Read(ADC_CH_PD2);  // หรือ analogRead(PD2)
        float voltage = ADC_ToVoltage(val, 3.3f);
        uint8_t percent = (uint8_t)ADC_ToPercent(val);

🔍 ADC_Read(channel) — อ่านดิบ 0-1023 — ADC_ToVoltage(val, vref) — แปลงเป็นแรงดัน — ADC_ToPercent() — 0-100% (ใช้กับ pot ได้สวย)

ขั้นที่ 3: Battery Monitor (VDD จริง)

        float vdd = ADC_GetVDD();  // คำนวณจาก internal Vref
        float batt = ADC_GetBatteryPercent(vdd, 3.0f, 4.2f);
        USART_Print("VDD: "); USART_PrintNum((int32_t)vdd);
        USART_Print("V, Batt: "); USART_PrintNum(batt);
        USART_Print("%\r\n");

🔍 ADC_GetVDD() — อ่าน internal 1.2V reference แล้วคำนวณ VDD จริง — ไม่ต้องต่ออะไรเพิ่ม! — ADC_GetBatteryPercent(vdd, vmin, vmax) — แปลงเป็น % แบตเตอรี่

ขั้นที่ 4: Average Reading (ลด Noise)

        uint16_t avg = ADC_ReadAverage(ADC_CH_PD2, 10);  // 10 samples
        Delay_Ms(500);
    }
}

🔍 ADC_ReadAverage(ch, n) — อ่าน n ครั้งแล้วหาค่าเฉลี่ย — ช่วยลด noise จากแหล่งจ่ายไฟ

⚠️ ข้อผิดพลาดที่พบบ่อย

ปัญหาสาเหตุวิธีแก้
ADC อ่านได้ 0 ตลอดใช้ pin ที่ไม่ใช่ ADC pinADC pins: PA1,PA2,PC4,PD2-PD6 — PD7 ไม่ใช่ ADC!
ค่าอ่านกระโดด/ไม่นิ่งNoise จากแหล่งจ่ายไฟ หรือ impedance สูงใช้ ADC_ReadAverage(), ลด R divider, ต่อ cap ที่ ADC pin
Voltage อ่านผิดใช้ Vref ผิด (3.3V vs VDD จริง)ใช้ ADC_GetVDD() แทนสมมติว่า VDD=3.3V
analogRead compile errorใช้ pin คงที่ (constant) ที่ไม่ใช่ ADCใช้เฉพาะ PA1,PA2,PC4,PD2-PD6 — compile-time check
Float operation ช้ามากCH32V003 ไม่มี FPUใช้ integer math เมื่อทำได้ เช่น mV = (adc*3300)/1023

🛠️ สร้าง Product: เครื่องวัดอุณหภูมิ + วัดแรงดันแบตเตอรี่

อ่าน NTC Thermistor (PD3) แปลงเป็น °C พร้อมแสดง VDD และ % แบตเตอรี่

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"

#define NTC_PIN   ADC_CH_PD3
#define NTC_RFIX  10000.0f
#define NTC_R25   10000.0f
#define NTC_B     3950.0f
#define T0        298.15f

int main(void)
{
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);
    ADC_SimpleInit();

    while(1)
    {
        // อ่าน VDD จริง
        float vdd = ADC_GetVDD();

        // อ่าน NTC
        uint16_t adc = ADC_ReadAverage(NTC_PIN, 10);
        float v_ntc = ADC_ToVoltage(adc, vdd);
        float r_ntc = NTC_RFIX * v_ntc / (vdd - v_ntc);

        // Steinhart-Hart (simplified B-parameter)
        float temp_k = 1.0f / (1.0f/T0 + logf(r_ntc/NTC_R25)/NTC_B);
        float temp_c = temp_k - 273.15f;

        USART_Print("Temp: ");
        USART_PrintNum((int32_t)temp_c);
        USART_Print("C, VDD: ");
        USART_PrintNum((int32_t)vdd);
        USART_Print("V, Batt: ");
        USART_PrintNum((int32_t)ADC_GetBatteryPercent(vdd, 3.0f, 4.2f));
        USART_Print("%\r\n");

        Delay_Ms(1000);
    }
}

✏️ ลองทำดู

  1. ใช้ analogRead() แทน ADC_Read() — เปรียบเทียบผลลัพธ์
  2. อ่าน 2 channels พร้อมกัน (PD2 pot + PD5 LDR) แล้วแสดงทั้งคู่ผ่าน USART
  3. ใช้ ADC_ReadVoltageCompensated() เพื่อชดเชย VDD ให้ผลลัพธ์แม่นยำกว่า
