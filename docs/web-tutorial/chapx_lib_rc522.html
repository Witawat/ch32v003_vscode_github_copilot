RC522 RFID Reader — SPI, UID Detection, Card Presence, Version Check

ระดับสูง

📋 สิ่งที่ใช้ได้ / สิ่งที่ใช้ไม่ได้

Library นี้เป็น wrapper แบบ SimpleHAL สำหรับ MFRC522 — ออกแบบมาเพื่อ อ่าน UID เท่านั้น (single-purpose) ไม่ใช่ MIFARE full stack

รู้จักขา

  • VCC: ไฟเลี้ยง 3.3V เท่านั้น — ห้าม 5V! (RC522 ทำงานที่ 3.3V)
  • GND: กราวด์
  • SCK: สัญญาณนาฬิกา SPI — ต่อขา PC5
  • MOSI: ข้อมูลจาก MCU เข้า RC522 — ต่อขา PC6
  • MISO: ข้อมูลจาก RC522 ส่งเข้า MCU — ต่อขา PC7
  • SDA (CS): เลือกชิป — ต่อขา PC4 (กำหนดได้ใน RC522_Init)
  • RST: รีเซ็ต hardware — ต่อขา PD2 (กำหนดได้ใน RC522_Init)
  • IRQ: สัญญาณขัดจังหวะ — ไม่ต้องต่อ (library นี้ไม่ใช้ interrupt — polling RC522_IsCardPresent เท่านั้น)

วิธีต่อทีละขั้น

  1. ต่อ VCC RC522 ไป 3.3V ของ MCU (ห้าม 5V)
  2. ต่อ GND RC522 ไป GND ของ MCU
  3. ต่อ SCK RC522 ไปขา PC5
  4. ต่อ MOSI RC522 ไปขา PC6
  5. ต่อ MISO RC522 ไปขา PC7
  6. ต่อ SDA (CS) RC522 ไปขา PC4
  7. ต่อ RST RC522 ไปขา PD2
  8. (ไม่ต้องต่อ) IRQ — library ไม่ใช้

RC522 เป็น RFID reader 13.56MHz อ่านบัตร ISO/IEC 14443 Type A — library นี้ wrapper ทำเฉพาะ อ่าน UID จาก REQA + anticollision

📚 หลักการทำงาน

MFRC522 เป็น RFID IC สื่อสารผ่าน SPI — ระยะอ่าน ~2-5 cm ขึ้นกับ antenna และการ์ด — ใช้ไฟ 3.3V กิน ~13-26 mA

ขั้นตอนที่ library wrapper นี้ทำใน RC522_ReadUID:

  • REQA (Request Type A): ถามว่ามีการ์ดเข้าใกล้สนามหรือไม่ — เป็นส่วนหนึ่งของ RC522_IsCardPresent
  • Anticollision (SEL CL1/2/3): อ่าน UID (4 bytes สำหรับ MIFARE Classic, 7/10 bytes สำหรับบางรุ่น) — จัดการ collision ภายในตัว
  • คืน UID + ความยาวจริง ผ่าน out-param uid_len (จำนวน bytes ของ UID ที่อ่านได้จริง)

สิ่งที่ wrapper นี้ ไม่ ทำ: ไม่มี Select Tag, ไม่มี MIFARE Authentication (Key A/B), ไม่มี Read/Write block — ใครต้องการฟีเจอร์เหล่านี้ต้องใช้ standard peripheral หรือขยาย library เอง

รูปแบบ API (สำคัญ — handle-based เหมือนบท AT24Cxx): ทุกฟังก์ชันรับ RC522_Instance* เป็น arg แรก — RC522_ReadUID มี 3 args (rfid, uid, &uid_len) โดย uid_len เป็น out-param — RC522_ReadUID และ RC522_Init คืน RC522_Status

💻 เขียน Code ทีละขั้น

ขั้นที่ 1: SPI + Init + Version Check

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "RC522.h"

RC522_Instance rfid;

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);     // debug

    // ⚠️ ต้องเรียก SPI_SimpleInit ก่อน RC522_Init เสมอ (RC522 ใช้ SPI)
    SPI_SimpleInit(SPI_MODE0, SPI_4MHZ, SPI_PINS_DEFAULT);  // PC5/PC6/PC7

    // CS=PC4, RST=PD2 — ตามที่ต่อในวงจรด้านบน
    RC522_Status st = RC522_Init(&rfid, PC4, PD2);
    if (st != RC522_OK) {
        USART_Println("RC522_Init FAIL");
        while (1);
    }

    // ตรวจ version เพื่อยืนยันการเชื่อมต่อ SPI
    uint8_t ver = RC522_GetVersion(&rfid);
    USART_Printf("RC522 version = 0x%02X\r\n", ver);
    if (ver != 0x91 && ver != 0x92) {
        USART_Println("⚠️ version ผิด — เช็ค SPI mode/SCK/wiring/ไฟ 3.3V");
        // ไม่จบ while(1) ก็ได้ — ลองอ่านการ์ดต่อไปเผื่อ version register เกร่อ
    }

🔍 ลำดับที่ถูกต้อง: SPI_SimpleInit → RC522_Init(&rfid, CS, RST) → RC522_GetVersion(&rfid) — version 0x91 = v1.0, 0x92 = v2.0, ค่าอื่น = SPI/wiring/ไฟ ผิด — ต้องส่ง &rfid ทุกครั้ง (handle-based)

ขั้นที่ 2: Polling Card + อ่าน UID

    while (1) {
        // 1. ตรวจว่ามีการ์ดเข้าใกล้ antenna หรือไม่
        if (RC522_IsCardPresent(&rfid)) {
            USART_Println("Card detected");

            // 2. อ่าน UID — มี OUT-PARAM &len (3 args)
            uint8_t uid[RC522_UID_MAX_LEN];
            uint8_t len = 0;
            RC522_Status r = RC522_ReadUID(&rfid, uid, &len);
            //                                       eeprom  uid   &out_len

            if (r == RC522_OK) {
                USART_Printf("UID (%u bytes): ", len);
                for (uint8_t i = 0; i < len; i++) {
                    USART_Printf("%02X ", uid[i]);
                }
                USART_Println("");
            } else {
                // RC522_ERROR_COLLISION / TIMEOUT / CRC / NOCARD
                USART_Println("ReadUID FAIL");
            }

            // 3. ⚠️ ต้อง Halt หลังอ่าน — ไม่งั้นจะอ่าน UID ซ้ำซ้อนทุกรอบ
            RC522_Halt(&rfid);
        }
        Delay_Ms(200);
    }
}

🔍 รูปแบบใหม่ที่ถูกต้อง: RC522_ReadUID(&rfid, uid, &len) มี 3 args (rfid, uid buffer, &uid_len out-param) และคืน RC522_Status — ห้าม เขียน RC522_ReadUID(&rfid, uid) แบบบทเดิม (บทเดิมเขียนผิด ไม่มี out-param) — ต้องเรียก RC522_Halt(&rfid) หลังอ่าน UID ทุกครั้ง ไม่งั้นการ์ดยังอยู่ในสนามจะถูกอ่านซ้ำ

ขั้นที่ 3: SPI Wiring Diagnostic + Reset

// ฟังก์ชัน diagnostic เช็ค SPI/wiring — ใช้ GetVersion เป็น heart-beat
void rc522_diagnose(RC522_Instance* rfid) {
    USART_Println("=== RC522 Diagnostic ===");

    uint8_t ver = RC522_GetVersion(rfid);
    USART_Printf("Version reg = 0x%02X\r\n", ver);
    switch (ver) {
        case 0x91: USART_Println("→ MFRC522 v1.0 OK"); break;
        case 0x92: USART_Println("→ MFRC522 v2.0 OK"); break;
        case 0x00:
        case 0xFF:
            USART_Println("→ ⚠️ 0x00/0xFF = ไม่ได้ต่อ/CS ลอย/SPI ผิด mode/ไฟไม่ถึง");
            USART_Println("   • เช็ค PC5/PC6/PC7 ตรงสายไหน");
            USART_Println("   • เช็ค CS=PC4, RST=PD2");
            USART_Println("   • เช็ค 3.3V ว่าจ่ายจริง (ไม่ใช่ 5V)");
            USART_Println("   • เช็ค SPI_SimpleInit ก่อน RC522_Init");
            break;
        default:
            USART_Println("→ version ไม่รู้จัก — น่าจะไฟ noise");
            break;
    }

    // ทดสอบ Reset → อ่าน version ใหม่
    USART_Println("Resetting RC522...");
    RC522_Reset(rfid);
    Delay_Ms(50);
    uint8_t ver2 = RC522_GetVersion(rfid);
    USART_Printf("Version after reset = 0x%02X\r\n", ver2);
    if (ver2 != ver) {
        USART_Println("⚠️ version เปลี่ยนหลัง reset — ไฟไม่ stable");
    }
}

🔍 RC522_GetVersion คืน uint8_t (ไม่ใช่ status) — ใช้เป็น heart-beat ตรวจ SPI โดยไม่ต้องมีการ์ด — RC522_Reset(&rfid) รีเซ็ต MFRC522 hardware (soft reset) — ล่าสุดต้องเว้น Delay ~50ms ให้ register กลับค่า

🛠️ Product: UID Whitelist Door Lock

อ่าน UID → เทียบกับ whitelist (array ของ UID ที่อนุญาต) → เปิด relay + buzzer feedback

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "RC522.h"
#include <string.h>

RC522_Instance rfid;

#define RELAY_PIN   PC0
#define BUZZER_PIN  PC1

// Whitelist — UID ที่อนุญาต (เปลี่ยนเป็น UID จริงที่อ่านได้จากขั้นที่ 2)
#define WHITELIST_COUNT  3
uint8_t whitelist[WHITELIST_COUNT][RC522_UID_MAX_LEN] = {
    {0xA1, 0xB2, 0xC3, 0xD4, 0,0,0,0,0,0},   // card 1 (4 bytes)
    {0xDE, 0xAD, 0xBE, 0xEF, 0x12, 0x34, 0,0,0},  // card 2 (7 bytes)
    {0x12, 0x34, 0x56, 0x78, 0,0,0,0,0,0},   // card 3 (4 bytes)
};
uint8_t whitelist_len[WHITELIST_COUNT] = {4, 7, 4};   // UID ยาวเท่าไหร่แต่ละใบ

// กด relay และเล่น buzzer
void door_grant(void) {
    USART_Println("✓ ACCESS GRANTED");
    GPIO_SimpleInit(RELAY_PIN, GPIO_OUT_PP);
    GPIO_WriteBit(RELAY_PIN, 1);     // เปิดล็อก
    PWM_SimpleInit(BUZZER_PIN, 1, 2000, 500);   // เสียงสูง = ผ่าน
    Delay_Ms(150);
    PWM_SetDuty(BUZZER_PIN, 1, 0);
    Delay_Ms(3000);                  // เปิด 3 วิ
    GPIO_WriteBit(RELAY_PIN, 0);     // ล็อกกลับ
}

void door_deny(void) {
    USART_Println("✗ ACCESS DENIED");
    PWM_SimpleInit(BUZZER_PIN, 1, 500, 500);    // เสียงต่ำ = ไม่ผ่าน
    Delay_Ms(400);
    PWM_SetDuty(BUZZER_PIN, 1, 0);
    Delay_Ms(1000);                  // หน่วงกัน brute-force
}

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);
    SPI_SimpleInit(SPI_MODE0, SPI_4MHZ, SPI_PINS_DEFAULT);

    if (RC522_Init(&rfid, PC4, PD2) != RC522_OK) {
        USART_Println("RC522 init fail");
        while (1);
    }

    // version check เป็นการเช็ค wiring ล่วงหน้า
    uint8_t ver = RC522_GetVersion(&rfid);
    if (ver != 0x91 && ver != 0x92) {
        USART_Println("⚠️ Check SPI/wiring — version wrong");
    }

    USART_Println("[DOOR] Waiting for card...");
    while (1) {
        if (!RC522_IsCardPresent(&rfid)) {
            Delay_Ms(150);
            continue;
        }

        uint8_t uid[RC522_UID_MAX_LEN];
        uint8_t len = 0;
        if (RC522_ReadUID(&rfid, uid, &len) != RC522_OK) {
            RC522_Halt(&rfid);
            continue;
        }

        USART_Print("UID: ");
        for (uint8_t i = 0; i < len; i++) USART_Printf("%02X ", uid[i]);

        uint8_t found = 0;
        for (uint8_t c = 0; c < WHITELIST_COUNT; c++) {
            if (len == whitelist_len[c] &&
                memcmp(uid, whitelist[c], len) == 0) {
                found = 1;
                break;
            }
        }
        if (found) door_grant();
        else        door_deny();

        RC522_Halt(&rfid);    // ⚠️ ต้อง Halt ไม่งั้นอ่าน UID ซ้ำ
        Delay_Ms(300);
    }
}

🔍 Pattern ที่ถูกต้อง: whitelist เก็บ UID ที่อนุญาต + ความยาวแยก — เปรียบเทียบ len ก่อน memcmp — PWM_SimpleInit ใช้ buzzer ให้ feedback เสียง (สูง = ผ่าน, ต่ำ = ไม่ผ่าน) — ไม่มี Auth/ReadBlock/WriteBlock เพราะ library นี้อ่าน UID ได้อย่างเดียว — RC522_Halt(&rfid) หลังอ่านทุกครั้งกัน UID ซ้ำซ้อน

⚠️ ข้อจำกัดของ Library

Library นี้ทำได้แค่ UID detection (single-purpose wrapper) — ออกแบบเพื่อกรณีใช้งานง่ายๆ เช่น door lock, attendance, card swap detection, NFC tag presence — ไม่ใช่ MIFARE full stack

ฟีเจอร์ที่ขาดหายไป (ตั้งใจไม่ใส่):

  • ไม่มี Select Tag — อ่าน UID ได้แต่ไม่ได้ active-select เพื่อสื่อสารต่อ
  • ไม่มี MIFARE Authentication — ไม่มีคำสั่ง Auth Key A/B ใดๆ
  • ไม่มี Read/Write block — ไม่อ่าน/เขียนข้อมูล 16-byte block ของ MIFARE Classic
  • ไม่มี Self-Test — ใช้ RC522_GetVersion ตรวจการเชื่อมต่อแทน (อ่าน version register)
  • ไม่มี interrupt support — ใช้ polling RC522_IsCardPresent เท่านั้น (ไม่ใช้ขา IRQ)

ถ้าต้องการฟีเจอร์เหล่านี้: ใช้ standard peripheral library ของ MFRC522 ทั่วไป, หรือขยาย wrapper นี้เองโดยเพิ่มฟังก์ชัน Select Tag + Auth + Read Block + Write Block ด้วยตนเอง — อ้างอิง MFRC522 datasheet และ register map ใน RC522.h (มี RC522_REG_* และ PICC_CMD_* ครบ)

ReadUID คืน RC522_ERROR_CRCantenna อ่น / noise / ระยะไกลเกินเปลี่ยนบัตรมาใกล้ antenna (2-5 cm) — ลด noise รอบๆ — ลดระยะห่าง metal — ลองเบรกออกอ่านบัตรใหม่รอบ
อ่าน UID ซ้ำซ้อนทุกรอบ (การ์ดยังอยู่)ลืม RC522_Halt(&rfid) หลังอ่านต้องเรียก RC522_Halt(&rfid) หลัง RC522_ReadUID ทุกครั้ง — ไม่งั้นการ์ดยังอยู่ในสนามจะถูกอ่านซ้ำ
ReadUID คืน RC522_ERROR_NOCARD ทั้งที่ IsCardPresent บอกมีการ์ดออกจากสนามเร็วเกินระหว่างสองคำสั่งเรียก RC522_ReadUID ทันทีหลัง IsCardPresent ไม่มี Delay คั่น — เพิ่มรอบ polling ให้ถี่ขึ้น
Build fail: RC522_ReadUID(&rfid, uid) ไม่พอ argsเขียนผิด: ลืม out-param &uid_lenใช้ 3 args: RC522_ReadUID(&rfid, uid, &len) — len เป็น out-param รับจำนวน bytes — คืน RC522_Status ไม่ใช่ UID length
Build fail: ฟังก์ชัน Self-Test / Select Tag / Auth ไม่มีใช้ API บทเดิมที่ fabricatedฟังก์ชันเหล่านี้ ไม่มี ใน header — wrapper ทำ UID detection เท่านั้น — ใช้ GetVersion แทนฟังก์ชัน self-test แบบเดิม
ไม่เจอการ์ดเลยแม้วงจรถูกไฟ 3.3V ตก / antenna เสีย / บัตรไม่ใช่ Type Aวัด VCC ที่ RC522 ต้อง ~3.3V — ลองบัตรใบอื่น — ตรวจบัตรเป็น ISO14443A (MIFARE/NTAG) ไม่ใช่ ISO15693

✏️ ลองทำดู

  1. ทำ UID reader debug — แสดง UID เป็น hex ทุกครั้งที่แตะ — ถ้า RC522_GetVersion(&rfid) ไม่ใช่ 0x91/0x92 ให้ print diagnostic (เช็คระบุว่า SPI ผิด, สายหลวม, หรือไฟ)
  2. ทำ multi-card whitelist — เก็บ 5 UID ที่อนุญาต → เปิด relay + เล่น buzzer feedback (เสียงสูง = ผ่าน, เสียงต่ำ = ไม่ผ่าน) — อ่าน UID แล้ว Halt เสมอ
  3. ทำ card swap detector — ตรวจจับการเปลี่ยนการ์ดระหว่างแตะ (เปรียบเทียบ UID กับครั้งก่อน) → print "card swapped" — ทดสอบพฤติกรรม RC522_Halt vs RC522_Reset
