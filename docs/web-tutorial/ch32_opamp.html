ex01_Voltage_Follower — OPAMP SimpleInit + Follower + ADC

📖 แนวคิด

ใช้ OPAMP ในโหมด Voltage Follower (บัฟเฟอร์) ผ่าน OPAMP_SimpleInit — ขาเข้าผ่าน OPAMP แล้วต่อเข้ากับ ADC ภายใน — อ่านค่าแรงดันแบบไม่สูญเสียกระแส

🔌 วงจร

    CH32V003
    OPAMP1_IN (PD5) --- สัญญาณอนาล็อกเข้า
    OPAMP1_OUT ------------ ต่อกับ ADC IN ภายในอัตโนมัติ
    ADC_IN (PA1) ---------- อ่านค่าแรงดันจาก OPAMP

    - PD5: OPAMP1 input (non-inverting)
    - OPAMP output เชื่อม ADC ภายใน — ไม่ต้องต่อสายภายนอก
MCU Pin→อุปกรณ์ขาหมายเหตุ
PD5 (OPAMP1_IN)←สัญญาณอนาล็อก—OPAMP non-inverting input
OPAMP1_OUT→ADC_IN (PA1)ภายใน MCUต่อภายใน — ไม่ต้องใช้สาย

รู้จักขา

  • PD5 (OPAMP1_IN): ขาเข้าสัญญาณอนาล็อกของ OPAMP (non-inverting)
  • OPAMP1_OUT: ขาออกของ OPAMP — ต่อกับ ADC ภายในช่อง 7 อัตโนมัติ
  • PA1 (ADC_IN): ขาอ่านค่า ADC ที่รับสัญญาณจาก OPAMP ภายใน MCU

วิธีต่อทีละขั้น

  1. ต่อ PD5 (OPAMP1_IN) ไป สัญญาณอนาล็อก — ป้อนสัญญาณเข้า OPAMP
  2. ภายใน MCU OPAMP1_OUT ต่อกับ ADC_IN (PA1) อัตโนมัติ — ไม่ต้องใช้สาย
  3. ต่อ GND ของสัญญาณเข้ากับ GND MCU

🧭 ผังการทำงาน

flowchart TD
    A["OPAMP_SimpleInit(FOLLOWER)"] --> B["OPAMP_Enable()"]
    B --> C["ADC_SimpleInit()"]
    C --> D["while(1)"]
    D --> E["ADC_Read(ch)"]
    E --> F["ADC_ToVoltage(val)"]
    F --> G["Print voltage"]
    G --> H["Delay_Ms(500)"]
    H --> D

💻 โค้ด + อธิบายทีละบรรทัด

#define CH32V003_PACKAGE  PACKAGE_TSSOP20
#include <SimpleHAL.h>

int main(void)
{
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);
    ADC_SimpleInit();
    OPAMP_SimpleInit(OPAMP1, VOLTAGE_FOLLOWER);
    OPAMP_Enable(OPAMP1);
    USART_Print("OPAMP Voltage Follower Ready!\r\n");

    while(1)
    {
        uint16_t adc_val = ADC_Read(7);       // ADC ch7 = OPAMP1 output
        float voltage = ADC_ReadVoltage(7);
        USART_Print("ADC: ");
        USART_PrintNum(adc_val);
        USART_Print(" = ");
        USART_PrintFloat(voltage, 2);
        USART_Print("V\r\n");
        Delay_Ms(500);
    }
}
  • OPAMP_SimpleInit(ch, mode): เริ่มต้น OPAMP1 หรือ OPAMP2 — โหมด VOLTAGE_FOLLOWER = output ตาม input แบบไม่ขยาย
  • OPAMP_Enable(ch): เปิด OPAMP — ต้องเรียกก่อน ADC อ่านค่า — กินกระแส ~1mA
  • ADC_Read(7): ช่อง 7 = OPAMP1 output ที่ต่อภายในกับ ADC — ไม่ต้องใช้ pin ภายนอก

⚠️ จุดควรระวัง

  • ต้องเปิด ADC_SimpleInit ก่อน OPAMP_SimpleInit — OPAMP output ต้องมี ADC เป็นปลายทาง
  • OPAMP กินกระแส ~1mA — ถ้าใช้ battery ควรปิดเมื่อไม่ใช้ (OPAMP_Disable)
  • แรงดัน input ต้องอยู่ในช่วง 0V~VDD — OPAMP rail-to-rail

✅ ตรวจสอบก่อนรัน

  • เลือก PACKAGE_TSSOP20 (SOP-8 มีแค่ OPAMP1 เท่านั้น)
  • ADC และ OPAMP ต้องใช้ VREF เดียวกัน — ปกติ VDD = 3.3V
  • Serial monitor ตั้ง baud 115200

ex02_NonInverting_Amp — ConfigNonInverting ขยาย 2 เท่า

📖 แนวคิด

ใช้ OPAMP ในโหมด Non-Inverting ขยายสัญญาณด้วย ConfigNonInverting — gain = 2 — ใช้ R ภายนอก 2 ตัวกำหนดอัตราขยาย — อ่านค่าผ่าน ADC

🔌 วงจร

    CH32V003
    OPAMP1_IN (PD5) --- สัญญาณเข้า (non-inverting)
    OPAMP1_OUT ----+---- R1=10kΩ ---- GND
                   |
                   +---- R2=10kΩ ---- PA1 (ADC in)
    - Gain = 1 + R2/R1 = 1 + 10k/10k = 2
MCU Pin→อุปกรณ์ขาหมายเหตุ
PD5 (OPAMP1_IN)←สัญญาณอนาล็อกเข้า—Non-inverting input
OPAMP1_OUT→R1=10kΩ → GND—Divider ขาล่าง
OPAMP1_OUT→R2=10kΩ → PA1 (ADC_IN)—Divider ขาบน, gain=2

รู้จักขา

  • PD5 (OPAMP1_IN): ขาเข้าสัญญาณอนาล็อก (non-inverting)
  • OPAMP1_OUT: ขาออก OPAMP ต่อ R1=10kΩ→GND และ R2=10kΩ→PA1
  • PA1 (ADC_IN): อ่านค่าแรงดัน output จาก OPAMP
  • R1=10kΩ, R2=10kΩ: ตัวต้านทานกำหนดอัตราขยาย gain = 1 + R2/R1 = 2

วิธีต่อทีละขั้น

  1. ต่อ PD5 (OPAMP1_IN) ไป สัญญาณอนาล็อก — ป้อนสัญญาณเข้า
  2. ต่อ OPAMP1_OUT ไป R1=10kΩ → GND — ขาล่างวงจรขยาย
  3. ต่อ OPAMP1_OUT ไป R2=10kΩ → PA1 (ADC_IN) — ส่ง output ให้ ADC

🧭 ผังการทำงาน

flowchart TD
    A["OPAMP_SimpleInit(FOLLOWER)"] --> B["OPAMP_ConfigNonInverting(gain=2)"]
    B --> C["OPAMP_Enable()"]
    C --> D["while(1)"]
    D --> E["ADC_ReadVoltage(7)"]
    E --> F["Vin = Vout / 2"]
    F --> G["Print Vin"]
    G --> H["Delay_Ms(500)"]
    H --> D

💻 โค้ด

#define CH32V003_PACKAGE  PACKAGE_TSSOP20
#include <SimpleHAL.h>

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);
    ADC_SimpleInit();
    OPAMP_SimpleInit(OPAMP1, VOLTAGE_FOLLOWER);
    OPAMP_ConfigNonInverting(OPAMP1, 2);  // gain = 2
    OPAMP_Enable(OPAMP1);

    while(1) {
        float vin = ADC_ReadVoltage(7) / 2.0f;
        USART_Print("Vin = ");
        USART_PrintFloat(vin, 3);
        USART_Print("V\r\n");
        Delay_Ms(500);
    }
}
  • OPAMP_ConfigNonInverting(ch, gain): ตั้งอัตราขยายแบบ non-inverting — gain = 1 + Rf/Rg — ภายในใช้ resistor ladder
  • แรงดัน output = Vin × gain — จากนั้น ADC อ่านค่า output → คำนวณย้อนกลับหา Vin

⚠️ จุดควรระวัง

  • gain สูงสุดที่ recommend = 8 — เกินนี้อาจมี noise และ offset สูง
  • Input signal + output × gain ต้องไม่เกิน VDD — ถ้าเกิน output จะคลิป
  • ADC ch7 (PA1) รับ output จาก OPAMP — ถ้าใช้ ch อื่นต้องเช็ค datasheet

ex03_Inverting_Amp — ConfigInverting ขยาย -2 เท่า

📖 แนวคิด

ใช้ OPAMP แบบ Inverting ขยายสัญญาณกลับเฟส — ConfigInverting gain = -2 — output = -2 × Vin — ต่อ R ภายนอกแบบ inverting topology

🧭 ผังการทำงาน

flowchart TD
    A["SystemInit + ADC_SimpleInit"] --> B["OPAMP_ConfigInverting(gain=2)"]
    B --> C["OPAMP_Enable()"]
    C --> D["while(1)"]
    D --> E["ADC_Read(7)"]
    E --> F["Calculate Vout"]
    F --> G["Vin = Vout / -2"]
    G --> H["Print Vout & Vin"]
    H --> I["Delay_Ms(500)"]
    I --> D

💻 โค้ด

#define CH32V003_PACKAGE  PACKAGE_TSSOP20
#include <SimpleHAL.h>

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    ADC_SimpleInit();
    OPAMP_SimpleInit(OPAMP1, VOLTAGE_FOLLOWER);
    OPAMP_ConfigInverting(OPAMP1, 2);   // gain = -2 (absolute)
    OPAMP_Enable(OPAMP1);

    while(1) {
        uint16_t adc = ADC_Read(7);
        float vout = (adc * 3.3f) / 4095.0f;
        float vin = vout / -2.0f;        // vin = vout / gain
        USART_Print("Vout: ");
        USART_PrintFloat(vout, 3);
        USART_Print("V, Vin: ");
        USART_PrintFloat(vin, 3);
        USART_Print("V\r\n");
        Delay_Ms(500);
    }
}
  • OPAMP_ConfigInverting(ch, gain): ตั้งค่า inverting — output = -gain × input — gain สัมบูรณ์
  • สัญญาณกลับเฟส 180° — ถ้า input สูงขึ้น output จะลดลง

⚠️ จุดควรระวัง

  • Output เป็นลบไม่ได้ (GND = 0V ต่ำสุด) — ถ้า Vin × -2 ตกต่ำกว่า GND output จะคลิปที่ 0V
  • ต้องต่อ R ภายนอกตาม topology inverting — CH32V003 OPAMP ใช้ internal resistor matrix

ex04_Comparator — ConfigComparator HIGH/LOW

📖 แนวคิด

ตั้ง OPAMP เป็น Comparator — เปรียบเทียบสัญญาณอนาล็อกกับ threshold — ConfigComparator HIGH = output HIGH เมื่อ Vin > Vref — LOW = LOW เมื่อ Vin < Vref — อ่านผลด้วย digitalRead

🧭 ผังการทำงาน

flowchart TD
    A["OPAMP_ConfigComparator(HIGH)"] --> B["OPAMP_Enable()"]
    B --> C["while(1)"]
    C --> D["digitalRead(OPAMP_OUT_PIN)"]
    D --> E["Print HIGH or LOW"]
    E --> F["Delay_Ms(200)"]
    F --> C

💻 โค้ด

#define CH32V003_PACKAGE  PACKAGE_TSSOP20
#include <SimpleHAL.h>

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);
    ADC_SimpleInit();
    OPAMP_SimpleInit(OPAMP1, VOLTAGE_FOLLOWER);
    OPAMP_ConfigComparator(OPAMP1, COMP_HIGH);  // output HIGH when Vin > 1.65V
    OPAMP_Enable(OPAMP1);

    while(1) {
        uint8_t cmp_out = digitalRead(OPAMP_OUT_PIN);
        USART_Print("Comparator: ");
        USART_Print(cmp_out ? "HIGH\r\n" : "LOW\r\n");
        Delay_Ms(200);
    }
}
  • COMP_HIGH: threshold ที่ VDD/2 (≈1.65V) — Vin > 1.65V → output HIGH
  • COMP_LOW: threshold ที่ VDD/4 — ใช้กับสัญญาณต่ำ
  • output ของ comparator อ่านผ่าน OPAMP_OUT_PIN (digital pin)

⚠️ จุดควรระวัง

  • Comparator output เป็น digital (HIGH/LOW) ไม่ใช่อนาล็อก — ถ้าต้องการค่าอนาล็อกใช้ ADC หลัง OPAMP
  • มี hysteresis ในตัว ~20mV — ป้องกัน oscillation ที่ threshold
  • delay ~1µs จาก input เปลี่ยนถึง output เปลี่ยน

ex05_OPAMP_with_ADC — Follower + ADC Read

📖 แนวคิด

รวม OPAMP follower + ADC — ใช้ OPAMP เป็นบัฟเฟอร์ลด impedance ของสัญญาณก่อนเข้า ADC — อ่านค่าแรงดันและแปลงเป็นค่าจริง — แสดงทาง USART

🧭 ผังการทำงาน

flowchart TD
    A["OPAMP_SimpleInit(FOLLOWER)"] --> B["OPAMP_Enable()"]
    B --> C["while(1)"]
    C --> D["ADC_Read(7)"]
    D --> E["ADC_ReadVoltage(7)"]
    E --> F["Print Raw & Voltage"]
    F --> G["Delay_Ms(250)"]
    G --> C

💻 โค้ด

#define CH32V003_PACKAGE  PACKAGE_TSSOP20
#include <SimpleHAL.h>

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);
    ADC_SimpleInit();
    OPAMP_SimpleInit(OPAMP1, VOLTAGE_FOLLOWER);
    OPAMP_Enable(OPAMP1);

    USART_Print("OPAMP + ADC Ready\r\n");

    while(1) {
        uint16_t raw = ADC_Read(7);
        float volt = ADC_ReadVoltage(7);
        USART_Print("Raw: ");
        USART_PrintNum(raw);
        USART_Print(" (");
        USART_PrintFloat(volt, 2);
        USART_Print("V)\r\n");
        Delay_Ms(250);
    }
}
  • ADC_ReadVoltage(ch): แปลง raw ADC (0-4095) เป็นแรงดัน (0-VDD) โดยอัตโนมัติ
  • OPAMP follower ทำให้ ADC อ่านค่าได้แม่นยำขึ้น — source impedance ต่ำลง

⚠️ จุดควรระวัง

  • ADC resolution 12-bit (0-4095) — VDD = 3.3V → 0.8mV/step
  • OPAMP มี offset ~5mV — ค่า ADC จะคลาดเคลื่อนเล็กน้อย

ex06_Advanced_Control — เปลี่ยนช่อง + Power Save

📖 แนวคิด

ควบคุม OPAMP ขั้นสูง — เปลี่ยน channel ระหว่าง OPAMP1↔OPAMP2 ขณะรัน — เปิด/ปิด Power Save mode — อ่านค่าสัญญาณต่างช่องและเปรียบเทียบ

🧭 ผังการทำงาน

flowchart TD
    A["Init OPAMP1+OPAMP2<br/>(VOLTAGE_FOLLOWER)"] --> B["active_ch = OPAMP1"]
    B --> C["while(1)"]
    C --> D{"3s elapsed?"}
    D -->|"No"| E["ADC_Read(active_ch)"]
    E --> F["Print ADC value"]
    F --> G["Delay_Ms(200)"]
    G --> C
    D -->|"Yes"| H["OPAMP_Disable(active_ch)"]
    H --> I["Toggle active_ch"]
    I --> J["PowerSave inactive ch"]
    J --> K["OPAMP_Enable(active_ch)"]
    K --> L["Print switched"]
    L --> C

💻 โค้ด

#define CH32V003_PACKAGE  PACKAGE_TSSOP20
#include <SimpleHAL.h>

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);
    ADC_SimpleInit();

    OPAMP_SimpleInit(OPAMP1, VOLTAGE_FOLLOWER);
    OPAMP_SimpleInit(OPAMP2, VOLTAGE_FOLLOWER);

    uint8_t active_ch = OPAMP1;

    while(1) {
        static uint32_t last_switch = 0;
        if(ELAPSED_TIME(last_switch, Get_CurrentMs()) >= 3000) {
            last_switch = Get_CurrentMs();
            OPAMP_Disable(active_ch);
            if(active_ch == OPAMP1) {
                active_ch = OPAMP2;
                OPAMP_EnablePowerSave(OPAMP1);   // OPAMP1 เข้า power save
            } else {
                active_ch = OPAMP1;
                OPAMP_EnablePowerSave(OPAMP2);
            }
            OPAMP_Enable(active_ch);
            USART_Print("Switched to ");
            USART_PrintNum(active_ch);
            USART_Print("\r\n");
        }

        uint8_t adc_ch = (active_ch == OPAMP1) ? 7 : 6;
        uint16_t val = ADC_Read(adc_ch);
        USART_Print("CH");
        USART_PrintNum(adc_ch);
        USART_Print(": ");
        USART_PrintNum(val);
        USART_Print("\r\n");
        Delay_Ms(200);
    }
}
  • OPAMP_EnablePowerSave(ch): ลดกระแส OPAMP เหลือ ~0.1mA — output ไม่แม่นยำเท่าเต็มที่
  • OPAMP_Disable(ch): ปิด OPAMP จริง — ประหยัดพลังงานสูงสุด
  • OPAMP1 → ADC ch7 (PA1), OPAMP2 → ADC ch6 (PC1) — ไม่เหมือนกัน

⚠️ จุดควรระวัง

  • Power Save mode = output มี offset มากขึ้น (~20mV) — ใช้เมื่อไม่ต้องการ precision สูง
  • Stabilization time หลังจากเปิด OPAMP ~10µs — รอเล็กน้อยก่อน ADC read
  • TSSOP20 มี 2 OPAMP — SOP-8 มีแค่ OPAMP1
