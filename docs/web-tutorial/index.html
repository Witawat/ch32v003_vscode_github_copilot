📚 สารบัญ

  • บทที่ 0เริ่มต้น เตรียมความพร้อม — ติดตั้ง Toolchain, VS Code, ต่อวงจร, Build & Flash ครั้งแรก
  • บทที่ 1เริ่มต้น เริ่มต้นอย่างถูกต้อง — SystemCoreClockUpdate, Timer_Init, CH32V003_PACKAGE, Debug Print
  • บทที่ 2เริ่มต้น GPIO — Digital Input/Output, Interrupt, Pulse Measurement, Shift Register
  • บทที่ 3เริ่มต้น Delay & Timer — จับเวลา Blocking/Non-Blocking, Stopwatch, Countdown
  • บทที่ 4เริ่มต้น USART — Serial Communication, Print, Read, Remap, Package-Aware
  • บทที่ 5กลาง PWM — LED Fade, Servo, Frequency, Auto-Start, Remap
  • บทที่ 6กลาง ADC — Analog Read, Voltage, Battery Monitor, Noise Reduction
  • บทที่ 7กลาง I2C — Sensor Communication, EEPROM, Bus Scanner, Remap
  • บทที่ 8กลาง SPI — High-Speed Transfer, Flash Memory, Config, Remap
  • บทที่ 9สูง DMA — Direct Memory Access, ADC+DMA, USART+DMA, Callbacks
  • บทที่ 10สูง Power Management — Sleep, Standby, AWU, PVD, Battery Life
  • บทที่ 11สูง Flash Storage — Non-Volatile Data, Config+CRC, Wear Leveling
  • บทที่ 12สูง Watchdog — IWDG, WWDG, System Reliability
  • บทที่ 13ผู้เชี่ยวชาญ OPAMP — Internal Op-Amp, Follower, Amplifier, Comparator
  • บทที่ 14ผู้เชี่ยวชาญ 1-Wire — DS18B20, ROM Commands, Multi-Device
  • บทที่ 15ผู้เชี่ยวชาญ Arduino API — millis/delay/random/yield, Code Portability
  • บทที่ 16ผู้เชี่ยวชาญ Timer Resource Guard — ป้องกัน PWM/Timer/Stopwatch ชนกัน
  • บทที่ 17ผู้เชี่ยวชาญ Package System — เลือก SOP8/SOP16/TSSOP20, Pin Validation
  • บทที่ 18ผู้เชี่ยวชาญ รวมหลายโมดูล — State Machine, SimpleScheduler, Product จริง 3 ตัวอย่าง
  • บทที่ 19สูง Workshop ดีบัก — Print Debug, LED Code, มัลติมิเตอร์, Logic Analyzer, GDB
  • 📎 บทเสริม
  • เสริม Aสูง จาก Breadboard สู่ PCB — Schematic, Layout, Gerber, สั่งผลิต, ประกอบ
  • เสริม Bกลาง สูตรสำเร็จ — 18 อุปกรณ์ยอดนิยม: OLED, DHT11, Servo, nRF24L01, Relay...
  • เสริม Cผู้เชี่ยวชาญ ข้อควรรู้ก่อนผลิตจริง — ROP Lock, Unique ID, Brown-out, Testing, Bootloader
  • เสริม Dเริ่มต้น ย้ายจาก Arduino มา CH32V003 — ตารางเทียบฟังก์ชัน, Porting ตัวอย่าง, ข้อควรระวัง
💡 วิธีอ่าน: ถ้ายังไม่ได้ติดตั้งอะไรเลย → เริ่มที่ บทที่ 0 ก่อน ไล่ไปตามลำดับ 1→19 — บทเสริม A-D อ่านเมื่อพร้อมทำของจริง — แต่ละบทมี Flowchart, วงจร, Code ทีละขั้น, และ Product จริงให้ลองทำ
