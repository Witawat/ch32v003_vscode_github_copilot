MAX7219 — LED Matrix 8×8 SPI

MAX7219 สื่อสารผ่าน SPI — ใช้ 5V จ่ายไฟมอดูลละ ~330mA (8×8 LEDs on) — CS, SCK, DIN 3 ขา — ต่อพ่วงหลายโมดูลได้โดย DOUT → DIN

📚 หลักการทำงาน

SPI Chainable: MAX7219 แต่ละตัวมี shift register ภายใน 16-bit — ส่งข้อมูลผ่าน SPI (CS, SCK, DIN) — ข้อมูลเลื่อนจาก DIN → DOUT ไปตัวถัดไป — CS pulse เพื่อ latch ข้อมูลทั้งหมด

8×8 Per Module: แต่ละโมดูลมี LED 8×8 = 64 ดวง — MAX7219 ควบคุม 8 แถว × 8 คอลัมน์ ด้วยการ scan multiplex (ทีละแถว) — ใช้ BCD decode mode สำหรับตัวเลข หรือ no-decode สำหรับ bitmap

Intensity Control: 16 ระดับความสว่าง (0-15) — ควบคุมด้วย PWM ภายใน — SetIntensity() ปรับความสว่าง — ค่า 0=มืดสุด, 15=สว่างสุด (ค่าแนะนำ 5-8)

Scroll Text Engine: MAX7219_ScrollText() ใช้ state machine ภายใน — เลื่อนข้อความทีละคอลัมน์ — รองรับภาษาไทยผ่านฟอนต์ bitmap — speed parameter ควบคุมความเร็ว (ค่า ms ต่อเฟรม)

💻 เขียน Code ทีละขั้น

ขั้นที่ 1: Init + Setup

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    SPI_Init(SPI_MODE0, SPI_SPEED_8M);

    MAX7219_Init(1, PC4);      // 1 module, CS=PC4
    MAX7219_SetIntensity(5);   // brightness 5/15
    MAX7219_Clear();

🔍 SPI Mode 0 — MAX7219_Init(n, cs_pin) ระบุจำนวนโมดูลและขา CS — SetIntensity 0-15 — Clear() ล้างหน้าจอทุกโมดูล

ขั้นที่ 2: Scroll Text + Custom Bitmap

    // เลื่อนข้อความ
    MAX7219_ScrollText("HELLO CH32V003", 100);

    // หรือแสดงทีละตัวอักษร
    MAX7219_PrintChar('A');

    // หรือ custom bitmap 8x8
    uint8_t heart[8] = {
        0b00111100,
        0b01111110,
        0b11111111,
        0b11111111,
        0b01111110,
        0b00111100,
        0b00011000,
        0b00000000
    };
    MAX7219_DrawBitmap(heart);

🔍 ScrollText(str, speed_ms) เลื่อนข้อความอัตโนมัติ — PrintChar(c) แสดง 1 ตัวอักษร — DrawBitmap(arr[8]) แสดง bitmap 8×8 แบบกำหนดเอง

ขั้นที่ 3: Loop สลับข้อความ

    Timer_t tmr;
    Start_Timer(&tmr, 3000, 1);
    uint8_t page = 0;

    while(1) {
        if(Is_Timer_Expired(&tmr)) {
            MAX7219_Clear();
            if(page == 0) {
                MAX7219_PrintChar('1');
            } else if(page == 1) {
                MAX7219_PrintChar('2');
            } else {
                MAX7219_PrintChar('3');
            }
            page = (page + 1) % 3;
        }
    }
}

🔍 ใช้ Non-Blocking Timer เปลี่ยนข้อความทุก 3 วิ — Clear() ก่อนเปลี่ยน — สลับระหว่าง 3 หน้าจอ — loop ไม่เคยบล็อก

⚠️ ข้อผิดพลาดที่พบบ่อย

ปัญหาสาเหตุวิธีแก้
LED ไม่ติดเลยSPI pin ผิด — ต้อง PC5=SCK, PC6=DIN (MOSI)ตรวจสอบ pin mapping — CH32V003 SPI1 ใช้ PC5/PC6
LEDs dim / สว่างไม่พอIntensity ต่ำกว่า 3 หรือไฟเลี้ยงไม่พอ (5V)SetIntensity(≥5) — ใช้ external 5V จ่ายไฟโดยตรง อย่าพึ่ง MCU
Scroll กระตุก / ไม่ smoothDelay น้อยเกินจน MAX7219 ตามไม่ทันspeed parameter ≥ 50ms ต่อเฟรม — ลอง 100ms
ต่อ 2 โมดูลแล้วไม่ทำงานที่ 2Init ระบุแค่ 1 โมดูลใช้ MAX7219_Init(2, PC4) — จำนวนโมดูลต้องตรงกับที่ต่อ
LED บางดวงติดค้างSPI noise หรือ CS toggle ผิดจังหวะต่อ pull-up 10k ที่ CS — ลด SPI speed เหลือ 1MHz

🛠️ สร้าง Product: ป้ายไฟวิ่งภาษาไทย 4 โมดูล

MAX7219 4 โมดูลต่อพ่วง — แสดงข้อความเลื่อนภาษาไทย — ใช้ Non-Blocking Timer เพื่อให้โปรแกรมทำงานอื่นต่อได้

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    SPI_Init(SPI_MODE0, SPI_SPEED_8M);

    MAX7219_Init(4, PC4);
    MAX7219_SetIntensity(5);
    MAX7219_Clear();

    while(1) {
        MAX7219_ScrollText("สวัสดี CH32V003 ", 80);
        Delay_Ms(1000);
        MAX7219_ScrollText("MAX7219 4 Module ", 80);
        Delay_Ms(1000);
    }
}
