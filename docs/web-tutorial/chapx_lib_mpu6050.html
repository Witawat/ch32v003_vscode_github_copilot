🔌 การต่อวงจร

            MPU6050 — 6-DOF IMU Sensor I2C
    ┌────────────────────────────────────┐
    │ MCU                        MPU6050 │
    │ PC1─────────SDA          ┌────────┤
    │ PC2─────────SCL          │ Gyro   │
    │ 3.3V────────VCC          │  3-axis│
    │ GND─────────GND          │ Accel  │
    │ PC3─────────INT(optional)│  3-axis│
    │                    addr └────────┤
    │ AD0─GND → 0x68  AD0─VCC → 0x69   │
    └────────────────────────────────────┘
MCU Pin→อุปกรณ์ขาหมายเหตุ
PC1↔SDA-สายข้อมูล I2C — ต้องมี R 4.7kΩ pull-up ไป 3.3V
PC2↔SCL-สายนาฬิกา I2C — ต้องมี R 4.7kΩ pull-up ไป 3.3V
3.3V→VCC-ไฟเลี้ยง 3.3V
GND→GND-กราวด์ร่วม; AD0→GND=0x68, AD0→VCC=0x69
PC3←INT-optional — data ready interrupt

รู้จักขา

  • VCC: ไฟเลี้ยง 3.3V
  • GND: กราวด์
  • SDA (PC1): สายข้อมูล I2C
  • SCL (PC2): สายนาฬิกา I2C
  • AD0: เลือก I2C address — GND=0x68, VCC=0x69
  • INT (PC3): ขา interrupt แจ้ง data ready (optional)
  • XDA/XCL: สาย I2C สำหรับต่อเซนเซอร์ภายนอก (pass-through, ไม่ต้องใช้ถ้ามีแค่ MPU6050)
  • pull-up 4.7kΩ: ต่อระหว่าง SDA→3.3V และ SCL→3.3V (โมดูลส่วนมากมีในตัว)

วิธีต่อทีละขั้น

  1. ต่อ VCC ของ MPU6050 ไป 3.3V
  2. ต่อ GND ของ MPU6050 ไป GND
  3. ต่อ SDA ของ MPU6050 ไป PC1 (ขา 13) ของ CH32V003
  4. ต่อ SCL ของ MPU6050 ไป PC2 (ขา 14) ของ CH32V003
  5. ต่อ AD0 ไป GND เพื่อใช้ address 0x68 (หรือ VCC=0x69)
  6. (optional) ต่อ INT ไป PC3 เพื่อรับสัญญาณ data ready interrupt
  7. ตรวจสอบว่าโมดูลมี R pull-up 4.7kΩ ในตัวหรือไม่ — ถ้าไม่มี ต่อ R เพิ่มจาก SDA→3.3V และ SCL→3.3V

PC1─SDA, PC2─SCL — AD0=GND → addr 0x68 — INT (PC3) optional สำหรับ interrupt แจ้ง data ready — ใช้ 3.3V

📚 หลักการทำงาน

MPU6050 มี MEMS sensors 2 ชนิดในชิปเดียว:

  • Gyroscope (ไจโร): วัดความเร็วเชิงมุม (°/s) — 3 แกน — ใช้คำนวณการหมุน
  • Accelerometer (แอคเซเลอโรมิเตอร์): วัดความเร่ง (g) — 3 แกน — ใช้หาทิศทางแรงโน้มถ่วง

Complementary Filter: รวมข้อดีของ Gyro (ตอบสนองเร็ว) และ Accel (แม่นในระยะยาว — drift-free)

angle = 0.98 × (angle_prev + gyro_rate × dt) + 0.02 × accel_angle

MPU6050_Data_t มี field: accel_x/y/z (g), gyro_x/y/z (°/s), temp (°C) — อ่านทั้งหมดในครั้งเดียวด้วย GetAll()

💻 เขียน Code ทีละขั้น

ขั้นที่ 1: Init + Setup

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "MPU6050.h"

MPU6050_Instance imu;
MPU6050_Data_t data;

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    USART_Init(USART1, BAUD_115200);
    I2C_Init(I2C1, I2C_SPEED_FAST);

    MPU6050_Init(&imu, 0x68);
    USART_Println("MPU6050 Ready");

🔍 MPU6050_Init(&imu, addr) — addr 0x68 (AD0=GND) หรือ 0x69 (AD0=VCC) — ใช้ I2C Fast Mode เพื่อความเร็วสูง

ขั้นที่ 2: อ่าน/เขียนค่า

    MPU6050_GetAll(&imu, &data);
    // data.accel_x, data.accel_y, data.accel_z (g)
    // data.gyro_x, data.gyro_y, data.gyro_z (°/s)
    // data.temp (°C)

    // แปลง accel → มุม (pitch, roll)
    float pitch = atan2(data.accel_y, data.accel_z) * 180.0f / M_PI;
    float roll  = atan2(data.accel_x, data.accel_z) * 180.0f / M_PI;

    USART_Print("Pitch: "); USART_PrintFloat(pitch, 1);
    USART_Print(" Roll: "); USART_PrintFloat(roll, 1);
    USART_Print(" Temp: "); USART_PrintFloat(data.temp, 1);
    USART_Println(" C");

🔍 MPU6050_GetAll(&imu, &data) — อ่านทั้งหมดในครั้งเดียว: accel ในหน่วย g, gyro ในหน่วย °/s, temp ใน °C

ขั้นที่ 3: Loop + แสดงผล

    float anglePitch = 0, angleRoll = 0;
    uint32_t lastTime = Get_CurrentMs();

    while(1) {
        MPU6050_GetAll(&imu, &data);

        uint32_t now = Get_CurrentMs();
        float dt = (now - lastTime) / 1000.0f;  // sec
        lastTime = now;

        // Accel angle
        float accPitch = atan2(data.accel_y, data.accel_z) * 180.0f / M_PI;
        float accRoll  = atan2(data.accel_x, data.accel_z) * 180.0f / M_PI;

        // Complementary filter
        anglePitch = 0.98f * (anglePitch + data.gyro_x * dt) + 0.02f * accPitch;
        angleRoll  = 0.98f * (angleRoll  + data.gyro_y * dt) + 0.02f * accRoll;

        USART_Print("P:"); USART_PrintFloat(anglePitch, 1);
        USART_Print(" R:"); USART_PrintFloat(angleRoll, 1);
        USART_Println("");

        Delay_Ms(10);  // ~100Hz
    }
}

🔍 Complementary filter — 0.98/0.02 คืออัตราส่วนความเชื่อถือระหว่าง Gyro (เร็วแต่ drift) กับ Accel (แม่นแต่ noisy) — dt ต้องถูกต้อง (ms → sec) — loop ต้องเร็วพอ (~100Hz)

🛠️ สร้าง Product: Self-Balancing Mini Robot

MPU6050 + Complementary Filter + PID + Motor — หุ่นยนต์ทรงตัว 2 ล้อ

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "MPU6050.h"

#define KP 25.0f  // PID proportional gain
#define KI  0.5f  // PID integral
#define KD  1.5f  // PID derivative

int main(void)
{
    SystemCoreClockUpdate();
    Timer_Init();
    I2C_Init(I2C1, I2C_SPEED_FAST);
    USART_Init(USART1, BAUD_115200);

    MPU6050_Instance imu;
    MPU6050_Data_t data;
    MPU6050_Init(&imu, 0x68);

    float angle = 0;
    uint32_t lastTime = Get_CurrentMs();

    while(1)
    {
        MPU6050_GetAll(&imu, &data);

        uint32_t now = Get_CurrentMs();
        float dt = (now - lastTime) / 1000.0f;
        lastTime = now;

        float accAngle = atan2(data.accel_x, data.accel_z) * 180.0f / M_PI;
        angle = 0.98f * (angle + data.gyro_y * dt) + 0.02f * accAngle;

        // PID output → Motor PWM
        float pid = KP * angle + KI * 0 + KD * data.gyro_y;
        // Motor left:  base + pid
        // Motor right: base - pid
        // (เชื่อมต่อมอเตอร์ผ่าน H-Bridge ที่นี่)

        USART_Print("Angle:"); USART_PrintFloat(angle, 1); USART_Println("");
        Delay_Ms(5);  // 200Hz control loop
    }
}

✏️ ลองทำดู

  1. ทำ digital level — ใช้ accel หา pitch/roll แสดงเป็นองศาบน OLED
  2. ทำ gesture mouse — ตรวจจับ tilt → ส่งค่าผ่าน USART → PC แปลเป็น mouse movement
  3. ทดลอง Complementary Filter — ลองเปลี่ยนค่า 0.98/0.02 → 0.95/0.05 และ 0.99/0.01 — ดูผลต่าง
  4. ทำ fall detection — ถ้า accel รวม > 2g → แจ้งเตือน "FALL!" (ใช้กับอุปกรณ์ผู้สูงอายุ)
