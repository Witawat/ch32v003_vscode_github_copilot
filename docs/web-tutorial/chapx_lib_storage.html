AT24Cxx — EEPROM I2C

PC1─SDA  PC2─SCL  3.3V─VCC  GND─GND  A0─GND  A1─GND  A2─GND
A0/A1/A2 = GND → I2C addr 0x50 (ต่อ VCC/VCC/VCC = 0x57)
#include "AT24Cxx.h"
AT24Cxx_Init(0x50, AT24C32); // addr, size (AT24C32=32Kbit/4KB)
AT24Cxx_WriteByte(0x50, 0, 42); // addr=0x50, mem_addr=0, data=42
uint8_t val = AT24Cxx_ReadByte(0x50, 0);
AT24Cxx_WritePage(0x50, 0, buffer, 32); // write 32 bytes (หาเขียนข้าม page!)
AT24Cxx_ReadPage(0x50, 0, buffer, 32);

⚠️ I2C addr 0x50-0x57 (เลือกด้วย A0/A1/A2 pins), page size: AT24C01=8B / AT24C02=8B / AT24C32=32B / AT24C256=64B, write cycle time ~5ms (ต้องรอ — ห้ามอ่าน/เขียนต่อทันที), endurance ~1M writes, page boundary: อย่าเขียนข้าม page (เช่น AT24C32 page 32B → เขียนที่ addr 30 ได้แค่ 2 byte ก่อนตีกลับ), ต่อได้หลายตัวผ่าน A0-A2

API หลัก

AT24Cxx_Init(addr, type)Init I2C + detect chipAT24Cxx_WriteByte(addr, mem, val)เขียน 1 byte
AT24Cxx_ReadByte(addr, mem)อ่าน 1 byteAT24Cxx_WritePage(addr, mem, buf, len)เขียน page (≤page_size)
AT24Cxx_ReadPage(addr, mem, buf, len)อ่านยาวตามต้องการAT24Cxx_EraseAll(addr)ลบทั้ง chip
AT24Cxx_WriteString(addr, mem, str)เขียนข้อความAT24Cxx_ReadString(addr, mem, buf, max)อ่านข้อความ

W25Qxx — SPI Flash

PC4─CS  PC5─SCK  PC6─MOSI  PC7─MISO  3.3V─VCC  GND─GND
/WP pin → 3.3V (disable write protect)  /HOLD pin → 3.3V
#include "W25Qxx.h"
W25Qxx_Init(PC4); // CS pin, auto-detect via JEDEC ID
uint32_t id = W25Qxx_ReadID();
USART_Print("Flash: "); USART_PrintHex(id, 6); USART_Println("");
W25Qxx_EraseSector(0);  // erase sector 0 (4KB) — ต้องทำก่อนเขียน!
W25Qxx_WritePage(0, "Hello SPI Flash", 15);
char buf[32];
W25Qxx_ReadData(0, (uint8_t*)buf, 15);
buf[15] = 0; USART_Println(buf);

⚠️ ต้อง erase sector ก่อนเขียนเสมอ (Nor Flash property — เขียนได้เฉพาะจาก 1→0, erase เปลี่ยน 0→1), sector=4KB / block=32KB/64KB, JEDEC ID auto-detect capacity (W25Q32=4MB / W25Q64=8MB / W25Q128=16MB), endurance ~100K writes per sector, write protection: /WP pin + status register block protect bits, page size 256B, chip erase takes ~40s (อย่าใช้ถ้าไม่จำเป็น), SPI max 80MHz (CH32V003 ทำได้ ~24MHz)

API หลัก

W25Qxx_Init(cs)Init SPI + detectW25Qxx_ReadID()อ่าน JEDEC ID (3 bytes)
W25Qxx_EraseSector(addr)ลบ 4KB sectorW25Qxx_EraseBlock(addr)ลบ 64KB block
W25Qxx_WritePage(addr, buf, len)เขียน ≤256BW25Qxx_ReadData(addr, buf, len)อ่าน (ไม่จำกัดความยาว)
W25Qxx_EraseChip()ลบทั้ง chip (~40s)W25Qxx_GetCapacity()คืนขนาดเป็น MB

DS3231 — RTC Module I2C

PC1─SDA  PC2─SCL  3.3V─VCC  GND─GND  CR2032─battery holder
SQW pin → PC0 (optional, 1Hz square wave output)
#include "DS3231.h"
DS3231_DateTime_t dt;
// Set: dt.year=26; dt.month=6; dt.day=29;
//      dt.hour=14; dt.minute=30; dt.second=0; dt.weekday=1;
// DS3231_SetDateTime(&dt);
DS3231_GetDateTime(&dt);
USART_PrintNum(dt.hour); USART_Print(":"); USART_PrintNum(dt.minute);
// Alarm:
DS3231_SetAlarm1(ALARM1_EVERY_SECOND, 0, 0, 0);
DS3231_EnableAlarm1(1);
// Temperature:
float t = DS3231_GetTemperature();

⚠️ I2C addr 0x68, accuracy ±2ppm (~1min error ต่อปี), CR2032 battery backup → เก็บเวลาขณะไฟดับ, SQW pin output: 1Hz/1kHz/4kHz/8kHz (ใช้ interrupt บอกเวลา), alarm 1+2 (match second/minute/hour/day), 24hr format, century bit (ปี 2000-2099), aging register สำหรับ calibrate crystal, temperature-compensated → แม่นกว่า DS1307 มาก, DS3231_GetTemperature() อ่าน sensor ในตัว (±3°C)

API หลัก

DS3231_GetDateTime(&dt)อ่านวันเวลาDS3231_SetDateTime(&dt)ตั้งวันเวลา
DS3231_GetTemperature()อ่านอุณหภูมิ °CDS3231_SetAlarm1(mode, s, m, h)ตั้ง alarm 1
DS3231_EnableAlarm1(en)เปิด/ปิด alarm 1DS3231_ClearAlarm1()ล้าง alarm flag
DS3231_EnableSQW(freq)เปิด square waveDS3231_GetUnixTime()Unix timestamp

PCA9685 — 16-Ch PWM Driver I2C

PC1─SDA  PC2─SCL  GND─GND common
5V external─VCC(power)  3.3V─VCC(logic)  OE─GND (enable, LOW=on)
⚠️ ต่อ power/logic VCC แยก — power ใช้ external 5V, logic ใช้ 3.3V จาก CH32V003
#include "PCA9685.h"
PCA9685_Init(0x40); // I2C addr 0x40-0x7F (A0-A5 pins)
PCA9685_SetPWMFreq(50); // 50Hz for servo
PCA9685_SetPWM(0, 0, 307); // ch0, on=0, off=307 → 1.5ms (servo center)
// 12-bit: off = 0-4095, duty = off/4096
// Servo calc:
uint16_t pwm = (uint16_t)((angle/180.0f)*(max-min) + min);
// All off: PCA9685_SetAllPWM(0, 0);

⚠️ 16 channels (ใช้กับ ServoCluster ได้หลายตัว), 12-bit PWM (4096 steps), external power 5-6V สำหรับขับ servo/LED, logic supply 2.3-5.5V (ต่อกับ CH32V003 3.3V), OE pin = output enable (LOW=enabled / HIGH=all off), I2C addr เลือกด้วย A0-A5 pins (0x40 baseline → 0x7F max, up to 62 modules!), frequency range 24Hz-1526Hz, 50Hz ใช้กับ servo (20ms period), สำหรับ LED dimming ใช้ ≥200Hz (ไม่กระพริบ), output totem-pole 25mA sink/source per channel

API หลัก

PCA9685_Init(addr)Init I2C + resetPCA9685_SetPWMFreq(hz)ตั้งความถี่ PWM
PCA9685_SetPWM(ch, on, off)ตั้ง PWM 1 channelPCA9685_SetAllPWM(on, off)ตั้งทุก channel พร้อมกัน
PCA9685_CalcPWM(deg, min, max)คำนวณ servo PWMPCA9685_Sleep()เข้า sleep mode

PCF8574 — IO Expander 8-bit I2C

PC1─SDA  PC2─SCL  3.3V─VCC  GND─GND  A0─GND  A1─GND  A2─GND (=addr 0x20)
INT─PC0 (optional — interrupt when any input changes)
#include "PCF8574.h"
PCF8574_Init(0x20); // addr 0x20-0x27 (A0-A2 pins)
PCF8574_WriteByte(0x20, 0xFF); // all pins HIGH
PCF8574_WriteBit(0x20, 0, 0);  // P0 = LOW
uint8_t state = PCF8574_ReadByte(0x20); // read all
uint8_t bit3  = PCF8574_ReadBit(0x20, 3); // read P3
// Interrupt on any change:
PCF8574_EnableInterrupt(0x20, PC0, my_callback);

⚠️ 8 I/O pins (quasi-bidirectional — ต้องเขียน 1 ก่อนอ่านทุกครั้ง), I2C addr 0x20-0x27 (เลือกด้วย A0-A2), interrupt-on-change (INT pin LOW เมื่อ input ใดๆเปลี่ยน → ใช้ external interrupt บน CH32V003), output latch (คงค่าสุดท้ายไว้), sink current 25mA per pin / source ~100µA (weak pull-up — ขับ LED ต้องต่อแบบ active-low), quasi-bidirectional requirement: เขียน 0xFF → ถึงจะอ่าน input ได้, PCF8574A = addr 0x38-0x3F (คนละรุ่น)

API หลัก

PCF8574_Init(addr)Init I2CPCF8574_WriteByte(addr, val)เขียน 8 bits พร้อมกัน
PCF8574_ReadByte(addr)อ่าน 8 bitsPCF8574_WriteBit(addr, bit, val)เขียน 1 bit
PCF8574_ReadBit(addr, bit)อ่าน 1 bitPCF8574_EnableInterrupt(addr, pin, cb)ตั้ง interrupt handler

I2CScan — Bus Scanner I2C

ต่ออุปกรณ์ I2C ตามปกติ → ใช้ I2CScan หา address ก่อนใช้งาน
PC1─SDA  PC2─SCL — scanner จะ scan 1-127 แล้วพิมพ์ address ที่พบทาง USART
#include "I2CScan.h"
I2C_SimpleInit(I2C_SPEED_100K, I2C_PINS_DEFAULT);
I2CScan_Scan(); // scans 1-127, prints found addresses to USART
// Manual scan:
for(uint8_t addr=1; addr<127; addr++) {
    I2C_Start(); I2C_WriteAddr(addr<<1);
    if(I2C_WaitAck()) {
        USART_Print("Found: 0x"); USART_PrintHex(addr, 2); USART_Println("");
    }
    I2C_Stop();
}

⚠️ ใช้หา address อุปกรณ์ I2C ก่อนใช้งาน sensor ใหม่, address conflicts detection (ถ้ามี 2 ตัว address เดียวกัน → ทั้งคู่ตอบ ACK), scan range 1-127 (0=general call, ไม่ scan), ใช้ USART_Print แสดงผล → ต้อง init USART1 ก่อน, I2C_SPEED_100K หรือ I2C_SPEED_400K, มีประโยชน์มากเวลา debugging: ต่ออุปกรณ์ไม่รู้ address → กด I2CScan ดูก่อน

API หลัก

I2C_SimpleInit(speed, pins)Init I2C busI2CScan_Scan()Scan + print address ทั้งหมด
I2CScan_Check(addr)เช็ค 1 addressI2CScan_GetCount()จำนวนอุปกรณ์ที่พบ

เลือกยังไง? เก็บบ configuration เล็กๆ → AT24Cxx, เก็บข้อมูลใหญ่ (log, firmware) → W25Qxx, ต้องการเวลานาฬิกาแม่น → DS3231, ระบบ RFID ประตู/บัตร → RC522, ขับ servo หลายตัว → PCA9685, ขยายขา GPIO → PCF8574, หา address อุปกรณ์ I2C → I2CScan

✏️ ลองทำดู

  1. AT24Cxx config store — บันทึก WiFi SSID/PASS ลง EEPROM, อ่านกลับตอน boot (auto-connect), มีฟังก์ชัน factory reset (ลบ EEPROM)
  2. W25Qxx data logger — อ่านเซนเซอร์ทุก 1s → append ลง Flash (1000 readings), กดปุ่ม → dump ทั้งหมดเป็น CSV ทาง USART, แสดงพื้นที่คงเหลือ
  3. DS3231 alarm clock — ตั้งเวลา+ปลุกผ่าน serial command, เมื่อถึงเวลาปลุก → เปิด buzzer 10s + LED flash, แสดงเวลาบน OLED
  4. RC522 door lock — whitelist UID 5 บัตรใน EEPROM, แตะบัตร → ตรงกับ whitelist → relay ปลดล็อก 3s + OLED แสดงชื่อ, ไม่ตรง → buzzer ปิ๊ด
  5. PCA9685 LED dimmer — 16 LEDs แยก dim อิสระ, รับคำสั่ง serial: "CH5=2048" → ตั้ง PWM channel 5, รองรับ fade effect (ค่อยๆเปลี่ยน)
  6. PCF8574 keypad — ต่อ matrix keypad 4x3 ผ่าน PCF8574 (7 pins → I2C), อ่าน key press + debounce, ส่ง key ทาง USART
