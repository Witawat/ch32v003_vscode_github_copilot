WS2815 ใช้ไฟ 12V — มีขา BI (Backup Input) สำหรับ break-point continue — ถ้า LED ดวงใดเสีย สัญญาณจะข้ามไปดวงถัดไป — ต้องใช้ Level Shifter 3.3V → 5V สำหรับ data

📚 หลักการทำงาน

WS2815 vs WS2812B: WS2815 เป็นรุ่น 12V ของ WS2812B — แรงดันสูงกว่าทำให้ voltage drop ตามสายน้อยลง — เหมาะกับ strip ยาวหรืองาน outdoor — protocol เหมือน WS2812B (800kHz NRZ, GRB)

Break-Point Continue (BPC): WS2815 มี 2 data input (DIN + BI) — ถ้า LED ดวงใดเสียหาย (open circuit) — สัญญาณจะถูกส่งต่อไป LED ถัดไปผ่านขา BI — LED ดวงอื่นยังทำงานได้ตามปกติ — ข้อดีสำหรับงานติดตั้งถาวร

12V Advantage: แรงดันสูง = กระแสต่ำ = voltage drop น้อย — ไฟ 12V 2A จ่าย LED ได้ 200+ ดวง — ไม่ต้องต่อไฟเสริมบ่อยเหมือน WS2812B — ใช้กับ PSU 12V ทั่วไป

API Compatible: WS2815Matrix มี API เหมือน WS2812Matrix — Init, Clear, SetPixel, Print, ScrollText, Rainbow — เปลี่ยนจาก WS2812B เป็น WS2815 แค่เปลี่ยนชื่อฟังก์ชัน

💻 เขียน Code ทีละขั้น

ขั้นที่ 1: Init + Setup

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "WS2815Matrix.h"

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();

    WS2815Matrix_Init(PC0, 8, 8);
    WS2815Matrix_SetBrightness(128);
    WS2815Matrix_Clear();
    WS2815Matrix_Show();

🔍 ใช้ API เดียวกับ WS2812Matrix — Init(pin, w, h) — SetBrightness 0-255 — Clear+Show pattern มาตรฐาน

ขั้นที่ 2: แสดงผล

    WS2815Matrix_SetCursor(0, 0);
    WS2815Matrix_SetTextColor(RGB(255, 165, 0)); // Orange
    WS2815Matrix_Print("12V");
    WS2815Matrix_Show();

    // Scroll text
    WS2815Matrix_ScrollText("WS2815", 150, RGB(0, 255, 255));
    // Rainbow
    WS2815Matrix_Rainbow(40);

🔍 ฟังก์ชันเหมือน WS2812Matrix — SetCursor + Print + Show — ScrollText เลื่อนข้อความ — Rainbow effect — ไม่ต้องเปลี่ยน logic

ขั้นที่ 3: Loop แสดงโหมด

    uint8_t mode = 0;
    Timer_t tmr;
    Start_Timer(&tmr, 5000, 1);

    while(1) {
        if(Is_Timer_Expired(&tmr)) {
            WS2815Matrix_Clear();
            if(mode == 0) {
                WS2815Matrix_SetCursor(0, 1);
                WS2815Matrix_Print("12V");
                WS2815Matrix_Show();
            } else {
                WS2815Matrix_Rainbow(30);
            }
            mode = !mode;
        }
    }
}

🔍 สลับโหมดทุก 5 วิ — แสดง "12V" กับ Rainbow — Non-Blocking Timer — WS2815 ทนทานกว่า WS2812B เพราะ break-point continue

⚠️ ข้อผิดพลาดที่พบบ่อย

ปัญหาสาเหตุวิธีแก้
LED เจอแต่ไม่ติดใช้ไฟ 5V — WS2815 ต้อง 12Vใช้ PSU 12V — อย่าใช้ 5V — WS2815 ไม่ทำงานที่ 5V
LED บางดวงไม่ติดแต่ดวงอื่นปกติLED ดวงนั้นเสีย — BPC ทำงานWS2815 มี break-point continue — เปลี่ยนเฉพาะ LED ที่เสีย
สีเพี้ยนทั้ง matrixLevel Shifter ไม่ทำงาน หรือต่อผิด3.3V → 5V จำเป็น — ใช้ 74HCT125 หรือ SN74AHCT125
ไฟ 12V แต่ LED สลัวPSU จ่ายกระแสไม่พอ — 12V ต้อง ≥ 1.5Aใช้ PSU 12V 2A+ — ตรวจสอบ rating PSU
BI ขาลอย — LED ทำงานแปลกขา BI ต้องต่อ GND เมื่อไม่ใช้ต่อ BI ลง GND — อย่าปล่อยลอย (floating)

🛠️ สร้าง Product: ป้ายไฟ Outdoor 12V

WS2815 8×8 แสดงข้อความเลื่อน — เหมาะกับงาน outdoor เพราะ 12V + BPC — ใช้ PSU 12V ทนแดดทนฝน

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "WS2815Matrix.h"

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    WS2815Matrix_Init(PC0, 8, 8);
    WS2815Matrix_SetBrightness(200);

    while(1) {
        WS2815Matrix_ScrollText("OPEN", 150, RGB(0, 255, 0));
        Delay_Ms(500);
        WS2815Matrix_Rainbow(40);
        Delay_Ms(500);
        WS2815Matrix_ScrollText("12V!", 150, RGB(255, 165, 0));
        Delay_Ms(500);
    }
}

✏️ ลองทำดู

  1. ทดสอบ Break-Point Continue — ถอด LED 1 ดวงออก ดูว่าดวงอื่นยังทำงาน
  2. ทำ Thermometer แสดงอุณหภูมิด้วยสี — ใช้ DHT11 — น้ำเงิน=เย็น, เขียว=ปกติ, แดง=ร้อน
