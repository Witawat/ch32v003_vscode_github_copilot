WS2815 ใช้ไฟ 12V — มีขา BI (Backup Input) สำหรับ break-point continue — ถ้า LED ดวงใดเสีย สัญญาณจะข้ามไปดวงถัดไป — ต้องใช้ Level Shifter 3.3V → 5V สำหรับ data

📚 หลักการทำงาน

WS2815 vs WS2812B: WS2815 เป็นรุ่น 12V ของ WS2812B — แรงดันสูงกว่าทำให้ voltage drop ตามสายน้อยลง — เหมาะกับ strip ยาวหรืองาน outdoor — protocol เหมือน WS2812B (800kHz NRZ, GRB)

Break-Point Continue (BPC): WS2815 มี 2 data input (DIN + BI) — ถ้า LED ดวงใดเสียหาย (open circuit) — สัญญาณจะถูกส่งต่อไป LED ถัดไปผ่านขา BI — LED ดวงอื่นยังทำงานได้ตามปกติ — ข้อดีสำหรับงานติดตั้งถาวร

12V Advantage: แรงดันสูง = กระแสต่ำ = voltage drop น้อย — ไฟ 12V 2A จ่าย LED ได้ 200+ ดวง — ไม่ต้องต่อไฟเสริมบ่อยเหมือน WS2812B — ใช้กับ PSU 12V ทั่วไป

API: ใช้ฟังก์ชัน Matrix_* — Matrix_Init, Matrix_SetPixel, Matrix_Show, Matrix_Clear — ทำงานกับ GPIO port/pin โดยตรง

💻 เขียน Code ทีละขั้น

ขั้นที่ 1: Init + Setup

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "WS2815Matrix.h"

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();

    Matrix_Init(GPIOC, GPIO_Pin_0, 8, 8, WIRING_ZIGZAG);
    Matrix_Clear();
    Matrix_Show();

🔍 Matrix_Init(port, pin, w, h, wiring) — ใช้ GPIOC + GPIO_Pin_0 — WIRING_ZIGZAG สำหรับ serpentine layout — ใช้กับ WS2815 matrix 12V

ขั้นที่ 2: แสดงผล

    // ตั้ง pixel ทีละดวง
    Matrix_SetPixel(0, 0, COLOR_RED);
    Matrix_SetPixel(3, 3, COLOR_GREEN);
    Matrix_SetPixel(7, 7, COLOR_BLUE);
    Matrix_Show();
    Delay_Ms(1000);

    // ล้าง
    Matrix_Clear();
    Matrix_Show();

    // Rainbow effect
    Matrix_Rainbow(40);

🔍 Matrix_SetPixel(x, y, color) ตั้งค่าสี — COLOR_RED, COLOR_GREEN, COLOR_BLUE เป็นค่าคงที่ — Matrix_Show() ส่ง buffer — API เรียบง่าย ไม่ต้องใช้ instance

ขั้นที่ 3: Loop แสดงโหมด

    uint8_t mode = 0;
    Timer_t tmr;
    Start_Timer(&tmr, 5000, 1);

    while(1) {
        if(Is_Timer_Expired(&tmr)) {
            Matrix_Clear();
            if(mode == 0) {
                for(uint8_t x=0; x<8; x++)
                    Matrix_SetPixel(x, 1, COLOR_ORANGE);
                Matrix_Show();
            } else {
                Matrix_Rainbow(30);
            }
            mode = !mode;
        }
    }
}

🔍 สลับโหมดทุก 5 วิ — Matrix_Rainbow effect — Non-Blocking Timer — WS2815 ทนทานกว่า WS2812B เพราะ break-point continue

⚠️ ข้อผิดพลาดที่พบบ่อย

ปัญหาสาเหตุวิธีแก้
LED เจอแต่ไม่ติดใช้ไฟ 5V — WS2815 ต้อง 12Vใช้ PSU 12V — อย่าใช้ 5V — WS2815 ไม่ทำงานที่ 5V
LED บางดวงไม่ติดแต่ดวงอื่นปกติLED ดวงนั้นเสีย — BPC ทำงานWS2815 มี break-point continue — เปลี่ยนเฉพาะ LED ที่เสีย
สีเพี้ยนทั้ง matrixLevel Shifter ไม่ทำงาน หรือต่อผิด3.3V → 5V จำเป็น — ใช้ 74HCT125 หรือ SN74AHCT125
ไฟ 12V แต่ LED สลัวPSU จ่ายกระแสไม่พอ — 12V ต้อง ≥ 1.5Aใช้ PSU 12V 2A+ — ตรวจสอบ rating PSU
BI ขาลอย — LED ทำงานแปลกขา BI ต้องต่อ GND เมื่อไม่ใช้ต่อ BI ลง GND — อย่าปล่อยลอย (floating)

🛠️ สร้าง Product: ป้ายไฟ Outdoor 12V

WS2815 8×8 แสดง Pixel Art — เหมาะกับงาน outdoor เพราะ 12V + BPC — ใช้ PSU 12V ทนแดดทนฝน

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "WS2815Matrix.h"

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    Matrix_Init(GPIOC, GPIO_Pin_0, 8, 8, WIRING_ZIGZAG);

    while(1) {
        // แสดงกรอบสีเขียว
        Matrix_Clear();
        for(uint8_t x=0; x<8; x++) {
            Matrix_SetPixel(x, 0, COLOR_GREEN);
            Matrix_SetPixel(x, 7, COLOR_GREEN);
        }
        for(uint8_t y=0; y<8; y++) {
            Matrix_SetPixel(0, y, COLOR_GREEN);
            Matrix_SetPixel(7, y, COLOR_GREEN);
        }
        Matrix_Show();
        Delay_Ms(2000);

        // Rainbow
        Matrix_Rainbow(40);
        Delay_Ms(2000);
    }
}
