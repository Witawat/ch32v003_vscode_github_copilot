BMP280 — ความกดอากาศ+อุณหภูมิ I2C

ระดับกลาง

🧭 แผนภาพการทำงาน

flowchart TD
    A["BMP280_Init(addr)"] --> B["SetMode(NORMAL)"]
    B --> C["ReadTemperature+ReadPressure"]
    C --> D["Calc Altitude"]
    D --> E["Display/Delay"]
    E --> C

🔌 การต่อวงจร

        BMP280 (I2C)
┌────────────────────────────────────┐
│ PC1 ──── SDA                       │
│ PC2 ──── SCL                       │
│ 3.3V ─── VCC                       │
│ GND  ─── GND                       │
│                                    │
│ SDO ─── GND  → addr = 0x76         │
│ SDO ─── VCC  → addr = 0x77         │
│ (ต่อ 2 ตัวบน I2C เดียวได้)          │
└────────────────────────────────────┘

SDO pin เลือก I2C address — ต่อ GND = 0x76, ต่อ VCC = 0x77 ทำให้ต่อ BMP280 ได้ 2 ตัวบนบัสเดียวกัน

📚 หลักการทำงาน

I2C Interface: แอดเดรส 0x76 หรือ 0x77 — เลือกด้วยขา SDO

Compensation Formula: BMP280 เก็บ calibration data ใน internal registers — Library จะอ่านและใช้คำนวณอัตโนมัติ

ความกดอากาศ: 300-1100 hPa — ใช้คำนวณความสูงจากระดับน้ำทะเลได้

อุณหภูมิ: -40°C ถึง +85°C — ใช้สำหรับ compensation ความกดอากาศ และใช้อ่านอุณหภูมิทั่วไปได้

Altitude: คำนวณจาก sea-level pressure — ค่าเริ่มต้น 1013.25 hPa (ความกดอากาศเฉลี่ยที่ระดับน้ำทะเล)

Modes: SLEEP (พัก), FORCED (วัด 1 ครั้งแล้วพัก — ประหยัดไฟ), NORMAL (วัดต่อเนื่องอัตโนมัติ)

Oversampling: Temperature x1-x16, Pressure x1-x16 — ค่าสูง = แม่นยำขึ้นแต่ใช้เวลานานขึ้น + กินไฟมากขึ้น

IIR Filter: กัน noise — off/2/4/8/16 — ใช้กับ NORMAL mode

💻 เขียน Code ทีละขั้น

ขั้นที่ 1: Init I2C + BMP280

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "BMP280.h"

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    I2C_SimpleInit(I2C_SPEED_100K, I2C_PINS_DEFAULT);

    BMP280_Init(0x76);                  // SDO=GND → 0x76
    BMP280_SetMode(BMP280_MODE_NORMAL); // วัดต่อเนื่อง
    Delay_Ms(100);                      // รอ measurement แรก
    USART_Println("BMP280 Ready!");

🔍 BMP280_Init(addr) โหลด calibration data โดยอัตโนมัติ, SetMode(NORMAL) เริ่มวัดต่อเนื่อง — ต้องรอ 100ms ให้ measurement แรกเสร็จ

ขั้นที่ 2: อ่านอุณหภูมิ + ความกดอากาศ + ความสูง

    float t = BMP280_ReadTemperature();          // °C
    float p = BMP280_ReadPressure() / 100.0f;     // Pa → hPa
    float alt = BMP280_ReadAltitude(1013.25f);    // เทียบ sea-level

    USART_Print("T: "); USART_PrintFloat(t, 1);
    USART_Print("C  P: "); USART_PrintFloat(p, 1);
    USART_Print("hPa  Alt: "); USART_PrintFloat(alt, 1);
    USART_Println("m");

🔍 ReadPressure() คืนค่าเป็น Pascal (Pa) — หาร 100 ได้ hPa, ReadAltitude(seaLevel_hPa) คำนวณความสูงจากระดับน้ำทะเล — เปลี่ยน seaLevel ได้ตามสภาพอากาศจริง

ขั้นที่ 3: Loop + USART Print

    Timer_t tmr;
    Start_Timer(&tmr, 1000, 1);

    while(1) {
        if(Is_Timer_Expired(&tmr)) {
            float t = BMP280_ReadTemperature();
            float p = BMP280_ReadPressure() / 100.0f;
            float alt = BMP280_ReadAltitude(1013.25f);
            USART_Print("T:"); USART_PrintFloat(t, 1);
            USART_Print(" P:"); USART_PrintFloat(p, 1);
            USART_Print(" Alt:"); USART_PrintFloat(alt, 1);
            USART_Println("m");
        }
        IWDG_Feed();
    }
}

🔍 ใช้ Timer_t อ่านทุก 1 วิ — NORMAL mode วัดต่อเนื่องให้ค่าล่าสุดตลอด, IWDG_Feed() เลี้ยง watchdog

⚠️ ข้อผิดพลาดที่พบบ่อย

ปัญหาสาเหตุวิธีแก้
อ่านค่าคืน 0 ตลอดI2C address ผิด — ใช้คนละ address กับที่ต่อ SDOเช็คขา SDO — GND = 0x76, VCC = 0x77 — หรือใช้ I2C Scan หา address
ค่าความสูงแปลก — ขึ้นๆ ลงๆ เป็นร้อยเมตรsea-level pressure ไม่ถูกต้อง — ใช้ค่า default 1013.25 hPa แต่ของจริงแตกต่างตามสภาพอากาศหาค่า sea-level pressure จริงจากเว็บพยากรณ์อากาศในพื้นที่ — ปรับ argument ใน ReadAltitude()
I2C bus hang — อ่านไม่ขึ้นอีกเลยI2C bus lockup — noise รบกวนระหว่างสื่อสารทำ I2C bus reset: ส่ง 9 clock pulses บน SCL, แล้ว Re-Init I2C
NORMAL mode กินไฟตลอดเวลา (~1.1mA)NORMAL mode วัดต่อเนื่อง — เหมาะกับ mains-poweredใช้ FORCED mode: SetMode(FORCED) → รอ → อ่าน → chip sleep อัตโนมัติ (~0.1μA)
อุณหภูมิอ่านได้สูงกว่าความเป็นจริง ~2°CSelf-heating จากวงจรบนบอร์ด — BMP280 อยู่ใกล้ regulatorแยก BMP280 ให้ห่างจาก heat source บน PCB, ใช้ FORCED mode ลด duty cycle

🛠️ สร้าง Product: เครื่องวัดความสูงพกพา

BMP280 + OLED SSD1306 — แสดง altitude แบบ real-time

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "BMP280.h"
#include "oled_i2c.h"

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    I2C_SimpleInit(I2C_SPEED_100K, I2C_PINS_DEFAULT);

    BMP280_Init(0x76);
    BMP280_SetMode(BMP280_MODE_NORMAL);
    Delay_Ms(100);

    OLED_Handle oled;
    OLED_Init(&oled, OLED_128x64, 0x3C);
    OLED_SetFont(&oled, FONT_8x16);

    Timer_t tmr;
    Start_Timer(&tmr, 500, 1);

    while(1) {
        if(Is_Timer_Expired(&tmr)) {
            float t = BMP280_ReadTemperature();
            float p = BMP280_ReadPressure() / 100.0f;
            float alt = BMP280_ReadAltitude(1013.25f);
            OLED_Clear(&oled);
            OLED_SetCursor(&oled, 0, 0);
            OLED_PrintFloat(&oled, "T:", t, 1); OLED_Print(&oled, " C");
            OLED_SetCursor(&oled, 0, 2);
            OLED_PrintFloat(&oled, "P:", p, 1); OLED_Print(&oled, " hPa");
            OLED_SetCursor(&oled, 0, 4);
            OLED_PrintFloat(&oled, "Alt:", alt, 1); OLED_Print(&oled, " m");
            OLED_Update(&oled);
        }
        IWDG_Feed();
    }
}
