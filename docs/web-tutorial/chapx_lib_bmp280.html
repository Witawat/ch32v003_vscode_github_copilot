BMP280 — ความกดอากาศ+อุณหภูมิ I2C

ระดับกลาง

🧭 แผนภาพการทำงาน

flowchart TD
    A["BMP280_Init(&bmp, BMP280_ADDR_LOW)"] --> B["BMP280_Read(&bmp, &temp, &press)"]
    B --> C["BMP280_GetAltitude(&bmp, press, 1013.25f)"]
    C --> D["Display/Delay"]
    D --> B

🔌 การต่อวงจร

        BMP280 (I2C)
┌────────────────────────────────────┐
│ PC1 ──── SDA                       │
│ PC2 ──── SCL                       │
│ 3.3V ─── VCC                       │
│ GND  ─── GND                       │
│                                    │
│ SDO ─── GND  → addr = 0x76         │
│ SDO ─── VCC  → addr = 0x77         │
│ (ต่อ 2 ตัวบน I2C เดียวได้)          │
└────────────────────────────────────┘

SDO pin เลือก I2C address — ต่อ GND = 0x76 (BMP280_ADDR_LOW), ต่อ VCC = 0x77 (BMP280_ADDR_HIGH) — ต่อ BMP280 ได้ 2 ตัวบนบัสเดียวกัน

MCU Pin→อุปกรณ์ขาหมายเหตุ
PC1↔SDA-สายข้อมูล I2C — ต้องมี R 4.7kΩ pull-up ไป 3.3V
PC2→SCL-สายนาฬิกา I2C — ต้องมี R 4.7kΩ pull-up ไป 3.3V
3.3V→VCC-ไฟเลี้ยง 3.3V
GND→GND-กราวด์ร่วม
GND→SDO-ต่อ GND = address 0x76, ต่อ VCC = address 0x77

รู้จักขา

  • VCC: ไฟเลี้ยง 3.3V
  • GND: กราวด์
  • SDA (PC1): สายข้อมูล I2C
  • SCL (PC2): สายนาฬิกา I2C
  • SDO: เลือก I2C address — GND=0x76, VCC=0x77
  • pull-up 4.7kΩ: ต่อระหว่าง SDA→3.3V และ SCL→3.3V (โมดูลส่วนมากมีในตัว)

วิธีต่อทีละขั้น

  1. ต่อ VCC ของ BMP280 ไป 3.3V
  2. ต่อ GND ของ BMP280 ไป GND
  3. ต่อ SDA ของ BMP280 ไป PC1 (ขา 13) ของ CH32V003
  4. ต่อ SCL ของ BMP280 ไป PC2 (ขา 14) ของ CH32V003
  5. ต่อ SDO ไป GND เพื่อใช้ address 0x76 (หรือ VCC=0x77 — ต่อ 2 ตัวบน I2C เดียวกันได้)
  6. ตรวจสอบว่าโมดูลมี R pull-up 4.7kΩ ในตัวหรือไม่ — ถ้าไม่มี ต่อ R เพิ่มจาก SDA→3.3V และ SCL→3.3V

📚 หลักการทำงาน

I2C Interface: แอดเดรส 0x76 (BMP280_ADDR_LOW) หรือ 0x77 (BMP280_ADDR_HIGH) — เลือกด้วยขา SDO

Compensation Formula: BMP280 เก็บ calibration data ใน internal registers — BMP280_Init() จะอ่านและใช้คำนวณอัตโนมัติ

ความกดอากาศ: 300-1100 hPa — ใช้คำนวณความสูงจากระดับน้ำทะเลได้

อุณหภูมิ: -40°C ถึง +85°C — ใช้สำหรับ compensation ความกดอากาศ และใช้อ่านอุณหภูมิทั่วไปได้

Altitude: คำนวณจาก sea-level pressure — BMP280_GetAltitude(&bmp, press, 1013.25f) — ค่าเริ่มต้น 1013.25 hPa (ความกดอากาศเฉลี่ยที่ระดับน้ำทะเล)

BMP280_Read(): อ่านทั้งอุณหภูมิและความกดอากาศในครั้งเดียว — ไม่มีฟังก์ชันแยก BMP280_ReadTemperature / BMP280_ReadPressure — ค่าความกดเป็น Pa ต้องหาร 100 เป็น hPa

💻 เขียน Code ทีละขั้น

ขั้นที่ 1: Init I2C + BMP280

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "BMP280.h"

BMP280_Instance bmp;

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    I2C_SimpleInit(I2C_SPEED_100K, I2C_PINS_DEFAULT);

    BMP280_Init(&bmp, BMP280_ADDR_LOW);  // 0x76
    USART_Println("BMP280 Ready!");

🔍 BMP280_Init(&bmp, addr) — ใช้ BMP280_ADDR_LOW (0x76) หรือ BMP280_ADDR_HIGH (0x77) — โหลด calibration data โดยอัตโนมัติ

ขั้นที่ 2: อ่านอุณหภูมิ + ความกดอากาศ + ความสูง

    float temp, press;
    BMP280_Read(&bmp, &temp, &press);     // อ่านทั้ง temp และ press ในครั้งเดียว
    float press_hPa = press / 100.0f;        // Pa → hPa
    float alt = BMP280_GetAltitude(&bmp, press, 1013.25f);

    USART_Print("T: "); USART_PrintFloat(temp, 1);
    USART_Print("C  P: "); USART_PrintFloat(press_hPa, 1);
    USART_Print("hPa  Alt: "); USART_PrintFloat(alt, 1);
    USART_Println("m");

🔍 BMP280_Read(&bmp, &temp, &press) อ่านทั้งสองค่าในฟังก์ชันเดียว — press เป็น Pa หาร 100 ได้ hPa — BMP280_GetAltitude() รับค่า press และ sea-level pressure

ขั้นที่ 3: Loop + USART Print

    Timer_t tmr;
    Start_Timer(&tmr, 1000, 1);

    while(1) {
        if(Is_Timer_Expired(&tmr)) {
            float temp, press;
            BMP280_Read(&bmp, &temp, &press);
            float alt = BMP280_GetAltitude(&bmp, press, 1013.25f);
            USART_Print("T:"); USART_PrintFloat(temp, 1);
            USART_Print(" P:"); USART_PrintFloat(press/100.0f, 1);
            USART_Print(" Alt:"); USART_PrintFloat(alt, 1);
            USART_Println("m");
        }
        IWDG_Feed();
    }
}

🔍 ใช้ Timer_t อ่านทุก 1 วิ — BMP280_Read() ให้ทั้ง temp และ press ในครั้งเดียว — IWDG_Feed() เลี้ยง watchdog

⚠️ ข้อผิดพลาดที่พบบ่อย

ปัญหาสาเหตุวิธีแก้
อ่านค่าคืน 0 ตลอดI2C address ผิด — ใช้คนละ address กับที่ต่อ SDOเช็คขา SDO — GND = BMP280_ADDR_LOW (0x76), VCC = BMP280_ADDR_HIGH (0x77)
ค่าความสูงแปลก — ขึ้นๆ ลงๆ เป็นร้อยเมตรsea-level pressure ไม่ถูกต้อง — ใช้ค่า default 1013.25 hPa แต่ของจริงแตกต่างตามสภาพอากาศหาค่า sea-level pressure จริงจากเว็บพยากรณ์อากาศในพื้นที่ — ปรับ argument ใน BMP280_GetAltitude()
I2C bus hang — อ่านไม่ขึ้นอีกเลยI2C bus lockup — noise รบกวนระหว่างสื่อสารทำ I2C bus reset: ส่ง 9 clock pulses บน SCL, แล้ว Re-Init I2C
อุณหภูมิอ่านได้สูงกว่าความเป็นจริง ~2°CSelf-heating จากวงจรบนบอร์ด — BMP280 อยู่ใกล้ regulatorแยก BMP280 ให้ห่างจาก heat source บน PCB

🛠️ สร้าง Product: เครื่องวัดความสูงพกพา

BMP280 + OLED SSD1306 — แสดง altitude แบบ real-time

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "BMP280.h"
#include "oled_i2c.h"
#include "oled_graphics.h"
#include "oled_fonts.h"

BMP280_Instance bmp;
OLED_Handle oled;

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    I2C_SimpleInit(I2C_SPEED_100K, I2C_PINS_DEFAULT);

    BMP280_Init(&bmp, BMP280_ADDR_LOW);

    OLED_Init(&oled, OLED_128x64, 0x3C);
    OLED_SetFont(&oled, FONT_8x16);

    Timer_t tmr;
    Start_Timer(&tmr, 500, 1);
    char buf[32];

    while(1) {
        if(Is_Timer_Expired(&tmr)) {
            float temp, press;
            BMP280_Read(&bmp, &temp, &press);
            float alt = BMP280_GetAltitude(&bmp, press, 1013.25f);

            OLED_Clear(&oled);
            SimpleHAL_Sprintf(buf, "T: %.1f C", temp);
            OLED_DrawStringAlign(&oled, 0, 0, buf, ALIGN_LEFT);
            SimpleHAL_Sprintf(buf, "P: %.1f hPa", press/100.0f);
            OLED_DrawStringAlign(&oled, 20, 0, buf, ALIGN_LEFT);
            SimpleHAL_Sprintf(buf, "Alt: %.1f m", alt);
            OLED_DrawStringAlign(&oled, 40, 0, buf, ALIGN_LEFT);
            OLED_Update(&oled);
        }
        IWDG_Feed();
    }
}

✏️ ลองทำดู

  1. Weather Station — ส่งค่า temp+pressure+altitude ผ่าน USART ทุก 1 วิ เปิด Serial Plotter ดูกราฟ
