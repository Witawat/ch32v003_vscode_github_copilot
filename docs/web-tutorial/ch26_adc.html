ex01_Simple_AnalogRead — อ่านค่า Analog พื้นฐาน

📖 แนวคิด

ตัวอย่างแรกของ ADC — ใช้ ADC_SimpleInit เริ่มต้น ADC ความละเอียด 12-bit (0-4095) อ่านค่าด้วย ADC_Read แล้วแปลงเป็นแรงดันจริงด้วย ToVoltage แสดงผลทาง USART

🔌 วงจร

    CH32V003              Potentiometer
      PA1 ----[ADC_IN1]----┬---- VCC (3.3V)
                           └---- GND
    - หรือใช้สายจั้มต่อ PA1 กับจุดแบ่งแรงดันใด ๆ
MCU Pin→อุปกรณ์ขาหมายเหตุ
PA1 (ADC_IN1)←Potentiometer (wiper)ขากลางADC input 0-3.3V
Potentiometer←VCC (3.3V)ขาบน—
Potentiometer→GNDขาล่าง—

🧭 ผังการทำงาน

    A["ADC_SimpleInit()"] --> B["while(1)"]
    B --> C["ADC_Read(ch)"]
    C --> D["ADC_ToVoltage(val, VDD)"]
    D --> E["Print voltage"]
    E --> F["Delay_Ms(500)"]
    F --> B

💻 โค้ด + อธิบายทีละบรรทัด

#define CH32V003_PACKAGE  PACKAGE_TSSOP20
#include <SimpleHAL.h>

int main(void)
{
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);
    ADC_SimpleInit();              // เริ่มต้น ADC 12-bit, Vref = 3.3V

    while(1)
    {
        uint16_t raw = ADC_Read(PA1);        // อ่านค่า raw 0-4095
        float voltage = ToVoltage(raw);      // แปลง raw → แรงดันจริง (V)
        USART_Print("Raw: ");
        USART_PrintNum(raw);
        USART_Print("  Voltage: ");
        USART_PrintFloat(voltage, 3);
        USART_Print(" V\r\n");
        Delay_Ms(500);
    }
}
  • ADC_SimpleInit(): กำหนด clock ADC = 6MHz, sample time = 7.5 cycles, continuous conversion mode — พร้อมใช้งานทันที
  • ADC_Read(pin): เลือก channel ตาม pin → เริ่ม conversion → รอจนเสร็จ → คืนค่า 12-bit (0-4095)
  • ToVoltage(raw): raw × (Vref / 4095) — Vref ปกติ = 3.3V (AVCC) — ใช้ ADC_GetVref() ดึงค่า Vref จริง

⚠️ จุดควรระวัง

  • ADC pin ต้องเป็น input เท่านั้น — ห้ามตั้งเป็น output ก่อน ADC_Read
  • แรงดัน input ต้องไม่เกิน AVCC (3.3V) — ถ้าเกินต้องใช้ voltage divider
  • ADC ความละเอียด 12-bit — 1 LSB = 3.3V / 4095 ≈ 0.8mV

✅ ตรวจสอบก่อนรัน

  • PA1 ต่อกับสัญญาณ analog ที่ต้องการวัดหรือยัง?
  • GND ของสัญญาณต่อร่วมกับ GND ของ MCU?
  • สายสัญญาณไม่ยาวเกินไป? (>10cm อาจมี noise ใส่ capacitor 0.1µF)

ex02_MultiChannel_Average — อ่านหลาย Channel + ค่าเฉลี่ย

📖 แนวคิด

อ่าน ADC จากหลายช่องสัญญาณ (PA1, PC4, PD6) — แต่ละ channel อ่านซ้ำ 16 ครั้งแล้วหาค่าเฉลี่ยด้วย ReadMultiple — แสดงผลเป็นเปอร์เซ็นต์ด้วย ToPercent — ใช้เทคนิค mitigate noise

🔌 วงจร

    PA1 ---- Potentiometer 1 (10kΩ)
    PC4 ---- Potentiometer 2 (10kΩ)
    PD6 ---- LDR + 10kΩ pull-down
MCU Pin→อุปกรณ์ขาหมายเหตุ
PA1 (ADC_IN1)←Potentiometer 1 (wiper)ขากลาง10kΩ
PC4 (ADC_IN4)←Potentiometer 2 (wiper)ขากลาง10kΩ
PD6 (ADC_IN6)←LDR + R 10kΩ (pull-down)—Voltage divider
Pot 1/2←VCC (3.3V)ขาบน—
Pot 1/2→GNDขาล่าง—
LDR←3.3V——
R 10kΩ→GND—Pull-down

    A["ADC_SimpleInit()"] --> B["while(1)"]
    B --> C["ADC_ReadMultiple(3ch)"]
    C --> D["ADC_ToPercent(val)"]
    D --> E["Print values %"]
    E --> F["Delay_Ms(500)"]
    F --> B

💻 โค้ด

#define CH32V003_PACKAGE  PACKAGE_TSSOP20
#include <SimpleHAL.h>

uint8_t adc_pins[] = {PA1, PC4, PD6};
#define NUM_CH  3

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);
    ADC_SimpleInit();

    while(1) {
        for(uint8_t i = 0; i < NUM_CH; i++) {
            uint16_t avg = ReadMultiple(adc_pins[i], 16);  // อ่าน 16 ครั้ง → ค่าเฉลี่ย
            uint8_t pct = ToPercent(avg);                  // 0-4095 → 0-100%
            USART_Print("CH");
            USART_PrintNum(i + 1);
            USART_Print(": ");
            USART_PrintNum(avg);
            USART_Print(" (");
            USART_PrintNum(pct);
            USART_Print("%)\r\n");
        }
        USART_Print("---\r\n");
        Delay_Ms(500);
        IWDG_Feed();
    }
}
  • ReadMultiple(pin, samples): อ่าน ADC ซ้ำ samples ครั้ง — ตัดค่าสูงสุด/ต่ำสุดออก — คืนค่าเฉลี่ย — ช่วยลด noise จากสัญญาณ
  • ToPercent(raw): raw × 100 / 4095 — คืนค่า 0-100% เหมาะกับ sensor analog เช่น LDR, pot, temp sensor

⚠️ จุดควรระวัง

  • ADC channel เปลี่ยนแต่ละครั้งต้องรอ sample time — ReadMultiple จัดการให้อัตโนมัติ
  • สัญญาณ noise สูง → เพิ่มจำนวน samples (32, 64) → แต่ใช้เวลานานขึ้น
  • ToPercent เหมาะกับ Vref เดียวกัน — ถ้า Vref เปลี่ยน ค่า % ก็เปลี่ยนตาม

ex03_Battery_Monitor — มอนิเตอร์แบตเตอรี่

📖 แนวคิด

วัดแรงดันแบตเตอรี่ Li-Po ผ่าน voltage divider (2:1) — ใช้ ADC_GetVDD อ่าน Vref จริงจาก internal reference 1.2V (Vrefint) — คำนวณหาระดับแบตเตอรี่ด้วย GetBatteryPercent

🔌 วงจร

    Li-Po 4.2V           CH32V003
      + ----[ 2kΩ ]----+---- PC4 (ADC_IN4)
                       └----[ 1kΩ ]---- GND
    Voltage divider: Vout = Vin × 1k / (2k + 1k) = Vin / 3
    (4.2V → 1.4V, 3.7V → 1.23V, 3.0V → 1.0V)
MCU Pin→อุปกรณ์ขาหมายเหตุ
Li-Po (+)→R 2kΩ—Voltage divider top
R 2kΩ→PC4 (ADC_IN4)—จุดแบ่งแรงดัน
PC4→R 1kΩ → GND—Divider bottom
Li-Po (-)↔GND—Common ground

🧭 ผังการทำงาน

flowchart TD
    A["ADC_SimpleInit()"] --> B["while(1)"]
    B --> C["ADC_GetVDD()"]
    C --> D["ADC_Read(BAT_PIN)"]
    D --> E["voltage = ToVoltage(raw) × DIVIDER_RATIO"]
    E --> F["GetBatteryPercent(raw, ratio)"]
    F --> G["Print VDD, Vbat, %"]
    G --> H["Delay_Ms(1000)"]
    H --> B

💻 โค้ด

#define CH32V003_PACKAGE  PACKAGE_TSSOP20
#include <SimpleHAL.h>

#define BAT_PIN        PC4
#define DIVIDER_RATIO  3.0f    // R1+R2 / R2 = (2+1)/1

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);
    ADC_SimpleInit();

    while(1) {
        uint16_t vdd_mv = ADC_GetVDD();                      // อ่าน Vrefint → คำนวณ VDD จริง (mV)
        uint16_t raw = ADC_Read(BAT_PIN);
        float vbat = ToVoltage(raw) * DIVIDER_RATIO;         // แรงดันแบตจริง (V)
        uint8_t pct = GetBatteryPercent(raw, DIVIDER_RATIO); // คำนวณ % อัตโนมัติ

        USART_Print("VDD: ");
        USART_PrintNum(vdd_mv);
        USART_Print(" mV  Bat: ");
        USART_PrintFloat(vbat, 2);
        USART_Print(" V (");
        USART_PrintNum(pct);
        USART_Print("%)\r\n");
        Delay_Ms(1000);
        IWDG_Feed();
    }
}
  • ADC_GetVDD(): อ่าน Vrefint (internal 1.2V) → คำนวณ VDD จริงแบบย้อนกลับ — แก้ปัญหา Vref เพี้ยนจากแหล่งจ่าย
  • GetBatteryPercent(raw, ratio): คำนวณ % ตาม curve ของ Li-Po (4.2V=100%, 3.0V=0%) — รับ raw + ratio divider
  • voltage divider: ลดแรงดัน 4.2V → 1.4V (ไม่เกิน AVCC) — เลือก R ให้กระแสไหลน้อย (≈ 1-2mA)

⚠️ จุดควรระวัง

  • แรงดันแบตเตอรี่สูงสุดห้ามเกิน AVCC (3.3V) ที่ขา MCU — ต้องใช้ voltage divider เสมอ!
  • R divider มีผลต่อ precision — tolerance 1% ดีกว่า 5% — ค่า Divider_RATIO ต้องตรงกับ R จริง
  • Li-Po 3.0V = cutoff — ถ้าต่ำกว่านี้ battery management ควรตัดวงจร

ex04_Compensated_Read — อ่านค่าแบบชดเชย Vref

📖 แนวคิด

ใช้ ReadVrefInt อ่านค่า Vrefint (internal 1.2V) เพื่อคำนวณ Vref จริง — จากนั้นใช้ ReadVoltageCompensated อ่านแรงดันแบบชดเชย — ให้ค่าถูกต้องแม้ VDD เปลี่ยนแปลง เช่น จากแบตเตอรี่

🧭 ผังการทำงาน

flowchart TD
    A["ADC_SimpleInit()"] --> B["while(1)"]
    B --> C["ReadVrefInt()"]
    C --> D["actual_vref = 1.2 × 4095 / vrefint_raw"]
    D --> E["ReadVoltageCompensated(PA1)"]
    E --> F["Print Vrefint + Vcomp"]
    F --> G["Delay_Ms(500)"]
    G --> B

💻 โค้ด

#define CH32V003_PACKAGE  PACKAGE_TSSOP20
#include <SimpleHAL.h>

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);
    ADC_SimpleInit();

    while(1) {
        uint16_t vrefint_raw = ReadVrefInt();                     // อ่าน raw ของ Vrefint (คาด ~1480)
        float actual_vref = 1.2f * 4095.0f / (float)vrefint_raw;  // คำนวณ Vref จริง (V)

        float v_comp = ReadVoltageCompensated(PA1);               // อ่าน voltage ชดเชยแล้ว (V)

        USART_Print("Vrefint raw: ");
        USART_PrintNum(vrefint_raw);
        USART_Print("  Actual Vref: ");
        USART_PrintFloat(actual_vref, 3);
        USART_Print(" V  PA1: ");
        USART_PrintFloat(v_comp, 3);
        USART_Print(" V\r\n");
        Delay_Ms(500);
        IWDG_Feed();
    }
}
  • ReadVrefInt(): อ่าน channel Vrefint ภายใน — ค่า raw ประมาณ 1480 (เมื่อ VDD=3.3V) — ใช้ calibrate Vref
  • ReadVoltageCompensated(pin): อ่าน ADC + ชดเชยด้วย Vrefint จริง — ได้แรงดันที่แม่นยำโดยไม่ต้อง calibrate ล่วงหน้า
  • actual_vref = 1.2 × 4095 / vrefint_raw: ถ้า vrefint_raw = 1500 → actual_vref = 3.276V (ต่างจาก 3.3V ~0.7%)

⚠️ จุดควรระวัง

  • Vrefint ต้องอ่านค่าเฉลี่ยหลายครั้ง (ReadMultiple) เพื่อความแม่นยำ — ตัวอย่างอย่างน้อย 16 ครั้ง
  • Vrefint คงที่ในอุณหภูมิคงที่ — ถ้าอุณหภูมิเปลี่ยน ค่า drift ~0.01%/°C
  • ReadVoltageCompensated ใช้เวลามากกว่า ADC_Read ปกติเล็กน้อยเพราะต้องอ่าน Vrefint ด้วย

ex05_DMA_Continuous_ADC — ADC ต่อเนื่องด้วย DMA

📖 แนวคิด

ใช้ DMA (Direct Memory Access) อ่าน ADC แบบต่อเนื่องโดยไม่ต้อง CPU interrupt — ใช้ DMA_analogReadStart เริ่ม DMA และ DMA_analogReadAverage อ่านค่าเฉลี่ยจาก buffer — ลดภาระ CPU สูงสุด

🧭 ผังการทำงาน

flowchart TD
    A["ADC_SimpleInit()"] --> B["DMA_analogReadStart(pin, buf)"]
    B --> C["while(1)"]
    C --> D["DMA_analogReadAverage()"]
    D --> E["ToVoltage(avg)"]
    E --> F["Print voltage"]
    F --> G["Delay_Ms(100)"]
    G --> C

💻 โค้ด

#define CH32V003_PACKAGE  PACKAGE_TSSOP20
#include <SimpleHAL.h>

#define ADC_PIN     PA1
#define SAMPLE_BUF  64      // 64 samples ใน DMA buffer

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);
    ADC_SimpleInit();

    DMA_analogReadStart(ADC_PIN, SAMPLE_BUF);   // เริ่ม DMA — ADC อ่านต่อเนื่อง 64 samples loop

    while(1) {
        uint16_t avg = DMA_analogReadAverage();   // อ่านค่าเฉลี่ยจาก DMA buffer ล่าสุด
        float v = ToVoltage(avg);
        USART_Print("DMA Avg: ");
        USART_PrintNum(avg);
        USART_Print("  ");
        USART_PrintFloat(v, 3);
        USART_Print(" V\r\n");
        Delay_Ms(100);
        IWDG_Feed();
    }
}
  • DMA_analogReadStart(pin, bufSize): ตั้งค่า ADC continuous mode + DMA circular buffer — ADC ทำงานตลอดเวลาไม่ต้อง CPU สั่ง
  • DMA_analogReadAverage(): อ่านค่าเฉลี่ยของ buffer ปัจจุบัน — DMA อัปเดต buffer ต่อเนื่อง — CPU แค่ดึงค่า
  • ข้อดี: ADC อ่าน 64 samples / วน loop — CPU ไม่เสียเวลารอ — ใช้กับ sensor ที่ต้องการอ่านถี่ ๆ

⚠️ จุดควรระวัง

  • DMA ใช้ buffer ใน RAM — bufSize ยิ่งมากยิ่งแม่นยำแต่ใช้ RAM มากขึ้น (64 sample × 2 byte = 128 bytes)
  • ห้ามเปลี่ยน pin ขณะ DMA ทำงาน — ต้อง DMA_analogReadStop() ก่อนเปลี่ยน
  • DMA และ ADC ใช้ clock เดียวกัน — ถ้า ADC clock เปลี่ยน DMA ก็เปลี่ยนตาม

ex06_Voltage_Average — ค่าแรงดันเฉลี่ยแบบปรับได้

📖 แนวคิด

ใช้ ReadVoltage อ่านแรงดันเป็น float โดยตรง — และ ReadAverage ที่ให้ปรับจำนวน samples ได้ — เหมาะกับงานที่ต้องการสมดุลระหว่างความเร็วและความแม่นยำ

🧭 ผังการทำงาน

flowchart TD
    A["ADC_SimpleInit()"] --> B["while(1)"]
    B --> C["ReadVoltage(PA1, 1)"]
    C --> D["ReadVoltage(PA1, 4)"]
    D --> E["ReadAverage(PA1, 64)"]
    E --> F["Print Fast, Avg4, Avg64"]
    F --> G["Delay_Ms(200)"]
    G --> B

💻 โค้ด

#define CH32V003_PACKAGE  PACKAGE_TSSOP20
#include <SimpleHAL.h>

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);
    ADC_SimpleInit();

    while(1) {
        float v_fast = ReadVoltage(PA1, 1);      // อ่าน 1 ครั้ง — เร็วที่สุด (~12µs)
        float v_avg4 = ReadVoltage(PA1, 4);      // อ่าน 4 ครั้งเฉลี่ย — เร็วพอควร
        float v_avg64 = ReadAverage(PA1, 64);    // อ่าน 64 ครั้งเฉลี่ย — แม่นยำที่สุด

        USART_Print("Fast: ");
        USART_PrintFloat(v_fast, 3);
        USART_Print("  Avg4: ");
        USART_PrintFloat(v_avg4, 3);
        USART_Print("  Avg64: ");
        USART_PrintFloat(v_avg64, 3);
        USART_Print(" V\r\n");
        Delay_Ms(200);
        IWDG_Feed();
    }
}
  • ReadVoltage(pin, samples): อ่าน ADC + คำนวณแรงดัน (V) — samples = 1-255 — คืน float
  • ReadAverage(pin, samples): อ่านและเฉลี่ย samples ครั้ง — ตัด outlier — คืน float
  • Trade-off: 1 sample ≈ 12µs (ADC clock 6MHz) → 64 samples ≈ 768µs + average time

⚠️ จุดควรระวัง

  • ยิ่ง samples มาก → กัน noise ได้ดีขึ้น → แต่ใช้เวลาและกระแสไฟมากขึ้น
  • อ่าน 1 sample อาจมี noise ±3 LSB — อ่าน 64 samples ลดเหลือ ±1 LSB
  • ถ้าต้องการ non-blocking ให้ใช้ DMA_analogReadStart แทน — ReadVoltage เป็น blocking
