Button — ปุ่มกด Debounce

ระดับเริ่มต้น

🧭 แผนภาพการทำงาน

flowchart TD

    B --> C["Button_Update(&btn) in loop"]

🔌 การต่อวงจร

     ปุ่มกด 1 ปุ่ม (Active LOW)
┌────────────────────────────────┐
│ MCU                     CH32V003│
│ PC1 ─── Button ─── GND         │
│                                │
│ ใช้ internal pull-up (~40kΩ)   │
│ กด = LOW (0), ปล่อย = HIGH (1) │
│ ACTIVE_HIGH: Button ─── VCC    │
│ แล้วใช้ internal pull-down     │
└────────────────────────────────┘

ขา PC1 ต่อกับปุ่มกดที่ต่อลง GND — เมื่อกดจะอ่านค่าเป็น 0 (ACTIVE_LOW) ใช้ตัวต้านทาน pull-up ภายใน MCU ไม่ต้องต่อ R ภายนอก

📚 หลักการทำงาน

Debounce: หน้าสัมผัสทางกลของปุ่มกดจะกระเด้ง (bounce) ประมาณ 5-20ms เมื่อกดหรือปล่อย — ต้องใช้ซอฟต์แวร์กรองสัญญาณรบกวนนี้ ค่า default 50ms ครอบคลุมเกือบทุกปุ่ม

Callback-based: แทนที่จะเช็ค digitalRead() เอง ผู้ใช้ลงทะเบียน callback function — เมื่อเหตุการณ์เกิดขึ้น (กด/กดค้าง/ดับเบิลคลิก) ฟังก์ชันจะถูกเรียกอัตโนมัติ

Long Press Threshold: กำหนดเวลาที่ถือว่า "กดค้าง" — default 1000ms — เหมาะสำหรับ secondary action เช่น long=select, short=next

Double Click Window: กรอบเวลาสำหรับการกด 2 ครั้งติดกัน — default 400ms — ถ้ากดครั้งที่ 2 ภายใน window จะนับเป็นดับเบิลคลิกแทนการกดเดี่ยว 2 ครั้ง

ต้องเรียก Update() ใน loop: State machine จะไม่ทำงานถ้าไม่เรียก Button_Update(&btn) เป็นประจำใน main loop — ไม่สามารถใช้ใน ISR ได้เพราะใช้ Delay_Ms() ภายใน

ISR-safe (indirect): ถ้าต้องการตรวจจับจาก ISR ให้ใช้ Button_DebounceISR() variant ซึ่งไม่ใช้ delay — หรือใช้ GPIO interrupt แล้ว set flag ให้ main loop อ่าน

💻 เขียน Code ทีละขั้น

ขั้นที่ 1: Init + ตั้งค่า Callbacks

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "Button.h"

Button_Handle btn;

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    USART_Init(115200);

    Button_Init(&btn, PC1, BUTTON_ACTIVE_LOW, 50);
    Button_SetCallback(&btn, on_press);
    Button_SetAdvancedCallback(&btn, on_long, 1000);
    Button_OnDoubleClick(&btn, on_double, 400);
    USART_Println("Button Ready!");

🔍 Button_Init(&btn, pin, mode, debounce_ms) — mode เป็น BUTTON_ACTIVE_LOW (ปุ่มต่อ GND) หรือ BUTTON_ACTIVE_HIGH (ปุ่มต่อ VCC) debounce 50ms คือค่ามาตรฐานที่ใช้ได้กับปุ่มทั่วไป

ขั้นที่ 2: สร้าง Callback Functions

void on_press(void) {
    USART_Println("Pressed!");
}
void on_long(void) {
    USART_Println("Long Press 1s!");
}
void on_double(void) {
    USART_Println("Double Click!");
}

🔍 Callback ทั้ง 3 ตัวแยกกันอิสระ — on_press เรียกเมื่อกดสั้น, on_long เรียกเมื่อกดค้างเกิน 1000ms, on_double เรียกเมื่อกด 2 ครั้งภายใน 400ms — แต่ละ callback รับ void ไม่มี parameter

ขั้นที่ 3: Loop + Update

    while(1) {
        Button_Update(&btn);
        IWDG_Feed();
    }
}

🔍 Button_Update(&btn) ต้องถูกเรียกทุก loop iteration — ตัว state machine ภายในจะเช็คเวลาที่ผ่านไปและสถานะขา GPIO เพื่อตัดสินใจว่าเหตุการณ์ไหนเกิดขึ้น — IWDG_Feed() เลี้ยง watchdog กันลืม

📋 API Reference

ฟังก์ชันคำอธิบายตัวอย่าง
Button_Init(&btn, pin, mode, ms)เริ่มต้นปุ่ม — mode=ACTIVE_LOW/ACTIVE_HIGH, debounce=20-100msButton_Init(&btn, PC1, BUTTON_ACTIVE_LOW, 50)
Button_SetCallback(&btn, cb)ตั้ง callback เมื่อกดสั้น (ปล่อยภายใน threshold)Button_SetCallback(&btn, on_press)
Button_SetAdvancedCallback(&btn, cb, ms)ตั้ง callback เมื่อกดค้างเกิน ms (default 1000)Button_SetAdvancedCallback(&btn, on_long, 1000)
Button_OnDoubleClick(&btn, cb, ms)ตั้ง callback เมื่อดับเบิลคลิกภายใน window msButton_OnDoubleClick(&btn, on_double, 400)
Button_Update(&btn)อัปเดต state machine — ต้องเรียกใน loopwhile(1){Button_Update(&btn);}
Button_IsPressed(&btn)เช็คสถานะปัจจุบัน — true=กดอยู่if(Button_IsPressed(&btn)){...}
Button_GetPressCount(&btn)อ่านจำนวนครั้งที่กดสะสม (เคลียร์ได้)uint16_t n = Button_GetPressCount(&btn)

⚠️ ข้อผิดพลาดที่พบบ่อย

ปัญหาสาเหตุวิธีแก้
กด 1 ครั้ง แต่ callback ทำงาน 2-3 รอบDebounce น้อยเกินไป (เช่น 10ms)เพิ่ม debounce เป็น 50-80ms — ปุ่มโลหะอาจต้อง 80ms
Long Press ไม่เคยถูกเรียกลืมตั้ง Button_OnLongPress() หรือ threshold สั้นไปเพิ่ม Button_SetAdvancedCallback(&btn, cb, 1000) และเช็คค่า threshold ≥ 500ms
Callback ไม่ทำงานเลยลืม Button_Update(&btn) ใน while(1)เพิ่มใน main loop ทุกรอบ — state machine ต้องถูกเรียกจึงจะทำงาน
Active High/Low กลับด้านตั้ง mode ไม่ตรงกับวงจร — ACTIVE_LOW แต่ต่อปุ่มเข้า VCCเช็ควงจร: ACTIVE_LOW → ปุ่มต่อ GND, ACTIVE_HIGH → ปุ่มต่อ VCC
Double Click ไม่ติดWindow แคบเกิน หรือกดไม่ทันเพิ่ม window เป็น 400-600ms — double click ต้องกด 2 ครั้งเร็ว
โปรแกรมค้างตอนเรียกใน ISRButton_Update() ใช้ Delay — ห้ามใช้ใน ISRย้ายมา main loop — ใช้ GPIO interrupt set flag แล้ว main loop อ่าน flag

🛠️ สร้าง Product: Single-button Menu

1 ปุ่ม 3 ท่า: กดสั้น=เลือกเมนูถัดไป, กดค้าง=ยืนยันเลือก, ดับเบิลคลิก=ย้อนกลับ — แสดงผลทาง USART

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "Button.h"

Button_Handle btn;
uint8_t menu_idx = 0;
const char* menu[] = {"LED ON", "LED OFF", "BLINK", "EXIT"};

void on_press(void) {
    menu_idx = (menu_idx + 1) % 4;
    USART_Print("> "); USART_Println(menu[menu_idx]);
}
void on_long(void) {
    USART_Print("SELECT: "); USART_Println(menu[menu_idx]);
    if(menu_idx == 0) pinMode(PC0, PIN_MODE_OUTPUT); digitalWrite(PC0, HIGH);
    if(menu_idx == 1) digitalWrite(PC0, LOW);
    if(menu_idx == 3) USART_Println("Goodbye!");
}
void on_double(void) {
    menu_idx = (menu_idx == 0) ? 3 : menu_idx - 1;
    USART_Print("BACK> "); USART_Println(menu[menu_idx]);
}

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    USART_Init(115200);
    Button_Init(&btn, PC1, BUTTON_ACTIVE_LOW, 50);
    Button_SetCallback(&btn, on_press);
    Button_SetAdvancedCallback(&btn, on_long, 1000);
    Button_OnDoubleClick(&btn, on_double, 400);
    USART_Println("=== Single-Button Menu ===");
    USART_Println(menu[0]);
    while(1) { Button_Update(&btn); IWDG_Feed(); }
}

✏️ ลองทำดู

  1. ตัวนับ Double-Click — นับจำนวนครั้งที่ดับเบิลคลิก แสดงผลผ่าน USART ทุกครั้งที่กด
  2. Hold-to-Dim LED — กดค้างเพื่อลด brightness ของ LED (PWM) ทีละ 10% ทุก 200ms — ใช้ Button_IsPressed() เช็คใน callback
  3. Combo Lock Sequence — ต้องกด sequence เช่น สั้น-สั้น-ยาว ให้ถูกต้องถึงปลดล็อก LED — ใช้ตัวแปรนับ state และ Button_GetPressCount()
