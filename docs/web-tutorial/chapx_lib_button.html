🔌 การต่อวงจร

     ปุ่มกด 1 ปุ่ม (Active LOW)
┌────────────────────────────────┐
│ MCU                     CH32V003│
│ PC1 ─── Button ─── GND         │
│                                │
│ ใช้ internal pull-up (~40kΩ)   │
│ กด = LOW (0), ปล่อย = HIGH (1) │
│ ACTIVE_HIGH: Button ─── VCC    │
└────────────────────────────────┘
MCU Pin→อุปกรณ์ขาหมายเหตุ
PC1→ปุ่มกดขา 1ขา 2 → GND
GND→ปุ่มกดขา 2ผ่านตัวปุ่ม

ขา PC1 ต่อกับปุ่มกดที่ต่อลง GND — เมื่อกดจะอ่านค่าเป็น 0 (BUTTON_ACTIVE_LOW) ใช้ตัวต้านทาน pull-up ภายใน MCU ไม่ต้องต่อ R ภายนอก

รู้จักขา

  • ขา 1 ของปุ่ม: ต่อกับ PC1 (อินพุตพร้อม pull-up ในตัว)
  • ขา 2 ของปุ่ม: ต่อกับ GND

วิธีต่อทีละขั้น

  1. ต่อ PC1 ไป ขา 1 ของปุ่ม — ขาสัญญาณ
  2. ต่อ ขา 2 ของปุ่ม ไป GND — เมื่อกดจะดึง PC1 ลง LOW
  3. ใช้ internal pull-up — ไม่ต้องต่อ R ภายนอก (MCU ตั้งค่าภายใน)

📚 หลักการทำงาน

Debounce: หน้าสัมผัสทางกลของปุ่มกดจะกระเด้ง (bounce) ประมาณ 5-20ms เมื่อกดหรือปล่อย — ตั้งค่าด้วย Button_SetDebounce(&btn, 50)

Button_Instance: ใช้ struct instance — Button_Init(&btn, pin, mode) — ตามด้วย Button_SetDebounce(&btn, ms) แยกต่างหาก — ไม่มี debounce ใน Init

Callback-based: ลงทะเบียน callback พร้อม event type — Button_SetCallback(&btn, BUTTON_EVENT_PRESS, my_callback) — callback รับ Button_Instance* b

Advanced Callback: Button_SetAdvancedCallback(&btn, BUTTON_EVENT_LONG_PRESS, cb, 1000) — พารามิเตอร์สุดท้ายคือ threshold ms

ต้องเรียก Update() ใน loop: State machine จะไม่ทำงานถ้าไม่เรียก Button_Update(&btn) เป็นประจำใน main loop

💻 เขียน Code ทีละขั้น

ขั้นที่ 1: Init + ตั้งค่า Callbacks

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "Button.h"

Button_Instance btn;

void on_press(Button_Instance* b) {
    USART_Println("Pressed!");
}
void on_long(Button_Instance* b) {
    USART_Println("Long Press 1s!");
}
void on_double(Button_Instance* b) {
    USART_Println("Double Click!");
}

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    USART_Init(115200);

    Button_Init(&btn, PC1, BUTTON_ACTIVE_LOW);
    Button_SetDebounce(&btn, 50);
    Button_SetCallback(&btn, BUTTON_EVENT_PRESS, on_press);
    Button_SetAdvancedCallback(&btn, BUTTON_EVENT_LONG_PRESS, on_long, 1000);
    Button_SetAdvancedCallback(&btn, BUTTON_EVENT_DOUBLE_CLICK, on_double, 400);
    USART_Println("Button Ready!");

🔍 Button_Init(&btn, pin, mode) — mode: BUTTON_ACTIVE_LOW / BUTTON_ACTIVE_HIGH — Button_SetDebounce() ตั้ง debounce แยก — Button_SetCallback() ใช้ event type — callback รับ Button_Instance* b

ขั้นที่ 2: Loop + Update

    while(1) {
        Button_Update(&btn);
        IWDG_Feed();
    }
}

🔍 Button_Update(&btn) ต้องถูกเรียกทุก loop iteration — state machine ภายในจะเช็คเวลาและสถานะ GPIO เพื่อเรียก callback — IWDG_Feed() เลี้ยง watchdog

📋 API Reference

ฟังก์ชันคำอธิบายตัวอย่าง
Button_Init(&btn, pin, mode)เริ่มต้นปุ่ม — mode=ACTIVE_LOW/ACTIVE_HIGHButton_Init(&btn, PC1, BUTTON_ACTIVE_LOW)
Button_SetDebounce(&btn, ms)ตั้งค่า debounce (ms) — default 50Button_SetDebounce(&btn, 50)
Button_SetCallback(&btn, event, cb)ตั้ง callback — event: BUTTON_EVENT_PRESSButton_SetCallback(&btn, BUTTON_EVENT_PRESS, cb)
Button_SetAdvancedCallback(&btn, event, cb, ms)ตั้ง callback สำหรับ LONG_PRESS/DOUBLE_CLICKButton_SetAdvancedCallback(&btn, BUTTON_EVENT_LONG_PRESS, cb, 1000)
Button_Update(&btn)อัปเดต state machine — ต้องเรียกใน loopwhile(1){Button_Update(&btn);}

⚠️ ข้อผิดพลาดที่พบบ่อย

ปัญหาสาเหตุวิธีแก้
กด 1 ครั้ง แต่ callback ทำงาน 2-3 รอบDebounce น้อยเกินไปเพิ่ม debounce เป็น 50-80ms
Long Press ไม่เคยถูกเรียกลืมตั้ง callback หรือ threshold สั้นไปใช้ Button_SetAdvancedCallback(&btn, BUTTON_EVENT_LONG_PRESS, cb, 1000)
Callback ไม่ทำงานเลยลืม Button_Update(&btn) ใน while(1)เพิ่มใน main loop ทุกรอบ
Active High/Low กลับด้านตั้ง mode ไม่ตรงกับวงจรBUTTON_ACTIVE_LOW → ปุ่มต่อ GND, BUTTON_ACTIVE_HIGH → ปุ่มต่อ VCC
โปรแกรมค้างตอนเรียกใน ISRButton_Update() ใช้ Delay — ห้ามใช้ใน ISRย้ายมา main loop — ใช้ GPIO interrupt set flag

🛠️ สร้าง Product: Single-button Menu

1 ปุ่ม 3 ท่า: กดสั้น=เลือกเมนู, กดค้าง=ยืนยัน, ดับเบิลคลิก=ย้อนกลับ

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "Button.h"

Button_Instance btn;
uint8_t menu_idx = 0;
const char* menu[] = {"LED ON", "LED OFF", "BLINK", "EXIT"};

void on_press(Button_Instance* b) {
    menu_idx = (menu_idx + 1) % 4;
    USART_Print("> "); USART_Println(menu[menu_idx]);
}
void on_long(Button_Instance* b) {
    USART_Print("SELECT: "); USART_Println(menu[menu_idx]);
    if(menu_idx == 0) { pinMode(PC0, PIN_MODE_OUTPUT); digitalWrite(PC0, HIGH); }
    if(menu_idx == 1) digitalWrite(PC0, LOW);
    if(menu_idx == 3) USART_Println("Goodbye!");
}
void on_double(Button_Instance* b) {
    menu_idx = (menu_idx == 0) ? 3 : menu_idx - 1;
    USART_Print("BACK> "); USART_Println(menu[menu_idx]);
}

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    USART_Init(115200);
    Button_Init(&btn, PC1, BUTTON_ACTIVE_LOW);
    Button_SetDebounce(&btn, 50);
    Button_SetCallback(&btn, BUTTON_EVENT_PRESS, on_press);
    Button_SetAdvancedCallback(&btn, BUTTON_EVENT_LONG_PRESS, on_long, 1000);
    Button_SetAdvancedCallback(&btn, BUTTON_EVENT_DOUBLE_CLICK, on_double, 400);
    USART_Println("=== Single-Button Menu ===");
    USART_Println(menu[0]);
    while(1) { Button_Update(&btn); IWDG_Feed(); }
}
