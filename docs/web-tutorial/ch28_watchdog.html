ex01_IWDG_Simple — ตั้งค่า IWDG + Feed พื้นฐาน

📖 แนวคิด

Independent Watchdog (IWDG) ใช้ clock แยก 40kHz ในตัว — ไม่ขึ้นกับ main clock — รีเซ็ต MCU ถ้าไม่ Feed ทันเวลา ตั้งค่า prescaler + reload ง่าย ๆ ด้วยฟังก์ชัน IWDG_SimpleInit

🧭 ผังการทำงาน

flowchart TD
    A["IWDG_SimpleInit(4000)"] --> B["count = 0"]
    B --> C["while(1)"]
    C --> D["count++"]
    D --> E{"count < 3?"}
    E -->|"Yes"| F["IWDG_Feed()"]
    F --> C
    E -->|"No"| G["⚠ รอ IWDG Reset"]
    G --> G

💻 โค้ด + อธิบายทีละบรรทัด

#define CH32V003_PACKAGE  PACKAGE_TSSOP20
#include <SimpleHAL.h>

int main(void)
{
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);

    IWDG_SimpleInit();               // ใช้ค่าเริ่มต้น: prescaler=4, reload=0xFFF → timeout ~1.6s
    USART_Print("IWDG Ready — Feeding every 500ms\r\n");

    while(1)
    {
        USART_Print("Alive!\r\n");
        IWDG_Feed();                 // รีเซ็ต counter IWDG — ต้องเรียกก่อน timeout
        Delay_Ms(500);
    }
}
  • IWDG_SimpleInit(): เปิด IWDG ด้วย prescaler=4 (LSI/4 = 10kHz), reload=0xFFF → timeout = (reload+1)/10kHz ≈ 1.6s
  • IWDG_Feed(): เขียนค่า 0xAAAA ลง IWDG_KR เพื่อ reload counter — ถ้าไม่เรียกก่อน timeout → MCU รีเซ็ต
  • Delay_Ms(500): feed ทุก 500ms ซึ่งน้อยกว่า 1.6s — ถ้า delay > 1.6s โดยไม่ feed จะเกิด watchdog reset

⚠️ จุดควรระวัง

  • IWDG เปิดแล้วปิดไม่ได้ (ยกเว้น reset) — ตั้งค่าผิดต้องกด reset
  • ใน debug mode IWDG ยังทำงาน — จะรีเซ็ตขณะ debug ถ้าไม่ feed
  • IWDG_SimpleInit เปิด LSI oscillator — รอ LSI stable ~2ms ก่อนเริ่มนับ

✅ ตรวจสอบก่อนรัน

  • ถ้า MCU รีเซ็ตวน loop → IWDG ทำงาน — ดูจาก USART ที่พิมพ์ซ้ำ ๆ
  • ลอง comment IWDG_Feed() → MCU ควรรีเซ็ตทุก ~1.6s

ex02_IWDG_Advanced — IWDG กำหนดค่าเอง + ตรวจสอบสาเหตุ Reset

📖 แนวคิด

ปรับ prescaler และ reload register ด้วยตัวเองเพื่อให้ได้ timeout ตามต้องการ — ใช้ WasResetCauseIWDG ตรวจสอบว่าครั้งก่อน reset เพราะ IWDG หรือไม่

🧭 ผังการทำงาน

flowchart TD
    A["WasResetCauseIWDG()?"] -->|"Yes"| B["Print WARN"]
    A -->|"No"| C["IWDG_DisableWriteProtect()"]
    B --> C
    C --> D["IWDG_SetPrescaler(64)"]
    D --> E["IWDG_SetReload(1249)"]
    E --> F["IWDG_ReloadCounter()"]
    F --> G["IWDG_Enable()"]
    G --> H["loop every 900ms"]
    H --> I["IWDG_Feed()"]
    I --> H

💻 โค้ด

#define CH32V003_PACKAGE  PACKAGE_TSSOP20
#include <SimpleHAL.h>

int main(void)
{
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);

    if(WasResetCauseIWDG()) {                    // เช็ค RCC_FLAG_IWDGRST
        USART_Print("[WARN] Previous reset was caused by IWDG!\r\n");
    }

    // prescaler = 64 (LSI/64 = 625Hz), reload = 1249 → timeout = 1250/625 ≈ 2.0s
    IWDG_DisableWriteProtect();                  // เปิดเขียน IWDG registers
    IWDG_SetPrescaler(IWDG_PRESCALER_64);        // 64: /64 → 625Hz
    IWDG_SetReload(1249);                        // reload = 1249
    IWDG_ReloadCounter();                        // โหลดค่า reload
    IWDG_Enable();                               // เปิด IWDG
    USART_Print("IWDG Advanced: timeout ~2s\r\n");

    while(1)
    {
        USART_Print("Feed!\r\n");
        IWDG_Feed();
        Delay_Ms(900);                           // Feed ทุก 900ms
    }
}
  • WasResetCauseIWDG(): อ่าน RCC ว่า IWDG reset flag ค้างอยู่ไหม — ใช้ตอน boot เพื่อแจ้งเตือน
  • IWDG_DisableWriteProtect(): ปลดล็อก IWDG_KR โดยเขียน 0x5555 — ต้องเรียกก่อน SetPrescaler/SetReload
  • IWDG_SetPrescaler / IWDG_SetReload: กำหนด divider (4/8/16/32/64/128/256) และค่า reload 12-bit

⚠️ จุดควรระวัง

  • IWDG_PRESCALER_256 + reload 0xFFF → timeout ~26.2s — นานมาก!
  • IWDG_ReloadCounter() ≠ IWDG_Feed() — reload counter เตรียมค่า, feed คือเขียน 0xAAAA
  • อ่าน RCC reset flag แล้วต้อง clear ด้วยตัวเอง

ex03_WWDG_Simple — Window Watchdog พื้นฐาน

📖 แนวคิด

Window Watchdog (WWDG) ใช้ clock จาก APB (PCLK) — รีเซ็ตเมื่อ counter ต่ำกว่าค่า window หรือ overflow — ต้อง Refresh ก่อนถึง window

🧭 ผังการทำงาน

flowchart TD
    A["WWDG_SimpleInit()"] --> B["counter=0x7F, window=0x50"]
    B --> C["while(1)"]
    C --> D["WWDG_Refresh()"]
    D --> E["Delay_Ms(200)"]
    E --> C

💻 โค้ด

#define CH32V003_PACKAGE  PACKAGE_TSSOP20
#include <SimpleHAL.h>

int main(void)
{
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);

    WWDG_SimpleInit();               // ใช้ค่าเริ่มต้น: counter=0x7F, window=0x50, prescaler=1
    USART_Print("WWDG Ready — Refresh every 200ms\r\n");

    while(1)
    {
        USART_Print("Alive!\r\n");
        WWDG_Refresh();              // รีเฟรช counter WWDG ก่อนถึง window
        Delay_Ms(200);
    }
}
  • WWDG_SimpleInit(): เปิด WWDG ด้วย counter=127, window=80, prescaler=1 (PCLK/4096) → timeout ~5ms-40ms แล้วแต่ PCLK
  • WWDG_Refresh(): โหลด counter กลับไปที่ค่าเริ่มต้น — ต้องเรียกเมื่อ counter > window เท่านั้น
  • WWDG เร็วกว่า IWDG มาก — ใช้กับงานที่ต้องการ timing แม่นยำ

⚠️ จุดควรระวัง

  • WWDG รีเซ็ตเฉพาะเวลาที่ถูกต้อง — ก่อน window หรือหลัง overflow ก็รีเซ็ตทั้งคู่
  • WWDG ทำงานบน PCLK — ถ้า PCLK เปลี่ยน WWDG timing เปลี่ยนตาม
  • WWDG_SimpleInit ใช้ค่าเริ่มต้นอาจ timeout ไวเกินไปสำหรับ main loop ที่ซับซ้อน

ex04_WWDG_Interrupt — WWDG พร้อม Early Wakeup Interrupt

📖 แนวคิด

ใช้ WWDG_SetCallback + WWDG_InitWithInterrupt เพื่อให้ WWDG แจ้งเตือนก่อนรีเซ็ตผ่าน EWI (Early Wakeup Interrupt) — ทำความสะอาดหรือบันทึกข้อมูลก่อน MCU รีเซ็ต

🧭 ผังการทำงาน

flowchart TD
    A["WWDG_SetCallback(EWI_Cb)"] --> B["WWDG_InitWithInterrupt(127,80,1)"]
    B --> C["while(1)"]
    C --> D{"wwdg_warning?"}
    D -->|"Yes"| E["Print warning"]
    D -->|"No"| F["WWDG_Refresh()"]
    E --> F
    F --> G["Delay_Ms(100)"]
    G --> C
    H["EWI Interrupt"] --> I["Toggle PC0\nSet wwdg_warning=1"]

💻 โค้ด

volatile uint32_t wwdg_warning = 0;

void WWDG_EWI_Callback(void) {      // เรียกเมื่อ counter ต่ำกว่า 0x40
    wwdg_warning = 1;
    digitalToggle(PC0);              // สัญญาณเตือน — สลับ LED
}

int main(void)
{
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);
    pinMode(PC0, PIN_MODE_OUTPUT);

    WWDG_SetCallback(WWDG_EWI_Callback);           // ลงทะเบียน callback EWI
    WWDG_InitWithInterrupt(127, 80, WWDG_PRESCALER_1);  // counter, window, prescaler
    USART_Print("WWDG Interrupt Ready\r\n");

    while(1)
    {
        if(wwdg_warning) {
            USART_Print("WWDG warning — about to reset!\r\n");
            wwdg_warning = 0;
        }
        USART_Print("Loop...\r\n");
        WWDG_Refresh();
        Delay_Ms(100);
    }
}
  • WWDG_SetCallback(cb): กำหนดฟังก์ชันที่จะเรียกเมื่อ EWI เกิด (counter ต่ำกว่า 0x40) — เรียกใน ISR context
  • WWDG_InitWithInterrupt: เปิด WWDG พร้อม EWI interrupt — callback ทำงานก่อนรีเซ็ตจริง ~64 clock
  • WWDG_EWI_Callback: ทำงานใน interrupt — สั้น! ใช้ตั้ง flag เท่านั้น

⚠️ จุดควรระวัง

  • WWDG_Refresh ใน callback ไม่ได้ช่วย — WWDG_Refresh ต้องเรียกใน main loop
  • EWI interrupt มี priority สูง — อย่าทำงานหนักใน callback
  • ต้องตั้ง WWDG_SetCallback ก่อน WWDG_InitWithInterrupt เสมอ

ex05_WWDG_Advanced — กำหนด Prescaler และ Window เอง

📖 แนวคิด

ใช้ WWDG_Init ตั้งค่า prescaler (1/2/4/8) และ window register ด้วยตัวเอง — ทำให้ timeout ปรับได้ตามต้องการ — เหมาะกับงานที่ต้องการ timing แน่นอน

🧭 ผังการทำงาน

flowchart TD
    A["WWDG_Init(127,95,PRESCALER_8)"] --> B["timeout ≈ 21.8ms"]
    B --> C["while(1)"]
    C --> D["WWDG_Refresh()"]
    D --> E["Delay_Ms(10)"]
    E --> C

💻 โค้ด

#define CH32V003_PACKAGE  PACKAGE_TSSOP20
#include <SimpleHAL.h>

int main(void)
{
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);

    // Prescaler = 8 → PCLK/4096/8, counter=0x7F, window=0x5F
    // timeout = (counter - window) * (4096 * prescaler) / PCLK
    // ≈ (127-95) * 32768 / 48MHz ≈ 21.8ms
    WWDG_Init(127, 95, WWDG_PRESCALER_8);
    USART_Print("WWDG Advanced: prescaler=8, window=0x5F\r\n");

    while(1)
    {
        USART_Print("Alive!\r\n");
        // ต้อง refresh เมื่อ counter > window (95) — refresh ถี่กว่า 21ms
        WWDG_Refresh();
        Delay_Ms(10);
    }
}
  • WWDG_Init(counter, window, prescaler): counter 6-bit (0-63 จริง ๆ คือ 7-bit 0x3F-0x7F), window = ขอบล่าง, prescaler = /1 /2 /4 /8
  • Refresh timing: ต้องเรียกเมื่อ counter > window — ถ้า counter < window แล้ว refresh → reset
  • Timeout: ((counter - window) + 1) × (4096 × prescaler) / PCLK — ยิ่ง prescaler สูง ยิ่ง timeout นาน

⚠️ จุดควรระวัง

  • WWDG counter ลดลงทุก 4096×prescaler PCLK cycles — ยิ่ง prescaler น้อย ยิ่งไว
  • ห้าม refresh ช้าเกินไป (counter ≤ window) และห้าม refresh เร็วเกินไป (หลัง counter reload รอบก่อน)
  • WWDG กับ IWDG ใช้พร้อมกันได้ — แต่ต้องคำนวณ timing ให้ consistent
