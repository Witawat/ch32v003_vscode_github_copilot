NeoPixel — WS2812B RGB Strip GPIO

ระดับกลาง

🧭 แผนภาพการทำงาน

flowchart TD
    A["NeoPixel_Init(PC0, N)"] --> B["NeoPixel_SetPixel(i, R,G,B)"]
    B --> C["NeoPixel_SetHSV(i, H,S,V)"]
    C --> D["NeoPixel_Show()"]
    D --> E["Disable Interrupts"]
    E --> F["Bit-bang 800kHz NRZ"]
    F --> G["Enable Interrupts"]
    G --> H["while(1): rainbow loop"]
    H --> B

🔌 การต่อวงจร

          WS2812B NeoPixel Strip
    ┌────────────────────────────────┐
    │ MCU                  WS2812B   │
    │ 5V (External PSU) ─── VCC      │
    │ GND ─────────────── GND        │
    │ PC0 ──[LEVEL SHIFT]── DATA     │
    │                                │
    │ ⚠️ ต้องใช้ Level Shifter!      │
    │ 3.3V → 5V (74HCT125/74AHCT125) │
    │ หรือลด VCC WS2812B เหลือ ~4V   │
    └────────────────────────────────┘

WS2812B ต้องการ 5V logic — CH32V003 3.3V ไม่พอ! — ต้องใช้ level shifter (74HCT125) หรือลดแรงดัน VCC ของ WS2812B ลง (เสี่ยง) — ต่อ 5V แยกทุก 50-100 LEDs

📚 หลักการทำงาน

WS2812B Protocol: ใช้ NRZ (Non-Return-to-Zero) ที่ 800kHz — แต่ละ LED รับ 24-bit (G→R→B, 8-bit ต่อสี) — BIT 0: HIGH 0.4µs + LOW 0.85µs, BIT 1: HIGH 0.85µs + LOW 0.4µs — RESET: LOW >50µs — ความแม่นยำระดับนาโนวินาที

Timing Critical: CH32V003 @ 48MHz — instruction ~21ns — ใช้ assembly bit-bang เพื่อความแม่นยำ — ต้องปิด interrupt ทั้งหมดระหว่าง Show() เพราะ interrupt จังหวะเดียวทำให้สีเพี้ยน

GRB Color Order: WS2812B ใช้ GRB (Green-Red-Blue) — ไม่ใช่ RGB มาตรฐาน — NeoPixel_SetPixel(i, r, g, b) จัดการให้แล้ว — SetHSV() ใช้ HSL→RGB conversion

Chain Topology: ข้อมูลส่งเรียงตาม LED — LED[0] → LED[1] → ... → LED[N-1] — LED แต่ละตัวกินข้อมูลของตัวเอง 24-bit แล้วส่งที่เหลือต่อไป — บัฟเฟอร์ต้องมีขนาด N × 24-bit

💻 เขียน Code ทีละขั้น

ขั้นที่ 1: Init + Setup

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"

#define NUM_LEDS 8

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();

    NeoPixel_Init(PC0, NUM_LEDS);   // DATA pin, count
    NeoPixel_SetBrightness(128);    // 0-255 global brightness

🔍 NeoPixel_Init(pin, count) จอง buffer ขนาด count × 3 bytes — SetBrightness() ปรับความสว่างโดยรวม (scale ทุกสี) — ต้องต่อระดับสัญญาณ 5V!

ขั้นที่ 2: ตั้งสี LED แต่ละดวง

    // LED 0 = Red
    NeoPixel_SetPixel(0, 255, 0, 0);
    // LED 1 = Green
    NeoPixel_SetPixel(1, 0, 255, 0);
    // Set all to Blue
    NeoPixel_SetAll(0, 0, 255);
    // LED 2 = HSV (Hue=120=Green)
    NeoPixel_SetHSV(2, 120, 255, 255);

    NeoPixel_Show();  // Send data to strip

🔍 SetPixel(index, R, G, B) ตั้งค่าสีใน buffer — SetAll(R,G,B) ตั้งทุก LED — SetHSV(index, H, S, V) ใช้ Hue 0-360 — ต้องเรียก Show() เพื่อส่งข้อมูล

ขั้นที่ 3: Rainbow Loop

    uint16_t hue = 0;

    while(1) {
        for(uint8_t i = 0; i < NUM_LEDS; i++) {
            uint16_t h = hue + (i * 360 / NUM_LEDS);
            NeoPixel_SetHSV(i, h % 360, 255, 255);
        }
        NeoPixel_Show();
        Delay_Ms(20);
        hue += 2;
    }
}

🔍 Rainbow effect — แต่ละ LED มี hue ต่างกัน 360/N องศา — hue เพิ่มทีละ 2 ทำให้สีหมุนวน — Show() ส่งข้อมูล strip — 20ms delay = ~50fps

⚠️ ข้อผิดพลาดที่พบบ่อย

ปัญหาสาเหตุวิธีแก้
สีเพี้ยน / LED ไม่ติดขาด Level Shifter — WS2812B ต้อง 5V logicใช้ 74HCT125/74AHCT125 level shifter — หรือลด VCC เหลือ 3.7-4.0V (เสี่ยง)
LED ท้ายๆ สีเพี้ยนแรงดันตกในสาย — ต่อ strip ยาวโดยไม่เสริมไฟต่อ 5V เพิ่มทุก 50-100 LEDs — GND ต้องต่อร่วมกันทั้งหมด
LED ติดๆ ดับๆ / กระพริบสุ่มInterrupt ขัดจังหวะตอน Show() — timing เสียShow() จะปิด interrupt อัตโนมัติ — ตรวจสอบว่าใช้ Show() ไม่ใช่เขียนเอง
3.3V Hack — ใช้ได้บ้างไม่ได้บ้างลด VCC เหลือ ~3.7V ให้ 3.3V เป็น HIGH ได้เป็นวิธีที่ไม่แนะนำ — ใช้ level shifter ดีกว่า — WS2812B อาจเสียหาย
LED แรกสีถูก ตัวต่อไปผิดLED เสียหรือบัดกรีไม่ดี — สัญญาณไม่ผ่านเปลี่ยน LED ดวงที่เสีย — ตรวจสอบจุดบัดกรี

🛠️ สร้าง Product: ไฟ RGB แสดงสถานะ 3 โหมด

8 LEDs แสดงสถานะ 3 แบบ — เขียว=ปกติ, แดง=เตือน (Blink), น้ำเงิน=โหมดตั้งค่า — กดปุ่มเปลี่ยนโหมด

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"

#define NUM_LEDS 8
typedef enum { MODE_NORMAL, MODE_WARNING, MODE_SETUP } Mode_t;

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    NeoPixel_Init(PC0, NUM_LEDS);
    NeoPixel_SetBrightness(128);

    pinMode(PC3, PIN_MODE_INPUT_PULLUP); // Button
    Mode_t mode = MODE_NORMAL;
    Timer_t tmr_blink;
    uint8_t blink_state = 0;

    while(1) {
        // Button press → change mode
        if(digitalRead(PC3) == 0) {
            Delay_Ms(50); // debounce
            if(digitalRead(PC3) == 0) {
                mode = (mode + 1) % 3;
                while(digitalRead(PC3) == 0); // wait release
            }
        }

        switch(mode) {
            case MODE_NORMAL:
                NeoPixel_SetAll(0, 255, 0); // Green
                NeoPixel_Show();
                break;

            case MODE_WARNING:
                if(!blink_state) {
                    Start_Timer(&tmr_blink, 500, 1);
                    blink_state = 1;
                }
                if(Is_Timer_Expired(&tmr_blink)) {
                    static uint8_t on = 1;
                    NeoPixel_SetAll(on ? 255 : 0, on ? 0 : 255, 0);
                    NeoPixel_Show();
                    on = !on;
                }
                break;

            case MODE_SETUP:
                NeoPixel_SetAll(0, 0, 255); // Blue
                NeoPixel_Show();
                blink_state = 0;
                break;
        }
        Delay_Ms(10);
    }
}

✏️ ลองทำดู

  1. Rainbow Cycle — ไล่สีรุ้งวน — ปรับความเร็วด้วย Potentiometer อ่าน ADC
  2. Chaser / Marquee — LED วิ่ง 1-3 ดวงพร้อมกัน — ใช้ Non-Blocking Timer เปลี่ยนตำแหน่ง
  3. VU Meter — อ่านเสียงจาก ADC — แปลงเป็นความสูงของ LED — ใช้ SetHSV(hue ตามความดัง)
