🔌 การต่อวงจร

          USB-to-Serial (CH340G / CP2102)
    ┌───────────────────────────────────┐
    │ MCU                          USB  │
    │ PD5 (TX) ──────────────► RX      │──► PC
    │ PD6 (RX) ◄────────────── TX      │
    │ GND ─────────────────── GND      │
    │                                   │
    │ LED: PC0───220Ω──|LED|───GND     │
    └───────────────────────────────────┘

    Pin Configurations:
    DEFAULT  : TX=PD5, RX=PD6  (ทุกแพ็กเกจ)
    REMAP2   : TX=PD6, RX=PD5  (สลับขั้ว — มีประโยชน์มาก!)
    REMAP1   : TX=PD0, RX=PD1  (เฉพาะ TSSOP-20/QFN-20)

CH32V003 มี 1 USART — ใช้ RX/TX แบบ cross-connect: MCU-TX → USB-RX, MCU-RX → USB-TX, GND ต้องต่อร่วมกัน

📚 หลักการทำงาน

USART (Universal Synchronous/Asynchronous Receiver-Transmitter) — การสื่อสารแบบ asynchronous serial ผ่าน 2 สาย (TX+RX)

Baud Rate — ความเร็วในการส่งข้อมูล, 115200 baud = ~115200 bits/วินาที (แนะนำสำหรับ CH32V003)

Frame Format — 8N1 (8 data bits, No parity, 1 stop bit) — เป็นค่า default ที่ใช้กันทั่วไป

SOP-8 note: USART ใช้ได้ทุกแพ็กเกจ — ใช้ PD5/PD6 (default pins) เหมือนกัน

REMAP2 trick: สลับ TX/RX กลับด้าน (TX=PD6, RX=PD5) — มีประโยชน์เมื่อต้องการ cross-connect โดยไม่ต้องสลับสาย

💻 เขียน Code ทีละขั้น

ขั้นที่ 1: Include + Init

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);

🔍 USART_SimpleInit(baud, pins) — บรรทัดเดียวจบ! เปิด Clock, ตั้งค่า GPIO, ตั้ง USART 8N1, เปิดใช้งาน

ขั้นที่ 2: ส่งข้อความ

    USART_Print("Hello from CH32V003!\r\n");
    USART_PrintNum(12345);
    USART_Print(" 0x");
    USART_PrintHex(0xAB, 1);  // uppercase hex

🔍 USART_Print() ส่ง string — USART_PrintNum() ส่งตัวเลข signed 32-bit — USART_PrintHex() ส่งเลขฐาน 16

ขั้นที่ 3: รับข้อมูล

    while(1) {
        if(USART_Available()) {
            uint8_t ch = USART_Read();  // blocking — แต่มีข้อมูลแน่
            USART_WriteByte(ch);         // echo กลับ
        }
    }
}

🔍 ห้ามเรียก USART_Read() โดยไม่เช็ค USART_Available() ก่อน! USART_Read() เป็น blocking — จะค้างถ้าไม่มีข้อมูล

🛠️ สร้าง Product: ควบคุม LED ผ่านคอมพิวเตอร์

พิมพ์คำสั่งใน Serial Monitor เพื่อควบคุม LED (ON/OFF/TOGGLE/BLINK)

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"

int main(void)
{
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);
    pinMode(PC0, PIN_MODE_OUTPUT);

    char cmd[16]; int idx = 0;

    USART_Print("Commands: ON, OFF, TOGGLE\r\n");

    while(1)
    {
        if(USART_Available())
        {
            char ch = USART_Read();
            if(ch == '\r' || ch == '\n') {
                cmd[idx] = '\0'; idx = 0;

                if(strcmp(cmd, "ON") == 0) {
                    digitalWrite(PC0, HIGH);
                    USART_Print("LED ON\r\n");
                } else if(strcmp(cmd, "OFF") == 0) {
                    digitalWrite(PC0, LOW);
                    USART_Print("LED OFF\r\n");
                } else if(strcmp(cmd, "TOGGLE") == 0) {
                    digitalToggle(PC0);
                    USART_Print("LED TOGGLED\r\n");
                }
            } else if(idx < 15) {
                cmd[idx++] = ch;
            }
        }
    }
}

✏️ ลองทำดู

  1. เพิ่มคำสั่ง BLINK N — ทำให้ LED กระพริบ N ครั้ง (parse ตัวเลขจาก string)
  2. ใช้ USART_PrintNum() + Get_CurrentMs() ทำ timestamp ทุกข้อความ
  3. เปลี่ยนไปใช้ USART_PINS_REMAP2 — สลับ TX/RX โดยไม่ต้องเปลี่ยนสาย
