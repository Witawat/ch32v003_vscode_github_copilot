บทที่ 5: PWM — ควบคุมความสว่าง LED และ Servo Motor

วงจร LED: R 220Ω จำกัดกระแส (PWM ทำให้ LED สว่างน้อยลงเฉลี่ย แต่วูบที่ความถี่สูงจนตามองไม่เห็น)
วงจร Servo: สายสัญญาณจาก PD2, ไฟ 5V ต้องจ่ายแยก! — CH32V003 จ่าย 3.3V ไม่พอสำหรับ Servo — GND ต้องต่อรวมกัน

SOP-8: PWM pins ที่ใช้ได้: PA1 (PWM1_CH2), PC4 (PWM1_CH4) — 2 channels เท่านั้น

📚 หลักการทำงาน

PWM (Pulse Width Modulation) — สร้างสัญญาณ digital ที่มี duty cycle เปลี่ยนแปลงได้ เพื่อจำลอง analog output

Duty Cycle — สัดส่วนเวลา HIGH ต่อคาบ — 0% = LOW ตลอด, 50% = ครึ่ง HIGH ครึ่ง LOW, 100% = HIGH ตลอด

ความถี่ PWM — LED: 1kHz พอ (ตามองไม่เห็นการกระพริบ) — Servo: 50Hz (20ms period)

Servo SG90Pulse WidthDuty @50Hz
0°1.0 ms5%
90°1.5 ms7.5%
180°2.0 ms10%

CH32V003 มี 2 Timers × 4 Channels = 8 PWM outputs — แต่ใช้ pin เดียวกันกับ GPIO/ADC ปกติ

💻 เขียน Code ทีละขั้น

ขั้นที่ 1: LED Fade (ง่ายสุด)

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    PWM_Init(PWM1_CH1, 1000);  // 1kHz, auto-start!

🔍 PWM_Init(channel, freq) — ตั้งค่า Timer + GPIO + auto-start! ไม่ต้องเรียก PWM_Start() แยก (ตั้งแต่ SimpleHAL v1.9)

ขั้นที่ 2: Fade Animation

    int duty = 0, direction = 1;
    while(1) {
        PWM_SetDutyCycle(PWM1_CH1, duty);
        Delay_Ms(10);
        duty += direction;
        if(duty >= 100) direction = -1;
        if(duty <= 0)   direction = 1;
    }
}

🔍 PWM_SetDutyCycle(ch, 0-100) — ตั้งค่าเป็นเปอร์เซ็นต์ — 10ms delay × 100 steps = fade 1 วิ

ขั้นที่ 3: Servo Control

    PWM_Init(PWM1_CH1, 50);  // 50Hz สำหรับ Servo
    while(1) {
        PWM_SetDutyCycle(PWM1_CH1, 5);   // 0°
        Delay_Ms(2000);
        PWM_SetDutyCycle(PWM1_CH1, 7);   // ~90°
        Delay_Ms(2000);
        PWM_SetDutyCycle(PWM1_CH1, 10);  // 180°
        Delay_Ms(2000);
    }

🔍 เปลี่ยนจาก 1kHz เป็น 50Hz — duty 5%=1ms, 7%=1.4ms, 10%=2ms

ขั้นที่ 4: Arduino-Style analogWrite

    analogWrite(PA1, 128);  // 50% duty @ 1kHz on PA1
    analogWrite(PC3, 64);   // 25% duty @ 1kHz on PC3

🔍 analogWrite(pin, 0-255) — Arduino-style — auto-init ที่ 1kHz — ใช้ pin name โดยตรง (compile-time validation)

⚠️ ข้อผิดพลาดที่พบบ่อย

ปัญหาสาเหตุวิธีแก้
PWM ไม่มี outputใช้ pin ที่ไม่รองรับ PWMตรวจสอบว่า pin เป็น PWM pin (PA1,PC0,PC3-4,PD2-4,PD7)
Servo กระตุก/ไม่หมุนจ่ายไฟ 3.3V ให้ Servo (กระแสไม่พอ)Servo ต้องใช้ไฟ 5V ภายนอก — GND ต้องต่อรวมกัน
LED สว่างสูงสุดแต่ PWM=50%ตาเห็นค่าเฉลี่ย — อาจคิดว่าสว่างสุดแล้วลอง 100% เทียบกับ 50% ในที่มืดจะเห็นความต่าง
analogWrite compile errorใช้ pin ที่ไม่ใช่ PWM pinใช้เฉพาะ PA1,PC0,PC3-4,PD2-4,PD7 (compile-time check)
SOP-8: PACKAGE errorใช้ PWM channel ที่ pin ไม่มีใน SOP-8SOP-8 PWM pins: PA1(PWM1_CH2), PC4(PWM1_CH4)

🛠️ สร้าง Product: ไฟ LED Fade + ควบคุม Servo

LED ค่อยๆ สว่างขึ้น-ดับลงที่ PD2 พร้อมกับ Servo กวาด 0°→180° ที่ PA1

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"

int main(void)
{
    SystemCoreClockUpdate();
    Timer_Init();

    PWM_Init(PWM1_CH1, 1000);  // PD2: LED Fade @1kHz
    PWM_Init(PWM1_CH2, 50);    // PA1: Servo @50Hz

    int led_duty = 0, led_dir = 1;
    int servo_angle = 0, servo_dir = 1;

    while(1)
    {
        PWM_SetDutyCycle(PWM1_CH1, led_duty);
        PWM_SetDutyCycle(PWM1_CH2, 5 + servo_angle * 5 / 180);

        Delay_Ms(15);

        led_duty += led_dir;
        if(led_duty >= 100) led_dir = -1;
        if(led_duty <= 0)   led_dir = 1;

        servo_angle += servo_dir;
        if(servo_angle >= 180) servo_dir = -1;
        if(servo_angle <= 0)   servo_dir = 1;
    }
}

✏️ ลองทำดู

  1. ใช้ analogWrite() แทน PWM_SetDutyCycle() — ทำ LED fade เหมือนเดิม
  2. เพิ่ม Servo ตัวที่ 2 บน PC0 (PWM2_CH3) — ควบคุม independent จากตัวแรก
  3. ใช้ PWM_Stop()/PWM_Start() ทำปุ่มกดเปิด-ปิด PWM
