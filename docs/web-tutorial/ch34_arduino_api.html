ex01_Basic_Aliases — millis, micros, delay, delayMicroseconds, interrupts

📖 แนวคิด

ทดสอบ Arduino API alias ทั้งหมด — millis(), micros(), delay(), delayMicroseconds(), interrupts(), noInterrupts() — เปรียบเทียบกับ SimpleHAL ดั้งเดิม — แสดงว่าชื่อคุ้นเคยทำงานเหมือน Arduino ทุกประการ

🧭 ผังการทำงาน

flowchart TD
    A["pinMode(LED, OUTPUT)"] --> B["while(1)"]
    B --> C["digitalToggle(LED)"]
    C --> D["delay(500)"]
    D --> E["USART_Print(millis())"]
    E --> F["USART_Print(micros())"]
    F --> G["delay(500)"]
    G --> B

💻 โค้ด + อธิบายทีละบรรทัด

#define CH32V003_PACKAGE  PACKAGE_TSSOP20
#include <SimpleHAL.h>

int main(void)
{
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);

    USART_Print("Arduino API Aliases Test\r\n");

    while(1)
    {
        USART_Print("millis: ");
        USART_PrintNum(millis());
        USART_Print(" micros: ");
        USART_PrintNum(micros());
        USART_Print("\r\n");

        noInterrupts();             // ปิด global interrupt
        // ส่วนวิกฤต — ไม่มี interrupt ขัดจังหวะ
        interrupts();               // เปิด global interrupt

        delay(1000);                // alias ของ Delay_Ms(1000)
        delayMicroseconds(500);     // alias ของ Delay_Us(500)
    }
}
  • millis(): คืนค่า milliseconds ตั้งแต่เริ่ม — uint32_t — overflow ทุก ~49 วัน — alias ของ Get_CurrentMs()
  • micros(): คืนค่า microseconds — ความละเอียดขึ้นกับ Timer_Init — alias ของ Get_CurrentUs()
  • delay(ms): blocking delay — alias Delay_Ms — ต้องเรียก Timer_Init ก่อน
  • delayMicroseconds(us): blocking delay ระดับ µs — alias Delay_Us — ใช้ busy-wait
  • interrupts() / noInterrupts(): เปิด/ปิด global interrupt — alias __enable_irq() / __disable_irq()

⚠️ จุดควรระวัง

  • micros() มีความละเอียด ~1µs เฉพาะตอน SysTick 1kHz — จริง ๆ ความแม่นยำ ±1 SysTick (~1ms)
  • noInterrupts() ปิดทุก interrupt — อย่าปิดนานเกิน 10µs — IWDG จะรีเซ็ต
  • delay() ใช้ SysTick — ถ้า Timer_Init ไม่เรียก delay = 0 ทันที

✅ ตรวจสอบก่อนรัน

  • Timer_Init() เรียกแล้ว? — มิฉะนั้น millis, delay ใช้ไม่ได้
  • Serial monitor 115200 baud

ex02_Random_Numbers — randomSeed, random, randomRange

📖 แนวคิด

สร้างตัวเลขสุ่มด้วย random() และ randomRange() — ใช้ randomSeed() กำหนด seed จาก ADC noise — เปรียบเทียบการสุ่มแบบมีช่วงและไม่มีช่วง

🧭 ผังการทำงาน

flowchart TD
    A["ADC_Read(0) as seed"] --> B["randomSeed(seed)"]
    B --> C["while(1)"]
    C --> D["random() = 0..RANDOM_MAX"]
    D --> E["randomRange(1,7) = dice"]
    E --> F["Print rand & dice"]
    F --> G["delay(500)"]
    G --> C

💻 โค้ด

#define CH32V003_PACKAGE  PACKAGE_TSSOP20
#include <SimpleHAL.h>

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);
    ADC_SimpleInit();

    uint16_t seed = ADC_Read(0);          // seed จาก noise ADC
    randomSeed(seed);

    USART_Print("Random Numbers:\r\n");

    while(1) {
        uint32_t r1 = random();            // 0 ถึง RANDOM_MAX (0x7FFFFFFF)
        uint8_t r2 = randomRange(1, 7);    // 1-6 = ลูกเต๋า

        USART_Print("rand: ");
        USART_PrintNum(r1);
        USART_Print(" dice: ");
        USART_PrintNum(r2);
        USART_Print("\r\n");
        delay(500);
    }
}
  • randomSeed(seed): กำหนด seed ให้ PRNG — ใช้ ADC noise (float pin) เพื่อค่าสุ่มจริง
  • random(): คืนค่า 0 ถึง RANDOM_MAX (0x7FFFFFFF) — PRNG แบบ LCG
  • randomRange(min, max): คืนค่า min ถึง max-1 — randomRange(1,7) = 1-6

⚠️ จุดควรระวัง

  • random() เป็น PRNG ไม่ใช่ true random — ถ้าต้องการความปลอดภัยใช้ HW RNG ไม่มีใน CH32V003
  • seed เดิม → ลำดับเดิมทุกครั้ง — ควรใช้ ADC noise หรือ seed จากแหล่งอื่น
  • randomRange ค่า max ไม่รวม — เช่น randomRange(0, 100) ได้ 0-99

ex03_Interrupt_yield — digitalPinToInterrupt + attachInterrupt + yield + IWDG

📖 แนวคิด

ใช้ digitalPinToInterrupt แปลง pin number เป็น interrupt number — attachInterrupt กับ callback — ใช้ yield() คืนเวลาให้ CPU ใน busy loop — IWDG ป้องกันค้าง

🧭 ผังการทำงาน

flowchart TD
    A["pinMode(PC1, INPUT_PULLUP)"] --> B["digitalPinToInterrupt(PC1)"]
    B --> C["attachInterrupt(irq, ISR, FALLING)"]
    C --> D["while(1)"]
    D --> E["Print isr_count"]
    E --> F["Busy loop + yield()"]
    F --> G["IWDG_Feed()"]
    G --> D

💻 โค้ด

#define CH32V003_PACKAGE  PACKAGE_TSSOP20
#include <SimpleHAL.h>

volatile uint32_t isr_count = 0;

void my_isr(void) {
    isr_count++;
}

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);

    pinMode(PC1, PIN_MODE_INPUT_PULLUP);
    uint8_t irq = digitalPinToInterrupt(PC1);
    attachInterrupt(irq, my_isr, FALLING);

    USART_Print("Interrupt yield test\r\n");

    while(1) {
        USART_Print("Count: ");
        USART_PrintNum(isr_count);
        USART_Print("\r\n");

        for(uint32_t i = 0; i < 100000; i++) {
            yield();        // ให้ CPU ประมวลผล interrupt
        }
        IWDG_Feed();
    }
}
  • digitalPinToInterrupt(pin): แปลง pin → EXTI line — PC1 → EXTI1 — alias ของ Get_EXTI_Line
  • attachInterrupt(irq, cb, mode): ผูก callback กับ EXTI line — RISING/FALLING/CHANGE
  • yield(): คืนเวลาให้ CPU ระหว่างรอ — ใช้ใน busy loop ให้ interrupt ทำงาน

⚠️ จุดควรระวัง

  • yield() ไม่ได้ทำอะไรพิเศษบน CH32V003 (ไม่มี scheduler) — แต่ช่วยให้ compiler optimize
  • digitalPinToInterrupt คืนค่า 0xFF ถ้า pin ไม่มี EXTI — เช็คค่าก่อน attach
  • ISR ต้อง short — อย่าใช้ delay/USART ใน ISR

ex04_Float_Print — dtostrf + USART_Println + PrintFloat + PrintlnHex

📖 แนวคิด

พิมพ์ float เป็น string ด้วย dtostrf — ใช้ USART_Println, USART_PrintFloat, USART_PrintlnHex — เปรียบเทียบรูปแบบการแสดงผลเลขทศนิยมและเลขฐาน 16

🧭 ผังการทำงาน

flowchart TD
    A["Init System+Timer+USART"] --> B["dtostrf(pi, 6, 4, buf)"]
    B --> C["USART_Println(buf)"]
    C --> D["USART_PrintFloat(pi, 2)"]
    D --> E["USART_PrintlnHex(0xDEADBEEF)"]
    E --> F["while(1) IWDG_Feed"]

💻 โค้ด

#define CH32V003_PACKAGE  PACKAGE_TSSOP20
#include <SimpleHAL.h>

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);

    float pi = 3.14159265f;
    char buf[16];

    dtostrf(pi, 6, 4, buf);           // "3.1416" (width=6, precision=4)
    USART_Println(buf);

    USART_PrintFloat(pi, 2);          // "3.14"
    USART_Println("");

    uint32_t val = 0xDEADBEEF;
    USART_PrintlnHex(val);            // "DEADBEEF"

    while(1) { IWDG_Feed(); }
}
  • dtostrf(val, width, precision, buf): แปลง float → string — width = ความกว้างรวม — precision = ทศนิยม
  • USART_Println(str): พิมพ์ string + ขึ้นบรรทัดใหม่ (\r\n)
  • USART_PrintFloat(val, precision): พิมพ์ float โดยตรง
  • USART_PrintlnHex(val): พิมพ์เลขฐาน 16 (8 หลัก) + ขึ้นบรรทัดใหม่

⚠️ จุดควรระวัง

  • dtostrf ใช้ buffer Ram — buffer ต้องใหญ่พอ (float = ~16 chars)
  • USART_PrintFloat พิมพ์สูงสุด 4 ตำแหน่ง — precision มากกว่านี้ใช้ dtostrf
  • USART_PrintlnHex พิมพ์ uint32 — ตัวเลข 8 หลัก A-F ตัวใหญ่

ex05_Advanced_Scheduler — 3-task millis scheduler + yield + random

📖 แนวคิด

สร้าง scheduler อย่างง่าย 3 งาน — ใช้ millis() จับเวลาแต่ละ task — yield() คืนเวลา — random() สร้างค่าสุ่มแสดง — จำลองการทำงานแบบ cooperative multitasking

🧭 ผังการทำงาน

flowchart TD
    A["Init System+Timer+USART"] --> B["randomSeed(ADC)"]
    B --> C["USART_Print Started"]
    C --> D["while(1)"]
    D --> E["task1(): 1s tick"]
    E --> F["task2(): 3s tick + random"]
    F --> G["task3(): 5s tick"]
    G --> H["yield()"]
    H --> I["IWDG_Feed()"]
    I --> D

💻 โค้ด

#define CH32V003_PACKAGE  PACKAGE_TSSOP20
#include <SimpleHAL.h>

void task1(void) {
    static uint32_t last = 0;
    if(ELAPSED_TIME(last, millis()) >= 1000) {
        last = millis();
        USART_Print("Task1: 1s tick\r\n");
    }
}

void task2(void) {
    static uint32_t last = 0;
    if(ELAPSED_TIME(last, millis()) >= 3000) {
        last = millis();
        USART_Print("Task2: 3s tick, rand=");
        USART_PrintNum(randomRange(0, 100));
        USART_Print("\r\n");
    }
}

void task3(void) {
    static uint32_t last = 0;
    if(ELAPSED_TIME(last, millis()) >= 5000) {
        last = millis();
        USART_Print("Task3: 5s tick\r\n");
    }
}

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);
    randomSeed(ADC_Read(0));

    USART_Print("Scheduler Started!\r\n");

    while(1) {
        task1();
        task2();
        task3();
        yield();
        IWDG_Feed();
    }
}
  • Scheduler แบบ cooperative: แต่ละ task ทำงานสั้น ๆ แล้วคืน control — ไม่มี preemption
  • ELAPSED_TIME + millis(): ตรวจสอบเวลาที่ผ่านไปแบบ non-blocking — task ทำงานเมื่อถึงคิว
  • randomRange: สร้างค่าสุ่มในแต่ละรอบ — seed จาก ADC noise
  • yield(): ให้ CPU พักระหว่างรอบ — ลดการใช้พลังงาน

⚠️ จุดควรระวัง

  • Scheduler นี้ไม่มี priority — ทุก task รันตามลำดับใน while(1)
  • ถ้า task ใด blocking (delay) — ทั้งระบบหยุด — ต้องใช้ ELAPSED_TIME เท่านั้น
  • IWDG_Feed ต้องเรียกใน loop หลัก — ไม่ใช่ในแต่ละ task
