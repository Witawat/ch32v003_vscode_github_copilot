🔍 CH32V003 มี hardware timer แค่ TIM1 กับ TIM2 ตัวเดียวต่อตัว — SysTick ถูก SimpleDelay ครอบครองอยู่แล้ว — สามโมดูล SimplePWM / SimpleTIM / Stopwatch / Countdown ต้องแย่ง TIM1/TIM2 กันผ่าน global g_tim1_owner และ g_tim2_owner — ไม่มี accessor แยก อ่าน/เขียนตัวแปร global โดยตรงได้เลย

📚 หลักการทำงาน

📖 แนวคิด

Timer Resource Guard คือระบบจัดการกรรมสิทธิ์ timer แบบ cooperative ผ่าน global g_tim1_owner / g_tim2_owner — ทุกโมดูลเช็คค่านี้ก่อนตั้งค่า timer ถ้ามีคนจองอยู่ก็จะ คืนค่าเงียบ ไม่ throw error ไม่ return bool — ผู้ใช้ต้องอ่าน g_timX_owner เพื่อ debug

ทำไมต้องมี Guard

CH32V003 มี hardware timer แค่ TIM1 และ TIM2 — แต่ SimpleHAL มีหลายโมดูลที่ต้องการ timer: SimplePWM (PWM), SimpleTIM (interrupt tick), Stopwatch/Countdown (จับเวลา) — ถ้าแต่ละโมดูลตั้งค่า timer โดยไม่เช็คว่าคนอื่นใช้อยู่ → register ของ timer จะถูกเขียนทับ → PWM ออกเพี้ยน callback หาย หรือ Stopwatch นับผิด

กลไกจริงใน SimpleTIM.c

  1. ก่อน init — ทุกโมดูลอ่าน g_timX_owner ถ้าค่า != TIM_OWNER_NONE และ != ตัวเอง → return; เงียบ ไม่แตะ register (SimpleTIM.c:119, SimplePWM.c:218)
  2. ถ้าเป็น TIM_OWNER_NONE หรือเป็นชื่อตัวเอง → ดำเนินการต่อ แล้วตั้ง *owner = ชื่อตัวเอง (SimpleTIM.c:122, SimplePWM.c:221)
  3. ปล่อย: TIM_DetachInterrupt(timer) จะคืน owner กลับเป็น TIM_OWNER_NONE อัตโนมัติ ถ้า ปัจจุบันเป็น TIM_OWNER_TIMER (SimpleTIM.c:280-282)
  4. PWM ไม่มี API ปล่อย owner — ต้อง PWM_Stop(channel) แล้วตั้ง g_timX_owner = TIM_OWNER_NONE ด้วยมือ
  5. ทุกการ block เป็น silent return — ไม่มี error code คืน → ต้องอ่าน g_timX_owner เพื่อตรวจสอบสาเหตุ

Stopwatch กับ ownership

Stopwatch_Init() ภายในเรียก TIM_SimpleInit(TIMEXT_DEFAULT_TIMER, 1000) + TIM_AttachInterrupt(...) + TIM_Start(...) — จึงจอง TIM2 ผ่านกลไกเดียวกับ SimpleTIM — g_tim2_owner จะกลายเป็น TIM_OWNER_TIMER (=2) ในการทำงานจริง ส่วน TIM_OWNER_TIMEXT (=3) เป็นค่าที่ header เตรียมไว้สำหรับ SimpleTIM_Ext ตาม docstring

TIMEXT_DEFAULT_TIMER

macro ที่เลือก timer เริ่มต้นสำหรับ Stopwatch/Countdown — default เป็น TIM_2 (SimpleTIM_Ext.c) — ถ้าต้องการให้ Stopwatch ใช้ TIM1 แทน (เช่นต้องการ TIM2 สำหรับ PWM2) → #define TIMEXT_DEFAULT_TIMER TIM_1 ก่อน #include "SimpleHAL.h"

ผลลัพธ์

  • Timer register ไม่ถูกเขียนทับโดยโมดูลที่มาทีหลัง → PWM ไม่เพี้ยน callback ไม่หาย
  • ผู้ใช้รู้ทันที (จากการอ่าน g_timX_owner) ว่า timer ตัวไหนถูกใครจอง → เลือกใช้ timer คนละตัวได้
  • ระบบ fail-safe — ไม่มีทางที่ timer จะถูกแย่งโดยไม่รู้ตัว

💻 เขียน Code ทีละขั้น

💻 โค้ด

ขั้นที่ 1 — PWM จอง TIM1 จริง

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"

void my_tick(void) { }

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);

    // เปิด PWM บน PC4 = PWM1_CH4 (ใช้ TIM1)
    PWM_Init(PWM1_CH4, 1000);       // SimplePWM.c ตั้ง g_tim1_owner = TIM_OWNER_PWM
    PWM_SetDutyCycle(PWM1_CH4, 50);
    PWM_Start(PWM1_CH4);

    USART_Print("g_tim1_owner = ");
    USART_PrintNum(g_tim1_owner);   // อ่าน global โดยตรง → 1
    USART_Print(" (PWM=");
    USART_PrintNum(TIM_OWNER_PWM); // 1
    USART_Print(")\r\n");

🔍 เมื่อ PWM_Init() ถูกเรียก — SimplePWM.c เช็ค g_tim1_owner ถ้าเป็น TIM_OWNER_NONE → จอง → ตอนนี้ TIM1 เป็นของ PWM — อ่านค่า global โดยตรงยืนยันได้

ขั้นที่ 2 — Conflict: SimpleTIM พยายามใช้ TIM1 → เงียบ

    // พยายามตั้ง TIM1 เป็น timer 1 Hz — จะ silent return เพราะ TIM1 เป็นของ PWM
    TIM_SimpleInit(TIM_1, 1);
    TIM_AttachInterrupt(TIM_1, my_tick);   // ก็เงียบเช่นกัน

    USART_Print("After TIM_SimpleInit(TIM_1): g_tim1_owner = ");
    USART_PrintNum(g_tim1_owner);          // ยังเป็น 1 (PWM) SimpleTIM ไม่แตะ register
    USART_Print(" → PWM still safe\r\n");

🔍 TIM_SimpleInit(TIM_1, ...) เช็ค g_tim1_owner พบว่าเป็น TIM_OWNER_PWM (ไม่ใช่ NONE หรือ TIMER) → return; เงียบ — register ของ PWM ไม่ถูกแตะ ผู้ใช้ตรวจสอบได้จากการที่ g_tim1_owner ยังเป็น 1

ขั้นที่ 3 — ใช้ TIM2 แทน → ทำงานได้

    // TIM2 ยังว่าง → SimpleTIM ใช้ได้
    TIM_SimpleInit(TIM_2, 2);              // 2 Hz = interrupt ทุก 500ms
    TIM_AttachInterrupt(TIM_2, my_tick);
    TIM_Start(TIM_2);

    USART_Print("g_tim2_owner = ");
    USART_PrintNum(g_tim2_owner);          // 2 = TIM_OWNER_TIMER
    USART_Print("\r\n");

🔍 หลักแก้ conflict ง่ายๆ คือเลือก timer คนละตัว — TIM1 เป็นของ PWM ก็ใช้ TIM2 สำหรับ SimpleTIM — print ยืนยันว่า owner เปลี่ยนเป็น TIM_OWNER_TIMER

ขั้นที่ 4 — SimpleTIM ปล่อย owner อัตโนมัติ

    // TIM_DetachInterrupt จะคืน owner กลับเป็น NONE ถ้าปัจจุบันเป็น TIMER
    TIM_DetachInterrupt(TIM_2);
    USART_Print("After detach TIM_2: g_tim2_owner = ");
    USART_PrintNum(g_tim2_owner);          // 0 = TIM_OWNER_NONE (คืนให้อัตโนมัติ)
    USART_Print("\r\n");

🔍 สังเกตว่า TIM_DetachInterrupt() ไม่เพียงปิด interrupt แต่ยังคืน g_tim2_owner กลับเป็น TIM_OWNER_NONE ให้อัตโนมัติ (SimpleTIM.c:280-282) — เป็นวิธีปล่อย timer ที่ถูกต้องสำหรับ SimpleTIM

ขั้นที่ 5 — ปล่อย TIM1 จาก PWM (ต้องทำเอง)

    // PWM ไม่มี API ปล่อย owner → ต้อง Stop แล้วตั้งค่า global เอง
    PWM_Stop(PWM1_CH4);
    g_tim1_owner = TIM_OWNER_NONE;        // คืนกรรมสิทธิ์ TIM1 ด้วยมือ

    USART_Print("After manual release: g_tim1_owner = ");
    USART_PrintNum(g_tim1_owner);          // 0 = NONE
    USART_Print("\r\n");

    // ตอนนี้ SimpleTIM ใช้ TIM1 ได้แล้ว
    TIM_SimpleInit(TIM_1, 10);            // 10 Hz
    TIM_AttachInterrupt(TIM_1, my_tick);
    TIM_Start(TIM_1);
    USART_Print("TIM_1 reclaimed: g_tim1_owner = ");
    USART_PrintNum(g_tim1_owner);         // 2 = TIM_OWNER_TIMER
    USART_Print("\r\n");

🔍 เพราะ SimplePWM ไม่มี PWM_Release() → วิธีปล่อยคือ PWM_Stop() แล้วเขียน g_tim1_owner = TIM_OWNER_NONE ด้วยตนเอง — หลังจากนี้ SimpleTIM จอง TIM1 ได้ตามปกติ

ขั้นที่ 6 — อ่าน g_timX_owner เพื่อ debug ทั้งระบบ

// helper แปลงค่า owner เป็นชื่อ (วางนอก main)
static const char* tim_owner_name(uint8_t o) {
    switch (o) {
        case TIM_OWNER_NONE:    return "NONE";
        case TIM_OWNER_PWM:     return "PWM";
        case TIM_OWNER_TIMER:   return "TIMER";
        case TIM_OWNER_TIMEXT:  return "TIMEXT";
        default:                return "UNKNOWN";
    }
}

// ใน main — พิมพ์สถานะ owner ทั้งคู่:
USART_Print("TIM1 owner: "); USART_Print(tim_owner_name(g_tim1_owner)); USART_Print("\r\n");
USART_Print("TIM2 owner: "); USART_Print(tim_owner_name(g_tim2_owner)); USART_Print("\r\n");
}

🔍 ไม่มี accessor แยก — อ่าน g_tim1_owner / g_tim2_owner โดยตรงได้จากทุกที่เพราะเป็น extern uint8_t — เป็นวิธีหลักในการตรวจสอบว่า timer ตัวไหนถูกใครจองอยู่

⚠️ จุดควรระวัง

ปัญหาสาเหตุวิธีแก้
TIM_SimpleInit() ไม่ทำงานtimer ตัวนั้นถูก PWM หรือ Stopwatch จองอยู่อ่าน g_timX_owner ถ้าเป็น TIM_OWNER_PWM(1) หรือ TIM_OWNER_TIMER(2) ให้ใช้ timer อีกตัว หรือปล่อยก่อน
PWM ออกเพี้ยนหลังเรียก SimpleTIMใช้ timer ตัวเดียวกัน แต่จริงๆ SimpleTIM จะถูก block → ปัญหาน่าจะมาจากที่อื่นตรวจ g_timX_owner — ถ้า SimpleTIM ถูก block จริง PWM ต้องไม่เพี้ยน — กลับไปดู config อื่น
อยากใช้ TIM1 หลังเลิก PWMPWM ไม่มี API ปล่อย ownerPWM_Stop(channel); แล้วตั้ง g_tim1_owner = TIM_OWNER_NONE; ด้วยตนเอง
เลิก SimpleTIM แล้ว owner ยังถูกจองเรียกแค่ TIM_Stop() ไม่ได้ปล่อย ownerใช้ TIM_DetachInterrupt(timer) จะคืน owner เป็น TIM_OWNER_NONE อัตโนมัติถ้าปัจจุบันเป็น TIM_OWNER_TIMER
Stopwatch ไม่นับเวลาTIM2 ถูก SimpleTIM หรือ PWM2 จองอยู่ → Stopwatch_Init เรียก TIM_SimpleInit(TIM_2) จึง silent returnปล่อย TIM2 ก่อน หรือ #define TIMEXT_DEFAULT_TIMER TIM_1 เพื่อให้ Stopwatch ใช้ TIM1
ใช้ PWM2 และ Stopwatch พร้อมกันไม่ได้ทั้งคู่ใช้ TIM2ย้าย PWM ไป TIM1 (PWM1_CHx) แล้วให้ Stopwatch ใช้ TIM2 อย่างเดียว
นึกว่า timer พัง เพราะ init แล้ว callback ไม่ทำงานจริงๆ คือ TIM_AttachInterrupt ถูก block เงียบเช็ค g_timX_owner — ถ้าไม่ใช่ TIM_OWNER_TIMER แปลว่า attach ไม่สำเร็จ

🛠️ สร้าง Product: PWM fade + Stopwatch uptime ไม่ชนกัน

ระบบที่ใช้ PWM ปั่นไฟ LED บน TIM1 ไปด้วย พร้อมกับ Stopwatch จับเวลา uptime บน TIM2 — คนละ timer จึงไม่ชนกัน มี diagnostic พิมพ์ค่า g_tim1_owner / g_tim2_owner ผ่าน USART

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"

static volatile uint8_t g_duty = 0;
static volatile int8_t  g_dir  = 1;

// fade ทีละขั้น (เรียกจากลูปหลัก ไม่ต้องใช้ timer เพิ่ม)
static void fade_step(void) {
    g_duty = (uint8_t)((int16_t)g_duty + g_dir);
    if (g_duty >= 100) { g_duty = 100; g_dir = -1; }
    else if (g_duty == 0 && g_dir == -1) { g_dir = 1; }
    PWM_SetDutyCycle(PWM1_CH4, g_duty);
}

int main(void)
{
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);

    // ==== TIM1: PWM fade บน PC4 (PWM1_CH4) ====
    PWM_Init(PWM1_CH4, 1000);
    PWM_Start(PWM1_CH4);
    USART_Print("PWM on TIM1/PC4   — g_tim1_owner = ");
    USART_PrintNum(g_tim1_owner);          // 1 = TIM_OWNER_PWM
    USART_Print("\r\n");

    // ==== TIM2: Stopwatch (default TIMEXT_DEFAULT_TIMER = TIM_2) ====
    Stopwatch_Init();
    Stopwatch_Start();
    USART_Print("Stopwatch on TIM2 — g_tim2_owner = ");
    USART_PrintNum(g_tim2_owner);          // 2 = TIM_OWNER_TIMER
    USART_Print("\r\n");

    // ==== ทดสอบ conflict: พยายามใช้ SimpleTIM บน TIM1 → ต้องเงียบ ====
    TIM_SimpleInit(TIM_1, 2);
    USART_Print("After TIM_SimpleInit(TIM_1): g_tim1_owner = ");
    USART_PrintNum(g_tim1_owner);          // ยังเป็น 1 (PWM ไม่ถูกเขียนทับ)
    USART_Print(" → conflict blocked, PWM safe\r\n");

    // ==== ลูปหลัก: fade + พิมพ์ uptime ====
    char buf[TIME_BUFFER_SIZE_HHMMSS];
    while (1) {
        fade_step();
        Stopwatch_GetTimeString(buf, TIME_FORMAT_HHMMSS, TIME_DISPLAY_NORMALIZED);
        USART_Print("duty=");
        USART_PrintNum(g_duty);
        USART_Print("  uptime: ");
        USART_Print(buf);
        USART_Print("\r\n");
        Delay_Ms(30);
    }
}

🔍 บทสรุป: การแยก timer ให้แต่ละโมดูลใช้คนละตัวคือวิธีที่ปลอดภัยที่สุด — PWM ที่ TIM1 + Stopwatch ที่ TIM2 → g_tim1_owner อ่านได้ 1 และ g_tim2_owner อ่านได้ 2 — ถ้าพยายามแย่ง TIM1 กลับ SimpleTIM จะ silent return โดยอัตโนมัติ

✅ ตรวจสอบก่อนรัน

✅ ตรวจสอบก่อนรัน

  • เช็คว่า PWM และ SimpleTIM ไปคนละ timer (TIM1 กับ TIM2) — อย่าใช้พร้อมกันบนตัวเดียว
  • หลัง init ทุกครั้ง ให้อ่าน g_tim1_owner / g_tim2_owner เพื่อยืนยันว่าโมดูลที่ต้องการได้จองถูกตัวจริงๆ
  • ถ้า TIM_SimpleInit() หรือ TIM_AttachInterrupt() ไม่ทำงาน — อย่าสรุปว่า hardware พัง ให้อ่าน g_timX_owner ก่อนเสมอ
  • ก่อนเรียก Stopwatch_Init() ตรวจว่า TIM2 ไม่ได้ถูก SimpleTIM หรือ PWM2 จองอยู่ (ไม่งั้น Stopwatch จะ silent)
  • เลิก SimpleTIM ต้องเรียก TIM_DetachInterrupt(timer) ไม่ใช่แค่ TIM_Stop() — เพื่อคืน owner ให้ timer ว่างอีกครั้ง
  • เลิก PWM ต้อง PWM_Stop(channel) แล้วตั้ง g_timX_owner = TIM_OWNER_NONE ด้วยมือ เพราะไม่มี API ปล่อย owner
  • ถ้า project ใช้ PWM2 และ Stopwatch พร้อมกัน — ย้าย Stopwatch ไป TIM1 ผ่าน #define TIMEXT_DEFAULT_TIMER TIM_1

✏️ ลองทำดู

  1. เปิด PWM บน PWM1_CH4 (TIM1) แล้วเรียก TIM_SimpleInit(TIM_1, 1) — เช็ค g_tim1_owner ก่อนและหลัง — สังเกตว่า SimpleTIM ถูก block และค่า owner ยังเป็น TIM_OWNER_PWM
  2. เลิก PWM ด้วย PWM_Stop(PWM1_CH4) + g_tim1_owner = TIM_OWNER_NONE แล้วเรียก TIM_SimpleInit(TIM_1, 1) อีกครั้ง — คราวนี้ต้องทำงานและ owner เปลี่ยนเป็น TIM_OWNER_TIMER
  3. เรียก TIM_SimpleInit(TIM_2, 2) แล้วเรียก Stopwatch_Init() — สังเกตว่า Stopwatch จะ silent เพราะ TIM2 ถูก SimpleTIM จอง — แล้วลอง TIM_DetachInterrupt(TIM_2) ก่อนเรียก Stopwatch_Init อีกครั้ง
