ex01_LED_Fade — PWM Fade LED 0-100%

📖 แนวคิด

ใช้ PWM เพื่อปรับความสว่าง LED แบบอะนาล็อกจาก 0% ถึง 100% — PWM_Init(pin, freq) สร้างสัญญาณ Square Wave ที่ความถี่ 1kHz — PWM_SetDutyCycle เปลี่ยนความกว้างพัลส์เป็นเปอร์เซ็นต์

🔌 วงจร

    CH32V003                  LED
    PD2 ----/\/\/\---->|---- GND
    PWM1_CH1  220 Ohm
    - ขาแอโนด (+ ยาว) ต่อ R 220Ω → PD2
    - ขาแคโทด (- สั้น) ต่อ GND
MCU Pin→อุปกรณ์ขาหมายเหตุ
PD2 (PWM1_CH1)→R 220Ωขา 1จำกัดกระแส LED
R 220Ω→LED (แอโนด)ขายาว (+)—
LED (แคโทด)→GNDขาสั้น (-)—

🧭 ผังการทำงาน

flowchart TD
    A["PWM_Init(PWM1_CH1, 1000Hz)"] --> B["while(1)"]
    B --> C["PWM_SetDutyCycle(ch, duty)"]
    C --> D["Delay_Ms(10)"]
    D --> E["duty += direction"]
    E --> F{"duty ≥ 100 หรือ ≤ 0?"}
    F -->|"Yes"| G["กลับ direction"]
    F -->|"No"| B
    G --> B

💻 โค้ด + อธิบายทีละบรรทัด

#define CH32V003_PACKAGE  PACKAGE_TSSOP20
#include <SimpleHAL.h>

int main(void)
{
    SystemCoreClockUpdate();
    Timer_Init();
    PWM_Init(PWM1_CH1, 1000);   // auto-starts! ไม่ต้อง PWM_Start()

    int duty = 0;
    int direction = 1;

    while (1)
    {
        PWM_SetDutyCycle(PWM1_CH1, duty);  // ตั้ง duty 0-100%
        Delay_Ms(10);

        duty = duty + direction;
        if (duty >= 100) direction = -1;
        if (duty <= 0)   direction = 1;
    }
}
  • PWM_Init(ch, freq_Hz): เริ่ม PWM channel ที่ pin เฉพาะ — ตั้ง prescaler+period auto — auto-start PWM ตั้งแต่ Init (TIM1)
  • PWM_SetDutyCycle(ch, percent): เปลี่ยน duty cycle 0-100 — คำนวณค่า compare register ให้เอง
  • PWM1_CH1 = PD2: TIM1 channel 1 output — ใช้ได้ทุกแพ็กเกจยกเว้น SOP-8 (SOP-8 ต้องใช้ PWM1_CH1 ที่ PD2 หรือ PWM2_CH1 ที่ PD4)

⚠️ จุดควรระวัง

  • PWM_Init auto-starts เฉพาะ TIM1 — TIM2 ต้องเรียก PWM_Start() เอง
  • PWM1_CH1 (PD2) กับ PWM1_CH2 (PA1) ใช้ TIM1 เดียวกัน → ความถี่ต้องเท่ากัน
  • LED ต้องมี R 220Ω เสมอ — ต่อตรงไม่มี R = LED + pin พัง

✅ ตรวจสอบก่อนรัน

  • LED ต่อถูกขั้ว? แอโนด→R→PD2, แคโทด→GND
  • ใช้ PWM channel ที่ถูกต้อง? ดู pin mapping ใน SimpleHAL.h
  • SystemCoreClockUpdate() + Timer_Init() เรียกก่อน PWM_Init?

ex02_Servo_Control — ควบคุม Servo SG90 0°-180°

📖 แนวคิด

Servo SG90 ใช้สัญญาณ PWM 50Hz (คาบ 20ms) — ความกว้างพัลส์ 1-2ms แปลงเป็นมุม 0°-180° — คำนวณเป็น % duty: 1ms=5%, 1.5ms=90°=7.5%, 2ms=180°=10%

🔌 วงจร

    CH32V003                SERVO SG90
    PD2 ---(Signal)-------> SIGNAL (ส้ม)
    PWM1_CH1
                              VCC (แดง) ---- +5V ภายนอก
                              GND (น้ำตาล) -- GND รวม
    - ต้องใช้ไฟ 5V ภายนอก — ห้ามใช้ 3.3V จาก MCU
    - GND Servo + MCU ต่อรวมกัน (common ground)
MCU Pin→อุปกรณ์ขาหมายเหตุ
PD2 (PWM1_CH1)→Servo SG90 (Signal)ส้มPWM 50Hz, duty 5-10%
Servo SG90 (VCC)←+5V ภายนอกแดงห้ามใช้ 3.3V จาก MCU
Servo SG90 (GND)↔GND (MCU + 5V)น้ำตาลCommon ground

    B --> C["while(1)"]
    C --> D["PWM_SetDutyCycle(5%) = 0°"]
    D --> E["Delay_Ms(2000)"]
    E --> F["PWM_SetDutyCycle(7%) ≈ 90°"]
    F --> G["Delay_Ms(2000)"]
    G --> H["PWM_SetDutyCycle(10%) = 180°"]
    H --> I["Delay_Ms(2000)"]
    I --> J["PWM_SetDutyCycle(7%) กลับ"]
    J --> K["Delay_Ms(2000)"]
    K --> C

💻 โค้ด

#define CH32V003_PACKAGE  PACKAGE_TSSOP20
#include <SimpleHAL.h>

int main(void)
{
    SystemCoreClockUpdate();
    Timer_Init();
    PWM_Init(PWM1_CH1, 50);    // 50Hz = 20ms period
    PWM_Start(PWM1_CH1);

    while (1)
    {
        PWM_SetDutyCycle(PWM1_CH1, 5);   // 0° = 1ms
        Delay_Ms(2000);

        PWM_SetDutyCycle(PWM1_CH1, 7);   // ~90° = 1.5ms
        Delay_Ms(2000);

        PWM_SetDutyCycle(PWM1_CH1, 10);  // 180° = 2ms
        Delay_Ms(2000);

        PWM_SetDutyCycle(PWM1_CH1, 7);
        Delay_Ms(2000);
    }
}
  • 50Hz: จำเป็นสำหรับ Servo — ถ้าใช้ความถี่อื่น Servo สั่นหรือไม่หมุน
  • Duty 5% = 1ms (0°): 5% ของ 20ms = 1ms — 10% = 2ms (180°) — ค่าเลขจำนวนเต็มเท่านั้น ไม่มีทศนิยม
  • PWM_Start: TIM1 auto-start หลัง Init แต่บางรุ่นต้องเรียก Start ชัดเจน — ปลอดภัยกว่าเรียกเสมอ

⚠️ จุดควรระวัง

  • SG90 กินกระแส ~250mA — MCU 3.3V จ่ายไม่พอ — ต้องใช้ +5V ภายนอก
  • GND รวมกันเสมอ — สัญญาณ control อ้างอิง GND เดียวกัน
  • ค่า duty ป้อนทศนิยมไม่ได้ — 7% ประมาณ 1.4ms (90° จริง ~7.5%) — ทดลองปรับเอา

ex03_Multiple_PWM — 3 PWM พร้อมกัน (LED + LED + Servo)

📖 แนวคิด

ใช้ PWM หลายช่องพร้อมกัน — PD2(PWM1_CH1) fade LED, PA1(PWM1_CH2) ควบคุม Servo, PC0(PWM2_CH3) blink LED — TIM1 channels แชร์ความถี่เดียวกัน ส่วน TIM2 แยกอิสระ

🔌 วงจร

    PD2 ---R---|LED1|---GND    (PWM1_CH1, TIM1, 50Hz)
    PA1 ---(Signal)-- Servo    (PWM1_CH2, TIM1, 50Hz)
    PC0 ---R---|LED2|---GND    (PWM2_CH3, TIM2, 1kHz)
MCU Pin→อุปกรณ์ขาหมายเหตุ
PD2 (PWM1_CH1)→R 220Ω → LED1แอโนดTIM1, 50Hz fade
LED1→GNDแคโทด—
PA1 (PWM1_CH2)→Servo SG90 (Signal)ส้มTIM1, 50Hz
Servo VCC←+5V ภายนอกแดง—
Servo GND↔GNDน้ำตาลCommon ground
PC0 (PWM2_CH3)→R 220Ω → LED2แอโนดTIM2, 1kHz blink
LED2→GNDแคโทด—

🧭 ผังการทำงาน

flowchart TD
    A["PWM_Init(PWM1_CH1, 50Hz)"] --> B["PWM_Init(PWM1_CH2, 50Hz)"]
    B --> C["PWM_Init(PWM2_CH3, 1000Hz)"]
    C --> D["PWM_Start() ทั้ง 3"]
    D --> E["while(1)"]
    E --> F["PWM1_CH1 fade 0-100%"]
    F --> G["PWM2_CH3 blink 0-50%"]
    G --> H["PWM1_CH2 servo 5-10%"]
    H --> I["Delay_Ms(20)"]
    I --> E

💻 โค้ด

#define CH32V003_PACKAGE  PACKAGE_TSSOP20
#include <SimpleHAL.h>

int main(void)
{
    SystemCoreClockUpdate();
    Timer_Init();

    // TIM1: PD2 + PA1 share same frequency
    PWM_Init(PWM1_CH1, 50);     // PD2 - LED1
    PWM_Init(PWM1_CH2, 50);     // PA1 - Servo

    // TIM2: independent frequency
    PWM_Init(PWM2_CH3, 1000);   // PC0 - LED2

    PWM_Start(PWM1_CH1);
    PWM_Start(PWM1_CH2);
    PWM_Start(PWM2_CH3);

    int led1_duty = 0, led1_dir = 1;
    int led2_duty = 0, led2_dir = 1;
    int servo_duty = 5, servo_dir = 1;

    while (1)
    {
        PWM_SetDutyCycle(PWM1_CH1, led1_duty);  // fade 0-100%
        led1_duty += led1_dir;
        if (led1_duty >= 100) led1_dir = -1;
        if (led1_duty <= 0)   led1_dir = 1;

        PWM_SetDutyCycle(PWM2_CH3, led2_duty);  // blink 0-50%
        led2_duty += led2_dir;
        if (led2_duty >= 50) led2_dir = -1;
        if (led2_duty <= 0)  led2_dir = 1;

        PWM_SetDutyCycle(PWM1_CH2, servo_duty); // sweep 5-10%
        servo_duty += servo_dir;
        if (servo_duty >= 10) servo_dir = -1;
        if (servo_duty <= 5)  servo_dir = 1;

        Delay_Ms(20);
    }
}
  • TIM1 channels (PD2, PA1, PC3, PC4): ทุกช่องใน TIMER เดียวกันใช้ความถี่เดียวกัน — PWM_Init หลังสุดชนะ
  • TIM2 channels (PD4, PD3, PC0, PD7): แยกอิสระ — ตั้งความถี่ต่างจาก TIM1 ได้
  • ทั้งหมดทำงานพร้อมกัน: ฮาร์ดแวร์ PWM ไม่กิน CPU — Delay_Ms(20) ใน loop อัปเดต duty ทุก 20ms

⚠️ จุดควรระวัง

  • PD2 (PWM1_CH1) กับ PA1 (PWM1_CH2) อยู่ TIM1 เดียวกัน — SET FREQUENCY เท่ากันเสมอ!
  • PC0 (PWM2_CH3) ใช้ TIM2 — แยกอิสระ ตั้งต่างได้
  • ดู pin mapping ให้ถูก — ใช้ pin ที่ไม่มี PWM output → ผิดช่อง → เงียบ

ex04_PWM_Advanced — Polarity + Read Back

📖 แนวคิด

ใช้ PWM_AdvancedInit กำหนด prescaler, period, duty_value โดยตรง — PWM_SetPolarity กลับขั้วสัญญาณ (active LOW) — อ่านค่าปัจจุบันด้วย PWM_GetDutyCycle / PWM_GetPeriod

🧭 ผังการทำงาน

flowchart TD
    A["PWM_AdvancedInit(PWM1_CH1, PSC=239, Period=99, Duty=50)"] --> B["PWM_SetPolarity(inverted)"]
    B --> C["PWM_Start()"]
    C --> D["while(1)"]
    D --> E["PWM_SetDutyCycle(current_duty)"]
    E --> F["Delay_Ms(50)"]
    F --> G["current_duty ++ / --"]
    G --> H{"≥ 100 หรือ ≤ 0?"}
    H -->|"Yes"| I["กลับทิศ"]
    H -->|"No"| D
    I --> D

💻 โค้ด

#define CH32V003_PACKAGE  PACKAGE_TSSOP20
#include <SimpleHAL.h>

int main(void)
{
    SystemCoreClockUpdate();
    Timer_Init();

    uint16_t prescaler = 239;
    uint16_t period    = 99;
    uint16_t duty_value = 50;

    PWM_AdvancedInit(PWM1_CH1, prescaler, period, duty_value);
    PWM_SetPolarity(PWM1_CH1, 1);   // inverted polarity
    PWM_Start(PWM1_CH1);

    (void)PWM_GetDutyCycle(PWM1_CH1);  // อ่านค่า duty
    (void)PWM_GetPeriod(PWM1_CH1);     // อ่านค่า period

    uint16_t current_duty = 0;
    int dir = 1;

    while (1)
    {
        PWM_SetDutyCycle(PWM1_CH1, current_duty);
        Delay_Ms(50);

        if (dir == 1) current_duty++;
        else          current_duty--;

        if (current_duty >= 100) dir = -1;
        if (current_duty <= 0)   dir = 1;
    }
}
  • PWM_AdvancedInit: รับ prescaler, period, duty_value ตรง ๆ — ไม่ auto คำนวณ — ต้องรู้ความถี่ที่ต้องการ
  • PWM_SetPolarity(ch, invert): 0=active HIGH (default), 1=active LOW — invert แล้ว duty 0% = LED ติด, 100% = ดับ
  • PWM_GetDutyCycle / PWM_GetPeriod: อ่านค่า CCxR / ARR จาก register — ใช้ debug หรือตรวจสอบสถานะ

⚠️ จุดควรระวัง

  • PWM_AdvancedInit ต้องคำนวณ prescaler/period เอง — ผิดค่า = ความถี่ไม่ตรง
  • กลับขั้ว (polarity=1): duty_value = 50 → สูง 50% ของ period — แต่ invert ทำให้ logic กลับ
  • ค่า duty_value เป็นค่าจริง 0-period ไม่ใช่ % — PWM_SetDutyCycle รับ % แต่ AdvancedInit รับค่าจริง

ex05_PWM_Frequency_Sweep — Buzzer 500Hz-4kHz

📖 แนวคิด

ใช้ PWM_SetFrequency เปลี่ยนความถี่แบบ real-time — ขับ piezo buzzer ผ่านทรานซิสเตอร์ 2N2222 — Duty 50% ให้ Square Wave เหมาะกับ buzzer — sweep 500Hz→1kHz→2kHz→4kHz

🔌 วงจร

    PD2 ---1kΩ--- BASE (2N2222)
    PWM1_CH1        |
                 COLLECTOR ----(+)---- VCC (5V)
                               |
                             Piezo
                               |
                 EMITTER -----(-)---- GND
                             Buzzer
    - ใช้ทรานซิสเตอร์ขับ Buzzer เพราะกระแสเกิน MCU จ่าย
MCU Pin→อุปกรณ์ขาหมายเหตุ
PD2 (PWM1_CH1)→R 1kΩขา 1Base resistor
R 1kΩ→2N2222 (Base)BDrive transistor
2N2222 (Collector)→Piezo Buzzer (-)——
Piezo Buzzer (+)→VCC (5V)—แหล่งจ่ายภายนอก
2N2222 (Emitter)→GNDE—

flowchart TD

    B --> C["PWM_Start()"]
    C --> D["while(1)"]
    D --> E["PWM_SetFrequency(500Hz) → 1s"]
    E --> F["PWM_SetFrequency(1000Hz) → 1s"]
    F --> G["PWM_SetFrequency(2000Hz) → 1s"]
    G --> H["PWM_SetFrequency(4000Hz) → 1s"]
    H --> I["ย้อนกลับ 2000 → 1000 → 500 Hz"]

💻 โค้ด

#define CH32V003_PACKAGE  PACKAGE_TSSOP20
#include <SimpleHAL.h>

int main(void)
{
    SystemCoreClockUpdate();
    Timer_Init();
    PWM_Init(PWM1_CH1, 500);
    PWM_SetDutyCycle(PWM1_CH1, 50);    // 50% = square wave
    PWM_Start(PWM1_CH1);

    while (1)
    {
        PWM_SetFrequency(PWM1_CH1, 500);  Delay_Ms(1000);
        PWM_SetFrequency(PWM1_CH1, 1000); Delay_Ms(1000);
        PWM_SetFrequency(PWM1_CH1, 2000); Delay_Ms(1000);
        PWM_SetFrequency(PWM1_CH1, 4000); Delay_Ms(1000);
        PWM_SetFrequency(PWM1_CH1, 2000); Delay_Ms(1000);
        PWM_SetFrequency(PWM1_CH1, 1000); Delay_Ms(1000);
        PWM_SetFrequency(PWM1_CH1, 500);  Delay_Ms(1000);
    }
}
  • PWM_SetFrequency(ch, freq_Hz): เปลี่ยนความถี่โดยคง duty ปัจจุบัน — เปลี่ยนทุกช่องใน TIMER เดียวกัน
  • Duty 50%: Square Wave ที่สมมาตร — ให้เสียงดังที่สุดจาก piezo buzzer
  • ทรานซิสเตอร์ 2N2222: Piezo buzzer กินกระแส ~30-100mA — MCU output สูงสุด ~8mA — ต้องใช้ transistor ขับ

⚠️ จุดควรระวัง

  • PWM_SetFrequency เปลี่ยนทุกช่องใน TIMER เดียวกัน — ถ้ามี servo อยู่ TIM1 จะเพี้ยนตาม
  • มนุษย์ได้ยิน ~20Hz-20kHz — 500Hz-4kHz เหมาะกับการทดสอบ
  • Buzzer แบบ active (มี oscillator) ใช้แค่ DC — ต้องใช้ passive buzzer ถึงจะใช้ PWM

ex06_PWM_Remap — เปลี่ยน Pin PWM

📖 แนวคิด

ใช้ PWM_SetRemap / PWM_InitRemap ย้าย PWM output ไป pin อื่น — เช่น PWM1_CH1 ปกติ PD2 → remap PARTIAL1 ไป pin อื่น — PWM_Write auto-init พร้อม remap

🧭 ผังการทำงาน

flowchart TD
    A["PWM_SetRemap(PWM1_CH1, PARTIAL1)"] --> B["PWM_Write(PWM1_CH1, 128)"]
    B --> C["PWM_Start() → duty 25% → Stop"]
    C --> D["PWM_InitRemap(PWM2_CH1, 1000, PARTIAL2)"]
    D --> E["PWM_Start() → duty 75% → 0% → Stop"]
    E --> F["Package-safe: IS_PWM_VALID_PACKAGE"]
    F --> G["while(1): fade PWM1↑ PWM2↓"]
    G --> H["Delay_Ms(50)"]
    H --> G

💻 โค้ด

#define CH32V003_PACKAGE  PACKAGE_TSSOP20
#include "SimpleHAL.h"

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    pinMode(PC0, PIN_MODE_OUTPUT);

#if !CH32V003_IS_SOP8
    // วิธีที่ 1: PWM_SetRemap + PWM_Write (ง่าย)
    PWM_SetRemap(PWM1_CH1, PWM_REMAP_PARTIAL1);
    PWM_Write(PWM1_CH1, 128);  // 50% duty @ 1kHz + PARTIAL1 remap
    PWM_Start(PWM1_CH1);

    Delay_Ms(2000);
    PWM_SetDutyCycle(PWM1_CH1, 25);
    Delay_Ms(2000);
    PWM_Stop(PWM1_CH1);

    // วิธีที่ 2: PWM_InitRemap (manual)
    PWM_InitRemap(PWM2_CH1, 1000, PWM_REMAP_PARTIAL2);
    PWM_Start(PWM2_CH1);
    PWM_SetDutyCycle(PWM2_CH1, 75);
    Delay_Ms(2000);
    PWM_SetDutyCycle(PWM2_CH1, 0);
    PWM_Stop(PWM2_CH1);
#endif

    // Package-safe: ใช้เฉพาะ channel ที่มี
    if (IS_PWM_VALID_PACKAGE(PWM1_CH1)) {
        PWM_Init(PWM1_CH1, 1000);
        PWM_Start(PWM1_CH1);
    }
    if (IS_PWM_VALID_PACKAGE(PWM2_CH1)) {
        PWM_Init(PWM2_CH1, 1000);
        PWM_Start(PWM2_CH1);
    }

    while (1) {
        digitalToggle(PC0);
        for (uint8_t i = 0; i <= 100; i += 5) {
            if (IS_PWM_VALID_PACKAGE(PWM1_CH1))
                PWM_SetDutyCycle(PWM1_CH1, i);
            if (IS_PWM_VALID_PACKAGE(PWM2_CH1))
                PWM_SetDutyCycle(PWM2_CH1, 100 - i);
            Delay_Ms(50);
        }
    }
}
  • PWM_SetRemap(ch, remap): เก็บค่ารีแมปไว้ — รอให้ PWM_Write/analogWrite ใช้ตอน auto-init
  • PWM_InitRemap(ch, freq, remap): init + remap ในคำสั่งเดียว — manual control
  • PWM_REMAP_PARTIAL1 / PARTIAL2: ย้าย PWM output ไป pin remap — ดู datasheet pinout

⚠️ จุดควรระวัง

  • PWM_REMAP_FULL ถูกลบ — เพราะใช้พอร์ท PE/PB ที่ไม่มีใน CH32V003
  • Remap ใช้ได้เฉพาะ TSSOP-20/QFN-20 — SOP-8/SOP-16 ไม่มี pin ให้ remap
  • เช็คด้วย IS_PWM_VALID_PACKAGE — ป้องกันใช้ channel ที่ไม่มีอยู่จริง

ex07_PWM_SOP8_Guard — ตรวจสอบแพ็กเกจก่อนใช้ PWM

📖 แนวคิด

SOP-8 มีแค่ 6 user pins — PWM channels ที่ใช้ได้: PWM1_CH1 (PD2) และ PWM2_CH1 (PD4) เท่านั้น — ใช้ IS_PWM_VALID_PACKAGE(ch) เช็คก่อน — เปลี่ยน CH32V003_PACKAGE เพื่อทดสอบ

🧭 ผังการทำงาน

flowchart TD
    A["SystemCoreClockUpdate()"] --> B["Timer_Init()"]
    B --> C["USART_SimpleInit()"]
    C --> D["try_pwm(PWM1_CH1)"]
    D --> E["try_pwm(PWM1_CH2)"]
    E --> F["try_pwm(…) ทุก channel"]
    F --> G["while(1) → Delay_Ms(1000)"]
    H["try_pwm(ch, name)"] --> I{"IS_PWM_VALID_PACKAGE?"}
    I -->|"Yes"| J["PWM_Init → Start → duty 30%"]
    I -->|"No"| K["ข้าม (SKIP)"]
    J --> L["พิมพ์ [OK] name"]
    K --> L

💻 โค้ด

#define CH32V003_PACKAGE  PACKAGE_SOP8     // ลองเปลี่ยน SOP16/TSSOP20
#include "SimplePWM.h"
#include "SimpleDelay.h"
#include "SimpleUSART.h"

static void try_pwm(PWM_Channel ch, const char* name) {
    if (IS_PWM_VALID_PACKAGE(ch)) {
        PWM_Init(ch, 1000);
        PWM_Start(ch);
        PWM_SetDutyCycle(ch, 30);
        USART_Print("  [OK] ");
    } else {
        USART_Print("  [SKIP] ");
    }
    USART_Print(name);
    USART_Print("\r\n");
}

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);

#if CH32V003_IS_SOP8
    USART_Print("\r\n=== PWM on SOP-8 (6 pins) ===\r\n");
    USART_Print("Only PWM1_CH1(PD2) and PWM2_CH1(PD4)\r\n\r\n");
#else
    USART_Print("\r\n=== PWM (all channels) ===\r\n\r\n");
#endif

    try_pwm(PWM1_CH1, "PWM1_CH1 (PD2)");
    try_pwm(PWM1_CH2, "PWM1_CH2 (PA1)");
    try_pwm(PWM1_CH3, "PWM1_CH3 (PC3)");
    try_pwm(PWM1_CH4, "PWM1_CH4 (PC4)");
    try_pwm(PWM2_CH1, "PWM2_CH1 (PD4)");
    try_pwm(PWM2_CH2, "PWM2_CH2 (PD3)");
    try_pwm(PWM2_CH3, "PWM2_CH3 (PC0)");
    try_pwm(PWM2_CH4, "PWM2_CH4 (PD7)");

    USART_Print("\r\nDone! Change CH32V003_PACKAGE and rebuild.\r\n");

    while (1) {
        Delay_Ms(1000);
    }
}
  • IS_PWM_VALID_PACKAGE(ch): compile-time macro — คืน true ถ้า channel นั้นมี pin จริงในแพ็กเกจ
  • SOP-8 มีแค่: PWM1_CH1 (PD2), PWM2_CH1 (PD4) — ที่เหลือไม่มี pin → SKIP
  • เปลี่ยน PACKAGE_SOP8 → PACKAGE_TSSOP20: rebuild เห็นผลต่าง — SOP-16 มีเพิ่มบาง channel

⚠️ จุดควรระวัง

  • SOP-8 ไม่มี PA1, PC3, PC4, PD3, PD7 — ใช้ PWN1_CH2/3/4 และ PWM2_CH2/4 ไม่ได้
  • IS_PWM_VALID_PACKAGE return false แต่ code ยัง compile ผ่าน — runtime เงียบ
  • SimpleHAL.h มี IS_PWM_VALID_PACKAGE — SimplePWM.h ก็มีเหมือนกัน

ex08_PWM_ADC_Control — ADC → PWM Brightness

📖 แนวคิด

Cross-module: อ่านค่า analog จาก potentiometer (PD2) → แปลง 0-1023 → 0-100% duty → PWM ที่ PC0 — แสดงค่าผ่าน USART real-time — สอนการเชื่อมต่อ ADC + PWM + USART

🔌 วงจร

    LED: PC0 --- 220Ω ---|>|--- GND
    USART: PD5=TX, PD6=RX

flowchart TD

    B --> C["while(1)"]
    C --> D["analogRead(PD2) → 0-1023"]
    D --> E["แปลงเป็น duty 0-100%"]

💻 โค้ด

#define CH32V003_PACKAGE  PACKAGE_TSSOP20
#include "SimpleHAL.h"

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    USART_SimpleInit(BAUD_115200, USART_PINS_DEFAULT);

    PWM_Init(PWM2_CH3, 1000);   // PC0, 1kHz
    PWM_Start(PWM2_CH3);
    ADC_SimpleInit();

    USART_Print("\r\n=== ADC → PWM Control ===\r\n");
    USART_Print("Turn potentiometer to adjust LED brightness\r\n");
    USART_Print("ADC(0-1023) → Duty(0-100%) → PWM(PC0)\r\n\r\n");

    while (1) {
        uint16_t adc = analogRead(PD2);   // 0-1023
        uint8_t duty = (uint8_t)(((uint32_t)adc * 100) / 1023);

        PWM_SetDutyCycle(PWM2_CH3, duty);

        USART_Print("ADC: ");
        USART_PrintNum(adc);
        USART_Print(" -> Duty: ");
        USART_PrintNum(duty);
        USART_Print("%\r\n");

        Delay_Ms(100);  // 10Hz update
    }
}
  • AnalogRead(pin): อ่าน ADC 10-bit (0-1023) — ต้องเรียก ADC_SimpleInit ก่อน
  • Map 0-1023 → 0-100: ((uint32_t)adc * 100) / 1023 — ใช้ uint32_t ป้องกัน overflow
  • PD2 (ADC_IN2): เป็นได้ทั้ง ADC input (ex08) และ PWM output (ex01-ex07) — ใช้คนละเวลากัน

⚠️ จุดควรระวัง

  • ADC_SimpleInit() ต้องเรียกก่อน analogRead — ไม่เรียก = อ่านได้ 0 ตลอด
  • PD2 ใน ex08 ใช้เป็น ADC input ไม่ใช่ PWM output — ดูให้ดีว่าต่อ pot ไม่ใช่ LED
  • Delay_Ms(100) = 10Hz update — ถ้าต้องการเนียนลดเป็น 20-50ms
