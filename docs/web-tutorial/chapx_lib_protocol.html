🏭 โปรโตคอลอุตสาหกรรม 1 ชนิด — Modbus RTU (USART + DMA)

ระดับสูง

⏱️ ดูดัชนีทั้งหมดที่ 📦 คลังอุปกรณ์ — บทเรียนเต็ม: Modbus RTU Master

Modbus RTU Master — โปรโตคอลอุตสาหกรรม (USART + DMA)

PD5─TX ── RX (Slave)   PD6─RX ── TX (Slave)   GND──GND
RS-485: PD5─DI, PD6─RO ของ MAX485 ── A/B สาย 2 เส้น ── 120Ω จบสาย

รู้จักขา

  • TX (PD5): ส่งคำขอ Modbus [Addr][FC][Data][CRC] ไป slave
  • RX (PD6): รับ response จาก slave
  • DE/RE (PC0): ควบคุม MAX485 — 1=ส่ง 0=รับ (เฉพาะ RS-485)
  • GND: กราวด์ร่วม — จำเป็นเสมอ

วิธีต่อทีละขั้น

  1. ต่อ PD5 ไป RX ของ slave และ PD6 ไป TX — ไขว้กัน
  2. ต่อ GND ร่วม — เช็ค slave address + baud (9600 8N1)
  3. ระยะไกล: ต่อผ่าน MAX485 (A/B + 120Ω) — ควบคุม DE/RE ด้วย GPIO
MCU Pin→อุปกรณ์ขาหมายเหตุ
PD5→SlaveRXUSART1 TX → device RX
PD6←SlaveTXUSART1 RX ← device TX
GND→SlaveGNDGround ร่วม
PC0→MAX485DE+RE1=TX, 0=RX (ทางเลือก)
 
#include "Modbus.h"
Modbus mb;
uint16_t regs[10];

MODBUS_Init(&mb, 1, MODBUS_TRANSPORT_USART, USART_PINS_DEFAULT);
// โหมด DMA: เปลี่ยน MODBUS_TRANSPORT_USART → MODBUS_TRANSPORT_DMA

if (MODBUS_ReadHoldingRegisters(&mb, 0x0000, 10, regs) == MODBUS_OK) {
    // regs[0..9] — ค่าจาก slave (FC 0x03)
}
MODBUS_WriteSingleRegister(&mb, 0x0000, 1000);  // FC 0x06

⚠️ Master อย่างเดียว (9600 8N1) — 8 function codes (01/02/03/04/05/06/0F/10) — CRC-16 + timeout + exception — โหมด DMA: DMA_CH2 TX + DMA_CH3 RX circular + USART IDLE จับจบเฟรม — RAM ~1.3KB — ดูบทเรียนเต็ม ที่นี่

API หลัก

Modbus_Status MODBUS_Init(Modbus* mb, uint8_t slave_addr, Modbus_Transport transport, uint8_t pin_config);
Modbus_Status MODBUS_ReadHoldingRegisters(Modbus* mb, uint16_t reg, uint16_t count, uint16_t* data);
Modbus_Status MODBUS_ReadInputRegisters(Modbus* mb, uint16_t reg, uint16_t count, uint16_t* data);
Modbus_Status MODBUS_ReadCoils(Modbus* mb, uint16_t coil, uint16_t count, uint8_t* data);
Modbus_Status MODBUS_WriteSingleRegister(Modbus* mb, uint16_t reg, uint16_t value);
Modbus_Status MODBUS_WriteSingleCoil(Modbus* mb, uint16_t coil, uint8_t value);
Modbus_Status MODBUS_WriteMultipleRegisters(Modbus* mb, uint16_t reg, uint16_t count, const uint16_t* data);
Modbus_Status MODBUS_WriteMultipleCoils(Modbus* mb, uint16_t coil, uint16_t count, const uint8_t* data);
Modbus_Status MODBUS_GetLastError(Modbus* mb);
const char*   MODBUS_StatusStr(Modbus_Status status);

💡 MODBUS_Init เป็น step แรกเสมอ — ฟังก์ชันอ่าน/เขียนทุกตัว return Modbus_Status ตรวจ == MODBUS_OK — exception จาก slave อ่านได้ด้วย MODBUS_GetLastException
