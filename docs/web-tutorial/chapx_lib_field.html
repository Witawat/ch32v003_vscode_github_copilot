SoilMoisture_YL69 — Soil Moisture (ADC)

PC4(ADC)─AO  3.3V─VCC  GND─GND  (DO optional — digital threshold)
⚠️ ใช้ transistor switch VCC — เปิดเฉพาะตอนวัด ลด corrosion

รู้จักขา

  • AO (PC4): ขา output อนาล็อก ต่อ ADC
  • VCC (3.3V): จ่ายไฟ (ควรใช้ transistor switch ปิดเมื่อไม่วัด)
  • GND: กราวด์ร่วม

วิธีต่อทีละขั้น

  1. ต่อ PC4 ไป AO — อ่านค่าความชื้น
  2. ต่อ VCC ผ่าน transistor switch — เปิดเฉพาะตอนวัดลด corrosion
  3. ต่อ GND ไป GND
MCU Pin→อุปกรณ์ขาหมายเหตุ
PC4←Soil Moisture YL69AOAnalog output (ADC)
3.3V→Soil Moisture YL69VCCจ่ายไฟ (ใช้ transistor switch)
GND↔Soil Moisture YL69GNDกราวด์ร่วม
 
#include "SoilMoisture.h"
SoilMoisture_Init(ADC_CH_PC4);
uint16_t raw = SoilMoisture_ReadRaw();
float percent = SoilMoisture_ReadPercent(); // 0-100%
// Percent = map(raw, WET_VALUE, DRY_VALUE, 100, 0)
// Calibrate: WET = submerged in water, DRY = air → set limits

⚠️ Corrosion! อย่าเสียบ probe ทิ้งไว้ในดินตลอด → ใช้ transistor switch VCC (เปิดเฉพาะตอนวัด — ยืดอายุ probe), probe lifetime ~3-6 เดือนถ้าเปิดตลอด, capacitive probe ดีกว่า (ไม่เป็นสนิม) แต่แพงกว่า, calibrate เอง — WET_VALUE/DRY_VALUE ต่างกันตามชนิดดิน, DO pin = digital output (HIGH/LOW threshold ปรับด้วย potentiometer), resistance-based: ดินแห้ง = R สูง, ดินเปียก = R ต่ำ

API หลัก

SoilMoisture_Init(ch)Init ADC channelSoilMoisture_ReadRaw()Raw ADC (0-4095)
SoilMoisture_ReadPercent()0-100% (calibrated)SoilMoisture_SetWetDry(w, d)ตั้ง calibration
SoilMoisture_ReadDigital(pin)อ่าน DO thresholdSoilMoisture_GetStatus()Dry/Normal/Wet

FlameSensor_KY026 — Flame Detect (ADC+GPIO)

PC4(ADC)─AO  PC1─DO  3.3V─VCC  GND─GND
(IR photodiode — จับ IR จากเปลวไฟ 760-1100nm)

รู้จักขา

  • AO (PC4): ขา output อนาล็อก ต่อ ADC
  • DO (PC1): ขา digital บอกสถานะ (Active LOW = เจอเปลวไฟ)
  • VCC (3.3V): จ่ายไฟ
  • GND: กราวด์ร่วม

วิธีต่อทีละขั้น

  1. ต่อ PC4 ไป AO — อ่านค่าความเข้มเปลวไฟ
  2. ต่อ PC1 ไป DO — อ่านสถานะดิจิตอล
  3. ต่อ 3.3V ไป VCC และ GND ไป GND
MCU Pin→อุปกรณ์ขาหมายเหตุ
PC4←Flame Sensor KY026AOAnalog output (ADC)
PC1←Flame Sensor KY026DODigital threshold (Active LOW)
3.3V→Flame Sensor KY026VCCจ่ายไฟ 3.3V
GND↔Flame Sensor KY026GNDกราวด์ร่วม
 
#include "FlameSensor.h"
FlameSensor_Init(ADC_CH_PC4);
uint16_t raw = FlameSensor_ReadRaw();
// Digital threshold (potentiometer on module):
uint8_t flame = FlameSensor_ReadDigital(PC1); // 0 = flame detected
// Sensitivity: 760-1100nm (IR flame spectrum)

⚠️ Response time ~1ms, range ~1m (candle) at max sensitivity, angle ~60°, โดนแสงแดด → false trigger (ใช้ cover/บังแดด หรือ digital threshold), potentiometer บนโมดูลปรับ digital threshold, DO active LOW (=0 เมื่อ detect flame), range ขึ้นกับความแรงของเปลวไฟ (เทียน 20cm → ไฟใหญ่ 1-2m), ใช้คู่กับ MQ2 gas sensor เพิ่มความน่าเชื่อถือ

API หลัก

FlameSensor_Init(ch)Init ADCFlameSensor_ReadRaw()Raw ADC (ยิ่งไฟใกล้ = ต่ำ)
FlameSensor_ReadDigital(pin)อ่าน DO thresholdFlameSensor_ReadLux()แปลงเป็น lux (approx)

SoundSensor_KY038 — Sound/Clap (ADC+GPIO)

PC4(ADC)─AO  PC1─DO  3.3V─VCC  GND─GND
(electret mic + LM393 op-amp comparator)

รู้จักขา

  • AO (PC4): ขา output อนาล็อก ความดังของเสียง
  • DO (PC1): ขา digital (Active LOW = เสียงดังเกิน threshold)
  • VCC (3.3V): จ่ายไฟ
  • GND: กราวด์ร่วม

วิธีต่อทีละขั้น

  1. ต่อ PC4 ไป AO — อ่านระดับเสียง
  2. ต่อ PC1 ไป DO — อ่านสถานะ threshold
  3. ต่อ 3.3V ไป VCC และ GND ไป GND
MCU Pin→อุปกรณ์ขาหมายเหตุ
PC4←Sound Sensor KY038AOAnalog output (ADC)
PC1←Sound Sensor KY038DODigital threshold (Active LOW)
3.3V→Sound Sensor KY038VCCจ่ายไฟ 3.3V
GND↔Sound Sensor KY038GNDกราวด์ร่วม
 
#include "SoundSensor.h"
SoundSensor_Init(ADC_CH_PC4);
uint16_t level = SoundSensor_ReadLevel();
uint8_t clap = SoundSensor_ReadDigital(PC1); // 0 = sound above threshold
// Clap counter:
static uint8_t claps = 0;
if(!digitalRead(PC1)) { claps++; Delay_Ms(200); }
if(claps == 2) { USART_Println("Double clap!"); claps=0; }

⚠️ Electret mic on module → amplified by LM393 op-amp → comparator vs pot-adjusted threshold, analog AO = sound amplitude (loudness), digital DO = binary (sound > threshold → LOW), potentiometer ปรับ digital threshold (หมุนจน sensitivity พอดี), noisy environment → false trigger → ปรับ pot ใหม่, sound level ไม่ calibrated (แค่ relative), response ~1ms, ใช้ตรวจจับ clap, เสียงดัง, voice control พื้นฐาน

API หลัก

SoundSensor_Init(ch)Init ADCSoundSensor_ReadLevel()Sound level (0-4095)
SoundSensor_ReadDigital(pin)อ่าน DO thresholdSoundSensor_GetLevel()Quiet/Normal/Loud

RainSensor_YL83 — Rain Detect (ADC+GPIO)

PC4(ADC)─AO  PC1─DO  3.3V─VCC  GND─GND
⚠️ corrosion! — ใช้ transistor switch VCC, nickel/gold-plated probe ทนกว่า

รู้จักขา

  • AO (PC4): ขา analog ความเข้มของฝน (ยิ่งเปียกยิ่งค่าต่ำ)
  • DO (PC1): ขา digital (Active LOW = เจอฝน)
  • VCC (3.3V): จ่ายไฟ (ควรใช้ transistor switch)
  • GND: กราวด์ร่วม

วิธีต่อทีละขั้น

  1. ต่อ PC4 ไป AO — อ่านค่า
  2. ต่อ PC1 ไป DO — อ่านสถานะ
  3. ต่อ VCC ผ่าน transistor switch — เปิดเฉพาะตอนวัด
  4. ต่อ GND ร่วม
MCU Pin→อุปกรณ์ขาหมายเหตุ
PC4←Rain Sensor YL83AOAnalog output (ADC)
PC1←Rain Sensor YL83DODigital threshold (Active LOW)
3.3V→Rain Sensor YL83VCCจ่ายไฟ (ใช้ transistor switch)
GND↔Rain Sensor YL83GNDกราวด์ร่วม
 
#include "RainSensor.h"
RainSensor_Init(ADC_CH_PC4);
uint16_t raw = RainSensor_ReadRaw();         // low = wet, high = dry
float percent = RainSensor_ReadPercent();     // 100% = complete rain
uint8_t rain = RainSensor_ReadDigital(PC1);  // 0 = rain detected

⚠️ Corrosion (เหมือน soil moisture) — ใช้ transistor switch VCC, nickel/gold plated probe ทนกว่าแบบธรรมดา, ต่อ control board แยก (LM393 comparator) → กันน้ำ (control board วางในที่แห้ง), principle: น้ำลด resistance ระหว่าง probe tracks → analog voltage เปลี่ยน, DO = digital ทันทีที่ detect rain, ใช้คู่กับ servo ปิดฝาเมื่อฝนตก

API หลัก

RainSensor_Init(ch)Init ADCRainSensor_ReadRaw()Raw (ต่ำ=เปียก)
RainSensor_ReadPercent()0-100% rain intensityRainSensor_ReadDigital(pin)DO threshold
RainSensor_SetWetDry(w, d)Calibrate limitsRainSensor_GetStatus()NoRain/Drizzle/Rain/Heavy

WaterFlow_YFS201 — Flow Rate (GPIO)

PC1─Signal (pulse)  5V─VCC  GND─GND  (inline pipe)
⚠️ 5V signal → voltage divider 2.2k+3.3k for CH32V003
YF-S201 = 450 pulses/L, YF-S402 = 98 pulses/L

รู้จักขา

  • Signal (PC1): ขา output พัลส์ วัดอัตราการไหล
  • VCC (5V): จ่ายไฟ 5V
  • GND: กราวด์ร่วม

วิธีต่อทีละขั้น

  1. ต่อ PC1 ไป Signal ของ Water Flow (ผ่าน voltage divider 2.2k+3.3k)
  2. ต่อ 5V ไป VCC และ GND ไป GND
  3. ต่อเซนเซอร์เข้ากับท่อน้ำ inline
MCU Pin→อุปกรณ์ขาหมายเหตุ
PC1←Water Flow YF-S201SignalPulse output (interrupt)
5V→Water Flow YF-S201VCCจ่ายไฟ 5V
GND↔Water Flow YF-S201GNDกราวด์ร่วม
 
#include "WaterFlow.h"
WaterFlow_Init(PC1);
volatile uint32_t pulses = 0;
void flow_isr(void) { pulses++; }
attachInterrupt(PC1, flow_isr, FALLING);
while(1) {
    Delay_Ms(1000); // 1s window
    float lpm = WaterFlow_CalcFlow(pulses, 1000); // L/min
    float total_L = WaterFlow_CalcVolume(pulses);
    USART_PrintFloat(lpm, 1); USART_Println(" L/min");
    pulses = 0; // reset counter each interval
}

⚠️ 450 pulses/L (YF-S201), 98 pulses/L (YF-S402) — K-factor varies by model, min flow ~1 L/min (mechanically limits), 10ms pulse width @ 6L/min (จับทันด้วย interrupt), 5V signal → ใช้ voltage divider ลดเหลือ 3.3V, RISING หรือ FALLING edge, ใช้ในระบบน้ำเปิดตลอด: สะสม pulses → total_L += pulses / 450.0f, ระวัง air bubbles → pulse ปลอม

API หลัก

WaterFlow_Init(pin)Init GPIO inputWaterFlow_CalcFlow(pulses, ms)L/min
WaterFlow_CalcVolume(pulses)Total litreWaterFlow_SetKFactor(k)ตั้ง pulses/L
WaterFlow_ResetTotal()Clear total volumeWaterFlow_GetTotalLiters()ยอดสะสม (L)

HX711 — Load Cell 24-bit (GPIO)

PC0─SCK  PC1─DOUT  3.3V─VCC  GND─GND
Load Cell bridge: E+ = red, E- = black, A+ = green, A- = white
⚠️ Keep wires short, twisted pair — 24-bit noise-sensitive

รู้จักขา

  • SCK (PC0): ขา clock ส่งพัลส์อ่านข้อมูล
  • DOUT (PC1): ขา data บอกว่าพร้อมอ่าน / ส่งค่า 24-bit
  • VCC (3.3V): จ่ายไฟ
  • GND: กราวด์ร่วม
  • E+/E-: จ่ายไฟ bridge ของ load cell (แดง/ดำ)
  • A+/A-: รับสัญญาณ differential จาก load cell (เขียว/ขาว)

วิธีต่อทีละขั้น

  1. ต่อ PC0 ไป SCK และ PC1 ไป DOUT
  2. ต่อ 3.3V ไป VCC และ GND ไป GND
  3. ต่อ E+ (แดง) และ E- (ดำ) จ่ายไฟให้ load cell
  4. ต่อ A+ (เขียว) และ A- (ขาว) อ่านค่าน้ำหนัก
MCU Pin→อุปกรณ์ขาหมายเหตุ
PC0→HX711SCKSerial clock
PC1←HX711DOUTData ready / data out
3.3V→HX711VCCจ่ายไฟ 3.3V
GND↔HX711GNDกราวด์ร่วม
HX711 A+ / A−←Load CellSignal (Green/White)Differential input
HX711 E+ / E−→Load CellExcitation (Red/Black)จ่ายไฟ bridge
 
#include "HX711.h"
HX711_Init(PC0, PC1); // SCK, DOUT
HX711_SetGain(HX711_GAIN_128);
int32_t tare_offset;
// Tare: HX711_Tare(10); // average 10 readings = zero offset
// Calibrate:
float scale = 420.0f; // raw units per kg (หาโดยวางน้ำหนักรู้ค่า)
int32_t raw = HX711_Read();
float kg = (raw - tare_offset) / scale;
// Averaging: float avg = HX711_ReadAvg(5);

⚠️ 24-bit ADC → sensitive to noise → keep wires short, twisted pair (A+ with A-), gain 128 (channel A) หรือ 64 (channel B), data rate 10 SPS (default) หรือ 80 SPS, DOUT HIGH → data ready → SCK 25-27 pulses to read, tare ก่อนวัดทุกครั้ง (หรือเก็บ tare_offset หลัง calibrate), calibration: วางน้ำหนักรู้ค่า (เช่น 1kg) → scale = (raw - tare) / 1.0, power supply noise → ใช้ capacitor ที่ VCC, อย่าใช้ breadboard (noise)

API หลัก

HX711_Init(sck, dout)Init GPIO pinsHX711_Read()Single raw reading
HX711_ReadAvg(n)Average n readingsHX711_Tare(n)Zero/tare (n avg)
HX711_SetGain(g)GAIN_128/64/32HX711_SetRate(r)RATE_10HZ/80HZ
HX711_GetOffset()Read tare offsetHX711_SetOffset(off)Restore tare

เลือกยังไง? วัดความชื้นดิน → SoilMoisture (ใช้ switch VCC ลดสนิม), ตรวจจับไฟ → FlameSensor + MQ2 gas (dual confirm), ตรวจจับเสียงดัง → SoundSensor (clap switch), ตรวจจับฝน → RainSensor (>80% → ปิดหน้าต่าง servo), วัดอัตราการไหลน้ำ → WaterFlow (นับ pulse interrupt), วัดน้ำหนักแม่นยำ → HX711 (24-bit — ดีกว่า ADS1115 สำหรับ load cell โดยเฉพาะ)

✏️ ลองทำดู

  1. Smart plant pot — SoilMoisture วัดความชื้น → แห้งกว่า 30% → relay เปิดปั๊มน้ำ 3 วินาที → รอ 10 วินาที → วัดซ้ำ, แสดงสถานะบน OLED (%, pump on/off, last water)
  2. Water meter + daily log — YFS201 วัด flow rate + สะสมปริมาตร → OLED แสดง L/min + total L → บันทึกยอด daily ลง AT24Cxx EEPROM → export CSV ผ่าน USART
  3. Load cell scale — HX711 + LCD1602 แสดงน้ำหนักเป็นกรัม (0.1g res) → ปุ่ม tare + calibrate → LED แบ่ง zone (kg: <0.5, 0.5-1, >1)
  4. Weather combo — RainSensor (rain) + SoundSensor (thunder detect) → OLED dashboard → LINE alert (ESP01 WiFi) เมื่อ detect ทั้งคู่ → relay ปิดหน้าต่าง
  5. Fire alarm system — FlameSensor + MQ2 gas → buzzer + relay (sprinkler solenoid) → OLED แสดง flame level bar + gas PPM → log event time ลง EEPROM
