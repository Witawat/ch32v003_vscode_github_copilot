INA219 — V/A/W Monitor (I2C)

PC1─SDA  PC2─SCL  3.3V─VCC  GND─GND
VIN+ ── load+ ── Rshunt 0.1Ω ── VIN- ── load- ── GND
(High-side: วัดกระแสก่อน load — ปลอดภัยกว่า low-side)

รู้จักขา

  • SDA (PC1): สายข้อมูล I2C ไป INA219
  • SCL (PC2): สายนาฬิกา I2C
  • VCC (3.3V): จ่ายไฟเลี้ยง INA219
  • GND: กราวด์ร่วม
  • VIN+: ต่อด้าน load+ ก่อน shunt resistor 0.1Ω
  • VIN-: ต่อด้าน load- หลัง shunt resistor

วิธีต่อทีละขั้น

  1. ต่อ PC1 ไป SDA และ PC2 ไป SCL — I2C
  2. ต่อ 3.3V ไป VCC และ GND ไป GND — จ่ายไฟ
  3. ต่อ VIN+ เข้า load+ ผ่าน shunt 0.1Ω — วัดกระแส high-side
MCU Pin→อุปกรณ์ขาหมายเหตุ
PC1↔INA219SDAI2C data
PC2→INA219SCLI2C clock
3.3V→INA219VCCจ่ายไฟ 3.3V
GND↔INA219GNDกราวด์ร่วม
VIN+↔Load +Rshunt 0.1ΩHigh-side measurement
VIN-↔Load −Rshunt 0.1Ωวัด voltage drop ข้าม shunt
 
#include "INA219.h"
INA219_Init(0x40, INA219_32V_2A); // range เลือกตาม shunt
float voltage = INA219_GetBusVoltage();   // V
float current = INA219_GetCurrent();       // mA
float power   = INA219_GetPower();         // mW
// Calibrate: INA219_SetCalibration(shunt_resistance_ohm, max_current_A);

⚠️ 4 I2C addresses (0x40-0x4F via A0,A1 jumpers), shunt R = 0.1Ω (default), max V=32V, max I depends on shunt (0.1Ω → 3.2A), high-side measurement (ต่อ shunt ก่อน GND — อ่านทั้ง V bus และ voltage drop ข้าม shunt), PGA + 12-bit ADC ในตัว — แม่นกว่า ADC ทั่วไป, calibration: current_LSB = max_current / 32768, cal_value = 0.04096 / (current_LSB * Rshunt)

API หลัก

INA219_Init(addr, range)Init + ตั้ง rangeINA219_GetBusVoltage()อ่านแรงดัน V (bus)
INA219_GetCurrent()อ่านกระแส mAINA219_GetPower()อ่านกำลังไฟฟ้า mW
INA219_ReadShuntVoltage()Shunt voltage mVINA219_SetCalibration(r, maxA)เปลี่ยน shunt/range

ADS1115 — 16-bit ADC 4ch (I2C)

PC1─SDA  PC2─SCL  3.3V─VCC  GND─GND  A0-A3 ── signal inputs
ADDR─GND = 0x48, ADDR─VCC = 0x49, ADDR─SDA = 0x4A, ADDR─SCL = 0x4B

รู้จักขา

  • SDA (PC1): สายข้อมูล I2C
  • SCL (PC2): สายนาฬิกา I2C
  • VCC (3.3V): จ่ายไฟเลี้ยง ADS1115
  • GND: กราวด์ร่วม
  • A0–A3: ขา input สัญญาณอนาล็อก 4 ช่อง
  • ADDR: เลือก address I2C 0x48–0x4B

วิธีต่อทีละขั้น

  1. ต่อ PC1 ไป SDA และ PC2 ไป SCL — I2C
  2. ต่อ 3.3V ไป VCC และ GND ไป GND — จ่ายไฟ
  3. ต่อสัญญาณที่ต้องการวัดเข้า A0–A3 — อ่านค่า 16-bit
  4. ต่อ ADDR ลง GND/VCC/SDA/SCL เพื่อเลือก address
MCU Pin→อุปกรณ์ขาหมายเหตุ
PC1↔ADS1115SDAI2C data
PC2→ADS1115SCLI2C clock
3.3V→ADS1115VCCจ่ายไฟ 3.3V
GND↔ADS1115GNDกราวด์ร่วม
A0–A3←สัญญาณอนาล็อกAIN0–AIN34-ch single-ended / 2-ch differential
ADDR→ADS1115ADDRต่อ GND/VCC/SDA/SCL เลือก I2C addr
 
#include "ADS1115.h"
ADS1115_Init(0x48); // 0x48-0x4B via ADDR pin
ADS1115_SetGain(ADS1115_GAIN_1);      // ±4.096V (0.125mV/step)
ADS1115_SetRate(ADS1115_RATE_128SPS); // sample rate 8-860 SPS
// Single-ended:
int16_t val0 = ADS1115_ReadSingle(0);   // ch0
float volt = ADS1115_ToVoltage(val0);   // convert to voltage
// Differential: int16_t diff = ADS1115_ReadDifferential(0, 1); // ch0-ch1
// Continuous: ADS1115_StartContinuous(0); val=ADS1115_ReadContinuous();

⚠️ 4 addresses via ADDR pin (ต่อ GND/VCC/SDA/SCL), gain 1/2/4/8/16 (±4.096V down to ±0.256V), 16-bit signed (±32768), rate 8-860 SPS, continuous mode auto-read FIFO, ดีกว่า CH32V003 ADC ในตัว (10-bit → 16-bit, PGA, differential, comparator with alert pin), input multiplexer 4ch single-ended หรือ 2ch differential

API หลัก

ADS1115_Init(addr)Init ADCADS1115_ReadSingle(ch)Single-shot raw
ADS1115_ToVoltage(raw)Raw → VoltageADS1115_ReadDifferential(p, n)Diff input
ADS1115_SetGain(g)GAIN_1/2/4/8/16ADS1115_SetRate(r)8/16/32/64/128/250/475/860 SPS
ADS1115_StartContinuous(ch)เริ่ม continuousADS1115_ReadContinuous()อ่านล่าสุด

MCP4725 — 12-bit DAC (I2C)

PC1─SDA  PC2─SCL  3.3V─VCC  GND─GND  VOUT ── scope/load
(A0 pin — GND=0x60, VCC=0x61, SDA=0x62, SCL=0x63)

รู้จักขา

  • SDA (PC1): สายข้อมูล I2C
  • SCL (PC2): สายนาฬิกา I2C
  • VCC (3.3V): จ่ายไฟเลี้ยง MCP4725
  • GND: กราวด์ร่วม
  • VOUT: ขา output แรงดันอนาล็อก 0–3.3V (12-bit)
  • A0: เลือก address I2C 0x60–0x63

วิธีต่อทีละขั้น

  1. ต่อ PC1 ไป SDA และ PC2 ไป SCL — I2C
  2. ต่อ 3.3V ไป VCC และ GND ไป GND — จ่ายไฟ
  3. ต่อ VOUT ไปออสซิลโลสโคปหรือ load — ได้แรงดัน 0–3.3V
  4. ต่อ A0 เลือก address ให้ตรง
MCU Pin→อุปกรณ์ขาหมายเหตุ
PC1↔MCP4725SDAI2C data
PC2→MCP4725SCLI2C clock
3.3V→MCP4725VCCจ่ายไฟ 3.3V
GND↔MCP4725GNDกราวด์ร่วม
VOUT→Scope / LoadVOUTAnalog output 0–3.3V (12-bit)
A0→MCP4725A0ต่อ GND/VCC/SDA/SCL เลือก addr
 
#include "MCP4725.h"
MCP4725_Init(0x60); // 0x60-0x67 (A0 pin + factory bits)
MCP4725_SetVoltage(2048, MCP4725_VREF_VDD); // 2048/4096 = 1.65V (3.3V VDD)
// EEPROM save: MCP4725_SaveToEEPROM(2048); // จำค่าไว้หลัง power-off
// Waveform: for(int i=0; i<4096; i+=8) { MCP4725_FastWrite(i); Delay_Us(10); }

⚠️ 12-bit (0-4095), I2C addr 0x60-0x67 (A0 pin + factory bits), VREF = VDD (default) หรือ external 2.048V reference, EEPROM เก็บค่าได้ (ใช้เป็น setpoint memory — เปิดเครื่องค่าเดิม), fast write = 3 bytes I2C (เร็วกว่า normal write), output drive ~15mA (ไม่พอขับ motor → ใช้ op-amp buffer), rise time ~6µs, resolution = VREF/4096, waveform generation: ramp, sine, triangle

API หลัก

MCP4725_Init(addr)Init DACMCP4725_SetVoltage(val, vref)ตั้งแรงดัน output
MCP4725_SaveToEEPROM(val)เก็บค่าใน EEPROMMCP4725_FastWrite(val)Fast write (3 bytes)
MCP4725_SetVREF(ref)VDD / External 2.048VMCP4725_PowerDown(mode)ปิด output (1k/100k/500kΩ)

PZEM004T — AC Energy Meter (USART)

PD5(TX)─RX(PZEM)  PD6(RX)─TX(PZEM)  5V─VCC  GND─GND
CT clamp ⇛ live wire (แค่ 1 เส้น), voltage probe ⤏ socket L-N
⚡ 220VAC อันตราย! — ต่อเฉพาะเมื่อรู้วิธี

รู้จักขา

  • TX (PD5): ส่งข้อมูล USART ไป RX ของ PZEM (คำสั่ง Modbus)
  • RX (PD6): รับข้อมูล USART จาก TX ของ PZEM (ค่าที่วัดได้)
  • VCC (5V): จ่ายไฟ 5V ให้ PZEM004T
  • GND: กราวด์ร่วม
  • CT Clamp: คล้องสายไฟเส้นเดียว (L) เพื่อวัดกระแส AC
  • Voltage Probe: เสียบวัดแรงดันไฟบ้าน 220VAC

วิธีต่อทีละขั้น

  1. ต่อ PD5 ไป RX ของ PZEM — ส่งคำสั่ง Modbus
  2. ต่อ PD6 ไป TX ของ PZEM — รับค่าที่วัดได้
  3. ต่อ 5V ไป VCC และ GND ไป GND — จ่ายไฟ
  4. คล้อง CT clamp รอบสาย L เส้นเดียว — วัดกระแส
MCU Pin→อุปกรณ์ขาหมายเหตุ
PD5→PZEM004TRXUSART TX → device RX
PD6←PZEM004TTXUSART RX ← device TX
5V→PZEM004TVCCจ่ายไฟ 5V
GND↔PZEM004TGNDกราวด์ร่วม
CT Clamp←สายไฟ (Live)คล้องวัดกระแส AC แบบไม่ต้องตัดสาย
Voltage Probe←Socket L–NProbeวัดแรงดัน AC 220V
 
#include "PZEM004T.h"
PZEM004T_Init(USART1);
float v  = PZEM004T_ReadVoltage();       // V
float a  = PZEM004T_ReadCurrent();       // A
float w  = PZEM004T_ReadPower();         // W
float e  = PZEM004T_ReadEnergy();        // kWh
float f  = PZEM004T_ReadFrequency();     // Hz
float pf = PZEM004T_ReadPowerFactor();   // 0-1
// Set address: PZEM004T_SetAddress(0x01, 0x02); // เปลี่ยนจาก addr 1 → 2

⚠️ ⚡ 220VAC อันตราย — ถ้าไม่มั่นใจให้ใช้ USB power meter แทน, Modbus-RTU protocol (baud 9600 8N1), address 1-255 (default 1), CT clamp 100A, อ่านทีละ register (ใช้เวลา ~200ms/register), PZEM004T = TTL output (ต่อตรง CH32V003), PZEM004Tv1 = RS485 (ต้องใช้ MAX485 converter), ต่อผิดขั้ว CT → current = 0, เปิด USART1 → ใช้ร่วมกับ USART_Print ไม่ได้ (ต้องเปลี่ยนเป็น SoftUART print)

API หลัก

PZEM004T_Init(usart)Init USART 9600PZEM004T_ReadVoltage()อ่าน V (0.1V res)
PZEM004T_ReadCurrent()อ่าน A (0.001A res)PZEM004T_ReadPower()อ่าน W (0.1W res)
PZEM004T_ReadEnergy()อ่าน kWh (0.001kWh)PZEM004T_ReadFrequency()Hz
PZEM004T_ReadPowerFactor()PF 0-1 (0.01)PZEM004T_SetAddress(old, new)เปลี่ยน addr

PZEM004Tv3 — AC Energy Meter v3 (USART)

PD5(TX)─RX(PZEM)  PD6(RX)─TX(PZEM)  5V─VCC  GND─GND
(ต่อแบบเดียวกับ PZEM004T — ต่างที่ firmware protocol)

รู้จักขา

  • TX (PD5): ส่งข้อมูล USART ไป RX ของ PZEMv3
  • RX (PD6): รับข้อมูล USART จาก TX ของ PZEMv3
  • VCC (5V): จ่ายไฟ 5V
  • GND: กราวด์ร่วม
  • CT Clamp: คล้องสาย L วัดกระแส AC
  • Voltage Probe: เสียบวัดแรงดัน 220VAC

วิธีต่อทีละขั้น

  1. ต่อ PD5 ไป RX ของ PZEMv3 — ส่งคำสั่ง
  2. ต่อ PD6 ไป TX ของ PZEMv3 — รับค่า
  3. ต่อ 5V ไป VCC และ GND ไป GND — จ่ายไฟ
  4. คล้อง CT clamp รอบสาย L — วัดกระแส
MCU Pin→อุปกรณ์ขาหมายเหตุ
PD5→PZEM004Tv3RXUSART TX → device RX
PD6←PZEM004Tv3TXUSART RX ← device TX
5V→PZEM004Tv3VCCจ่ายไฟ 5V
GND↔PZEM004Tv3GNDกราวด์ร่วม
CT Clamp←สายไฟ (Live)คล้องวัดกระแส AC แบบไม่ต้องตัดสาย
Voltage Probe←Socket L–NProbeวัดแรงดัน AC 220V
 
#include "PZEM004Tv3.h"
PZEM004Tv3_Init(USART1, 3); // address=3
PZEM004Tv3_Data_t data;
if(PZEM004Tv3_ReadAll(&data)) {
    USART_PrintFloat(data.voltage, 1); USART_Print("V ");
    USART_PrintFloat(data.current, 2); USART_Print("A ");
    USART_PrintFloat(data.power, 1); USART_Println("W");
}
// Alarms: PZEM004Tv3_SetAlarm(PZEM_ALARM_VOLT_HIGH, 250.0f);

⚠️ v3 ใช้ protocol ใหม่ (ต่างจาก v1 — ห้ามใช้ PZEM004T.h), มี register alarms (over-voltage, over-current, over-power), direct TTL (5V — ใช้ voltage divider RX), รวมทุก register ใน 1 request → เร็วกว่า v1 (ไม่ต้อง request ทีละตัว), response time ~80ms (ทั้งหมด), ต้องใช้ PZEM004Tv3.h เท่านั้น (ไม่ compatible กับ PZEM004T.h), baud ยัง 9600 8N1

PZEM004Tv3_ReadVoltage()อ่านเฉพาะ VPZEM004Tv3_ReadPower()อ่านเฉพาะ W
PZEM004Tv3_SetAlarm(type, val)ตั้งค่า alarmPZEM004Tv3_GetAlarm(type)อ่าน alarm status

OH49E — Hall Effect Sensor (ADC)

3.3V─VCC  GND─GND  PC4(ADC)─OUT
(ใช้แม่เหล็กถาวร — ขั้วเหนือ/ใต้ให้ผลลัพธ์ตรงข้าม)

รู้จักขา

  • OUT (PC4): ขา output อนาล็อก ต่อเข้า ADC ของ MCU
  • VCC (3.3V): จ่ายไฟ 3.3V
  • GND: กราวด์ร่วม

วิธีต่อทีละขั้น

  1. ต่อ 3.3V ไป VCC และ GND ไป GND — จ่ายไฟ
  2. ต่อ PC4 ไป OUT ของ OH49E — อ่านค่า ADC วัดสนามแม่เหล็ก
MCU Pin→อุปกรณ์ขาหมายเหตุ
PC4←OH49EOUTAnalog output (ADC)
3.3V→OH49EVCCจ่ายไฟ 3.3V
GND↔OH49EGNDกราวด์ร่วม
 
ADC_SimpleInit();
uint16_t raw = analogRead(PC4);
float voltage = ADC_ToVoltage(raw, 3.3f);
// Output ~2.5V at zero field (quiescent), ↑ with South pole, ↓ with North pole
// Sensitivity: ~1.4mV/Gauss (typical)

⚠️ Ratiometric — Vout changes with VCC (ใช้ ADC_ToVoltage ชดเชย), output 0-5V range → CH32V003 ADC 3.3V max (วัดได้เฉพาะ 0-3.3V → lost range เหนือ 3.3V), ใช้กับแม่เหล็กถาวร, ไม่บอกขั้วโดยตรง (แค่ analog voltage เปลี่ยน), non-latching (magnet หาย → กลับ 2.5V), linear output proportional to magnetic field, อ่านง่าย (ADC อย่างเดียว) — ไม่ต้อง protocol ซับซ้อน

API หลัก

ADC_SimpleInit()Init ADCanalogRead(pin)อ่าน raw ADC
ADC_ToVoltage(raw, vref)Raw → VoltageADC_ToGauss(voltage)Voltage → Gauss

เลือกยังไง? วัด DC power → INA219, ต้องการ ADC แม่นสูง 4 channels → ADS1115, สร้าง analog waveform → MCP4725, วัดไฟบ้าน 220V → PZEM004Tv3 (เร็วกว่า), ตรวจจับแม่เหล็กถูกๆ → OH49E, อ่านค่าแบบไม่ต้อง calibrate → PZEM004Tv3

✏️ ลองทำดู

  1. INA219 battery fuel gauge — วัด V+I ทุก 1s → คำนวณ mAh ใช้ไป, แสดง % แบตคงเหลือบน OLED, ส่ง serial log เป็น CSV
  2. ADS1115 load cell reader — 4-wire bridge (differential mode) → calibrate ด้วยลูกตุ้มน้ำหนักรู้ค่า → แสดงน้ำหนักเป็นกรัมบน LCD 16x2
  3. MCP4725 function generator — สร้าง sine wave 10Hz (4096 samples/cycle), รับความถี่จาก rotary encoder, แสดง wave บน OLED
  4. PZEM004Tv3 power monitor — ทำ dashboard บน OLED: V, A, W, kWh, PF, Hz, พร้อม log ทุก 5 วินาทีลง EEPROM (AT24Cxx) เก็บสถิติรายวัน
  5. OH49E RPM counter — วางแม่เหล็กบนล้อหมุน, วัดจำนวน pulse/sec → นับรอบ, แสดง RPM บน TM1637, ทำ tachometer แบบง่าย
