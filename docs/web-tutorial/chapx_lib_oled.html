OLED SSD1306 — จอกราฟิก 128×64 I2C

ระดับกลาง

🧭 แผนภาพการทำงาน

flowchart TD
    A["I2C_SimpleInit()"] --> B["OLED_Init(&oled, OLED_128x64, 0x3C)"]
    B --> C["OLED_Clear(&oled)"]
    C --> D["OLED_SetFont + OLED_DrawStringAlign"]
    D --> E["OLED_Update(&oled)"]
    E --> F["while(1) loop"]
    F --> D

🔌 การต่อวงจร

          OLED SSD1306 128x64 I2C (0x3C)
    ┌────────────────────────────────┐
    │ MCU                      OLED  │
    │ 3.3V ─────────────── VCC      │
    │ GND  ─────────────── GND      │
    │ PC1  ─────────────── SDA      │
    │ PC2  ─────────────── SCL      │
    │                 (pull-up 4.7k)│
    └────────────────────────────────┘
MCU Pin→อุปกรณ์ขาหมายเหตุ
PC1↔SDA-สายข้อมูล I2C — ต้องมี R 4.7kΩ pull-up ไป 3.3V
PC2↔SCL-สายนาฬิกา I2C — ต้องมี R 4.7kΩ pull-up ไป 3.3V
3.3V→VCC-ไฟเลี้ยง 3.3V; I2C addr 0x3C หรือ 0x3D
GND→GND-กราวด์ร่วม

ใช้ I2C address 0x3C (ค่าเริ่มต้น) — บางโมดูลใช้ 0x3D ให้ตรวจสอบด้วย I2C_Scan() ก่อน

📚 หลักการทำงาน

Buffer-based Graphics: OLED_Init() จอง RAM buffer ขนาด (width × height) / 8 ไบต์ — สำหรับ 128×64 = 1,024 ไบต์ (1KB) การวาดทั้งหมดทำใน buffer ก่อน แล้วเรียก OLED_Update() ส่งทั้งจอไปที่ SSD1306 ผ่าน I2C

Pipeline: Clear → Draw → Update: ทุกเฟรมเริ่มด้วย Clear() ล้าง buffer → วาดข้อความ/รูปทรงด้วยฟังก์ชันต่างๆ → สั่ง Update() เพื่อส่งข้อมูล I2C ขึ้นจอ การแยกขั้นตอนทำให้วาดหลายอย่างก่อนแสดงผลครั้งเดียว ลด flicker

Font System: รองรับฟอนต์ 6×8 และ 8×16 — เปลี่ยนได้ด้วย OLED_SetFont() ระบบ font จัดเก็บเป็น bitmap ใน Flash ROM — ใช้ OLED_DrawStringAlign() สำหรับจัดตำแหน่งข้อความแบบซ้าย/กลาง/ขวา

Graphic Primitives: OLED_SetPixel, OLED_DrawLine, OLED_DrawRect, OLED_DrawCircle — ทุกอย่างทำงานบน buffer ก่อน ใช้ algorithm ของ Bresenham สำหรับเส้นและวงกลม

💻 เขียน Code ทีละขั้น

ขั้นที่ 1: Init + Setup

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "oled_i2c.h"
#include "oled_graphics.h"
#include "oled_fonts.h"

OLED_Handle oled;

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    I2C_SimpleInit(I2C_SPEED_400K, I2C_PINS_DEFAULT);

    OLED_Init(&oled, OLED_128x64, 0x3C);
    OLED_Clear(&oled);
    OLED_SetFont(&oled, FONT_8x16);

🔍 เริ่มต้นระบบด้วย I2C ความเร็ว 400kHz — OLED_Init() รับ size ก่อน address (OLED_128x64, 0x3C) — มี OLED_128x32 และ OLED_96x16 ด้วย — ตามด้วย Clear ล้าง buffer

ขั้นที่ 2: วาดข้อความและรูปทรง

    OLED_SetFont(&oled, FONT_6x8);
    OLED_DrawStringAlign(&oled, 0, 0, "สวัสดี!", ALIGN_LEFT);
    OLED_SetFont(&oled, FONT_8x16);
    OLED_DrawStringAlign(&oled, 20, 0, "CH32V003", ALIGN_LEFT);

    OLED_DrawRect(&oled, 10, 10, 50, 30);
    OLED_DrawCircle(&oled, 100, 50, 15);
    OLED_DrawLine(&oled, 0, 63, 127, 63);

    OLED_Update(&oled);

🔍 OLED_DrawStringAlign รับพิกัด (x,y) แบบ pixel พร้อม alignment (ALIGN_LEFT/CENTER/RIGHT) — DrawRect/DrawCircle/DrawLine ทำงานบน buffer — อย่าลืม OLED_Update() ส่งข้อมูลขึ้นจอ!

ขั้นที่ 3: Loop + อัปเดตข้อมูล

    Timer_t tmr;
    Start_Timer(&tmr, 2000, 1);
    int count = 0;
    char buf[16];

    while(1) {
        if(Is_Timer_Expired(&tmr)) {
            OLED_Clear(&oled);
            SimpleHAL_Sprintf(buf, "Count: %d", count);
            OLED_SetFont(&oled, FONT_8x16);
            OLED_DrawStringAlign(&oled, 20, 0, buf, ALIGN_LEFT);
            OLED_Update(&oled);
            count++;
        }
    }
}

🔍 ใช้ Non-Blocking Timer อัปเดตทุก 2 วินาที — Clear() + DrawStringAlign() + Update() เป็น pattern มาตรฐาน — ใช้ sprintf สร้างข้อความพร้อมตัวเลข — loop ไม่เคยหยุดรอ

⚠️ ข้อผิดพลาดที่พบบ่อย

ปัญหาสาเหตุวิธีแก้
จอไม่ติด / ดำสนิทI2C address ผิด (0x3C vs 0x3D)ใช้ I2C_Scan() สแกนหา address ที่ถูกต้อง
ตัวหนังสือไม่ขึ้นลืมเรียก OLED_Update() หลังวาดต้องเรียก Update() ทุกครั้งที่ต้องการให้ข้อมูลแสดงบนจอ
RAM ไม่พอ (compile error)OLED buffer 128x64 = 1KB — CH32V003 มี RAM แค่ 2KBลดขนาดเหลือ OLED_128x32 (512B) หรือ OLED_96x16 (192B)
จอ flicker / กระพริบเรียก OLED_Update() บ่อยเกินไปควรเรียก Update() ไม่เกิน 20fps — ใช้ Timer ควบคุม
ข้อความภาษาไทยไม่แสดงใช้ฟอนต์ที่ไม่มี glyph ไทย หรือไฟล์ .c ไม่ includeใช้ FONT_8x16 และ include font_thai.h ถูกต้อง

🛠️ สร้าง Product: นาฬิกาดิจิทัล OLED + DS3231

แสดงเวลาและวันที่ภาษาไทยบน OLED 128x64 ด้วย DS3231 RTC ผ่าน I2C — ใช้ Non-Blocking Timer อัปเดตทุก 1 วินาที

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "oled_i2c.h"
#include "oled_graphics.h"
#include "oled_fonts.h"

OLED_Handle oled;
RTC_DS3231_t rtc;

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    I2C_SimpleInit(I2C_SPEED_400K, I2C_PINS_DEFAULT);

    OLED_Init(&oled, OLED_128x64, 0x3C);
    OLED_SetFont(&oled, FONT_8x16);

    if(DS3231_Init(&rtc) != DS3231_OK) {
        OLED_Clear(&oled);
        OLED_DrawStringAlign(&oled, 0, 24, "RTC Error!", ALIGN_CENTER);
        OLED_Update(&oled);
        while(1);
    }

    Timer_t tmr;
    Start_Timer(&tmr, 1000, 1);
    char buf[32];

    while(1) {
        if(Is_Timer_Expired(&tmr)) {
            RTC_DateTime_t dt;
            DS3231_GetDateTime(&rtc, &dt);

            OLED_Clear(&oled);
            SimpleHAL_Sprintf(buf, "%02d:%02d:%02d", dt.hour, dt.minute, dt.second);
            OLED_DrawStringAlign(&oled, 10, 0, buf, ALIGN_CENTER);

            SimpleHAL_Sprintf(buf, "%02d/%02d/%04d", dt.day, dt.month, dt.year);
            OLED_DrawStringAlign(&oled, 48, 0, buf, ALIGN_CENTER);

            OLED_Update(&oled);
        }
    }
}
