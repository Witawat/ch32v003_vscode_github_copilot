OLED SSD1306 — จอกราฟิก 128×64 I2C

ระดับกลาง

🧭 แผนภาพการทำงาน

flowchart TD
    A["I2C_SimpleInit()"] --> B["OLED_Init(&oled, OLED_128x64, 0x3C)"]
    B --> C["OLED_Clear(&oled)"]
    C --> D["OLED_SetCursor + Drawing"]
    D --> E["OLED_Update(&oled)"]
    E --> F["while(1) loop"]
    F --> D

🔌 การต่อวงจร

          OLED SSD1306 128x64 I2C (0x3C)
    ┌────────────────────────────────┐
    │ MCU                      OLED  │
    │ 3.3V ─────────────── VCC      │
    │ GND  ─────────────── GND      │
    │ PC1  ─────────────── SDA      │
    │ PC2  ─────────────── SCL      │
    │                 (pull-up 4.7k)│
    └────────────────────────────────┘

ใช้ I2C address 0x3C (ค่าเริ่มต้น) — บางโมดูลใช้ 0x3D ให้ตรวจสอบด้วย I2C_Scan() ก่อน

📚 หลักการทำงาน

Buffer-based Graphics: OLED_Init() จอง RAM buffer ขนาด (width × height) / 8 ไบต์ — สำหรับ 128×64 = 1,024 ไบต์ (1KB) การวาดทั้งหมดทำใน buffer ก่อน แล้วเรียก OLED_Display() ส่งทั้งจอไปที่ SSD1306 ผ่าน I2C

Pipeline: Clear → Draw → Display: ทุกเฟรมเริ่มด้วย Clear() ล้าง buffer → วาดข้อความ/รูปทรงด้วยฟังก์ชันต่างๆ → สั่ง Display() เพื่อส่งข้อมูล I2C ขึ้นจอ การแยกขั้นตอนทำให้วาดหลายอย่างก่อนแสดงผลครั้งเดียว ลด flicker

Font System: รองรับฟอนต์ 6×8 (small) และ 8×16 (normal/bold) — เปลี่ยนได้ด้วย OLED_SetFont() ระบบ font จัดเก็บเป็น bitmap ใน Flash ROM — รองรับอักขระ UTF-8 ภาษาไทย

Graphic Primitives: DrawPixel, DrawLine, DrawRect (filled/unfilled), DrawCircle — ทุกอย่างทำงานบน buffer ก่อน ใช้ algorithm ของ Bresenham สำหรับเส้นและวงกลม

💻 เขียน Code ทีละขั้น

ขั้นที่ 1: Init + Setup

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "oled_i2c.h"`n#include "oled_graphics.h"

OLED_Handle oled;

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    I2C_SimpleInit(I2C_SPEED_400K, I2C_PINS_DEFAULT);

    OLED_Init(&oled, OLED_128x64, 0x3C);
    OLED_Clear(&oled);
    OLED_SetFont(&oled, FONT_8x16);

🔍 เริ่มต้นระบบด้วย I2C ความเร็ว 400kHz — OLED_Init() รับ address 0x3C และขนาดจอ OLED_128x64 (มี OLED_128x32 และ OLED_96x16 ด้วย) — ตามด้วย Clear ล้าง buffer

ขั้นที่ 2: วาดข้อความและรูปทรง

    OLED_SetCursor(&oled, 0, 0);
    OLED_Print(&oled, "สวัสดี!");
    OLED_SetCursor(&oled, 1, 0);
    OLED_Print(&oled, "CH32V003");

    OLED_DrawRect(&oled, 10, 10, 50, 30, 1);
    OLED_DrawCircle(&oled, 100, 50, 15, 1);
    OLED_DrawLine(&oled, 0, 63, 127, 0, 1);

    OLED_Update(&oled);

🔍 SetCursor กำหนดแถว-คอลัมน์ (row, col) สำหรับข้อความ — Print() รองรับ UTF-8 ภาษาไทยโดยตรง — DrawRect/DrawCircle/DrawLine พารามิเตอร์สุดท้ายคือ color (1=ขาว, 0=ลบ) — อย่าลืม OLED_Display() ส่งข้อมูลขึ้นจอ!

ขั้นที่ 3: Loop + อัปเดตข้อมูล

    Timer_t tmr;
    Start_Timer(&tmr, 2000, 1);
    int count = 0;

    while(1) {
        if(Is_Timer_Expired(&tmr)) {
            OLED_Clear(&oled);
            OLED_SetCursor(&oled, 2, 0);
            OLED_Print(&oled, "Count: ");
            OLED_PrintNum(&oled, count);
            OLED_Update(&oled);
            count++;
        }
    }
}

🔍 ใช้ Non-Blocking Timer อัปเดตทุก 2 วินาที — Clear() + Print() + Display() เป็น pattern มาตรฐาน — OLED_PrintNum() แสดงตัวเลข — loop ไม่เคยหยุดรอ

⚠️ ข้อผิดพลาดที่พบบ่อย

ปัญหาสาเหตุวิธีแก้
จอไม่ติด / ดำสนิทI2C address ผิด (0x3C vs 0x3D)ใช้ I2C_Scan() สแกนหา address ที่ถูกต้อง
ตัวหนังสือไม่ขึ้นลืมเรียก OLED_Display() หลังวาดต้องเรียก Display() ทุกครั้งที่ต้องการให้ข้อมูลแสดงบนจอ
RAM ไม่พอ (compile error)OLED buffer 128x64 = 1KB — CH32V003 มี RAM แค่ 2KBลดขนาดเหลือ OLED_128x32 (512B) หรือ OLED_96x16 (192B)
จอ flicker / กระพริบเรียก OLED_Display() บ่อยเกินไปควรเรียก Display() ไม่เกิน 20fps — ใช้ Timer ควบคุม
ข้อความภาษาไทยไม่แสดงใช้ฟอนต์ที่ไม่มี glyph ไทย หรือไฟล์ .c ไม่ includeใช้ FONT_8x16 และ include font_thai.h ถูกต้อง

🛠️ สร้าง Product: นาฬิกาดิจิทัล OLED + DS3231

แสดงเวลาและวันที่ภาษาไทยบน OLED 128x64 ด้วย DS3231 RTC ผ่าน I2C — ใช้ Non-Blocking Timer อัปเดตทุก 1 วินาที

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "oled_i2c.h"`n#include "oled_graphics.h"

OLED_Handle oled;
RTC_DS3231_t rtc;

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    I2C_SimpleInit(I2C_SPEED_400K, I2C_PINS_DEFAULT);

    OLED_Init(&oled, OLED_128x64, 0x3C);
    OLED_SetFont(&oled, FONT_8x16);

    if(DS3231_Init(&rtc) != DS3231_OK) {
        OLED_Clear(&oled);
        OLED_SetCursor(&oled, 3, 0);
        OLED_Print(&oled, "RTC Error!");
        OLED_Update(&oled);
        while(1);
    }

    Timer_t tmr;
    Start_Timer(&tmr, 1000, 1);

    while(1) {
        if(Is_Timer_Expired(&tmr)) {
            RTC_DateTime_t dt;
            DS3231_GetDateTime(&rtc, &dt);

            OLED_Clear(&oled);
            OLED_SetCursor(&oled, 1, 2);
            OLED_PrintNumZero(&oled, dt.hour, 2);
            OLED_Print(&oled, ":");
            OLED_PrintNumZero(&oled, dt.minute, 2);
            OLED_Print(&oled, ":");
            OLED_PrintNumZero(&oled, dt.second, 2);

            OLED_SetCursor(&oled, 3, 1);
            OLED_PrintNumZero(&oled, dt.day, 2);
            OLED_Print(&oled, "/");
            OLED_PrintNumZero(&oled, dt.month, 2);
            OLED_Print(&oled, "/");
            OLED_PrintNum(&oled, dt.year);

            OLED_Update(&oled);
        }
    }
}
