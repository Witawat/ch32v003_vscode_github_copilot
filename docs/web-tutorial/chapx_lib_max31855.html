MAX31855/MAX6675 — Thermocouple K-Type SPI

└────────────────────────────────────┘

SPI mode 0 — MAX31855 อ่าน 32-bit (14-bit TC + 12-bit CJ + fault), MAX6675 อ่าน 16-bit (12-bit TC) — ห้ามใช้ SOP-8 (ไม่มี SPI pin)

📚 หลักการทำงาน

Thermocouple K-Type: วัดอุณหภูมิจากแรงดัน mV ที่เกิดขึ้นระหว่างโลหะ 2 ชนิด (Chromel-Alumel) — ช่วงกว้างมาก -270°C ถึง +1372°C

Cold-Junction Compensation (CJC): ฝังในชิป — วัดอุณหภูมิที่ขั้วต่อ PCB แล้วชดเชยอัตโนมัติ — ไม่ต้องใช้ lookup table

ไม่ต้องใช้ ADC: MAX31855/MAX6675 อ่านแรงดัน mV โดยตรงจาก thermocouple — มี internal ADC 14-bit (MAX31855) หรือ 12-bit (MAX6675)

MAX31855: 32-bit frame — thermocouple temp (14-bit) + internal/cold-junction temp (12-bit) + fault bits (OC/SCG/SCV) — range -270°C ถึง +1372°C, accuracy ±2°C

MAX6675: 16-bit frame — thermocouple temp (12-bit) — range 0°C ถึง 1024°C, accuracy ±3°C, ถูกกว่าและง่ายกว่า MAX31855

Fault Detection: OC = thermocouple หลุด (open circuit), SCG = short to GND, SCV = short to VCC — MAX31855 เท่านั้น

💻 เขียน Code ทีละขั้น

ขั้นที่ 1: Init SPI + MAX31855

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "MAX31855.h"

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    SPI_SimpleInit(SPI_MODE0, SPI_SPEED_1M, SPI_PINS_DEFAULT);

    MAX31855_Init(PC4);       // CS pin
    USART_Println("MAX31855 Ready!");

🔍 SPI_SimpleInit(SPI_MODE0, ...) — MAX31855/MAX6675 ใช้ SPI mode 0 (CPOL=0, CPHA=0), MAX31855_Init(CS_PIN) กำหนด chip-select — เลือกขาไหนก็ได้

ขั้นที่ 2: อ่าน Thermocouple + Cold-Junction + Fault

    float tc = MAX31855_ReadCelsius();     // thermocouple temp
    float cj = MAX31855_ReadInternal();     // cold-junction temp
    uint8_t fault = MAX31855_ReadFault();   // 0=OK, bit0=OC, bit1=SCG, bit2=SCV

    USART_Print("TC: "); USART_PrintFloat(tc, 1);
    USART_Print("C  CJ: "); USART_PrintFloat(cj, 1);
    USART_Print("C  Fault: "); USART_PrintNum(fault);
    USART_Println();

    if(fault & 0x01) USART_Println("⚠️ Open Circuit!");
    if(fault & 0x02) USART_Println("⚠️ Short to GND!");
    if(fault & 0x04) USART_Println("⚠️ Short to VCC!");

🔍 ReadFault() ตรวจสอบ fault — bit0=OC (thermocouple หลุด), bit1=SCG (ช็อต GND), bit2=SCV (ช็อต VCC) — มีเฉพาะ MAX31855, MAX6675 ไม่มี fault detection

ขั้นที่ 3: Loop + MAX6675 variant

    Timer_t tmr;
    Start_Timer(&tmr, 500, 1);

    while(1) {
        if(Is_Timer_Expired(&tmr)) {
            float tc = MAX31855_ReadCelsius();
            float cj = MAX31855_ReadInternal();
            uint8_t fault = MAX31855_ReadFault();

            if(fault == 0) {
                USART_Print("TC: "); USART_PrintFloat(tc, 1);
                USART_Print("°C (CJ:"); USART_PrintFloat(cj, 1);
                USART_Println("°C)");
            } else {
                USART_Print("Fault: "); USART_PrintNum(fault);
                USART_Println(" — Check Thermocouple!");
            }
        }
        IWDG_Feed();
    }
}

⚠️ ข้อผิดพลาดที่พบบ่อย

ปัญหาสาเหตุวิธีแก้
อ่านได้ค่า ~0°C ตลอดต่อ thermocouple ผิดขั้ว — T+ กับ T- สลับกันK-Type: สีเหลือง → T+, สีแดง → T- — ถ้าสลับอุณหภูมิจะกลับทิศ
MAX31855 Fault bit 0 (OC) ตลอดThermocouple ขาด หรือต่อไม่แน่นเช็คขั้วต่อ — thermocouple ต้องเชื่อมกับขั้วสกรูของ MAX31855 ให้แน่น
ใช้กับ SOP-8 Package ไม่ได้ — ไม่มี SPIMAX31855 SOP-8 มีแต่ analog I/O ไม่มี SPIต้องใช้ SOP-16 หรือ QFN package ที่มี SPI — เช็ค datasheet package
อุณหภูมิกระโดด ±10°C ระหว่างอ่านNoise coupling บน thermocouple wire — สายยาวหรือใกล้มอเตอร์ใช้ twisted-pair thermocouple wire, ใส่ ferrite bead, ใช้ averaging 4-8 ครั้ง
MAX6675 อ่านไม่ออก — คืน 0MAX6675 ใช้ 16-bit SPI — mode 1 (ไม่ใช่ mode 0)MAX6675 ใช้ SPI mode 1 (CPOL=0, CPHA=1) — ต่างจาก MAX31855 ที่ใช้ mode 0

🛠️ สร้าง Product: เครื่องวัดอุณหภูมิเตาเผา K-Type

MAX31855 + OLED — แสดงอุณหภูมิ real-time + fault warning

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "MAX31855.h"
#include "oled_i2c.h"

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    SPI_SimpleInit(SPI_MODE0, SPI_SPEED_1M, SPI_PINS_DEFAULT);

    MAX31855_Init(PC4);

    OLED_Handle oled;
    OLED_Init(&oled, OLED_128x64, 0x3C);
    OLED_SetFont(&oled, FONT_8x16);

    Timer_t tmr;
    Start_Timer(&tmr, 500, 1);

    while(1) {
        if(Is_Timer_Expired(&tmr)) {
            float tc = MAX31855_ReadCelsius();
            float cj = MAX31855_ReadInternal();
            uint8_t fault = MAX31855_ReadFault();

            OLED_Clear(&oled);
            if(fault == 0) {
                OLED_SetCursor(&oled, 0, 0);
                OLED_PrintFloat(&oled, "TC:", tc, 1); OLED_Print(&oled, " C");
                OLED_SetCursor(&oled, 0, 2);
                OLED_PrintFloat(&oled, "CJ:", cj, 1); OLED_Print(&oled, " C");
            } else {
                OLED_SetCursor(&oled, 0, 1);
                OLED_Print(&oled, "FAULT! Check");
                OLED_SetCursor(&oled, 0, 2);
                OLED_Print(&oled, "Thermocouple!");
            }
            OLED_Update(&oled);
        }
        IWDG_Feed();
    }
}

✏️ ลองทำดู

  1. วัดอุณหภูมิหัวแร้งบัดกรี — แตะ thermocouple ที่ tip หัวแร้ง — สังเกต response time (fast!)
  2. ทดลองสลับขั้ว T+ / T- — ดูว่าอุณหภูมิกลับทิศ — ทำความเข้าใจ thermocouple polarity
  3. ทำ PID Temperature Controller — MAX31855 + Relay/SSR — ควบคุมอุณหภูมิเตาเผาให้คงที่
  4. เทียบ MAX31855 vs MAX6675 — ต่อบน SPI บัสเดียวกัน (คนละ CS) — สังเกต accuracy และ fault detection
