ทุก task ใช้ทรัพยากรร่วมกันหมด — ไม่มี preemption — แต่ละ task ต้องรีบทำงานแล้ว return — ถ้า task ไหนบล็อก (Delay) task อื่นจะอดทำงาน

📚 หลักการทำงาน

Cooperative Multitasking: ต่างจาก RTOS แบบ preemptive — ไม่มีการขัดจังหวะกลางคัน — แต่ละ task ต้อง "ให้ความร่วมมือ" โดยการ return เร็ว — ถ้า task ไหนใช้เวลานาน task อื่นจะ delay

8 Tasks Max: scheduler รองรับสูงสุด 8 tasks — เพียงพอสำหรับระบบฝังตัวส่วนใหญ่ — task 0-7 — เพิ่ม task ได้ด้วย Scheduler_AddTask() ก่อน Scheduler_Start()

Interval-Based: แต่ละ task มี interval ของตัวเอง — scheduler จะเรียก task เมื่อถึงเวลา — ไม่จำเป็นต้องเท่ากัน — เช่น sensor=2000ms, display=500ms, button=50ms

AddTask → Run → Yield Pattern: ลงทะเบียน task function + interval — scheduler จะวนเรียกตามลำดับ — task ทำงานเสร็จแล้ว return — scheduler จับเวลารอบถัดไป — ไม่มี stack switching แบบ RTOS (lightweight มาก)

ข้อจำกัด: ไม่เหมาะกับ task ที่ใช้เวลานาน (>interval) — ถ้า task 1 ใช้ 80ms แต่ interval 50ms → task อื่นจะถูกลดเวลา — ต้องออกแบบให้แต่ละ task จบภายใน 1-5ms

💻 เขียน Code ทีละขั้น

ขั้นที่ 1: Init + สร้าง Task Functions

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "SimpleScheduler.h"

// Task callbacks — ต้อง void(void)
void task_sensor(void) {
    static float temp;
    if(DHT_Read(&temp, NULL) == DHT_OK)
        USART_Print("T:"); USART_PrintFloat(temp, 1); USART_Println("");
}
void task_display(void) {
    digitalToggle(PC0);  // Heartbeat LED
    USART_Println(".");
}
void task_button(void) {
    static uint8_t last = 1;
    uint8_t now = digitalRead(PC1);
    if(!now && last) USART_Println("BTN!");
    last = now;
}

🔍 แต่ละ task เป็นฟังก์ชัน void task_name(void) — ต้องจบภายในเวลาไม่เกิน interval ของ task ที่ถี่ที่สุด — ใช้ static variable เก็บ state — DHT_Read อาจใช้เวลานาน (~25ms) จึงต้องตั้ง interval ≥ 2000ms

ขั้นที่ 2: Add Tasks + Start Scheduler

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    USART_Init(115200);
    pinMode(PC0, PIN_MODE_OUTPUT);    // Heartbeat LED
    pinMode(PC1, PIN_MODE_INPUT_PULLUP);  // Button

    DHT_Init(PC2, DHT11);
    Scheduler_Init();
    Scheduler_AddTask(task_sensor,  2000);  // ทุก 2 วิ
    Scheduler_AddTask(task_display,  500);  // ทุก 0.5 วิ
    Scheduler_AddTask(task_button,    50);  // ทุก 50ms
    Scheduler_Start();

🔍 Scheduler_AddTask(callback, interval_ms) — เพิ่ม task ก่อน Start — ต้องเรียก Scheduler_Init() ก่อน — interval ควรเป็นเท่าของ task ที่ถี่ที่สุดเพื่อให้ predictable — 8 tasks max

ขั้นที่ 3: Run Loop

    while(1) {
        Scheduler_Run();
        IWDG_Feed();  // เลี้ยงระหว่าง idle
    }
}

🔍 Scheduler_Run() — หัวใจของ scheduler — เช็คทุก task ว่าถึงเวลาหรือยัง — ถ้าไม่มี task ไหนถึงเวลา จะ return ทันที (ไม่ delay) — main loop ควรเบา — IWDG_Feed() ถูกเรียกทุกรอบแม้ไม่มี task ทำงาน

📋 API Reference

ฟังก์ชันคำอธิบายตัวอย่าง
Scheduler_Init()เริ่มต้น scheduler — เคลียร์ task ทั้งหมดScheduler_Init()
Scheduler_AddTask(cb, ms)เพิ่ม task — cb=void(void), interval เป็น msScheduler_AddTask(task_led, 500)
Scheduler_Start()เริ่ม scheduler — ต้องเรียกหลัง AddTask ทั้งหมดScheduler_Start()
Scheduler_Run()เรียกใน while(1) — เช็คและรัน task ที่ถึงเวลาwhile(1){Scheduler_Run();}
Scheduler_Stop()หยุด scheduler — task จะไม่ถูกรันScheduler_Stop()
Scheduler_RemoveTask(index)ลบ task ตาม index (0-7)Scheduler_RemoveTask(2)
Scheduler_SetInterval(index, ms)เปลี่ยน interval ของ task ใน runtimeScheduler_SetInterval(0, 1000)
Scheduler_GetTaskCount()คืนจำนวน task ที่ลงทะเบียนuint8_t n = Scheduler_GetTaskCount()

⚠️ ข้อผิดพลาดที่พบบ่อย

ปัญหาสาเหตุวิธีแก้
Task ไม่ถูกรันเลยลืม Scheduler_Start() — หรือ Scheduler_Run() ใน loopต้องเรียกทั้ง Start และ Run — Check: Init → AddTask → Start → while(Run)
Task ทำงานไม่ตรงเวลา — ดีเลย์สะสมTask ใช้เวลานานกว่า interval — task อื่นถูก delayแบ่งงานหนักเป็น state machine — ใช้ Timer_t แบบ async — ลด interval ให้เหลือ 1ms/รอบ
Task A block แล้ว Task B ไม่ทำงานใช้ Delay_Ms() ใน task callbackห้ามใช้ Blocking Delay ใน task — ใช้ flag + state machine — หรือตั้ง Timer_t แยก
เพิ่ม task เกิน 8 แล้วไม่แจ้ง errorลิมิต 8 tasks — task ที่ 9+ ถูกละเลยเช็ค Scheduler_AddTask return 0 — หรือเพิ่ม MAX_TASKS ใน header
Stack overflow — MCU resetTask ใช้ local variable เยอะเกิน — stack พอกลด local var — ใช้ global/static — CH32V003 มี RAM แค่ 2KB
Task ทำงานซ้ำซ้อน — 2 รอบติดกันInterval สั้นเกิน + task ช้า — scheduler คิดว่าถึงเวลา 2 รอบเพิ่ม interval ให้มากกว่า execution time — หรือใช้ Scheduler_ResetTask(index)

🛠️ สร้าง Product: 3-Task System

Task 1: อ่านเซนเซอร์ทุก 2 วิ — Task 2: อัปเดตจอ OLED ทุก 0.5 วิ — Task 3: เช็คปุ่มกดทุก 50ms — LED heartbeat

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "SimpleScheduler.h"
#include "DHT.h"
#include "OLED.h"

OLED_t oled;
float temp = 0, hum = 0;
uint8_t btn_state = 0;

void task_sensor(void) {
    DHT_Read(&temp, &hum);
}
void task_display(void) {
    OLED_Clear(&oled);
    OLED_SetCursor(&oled,0,0); OLED_PrintFloat(&oled,"T:",temp,1);
    OLED_SetCursor(&oled,0,1); OLED_PrintFloat(&oled,"H:",hum,1);
    OLED_Display(&oled);
    digitalToggle(PC3);  // Heartbeat
}
void task_button(void) {
    static uint8_t last = 1;
    uint8_t now = digitalRead(PC1);
    if(!now && last) { btn_state = !btn_state;
        USART_Println(btn_state ? "ON" : "OFF"); }
    last = now;
}

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    USART_Init(115200);
    DHT_Init(PC0, DHT11);
    pinMode(PC1, PIN_MODE_INPUT_PULLUP);
    pinMode(PC3, PIN_MODE_OUTPUT);
    OLED_Init(&oled, 0x3C, OLED_128x64);
    OLED_SetFont(&oled, FONT_8x16);

    Scheduler_Init();
    Scheduler_AddTask(task_sensor,  2000);
    Scheduler_AddTask(task_display,  500);
    Scheduler_AddTask(task_button,    50);
    Scheduler_Start();

    while(1) { Scheduler_Run(); IWDG_Feed(); }
}

✏️ ลองทำดู

  1. เพิ่ม Task ควบคุม PID — task_pid ทุก 1 วิ — ใช้ PID_Compute คำนวณ output — เปิด heater relay
  2. Task Profiling — วัด execution time ของแต่ละ task ด้วย Get_CurrentUs() — แสดงทาง USART ว่าตัวไหนหนักสุด
  3. Dynamic Interval — เปลี่ยน interval task_button จาก 50ms → 300ms เมื่อไม่ได้กดนาน 10 วิ — ประหยัด CPU
