OH49E เป็น Linear Hall Sensor แบบ Ratiometric — Output เป็น analog voltage แปรผันตามสนามแม่เหล็ก — Sensitivity ประมาณ 1.4mV/Gauss

📚 หลักการทำงาน

OH49E เป็น Linear Hall Effect Sensor — ตรวจจับสนามแม่เหล็กและคืนค่าแรงดัน analog แบบ Ratiometric (แปรผันตาม VCC) — Sensitivity ประมาณ 1.4mV/Gauss — วัดได้ทั้งขั้ว North และ South

Ratiometric Output หมายความว่าแรงดัน output เป็นสัดส่วนกับ VCC — ที่ 0 Gauss output = VCC/2 — ถ้า VCC=3.3V → zero=1.65V

การใช้งาน: วัดความแรงสนามแม่เหล็ก, ตรวจจับตำแหน่งแม่เหล็ก, Current Sensor, ตรวจจับการเปิด-ปิด (Proximity Switch)

💻 เขียน Code ทีละขั้น

ขั้นที่ 1: Init OH49E

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "OH49E.h"

OH49E_Instance hall;

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    USART_Init(115200);

    OH49E_Init(&hall, ADC_CH_PC4, 3.3f, 3.3f);
    // adc_ch, vcc, vref
    USART_Println("OH49E Hall Sensor Ready!");

🔍 OH49E_Init(&hall, ADC_CH_PC4, vcc, vref) — ตั้งค่า ADC + VCC reference — VCC และ Vref มักเท่ากับ 3.3V สำหรับ CH32V003

ขั้นที่ 2: อ่าน Voltage + Field Strength

    float v = OH49E_ReadVoltage(&hall);
    int str = OH49E_GetFieldStrength(&hall);

    USART_Print("Voltage: ");
    USART_PrintFloat(v, 3);
    USART_Print(" V  |  Field: ");
    USART_PrintDec(str);
    USART_Print(" Gauss");

    if(str > 10) {
        USART_Println(" SOUTH+");
    } else if(str < -10) {
        USART_Println(" NORTH-");
    } else {
        USART_Println(" ~ZERO");
    }

🔍 OH49E_ReadVoltage(&hall) — อ่านแรงดัน output (V) — OH49E_GetFieldStrength(&hall) — อ่านค่า Gauss (ค่าบวก=South, ค่าลบ=North) — threshold ±10 Gauss กัน noise

ขั้นที่ 3: ตรวจจับแม่เหล็ก + LED แสดงขั้ว

    pinMode(PC0, PIN_MODE_OUTPUT); // LED South
    pinMode(PC1, PIN_MODE_OUTPUT); // LED North

    while(1) {
        int str = OH49E_GetFieldStrength(&hall);

        if(str > 15) {
            digitalWrite(PC0, HIGH); // South detected
            digitalWrite(PC1, LOW);
        } else if(str < -15) {
            digitalWrite(PC0, LOW);
            digitalWrite(PC1, HIGH); // North detected
        } else {
            digitalWrite(PC0, LOW);
            digitalWrite(PC1, LOW);
        }
        Delay_Ms(50);
    }
}

🔍 ใช้ hysteresis ±15 Gauss — LED 2 ดวงแสดงขั้วแม่เหล็ก — South = PC0, North = PC1

⚠️ ข้อผิดพลาดที่พบบ่อย

ปัญหาสาเหตุวิธีแก้
ค่าไม่เปลี่ยนเมื่อเอาแม่เหล็กเข้าใกล้แม่เหล็กอ่อนเกิน/อยู่ไกลเกินใช้แม่เหล็ก Neodymium — ให้ใกล้ผิวเซนเซอร์ที่สุด
ค่า Gauss เพี้ยนหลังจากเปลี่ยน VCCRatiometric — zero shift ตาม VCCระบุ VCC จริงตอน Init — library calibrate ให้
ค่ากระพือแม้ไม่มีแม่เหล็กNoise จาก ADC + switching power supplyใช้ averaging — ต่อ 0.1µF cap ที่ output
Output ติดอยู่ที่ 0V หรือ VCCแม่เหล็กแรงมากจนเซนเซอร์อิ่มตัวOH49E มี linear range ±1000G — ถอยแม่เหล็กออก

🛠️ สร้าง Product: Magnetic Field Strength Meter

OH49E + OLED — แสดงค่า Gauss แบบ Real-Time + กราฟแท่ง

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "OH49E.h"
#include "oled_i2c.h"

int main(void)
{
    SystemCoreClockUpdate();
    Timer_Init();
    I2C_Init(PC1, PC2, I2C_SPEED_STANDARD);
    USART_Init(115200);

    OH49E_Instance hall;
    OH49E_Init(&hall, ADC_CH_PC4, 3.3f, 3.3f);

    OLED_Handle oled;
    OLED_Init(&oled, OLED_128x64, 0x3C);
    OLED_SetFont(&oled, FONT_8x16);

    char buf[64];
    while(1)
    {
        float v = OH49E_ReadVoltage(&hall);
        int str = OH49E_GetFieldStrength(&hall);

        OLED_Clear(&oled);
        snprintf(buf, sizeof(buf), "Field: %.1f G", (float)str);
        OLED_DrawStringAlign(&oled, 0, 0, buf, ALIGN_LEFT);

        const char* pole = (str > 5) ? " SOUTH" :
                           (str < -5) ? " NORTH" : " --";
        snprintf(buf, sizeof(buf), "%s", pole);
        OLED_DrawStringAlign(&oled, 80, 0, buf, ALIGN_LEFT);

        snprintf(buf, sizeof(buf), "V: %.2f", v);
        OLED_DrawStringAlign(&oled, 0, 40, buf, ALIGN_LEFT);

        OLED_Update(&oled);
        Delay_Ms(100);
    }
}

✏️ ลองทำดู

  1. ทำ Current Sensor แบบไม่สัมผัส — พันสายไฟรอบ Toroid Core แล้ววาง OH49E ใน gap — calibrate เทียบกับ DMM
  2. ทำ RPM Sensor — ติดแม่เหล็กบนมอเตอร์ — นับจำนวนครั้งที่สนามแม่เหล็กเปลี่ยน
  3. ทำ Magnetic Door Sensor — ตรวจจับการเปิด-ปิดประตูด้วยแม่เหล็ก
