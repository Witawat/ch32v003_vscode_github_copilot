Servo — RC Servo ควบคุมด้วย PWM

PD2─Signal(orange)  5V external─VCC(servo,red)  GND─GND(common,brown)  ⚡ ห้ามจ่าย servo จาก WCH-Link!
MCU Pin→อุปกรณ์ขาหมายเหตุ
PD2 (PWM)→Servo SG90Signal (Orange)PWM 50Hz ควบคุมมุม
5V→Servo SG90VCC (Red)External 5V, ห้ามใช้ WCH-Link
GND↔Servo SG90GND (Brown)กราวด์ร่วม MCU + servo power

Servo RC ใช้สัญญาณ PWM ความถี่ 50Hz (คาบ 20ms) ควบคุมมุมด้วยความกว้าง pulse:

มุมPulse (SG90 มาตรฐาน)Duty ที่ 50Hz
0°0.5ms2.5%
90°1.5ms7.5%
180°2.5ms12.5%
#include "Servo.h"
Servo_Instance s;
Servo_Init(&s, PWM1_CH4);
Servo_Attach(&s);
Servo_Write(&s, 0);   Delay_Ms(1000);  // 0°
Servo_Write(&s, 90);  Delay_Ms(1000);  // 90°
Servo_Write(&s, 180); Delay_Ms(1000);  // 180°

// ป้องกันมุมเกินขอบ (soft limit):
uint8_t angle = 90;
if(angle > 180) angle = 180;
Servo_Write(&s, angle);

⚠️ 50Hz = ค่าคงที่ ห้ามเปลี่ยน! — servo ทุกตัวใช้ 50Hz (20ms frame), pulse range 0.5-2.5ms เป็นค่ามาตรฐาน SG90 — servo บางตัวใช้ 1-2ms (เช็ค datasheet), servo กินไฟ ~500mA ตอน stall (มอเตอร์ติดขัด) → ต้องใช้ external 5V, ห้ามจ่ายจาก WCH-Link (Link จ่ายได้ ~100mA), GND ต้องต่อร่วมระหว่าง MCU กับ servo power supply, ควรมี min/max angle protection (soft limit) ป้องกัน servo พยายามหมุนเกินขอบเขตเชิงกล → servo พัง, ถ้าต่อ servo หลายตัว → ใช้ external 5V 2A+ และต่อ capacitor 470µF-1000µF ขนานกับ power rail ป้องกัน voltage sag

API หลัก

PWM_SimpleInit(ch, pin, freq)Init PWM channel/chip/frequencyPWM_SetDuty(ch, duty%)ตั้ง duty cycle 0-100%
PWM_Start(ch)เริ่มสร้างสัญญาณ PWMPWM_Stop(ch)หยุด PWM output
PWM_SetPeriod(ch, freq)เปลี่ยนความถี่ PWMPWM_GetDuty(ch)อ่านค่า duty ปัจจุบัน

ServoTester — เครื่องมือ Calibrate Servo (PWM)

#include "ServoTester.h"
ServoTester_Init(1, PD2);          // PWM channel 1, pin PD2
ServoTester_Sweep(0, 180, 2);      // 0° → 180° → 0°, ทีละ 2°/step
ServoTester_SetCenter(90);          // ตั้ง center position (90°)
ServoTester_TestRange(500, 2500);   // ทดสอบ pulse 500µs-2500µs ทีละ 100µs

// ใช้ Sweep หา min/max จริงของ servo:
ServoTester_Sweep(0, 180, 1);      // 1°/step — สังเกตว่า servo หยุดหมุนที่มุมไหน
// ถ้า servo กระตุกที่ 0° → min pulse อาจต้องปรับเป็น 600µs
// ถ้า servo กระตุกที่ 180° → max pulse อาจต้องปรับเป็น 2400µs

⚠️ ใช้หา min/max pulse ของ servo แต่ละตัว — servo แต่ละรุ่น/ยี่ห้อ pulse range ไม่เท่ากัน: บางตัว 0°=500µs บางตัว 0°=1000µs, center=1500µs ตามมาตรฐาน RC servo, วิธี calibrate: 1) เปิด Sweep(0,180,1) ดูว่า servo เริ่มกระตุกที่มุมไหน → บันทึกเป็น min/max, 2) ใช้ SetCenter(90) ดูว่า servo อยู่ตรงกลางจริงหรือไม่ → ถ้าไม่ → offset pulse, 3) ใช้ TestRange(min_us, max_us) ทดสอบช่วง pulse ที่บันทึกไว้ — servo ควรหมุนนุ่มนวลตลอดช่วง, ใช้ ServoTester ก่อนต่อ servo เข้ากับโปรเจกต์จริงเพื่อป้องกัน servo พัง

API หลัก

ServoTester_Init(ch, pin)Init PWM + channelServoTester_Sweep(min,max,step)Sweep angle ไป-กลับ
ServoTester_SetCenter(deg)Center positionServoTester_TestRange(us_min,us_max)ทดสอบช่วง pulse
ServoTester_SetPulse(us)ส่ง pulse แบบระบุ µsServoTester_Stop()หยุด sweep

StepperMotor — 28BYJ-48 + ULN2003 (GPIO)

PC0─IN1(blue)  PC1─IN2(pink)  PC2─IN3(yellow)  PC3─IN4(orange)  5V external─VCC(ULN2003+)  GND─GND(ULN2003-)

28BYJ-48 specs: 5V, 0.3 kg·cm torque, 1:64 gear ratio, 5-wire unipolar
MCU Pin→อุปกรณ์ขาหมายเหตุ
PC0→ULN2003 → StepperIN1 (Blue)Coil 1 drive
PC1→ULN2003 → StepperIN2 (Pink)Coil 2 drive
PC2→ULN2003 → StepperIN3 (Yellow)Coil 3 drive
PC3→ULN2003 → StepperIN4 (Orange)Coil 4 drive
5V→ULN2003VCC (ULN2003+)External 5V จ่าย motor
GND↔ULN2003GND (ULN2003−)กราวด์ร่วม
 
#include "StepperMotor.h"
StepperMotor_Instance st;
StepperMotor_InitULN2003(&st, PC0, PC1, PC2, PC3, 2048);
StepperMotor_SetSpeed(&st, 5);              // 5 RPM
Stepper_SetMode(&st, STEPPER_FULL_STEP);

// Full-step: 2048 steps = 1 revolution
StepperMotor_Move(&st, 2048);             // หมุน 1 รอบ
StepperMotor_MoveDegrees(&st, 90);       // หมุน 90°

// Half-step: 4096 steps = 1 revolution (นุ่มนวลกว่า)
Stepper_SetMode(&st, STEPPER_HALF_STEP);
StepperMotor_SetSpeed(&st, 3);              // ลด speed เพราะ step เพิ่ม 2 เท่า
StepperMotor_Move(&st, 4096);             // หมุน 1 รอบ (half-step)

// Direction control:
Stepper_SetDirection(&st, STEPPER_CW);     // clockwise
StepperMotor_Move(&st, 1024);                 // หมุนครึ่งรอบ
Stepper_SetDirection(&st, STEPPER_CCW);    // counter-clockwise
StepperMotor_Move(&st, 1024);                 // หมุนกลับครึ่งรอบ

// Pattern: conveyor belt forward → pause → backward
while(1) {
    Stepper_SetDirection(&st, STEPPER_CW);
    StepperMotor_Move(&st, 8192);  // 4 รอบ (ระยะทาง conveyor)
    Delay_Ms(2000);        // หยุด 2s
    Stepper_SetDirection(&st, STEPPER_CCW);
    StepperMotor_Move(&st, 8192);  // กลับ
    Delay_Ms(2000);
}

⚠️ 28BYJ-48 = 2048 steps/rev (full-step), 4096 steps/rev (half-step) — gear ratio 1:64, torque ~0.3 kg·cm (เบามาก), ULN2003 รับ 5V logic (CH32V003 3.3V → marginal แต่ใช้งานได้ — ULN2003 threshold ~2.5V), ควรทำ acceleration (ramp speed): ค่อยๆ เพิ่มความเร็วตอน start และลดความเร็วตอน stop → ป้องกัน step loss, Full-step vs Half-step: half-step torque ลดลง ~30% แต่หมุนนุ่มนวลกว่าและเพิ่ม resolution 2 เท่า, การคำนวณระยะทาง: 1 รอบ = 2048 steps → ถ้ารู้ระยะทางต่อรอบ (เช่น lead screw pitch) → ขั้นต่อ mm = 2048 / pitch_mm, 28BYJ-48 กินไฟ ~200mA ตอน full load → ใช้ external 5V 1A

API หลัก

StepperMotor_InitULN2003(in1..in4)Init 4 GPIO pinsStepperMotor_SetSpeed(rpm)ตั้งความเร็ว RPM
StepperMotor_Move(steps)หมุน N ขั้น (blocking)StepperMotor_MoveDegrees(deg)หมุน N องศา
Stepper_SetMode(mode)FULL_STEP/HALF_STEPStepper_SetDirection(dir)CW/CCW
Stepper_Stop()หยุดมอเตอร์Stepper_Release()ปลด coil ทั้งหมด (free spin)

L298N — DC Motor Driver H-Bridge (GPIO+PWM)

Motor A: PC0─IN1  PC1─IN2  PC4(PWM)─ENA
Motor B: PC2─IN3  PC3─IN4  PC5(PWM)─ENB (optional)
5-12V external─VCC(motor, terminal block)  5V─VCC(logic)  GND─GND(common)

⚠️ ถ้าใช้ไฟ motor >12V → ถอด jumper 5V regulator ออก!
⚠️ 5V terminal ใช้จ่าย CH32V003 ได้ (ถ้า motor ≤12V, regulator in use)
MCU Pin→อุปกรณ์ขาหมายเหตุ
PC0→L298N Motor AIN1Direction bit 1
PC1→L298N Motor AIN2Direction bit 2
PC4→L298N Motor AENAPWM speed (หรือ jumper = full)
PC2→L298N Motor BIN3Direction bit 1
PC3→L298N Motor BIN4Direction bit 2
PC5→L298N Motor BENBPWM speed (หรือ jumper = full)
5–12V→L298N MotorVCC (terminal)External power สำหรับ motor
5V→L298N Logic5V (logic)ใช้ onboard regulator หรือ external
GND↔L298NGNDกราวด์ร่วม
 
#include "L298N.h"
// Init motor A (IN1, IN2, ENA)
pinMode(PC0, PIN_MODE_OUTPUT); pinMode(PC1, PIN_MODE_OUTPUT);
PWM_SimpleInit(1, PC4, 1000);   // 1kHz PWM
PWM_Start(1);

// Forward 75% speed:
digitalWrite(PC0, HIGH); digitalWrite(PC1, LOW);
PWM_SetDuty(1, 75);
Delay_Ms(2000);

// Reverse 50% speed:
digitalWrite(PC0, LOW); digitalWrite(PC1, HIGH);
PWM_SetDuty(1, 50);
Delay_Ms(2000);

// Brake (motor short — หยุดเร็ว):
digitalWrite(PC0, HIGH); digitalWrite(PC1, HIGH);
PWM_SetDuty(1, 100);    // duty 100% = full brake force

// Coast (free spin — ปล่อยให้ไหล):
digitalWrite(PC0, LOW); digitalWrite(PC1, LOW);

// === Differential Drive (2-wheel robot) ===
// Left motor = IN1,IN2  Right motor = IN3,IN4
// Turn right: left=forward, right=reverse
void robot_turn_right(int speed) {
    digitalWrite(IN1, HIGH); digitalWrite(IN2, LOW);   // left fwd
    digitalWrite(IN3, LOW);  digitalWrite(IN4, HIGH);  // right rev
    PWM_SetDuty(1, speed); PWM_SetDuty(2, speed);
}
// Turn left: left=reverse, right=forward
// Stop: brake both

⚠️ L298N มี 2 motor channels (IN1-IN2 = Motor A, IN3-IN4 = Motor B), ENA/ENB = PWM speed control — ต่อกับ PWM pin ของ CH32V003 (ถ้าไม่ใช้ PWM → ต่อ ENA/ENB กับ 5V jumper → full speed ตลอด), มี flyback diode ในตัว (1N4007 × 8) — แต่ถ้ากระแสสูง (>1A) หรือ PWM ความถี่สูง (>10kHz) ควรเพิ่ม Schottky diode ภายนอก, VCC motor (6-12V) กับ VCC logic (5V) แยกกัน → ถ้าใช้ >12V ต้องถอด jumper 5V regulator ออกและจ่าย 5V logic แยก, duty cycle ต่ำ (<20%) motor อาจไม่หมุนเพราะแรงดันตก — minimum ~2V สำหรับ DC motor ทั่วไป, L298N voltage drop ~2V (Darlington transistor) → ถ้าใช้ 6V motor จริง motor ได้แค่ ~4V

API หลัก

pinMode(pin, PIN_MODE_OUTPUT)ตั้ง GPIO เป็น outputdigitalWrite(pin, HIGH/LOW)เขียน logic level
PWM_SimpleInit(ch, pin, freq)Init PWM channelPWM_SetDuty(ch, 0-100)ปรับ speed 0-100%
PWM_Start(ch)เริ่ม PWMPWM_Stop(ch)หยุด PWM

DRV8825 — Stepper Driver Microstep (GPIO)

PC0─DIR    PC1─STEP   PC2─ENABLE(opt,LOW=on)   PC3─M0   PC4─M1   PC5─M2  (microstep select)
12-24V external─VMOT  GND─GND(common)  Motor: A1/A2(1 coil)  B1/B2(1 coil)

⚠️ ต้องตั้ง current limit pot ก่อนใช้! — หมุน Vref ให้ถูกต้อง ก่อนต่อ motor
MCU Pin→อุปกรณ์ขาหมายเหตุ
PC0→DRV8825DIRทิศทาง CW/CCW
PC1→DRV8825STEPStep pulse (rising edge)
PC2→DRV8825ENABLEActive LOW = on (optional)
PC3→DRV8825M0Microstep select bit 0
PC4→DRV8825M1Microstep select bit 1
PC5→DRV8825M2Microstep select bit 2
12–24V→DRV8825VMOTExternal motor power
GND↔DRV8825GNDกราวด์ร่วม
DRV8825 A1/A2→Stepper MotorCoil Aขดลวดชุด A
DRV8825 B1/B2→Stepper MotorCoil Bขดลวดชุด B
 
#include "DRV8825.h"
DRV8825_Init(PC0, PC1, PC2);             // DIR, STEP, ENABLE
DRV8825_SetMicrostep(DRV8825_1_32_STEP);  // 1/32 microstep
DRV8825_SetDirection(DRV8825_CW);
DRV8825_Enable();                          // ENABLE=LOW → driver on

// === Manual step pulse (speed control with delay) ===
uint32_t steps = 6400;  // 1 rev with 1/32 microstep (200×32)
uint32_t step_delay = 500; // µs between steps → speed
for(uint32_t i = 0; i < steps; i++) {
    DRV8825_Pulse();         // single step (toggles STEP pin)
    Delay_Us(step_delay);    // longer delay = slower
}

// === RPM-based rotation (Lib handles timing) ===
DRV8825_Rotate(60, DRV8825_1_16_STEP, 3200);  // 60RPM, 1/16, 3200 steps

// === Direction change ===
DRV8825_SetDirection(DRV8825_CW);
DRV8825_Rotate(120, DRV8825_1_8_STEP, 800);
Delay_Ms(500);
DRV8825_SetDirection(DRV8825_CCW);
DRV8825_Rotate(120, DRV8825_1_8_STEP, 800);   // back to start

// === Microstep table ===
// DRV8825_1_1_STEP  = 200 steps/rev  → 1.8°/step
// DRV8825_1_2_STEP  = 400 steps/rev  → 0.9°/step
// DRV8825_1_8_STEP  = 1600 steps/rev → 0.225°/step
// DRV8825_1_16_STEP = 3200 steps/rev → 0.1125°/step
// DRV8825_1_32_STEP = 6400 steps/rev → 0.05625°/step

⚠️ NEMA17 stepper (1.8°/step = 200 steps/rev full-step) — microstepping เพิ่ม resolution แต่ torque ลดลงตาม microstep (1/32 ≈ 5% torque!), VMOT 8.2-45V — higher voltage = faster max speed, current limit potentiometer ต้องตั้งก่อนใช้! สูตร: Vref = I_limit × 0.5 (DRV8825) — ใช้มัลติมิเตอร์วัด Vref ที่ pot pin เทียบ GND, logic 3.3V OK — CH32V003 ต่อตรงได้, STEP pin trigger on rising edge, min pulse width 1.9µs, DIR ต้องตั้งก่อน STEP pulse (timing: t_SU ≥ 650ns before step), DRV8825 ต่างจาก A4988: DRV8825 microstep ได้ละเอียดกว่า (1/32 vs 1/16) และ current rating สูงกว่า (2.5A vs 2A), heat sink จำเป็นที่กระแส >1A — DRV8825 ร้อนมาก

API หลัก

DRV8825_Init(dir,step,en)Init GPIO pinsDRV8825_SetMicrostep(m)เลือก microstep 1/1~1/32
DRV8825_SetDirection(d)CW/CCWDRV8825_Pulse()Generate 1 step pulse
DRV8825_Rotate(rpm,m,steps)หมุน N steps ที่ RPMDRV8825_Enable()/Disable()เปิด/ปิด driver
DRV8825_Reset()Reset driverDRV8825_Sleep()Sleep mode (ประหยัดไฟ)

Relay — Relay Module (GPIO)

PC0─IN(signal)  5V─VCC(power)  GND─GND
COM─common  NO─normally open  NC─normally closed  → load

Module ภายใน: optocoupler + transistor + flyback diode + relay coil
Typical relay: SRD-05VDC (5V coil, 10A/250VAC or 10A/30VDC)
MCU Pin→อุปกรณ์ขาหมายเหตุ
PC0→Relay ModuleIN (Signal)HIGH/LOW ควบคุม relay
5V→Relay ModuleVCCจ่ายไฟ 5V (coil ~70mA)
GND↔Relay ModuleGNDกราวด์ร่วม
COM↔LoadCOMขั้วกลาง relay
NO→LoadNOปกติเปิด (ต่อเมื่อ relay ON)
NC→LoadNCปกติปิด (ต่อเมื่อ relay OFF)
 
#include "Relay.h"
Relay_Instance r;
Relay_Init(&r, PC0, RELAY_ACTIVE_HIGH);

// Basic on/off:
Relay_On(&r); Delay_Ms(5000); Relay_Off(&r);

// Toggle:
Relay_Toggle(&r);  // flip state
Delay_Ms(1000);
Relay_Toggle(&r);  // flip back

// === Pattern: Timer relay (on 5 min, off 5 min) ===
uint32_t start = Timer_GetMillis();
uint8_t relay_state = 0;  // 0=OFF, 1=ON
while(1) {
    uint32_t elapsed = Timer_GetMillis() - start;
    if(elapsed > 300000) { // 5 minutes = 300,000ms
        relay_state = !relay_state;
        if(relay_state) Relay_On(&r);
        else Relay_Off(&r);
        start = Timer_GetMillis();
    }
    IWDG_Feed();
}

// === Active Low module (บางโมดูลใช้ LOW→ON) ===
// Relay_Init(&r, PC0, RELAY_ACTIVE_LOW);
// HIGH = OFF, LOW = ON

⚠️ เช็ค ACTIVE_HIGH vs ACTIVE_LOW ก่อนใช้! — บางโมดูล HIGH→ON, บางโมดูล LOW→ON (ต้องอ่าน datasheet), flyback diode มีในโมดูลแล้ว (optocoupler + diode + transistor) → ไม่ต้องเพิ่ม external diode, switching inductive load (มอเตอร์, solenoid, pump) → ควรเพิ่ม snubber circuit (RC: 100Ω + 0.1µF ในอนุกรม ขนานกับ contact) — ลด arcing และ EMI, ⚡ ห้ามต่อ 220VAC ถ้าไม่รู้วิธี! — ไฟบ้านอันตรายถึงชีวิต ต้องมีความรู้และอุปกรณ์ป้องกัน (MCB, fuse, enclosure), รีเลย์ contact มีอายุการใช้งาน: electrical ~100,000 cycles (ที่ rated load), mechanical ~10,000,000 cycles, switching speed: ~5-10ms on, ~3-5ms off — ไม่เหมาะกับ PWM หรือ switching ความถี่สูง → ใช้ MOSFET/SSR แทน, ใช้ external 5V จ่าย relay module (coil กิน ~70mA) — CH32V003 pin จ่ายได้ ~8mA ไม่พอ

Relay_GetState(pin)อ่านสถานะ (0/1)Relay_Pulse(pin, ms)เปิด N ms → ปิด

✏️ ลองทำดู

  1. Servo pan-tilt 2-axis — ใช้ joystick 2 ADC pots (PC4=x, PC5=y) ควบคุม servo PD2=pan, PD3=tilt → map ADC 0-4095 → angle 0-180 (อย่าลืม external 5V 2A)
  2. Stepper conveyor belt — forward 4096 steps (2 revs) → stop 2s → reverse 4096 → loop → เพิ่ม acceleration ramp (start slow, increase speed, slow before stop)
  3. L298N 2-wheel robot — differential drive: left wheel forward + right backward = turn right (ใช้ทั้ง 2 channel), ทำระยะไกล: เดินหน้า 2s, เลี้ยวขวา 1s, เดินหน้า 2s, หยุด
  4. DRV8825 CNC-style — absolute positioning ด้วย limit switch (PC3=limit X): home→move 5000 steps→check switch→reverse→home → ใช้ 1/16 microstep เพิ่มความแม่นยำ
  5. Relay timer — on 5 นาที, off 5 นาที, วน loop → ต่อ LED เป็น load → ถ้าต้องการความแม่นยำ ใช้ DS3231 RTC (บทจัดเก็บ) แทน Timer_GetMillis()
