ShiftReg595 — 74HC595 GPIO

74HC595 ใช้ 3 ขา (DATA, CLK, LATCH) — 8 outputs ต่อ chip — ต่อพ่วงหลายตัวได้ — output กระแส ~6mA ต่อขา — ใช้ external 5V ได้ (CH32V003 3.3V logic ใช้ได้กับ 74HC595 5V)

📚 หลักการทำงาน

Serial-In Parallel-Out (SIPO): 74HC595 รับข้อมูล serial 1 bit ต่อครั้งผ่านขา DATA — CLK ใช้ shift ข้อมูลเข้า register — LATCH pulse คัดลอกข้อมูลจาก shift register ไป output register — output เปลี่ยนพร้อมกันทุกขา

8 Outputs per Chip: แต่ละ 74HC595 มี 8 outputs (Q0-Q7) — เขียนค่า 8-bit (0-255) เข้า shift register — Update() ส่ง LATCH pulse — LEDs เปลี่ยนพร้อมกัน (no flicker)

Chain Multiple Chips: ต่อ Q7' (pin 9) ของตัวแรกเข้า DATA ของตัวที่สอง — ส่งข้อมูล 16-bit ต่อเนื่อง — LATCH pulse เดียวอัปเดตทุกตัวพร้อมกัน — ShiftReg595_Write16() สำหรับ 2 chips

No PWM: 74HC595 เป็น digital output เท่านั้น — ไม่มี PWM ในตัว — ถ้าต้องการ PWM ต้องใช้ software PWM หรือใช้ GPIO ของ MCU โดยตรง — แต่ต่อ LEDs มากกว่า 8 ดวงด้วย GPIO 3 ขาเท่านั้น

💻 เขียน Code ทีละขั้น

ขั้นที่ 1: Init + Setup

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "ShiftReg595.h"

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();

    ShiftReg595_Init(PC0, PC1, PC2);  // DATA, CLK, LATCH

🔍 ShiftReg595_Init(data, clk, latch) ตั้ง 3 ขา — ใช้ GPIO bit-bang — ไม่ต้องใช้ SPI — 3.3V logic ใช้กับ 74HC595 ได้ (V_IH min = 3.15V สำหรับ VCC=5V)

ขั้นที่ 2: เขียนค่า + Update

    // LED สลับฟันปลา
    ShiftReg595_Write(0b10101010);
    ShiftReg595_Update();
    Delay_Ms(500);

    // LED ตรงข้าม
    ShiftReg595_Write(0b01010101);
    ShiftReg595_Update();
    Delay_Ms(500);

    // ควบคุมทีละ bit
    ShiftReg595_WriteBit(0, 1);  // Q0 = HIGH
    ShiftReg595_WriteBit(7, 1);  // Q7 = HIGH
    ShiftReg595_Update();

    // 16-bit สำหรับ 2 chips
    ShiftReg595_Write16(0b1111000000001111);
    ShiftReg595_Update();

🔍 Write(value) เขียน 8-bit ลง buffer — ต้องเรียก Update() เพื่อ latch output — WriteBit(bit, val) เปลี่ยนทีละบิต — Write16 สำหรับ 2 chips ต่อพ่วง

ขั้นที่ 3: LED Chaser Binary Counter

    uint8_t counter = 0;

    while(1) {
        ShiftReg595_Write(counter);
        ShiftReg595_Update();
        Delay_Ms(200);
        counter++;
    }
}

🔍 Binary counter 0-255 — LEDs แสดงผลเป็น binary — 8-bit counter วิ่งวน — Delay_Ms 200ms ต่อขั้น — ดูจังหวะ shift อย่างชัดเจน

🛠️ สร้าง Product: LED Chaser 8 ดวง

LED 8 ดวงวิ่งไปมา (Knight Rider / Larson Scanner) — ใช้ Non-Blocking Timer

#define CH32V003_PACKAGE PACKAGE_TSSOP20
#include "SimpleHAL.h"
#include "ShiftReg595.h"

int main(void) {
    SystemCoreClockUpdate();
    Timer_Init();
    ShiftReg595_Init(PC0, PC1, PC2);

    Timer_t tmr;
    Start_Timer(&tmr, 100, 1);
    int8_t pos = 0, dir = 1;

    while(1) {
        if(Is_Timer_Expired(&tmr)) {
            uint8_t pattern = 1 << pos;
            ShiftReg595_Write(pattern);
            ShiftReg595_Update();

            pos += dir;
            if(pos >= 7 || pos <= 0) dir = -dir;
        }
    }
}

✏️ ลองทำดู

  1. Binary Counter — นับ 0-255 แสดงผลบน LED 8 ดวง — ใช้ Non-Blocking Timer 100ms
  2. Knight Rider — LED วิ่งไป-กลับ 8 ดวง — smooth acceleration ด้วย delay แปรผัน
  3. Chain 2 Chips — ต่อ 16 LEDs — ใช้ Write16() — ทำ pattern 16-bit (เช่น ไฟวิ่ง 2 ดวงสวนกัน)
